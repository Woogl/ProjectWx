# Wiki

## 한줄 요약

프로젝트 지식은 주제별 Wiki에서 찾고, 개발 작업의 판단과 진행은 Workflow에서 관리합니다.

AI가 원자료를 확인하여 재사용할 지식을 작성·갱신합니다. 주제 개요에서 책임·진입점과 상세 기능을 찾고, 구현 변경 전에는 각 페이지의 근거와 검증 범위를 확인합니다. 사람의 기획·설계·리뷰·테스트 판단은 [Workflow](../workflow/index.md)에서 진행합니다.
