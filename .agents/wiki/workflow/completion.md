# 완료

상태: current · 범위: 인간 테스트 승인 후 전체 작업 완료 처리 · 기준: 2026-09-21 사용자 합의, 작업 트리 반영

작업 단계: 완료

**테스터 승인 후 AI가 자료를 정리하고 작업을 마칩니다.**

- 사람: 최종 결과와 남은 제약을 확인합니다.
- AI: 확정 기획·설계, 코드 리뷰, 테스트 승인 근거를 연결합니다.
- AI: 재사용할 지식은 위키에 반영하고 불필요한 임시 자료를 정리합니다.

사람이 문서를 다시 조립하거나 복사할 필요는 없습니다. 필요한 판단·승인 근거는 보존합니다.

[테스트](testing.md) 결과를 인간이 승인하면 이 단계로 넘어옵니다. 자동 테스트 통과나 AI 판단만으로 완료 처리하지 않습니다.

최종 기획서 확정본의 버전, 구현 체크리스트와 설계 합의, 인간 코드 리뷰 결과, 테스트 결과 및 인간 승인 근거를 연결합니다. 승인자·승인일·승인 범위와 남은 제약을 확인하고 전체 작업을 완료로 표시합니다. 인간이 예외로 수용한 미검증 항목은 수용 근거와 함께 남기고 테스트 통과로 바꾸지 않습니다.

이 연결·기록·최종 인계 자료 정리는 AI가 수행합니다. 사람이 문서를 조립하거나 판단 내용을 다시 옮기지 않습니다. 각 단계의 판단 원문과 통합 확정본을 함께 연결하고 후속 수정으로 철회·대체된 결정을 현재 근거로 사용하지 않습니다. OpenWiki의 기획·설계 확정 인계 문서는 해당 단계의 스냅샷이며 코드 리뷰나 테스트 수용을 대신하지 않습니다.

변경된 동작·검증 결과·남은 제약을 사용자에게 설명합니다. 변경 내역은 Git으로 추적하며 작업별 worklog는 작성하지 않습니다. 완료 처리 자체가 외부 전송·커밋·푸시 권한을 부여하지는 않습니다.

## 작업 자료 정리

완료 인계에는 AI의 자료 정리도 포함합니다. [보존·정리 절차](../maintenance.md#작업-자료의-보존과-정리)에 따라 재사용할 현재 동작·제약·결정 이유만 기존 Wiki 정본에 통합하고, `.agents/in-progress/`의 해결된 지적·중복·임시 자료를 정리합니다. 원문 판단과 필요한 승인·검증 근거의 복원 가능성을 먼저 확인하고, 확인할 수 없는 자료는 보존 이유와 함께 유지합니다. 보류한 후속 항목은 이유와 재개 조건을 남깁니다.

OpenWiki의 확정 인계·판단 기록·변경 연결·저장 복구 자료는 직접 삭제하지 않습니다. 변경 작업으로 대체된 확정본도 당시 판단·승인 근거로 보존합니다. 브라우저 상태를 확인하지 못하면 관련 자료를 보존합니다. 링크·의존 목록을 함께 갱신하고 정리 결과는 대화로 전달합니다. 별도 완료 보고서나 archive 폴더를 만들지 않습니다.

재사용할 작업 방법이 생기면 [작업 가이드 작성](../documents/write-guide.md)을 참고합니다. 새로운 가이드를 만드는 것 자체는 필수가 아닙니다.
