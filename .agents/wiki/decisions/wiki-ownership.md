# Wiki에 모듈 설명 통합

상태: current · 범위: 문서 운영 결정 · 결정일 2026-09-20

이 작업의 사용자 대화에서 모듈 README 본문을 Wiki에 통합하고 기존 위치에는 링크만 남기는 제안을 제시했으며, 사용자가 “네, 좋습니다. 진행합시다.”라고 승인했다. 이 문서는 해당 대화의 수기 기록이며 별도 대화 내보내기 파일은 없다.

- 모듈 설명은 `modules/`에서 관리한다.
- 루트 README는 프로젝트 소개와 Wiki 입구로 유지한다.
- 모듈 README는 해당 Wiki 페이지로 연결하는 안내만 담는다.
- 기획·회의록·코드·리뷰 원자료는 보존한다.
- 기존 설명 이관을 코드 재검증 완료로 표시하지 않는다.

이 결정은 게임 규칙이나 코드 구조를 변경하지 않는다. 관련: [운영 절차](../maintenance.md), [목차](../index.md).

## 작업별 worklog 폐지

2026-09-20 같은 대화에서 신규 worklog 작성과 강제 훅을 폐지하고 기존 기록은 보관하며 필요한 지식만 Wiki로 흡수하자는 제안에 사용자가 “네 정리합시다.”라고 승인했다.

변경 내역은 Git, 현재 설명은 Wiki 모듈·시스템, 설계 결정은 decisions, 미결정은 questions로 관리한다. Wiki log는 작업 일지를 대체하지 않고 Wiki 갱신 이력만 기록한다. 최초 정리에서는 기존 기록을 보존했으며, 아래 후속 결정으로 보관 방침을 대체했다.
