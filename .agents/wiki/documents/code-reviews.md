# 코드 리뷰

상태: current · 범위: 코드 리뷰·검토 기록 탐색 · 기준: 2026-09-21 작업 트리의 문서 존재 여부 확인

후속 조치에 필요한 리뷰는 `.agents/in-progress/`에서 대상별 하나로 관리합니다. 현재 미해결 사항·미확인 범위만 유지하고 해결된 지적은 제거합니다. 보존 이유가 없어지면 [보존·정리 절차](../maintenance.md#작업-자료의-보존과-정리)에 따라 문서와 목록 링크를 정리합니다. 기존 자료의 경로 이관은 코드 재검증이 아니며, 리뷰 제안은 확정 결정이 아닙니다.

## 모듈 코드 리뷰

현재 등록된 모듈 리뷰 문서는 없습니다. 모듈 리뷰는 AI 워크플로우와 별도로 운영하며, 워크플로우의 인간 코드 리뷰 수용 여부를 대신하지 않습니다.

현재 보관 중인 과거 점검 보고서는 없습니다. 수행 절차는 [워크플로우 / 코드 리뷰](../workflow/implementation.md#인간-코드-리뷰)를 참고합니다.
