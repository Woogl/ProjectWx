# 사용 방법 안내

상태: current · 범위: 웹 중심 작업·판단 흐름 · 기준: 2026-09-21 사용자 합의; 자동화 회귀 검사, 실제 AI·게임 실행은 별도 검증

**사람은 판단하고, AI는 조사·구현·검증·기록을 맡습니다.**

1. **작업**에서 제목과 기획서를 입력하고 AI 검토를 시작합니다.
2. AI가 묻는 질문에 답합니다. 답변을 결정하면 AI가 다시 검토합니다.
3. **기획 확정 · 설계 검토**를 누르면 AI가 코드를 조사하고 필요한 설계 판단을 준비합니다.
4. **설계 확정 · AI 구현 시작**을 누르면 AI가 구현·자체 검증을 수행합니다.
5. 결과와 코드 변경을 보고 **코드 리뷰 승인** 또는 **수정 요청**을 선택합니다. 승인하면 AI 검증이 이어집니다.
6. AI 검증 결과와 직접 확인할 항목을 확인하고 **결과 수용 · 완료**를 누릅니다.

다음 단계와 자료 전달은 자동으로 연결됩니다. 원본·이미 결정한 답변·상세 근거는 필요할 때 펼칩니다. 미실행 검사는 미검증으로 표시하며, 이를 수용할 때는 이유를 남깁니다.

## 실행과 공유

- 실행: 저장소의 BatchFiles/OpenWorkflow.bat.
- 기획·설계 검토: 설치·로그인된 Codex, Claude Code, Gemini CLI 중 사용합니다.
- 구현·검증 실행: 현재는 Codex CLI의 저장소 쓰기 샌드박스를 사용합니다. 실행 권한이나 환경이 부족하면 사유를 표시합니다.
- 입력·판단·실행 결과는 .agents/in-progress/에 자동 저장됩니다. 같은 저장소를 사용하는 사람이 함께 확인할 수 있습니다. 별도 PC에는 Git 등으로 파일을 전달해야 합니다.
- 구현·검증은 브라우저를 닫아도 계속됩니다. 서버가 중단되면 완료로 처리하지 않고 현재 변경을 확인해 이어갑니다. 기획·설계 검토 중에는 결과가 나올 때까지 화면을 유지합니다.
- 같은 입력을 서로 수정한 경우에만 사용할 내용을 묻습니다. 다른 작업은 계속할 수 있습니다.
