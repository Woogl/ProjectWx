# 기획

## 한줄 요약

기획 원본의 미정·충돌을 사람의 판단으로 해소하고, 통합 기획을 확정해 설계로 넘깁니다.

작업 단계: 기획

[전체 흐름과 공통 판단 규칙](index.md)을 기준으로 진행합니다. 입력은 기획서 원본이며 원본·인간 판단·AI 통합 초안을 구분합니다.

## 진행 절차

1. **새 작업 제목 입력 → 새 작업 만들기**로 시작하거나 **기존 작업**에서 이어갈 작업을 선택합니다. 기존 작업의 입력 수정·파일 불러오기는 그 작업의 개정이며, 독립된 새 작업에는 이전 판단·의견·초안을 넘기지 않습니다.
2. 제목과 기획서를 입력합니다. 원본을 붙여 넣거나 UTF-8 .md·.txt, .docx·.pdf·.pptx 파일을 불러온 뒤 **AI 기획 검토 · 답변 반영**을 누릅니다. 첨부 자료의 추출 한계는 [도구 구조](../../wiki/knowledge/tooling/wiki-workflow.md#로컬-웹-뷰어)를 참고합니다.
3. AI는 목적·범위·동작·수치·예외·완료 기준을 분석하고 필요한 판단만 질문합니다. [공통 판단 절차](index.md#기획설계의-공통-판단-절차)에 따라 답변 결정과 AI 재검토를 반복합니다. 검토 이후 수정 의견은 **추가 요청·수정 의견**에 적습니다.
4. 사람이 통합 기획과 판단 기록을 확인하고 **기획 확정 · 설계 검토**를 누릅니다. AI가 확정본과 원본·판단·관련 자료를 저장·연결하면 [설계 검토](implementation.md)가 자동으로 이어집니다.

## 최종 기획서 확정본 작성

AI는 원본과 답변을 단순히 이어 붙이지 않고 다음 내용을 하나의 기획서로 통합합니다.

- 목적·범위·제외 범위
- 동작 규칙과 수치, 정상·예외·경계 조건
- 기대 결과·완료 기준
- 판단 근거, 확정 시점·버전·적용 범위

미정 수치나 정책을 임의로 채우지 않습니다. 확정 후 수정은 [확정 이후 변경](index.md#확정-이후-변경)을 따릅니다.
