# 완료

## 한줄 요약

테스트 수용 후 승인 근거를 연결하고, 재사용할 지식과 작업 자료를 정리해 완료합니다.

작업 단계: 완료

[테스트](testing.md) 결과를 사람이 수용한 뒤 진행합니다. 자동 테스트 통과나 AI 판단만으로 완료 처리하지 않습니다.

## 완료 확인

AI는 최종 기획·설계 버전, 구현 범위, 인간 코드 리뷰 결과, 테스트 결과와 승인자·승인일·승인 범위·남은 제약을 연결합니다. 각 판단 원문과 통합 확정본을 함께 참조하며 철회·대체된 결정을 현재 근거로 사용하지 않습니다. 기획·설계 확정 인계는 해당 단계의 스냅샷으로, 코드 리뷰·테스트 수용을 대신하지 않습니다.

## 작업 자료 정리

AI는 [보존·정리 절차](records.md)에 따라 재사용할 지식을 기존 Wiki 정본에 통합하고 작업 자료를 정리합니다. 판단·승인 근거의 복원 가능성과 현재 저장·복구 참조를 확인한 뒤 정리하며, 확인할 수 없는 자료는 이유와 함께 유지합니다. Workflow 확정본과 판단 원문은 보존합니다. 보류한 후속 항목에는 이유와 재개 조건을 남깁니다.

재사용할 작업 방법이 생기면 [작업 방법 작성](../../wiki/wiki-maintenance.md#작업-방법-작성)을 따릅니다. 새 문서 작성 자체는 완료 조건이 아닙니다.

## 최종 전달

수용 범위 확인과 정리를 마친 뒤 작업을 완료로 표시하고 변경된 동작·검증 결과·남은 제약·유지한 자료의 이유를 대화로 전달합니다. 별도 완료 보고서·archive 폴더·worklog는 만들지 않습니다. 완료 처리는 외부 전송·커밋·푸시 권한을 부여하지 않습니다.
