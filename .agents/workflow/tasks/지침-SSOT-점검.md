## 조사 근거

- AGENTS.md와 작업 절차, 프로젝트 스킬, Wiki/README.md, 하네스 설정 및 Workflow 프롬프트를 대조했다. Gemini는 AGENTS.md를 직접 지정하고 Workflow 요청문도 정본 경로를 참조한다.
- 주석 정리 스킬은 작업별 worklog를 금지해 변경 작업의 기록을 요구하는 정본과 충돌했다.
- 모듈 리뷰의 기록 보존·상태 규칙은 스킬에도 별도로 있었다.
- 일반 작업의 커밋 금지와 Git 스킬·기존 무인 실행의 경계가 정본에 명시되지 않았다. 일일 Routine의 기존 승인 근거는 comment-cleanup-routine.md에 있다.
- Wiki 갱신 sparse 사본은 AGENTS.md가 참조하는 작업 절차 정본을 누락했다.
- Wiki 도구 버전은 README 본문과 설정 스크립트에 중복되어 있었으며, 서버는 이미 설정 스크립트 태그를 읽고 있었다. 본문을 그 태그 참조로 바꿨다.
- Wiki 주제 문서는 과거 결정의 출처와 정본 우선 안내를 제공한다. 생성 문서와 캡처 원자료는 이번 작업에서 수정하지 않았다.
