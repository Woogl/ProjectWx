- D1 (확인) Wiki 원자료 112건의 `refresh_due`가 모두 2026-10-26이다. `lint --as-of 2026-10-27`은 오류 343건("accepted claims require fresh active support")이고, 레저를 쓰는 모든 트랜잭션이 막힌다. README 2단계(수집 뒤, 10개씩)로는 풀리지 않고, 기한이 가까운 active 원자료 전부의 `refresh_due`만 트랜잭션 하나로 늦춰야 풀린다(점검 중 순정 검증기로 모의 실험).
- D2 (확인) 스킬 두 개가 작업 중인 AI에게 Wiki 직접 수정을 지시한다: `comment-cleanup/SKILL.md:73`, `module-review/SKILL.md:154`. 정본 145행("Wiki는 Wiki 갱신만 씁니다")과 어긋나고 플러그인 레저를 우회한다.

- E1 Wiki 절차의 빈 곳: 이름이 바뀌거나 지워진 기획서 처리, 날짜는 UTC, 원본은 바이트 그대로 복사, 무인 실행에서 페이지 삭제·병합·이름 변경 금지, 새 원자료가 옛 결정과 어긋날 때 순정 대체(`supersedes`)로 처리.
