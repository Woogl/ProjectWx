## 요청

- 요청자: woogle · 2026-09-27

> 현재 캐릭터의 이동속도를 처리할 때 CharacterMovementComponent의 이동속도에 MOV 스탯을 배율로 곱하는 방식으로 구현이 되어있습니다.
> MOV 스탯을 아예 CharacterMovementComponent의 이동속도를 대신하는 스탯으로 바꿔주세요. 그러니까 MOV 스탯이 500 이면, 500 cm/s로 이동할 수 있는 상태인 것입니다.
> 어트리뷰트 테이블에도 MOV 스탯 입력을 추가합니다.

## 구현 계획

추가 질문 없음. 아래 계획으로 구현 승인을 요청합니다.

**정한 것**
- `UWxCombatAttributeSet::SPD`의 이름을 요청 용어대로 `MOV`로 바꾸고, 값을 이동 속도(cm/s)로 바꾼다. 캐릭터의 `MaxWalkSpeed`는 MOV 값을 그대로 쓴다(MOV 500 = 500 cm/s). 이름이 바뀌어서, 배율 뜻으로 남은 호출이 있으면 컴파일 오류로 모두 드러난다.
- 질주(×1.5)와 정찰·배회 감속은 지금처럼 `WxEffect_MoveSpeedScale`이 MOV에 배율을 곱한다(예: 500 × 1.5 = 750).
- 기본 이동 속도는 테이블 한 곳에서만 정한다. 캐릭터 생성자의 `MaxWalkSpeed = 500/400` 줄과 어트리뷰트 초기값 `InitSPD(1.f)`를 지운다. MOV 열의 기본값은 다른 스탯 열처럼 0이다. 그래서 MOV를 채우지 않은 행의 캐릭터는 움직이지 않고, 입력 누락이 바로 눈에 띈다.
- 범위 밖: 앉은 속도(`MaxWalkSpeedCrouched`), 공격 속도 배율 `ASPD`는 그대로 둔다.

**코드 변경**
1. `Plugins/WxCombat/.../Attribute/WxCombatAttributeSet.h/.cpp`: `SPD`를 `MOV`로 바꾼다(접근자·`OnRep_MOV`·복제 등록 포함). 주석을 cm/s 의미로 고치고 약어 표를 갱신한다. 생성자의 `InitSPD(1.f)`를 지운다.
2. `.../Attribute/WxCombatAttributeInitTableRow.h`: `float MOV = 0.f;`를 추가한다(Category Combat, ClampMin 0, 단위 cm/s).
3. `.../WxAbilitySet.cpp` `GiveToAbilitySystem`: `Row->MOV`를 MOV 베이스에 기록한다.
4. `Source/WxGame/Character/WxCharacterBase.h/.cpp`: `HandleSPDAttributeChanged`를 `HandleMOVAttributeChanged`로 바꾼다. 초기 1회 적용과 변경 콜백 모두 `MaxWalkSpeed = MOV`로 하고, 클래스 기본값을 읽던 코드는 지운다.
5. `WxPlayerCharacter.cpp`·`WxEnemyCharacter.cpp`: 생성자의 `MaxWalkSpeed` 줄을 지우고, 이 때문에 쓰지 않게 된 include가 있으면 정리한다.
6. `WxEffect_MoveSpeedScale.cpp`: 대상 어트리뷰트를 MOV로 바꾼다.
7. `WxEffect_MoveSpeedOverride.h/.cpp`: MOV를 절대값(cm/s)으로 덮어쓴다. 배율이 아니므로 SetByCaller 태그는 `SetByCaller.MoveSpeedScale` 대신 기존의 범용 태그 `SetByCaller.Magnitude`를 재활용한다(새 태그는 만들지 않음).
8. `Plugins/WxAI/.../WxBTService_MirrorMovement.h/.cpp`: 도플갱어 추적 속도는 `Master MaxWalkSpeed × 1.25`라는 절대값을 `SetByCaller.Magnitude`에 실어 보낸다. 클래스 기본 MaxWalkSpeed로 나눠 배율을 만들던 계산은 지운다. SPD 주석도 고친다.
9. 주석만 고치는 곳: `WxGameplayTags.h`(MoveSpeedScale 설명을 'MOV에 곱하는 배율'로), `WxAbility_Sprint.h`, `WxBTTask_Wander.cpp`, `WxBTTask_Patrol.cpp`의 SPD 언급을 MOV로 바꾼다.

**데이터 이관 (`Content/DesignerTables/DT_CharacterAttribute`)**
- 지금 실제 이동 속도는 C++ 기본값 그대로다(캐릭터 BP 7개 모두 MaxWalkSpeed를 덮어쓰지 않음). 속도가 그대로 유지되도록 행에 다음 값을 채운다.

**문서**
