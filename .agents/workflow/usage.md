# 사용 방법 안내

## 한줄 요약

OpenWorkflow에서 작업을 열면 입력·판단·결과가 공용 파일에 저장되어 다음 단계로 이어집니다.

작업 순서와 판단 기준은 [Workflow](process/index.md), 단계별 입력 방법은 [기획](process/planning.md)에서 설명합니다.

## 실행과 작업 열기

저장소의 [OpenWorkflow.bat](../../BatchFiles/OpenWorkflow.bat)을 실행합니다. 기획·설계 검토에는 설치·로그인된 Codex, Claude Code, Gemini CLI 중 하나를 사용하며 구현·검증에는 현재 Codex CLI가 필요합니다. 실행 권한이나 환경이 부족하면 실패 사유를 확인합니다.

처음 열거나 새로고침하면 빈 시작 화면을 표시합니다. 저장된 작업은 **기존 작업**에서 선택합니다. 원본·이미 결정한 답변은 작업 화면에서 필요할 때 펼치며, 진행상황은 검토·답변·확정 기록에서 자동 계산합니다.

구현·검증은 브라우저를 닫아도 계속됩니다. 서버가 중단되면 완료로 간주하지 않고 AI가 현재 변경과 실행 상태를 확인해 이어갑니다. 기획·설계 검토 중에는 결과가 나올 때까지 화면을 유지합니다.

## 저장과 공유

입력·판단·실행 결과는 `.agents/workflow/tasks/`의 공용 파일에 저장되고 브라우저는 미전송 입력·실패 요청의 복구 자료를 유지합니다. 저장 실패 시 표시되는 오류와 복구 안내를 따르며, 중복 작업을 새로 만들어 복구하지 않습니다.

한 작업은 한 사람이 편집하고 다른 사람은 공용 파일로 진행상황을 확인합니다. 오래된 저장 요청은 거부되며 동시 편집 병합·충돌 선택 화면은 제공하지 않습니다. 별도 PC·체크아웃에는 작업 파일과 관련 확정 인계·공용 기록을 함께 전달해야 합니다. 자동 Git 전송은 하지 않습니다.

작업 제목은 식별자입니다. 변경이 필요하면 **현재 작업 제목 변경**을 사용하여 파일명과 참조를 함께 갱신합니다. 관련 파일을 직접 이름 변경하지 않습니다.

문서 열람은 [Wiki](../wiki/index.md), 실행 제약·저장·복구의 상세 구조는 [Wiki·Workflow 도구 구조](../wiki/knowledge/tooling/wiki-workflow.md)를 참고합니다.
