# 사용 방법 안내

## 기존 작업의 테스트 결과 전달

1. **작업 현황 대시보드**에서 확인한 작업의 **테스트 결과**를 선택합니다.
2. **처리할 AI**에서 연결된 Codex·Claude Code·Gemini CLI 중 하나를 고릅니다. 확인자와 직접 확인한 항목을 적고 **이상 없음 / 이상 있음** 중 하나를 선택합니다.
3. **이상 있음**이면 나타나는 입력란에 문제 상황과 재현 방법을 적습니다.
4. **AI에게 전달**을 누르면 접수 후 처리 상태·결과·다시 확인할 항목을 같은 화면에서 볼 수 있습니다.

이상 없음은 AI가 확인 범위를 대조하고 남은 정리를 수행합니다. 이상 있음은 기존 합의 범위에서 수정·검증한 뒤 재확인을 요청합니다. 코드가 바뀌었거나 미확인 항목이 남으면 완료로 처리하지 않습니다.

전송 실패 시 입력과 AI 선택을 보존하며, 응답을 받지 못한 요청은 같은 버튼으로 다시 확인할 수 있습니다. AI 처리 실패·중단 시에는 **처리할 AI**를 그대로 두거나 다른 AI로 바꾼 뒤 **저장된 결과로 AI 다시 시도**를 선택합니다. 이전 처리 AI와 결과도 이력에 남습니다. 접수 이후 코드가 바뀌었다면 새 결과를 제출합니다.

선택 목록에는 서버가 찾은 로컬 CLI만 표시됩니다. 해당 서비스의 로그인과 사용 가능한 권한이 필요하며, 권한 때문에 수행하지 못한 검증·정리는 결과에서 확인할 수 있습니다.

접수 내용과 결과는 작업 기록에 남습니다. 대시보드 상태는 자동으로 갱신되며, 문서 본문에 추가된 기록은 `OpenWorkflow.bat`으로 화면을 다시 만들면 보입니다. AI 연결이 없거나 이전 버전이면 같은 배치 파일을 다시 실행합니다.
