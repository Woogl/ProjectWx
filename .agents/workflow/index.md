# Workflow

## 한줄 요약

공통 작업 절차와 개별 작업 기록을 한 공간에서 관리합니다.

프로젝트 지식은 [Wiki](../wiki/index.md), 작업 진행 방법은 `process/`, 개별 작업의 상태·판단·확정본·미해결 리뷰·검증 근거는 `tasks/`에 둡니다. 완료 여부는 상태로 관리하며 완료만으로 작업 파일을 이동하지 않습니다.

## 개별 작업

웹의 기존 작업 목록은 `tasks/`의 공용 작업 파일에서 읽습니다. 대화로 수행한 작업의 후속 리뷰도 같은 폴더에 두며, 웹 작업을 별도로 만들 필요는 없습니다. 현재 필요한 후속 조치가 없고 보존할 판단 근거도 없으면 결과를 대화로 전달합니다.
