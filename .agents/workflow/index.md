# Workflow

## 한줄 요약

공통 작업 절차와 개별 작업 기록을 한 공간에서 관리합니다.

프로젝트 지식은 [Wiki](../../.wiki/_index.md), 작업 진행 방법은 `process/`, 개별 작업의 상태·판단·확정본·미해결 리뷰·검증 근거는 `tasks/`에 둡니다. 완료 여부는 상태로 관리하며 완료만으로 작업 파일을 이동하지 않습니다.
