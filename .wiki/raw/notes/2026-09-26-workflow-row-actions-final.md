# 사용자 결정

2026-09-26 사용자가 대시보드를 테스트하며 앞선 결정(확인 대기에는 기록 열기 없음, 완료에는 작업 진행 없음, raw/notes/2026-09-26-workflow-dashboard-row-actions.md)에 이어 "진행 중도 기록 열기 버튼 없애주세요", "\"사람이 작업하고 판단하는 공간\"이라는 왼쪽 탭 문구 제거해주세요"라고 했다. 또 "AI 확인 요청" 표시가 있는 행의 버튼 줄이 맞지 않는 화면을 알려줬다.

# 구현 관찰

- `.agents/scripts/wiki-viewer/workflow.js`: 확인 대기·진행 중 행은 작업 진행 버튼만, 완료·리뷰·참고 행은 기록 열기만 둔다. 생성 문서에 아직 없는 새 기록 안내도 기록 열기 자리에만 나온다.
- 줄 어긋남 원인: 행마다 따로 그리는 그리드의 버튼 칸이 `auto`라, 버튼 아래 상태 배지가 붙은 행만 칸이 넓어져 다음 행동 열과 버튼이 왼쪽으로 밀렸다. 버튼 칸을 160px로 고정하고 오른쪽 정렬했다. 1000px 이하에서는 버튼 칸이 행 아래로 내려가 왼쪽 정렬이다.
- 사이드바의 소개 문구 요소(`#purpose`)와 문구를 넣던 스크립트 줄, 전용 스타일을 지웠다. 사이드바는 Workflow 화면에서만 보이므로 Wiki 화면에는 영향이 없다.

# 검증

- TestWikiViewer: 확인 대기·진행 중 행은 작업 진행 버튼만, 완료 행은 기록 열기만, 리뷰·참고 행은 버튼 없음.
- 헤드리스 Edge 1920px: 확인 대기 17행 모두 다음 행동 열 왼쪽(877)과 버튼 오른쪽(1743)이 같았고, 배지가 있는 체크포인트 행도 같았다. 900px에서는 버튼 칸이 행 아래 왼쪽에 모였다. 사이드바는 로고 아래 메뉴가 바로 오고 스크립트 오류가 없었다.
