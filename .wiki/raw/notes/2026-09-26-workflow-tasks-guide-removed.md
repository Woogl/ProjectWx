# 사용자 요청

2026-09-26 사용자가 "기록 작성 규칙 버튼 제거해주세요. 안쓰는 문서라면 문서까지도 제거하구요."라고 했다.

# 관찰과 변경

- `.agents/workflow/tasks/index.md`는 같은 날 "작업 현황 목록은 이 문서에 적지 않는다, 규칙은 작업 절차에 있다"는 안내 두 줄로 줄어 있었다. 쓰는 곳은 대시보드의 기록 작성 규칙 링크, `.agents/workflow/index.md` 목차의 작업 현황 줄, Wiki `wiki-workflow`의 한 문장뿐이었다. 목록을 만드는 `--tasks` 명령과 상태 줄 규칙은 작업 절차 문서에도 있어 정보 손실이 없다.
- 대시보드 머리는 제목과 새 작업 버튼만 남았다. 목차 줄을 지우고, 서버의 기록 경로 검사·작업 목록 생성과 화면의 기록 목록에서 `index.md`를 제외하던 조건도 지웠다. 기록 폴더의 모든 `.md`가 작업 기록이다.
- 문서는 `git rm -f`로 지웠다(사용자가 직접 요청한 삭제라 자동 모드에서도 허용됐다). 과거 작업 기록과 원자료에 남은 `tasks/index.md` 언급은 이력이라 그대로 둔다.

# 검증

- TestWikiViewer(대시보드 머리가 제목·새 작업 버튼뿐), TestWorkflowTestFeedback(안내 문서 없는 기록 폴더), 링크 검사로 확인했다.
