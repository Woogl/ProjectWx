# 사용자 요청

2026-09-26 사용자는 새 작업 기록 이름이 `task-<해시>.md`가 된다는 안내를 보고 "해시 말고 한글로 추적할 수는 없나요?"라고 물었다. AI는 한글 제목 이름이 사람·AI 모두 제목으로 찾기 쉬워 더 낫다고 답하고, 승인된 웹 새 작업 기능의 세부 사항으로 바로 바꿨다.

# 구현 관찰

- 이름: 제목을 NFC로 정규화하고 글자·숫자(`\p{L}\p{N}`)가 아닌 연속 문자를 `-` 하나로 바꾼다. 앞뒤 `-`를 지우고 60자로 자른다. Windows 예약 이름(CON·PRN·AUX·NUL·COM1~9·LPT1~9)은 `-작업`을 붙이고, 남는 글자가 없으면 `작업`이다. 대소문자는 그대로 둔다(`Boss HP bar 개선` → `Boss-HP-bar-개선.md`, `저장/복원: "좌표" 확인?` → `저장-복원-좌표-확인.md`).
- 같은 이름: `이름.md`가 있으면 `이름-2.md`, `이름-3.md` 순서로 빈 이름을 찾고 배타적 생성(`wx`)으로 쓴다. Windows에서는 대소문자만 다른 이름도 같은 이름으로 본다.
- 재전송: 이름에 접수 식별자가 없으므로 같은 접수는 처리 이력(`test_feedback_*.json`)의 create 요청에서 찾는다. 내용이 같으면 그 기록을 돌려주고, 다르면 "같은 접수의 내용이 바뀌었습니다"로 거절한다. 서버를 다시 시작해도 같다.
- 터미널에서 이어하기: 영문·숫자 이름 제한을 없앴다. cmd 특수 문자(`"`·`%`·`^`·`&`·`|`·`<`·`>`·`!`)는 창을 여는 쪽에서 막고, 새 기록 이름에는 이 문자가 생기지 않는다.
- AI 처리 이력 파일 이름(`test_feedback_<기록 경로 SHA-256>.json`)은 바꾸지 않았다.

# 검증

- TestWorkflowTestFeedback: 한글 제목 이름, 같은 제목의 `-2`, 기호·예약 이름·빈 이름, 서버 재시작 뒤 재전송, 작업 목록의 한글 기록 표시, 한글 경로 이어하기 인자를 확인했다.
- 실제 `cmd start` 창에서 `.agents/workflow/tasks/보스-체력바-지연-감소.md`가 든 이어하기 요청문이 인자 하나로 그대로 전달됐다(인자 기록 스크립트, AI 호출 없음).
- Git은 `core.quotepath`가 기본값이면 한글 경로를 8진수 escape(`\353\263\264…`)로 보여준다. 이 저장소에는 설정이 없다.
