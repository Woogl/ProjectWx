# WX

프로젝트 기술 문서는 [WX Wiki](Wiki/README.md)에서 관리합니다.

Obsidian에서 `Wiki/` 폴더를 "Open folder as vault"로 한 번 연 뒤에는 [OpenWiki.bat](BatchFiles/OpenWiki.bat)을 더블클릭해 엽니다. 작업 현황은 [OpenWorkflow.bat](BatchFiles/OpenWorkflow.bat)으로 봅니다.

**WX**는 포스트 아포칼립스 세계를 배경으로 한 3D 액션 게임입니다.  
플레이어는 무너진 문명의 잔해 속에서 다양한 적과 맞서 싸워야합니다.
때로는 피하고, 때로는 충돌하며 어떤 방식으로 살아갈지 선택하세요.
