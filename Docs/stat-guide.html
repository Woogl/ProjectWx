전투 시스템 어트리뷰트 및 공식 레퍼런스

어트리뷰트 요약

모든 전투 어트리뷰트는 UWxCombatAttributeSet에 정의되며, 3개 카테고리로 나뉜다.

어트리뷰트 카테고리 범위 설명
HP Vital 0 ~ MaxHP 현재 체력. 0 이하 시 사망
MaxHP Vital ≥ 1 최대 체력. 변경 시 HP 비율 유지
MP Vital 0 ~ MaxMP 마나. 어빌리티 사용 비용
MaxMP Vital ≥ 0 최대 마나
DP Vital 0 ~ MaxDP 무력화 게이지. MaxDP 도달 시 그로기
MaxDP Vital ≥ 1 무력화 최대치 (그로기 임계값)
ATK Combat 제한 없음 공격력. 대미지 공식의 기본값
DEF Combat 제한 없음 방어력. 대미지 경감률에 사용
SPD Combat 제한 없음 이동속도 배율 (기본값 1.0)
CritRate Combat 제한 없음 치명타 확률 (1당 1%)
CritDMG Combat 제한 없음 치명타 피해 보너스 (1당 +1%)
IncomingDamage Meta - 대미지 전달용 임시 어트리뷰트 (비복제)

생존 스탯

HP

HP Health Points

캐릭터의 현재 체력. 대미지를 받으면 감소하며, 0 이하가 되면 사망 상태(State.Dead)가 발동한다.

범위: 0 ~ MaxHP (클램프)
사망 조건: IncomingDamage에 의해 HP ≤ 0
비율 유지: MaxHP 변경 시 HP를 비율로 재조정
복제: 항상 복제 (REPNOTIFY_Always)
MP

MP Mana Points

어빌리티를 사용하기 위한 자원. 어빌리티마다 고유한 MP 소모량이 있으며, MP가 부족하면 어빌리티를 사용할 수 없다. 공격이 적중하면 5 MP가 자동으로 회복된다.

범위: 0 ~ MaxMP (클램프)
적중 시 회복: +5 MP (고정값)
궁극기 비용: 100 MP
복제: 항상 복제
DP

DP Daze Points

무력화 게이지. 피격 시 최종 대미지만큼 DP가 누적되며, MaxDP에 도달하면 그로기 상태(State.Groggy)가 발동한다. 그로기 상태에서는 DP가 시간에 따라 자동 감소하며, 0이 되면 그로기가 해제된다.

범위: 0 ~ MaxDP (클램프)
누적량: = 최종 대미지
그로기 조건: DP ≥ MaxDP
그로기 중 누적: 불가 (그로기 상태에서 DP 미증가)

그로기 DP 드레인

그로기가 발동하면 DP가 일정 속도로 감소한다. 총 드레인 시간은 GroggyDuration 프로퍼티로 설정한다.

// 초당 30회 틱으로 DP를 감소 DrainPerTick = (MaxDP / GroggyDuration) × (1 / 30) NewDP = max(CurrentDP - DrainPerTick, 0) // DP가 0에 도달하면 그로기 해제 if NewDP ≤ 0 → State.Groggy 태그 제거

전투 스탯

ATK

ATK Attack

공격력. 대미지 계산 공식의 기본값으로 사용된다. 공격자의 ATK가 높을수록 더 많은 대미지를 준다.

역할: 대미지 공식의 Source 값
클램프: 없음
DEF

DEF Defense

방어력. 경감률 계산에 사용되어 받는 대미지를 줄인다. DEF 100이면 대미지 50% 감소, DEF 200이면 약 67% 감소.

역할: 대미지 경감률의 Target 값
경감률 공식: 100 / (100 + DEF)

DEF에 따른 대미지 경감률

DEF 0 100 / (100 + 0) = 100% 대미지
DEF 50 100 / (100 + 50) = 66.7% 대미지
DEF 100 100 / (100 + 100) = 50.0% 대미지
DEF 200 100 / (100 + 200) = 33.3% 대미지
DEF 400 100 / (100 + 400) = 20.0% 대미지
SPD

SPD Speed

이동속도 배율. 캐릭터의 기본 이동속도(BaseWalkSpeed)에 곱하여 최종 이동속도를 결정한다. 기본값 1.0으로, 대시 중에는 +0.5가 더해져 1.5배속이 된다.

기본값: 1.0 (배율)
적용 공식: MaxWalkSpeed = BaseWalkSpeed × SPD
대시 보너스: SPD + 0.5 (대시 중)
복제: 항상 복제
CR

CritRate Critical Rate

치명타 확률. 1당 1%의 확률로 치명타가 발동한다. 치명타 확률은 0~100% 범위로 클램프된다.

단위: 1 = 1% 확률
공식: Clamp(CritRate × 0.01, 0, 1)
CD

CritDMG Critical Damage

치명타 추가 피해. 1당 +1%의 추가 대미지를 적용한다. CritDMG 100이면 치명타 시 2배 대미지.

단위: 1 = +1% 추가 피해
배율 공식: 1 + CritDMG × 0.01

치명타 계산 예시

CritRate = 50, CritDMG = 150 인 경우:

치명타 확률 50 × 0.01 = 50%
치명타 배율 1 + 150 × 0.01 = 2.5x
일반 피해 (ATK 200, DEF 100) 200 × 0.5 = 100
치명타 피해 100 × 2.5 = 250

대미지 계산 파이프라인

공격이 적중하면 WxDamageExecCalc에서 다음 순서로 대미지를 계산한다.

무적 체크
→
퍼펙트 가드 체크
→
기본 대미지
→
치명타 판정
→
가드 감소
→
HP 감소 + DP 누적

1. 무적 체크

대상이 ANS.Invincible 태그를 보유하면 대미지를 적용하지 않고 즉시 종료한다.

2. 퍼펙트 가드

대상이 ANS.PerfectGuard 태그를 보유하면 대미지를 무효화하고, 공격자에게 DP를 반사한다.

ReflectDP = ATK공격자 × (100 / (100 + DEF방어자)) // 반사된 DP는 공격자의 무력화 게이지에 누적

3. 기본 대미지 계산

DefenseMultiplier = 100 / (100 + DEF피격자) BaseDamage = ATK공격자 × DefenseMultiplier

4. 치명타 판정

CritChance = Clamp(CritRate공격자 × 0.01, 0, 1) if rand() < CritChance: FinalDamage = BaseDamage × (1 + CritDMG공격자 × 0.01)

5. 가드 감소

대상이 ANS.Guard 태그를 보유하면 최종 대미지가 50% 감소한다.

if Guard: FinalDamage = FinalDamage × 0.5

6. 적용

최종 대미지가 0보다 크면 다음이 적용된다:

HP피격자 -= FinalDamage // IncomingDamage를 통해 간접 적용 DP피격자 += FinalDamage // 그로기 상태가 아닐 때만 MP공격자 += 5 // 공격자 마나 회복 (고정값)
HP가 0 이하가 되면 State.Dead 태그가 부여되어 사망 어빌리티가 발동한다.
DP가 MaxDP에 도달하면 State.Groggy 태그가 부여되어 그로기 어빌리티가 발동한다.
두 판정 모두 PostGameplayEffectExecute에서 수행되어, 어트리뷰트 값이 확정된 후 처리된다.

전체 계산 예시

상황: 일반 공격

공격자 ATK=200, CritRate=30, CritDMG=100
피격자 DEF=100, HP=500, DP=20, MaxDP=200

방어 배율 100 / (100 + 100) = 0.5
기본 대미지 200 × 0.5 = 100
치명타 확률 30 × 0.01 = 30%
일반 히트 시 HP: 500 → 400  |  DP: 20 → 120
치명타 히트 시 (2.0x) HP: 500 → 300  |  DP: 20 → 220 → 200 (그로기!)

상황: 가드 중 피격

동일 조건에서 피격자가 가드 중 (치명타 미발생)

가드 전 대미지 100
가드 감소 (50%) 100 × 0.5 = 50
결과 HP: 500 → 450  |  DP: 20 → 70

상황: 퍼펙트 가드

동일 조건에서 피격자가 퍼펙트 가드 성공

피격자 대미지 0 (무효화)
공격자 DP 반사 200 × 0.5 = 100 DP
결과 피격자: 변동 없음  |  공격자: DP += 100

상태 전이

사망 (State.Dead)

조건: IncomingDamage에 의해 HP ≤ 0 발동: 사망 몽타주 재생 → 래그돌 전환 특성: 사망 중 다른 모든 어빌리티 취소 및 차단

그로기 (State.Groggy)

조건: DP ≥ MaxDP 발동: 그로기 몽타주 재생 + DP 자동 드레인 시작 해제: DP가 0에 도달 시 그로기 태그 제거 특성: 그로기 중 다른 모든 어빌리티 취소 및 차단 그로기 중 피격 시 DP가 추가 누적되지 않음 그로기 몽타주가 다른 몽타주에 의해 중단되면, 해당 몽타주 종료 후 자동 재재생

어빌리티 비용 시스템

모든 어빌리티는 MP를 소모하며, CommitAbility 시점에 비용이 차감된다.

비용 검사 및 차감

// CheckCost: 어빌리티 사용 가능 여부 가능 조건: CurrentMP ≥ MPCost // ApplyCost: 비용 차감 MP -= MPCost
MP가 부족하면 어빌리티가 활성화되지 않는다. 궁극기의 경우 비용이 100 MP이다.
