2. 생존 스탯

HP

HP & MaxHP — 체력

HP는 캐릭터가 버틸 수 있는 체력이다. 대미지를 받으면 HP가 줄어들고, HP가 0이 되면 캐릭터가 사망한다.

범위

HP는 항상 0 ~ MaxHP 사이로 유지된다. MaxHP는 최소 1 이상이어야 한다.

MaxHP 변경 시 비율 유지

버프나 레벨업으로 MaxHP가 바뀌면, 현재 HP가 같은 비율로 조정된다. 예를 들어 MaxHP 100에서 HP 60(60%)인 상태에서 MaxHP가 200으로 증가하면, HP도 120(60%)이 된다.

새 HP = 새 MaxHP × (현재 HP ÷ 이전 MaxHP)
MP

MP & MaxMP — 마나

MP는 어빌리티를 사용하기 위한 자원이다. MP 비용이 설정된 어빌리티는 MP가 부족하면 사용할 수 없다.

범위

MP는 항상 0 ~ MaxMP 사이로 유지된다. MaxMP는 최소 0 이상이다.

적중 시 MP 회복

공격이 적중할 때마다 공격자의 MP가 +5 회복된다. 단, 상대가 무적이거나 퍼펙트 가드에 성공한 경우에는 대미지가 발생하지 않으므로 회복도 일어나지 않는다.

DP

DP & MaxDP — 그로기 수치

DP는 대미지를 받을 때마다 누적되는 “충격 게이지”이다. DP가 MaxDP에 도달하면 캐릭터가 그로기 상태에 빠져 일정 시간 무방비가 된다.

범위

DP는 항상 0 ~ MaxDP 사이로 유지된다. MaxDP는 최소 1 이상이어야 한다.

DP 누적 규칙

대미지를 받으면 최종 대미지와 같은 수치만큼 DP가 증가한다. 단, 이미 그로기 상태인 동안에는 DP가 추가로 누적되지 않는다.

그로기 발동

DP가 MaxDP에 도달하면 자동으로 그로기 상태에 진입한다. 자세한 내용은 특수 상태 섹션을 참고한다.

그로기 중 DP 드레인

그로기 상태에 진입하면 DP가 5.0초에 걸쳐 자동으로 0까지 감소한다. 초당 30회 감소하며, DP가 0이 되면 그로기가 해제된다.

틱당 감소량 = MaxDP ÷ (5.0초 × 30) = MaxDP ÷ 150

예시: MaxDP가 300이면 틱당 2.0씩 감소한다. 150번의 틱(= 5초) 후에 DP가 완전히 드레인된다.

퍼펙트 가드 DP 반사

퍼펙트 가드에 성공하면 피격자는 대미지를 받지 않고, 대신 공격자의 DP가 증가한다. 반사되는 DP는 기본 대미지 공식과 동일하게 계산된다.

반사 DP = ATK공격자 × 방어배율

3. 전투 스탯

ATK

ATK — 공격력

ATK는 대미지의 기준이 되는 수치이다. ATK가 높을수록 한 번의 공격에 더 큰 대미지를 준다.

기본 대미지 = ATK × 방어배율
DEF

DEF — 방어력

DEF는 받는 대미지를 줄여주는 수치이다. DEF가 높을수록 대미지 경감률이 커지지만, 쌓을수록 효율이 떨어지는 수확 체감 구조이다. DEF를 아무리 높여도 대미지를 100% 막을 수는 없다.

방어배율 = 100 ÷ (100 + DEF)

SPD

SPD — 이동속도

SPD는 캐릭터의 기본 걸음 속도에 곱해지는 배율이다. 기본값은 1.0(=100%)이다.

실제 이동속도 = 기본 걸음 속도 × SPD

대시 (스프린트)

대시 버튼을 누르고 있으면 SPD에 +0.5가 더해진다. 버튼을 놓으면 보너스가 사라진다.

대시 중: SPD + 0.5 → 기본 SPD 1.0 기준 이동속도 150%

사망 상태에서는 대시를 사용할 수 없다.

CRIT

CritRate & CritDMG — 치명타

CritRate는 공격할 때 치명타가 터질 확률을 결정한다. CritDMG는 치명타가 터졌을 때 얼마나 더 강한 대미지를 줄지 결정한다.

치명타 확률

CritRate 1당 1% 확률이다. CritRate 50이면 50% 확률로 치명타가 발동한다. 확률은 0% ~ 100% 범위로 제한된다.

치명타 배율

치명타가 발동하면 대미지에 추가 배율이 적용된다. CritDMG 1당 +1% 추가이다.

치명타 대미지 = 기본 대미지 × (1 + CritDMG × 0.01)

4. 대미지 계산 흐름

공격이 적중하면 다음 순서로 대미지가 계산된다.

무적 판정

피격자가 무적(ANS.Invincible) 상태이면, 모든 계산을 건너뛴다. 대미지도, DP 누적도, MP 회복도 일어나지 않는다.

퍼펙트 가드 판정

피격자가 퍼펙트 가드(ANS.PerfectGuard) 상태이면:

• 피격자: 대미지 없음
• 공격자: DP += ATK공격자 × 방어배율 (DP 반사)
• 피격자에게 피격 리액션 발생

이후 계산은 중단된다.

기본 대미지 계산

공격자의 ATK와 피격자의 DEF를 사용하여 기본 대미지를 산출한다. 결과가 0 이하면 중단.

방어배율 = 100 ÷ (100 + DEF피격자)
기본 대미지 = ATK공격자 × 방어배율 (최소 0)

치명타 판정

공격자의 CritRate에 따라 치명타 여부를 확률적으로 결정한다. 치명타가 발동하면 CritDMG만큼 대미지가 증폭된다.

치명타 발동 시: 대미지 ×= (1 + CritDMG공격자 × 0.01)

가드 감소

피격자가 가드(ANS.Guard) 상태이면, 대미지가 50% 감소한다.

가드 중: 대미지 ×= 0.5

대미지 & DP 적용

최종 대미지가 0보다 크면 피격자에게 적용한다.

• 피격자 HP -= 최종 대미지
• 피격자 DP += 최종 대미지 (단, 그로기 상태가 아닐 때만)

피격 후처리

• 대미지 숫자 표시 (치명타이면 강조 표시)
• 공격자 MP +5 회복
• 피격자에게 피격 리액션 발생

대미지 공식 요약

최종 대미지 = ATK공격자 × 100 ÷ (100 + DEF피격자) × 치명타 배율 × 가드 배율

• 치명타 배율 = 치명타 발동 시 (1 + CritDMG × 0.01), 미발동 시 1.0
• 가드 배율 = 가드 중 0.5, 아닐 때 1.0

5. 전체 계산 예시

공격자: ATK 100, CritRate 25, CritDMG 150 / 피격자: DEF 100, MaxDP 300

일반 공격

평범한 한 타. 치명타 미발동, 가드 없음.

기본 대미지 = 100 × (100÷200) = 50

치명타 미발동 (75% 확률)

가드 없음

HP -50   DP +50   공격자 MP +5

치명타 공격

운 좋게 치명타가 터진 상황.

기본 대미지 = 50

치명타! ×(1 + 150×0.01) = 50 × 2.5 = 125

가드 없음

HP -125   DP +125   공격자 MP +5

가드

피격자가 가드를 올린 상태에서 맞은 경우.

기본 대미지 = 50

치명타 미발동

가드: 50 × 0.5 = 25

HP -25   DP +25   공격자 MP +5

가드 + 치명타

가드 중에 치명타를 맞은 최악의 상황.

기본 대미지 = 50

치명타! 50 × 2.5 = 125

가드: 125 × 0.5 = 62.5

HP -62.5   DP +62.5   공격자 MP +5

퍼펙트 가드

타이밍을 맞춰 퍼펙트 가드에 성공한 경우.

반사 DP = 100 × (100÷200) = 50

피격자: 대미지 없음

공격자: DP +50

피격자 HP ±0   공격자 DP +50

무적

무적 상태에서 공격을 받은 경우.

무적 상태 감지

모든 계산 건너뜀

6. 특수 상태

사망 (State.Dead)

  • 발동 조건: 대미지를 받아 HP가 0 이하로 떨어졌을 때 (이미 사망 상태가 아닌 경우에만)
  • 진입 시 동작: 캐릭터에 State.Dead 태그가 부여되고, 사망 처리가 실행된다
  • 영향: 대시 등 State.Dead에 의해 차단되는 어빌리티를 사용할 수 없게 된다

그로기 (State.Groggy)

  • 발동 조건: 대미지를 받아 DP가 MaxDP에 도달했을 때 (이미 그로기 상태가 아닌 경우에만)
  • 진입 시 동작: 캐릭터에 State.Groggy 태그가 부여되고, 그로기 어빌리티가 자동 활성화된다
  • 그로기 중: 사용 중이던 모든 어빌리티가 취소되고, 새로운 어빌리티 사용이 차단된다. 그로기 전용 모션이 재생된다
  • 지속 시간: DP가 5.0초에 걸쳐 0까지 자동 감소한다
  • 해제 조건: DP가 0에 도달하면 State.Groggy 태그가 제거되고, 정상 상태로 돌아간다
  • 그로기 중 추가 DP: 그로기 상태에서는 대미지를 받아도 DP가 추가 누적되지 않는다 (드레인만 진행)

7. 어빌리티 비용

MP 비용

MP 소모와 쿨다운

MP 비용

각 어빌리티는 고유의 MP 비용을 가질 수 있다 (기본값: 0). MP 비용이 0보다 큰 어빌리티는 사용 시 다음 과정을 거친다:

단계내용
비용 검사현재 MP가 MP 비용 이상이어야 어빌리티를 사용할 수 있다. 부족하면 사용이 차단된다.
비용 차감어빌리티가 성공적으로 활성화되면 MP에서 비용만큼 즉시 차감된다.

쿨다운

어빌리티에 쿨다운 시간과 쿨다운 태그가 설정되어 있으면, 사용 후 설정된 시간 동안 같은 어빌리티를 다시 사용할 수 없다. 쿨다운이 끝나면 자동으로 재사용 가능해진다.
