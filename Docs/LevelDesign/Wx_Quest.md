## 3. 퀘스트 요약

**습격으로 마을이 무너진 직후, 마지막으로 남은 마을 사람이 쓰러진 이장에게서 공성포 발사 코드를 받아 언덕 위 공성포를 가동시키고 적 기지의 보호막 하나를 파괴한다.**

## 4. 시놉시스

### 3.1 불타는 마을 — 이장

주인공은 이 마을 사람 출신으로, 시작 위치 언덕 위로 올라가면 불타고 있는 마을과 마을을 떠나 공성포 진지로 향하고 있는 외계인의 우주선이 보인다.
막 외계인의 습격이 끝난 마을에 도착하면 마을 사람들은 전부 쓰러져있거나 납치 당해 대화할 수 있는 사람이 없고,
유일하게 부상을 입고 벽에 기대 앉아있는 촌장과 대화할 수 있다.

촌장은 이 마을이 사실 적을 물리칠 수 있는 공성포의 시동코드를 관리하는 마을임을 알려주며,
공성포의 코드를 주인공에게 건네며 외계인에게 복수해달라고 요청한 뒤 기절한다.

대화를 마치고 나서 주인공은 저 멀리 있는 언덕 위의 공성포 진지를 바라보며 복수를 다짐하고 길을 떠난다.

### 3.2 공성포 진지 — 밸브 3개

여러 일을 겪고 난 뒤 공성포 진지에 도착한 플레이어는 문 앞의 적 보초를 무찌른 뒤 공성포 진지 앞에 쓰러져있는 경비병을 발견한다.
경비병은 명령서를 가지고 있었으며, 공성포를 작동시키기 위해서는 밸브 3개를 작동시켜야한다는 메시지와 함께 의미심장한 찢긴 메시지 또한 남겨져 있다.(이 찢겨진 곳은 외계인들의 침공을 예상하고 중앙 정부에서 지침이 내려왔음을 알리는 내용이다.)

명령서를 발견한 주인공은 다시금 복수를 다짐하며 진지 내로 들어가고, 명령서를 읽은 대로 밸브 3개를 적을 물리쳐가면서 작동시키게 된다.
밸브 3개를 작동시키면 증기 파이프들이 큰 소리를 내며 채워지고 공성포를 충전할 준비가 됐음을 알린다.

주인공은 엘리베이터를 타고 공성포까지 올라가게 된다.

### 3.3 상부 — 발사와 방어

엘리베이터를 타고 올라가니 공성포와 공성포를 작동시키는 패널이 보이며, 주인공은 촌장한테 받은 공성포 코드를 입력하여 패널을 작동시킨다.
그러자 공성포가 증기가 차오르며 충전을 시작한다.

그 때 마을을 습격한 적들이 뒤에서 튀어나오며 역시 코드가 그 마을에 숨겨져있을줄 알았다고 하며, 주인공이 함정에 걸린것이며 이제 이 공성포는 본인들이 쓰겠다고 말한다.

몰려오는 적들을 모두 물리치고 마을의 복수를 성공한 주인공.
그 뒤 공성포를 적의 본진에 겨냥하여 발사하게 되고, 명중하게 된다.

다만 적의 본진의 보호막은 여러겹으로, 3개중 1개를 부순것을 본 주인공은 이 과정을 반복해야함을 깨닫고 새로운 여정을 시작한다.

## 6. 퀘스트 상세

1. 퀘스트 발동
언덕 위에 도착해 전체 경관을 확인하면 메인 퀘스트 ‘홀로 남은 마을 생존자’가 시작된다.
목표: 불타고 있는 마을에 도착하십시오

        퀘스트 제목 : Text
        마을 목표 좌표 : Vector
        목표 문구 : Text
        완료 조건 : 마을 지역 볼륨 진입 시


2. 이장과 대화
마을 도착 시 쓰러진 이장에게 목표 인디케이터를 표시한다.
목표 변경: 쓰러진 이장과 대화하십시오

        목표 대상 : Actor Reference
        목표 문구 : Text
        이장 : 해당 목표 도중에만 대화 가능하며 그 뒤 상호작용 불가능
        완료 조건 : 대화 종료


3. 공성포 진지로 이동
이장과의 대화가 끝나면 공성포 진지에 목표 인디케이터를 표시한다.
목표 변경: 공성포 진지로 향하십시오

        목표 표시 좌표 : Vector
        목표 문구 : Text
        완료 조건 : 공성포 진지 지역 볼륨 진입 시

4. 공성포 진지 진입
플레이어가 공성포 진지 내부에 진입하면 목표가 변경된다.
목표 변경: 밸브 3개를 작동시키십시오

        밸브 : Actor Reference
        목표 문구 : Text
        완료 조건 : 밸브 3개 모두 작동

5. 엘리베이터 작동
밸브 3개를 모두 작동시키면 목표가 변경되고 엘리베이터에 목표 인디케이터를 표시한다.
목표 변경: 공성포에 코드를 입력하십시오

        목표 표시 좌표 : Vector
        목표 문구 : Text
        완료 조건 : 엘리베이터 도착


6. 엘리베이터 탑승
엘리베이터에 탑승하면 목표 인디케이터가 공성포 진지의 패널로 변경됨(목표는 변경되지 않음)

        목표 표시 좌표 : Actor Reference
        완료 조건 : 패널 입력(버튼 작동)



7. 옥상 버튼 작동 및 웨이브 전투
엘리베이터로 진지 옥상에 도착해 패널에 코드를 입력하면(버튼 작동) 웨이브 전투를 시작한다.
목표 변경: 몰려온 적들을 물리치고 공성포를 발사하십시오

        목표 대상 : Actor Reference
        목표 문구 : Text
        적 웨이브 스포너 : (우성님 재량)
        적 대사 : Data Table
        완료 조건 : 스포너에서 생성된 적 모두 처치


8. 퀘스트 완료
모든 적을 처치하면 공성포 발사 컷신을 재생한다.
컷신이 끝나면 퀘스트를 완료하고 보상을 지급한다.

        공성포 발사 컷신 : Level Sequence
        보상 : Reward Data
        완료 조건 : 컷신 재생 종료

## 6-1. 밸브 규칙

        1. 3개의 밸브를 전부 상호작용 할 경우 퀘스트 목표 변경(5.엘리베이터 작동)
        2. 밸브를 작동시키면 밸브가 180도 한바퀴 돔
        3. 밸브를 작동시킬 때 옆 파이프 머티리얼 변경
        4. 밸브의 순서는 관계 없음
        5. 밸브 작동(상호작용) 후 상호작용 불가
                 6. (원칙상) 밸브를 전부 작동시켜야 옥상 버튼 작동 가능

## 7. 완료 보상

1. 많은 량의 골드를 보상으로 퀘스트 완료 시 지급
2. 공성포를 통해 적의 기지의 보호막을 부수는 것이 보상으로 작용
