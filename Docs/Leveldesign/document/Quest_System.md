# QUEST 시스템 기획서

## 1. 문서 개요

WX의 QUEST 오브젝트는 웨이브 소환 → 처치 판정 → 문 개방으로 이어지는 전투 이벤트 흐름을 관리하는 장치다. QuestWave 레버가 신호를 보내면 이 오브젝트가 전체 흐름을 자동으로 처리한다.

레버가 신호 발송만 담당하고 이후 모든 판단과 처리를 QUEST 오브젝트가 맡는 구조이므로, 같은 QUEST 오브젝트를 다른 레버나 다른 던전에서도 재사용할 수 있다.

---

## 2. 역할

QUEST 오브젝트는 다음 세 가지를 처리한다.

- **웨이브 소환:** 웨이브별로 지정된 스폰 포인트에서 적을 즉시 소환
- **처치 판정:** 현재 웨이브의 적이 전부 처치됐는지 지속적으로 감시. 완료 시 다음 웨이브로 진행
- **문 개방:** 마지막 웨이브 처치 완료 시 연결된 문에 개방 신호 전달

---

## 3. 웨이브 구성

총 3웨이브로 구성된다. 한 웨이브의 적을 전부 처치하면 2초 뒤 다음 웨이브가 시작된다. 3웨이브까지 모두 처치하면 대형문이 열린다.

| 웨이브 | 적 수 | 시작 조건 |
|---|---|---|
|<img width="55" height="60" alt="image" src="https://github.com/user-attachments/assets/79082b08-4c86-434f-bf6f-60141ab50155" />
 1웨이브 | X명 (추후 확정) | QuestWave 레버 작동 직후 즉시 소환 |
| 2웨이브 | X명 (추후 확정) | 1웨이브 전부 처치 후 2초 경과 |
| 3웨이브 | X명 (추후 확정) | 2웨이브 전부 처치 후 2초 경과 |

웨이브 간 2초는 플레이어가 숨을 고르고 다음 소환을 인지할 수 있는 짧은 여유 시간이다. 플레이 테스트 결과에 따라 조정 가능하다.

---

## 4. 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 1웨이브 스폰 포인트 목록 | 1웨이브 소환 시 적이 등장할 스폰 포인트. 여러 개 지정 가능 |
| 2웨이브 스폰 포인트 목록 | 2웨이브 소환 시 적이 등장할 스폰 포인트. 여러 개 지정 가능 |
| 3웨이브 스폰 포인트 목록 | 3웨이브 소환 시 적이 등장할 스폰 포인트. 여러 개 지정 가능 |
| 웨이브 간 대기 시간 | 한 웨이브 클리어 후 다음 웨이브가 시작될 때까지의 시간(초). 기본값 2초 |
| 연결된 문 | 3웨이브 클리어 후 개방 신호를 보낼 문 |

## 5. 동작 알고리즘

QuestWave 레버를 당기는 순간부터 문이 열리기까지의 전체 흐름.

```
[QuestWave 레버 당김]
        │
        ▼
[QUEST 오브젝트: 시작 신호 수신]
        │
        ▼
[1웨이브 소환]
        │
        ▼
┌──────────────────────┐
│  1웨이브 전부 처치됐는가?  │
└──────────────────────┘
        │
   아니오 ──→ 대기
        │
        예
        │
        ▼
[2초 대기]
        │
        ▼
[2웨이브 소환]
        │
        ▼
┌──────────────────────┐
│  2웨이브 전부 처치됐는가?  │
└──────────────────────┘
        │
   아니오 ──→ 대기
        │
        예
        │
        ▼
[2초 대기]
        │
        ▼
[3웨이브 소환]
        │
        ▼
┌──────────────────────┐
│  3웨이브 전부 처치됐는가?  │
└──────────────────────┘
        │
   아니오 ──→ 대기
        │
        예
        │
        ▼
[연결된 문에 개방 신호 전달]
        │
        ▼
[QUEST 오브젝트: 완료 상태 전환]
        │
        ▼
[QuestWave 레버 작동 상태 저장]
```

## 6. 사망 및 리스폰 처리

웨이브 진행 중(1웨이브 시작 이후 ~ 문 개방 완료 전) 어느 시점에 사망하더라도 동일하게 처리된다.

```
[플레이어 사망]
        │
        ▼
[리스폰 발생]
        │
        ▼
┌──────────────────────────────┐
│  QUEST 오브젝트 완료 상태인가?  │
└──────────────────────────────┘
        │
   아니오 (웨이브 진행 중 또는 미시작)
        │
        ▼
[QuestWave 레버 상태 초기화]
[진행 중이던 웨이브의 적 전부 제거]
[QUEST 오브젝트 초기 상태로 복귀]
→ 레버를 다시 당기면 1웨이브부터 재시작
        │
        예 (문 개방 완료 후)
        │
        ▼
[레버 및 QUEST 오브젝트 완료 상태 유지]
[문 열린 채로 유지]
```

핵심은 **문이 열리기 전까지는 어느 웨이브에서 사망하든 1웨이브부터 다시 시작한다**는 것이다. 2웨이브나 3웨이브 도중 사망해도 중간 저장은 없다.

---

## 7. 사용 예시

**던전01 3구역 이벤트**

3구역에는 레버가 3개 있다. 정답 레버 1개(QuestWave)와 오답 레버 2개(Alert)로 구성된다.

정답 레버를 당기면:
1. QUEST 오브젝트가 1웨이브 적을 소환한다.
2. 플레이어가 1웨이브를 전부 처치하면 2초 후 2웨이브가 소환된다.
3. 2웨이브를 전부 처치하면 2초 후 3웨이브가 소환된다.
4. 3웨이브를 전부 처치하면 대형문이 열리고 QUEST 오브젝트가 완료 상태로 전환된다. 이 시점에 레버 상태가 저장된다.

오답 레버를 당기면 비상음만 재생되며 QUEST 오브젝트에 아무 영향이 없다.
