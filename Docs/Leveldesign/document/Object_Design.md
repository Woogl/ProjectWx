# 던전 배치물 기획서

> **명칭 안내:** 본 문서에서 배치물은 두 가지로 분류한다.
> - **소품 (Prop):** 배경 및 장식 요소. 상호작용 없음.
> - **장치 (Device):** 플레이어 또는 특정 조건에 의해 상태가 변하는 기능성 배치물.
>
> 본 문서는 장치를 중심으로 서술한다. 명칭은 추후 최종 확정.

---

## 1. 문서 개요

던전 내 배치되는 장치의 종류, 역할, 동작 방식, 배치 기준을 정리한 문서다. 던전 단위 기획서(Detail)에서 장치를 언급할 때 이 문서를 기준으로 삼는다.

장치의 상태(레버 작동 여부, 문 개폐, 엘리베이터 활성화 등)는 저장 데이터에 포함되며, 게임을 다시 실행하거나 리스폰이 발생해도 유지된다. 유지 및 초기화 규칙의 상세 내용은 리스폰 시스템 기획서를 참고한다.

---

## 2. 배치 원칙

같은 종류의 장치라도 맵에 배치할 때 각 인스턴스마다 개별 설정이 가능하다. 예를 들어 같은 레버 장치를 두 개 놓더라도, 하나는 문을 열도록, 다른 하나는 몬스터를 소환하도록 각각 다르게 연결할 수 있다.

이 구조 덕분에 장치 종류는 최소로 유지하면서도 다양한 상황에 유연하게 대응할 수 있다.

---

## 3. 공통 구성 요소

모든 장치가 기본으로 갖는 구성 요소다. 장치별 추가 요소는 각 항목에서 따로 정의한다.

| 구성 요소 | 역할 |
|---|---|
| 3D 외형 | 장치의 시각적 형태. 배치 후 교체 가능 |
| 상호작용 범위 | 플레이어가 가까이 있을 때 상호작용이 가능한 영역 |
| 상호작용 안내 UI | 상호작용 가능 범위 진입 시 표시. "F — [행동]" 형태. 장치 상태에 따라 표시 여부가 달라짐 |
| 시각 효과 | 작동 시 재생되는 파티클·발광 등 시각 효과 |
| 효과음 | 작동 시 재생되는 소리 |

## 4. 장치 목록

---

### 4.1 레버

연결된 대상 장치에 신호를 전달하는 장치다. 한 번 작동하면 리스폰 이후에도 작동 상태가 유지된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 레버 본체 | 레버 외형 |
| 상호작용 범위 | 플레이어 접근 감지 범위 |
| 상호작용 안내 UI | "F — 레버 당기기". 작동 후에는 표시되지 않음 |
| 작동 효과 | 레버 당기는 순간 재생되는 이펙트와 효과음 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 레버 종류 | 이 레버가 수행할 동작 유형. 배치 시 선택 |
| 연결 대상 | 신호를 전달할 장치. 배치 시 맵에서 직접 지정. QuestWave 종류는 퀘스트 오브젝트를 지정 |

#### 레버 종류

레버는 종류에 따라 연결 대상에게 보내는 신호와 그 효과가 달라진다. 아래 여섯 가지 종류가 있다.

**경보 레버 (Alert)**
당기면 비상음이 재생된다. 이펙트 없이 소리만 나온다. 게임플레이에 실질적인 영향은 없다. 퍼즐 구간에서 오답 선택지나 배경 연출 용도로 배치한다.

**소환 레버 (Spawn)**
당기면 연결된 스폰 포인트에서 몬스터를 즉시 소환한다. 레버 작동 자체가 전투 이벤트의 시작점 역할을 한다. 소환은 1회에 한하며, 이후 추가 소환은 없다.

**엘리베이터 활성화 레버 (ElevatorOn)**
연결된 엘리베이터를 가동 상태로 전환한다. 특정 조건을 달성한 후 숏컷을 개방할 때 사용한다.

**엘리베이터 호출 레버 (ElevatorCall)**
연결된 엘리베이터가 다른 층에 있을 때 현재 층으로 이동시킨다. 탑승 전 불필요한 대기 없이 바로 진입할 수 있도록 동선 앞에 배치한다.

> **[예외] 반복 사용 및 동적 활성화:** ElevatorCall 레버는 다른 레버와 달리 한 번 작동해도 영구 비활성화되지 않는다. 엘리베이터가 이 레버가 있는 층에 도착해 있으면 상호작용 UI가 표시되지 않고 당길 수 없다. 엘리베이터가 다른 층으로 이동하면 다시 활성화되어 재사용이 가능하다. 이 활성화 여부는 저장 데이터가 아닌 엘리베이터의 현재 위치를 실시간으로 참조해 결정된다.

**문 열기 레버 (DoorOpen)**
연결된 문에 개방 신호를 보낸다. 퍼즐 구간 정답 레버로 주로 사용된다.

**퀘스트 웨이브 레버 (QuestWave)**
당기면 연결된 퀘스트 오브젝트에 시작 신호를 보낸다. 이 신호를 받은 퀘스트 오브젝트가 웨이브 소환, 처치 판정, 문 개방까지의 전체 흐름을 처리한다. 레버는 신호 발송 역할만 담당한다.

> **[예외] 세이브 타이밍:** QuestWave 레버는 다른 레버와 달리, 레버를 당긴 직후가 아닌 웨이브 전부 처치 + 문 개방 완료 시점에 작동 상태가 저장된다. 웨이브를 클리어하기 전에 사망하면 리스폰 시 레버가 초기 상태로 돌아가며, 레버를 다시 당겨 웨이브를 처음부터 시작해야 한다.

#### 동작 방식

작동한 레버는 이후 다시 상호작용할 수 없으며, 상호작용 안내 UI도 표시되지 않는다. **단, ElevatorCall 레버는 예외다.** 이 레버는 엘리베이터의 현재 위치에 따라 활성/비활성이 반복적으로 전환된다.

레버를 당기면 레버 애니메이션·이펙트·효과음이 재생되고 연결된 대상에 신호가 전달된다. 리스폰 후에도 작동 상태가 유지된다.

#### 배치 시 설정 항목

- **레버 종류:** 수행할 동작 유형 선택
- **연결 대상:** 신호를 전달할 장치를 맵에서 직접 지정

#### 사용 예시

- 던전01 1구역: DoorOpen 레버 1개. 1구역과 2구역을 연결하는 문에 연결.
- 던전01 3구역: QuestWave 레버 1개(정답). 퀘스트 오브젝트에 연결. Alert 레버 2개(오답).

### 4.2 엘리베이터

플레이어를 층 간 이동시키는 장치다. 자체 버튼 없이 레버와 연동해 작동한다. 메인 루트 진행보다는 숏컷 경로나 체크포인트 복귀 수단으로 주로 사용한다.

던전01 기준으로는 2층 네임드 처치 후 활성화되어 체크포인트로 빠르게 돌아갈 수 있는 이동 수단이 된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 바닥 | 플레이어가 올라타는 엘리베이터 바닥 |
| 문 | 탑승 시 열리고 이동 중 닫히는 문 |
| 이동 경로 | 각 층 사이의 이동 경로. 층 간 높이를 기준으로 설정 |
| 작동 소리 | 이동 소리, 문 열림/닫힘 소리 |
| 비활성 표시 | 전원이 꺼진 상태를 시각적으로 표현 (어두운 패널 등) |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 층 수 | 이 엘리베이터가 오갈 수 있는 총 층 수. 배치 시 지정 |
| 층 간 높이 | 한 층을 이동하는 실제 거리. 맵 실측값을 입력 |
| 초기 활성화 여부 | 처음부터 사용 가능한 상태인지 여부. 조건이 있으면 비활성으로 시작 |

#### 동작 방식

비활성 상태에서는 상호작용 UI가 표시되지 않으며, "전원 없음" 안내가 표시될 수 있다. ElevatorOn 레버가 신호를 보내면 활성 상태로 전환된다.

활성 상태에서 내부 조작부에 접근해 F를 입력하면 층 선택 UI가 표시된다. 층을 선택하면 문이 닫히고, 해당 층으로 이동한 뒤 문이 열린다. 이동 중 플레이어는 엘리베이터 바닥과 함께 움직인다.

전투 중 탑승이 가능하며, 이동 중 공격을 받아도 멈추지 않는다. 적도 같은 바닥에 올라탈 수 있어 이동 중 전투가 발생할 수 있다.

조건에 따라 활성화되는 엘리베이터는 해당 이벤트(예: 네임드 처치)가 완료될 때 활성화 처리된다.

#### 배치 시 설정 항목

- **층 수:** 이 엘리베이터가 오갈 층의 수
- **층 간 높이:** 맵 실측 기준 층 간 높이
- **초기 활성화 여부:** 처음부터 사용 가능하면 활성, 조건이 있으면 비활성으로 설정

#### 사용 예시

- 던전01 엘리베이터 A: 2층 운행. 초기 비활성 상태. 2층 네임드 처치 이벤트 완료 시 활성화.

### 4.3 문

레버 신호를 수신하여 열리는 장치다. 플레이어가 직접 상호작용하지 않는다. 한 번 열리면 리스폰 이후에도 열린 상태가 유지된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 문 외형 | 문의 3D 외형 |
| 충돌 | 닫힌 상태에서 통과를 차단. 열리면 해제됨 |
| 열림 애니메이션 | 문 개방 모션 |
| 열림 소리 | 개방 효과음 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 초기 잠금 여부 | 잠긴 상태로 시작하면 레버 신호 없이는 열리지 않음 |

레버의 연결 대상으로 이 문을 지정하는 것으로 연결이 완료된다.

#### 동작 방식

연결된 레버로부터 신호를 받으면 열림 애니메이션과 효과음이 재생되며 문이 개방된다. 개방된 이후에는 통과가 가능하며, 리스폰이 발생해도 열린 상태가 유지된다.

#### 배치 시 설정 항목

- **초기 잠금 여부:** 잠긴 문이면 잠금 상태로 설정
- 레버의 연결 대상으로 이 문을 지정해 연결

#### 사용 예시

- 던전01 1구역→2구역 연결 문: 초기 잠금 상태. DoorOpen 레버의 연결 대상으로 지정.

### 4.4 체크포인트

플레이어가 진입하면 자동으로 활성화되어 사망 시 복귀 지점으로 등록되는 장치다. 던전01 기준으로는 3개를 배치한다 (입구 / 2구역 끝 / 보스 앞).

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 외형 | 체크포인트를 나타내는 표식 (기둥, 불꽃 등) |
| 감지 범위 | 플레이어가 진입하면 자동으로 활성화되는 영역 |
| 활성화 효과 | 최초 활성화 시 재생되는 이펙트와 효과음 |
| 활성/비활성 구분 | 활성 여부를 외형 또는 이펙트로 시각적으로 구분 |
| 상호작용 안내 UI | "F — 회복". 활성화 이후 언제든 표시됨 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 체크포인트 번호 | 던전 내 순서를 나타내는 고유 번호. 사망 시 어느 체크포인트로 복귀할지 판단하는 기준이 됨 |

#### 동작 방식

감지 범위에 진입하면 자동으로 활성화된다. 최초 진입 시 이펙트와 효과음이 재생되며 현재 복귀 지점으로 등록된다. 이전에 활성화된 체크포인트는 해제된다.

활성화 이후에는 F키 상호작용 안내 UI가 상시 표시된다. F를 입력하면 다음 두 가지가 동시에 처리된다.

- **HP/MP 전량 회복**
- **던전 내 일반 적 전부 리젠** — 리스폰 시와 동일한 규칙을 따른다. 네임드 적, 웨이브 시스템 적, Spawn 레버로 소환된 적은 리젠되지 않는다. 장치 상태(레버, 문, 엘리베이터 등)는 유지된다.

횟수 제한 없이 반복 사용이 가능하다. 단, 사용할 때마다 적이 다시 등장한다.

#### 배치 시 설정 항목

- **체크포인트 번호:** 던전 내 진행 순서에 맞게 번호 부여 (예: 0 = 입구, 1 = 2구역 끝, 2 = 보스 앞)
- 배치 위치는 리스폰 후 자연스럽게 진행 가능한 지점으로 선정

#### 사용 예시

- 던전01 체크포인트 0: 던전 입구. 번호 0.
- 던전01 체크포인트 1: 2구역 끝. 번호 1.
- 던전01 체크포인트 2: 보스 앞. 번호 2.

### 4.5 상자

던전 내 보상을 지급하는 장치다. Normal과 Special 두 종류가 있으며, 종류 무관하게 한 번 개봉하면 리스폰 후에도 다시 등장하지 않는다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 외형 | 닫힌 상태와 열린 상태 외형이 구분됨 |
| 상호작용 범위 | 플레이어 접근 감지 범위 |
| 상호작용 안내 UI | "F — 상자 열기". 개봉 후에는 표시되지 않음 |
| 열림 애니메이션 | 뚜껑 개방 모션 |
| 열림 소리 | 개봉 효과음 |
| 획득 UI | 개봉 시 획득 아이템 목록 표시 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 상자 종류 | Normal 또는 Special. 외형과 개봉 효과음에만 영향. 내용물은 아이템 테이블로 별도 관리 |
| 아이템 테이블 | 개봉 시 지급할 아이템 목록. 배치 시 각 상자마다 개별 지정 가능. 아이템 테이블은 추후 제작 |

#### 동작 방식

개봉되지 않은 상태에서만 상호작용 안내 UI가 표시된다. F를 입력하면 열림 애니메이션과 효과음이 재생되고, 지정된 아이템이 지급되며 획득 UI가 표시된다. 이후 해당 상자는 영구적으로 개봉 상태가 유지된다.

#### 배치 시 설정 항목

- **상자 종류:** Normal 또는 Special 선택. 외형과 개봉 효과음에만 영향
- **아이템 테이블:** 지급할 아이템 목록 지정. 상자마다 개별 설정 가능

#### 사용 예시

*(던전별 배치 시 Detail 문서에 기재)*

### 4.6 CCTV 관측기

던전01 고유 장치. 지정된 CCTV 영상을 재생해 퍼즐 힌트를 제공한다. 반복 열람이 가능하며 상태 변화는 없다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 모니터 외형 | 모니터 및 본체 형태 |
| 상호작용 범위 | 플레이어 접근 감지 범위 |
| 상호작용 안내 UI | "F — 영상 확인" |
| 켜짐 소리 | 모니터가 켜지는 효과음 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 재생 씬 | 상호작용 시 로드되어 재생되는 씬. 특정 레버를 누르는 장면 등 힌트 영상 역할. 배치 시 지정 |

#### 동작 방식

상태 변화 없이 언제든 반복 열람이 가능하다. F를 입력하면 지정된 씬이 로드되어 카메라가 전환되고 컷신이 재생된다. 재생이 끝나거나 취소 키를 입력하면 플레이어 시점으로 돌아오고 씬이 해제된다.

#### 배치 시 설정 항목

- **재생 씬:** 상호작용 시 보여줄 씬 에셋 지정

#### 사용 예시

- 던전01 1구역 관측기: 1→2구역 문의 정답 레버를 누르는 장면 재생. 튜토리얼 역할.
- 던전01 2구역 관측기: 엘리베이터 정답 레버를 누르는 장면 재생.
- 던전01 3구역 관측기: 스위치 3개 중 정답 레버를 누르는 장면 재생.

### 4.7 전기 문

좁은 복도를 막는 타이밍 퍼즐 장치다. 양쪽 기둥 사이에서 전기가 주기적으로 점멸하며, 플레이어는 전기가 꺼진 순간 회피로 통과해야 한다. 영구 비활성화 수단은 없으며, 리스폰 후에도 동일한 주기로 계속 작동한다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 기둥 외형 | 양쪽 전기 발생 기둥. 가게 도난방지 게이트 형태 |
| 전기 이펙트 | 기둥 사이를 흐르는 전기. 활성 시에만 표시 |
| 충돌 | 전기 활성 시에만 유효. 비활성 시 통과 가능 |
| 깜빡임 이펙트 | 전기가 꺼지기 직전 타이밍을 예고하는 시각적 경고. 플레이어가 타이밍을 읽을 수 있도록 명확하게 표현 |
| 전기 효과음 | 전기가 흐르는 동안 지속 재생 |
| 접촉 효과음 | 플레이어 접촉 시 재생 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 전기 활성 시간 | 전기가 켜져 있는 지속 시간(초). 짧을수록 위협 구간이 줄어 난이도가 낮아짐 |
| 전기 꺼짐 시간 | 전기가 꺼진 지속 시간(초). 플레이어가 회피 후 통과할 수 있는 여유 시간 |
| 접촉 데미지 | 전기 활성 중 접촉 시 가하는 피해량 |
| 넉백 강도 | 접촉 시 밀려나는 힘의 세기. 너무 강하면 인근 전투 구간과 겹칠 수 있어 주의 |

#### 동작 방식

레벨 시작과 동시에 전기 활성 → 꺼짐 → 활성 순으로 무한 반복한다. 꺼지기 직전 깜빡임 이펙트로 타이밍을 미리 알려준다.

전기가 켜진 상태에서 접촉하면 피해를 받고 뒤로 밀려난다. 꺼진 상태에서는 자유롭게 통과할 수 있다. 통과 시도 횟수 제한은 없으며, 실패하면 피해와 넉백이 발생한다.

#### 배치 시 설정 항목

- **전기 활성 시간 / 꺼짐 시간:** 플레이 테스트 후 조정. 꺼짐 시간은 회피 후 이동까지 여유가 있는 수치로 설정
- **접촉 데미지:** 즉사하지 않는 수치로 설정
- **넉백 강도:** 밀려난 위치가 인근 전투 구간과 겹치지 않는지 확인 후 설정

#### 사용 예시

- 던전01 3구역 좁은 복도: 수치는 플레이 테스트 후 확정.
