# 던전 배치물 기획서

> **명칭 안내:** 본 문서에서 배치물은 두 가지로 분류한다.
> - **소품 (Prop):** 배경 및 장식 요소. 상호작용 없음.
> - **장치 (Device):** 플레이어 또는 특정 조건에 의해 상태가 변하는 기능성 배치물.
>
> 본 문서는 장치를 중심으로 서술한다. 명칭은 추후 최종 확정.

---

## 1. 문서 개요

던전 내 배치되는 장치의 정의, 구성 요소, 동작 조건, 데이터 설정 방법을 정의한다. 던전 단위 문서(Detail)에서 장치를 언급할 때 이 문서를 기준으로 삼는다.

장치의 상태(레버 IsActivated, 문 개폐 상태 등)는 세이브 데이터에 포함되며 게임 재시작 후에도 유지된다. 세부 규칙은 리스폰 시스템 기획서를 따른다.

---

## 2. 클래스 및 인스턴스 구조

장치는 클래스(Blueprint) 단위로 설계하며, 맵에 배치된 각 액터는 인스턴스다. 동일 클래스를 사용하더라도 인스턴스별로 데이터를 개별 지정한다.

---

## 3. 공통 구성 요소

모든 장치가 기본으로 갖는 구성 요소다. 장치별 추가 요소는 각 항목에서 정의한다.

**스태틱 메시 (Static Mesh)**
장치의 3D 외형. 배치 후 교체 가능.

**콜리전 (Collision)**
물리 충돌 및 상호작용 감지 범위. 장치마다 별도 설정.

**상호작용 UI (Interaction Widget)**
상호작용 가능 범위 진입 시 표시. "F — [행동]" 형태. 장치 상태에 따라 표시 여부가 달라진다.

**이펙트 (VFX)**
작동 시 재생되는 시각 효과.

**사운드 (SFX)**
작동 시 재생되는 효과음.

## 4. 장치 목록

---

### 4.1 레버 (BP_Lever)

연결된 대상 장치에 신호를 전달하는 장치. 한 번 작동하면 리스폰 이후에도 상태가 유지된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 | 레버 본체 외형 |
| 상호작용 콜리전 | 플레이어 접근 감지 범위 |
| 상호작용 UI | "F — 레버 당기기" / 작동 후 미표시 |
| 작동 이펙트 | 레버 당기는 순간 재생 |
| 작동 사운드 | 금속음 또는 기계음 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| LeverType | Enum | 이 레버가 수행할 동작 유형. 타입에 따라 TargetActor에 보내는 신호와 대상의 반응이 달라짐 |
| IsActivated | Bool | 작동 여부. 초기값 false. true가 되면 재작동 불가. 런타임 관리 |
| TargetActor | Actor Reference | 신호를 전달할 대상 장치. 인스턴스마다 지정. QuestWave 타입은 QUEST 오브젝트를 지정 |

LeverType 열거형 값:
- **Alert:** 비상음이 재생되지만 게임플레이 효과 없음
- **Spawn:** 연결된 스폰 포인트에서 몬스터를 즉시 소환
- **ElevatorOn:** 연결된 엘리베이터의 활성화 상태를 켬 (IsActivated = true)
- **ElevatorCall:** 연결된 엘리베이터가 다른 층에 있을 때 현재 층으로 호출
- **DoorOpen:** 연결된 문을 개방
- **QuestWave:** WX QUEST 시스템과 연동. 웨이브 소환 트리거. 웨이브 전부 처치 시 연결된 문 자동 개방

#### 동작 조건

- `IsActivated = true`인 레버는 상호작용 UI를 표시하지 않으며 재작동 불가.
- F 입력 시: 레버 애니메이션·이펙트·사운드 재생 → `IsActivated = true` → `TargetActor`에 신호 전달.
- 리스폰 후에도 `IsActivated = true` 유지.

#### 레버 종류별 상세

**경보 레버 (LeverType: Alert)**
당기면 비상음이 재생된다. 게임플레이 영향 없음. 퍼즐 구간 오답 선택지 또는 배경 연출 용도로 배치한다.

**소환 레버 (LeverType: Spawn)**
당기면 연결된 스폰 포인트에서 몬스터를 즉시 소환한다. 레버 작동 자체가 전투 이벤트의 시작점이다. 1회 소환 후 추가 소환 없음.

**엘리베이터 활성화 레버 (LeverType: ElevatorOn)**
연결된 엘리베이터의 `IsActivated`를 true로 전환한다. 특정 조건 달성 후 숏컷을 개방하는 구간에서 사용한다.

**엘리베이터 호출 레버 (LeverType: ElevatorCall)**
연결된 엘리베이터가 다른 층에 있을 때 현재 층으로 이동시킨다. 엘리베이터가 이미 해당 층에 있으면 반응하지 않는다. 탑승 전 대기 없이 진입할 수 있도록 동선 앞에 배치한다.

**문 열기 레버 (LeverType: DoorOpen)**
연결된 문에 개방 신호를 보낸다. 퍼즐 구간 정답 레버로 주로 사용된다.

**퀘스트 웨이브 레버 (LeverType: QuestWave)**
WX QUEST 시스템과 연동된 레버. 당기면 `TargetActor`로 지정된 QUEST 오브젝트에 시작 신호를 보낸다. 웨이브 소환, 처치 판정, 문 개방까지의 전체 흐름은 QUEST 오브젝트가 처리한다. 이 레버는 신호 발송만 담당한다.

**[예외] 세이브 타이밍:** 다른 레버와 달리, QuestWave 레버의 `IsActivated = true` 상태는 웨이브 전부 처치 + 문 개방 완료 시점에 저장된다. 레버를 당긴 후 웨이브 클리어 전에 사망하면 리스폰 시 레버가 초기화(IsActivated = false)되며, 플레이어는 레버를 다시 당겨 웨이브를 처음부터 시작해야 한다.

#### 데이터 입력

레벨 에디터 Details 패널에서 지정.

- **LeverType:** 드롭다운에서 선택
- **TargetActor:** 연결할 장치를 맵에서 직접 지정

#### 사용 예시

- 던전01 1구역: DoorOpen 레버 1개. TargetActor = 1→2구역 연결 문.
- 던전01 3구역: QuestWave 레버 1개(정답). TargetActor = QUEST 오브젝트. Alert 레버 2개(오답).

### 4.2 엘리베이터 (BP_Elevator)

플레이어를 수직 이동시키는 장치. 단독 버튼 없이 연결된 레버를 통해 호출 및 이동한다. 메인 루트 진행보다 숏컷 경로 또는 체크포인트 복귀 수단으로 사용된다.

던전01 기준: 2층 네임드 처치 후 활성화. 체크포인트로 빠르게 복귀하는 역할.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 (바닥) | 엘리베이터 바닥 외형 |
| 스태틱 메시 (문) | 열리고 닫히는 문 외형 |
| 이동 경로 | 층 간 이동 경로. 스플라인 또는 Z축 오프셋으로 정의 |
| 작동 사운드 | 이동 시 기계 소리, 문 열림/닫힘 소리 |
| 비활성 표시 | `IsActivated = false` 상태 시각적 표시 (어두운 패널 등) |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| TotalFloors | Int | 이 엘리베이터가 이동 가능한 총 층 수. 인스턴스마다 지정 |
| FloorHeightPerLevel | Float | 한 층당 이동 거리(cm). 맵 실측값 입력 |
| IsActivated | Bool | 활성화 여부. false면 상호작용 UI 미표시. ElevatorOn 레버로 true 전환 |

#### 동작 조건

- `IsActivated = false` 상태에서는 상호작용 UI 미표시. (또는 "전원 없음" 표시)
- 활성 상태에서 내부 조작부 접근 → F 입력 → 층 선택 UI 표시 → 층 선택 → 문 닫힘 → 이동 → 도착 → 문 열림.
- 이동 중 플레이어도 엘리베이터 바닥과 함께 이동.
- 전투 중 탑승 가능. 탑승 중 공격받아도 이동 중단 없음.
- 적도 같은 바닥에 올라탈 수 있음. 이동 중 전투 발생 가능.
- 활성화 조건이 있는 경우, 해당 이벤트 블루프린트에서 `IsActivated = true`로 전환.

#### 데이터 입력

레벨 에디터 Details 패널에서 지정.

- **TotalFloors:** 이 엘리베이터가 오갈 층 수
- **FloorHeightPerLevel:** 맵 실측 층 간 높이(cm)
- **IsActivated:** 초기 비활성이면 false

#### 사용 예시

- 던전01 엘리베이터 A: TotalFloors=2, IsActivated=false(초기). 2층 네임드 처치 이벤트 시 활성화.

### 4.3 문 (BP_Door)

레버 신호를 수신하여 열리는 장치. 플레이어가 직접 상호작용하지 않는다. 한 번 열리면 리스폰 이후에도 열린 상태를 유지한다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 | 문 외형 |
| 콜리전 | 닫힌 상태에서 통과 차단. 열리면 비활성화 |
| 열림 애니메이션 | 문 개방 모션 |
| 열림 사운드 | 개방 효과음 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| IsLocked | Bool | 초기 잠금 여부. true면 연결된 레버 신호 수신 전까지 개방 불가. 열림 여부는 런타임 자동 관리 |

#### 동작 조건

레버로부터 신호 수신 시: `IsOpen = true` 변경 → 열림 애니메이션·사운드 재생 → 콜리전 비활성화. 이후 리스폰이 발생해도 상태 유지.

#### 데이터 입력

- **IsLocked:** 잠긴 문이면 true
- 레버의 `TargetActor`에 이 문을 지정하면 연결 완료

#### 사용 예시

- 던전01 1→2구역 연결 문: IsLocked=true. DoorOpen 레버의 TargetActor로 지정.

### 4.4 체크포인트 (BP_Checkpoint)

플레이어가 진입하면 자동 활성화되며 사망 시 복귀 지점으로 등록된다. 던전01 기준 3개 배치 (입구 / 2구역 끝 / 보스 앞).

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 | 체크포인트 표식 외형 (기둥, 불꽃 등) |
| 감지 콜리전 | 플레이어 진입 감지. 트리거 형태 |
| 활성화 이펙트 | 최초 활성화 시 재생 |
| 활성화 사운드 | 활성화 및 회복 효과음 |
| 활성/비활성 상태 표시 | 메시 또는 이펙트로 활성 여부 구분 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| IsActivated | Bool | 활성화 여부. 최초 진입 시 자동으로 true. 이후 현재 복귀 지점으로 등록됨. 런타임 관리 |
| CheckpointID | Int | 던전 내 순서 식별 번호. 인스턴스마다 지정. 사망 시 어느 체크포인트로 복귀할지 결정하는 데 사용 |

#### 동작 조건

- 키 입력 없이 감지 콜리전 진입만으로 작동.
- `IsActivated = false` 상태에서 진입 시: 이펙트·사운드 재생 → `IsActivated = true` → 현재 활성 체크포인트로 등록 (이전 체크포인트 해제) → HP/MP 전량 회복.
- 이미 활성화된 체크포인트 재진입 시 별도 반응 없음. 회복도 없음.

#### 데이터 입력

- **CheckpointID:** 던전 내 순서에 맞게 번호 부여 (0: 입구, 1: 2구역 끝, 2: 보스 앞 등)
- 배치 위치는 리스폰 후 자연스럽게 진행 가능한 지점으로 설정

#### 사용 예시

- 던전01 체크포인트 0: 던전 입구. CheckpointID=0.
- 던전01 체크포인트 1: 2구역 끝. CheckpointID=1.
- 던전01 체크포인트 2: 보스 앞. CheckpointID=2.

### 4.5 상자 (BP_Chest)

던전 내 보상을 지급하는 장치. Normal / Special 종류 무관하게 개봉 후 리스폰되지 않는다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 | 상자 외형 (닫힘 / 열림 상태 메시 구분) |
| 상호작용 콜리전 | 플레이어 접근 감지 범위 |
| 상호작용 UI | "F — 상자 열기" / 개봉 후 미표시 |
| 열림 애니메이션 | 뚜껑 개방 모션 |
| 열림 사운드 | 개봉 효과음 |
| 아이템 획득 UI | 획득 아이템 목록 표시 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| ChestType | Enum | 상자 종류 (Normal / Special). 외형과 개봉 사운드에만 영향. 내용물은 LootTable로 관리 |
| IsOpened | Bool | 개봉 여부. 초기값 false. true가 되면 재상호작용 불가. 런타임 관리 |
| LootTable | DataTable | 개봉 시 고정 지급할 아이템 목록. 인스턴스마다 개별 지정 가능. 아이템 테이블 추후 제작 |

#### 동작 조건

- `IsOpened = false` 상태에서만 UI 표시 및 상호작용 가능.
- F 입력 시: 열림 애니메이션·사운드 재생 → LootTable 아이템 지급 → 획득 UI 표시 → `IsOpened = true`.

#### 데이터 입력

- **ChestType:** 드롭다운에서 Normal / Special 선택. 외형과 개봉 사운드에만 영향
- **LootTable:** 지급 아이템 테이블 지정. 인스턴스마다 개별 설정 가능

### 4.6 CCTV 관측기 (BP_CCTVMonitor)

던전01 고유 장치. 지정된 CCTV 영상을 재생하여 퍼즐 힌트를 제공한다. 반복 열람 가능하며 별도 상태 변화 없음.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 | 모니터 및 본체 외형 |
| 상호작용 콜리전 | 플레이어 접근 감지 범위 |
| 상호작용 UI | "F — 영상 확인" |
| 작동 사운드 | 모니터 켜지는 효과음 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| SceneLevel | Level Asset | 상호작용 시 로드할 레벨 인스턴스. 해당 레벨이 켜지면서 컷신처럼 맵 개방 장면을 보여줌. 인스턴스마다 지정 |

#### 동작 조건

- 상태 변화 없이 언제든 재열람 가능.
- F 입력 시: `SceneLevel` 로드 → 해당 레벨 내 카메라로 시점 전환 → 컷신 재생.
- 재생 종료 또는 취소 키 입력 시: 플레이어 시점으로 복귀 → `SceneLevel` 언로드.

#### 데이터 입력

- **SceneLevel:** 상호작용 시 로드할 레벨 인스턴스 에셋 지정

#### 사용 예시

- 던전01 1구역 관측기: SceneLevel = 1→2구역 문의 정답 레버를 누르는 장면. 튜토리얼 역할.
- 던전01 2구역 관측기: SceneLevel = 엘리베이터 정답 레버를 누르는 장면.
- 던전01 3구역 관측기: SceneLevel = 스위치 3개 중 정답 레버를 누르는 장면.

### 4.7 전기 문 (BP_ElectricDoor)

좁은 복도를 막는 타이밍 퍼즐 장치. 양쪽 기둥 사이로 전기가 주기적으로 흐른다. 전기가 꺼진 타이밍에 회피로 통과해야 한다. 영구 비활성화 수단은 없으며 리스폰 후에도 동일한 주기로 작동한다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 스태틱 메시 (기둥) | 양쪽 전기 발생 기둥 외형. 가게 도난방지 게이트 형태 |
| 전기 이펙트 | 기둥 사이를 흐르는 전기 시각 효과. 활성 시에만 표시 |
| 콜리전 | 전기 활성 시에만 유효. 비활성 시 비활성화되어 통과 가능 |
| 깜빡임 이펙트 | 꺼지기 직전 시각적 경고. 플레이어가 타이밍을 읽을 수 있도록 명확하게 표현 |
| 루프 사운드 | 전기 흐르는 지속 효과음 |
| 접촉 사운드 | 플레이어 접촉 시 효과음 |

#### 클래스 설계

| 변수명 | 타입 | 설명 |
|---|---|---|
| OnDuration | Float | 전기 활성 지속 시간(초). 짧을수록 위협 시간이 줄어 난이도 낮아짐 |
| OffDuration | Float | 전기 꺼짐 지속 시간(초). 플레이어가 회피 후 통과할 수 있는 여유 시간 |
| DamageAmount | Float | 전기 활성 중 접촉 시 플레이어에게 가하는 데미지 |
| KnockbackStrength | Float | 접촉 시 밀려나는 힘의 세기. 너무 강하면 이전 전투 구간과 연결될 수 있어 주의 |

#### 동작 조건

- 레벨 시작과 동시에 OnDuration → OffDuration 주기로 무한 반복.
- 전기 활성 상태에서 플레이어 접촉 시: DamageAmount 데미지 + KnockbackStrength 방향으로 밀어냄.
- OffDuration 구간에서는 콜리전 비활성화 → 자유롭게 통과 가능.
- 꺼지기 직전 깜빡임 이펙트로 타이밍을 예고.
- 통과 시도 횟수 제한 없음. 실패 시 데미지 + 넉백.
- 영구 비활성화 수단 없음.

#### 데이터 입력

레벨 에디터 Details 패널에서 지정.

- **OnDuration / OffDuration:** 플레이 테스트 후 조정. OffDuration은 회피 후 이동까지 여유가 있는 수치로 설정
- **DamageAmount:** 즉사하지 않는 수치로 설정
- **KnockbackStrength:** 밀려난 위치가 이전 전투 구간과 겹치지 않도록 확인 후 설정

#### 사용 예시

- 던전01 3구역 좁은 복도: OnDuration / OffDuration / DamageAmount / KnockbackStrength 수치는 플레이 테스트 후 확정.
