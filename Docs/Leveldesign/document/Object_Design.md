
# 던전 배치물 기획서

---

## 1. 문서 개요

던전 내 배치되는 배치물의 종류, 역할, 동작 방식, 배치 기준을 정리한 문서다. 던전 단위 기획서(Detail)에서 배치물를 언급할 때 이 문서를 기준으로 삼는다.

---

## 2. 구분 규칙

배치물의 타입을 스포너블과 기믹 두 가지로 규정한다. 배치물 별 추가 요소는 각 항목에서 따로 정의한다.

| 항목 | 스포너블 (Spawnable) | 기믹 (Gimmick) |
| --- | --- | --- |
| 체크포인트 상호작용 시 | 다시 스폰(리젠), 최초 위치로 재배치 | 영향 없음, 상태 유지 |
| 상태 지속성 | 리젠 시 초기화 | 레벨 이동·재접속·월드 파티션 스트리밍 시에도 유지 |
| 배치 방식 | WxSpawner를 통해서만 배치 | BP 클래스를 레벨에 직접 배치 |
| 인스턴스 편집 | 불가 (클래스 디폴트 사용) | 가능 |
| 예시 | 졸병, 보스, 장식물(Prop) | 문, 엘리베이터 |

---

## 3. 공통 구성 요소

모든 배치물이 기본으로 갖는 구성 요소다. 장치별 추가 요소는 각 항목에서 따로 정의한다.

| 구성 요소 | 역할 |
|---|---|
| 3D 외형 | 배치물의 시각적 형태. 배치 후 교체 가능 |
| 상호작용 범위 | 플레이어가 가까이 있을 때 상호작용이 가능한 영역. 같은 범위 내에 두 가지 이상의 상호작용 가능한 배치물이 있을 경우 가장 가까운 것을 우선함 |
| 상호작용 안내 UI | 상호작용 가능 범위 진입 시 표시. "F — [행동]" 형태. 배치물 상태에 따라 표시 여부가 달라짐 |

## 4. 배치물 목록

---

### 4.1 경보 레버

퍼즐 구간에서 오답 선택지나 배경 연출 용도로 배치하는 기믹이다. 어떤 장치에도 귀속되지 않는 독립 배치물이다.

#### 동작 방식 및 특징

상호작용 시 비상음이 재생된다. 이펙트 없이 소리만 나온다. 게임플레이에 실질적인 영향은 없다. 작동 후 상호작용 안내 UI가 사라지며 재사용이 불가능하다. 

---

### 4.2 스포너 (레버형)

레버 조작으로 몬스터를 즉시 소환하는 기믹이다. 소환은 1회에 한한다. 

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 레버 | 소환을 발동하는 상호작용 기믹. 스포너에 귀속된다 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 소환 몬스터 목록 | 소환할 몬스터 종류와 수량 목록. 배치 시 지정 ( 예 : 검병 x2, 단검병 x1 ) |

#### 동작 방식 및 특징

레버를 당기면 지정된 몬스터가 스포너가 배치된 지점에서 소환된다. 소환 후 레버는 비활성화되어 재사용이 불가능하다. 리스폰 후에도 비활성화 상태가 유지된다.

### 4.3 문 (레버형)

레버를 통해 개방되는 기믹이다. 한 번 개방되면 리스폰 후에도 열린 상태가 유지된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 문 본체 | 닫힌 상태에서 통로를 차단한다. 개방 시 충돌이 해제된다 |
| 레버 | 문 개방을 발동하는 상호작용 기믹. 문에 귀속된다 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 초기 잠금 여부 | 잠긴 상태로 시작하면 레버 조작 없이는 열리지 않음 |

#### 동작 방식 및 특징

레버를 당기면 문이 개방된다. 개방 이후 통과가 가능하며 리스폰이 발생해도 개방된 상태가 유지된다. 레버는 작동 후 재사용 불가.

### 4.4 엘리베이터

플레이어를 다른 층으로 이동시키는 기믹이다. 층과 층의 이동 경로는 스플라인으로 제작한다. 활성화 레버와 층 불러오기 레버가 내장되어 있다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 바닥 | 플레이어가 올라타는 엘리베이터 바닥 |
| 문 | 탑승 시 열리고 이동 중 닫히는 문 |
| 비활성 표시 | 전원이 꺼진 상태를 시각적으로 표현  (닫혀 있는 문) |
| 스플라인 경로 | 엘리베이터가 이동하는 궤적 |
| 활성화 레버 | 비활성 엘리베이터를 영구 활성화하는 레버. 1회 작동 후 레버 비활성화 |
| 층 불러오기 레버 | 다른 층에 있는 엘리베이터를 현재 층으로 호출하는 레버. 반복 사용 가능 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 이동 시간 | 엘리베이터가 목적지로 이동하는 시간 |
| 초기 활성화 여부 | 처음부터 사용 가능한 상태인지 여부. 조건이 있으면 비활성으로 시작 |
| 스플라인 | 이동 경로와 정차 지점 설정 |

#### 동작 방식 및 특징

비활성 상태에서는 문이 닫혀 있으며 탑승이 불가능하다. 활성화 레버를 당기면 영구 활성화된다.

탑승 후 내부 바닥에 상호작용 시 다른 층으로 이동 (현재 구현 상태)

이동 중에는 엘리베이터 문이 닫히고 도착 시 문이 다시 개방된다.

층 불러오기 레버는 엘리베이터가 해당 층에 없을 때만 활성화된다. 엘리베이터가 도착해 있으면 상호작용 UI가 표시되지 않는다.

### 4.5 체크포인트

플레이어가 처음 상호작용 시 활성화 되는 기믹으로 가장 최근에 상호작용 시 사망 후 해당 위치에서 부활하게 된다. 상호작용 시 체력 / 마나가 회복되며 몬스터가 리젠된다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 활성/비활성 구분 | 활성 여부를 외형으로 시각적으로 구분 |

#### 동작 방식 및 특징

레벨엔 비활성화된 상태로 배치되어 있으며, 가까이 다가가 상호작용 시 활성화된다.

가장 최근에 상호작용하였을 경우 사망 시 해당 체크포인트에서 부활한다.

활성화 이후에는 상호작용 안내 UI "F — 휴식"이 상시 표시된다. 

상호작용 시 다음과 같은 효과가 발동된다.

- **플레이어 HP/MP 전량 회복**
- **던전 내 일반 적 전부 리젠** — 리스폰 시와 동일한 규칙을 따른다. 네임드 적, 스포너로 소환된 적은 리젠되지 않는다. 장치 상태(문, 엘리베이터 등)는 유지된다.

횟수 제한 없이 반복 사용이 가능하다.

### 4.6 상자

던전 내 보상을 지급하는 기믹이다. Normal과 Special 두 종류가 있다.

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 외형 | 닫힌 상태와 열린 상태 외형이 구분됨 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 상자 종류 | Normal 또는 Special. 외형과 개봉 효과음에만 영향. |
| 아이템 (개발중) | 개봉 시 지급할 아이템 목록. 배치 시 각 상자마다 개별 지정 가능 |

#### 동작 방식 및 특징

개봉되지 않은 상태에서만 상호작용 안내 UI "F — 상자 열기"가 표시된다. F를 입력하면 지정된 아이템이 지급된다. 이후 해당 상자는 영구적으로 개봉 상태가 유지된다.

### 4.7 CCTV 관측기

던전01 고유 기믹. 지정된 CCTV 영상을 재생해 퍼즐 힌트를 제공한다. 반복 열람이 가능하다.

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 레벨 인스턴스 | 상호작용 시 로드되어 재생되는 컷신. 특정 레버를 누르는 장면 등 힌트 영상 역할. 배치 시 지정 |

#### 동작 방식 및 특징

언제든 반복 열람이 가능하다. F를 입력하면 지정된 레벨 인스턴스가 로드되어 카메라가 전환되고 컷신이 재생된다. 재생이 끝나거나 상호작용 키를 재입력하면 플레이어 시점으로 돌아온다.

레벨 인스턴스 감상 도중 플레이어는 조작할 수 없으며, 적에게 피해를 입으면 플레이어 시점으로 돌아온다.

### 4.8 전기 통로

던전 01의 기믹으로 통로의 벽면에서 발생한 레이저 벽이 통로를 따라 전진하는 타이밍 기믹이다. 플레이어는 레이저 벽에 충돌하는 타이밍에 맞춰 극한 회피를 시전하여 데미지를 입지 않고 전진할 수 있다. 이를 통해 극한 회피의 숙련을 유도한다. 

#### 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 레이저 이펙트 | 양쪽 벽 사이를 잇는 레이저의 외형 |
| 충돌 영역 | 레이저 벽과 함께 전진하는 피해 판정 영역 |

#### 설정 항목

| 설정 항목 | 설명 |
|---|---|
| 전진 속도 | 레이저 벽이 이동하는 속도 |
| 접촉 데미지 | 레이저 벽 접촉 시 가하는 피해량. 고정 데미지로 방어력 무시 |

#### 동작 방식 및 특징

해당 통로의 끝에서 레이저 벽이 생성되며 앞으로 전진한다. 플레이어는 이를 극한 회피를 활용하여 회피하며 전진할 수 있으며, 레이저 벽과 부딪힐 경우 뒤로 넉백하며 약간의 무적 시간을 부여한다. 레이저 벽은 통로의 맨앞에 도달하면 다시 초기 위치로 돌아와 반복된다.

비활성화는 불가능하다.
