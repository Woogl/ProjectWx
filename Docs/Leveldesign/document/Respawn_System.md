# 리스폰 시스템 기획서

## 1. 문서 개요

본 문서는 WX 던전 내 리스폰 시스템의 정의, 규칙, 대상 및 예외, 구체적 상황을 정리한다.
오브젝트별 상세 설계는 오브젝트 기획서를 함께 참고한다.

---

## 2. 용어 정의

**리스폰 (Respawn)**
플레이어가 사망한 후 가장 최근에 활성화된 체크포인트에서 다시 시작하는 전체 프로세스를 의미한다. 사망 감지 → 페이드 아웃 → 상태 복원 → 위치 이동 → 회복 → 페이드 인까지의 흐름 전체가 리스폰이다.

리스폰은 사망을 통해서만 발생한다. 현재 기획 기준으로 자발적 귀환 기능은 없다.

**리젠 (Regen)**
리스폰 프로세스 내에서 일반 적이 다시 등장하는 것을 의미한다. 리스폰의 하위 단계로, 리스폰이 발생할 때 리젠 대상 적들이 즉시 재배치된다. 모든 적이 리젠되는 것은 아니며, 대상 여부는 섹션 5에서 정의한다.

---

## 3. 리스폰 규칙

리스폰 처리는 가장 최근에 활성화된 체크포인트를 기준으로 한다.
체크포인트 이전 구역에서 발생했던 일 중 일부는 초기화되고, 일부는 유지된다. 아래 규칙이 그 기준이다.

**리젠 대상:** 던전 내 모든 일반 적. 즉시 배치 방식으로 재등장 (페이드 아웃·인으로 전환 구간이 가려지므로 별도 연출 없음).

**유지되는 것:** 플레이어가 상호작용으로 변경한 오브젝트 상태 (레버, 문, 엘리베이터 활성화 등), 네임드 적 처치 여부, 웨이브 시스템 종료 상태, 상자 개봉 여부, 체크포인트 활성화 여부. 단, QuestWave 레버는 예외 — 웨이브 클리어 + 문 개방 완료 전 사망 시 레버 상태 초기화.

핵심 원칙은 **"플레이어가 능동적으로 바꾼 것은 유지된다"**는 것이다. 레버를 당겼다면 그 상태가 그대로이고, 이미 열린 문은 다시 닫히지 않는다.

**플레이어 상태:** 리스폰 시 HP/MP 전량 회복. 전투 기획자 협의 후 변경될 수 있음.

**던전 재진입 시:** 사망 리스폰과 동일한 규칙을 따른다. 세이브 데이터를 기준으로 상태가 복원되며, 일반 적은 다시 등장하고 유지 항목은 그대로다.

---

## 4. 리스폰 프로세스

플레이어 HP가 0이 되는 순간 아래 순서로 처리된다.

1. 사망 처리 — 플레이어 HP 0 감지
2. 페이드 아웃
3. 세이브 데이터 로드 — 마지막 활성 체크포인트 기준
4. 초기화 대상 처리 — 일반 적 즉시 재배치
5. 플레이어 위치를 체크포인트 위치로 이동
6. HP/MP 전량 회복
7. 페이드 인

## 5. 리스폰 대상 및 예외

### 5.1 적

| 대상 | 리젠 여부 | 비고 |
|---|---|---|
| 일반 적 | O (리젠됨) | 리스폰 시 던전 내 모든 구역의 일반 적 즉시 재배치 |
| Spawn 레버 소환 적 | X (리젠 안 됨) | 레버가 재작동되지 않으므로 소환 조건 자체가 사라짐 |
| 웨이브 시스템 적 | X (리젠 안 됨) | 웨이브 종료 이후 다시 등장하지 않음 |
| 네임드 적 | X (리젠 안 됨) | 한 번 처치하면 영구 제거 |
| 보스 | 해당 없음 | 보스는 소멸·재생성되지 않음. 단, 플레이어 사망 후 재도전 시 보스 HP 전량 초기화 |

### 5.2 오브젝트

| 대상 | 상태 유지 여부 | 비고 |
|---|---|---|
| 레버 | X (상태 유지) | 작동한 레버는 되돌아오지 않음. **[예외] QuestWave 레버:** 웨이브 클리어 + 문 개방 완료 전에 사망 시 레버 초기화. 완료 후에만 상태 유지 |
| 문 | X (상태 유지) | 레버로 열린 문은 열린 채 유지 |
| 엘리베이터 | X (상태 유지) | 활성화된 엘리베이터는 계속 사용 가능 |
| 체크포인트 | X (상태 유지) | 활성화된 체크포인트는 유지 |
| CCTV 관측기 | X (상태 유지) | 반복 열람 가능 |
| 상자 (Normal / Special) | X (리스폰 안 됨) | 개봉 후 영구 소비. 종류 무관하게 동일 규칙 적용 |
| 전기 문 | 해당 없음 | 리스폰 규칙 적용 대상 아님. 레벨 시작부터 일정 주기로 작동하며 사망과 무관하게 항상 동일 상태 유지 |

## 6. 구체적 상황과 예시

### 상황 1 — 일반 전투 구역에서 사망

플레이어가 1구역에서 적 2마리와 싸우다 사망했다. 가장 최근 활성화된 체크포인트는 던전 입구다.
리스폰 후 1구역의 일반 적 2마리는 리젠된다. 플레이어가 이미 당긴 레버나 열어놓은 문은 그대로 유지된다.

### 상황 2 — 네임드 처치 후 사망

플레이어가 2구역 2층의 네임드를 처치하고 레버를 작동해 엘리베이터를 개방했다. 이후 3구역에서 사망했다.
리스폰 후 네임드는 리젠되지 않는다. 엘리베이터는 여전히 활성화 상태다. 3구역의 일반 적은 리젠된다.

### 상황 3 — 웨이브 종료 이후 사망

플레이어가 3구역에서 정답 레버를 작동해 대형문이 열리고 웨이브가 종료되었다. 이후 사망했다.
리스폰 후 레버는 당겨진 상태 그대로이고, 대형문도 열려 있다. 웨이브는 종료된 채로 유지되어 더 이상 해당 구역에서 적이 소환되지 않는다.

### 상황 4 — 체크포인트 중간 경유 후 사망

플레이어가 2구역 끝 체크포인트를 활성화한 뒤 3구역에서 사망했다.
복귀 지점은 2구역 끝 체크포인트다. 던전 전체의 일반 적이 리젠된다. 단, 레버·문·엘리베이터 상태는 유지된다.
