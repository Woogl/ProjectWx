# 레버 / 피스톤 기믹 사양서

## 1. 구성 요소

| 요소 | 역할 | 비고 |
|---|---|---|
| 레버 | 플레이어가 상호작용하는 입력 장치. 증기와 연결됨 |  |
| 증기 | 실제 판정 대상. ON/OFF 상태값을 보유하고 지정 위치로 이동 | 길을 막거나 여는 장치 |

## 2. 규칙

- 레버를 당기면 증기가 현재 상태에 따라 ON/OFF 상태로 전환 됨 
- 레버 조작 도중 다시 조작할 수 없다.
- 증기는 길을 막는 벽의 역할을 함.
- 증기와 부딪혔을 시 데미지 X, 튕김 X.
- 레버의 상태값은 변하지 않고 증기의 상태값만 변화한다.
- 레버는 무한히 상호작용할 수 있다.
- 하나의 레버는 여러 증기에 연결할 수 있다 (1:N).
- 하나의 증기는 여러 레버에 중복 연결될 수 있다 (N:1).
- 증기는 ON 상태로 시작할 수도 있고 OFF 상태로 시작할 수도 있다.
- 세이브 로드 및 리스폰 시 마지막 상태가 유지된다.

## 3. 연출

| 상황 | 연출 |
|---|---|
| 증기 OFF 시 | 증기가 필드에서 즉시 사라짐 |
| 증기 ON 시 | 증기가 필드에 즉시 분출됨 |
| 레버 당길 시 | 레버가 당겨진 반대쪽 방향으로 이동 (시간 1초) |
