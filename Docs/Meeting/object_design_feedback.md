# 📋 던전 배치물 기획서 2차 검토 결과

## 관련 기획서
* Object_Design.md

## 피드백

### 1. 구현 우선순위
- 구현 필요한 항목의 분량이 프로그래머 혼자 소화하기에 많습니다.
- 구현 우선순위를 상/중/하로 구분해서 적어주세요. 우선순위대로 처리하겠습니다.

### 2. 배치물 타입
- 스포너블(Spawnable), 기믹(Gimmick)에 대한 설명이 프로그래머의 제안을 그대로 복사하신 것 같습니다.
- 기획적인 의도와 부합되지 않는 부분이 있을지, 레벨 작업하실 때 이슈가 없을지 재차 확인 부탁드립니다.
- 민석님께서 이해가 잘 안되는 부분이나 걱정되는 부분이 있다면 언제든지 문의해주셔도 됩니다.

### 3. 공통 구성 요소
- 3D 외형의 설명에서 `배치 후 교체 가능`이 Gimmick 타입의 규칙 중 `클래스 디폴트 사용`과 충돌됩니다.
  - 외형을 클래스 디폴트로 쓸 것인지, Instance Editable하게 사용할 것인지 확인 바랍니다.
- 상호작용 범위 형태에 대한 내용이 누락되었습니다.
  - 구(Sphere)만 지원해드리면 될지, 아니면 오브젝트마다 다양한 형태를 원하시는지 확인하여 내용 추가바랍니다.

### 4. 설정 항목
- 반드시 데이터 타입 명시 바랍니다.
- 문맥상 `초기 잠금 여부`는 bool, `이동 시간`은 float 등으로 예상됩니다만, 명확히 써주시지 않으면 문제가 생길 수 있습니다.

### 5. 스포너 (레버형)
- `소환 몬스터 목록`의 데이터가 중복되므로, 설정 항목에서 제거 바랍니다.
  - 포함된 스포너(WxSpawner) 내부에 이미 소환할 몬스터가 정의됩니다.
- 하나의 레버 조작을 통해서 다수의 몬스터를 스폰하는 것이 필요하신게 맞나요?

### 6. 문 (레버형)
- 잠기지 않은 상태로 시작하는 문(`초기 잠금 여부 == false`)에 대해 어떤 식으로 작동해야 되는지 설명이 누락되었습니다.
- 근본적으로 `초기 잠금 여부` 변수가 왜 필요한지, 어떤 상황에서 쓰일지가 의문입니다.
  - 처음부터 열려있고, 다시 닫히는 일도 없고, 레버조차 작동하지 않을텐데, 이런 문이 왜 필요한가?

### 7. 엘리베이터
- `비활성 표시`의 시각적 표현에 대해 추가 설명바랍니다. 제 생각에는 간단한 조명의 ON/OFF로 처리해도 될 것 같습니다.
- `탑승 후 내부 바닥에 상호작용 시` 에서 상호작용 범위나 형태 등에 대한 내용이 누락되어 있습니다. 현재 구현 상태에 대한 안내가 필요하다면 별도 공유드리겠습니다.
- 처음부터 사용 가능한 상태(`초기 활성화 여부 == true`)이면 활성화 레버가 필요 없을 것 같은데, 이 부분에 대한 계획 있으신지 문의드립니다.

### 8. 체크포인트
- `활성/비활성 구분`에 대해 외형을 무엇으로 구분하는 것을 원하시는지 설명바랍니다.
  - VFX, 3D 모델, 애니메이션 등
- 체크포인트 활성화되기 전/후의 상호작용 UI 텍스트의 변경이 필요한지 확인 부탁드립니다.
  - (예시) 활성화 전 : 체크포인트 활성화 / 활성화 후 : 휴식

### 9. 상자
- `Normal`과 `Special`은 기능적인 차이가 없는, 단순 외형에 따른 구분인가요?
- 외형만 다른 것이라면 외형만 다른 BP 두 개로 제공해드리겠습니다.

### 10. CCTV 관측기
- 구현적인 이유로 다음 두가지는 제외하고 진행하겠습니다.
  - `상호작용 키를 재입력하면 플레이어 시점으로 돌아온다.` (→ 다이얼로그 시스템을 고도화할 때 스킵 기능 추가 고려 중)
  - `적에게 피해를 입으면 플레이어 시점으로 돌아온다.` (→ 애초에 적이 올 수 없는 곳에 CCTV 관측기를 배치하는 것을 희망)

### 11. 전기 통로
- 방무뎀 구현에 대해서는 다음 회의 때까지 좀 더 고민해보고 답변드리겠습니다.
- 넉백 시 무적시간 부여가 과연 필요할지, 전투 기획자와 논의바랍니다.
  - 전기 통로에서만 쓸 "전용 넉백"을 추가하거나, "모든 넉백의 공통 무적 규칙"이 추가되야하기 때문입니다.
  - 무적시간이 중요하지 않다면 빼는 것이 낫다고 생각합니다.

### 12. 활성화/비활성화 규칙
- 활성화 시 동작, 비활성화 시 동작에 대한 설명이 누락된 곳이 있습니다.
  - 무엇을 활성화하고, 무엇을 비활성화해야하는 것인지 누락없이 서술 바랍니다.
- 문(레버형)의 `초기 잠금 여부`와 엘리베이터의 `초기 활성화 여부`가 어떤 부분에서 다른가요?
- 활성화/비활성화를 공통 기능으로 올리는 것이 나을 것 같아보이는데 검토 바랍니다.
