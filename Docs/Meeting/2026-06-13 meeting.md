# 작업 진행 사항 공유

> 기획자 입장에서 게임플레이에 체감되는 부분만 설명

## 1. 락온 어빌리티 개선
- 플레이어 캐릭터가 락온 중일 때 옆걸음 가능하게 됨
- 락온 중에 마우스 움직이면 해당 방향의 타겟 재탐색
- 적의 신체 부위별 락온 가능

## 2. 회피 어빌리티 개선
- 회피 어빌리티의 애니메이션을 8방향으로 개선
- 충전형 포션 사용하는 어빌리티 추가 (GA_UseItem)

## 3. 아이템 기반 작업
- 아이템 등급 사전 작업 (Common/Rare/Epic/Legendary)
- 충전형 포션 추가. 체크포인트 상호작용하면 충전됨
- 기본 지급 아이템 추가. 현재는 충전형 포션을 기본 지급
- 보상 테이블 추가. 보물상자에서 보상 지급 가능
