# ✅ 구현 완료된 부분 공유

> 기획자 입장에서 체감될 수 있는 게임플레이에 대한 부분만 설명했습니다.

## 1. 락온 어빌리티 개선

- 플레이어 캐릭터가 락온 중일 때 옆걸음 가능
- 락온 중에 마우스 움직이면 해당 방향의 타겟 재탐색
- 적의 신체 부위별 락온 가능

## 2. 회피 어빌리티 개선

- 회피 어빌리티의 애니메이션을 8방향으로 개선

## 3. 아이템 사용 어빌리티 추가
- 충전형 포션 사용하는 어빌리티 추가 (GA_UseItem)

## 4. 적 정찰 기능

- 적이 Spline 경로를 따라 정찰하는 기능 추가
- 적의 시야각, 시야 감지 거리, 청각 감지 거리를 캐릭터 BP 변수화

## 5. 아이템 작업

- 충전형 포션 추가. 체크포인트 상호작용하면 충전
- 기본 지급 아이템 추가. 현재는 충전형 포션을 기본 지급
- 보상 테이블 추가. 보물상자 상호작용과 적 처치 시 보상 지급됨
- 아이템 등급 사전 작업 (Common/Rare/Epic/Legendary)

## 6. AI를 활용한 개발 환경 개선

- 디스코드 방에 AI 보고용 채팅방 생성
  - ai-room : AI가 최근 24시간 동안 작업 내용을 요약해서 알려줍니다. 
  - github-noty : 우리가 github에 작업물을 push 할 때마다 이를 감지해서 알려줍니다.
- 새벽 6시마다 AI가 프롬프트 자동 실행
  - 블루프린트 스냅샷 json 청소
  - 코드 관련 README.md 파일 최신화

# 💬 논의 주제

## 1. PC 조립 퀄리티

- 조립된 BP_HR 캐릭터의 품질이 기대 이하이며, 이 상태에서 추가 기능을 덧붙이면 더 나빠질 것으로 예상됩니다.
- 애니메이션 조립은 아트적인 감각이 필요한 작업이라서 창영님이 폴리싱을 하더라도 해결되지 않을 것으로 생각됩니다.
- 팀원 중에 애니메이터가 없다는 현실적인 한계를 받아들이고, 애니메이션 조립을 다시 해야한다고 판단합니다.

> #### 해결 방안 제안 1  
> - 민석님께 제작 방법을 알려드려서 PC를 하나 더 만든다. (1~2주 예상)  
> - BP_HR(창영님), BP_Player(우성님), BP_???(민석님)에서 괜찮은 부분만 섞어서 완성

> #### 해결 방법 제안 2  
> - 검증된 애니메이션을 하나 구매해서, 여기에 있는 것으로 전부 대체한다.  
> - https://www.fab.com/listings/e5fff258-3c0b-4e82-bcef-0408f4924a92

## 2. 월드의 크기 (km)

- 월드의 크기가 작더라도, 반드시 오픈월드 방식(월드 파티션)으로 구현 진행할 예정입니다.
- 대략적으로라도 월드 크기를 정해주셔야 본격적인 기획 및 구현이 가능할 것 같습니다.
- 민석님께서 제작 가능한 랜드스케이프나 Height map 규모를 판단하여 정하면 좋을 것 같습니다.

# 📋 요청 사항

## 1. 추가적인 아이템 필요성 검토

- 지금까지 아이템은 기획 없이 선구현 했습니다.
  - 현재 구현된 아이템: 골드, 충전형 포션
- 추가적인 아이템이 필요하다면, 어디까지 필요한지 아이템 기획이 필요합니다.
- 아이템 기획을 해달라는 요청이 아닌, 추가적인 아이템이 필요할지에 대한 검토 요청입니다.

## 2. Docs 폴더 정리

- 현재는 문서가 많지 않아서, 폴더 구조를 단순화하는 것이 낫겠습니다. 

> #### 해결 방안 제안
> - 카테고리 단위로 5개 폴더를 나누고, 내부에 중첩 폴더를 두지 않는 방향을 제안합니다.
>   - Combat design: 전투 기획서
>   - Level design: 레벨디자인 기획서
>   - System design: 시스템 기획서 (아이템, 퀘스트, 기타 등등)
>   - Programmer: 프로그래머 기술서
>   - Meeting: 회의 자료

- 마찬가지로 README.md 도 정리 필요합니다.
> #### 해결 방안 제안
>   - README.md는 시스템 기획서가 아니라 프로젝트 소개 문서입니다.
>   - Docs에 대한 포인터를 지워주세요.
>   - 시스템 기획을 나열하거나 규칙/흐름을 설명하지 마세요.
