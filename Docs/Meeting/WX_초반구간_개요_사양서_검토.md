## 1. 식생 (하)

- 폴리지를 만들어서 브러쉬로 칠해도 될텐데, PCG 작업을 고려하신 이유가 있을까요?

          - 모든 부분을 전부 브러쉬로 표현하기 어렵다 생각했음
          - PCG 학습 겸
          - 폴리지 브러쉬도 디테일한 기획에서는 고려중인데 이건 요청할건 아닌거같아서 적지 않았습니다.

## 3. 길 (하)

- 길은 Spline PCG로 만드는게 관리하기 더 좋습니다.
- 길을 지형이랑 똑같이 랜드스케이프에 직접 칠해버리면 오히려 분리가 안될 것 같은데, 어떤 부분이 걱정되나요?

          - 일부 오솔길의 경우에는 분리안된 느낌을 주거나 약간의 레벨 동선 유도를 위해 희끄무레하게 길을 만들고 싶어서 요청
          - 말씀하신대로 길 Spline PCG 작업 후에 필요한 부분을 머티리얼로 칠하면 될것같습니다(연구소 가는 길 등)

## 4. 시간 (하)

- 지역보다는 퀘스트 진행에 따라 시간대가 고정되는게 더 자연스러울 것 같은데, 기획적으로 검토해주세요.

          - 지역따라 날씨에 따라 분위기를 연출할 계획 (엘든링 케일리드가 에시)
          - 다만 일직선형 오픈월드 레벨디자인이고, 지역이 진행됨 자체가 퀘스트 진행과 관련 있으므로 문제 없어보이는데 이건 토의 후 결정

## 6. 퀘스트 (상)

- 세부적인 퀘스트 시나리오와 기획서 준비해주세요.
- 적 웨이브 스폰은 퀘스트의 이벤트에 포함시키겠습니다.
- 화포 코드 상호작용은 아이템 획득 방식이 아니라, 선형적인 퀘스트 진행 방식으로 동작합니다.
  - 신규 아이템은 추가하지 않겠습니다. 아이템에 대한 기반 기획이 없는 상태에서 그때그때 개별 아이템을 추가하다보면, 시스템 규칙이 이상해지기 때문입니다.

            - 웨이브 스폰을 퀘스트 시스템이라고 부르시던데 용어가 제가 헷갈려서 이에 관해 토의 필요
            - 세부 퀘스트 기획서는 준비하겠습니다.
            - 아이템을 만들진 않더라도 코드를 얻었다는 느낌을 줘야할텐데, 이거는 고민을 해봐야겠네요.

## 기타

### 1. 우선순위 규칙

- 우선순위 규칙은 잘 세우셨는데, 규칙이 일관적으로 적용되진 않은 것 같습니다. 식생이나 자갈 없으면 초반 구간이 성립 안된다는게 저로서는 잘 이해가 안되는 부분입니다.
- 구현 관점에서는 대체로 게임플레이가 1순위고, 장식성 요소는 후순위입니다.

          - 단순히 장식적 요소가 아니라 유저의 동선을 인식시키고 유도하는지 확인하기 위해서 필요한 것으로 생각합니다. 
          - 다만 현재 후반던전 기믹 제작 등 다양한 조정이 필요하여, 우선순위에 대한 고려는 다시하겠습니다.

### 2. 기능 구현 비중 조절

- 기능 구현에 비중이 너무 쏠리면 레벨디자인 포폴로서 안좋게 작용할 것 같습니다.
- 민석님은 본인의 레벨디자인 역량 어필에 집중해주세요.
- 저는 기술 지원 위주로 서포트하겠습니다.

          - 저도 레벨디자인에만 쏟고싶은데, 현재 타 포폴 현황이나 공고를 보았을때는 기술적 능력이 무조건 필요할 것으로 생각됩니다.
          - 다만 이건 개인적인 고민으로 생각되므로 일단은 넘어가겠습니다.

### 3. 적 배치 관련

- 적 배치에 따라 뒤잡, 앞잡 규칙에 수정이 필요할 수도 있을 것 같습니다.
- 참고로 지금 잠입 기능(C키) 구현되어있으니 궁금하면 테스트해보세요.

          - 수정이 어떤게 필요할것 같은지 대해서 이야기해보면 좋을것 같습니다.

### 4. 레거시 기믹 제거

- 안쓰게될 기믹 목록 알려주세요. (레이저벽, 적 스폰 버튼 같은)
- 개발 단계에서는 억지로 재활용하는 것 보다는 빠르게 폐기하는게 낫습니다.

          - 레이저 통로, CCTV 관측기, 스폰 버튼, 경보 버튼은 사용하지 않을것 같습니다.
          - 엘리베이터, 문, 보물 상자 등등은 사용할 예정이고, 그 외 궁금한건 물어봐주시면 될것 같습니다.
