# WX_초반구간_사양서 검토

> 별도의 언급이 없으면 프로그래밍적인 구현이 필요 없다는 의미입니다.
> 구현 관점에서 우선순위가 이상하게 느껴지는 부분은 순위 재조정했습니다.
> 제가 민석님 의도를 캐치 못했거나, 누락된 부분 있으면 알려주세요.

### 1. 식생 (하)
* 폴리지를 만들어서 브러쉬로 칠해도 될텐데, PCG 작업을 고려하신 이유가 있을까요?

### 2. 물 (하)
* Water 플러그인 사용합시다.
* 다음 문서 읽고나면 혼자서 충분히 하실 수 있을 것 같은데, 지원 필요하면 저한테 문의주세요.
  * https://dev.epicgames.com/documentation/unreal-engine/water-body-actors-in-unreal-engine

### 3. 길 (하)
* 길은 Spline PCG로 만드는게 관리하기 더 좋습니다.
* 길을 지형이랑 똑같이 랜드스케이프에 직접 칠해버리면 오히려 분리가 안될 것 같은데 어떤 부분이 걱정되나요?

### 4. 시간 (하)
* 지역보다는 퀘스트 진행에 따라 시간대가 고정되는게 더 자연스러울 것 같은데, 기획적으로 검토해주세요.

### 5. HLOD (중)
* 연구해보겠습니다.

### 6. 퀘스트 (상)
* 세부적인 퀘스트 시나리오와 기획서 준비해주세요.
* 적 웨이브 스폰은 퀘스트의 이벤트에 포함시키겠습니다.
* 화포 코드 상호작용은 아이템 획득 방식이 아니라, 선형적인 퀘스트 진행 방식으로 동작합니다.
  * 신규 아이템은 추가하지 않겠습니다.
  * 아이템 기반 기획이 없는 상태에서, 그때그때 개별 아이템을 추가하다보면 시스템 규칙이 이상해지기 때문입니다.

### 7. 거점 활성화 (중)
* 레벨시퀀스로 근처를 주요 지점을 보여주는 연출로 대체합시다. (어크 같은)
* 영상 찍었을 때 POI 보여주는 용도로 이게 더 나을 것 같습니다.
* 월드맵 안만들겠습니다. UI로 가라치면 나중에 폐기 비용 발생합니다.

### 8. 다이얼로그 (상)
* 기반 시스템 준비하겠습니다.
* 세부 기획 준비해주세요. (UI, 입력, 카메라, 데이터 관리 등)

### 9. 화포 건물 내부 (상)
* 글만으로는 이해가 잘 안되서, 던전 구조에 대한 프로토타이핑이나 기획서 준비해주세요.
* 기어 작동 연출이 필요하다면 나이아가라로 증기 VFX 출력하거나 끄는 방식으로 하죠.

### 10. 화포 발사 (중)
* 순수 연출이고, 카메라 연출이 필요해보이니 BP 말고 레벨시퀀스를 씁시다.
* BP에서 직접 로직을 짜고 싶으시다면, 다른 후보를 찾아보죠.

# 기타

우선순위 규칙과 본문 내용이 다른 것 같습니다. 식생이나 자갈 없으면 초반 구간이 성립 안된다는게 이해가 안되어서요.  
구현 관점에서는 게임플레이가 1순위고, 장식성 요소는 후순위입니다.

기능 구현에 비중이 너무 쏠리면 레벨디자인 포폴로서 안좋게 작용할 수 있을 것 같아요.  
민석님은 본인의 레벨디자인 역량 어필에 집중해주시고, 저는 기술 지원 위주로 서포트하겠습니다.

적 배치에 따라 뒤잡, 앞잡 규칙에 수정이 필요할 수도 있을 것 같습니다.  
참고로 지금 잠입 기능(C키) 구현되어있으니 궁금하면 테스트해보세요.

안쓸 기믹, 제거할 기믹 알려주세요.(레이저벽, 적 스폰 버튼 같은)  
개발 단계에서는 굳이 억지로 재활용하는 것 보다는 빠르게 폐기하는게 나아요.
