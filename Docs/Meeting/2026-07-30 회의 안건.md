# 개발 진행 사항

## 1. 퀘스트 개발 중
- 선형적 구조로 개발. 퀘스트 실패는 안만들 예정
- State Tree 기반. 약 2주 후 사용방법 가이드 예정
- 다음 회의 전까지 상세한 퀘스트 시나리오 전달 요청

## 2. 다이얼로그 개발 중
- 선형적 구조로 개발. 선택지는 안만들 예정
- Data Table 기반. 약 2주 후 사용방법 가이드 예정
- Npc 초안도 개발함. 나중에 메타휴먼이나 Mass entity 등 기술적 요소를 적용하게 될 예정

## 3. 앞잡, 뒤잡 대미지 통일
- DT_Damgae에서 AM_Finisher 항목 수정하면 수치 변경 가능.

## 4. 잠입 모드 개발 완료
- C키 토글하면 웅크린 상태로 이동하고, 발소리가 안남
- 적에게 조용히 접근해서 뒤잡하기 좋음

## 5. 기믹 갱신
- 유지되는 기믹 : 문, 엘리베이터, 보물상자, 체크포인트
- 삭제한 기믹 : 레이저 통로, 스폰 레버, 알림 레버, CCTV
- 체크포인트를 확장해서 거점의 기능을 추가하는 것을 제안
  - 체크포인트 첫 상호작용 시에만 주변 지역 구경시켜주고, 월드맵(임시) 띄우는 기능이 추가됨
  - 이번 주 내에 기믹 기획서 갱신 요청

## 6. 치트 시스템 선행 개발
- 플레이어 자살 치트 : KillPlayer
- 플레이어 자해 치트 : DamagePlayer {dmg:float}
- 100m 내의 적 즉사 치트 : KillNearby {range:float}
- 기타 테스트에 필요한 치트 있으면 건의 요청

# AI 활용 시 당부사항

이하의 원칙은 반드시 지켜주세요. 같은 실수가 반복되면 안됩니다.

1. AI가 생성한 글에서 본인이 설명할 수 없는 내용은 뺀다.

2. AI가 설계한 내용을 프로그래머에게 전달하지 말 것.

3. AI에게 기획적인 의도를 넘기지 말 것. 의도와 판단은 사람의 몫이다.
