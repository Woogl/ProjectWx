# 게임 프로그래밍 언어

## 1. 실행 방식에 따른 프로그래밍 언어 분류

사람이 쓴 코드는 그대로 실행되지 않는다.  
기계가 알아듣는 형태로 번역되어야 한다.  
**그 번역이 언제 일어나는가**에 따라 크게 두 가지로 나뉜다.

### 1) 컴파일 언어

| 항목 | 내용 |
| -- | -- |
| 방식 | 소스 코드 전체를 빌드해서 실행 가능한 바이너리 파일을 만든다. (컴파일러) |
| 장점 | 높은 성능. 컴파일 타임에 오류를 잡아냄 |
| 단점 | 수정할 때마다 빌드 필요. 높은 학습 난이도 |
| 예시 | C, C++, Rust |

### 2) 인터프리터 언어 (스크립트)

| 항목 | 내용 |
| -- | -- |
| 방식 | 실행 시점에 소스 코드를 한줄씩 읽어가며 처리한다. (인터프리터) |
| 장점 | 빌드 없이 즉시 반영. 낮은 학습 난이도 |
| 단점 | 실행 속도와 성능 낮음. 런타임 시점에 오류 발견됨 |
| 예시 | Python, Lua, JavaScript |

---

## 2. 게임 개발에서 왜 여러개의 언어를 쓰는가?

이론적으로는 하나의 언어로 모든 게임 콘텐츠를 개발할 수 있다.  
하지만 두가지 토끼를 모두 잡기 위해서 여러 언어를 사용해 적절히 분업한다.

| 계층 |  분야 | 주요 예시 | 담당 |
| -- | -- | -- | -- | 
| 컴파일 언어 | 물리, 렌더링, 네트워크, 프레임마다 도는 코어 로직 | 엔진 저수준 작업, 고성능이 요구되는 분야 | 프로그래머 |
| 스크립트 언어 | 빠른 개발 Iteration 및 테스트가 요구되는 분야 | 신규 콘텐츠, UI, 프로토타이핑 | 기획자, 아티스트, 프로그래머 |

## 3. 언리얼 엔진에서 지원하는 언어

| 언어 | 사용 시기 | 계층 | 현재 위치 |
| -- | -- | -- | -- |
| C++ | UE1 ~ 현재 | 컴파일 | 엔진 본체 |
| Blueprint | UE4 ~ 현재 | 스크립트 | UE5 주력 |
| Verse | UEFN(2023~), UE6 | 스크립트 | 차기 주력 |
| Unreal Script | UE1 ~ UE3 | 스크립트 | 폐기됨 |
| Python | UE4.20 ~ 현재 | 스크립트 | 에디터 전용 |

### 1) C++

엔진을 구성하는 네이티브 언어.

**장점**
- 성능 상한이 가장 높음
- 엔진의 모든 기능에 접근할 수 있음

**단점**
- 수정할 때마다 재빌드, 에디터 재시작 필요
- 크래시 위험성 존재
- 학습 부담 높음

```c++
#pragma once
 
#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "FloatingActor.generated.h"
 
UCLASS()
class QUICKSTART_API AMyActor : public AActor
{
    GENERATED_BODY()

public:
    // 이 액터 프로퍼티의 디폴트 값 설정
    AMyActor();

    UPROPERTY(VisibleAnywhere)
    UStaticMeshComponent* VisualMesh;

protected:
    // 게임 시작 또는 스폰 시 호출됨
    virtual void BeginPlay() override;

public:
    // 프레임마다 호출됨
    virtual void Tick(float DeltaTime) override;
};
```

### 2) Blueprint

UE4부터 도입된 비주얼 스크립트 언어

<이미지 첨부 예정>

**장점**

### 3) Verse

Epic이 만든 차세대 스크립트 언어

- 함수형·논리형·명령형에서 아이디어를 가져온 다중 패러다임 언어
- 모든 함수가 값을 반환하며, 원자적 트랜잭션을 언어 차원에서 지원
- 텍스트 기반이므로 AI 입장에서 가독성 우수

### 4) Unreal Script

UE1(1998)부터 UE3까지 사용된 텍스트 기반 스크립트 언어.  
UE4에서 제거되었고, 그 역할은 Blueprint와 C++이 한다.

```
// Declare two variables that refer to a pawns.
var pawn P, Q;
 
// Here is a function that makes use of P.
// It displays some information about P.
function MyFunction()
{
    // Set P’s enemy to Q.
    P.Enemy = Q;

    // Tell P to play his running animation.
    P.PlayRunning();
}
```

### 5) Python

UE4.20부터 지원되어 에디터 유틸리티를 만들 수 있는 언어.

**장점**
- 에셋 일괄 수정, 임포트 자동화 같은 에디터 자동화 파이프라인을 만들 수 있음

**단점**
- 패키징된 게임 빌드에서는 실행되지 않기 때문에 게임플레이 로직에 사용 불가

```py
import unreal

# 에디터 세계(World) 가져오기
editor_actor_subsystem = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)

# 스태틱 메시 액터를 레벨에 생성 (기본 큐브 기본 에셋 지정)
mesh_asset = unreal.EditorAssetLibrary.load_asset("/Engine/BasicShapes/Cube.Cube")
spawned_actor = editor_actor_subsystem.spawn_actor_from_object(mesh_asset, unreal.Vector(0.0, 0.0, 100.0))

# 액터 이름 및 위치 변경
spawned_actor.set_actor_label("Python_Cube_01")
spawned_actor.set_actor_location(unreal.Vector(200.0, 100.0, 150.0), sweep=False, teleport=False)

unreal.log(f"액터 생성 완료: {spawned_actor.get_actor_label()}")
```
