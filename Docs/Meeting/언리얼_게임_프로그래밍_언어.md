# 게임 프로그래밍 언어

## 코드의 종류
게임이 규칙대로 동작하기 위해서는 코드(프로그래밍 언어)가 필요하다.  
코드는 실행 방식에 따라 두가지 카테고리로 나뉜다.

### 1. 컴파일 언어
개넘: 실행 전에 기계어로 변환 후 실행하는 언어
컴파일러: 소스 코드 전체를 기계어로 변환해서 실행가능한 바이너리를 만든다.
장점: 고성능, 컴파일 타임 검증
단점: 학습 난이도 높음, 수정할 때마다 빌드해야됨, 크래시 위험성
예시: C, C++, Rust

### 2. 인터프리터 언어 (스크립트)
개념: 실행 중에 한줄씩 읽어가면서 실행하는 언어
인터프리터: 소스 코드를 한줄씩 읽어가면서 처리한다.
장점: 쉬운 난이도, 컴파일 없이 빠른 테스트
단점: 저성능, 런타임 에러 발생 가능성
예시: C#, Python, Lua

## 게임 개발에 왜 언어를 두개 이상 함께 쓰는가?
이론적으로는 하나의 언어로 모든 컨텐츠를 만들 수 있지만, 분업을 고려하여 적절히 스크립팅으로 구현하는 것이 일반적.

| 언어 | 주요 활용처 | 예시 |
| -- | -- | -- |
| 컴파일 언어 | 고성능이 요구되는 곳 | 물리, 렌더링, 실시간 네트워크 |
| 인터프리터 언어 | 반복 작업에서 빠른 Iteration이 필요한 곳 | 신규 컨텐츠, UI, 테스트, 디버깅 |

## 언리얼 엔진에서 지원하는 언어

### 1. C++
엔진을 구성하는 네이티브 프로그래밍 언어

### 2. Blueprint
UE4~UE5에서 사용된 비주얼 스크립트 언어

### 3. Verse
UE6 부터 도입되는 차세대 함수형 스크립트 언어

### 4. Unreal Script
UE2~UE3에서 사용된 텍스트 기반 스크립트 언어

### 5. Python
UE5에서 에디터 유틸리티를 만드는데 제한적으로 사용 가능
