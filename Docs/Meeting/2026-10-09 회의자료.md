## 현광(약운) A/S 완료

* 궁극기 1,2 코스트를 UP 100으로 통일
* 적에게 대미지 가할 때마다 UP 10씩 회복
* MP 안쓰는 캐릭터로 변경, HUD에도 MP 출력 안되게 수정
* 도플갱어 위치를 PC 우측 50cm로 바꾸고, 벽과 바닥 관통되게 수정
* 궁극기 1 활성화 중(도플갱어 소환 중)일 때 전기 VFX Looping
* 동영상 촬영 끝났으면 이것으로 사후지원 마무리하겠음

## 숲 바이옴 PCG 개발 완료

* `PCG_ForestBiome` : 랜드스케이프 위에 놓인 스플라인/컨텐츠를 인식해서 숲에 어울리는 아트 에셋을 자동 배치해줌
  * 머터리얼: 흙, 이끼, 절벽
  * 포인트 샘플러: 나무, 풀, 잔디, 바위
  * 스플라인 샘플러: 오솔길, 강 
* `PCG_Road`: 도로 만드는 법이 바뀌어서 교체해야됨. 가이드 드리겠음
* 제가 생각한 PCG 바이옴 개발 방향성에 대해서는 문서 참고
  * [PCG 개발 방향성](PCG%20개발%20방향성.md)

## 퀘스트 샘플 추가 예정

* `Quest_MoveToTarget` : 위치로 이동하기 샘플
* `Quest_InteractToTarget` : 대상과 상호작용하기 샘플
* `Quest_KillEnemy` : 적 처치하기 샘플
* `Quest_Final` : 적 3웨이브 처치 + 적 웨이브 시작할 때마다 대사 출력 + 모두 클리어하면 레벨시퀀스 재생

# 프로젝트 방향성 이슈

## 현재 프로젝트 상태 진단
* 전투 포폴을 위해서 명조로 방향성을 잠시 틀었던 부분을 마무리하고, 기획 방향을 조정해야됨
* 그런데 이대로 가다가는 영영 프로젝트가 끝나지 않을 것 같고, 지속불가능할 것 같은 생각이 들음
* 현재 문제점
  * 그때그때 추가하고 싶은 것을 더하다보니 프로젝트의 방향이 명확하지 않은 연습장처럼 되었음
  * 프로젝트 완성과 무관한 부분에 시간을 낭비함 (디테일, 장식요소, 모듈화, 멀티플레이, 작업 편의성)
  * 필요없는 부분까지 오버엔지니어링하거나, 낡은 기획이 쌓임

## 미니 프로젝트에서 실험
> 개발 철학: AI가 실무자다. 사람은 디렉터다.
* 미니 프로젝트에서 실험 진행해보는 중이며, 다음주 회의 때 결과 공유 예정
  * https://github.com/Woogl/Ag/blob/main/Docs/AI%20%EC%9B%8C%ED%81%AC%ED%94%8C%EB%A1%9C%EC%9A%B0.md
* 바이브 QA, 바이브 밸런싱 정도는 가능하게 지원할 예정. C++의 한계점 때문에 바이브 구현까지는 좀 힘듦.
* 약 2주의 마일스톤을 반복
  * 기획 단계 (1주일): AI 입장에서 일하기 좋은 기획서를 작성한다. 모순점, 중복 서술, 누락된 내용이 없어야함.
  * 구현 단계 (1주일): AI에게 기획서를 모두 전달하고, 구현 계획을 세우고, 승인된 계획대로 AI가 모두 구현한다.
  * QA 단계 (3일): 사람이 플레이해보고 피드백
* 마일스톤 일정
  * M1 보스전 (10월 중) : 전투 시스템, 플레이어 캐릭터(1종), 보스 캐릭터(1종)
  * M2 필드전 (11월 초) : 쫄병 캐릭터(근거리 1종, 원거리 1종), 필드 레벨디자인
  * M3 성장요소 (11월 말) : 아이템, 인벤토리, 재화, 장비, 레벨업
  * M4 내러티브 (12월 중) : 퀘스트, NPC, 상호작용
  * 참고로 마일스톤 주제가 확정된 것은 아님
* 무조건 올해 내에 프로젝트를 마무리할 예정
