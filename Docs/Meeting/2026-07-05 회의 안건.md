# 1. 구현 사항 공유

## 1-1. 앞잡/뒤잡 구현 진행 중
* GA_Finisher 추가했으며, F 키로 발동 가능
* 기획적으로 추가 확인 필요한 부분이 있어 70% 정도만 구현된 상태.
* 상호작용 UI에서 대상 선택하고, 선택된 대상에 대한 외곽선 강조 있음.
* 락온한 적, 가까운 적에 대한 상호작용 UI 우선순위 정렬은 후순위 작업 예정.

#### 앞잡 관련
* 현재는 앞잡 대미지도 크리티컬 터질 수 있음.
→  크리티컬 안터지게 할지 기획적인 확인 필요.
* 앞잡 모션 속도가 시전자의 ASPD(공속 스탯) 영향을 받아야할지?
→ 피격자 모션 속도 이슈가 있어, ASPD 영향 안받는 방향을 희망함.

#### 뒤잡 관련
* 적절한 애니메이션이 없어서, 일단 앞잡과 같은 애니메이션을 사용함.
→ 적절한 애니메이션 찾으면 수정 가능.
* 뒤잡 기획 관련해서 확인 필요한 부분은 이번 회의에서 결정하고 추가 작업하겠음.
  * 뒤잡 당한 적을 즉사시킬지?
  * 보스/엘리트몹은 뒤잡 면역시킬지?

## 1-2. 체크포인트 리팩토링 중
* BP_CheckPoint를 Gimmick 기반에서 PlayerStart 기반으로 변경함.
* 레벨에 배치되어있는 BP_CheckPoint 재배치 필요.
* PIE에서 랜덤한 체크포인트에서 시작되는 버그가 있는데, 빠른 시일 내에 고칠 예정.

## 1-3. BGM 시스템 선개발
* WxSound 플러그인 추가.
* 플레이어와 적의 전투 상태나, 플레이어가 위치한 지역에 따라서 적절한 BGM을 재생함.
* Chooser Table 기반으로 개발.
  * Chooser Table에 대한 도큐먼트: https://dev.epicgames.com/documentation/unreal-engine/dynamic-asset-selection-in-unreal-engine?lang=ko

# 2. 논의 안건

## 2-1. UE 5.8 버전업
* UE 5.8 이 출시되었으며, 빠른 시일 내에 엔진 버전업 희망함.
* UE 5.8 은 마지막 UE 5 정식 버전으로, 에픽게임즈는 앞으로 UE 6 출시에 집중할 예정이라고 함.
* UE 5.8 은 MCP 지원이 추가되어 LLM로 에디터 작업이 가능하다는 점이 강력함.

## 2-2. 다이얼로그, 컷신 시스템 관련
* 궁극기 컷신에 대한 프로그래밍적인 구현은 되어있으나, 궁극기 컷신 에셋 작업이 지연되고 있음.
* 레벨시퀀스 작업이 부담되거나, 우선순위가 낮다면 궁극기에서 컷신을 안쓰는 것을 고려해볼 수 있음.

## 2-3. 기획서와 코드 간의 이격 이슈
* 기획서에 최신화되지 않은 내용, 코드에서 먼저 선구현되는 내용이 많은 편임.
* 원칙적으로는 코드 구현 이전에 기획서가 먼저 최신화되어서, 기획서가 단일 진실 공급원(Single Source of Truth)가 되는 것이 바람직함.
* 이슈를 해결하기 위해 AI Skill을 시범 운영하겠음.
  * `/spec-audit` : 지정한 기획서를 실제 코드 구현 사항을 대조하여 분류하는 AI Skill
  * `✅ 일치` : 기획대로 구현됨(수치·동작 일치).
  * `❌ 불일치` : 구현은 됐으나 기획과 다름(수치가 다르다·동작이 다르다·조건이 다르다).
  * `⚠️ 미구현` : 코드에 해당 규칙의 흔적이 없음.
  * `❔ 확인불가` : 코드만으로 판단 못 함(DataTable Row·BP 디폴트값·에셋 설정에 의존).
* 다른 해결방안이 있다면 의견 제시 희망함.
