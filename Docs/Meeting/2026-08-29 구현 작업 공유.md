# 작업 내용

## 레벨디자인 관련
1. 박스 컴포넌트 꼭지점에 피봇 핸들 추가
2. 연결된 디바이스 간의 연결선 추가
3. 배치된 디바이스의 초기 상태를 편집 가능 (InstanceEditable)

## 전투 관련
4. 패시브 어빌리티 추가. 임시로 적 타격 시 MP5, UP5 회복.
5. 소울라이크 방식 선입력 추가 (0.4초)
6. 퍼펙트 회피 시 잔상 추가
7. 타격, 피격 시 카메라 셰이크 추가
8. 적 패턴 어빌리티의 콤보 몽타주 지원

## 기타
9. 시작 화면 레벨 추가 (LV_FrontEnd)

# 작업 예정
1. 캐릭터 개발
2. 지역 볼륨 추가
3. 퀘스트 신규 기능 추가
4. PCG

# 요청 사항
1. LV_OpenWorld 에 PlayerStart 배치하기
2. 던전 내 피스톤 배치 완료하기
3. Player의 포트레이트 만들기 (1024*1024)
4. Player의 공격, 회피, 스킬, 궁극기 아이콘 만들기 (512*512)
