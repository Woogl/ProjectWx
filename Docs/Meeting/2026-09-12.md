# 전투 구현 상황 공유

## 현광 E 스킬 구현 완료

BP_TestHG 로 플레이해서 E 스킬 쓰면 테스트 가능합니다.

분신 소환, 분신 돌진(협동), UI 전환, 자원 회복, 충돌 처리, 어그로 제외 등이 적용되어 있습니다.

기획 요구에 부합하는지 확인해주시면 될 것 같아요.

이어서 현광 궁극기 작업 예정입니다.

## 공용 어빌리티를 담는 ABS 추가

ABS_Shared_Player, ABS_Shared_Enemy를 추가했습니다.

각각 모든 PC가 공통적으로 쓰는 어빌리티, 모든 적이 공통적으로 쓰는 어빌리티를 관리합니다.

공용이므로 수정하면 안됩니다.

## 캐릭터 Template 추가

신캐 만들 때 복붙해서 쓸 수 있는 샘플용 TemplatePlayer, TemplateEnemy 생성했습니다.

폴더 통째로 Advanced Copy 해서 레퍼런싱 유지시키고, 에셋 이름 일괄 변경하는 워크플로우를 추천합니다.

당연한 부분이지만, 테이블 데이터 추가나 추가 기능은 직접 작업해야합니다.

## 적 시야 범위 변수화

AIBehaviorComponent에 시야 거리, 시야각, 청각 거리 변수 추가했습니다.

적 시야에 대한 에디터 시각화 추가했습니다.

## 범위 공격 기능 추가

기존에 대미지 발생은 무기나 투사체를 통해서만 가능했는데요, ANS_AreaDamage를 쓰면 시전자 근처에 범위로 대미지를 가할 수 있습니다.

범위(AOE)나 필터링 데이터는 TargetingPreset으로 관리합니다.

BP_TemplatePlayer의 궁극기 어빌리티 참고하면 됩니다.

겸사겸사 이러한 TargetingPreset을 쓰는 AnimNotify들의 범위에 대해 에디터 시각화도 추가했습니다.
