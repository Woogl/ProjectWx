# 🗺️ 레벨디자인 관련 작업

## 1. 상호작용 재설계

기존의 기믹(Gimmick) 구조를 모듈식 액터(Device)로 재설계했습니다.
이전에는 하나의 컨텐츠 규칙을 중시하여, 상호작용 대상을 하위 구성요소(컴포넌트)로 제한했습니다.
현재는 각각의 독립적인 모듈식 액터(Device) 단위로 배치 및 조립하여 외부 구동 가능한 방식으로 설계를 변경했습니다.

따라서 기존의 Gimmick 이라는 용어는 폐기됩니다.
기획서에 각 컨텐츠에 대한 조립 예시와 상호작용을 적어주셨으면 합니다.

**장점**
- 장치 액터들을 다양하게 조립하여 다양한 퍼즐 콘텐츠를 만들 수 있도록 확장성이 증가했습니다.

**단점**
- Device 조립에 대한 경우의 수가 다양해지므로 작업 복잡도가 상승합니다.
  - 조립이 필요없는 경우(자체 완결): 보물상자, 체크포인트
  - 하나의 연결만 요구하는 경우(1:1): 문
  - 여러개의 연결을 요구하는 경우(1:N): 엘리베이터
  - 케이스바이케이스인 경우(N:N): 피스톤
- 에디터 편의기능 몇가지 추가할 예정이며, 작업 중 불편사항 있으면 개선 아이디어 제안 부탁드립니다.

피스톤 장치 개발은 내일 중으로 완료 예정입니다.

## 2. 퀘스트 시스템 개발 완료

퀘스트 시스템 작업 편의를 위한 몇가지 프리셋 추가했습니다.
LV_OpenWorld에서 간단한 퀘스트 몇가지 만들면서 테스트해보시길 바랍니다.
- NPC와 대화하기 퀘스트
- 목적지로 이동하기 퀘스트
- 적 죽이기 퀘스트

# ⚔️ 전투 관련

## 3. 어빌리티 개선

여러개의 스킬(1,2,3,4)을 E스킬 1개로 줄였습니다.
강공격(좌클릭 홀드), 낙하공격(공중에서 좌클릭) 추가했습니다.
적 패턴 어빌리티도 PC 공격/스킬 어빌리티처럼 몽타주 여러개를 연속 발동할 수 있도록 수정했습니다.

## 4. 스탯 수정

구두 논의된 사항 코드에 반영했습니다.
- 현재 구현된 모든 스탯에 음수 허용 안함 (현재는 저항력 스탯이 없음)
- 치확, 치피는 백분율로 입력

스탯 기획서 작성 시 이하 내용 참고 부탁드립니다.
- 각 스탯에 대한 Min, Max, Default 값 설명 필요
- 백분율, 만분율인 경우에는 단위 기재 필요

## 6. 대미지 테이블 수정

대미지 테이블의 UP 회복량, MP 회복량 제거했습니다.
명조의 공명회로 처럼 캐릭터별 자원 회복 규칙이 추가될 예정으로 알고 있습니다.

대미지 테이블에 크리티컬 발생 불가능하게 막는 플래그 추가했습니다.
앞잡, 뒤잡, 도트댐 같은 곳에서 사용할 것으로 예상합니다.

## 7. 포폴용 캐릭터 기획서 최종안 작성 요청

입사 지원 포폴용 캐릭터 기획서라고 생각하시고, 누락되는 내용 없이 꼼꼼하게 최종 기획서 작성 부탁드립니다.

이하는 제가 공유드리고 싶은 내용입니다.
- 읽고 이해하기 쉽게 고유 용어 최소화했으면 합니다. 직관적인 용어(E스킬, 궁극기, MP 등) 사용해주셨으면 합니다.
- 포폴용 캐릭터의 MP 회복, UP 회복에 대한 기획 추가 부탁드립니다.
- 변신 기능 구현 가능하므로 필요하다면 추가 부탁드립니다.
- 연출 관련된 부분(잔상 등)에 대해서는 구현 작업하다가 필요할 때마다 물어보겠습니다.
