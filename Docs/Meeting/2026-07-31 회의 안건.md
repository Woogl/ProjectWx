# 개발 진행 사항

## 1. 퀘스트 개발 중
- 선형적 구조로 개발. 퀘스트 실패는 안만들 예정
- State Tree 기반. 약 2주 후 사용법 가이드 예정
- 다음 회의 전까지 상세한 퀘스트 내용 전달 요청 바랍니다.

## 2. 다이얼로그 개발 중
- 선형적 구조로 개발. 선택지는 안만들 예정
- Data Table 기반. 약 2주 후 사용법 가이드 예정
- NPC 초안도 개발 중. 나중에 메타휴먼이나 Mass entity 등 기술적 요소를 적용 예정

## 3. 앞잡, 뒤잡 대미지 통일
- DT_Damgae에서 AM_Finisher 항목 수정하면 대미지 수치 변경 가능

## 4. 잠입 모드 개발 완료
- C키 토글하면 웅크린 상태로 이동하고, 발소리가 안남
- 적에게 조용히 접근해서 뒤잡하기 좋음

## 5. 기믹 갱신
- LV_OpenWorld 에서 필요 없는 기믹 모두 제거했습니다.

| 분류 | 기믹 |
| -- | -- |
| 유지 | 문, 엘리베이터, 보물상자, 체크포인트 |
| 삭제 | 레이저 통로, 스폰 레버, 알림 레버, CCTV |

- 이번 주 내에 기믹 기획서 갱신 요청 바랍니다.
- 기존 기믹 기획도 수정 필요하게 될 것 같은데, 퀘스트 시나리오 전달 받으면 검토하겠습니다.

| 기믹 | 변경 제안 |
| -- | -- |
| 체크포인트 | 거점 기능 추가(확장)하는 것을 제안.<br>첫 상호작용 시에만 주변 지역 구경시켜주고, 월드맵(임시) 띄운다. |

## 6. PCG 개발 중
- 도로 PCG를 두가지 방식으로 구현했습니다.
- 테스트 결과 데칼 액터 방식 대신에 스플라인 메시 방식만으로도 작업하는 것을 권장드립니다.

| 구현 방식 | 샘플 에셋명 | 장점 | 단점 |
| -- | -- | -- | -- |
| 데칼 액터 | PCG_RoadDecal | 비포장도로 표현에 적합 | 투영할 표면이 없으면 사용 불가<br>캐릭터나 나무 위에 데칼 깔리는 현상 방지가 까다로움<br>연산량이 매우 높음 |
| 스플라인 메시 | PCG_RoadSplineMesh | 포장도로 표현에 적합<br>고가도로 등 자유로운 표현 가능 | 굴곡이 심한 곳에서는 튀어나오거나 파뭍혀서 어색할 수 있음 |

## 7. 치트 시스템 (선행 개발)
- 테스트에 필요한 치트 추가

| 치트 | 기능 | 비고 |
| -- | -- | -- |
| `WxKillPlayer` | 플레이어 자살 치트 | |
| `WxDamagePlayer {dmg:float}` | 플레이어 자해 치트 | 입력한 수치만큼 대미지 입음 |
| `WxKillEnemies {range:float}` | 적 즉사 치트 | 수치 입력 안하면 기본 범위 100m |

- 그 외 필요한 치트 있으면 언제든지 건의 요청 바랍니다.

## 8. 게임플레이 피쳐 모듈화 (선행 개발)
- 미니 게임 같은 것도 확장해서 붙일 수 있게 준비 중
- 낚시, 퍼즐 등
