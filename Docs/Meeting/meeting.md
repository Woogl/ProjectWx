# 📋 전달사항

## 플레이어 캐릭터 기획

아직 플레이어 캐릭터 관련된 세부 기획 문서를 전달받지 못했습니다.

보스나 적보다는 플레이어 캐릭터가 훨씬 더 중요하므로, 우선순위 높혀서 만들어주셨으면 합니다.

## 보스 기획
* 관련 기획서: `WX_첫_보스_기획서.docx`

창영님 머리속에 어떠한 아트스타일이나 전투 장면이 구체화되신 것 같습니다.

저와 민석님과 공유가 더 잘 될 수 있도록, 아트 스타일이나 전투 장면에 대한 **컨셉 아트 3~4장**을 만들어주셨으면 합니다. 

AI를 활용하셔도 좋고, 원하시는 느낌만 전달되면 됩니다.

## 배치물 기획

* 관련 기획서: `Object_Design.md`

고생하셨습니다. 몇가지 오류가 있긴 한데, 이런 부분은 따로 말씀드리겠습니다.

샘플 배치물은 우선순위대로 구현하고, 완성되는대로 민석님께 바로바로 공유드리겠습니다.

서로 물어볼 부분 있으면 즉시 DM으로 물어보면서 처리해도 될 것 같습니다.

## 리스폰 기획

* 관련 기획서: `Respawn_System.md`

플레이어 캐릭터 사망 및 부활에 대해서는 작업할 것이 좀 많습니다.

배치물, 플레이어 캐릭터, 적 관련 작업이 끝나고 나면 진행하겠습니다.

## 아이템 기획 검토 (신규)

아이템 및 인벤토리에 대한 기반 구현이 완료되어있습니다.

인게임에서 키보드 I 키를 누르면 인벤토리 들어갈 수 있고, 보유 중인 골드 수량 확인 가능합니다.

아이템 관련된 신규 기획이 필요할 수도 있을 것 같은데, 두 분이서 논의하시어 결정바랍니다.

프로토타입 단계에서는 중요하지 않다고 판단되면 건너뛰어도 괜찮습니다.

**아이템 기획 시 고려해봄직한 것들**
* 아이템에 대한 정의와 규칙?
* 골드 외 신규 구현 필요한 아이템?
* 아이템 획득 관련된 HUD 정보, 신규 UI?

# 과제

## 이창영
- 아트 스타일이나 전투 장면에 대한 컨셉 아트 3~4장을 만들어주세요
  - 민석님이 아트 리소스를 찾을 때, 제가 보유한 에셋 중에 적절한 것이 있는지 찾기 위함입니다.
- 현재 구현된 기능으로 플레이어 캐릭터나 적 캐릭터를 만들어주세요.
  - 추가 구현 필요한 부분을 서로 가늠하기 위함입니다.

## 이민석
- 구현 완료된 배치물을 레벨에 배치해보고 정상 작동하는지 테스트해주세요.
  - 구현 완료된 배치물에 대한 목록은 따로 전달드리겠습니다.
  - 추가 구현 필요한 기능이 있거나, 의도와 다르게 구현된 부분 있으면 수정 요청해주세요.
