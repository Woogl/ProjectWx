1. 어트리뷰트 요약

캐릭터가 가진 모든 스탯의 목록. 최댓값(Max) 항목은 같은 행에서 함께 다룬다.

스탯 범위 설명
HP / MaxHP 0 ~ MaxHP 체력. 0이 되면 사망 처리된다. MaxHP는 1 이상으로 보장된다.
PP / MaxPP 0 ~ MaxPP 강인도. 비가드 상태 피격 시 데미지만큼 차감되고, 0이 되면 피격 경직이 발동한다.
SP / MaxSP 0 ~ MaxSP 스태미나. 가드 피격 시 데미지만큼 차감되고, 0이 되면 가드가 해제된다.
DP / MaxDP 0 ~ MaxDP 그로기 수치. MaxDP에 도달하면 그로기 상태에 진입하고, 0으로 떨어지면 회복된다.
MP / MaxMP 0 ~ MaxMP 마나. 어빌리티 사용 비용으로 소모된다.
UP / MaxUP 0 ~ MaxUP 궁극기 게이지. 궁극기 사용 비용으로 소모된다.
ATK ≥ 0 공격력. 데미지 계산의 기반 수치.
DEF ≥ 0 방어력. 받는 데미지를 비율로 경감한다.
CritRate 포인트 (1pt = 1%) 치명타 확률.
CritDMG 포인트 (1pt = 1%) 치명타 발동 시 추가 피해.
SPD 기본값 1.0 이동 속도 배율. 기본 이동 속도에 곱해진다.

2. 스탯 상세

각 스탯이 게임 플레이에서 어떤 체감을 주는지 먼저 설명하고, 그 아래에 수치·공식을 정리한다.

HP체력

캐릭터의 생명 게이지. 데미지를 입을 때마다 줄어들고, 0이 되는 순간 사망한다. 0으로 떨어지지 않는 한 그 어떤 상태(가드 해제, 그로기 등)도 캐릭터를 곧바로 죽이지는 않는다.

범위 · 0 ~ MaxHP 사이로 강제 보정
최댓값 · MaxHP는 항상 1 이상
최댓값 변동 시 · MaxHP가 늘거나 줄면 현재 HP는 비율을 유지한 채 함께 변한다. 예를 들어 50% 체력 상태에서 MaxHP가 두 배가 되면 현재 HP도 두 배가 된다.
PP강인도 (Poise)

맞아도 비틀거리지 않고 버틸 수 있는 한계치. 비가드 상태에서 피격을 받으면 그만큼 줄어들고, 0이 되는 순간 피격 경직이 발동한다. PP가 높을수록 잡몹의 공격을 무시하고 콤보를 이어갈 수 있다.

범위 · 0 ~ MaxPP 사이로 강제 보정
차감 규칙 · 비가드 상태 피격 시 PP는 받은 최종 데미지만큼 차감된다.
최댓값 변동 시 · MaxPP가 변하면 현재 PP는 비율을 유지한 채 함께 변한다.
SP스태미나 (Stamina)

가드를 유지할 때 쓰는 자원. 가드 중 피격을 받을 때마다 줄어들고, 0이 되면 가드가 풀리며 가드 해제 모션이 재생된다. SP를 잘 관리하지 못하면 막다가 그대로 무너진다.

범위 · 0 ~ MaxSP 사이로 강제 보정
차감 규칙 · 가드 상태에서 가드 가능한 공격을 막으면 SP는 받은 최종 데미지만큼 차감된다.
최댓값 변동 시 · MaxSP가 변하면 현재 SP는 비율을 유지한 채 함께 변한다.
DP그로기 수치 (Daze)

맞을수록 누적되는 그로기 게이지. MaxDP에 도달하면 캐릭터가 그로기 상태에 빠진다. 그로기 상태에서는 더 이상 DP가 쌓이지 않으며, DP가 0으로 떨어지면 그로기에서 회복된다.

범위 · 0 ~ MaxDP 사이로 강제 보정
그로기 진입 · DP ≥ MaxDP가 되는 순간 그로기 상태로 전환된다.
그로기 해제 · 그로기 중 DP가 0이 되면 자동 해제된다.
MP마나 (Mana)

어빌리티 사용 비용으로 소모되는 자원. 적중 시 일부 공격은 MP를 회복시켜 주기 때문에 공격적인 플레이어일수록 MP가 빨리 차오른다.

범위 · 0 ~ MaxMP 사이로 강제 보정
최댓값 변동 시 · MaxMP가 변하면 현재 MP는 비율을 유지한 채 함께 변한다.
비용 수치 · 어빌리티별 MP 소모량은 어빌리티 BP의 비용 슬롯에 데이터로 정의된다.
UP궁극기 게이지 (Ultimate)

궁극기 사용 비용으로 소모되는 자원. MP와 별도 게이지로 관리되며, 궁극기를 발동할 때만 사용된다.

범위 · 0 ~ MaxUP 사이로 강제 보정
비용 수치 · 궁극기별 UP 소모량은 어빌리티 BP의 비용 슬롯에 데이터로 정의된다.
ATK공격력

캐릭터가 입히는 데미지의 기반 수치. 공격마다 정해진 계수가 곱해지고, 그 결과가 방어력으로 한 번 깎여서 최종 데미지가 만들어진다.

기본 데미지 공식
기본 데미지 = ATK × (100 / (100 + DEF))

여기에 공격마다 정해진 계수, 치명타 배수, 가드 감소가 추가로 곱해져 최종 데미지가 결정된다.

DEF방어력

받는 데미지를 비율로 깎아주는 스탯. 절대값을 빼는 방식이 아니라 경감률로 동작하기 때문에, DEF가 높아질수록 한 포인트당 효과는 점점 줄어들지만 절대 100%가 되지는 않는다.

경감률 공식
받는 데미지 배율 = 100 / (100 + DEF)

예: DEF가 100이면 받는 데미지가 절반(50%)이 된다. DEF는 누적할수록 효율이 천천히 떨어지는 특성이 있다.

CritRate치명타 확률

공격이 치명타로 들어갈 확률. 같은 공격이라도 치명타가 터지면 데미지가 크게 뛰기 때문에, 평균 데미지를 끌어올리는 핵심 스탯이다.

환산 · 1포인트 = 1% 확률 (예: CritRate = 25이면 25% 확률로 치명타 발동)
CritDMG치명타 추가 피해

치명타가 터졌을 때 데미지를 얼마나 더 부풀릴지 결정하는 스탯. CritRate가 치명타가 터지는 빈도를 결정한다면, CritDMG는 치명타 한 방의 크기를 결정한다.

환산 · 1포인트 = 1% 추가 피해
치명타 시 배수
치명타 배수 = 1 + CritDMG × 0.01

예: CritDMG = 50이면 치명타 시 데미지가 1.5배가 된다. CritDMG = 100이면 2배.

SPD이동 속도 배율

캐릭터의 이동 속도를 결정하는 스탯. 더해지는 값이 아니라 기본 이동 속도에 곱해지는 배율이라는 점이 중요하다. 기본값은 1.0이며, 1보다 크면 빨라지고 1보다 작으면 느려진다.

적용 방식
실제 이동 속도 = 기본 이동 속도 × SPD

예: 기본 이동 속도가 600일 때 SPD = 1.5이면 실제 이동 속도는 900이 된다. SPD = 0.5이면 300으로 떨어진다. 가산이 아닌 곱셈이라는 점을 잊지 말 것.
