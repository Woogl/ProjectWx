2. 스탯 상세

HP — 체력

캐릭터의 생존을 결정하는 가장 기본적인 스탯이다. 피격 시 최종 대미지만큼 감소하며, 0이 되면 사망한다.

규칙

  • 범위: 0 ~ MaxHP
  • MaxHP 최소값: 1 (0 이하로 설정할 수 없다)
  • HP가 0에 도달하면 사망 상태가 부여된다
  • MaxHP 변경 시 HP가 비율을 유지하며 조정된다

PP — 강인도

피격 시 경직에 대한 저항력이다. 높을수록 공격을 맞아도 모션이 끊기지 않으며, 0이 되면 피격 경직이 발동된다.

규칙

  • 범위: 0 ~ MaxPP
  • 피격 시 최종 대미지만큼 PP가 감소한다
  • PP가 0 이하가 되면 피격 경직 모션이 발동되고, PP가 MaxPP로 즉시 회복된다 (그로기 상태가 아닌 경우)
  • 가드 중 피격 시에도 PP가 MaxPP로 회복된다 (그로기 상태가 아닌 경우)
  • 그로기 진입 시 PP가 0으로 설정되고, 그로기 해제 시 MaxPP로 회복된다

DP — 그로기 수치

피격할 때마다 누적되는 수치이다. 최대에 도달하면 일정 시간 무방비 상태(그로기)에 빠진다. 그로기 동안에는 DP가 점차 감소하며, 이미 그로기 상태인 대상에게는 DP가 추가로 누적되지 않는다.

규칙

  • 범위: 0 ~ MaxDP
  • MaxDP 최소값: 1
  • 피격 시 최종 대미지만큼 DP가 증가한다
  • DP가 MaxDP에 도달하면 그로기 상태가 발동된다
  • 그로기 상태에서는 추가 DP 누적이 무시된다
  • 퍼펙트 가드 시 공격자에게 DP가 반사된다

MP — 마나

스킬을 사용하기 위한 자원이다. 일반 공격으로 적을 때려서 채우고, 스킬로 소비하는 순환 구조를 가진다. 퍼펙트 가드나 극한 회피 성공 시에도 회복된다.

규칙

  • 범위: 0 ~ MaxMP
  • 획득 경로:
    • 일반 공격 적중 시: +5
    • 퍼펙트 가드 성공 시: +5
    • 극한 회피 성공 시: +5
  • 소비: 스킬 사용 시 (캐릭터별 설정 비용)

UP — 궁극기 수치

궁극기를 사용하기 위한 자원이다. 스킬로 적을 때려서 채우며, 궁극기 사용 시 전량 소모된다.

규칙

  • 범위: 0 ~ MaxUP
  • 획득 경로: 스킬 적중 시 +5
  • 소비: 궁극기 사용 시 -100

SP — 스태미나

가드의 지속 가능성을 결정하는 자원이다. 가드 중 피격 시 소모되며, 전투 외에서는 자동으로 회복된다.

규칙

  • 범위: 0 ~ MaxSP
  • 소비: 가드 중 피격 시, 감소된 대미지(가드 후 대미지)만큼 소모
  • 자연 회복: 1/30초 간격으로 자동 회복. 0에서 MaxSP까지 4초 소요
틱당 회복량 = MaxSP ÷ (4.0 ÷ (1/30)) = MaxSP ÷ 120

ATK — 공격력

모든 대미지 계산의 출발점이다. 높을수록 적에게 입히는 대미지가 증가한다.

대미지 기본 공식

기본 대미지 = ATK × (100 ÷ (100 + 대상 DEF))

버프에 의해 일시적으로 증가할 수 있다. 예: ATK 버프는 5초 동안 ATK를 50% 증가시킨다.

DEF — 방어력

받는 대미지를 줄여주는 스탯이다. DEF가 높을수록 대미지 경감률이 올라가지만, 수확체감 곡선을 따르기 때문에 무한히 쌓는다고 완전 면역이 되지는 않는다.

방어 배율 공식

방어 배율 = 100 ÷ (100 + DEF)

실제 대미지 = ATK × 방어 배율. DEF가 0이면 배율 1.0(경감 없음), DEF 100이면 배율 0.5(50% 경감).

CritRate & CritDMG — 치명타

공격이 치명타로 판정되면 추가 대미지가 적용된다. 치명타 확률과 치명타 대미지 배율 두 가지 스탯으로 구성된다.

치명타 확률

치명타 발생 확률 = CritRate × 1%   (0% ~ 100% 범위로 제한)

CritRate 1당 1%. CritRate가 50이면 50% 확률로 치명타가 발생한다.

치명타 대미지 배율

치명타 대미지 = 기본 대미지 × (1 + CritDMG × 0.01)

CritDMG 1당 1% 추가 대미지. CritDMG가 150이면 치명타 시 기본 대미지의 250%가 적용된다.

SPD — 이동 속도

캐릭터의 이동 속도를 결정하는 배율 스탯이다. 기본값은 1.0이며, 이 값에 기본 걸음 속도(600 cm/s)를 곱하여 실제 이동 속도가 결정된다.

이동 속도 공식

실제 이동 속도 = 기본 걸음 속도(600) × SPD

스프린트

스프린트 중에는 SPD에 +0.5가 가산된다. 기본 상태(SPD 1.0)에서 스프린트를 사용하면 SPD가 1.5가 되어 이동 속도가 900 cm/s가 된다.

3. 대미지 파이프라인

대미지 처리 흐름

공격이 적중하면 다음 순서로 대미지가 처리된다. 각 단계에서 조건이 충족되면 분기하여 처리가 달라진다.

공격 적중
↓
1단계: 무적 판정
대상이 무적 상태인가?
예 → 대미지 무효, 회피 어빌리티면 방어자 MP +5, 극한 회피 발동
↓ 아니오
2단계: 퍼펙트 가드 판정
대상이 퍼펙트 가드 중인가?
예 → 대미지 무효, 공격자에게 DP 반사, 방어자 MP +5
↓ 아니오
3단계: 대미지 계산
기본 대미지 = ATK × 방어 배율
치명타 판정 → 가드 감소 적용
↓
4단계: 스탯 적용
HP -= 최종 대미지  |  PP -= 최종 대미지  |  DP += 최종 대미지 (그로기 아닌 경우)
가드 중이면 SP -= 최종 대미지
↓
5단계: 상태 판정
PP ≤ 0 → 피격 경직 발동  |  DP ≥ MaxDP → 그로기  |  HP ≤ 0 → 사망
↓
6단계: 공격자 자원 회복
일반 공격 적중 → 공격자 MP +5  |  스킬 적중 → 공격자 UP +5

대미지 계산 상세 (3단계)

기본 대미지

기본 대미지 = ATK × (100 ÷ (100 + 대상 DEF))

치명타

확률 판정(CritRate × 1%)에 성공하면 치명타 배율이 적용된다.

치명타 시 대미지 = 기본 대미지 × (1 + CritDMG × 0.01)

가드 감소

대상이 가드 중이고, 공격이 막을 수 없는 공격이 아닌 경우 대미지가 50% 감소한다.

가드 시 대미지 = 치명타 적용 대미지 × 0.5

막을 수 없는 공격은 가드 감소를 무시하고 풀 대미지가 적용된다.

퍼펙트 가드 DP 반사

퍼펙트 가드 성공 시, 공격자에게 DP가 반사된다. 반사량은 방어 측의 방어배율이 적용된 대미지 값이다.

반사 DP = 공격자 ATK × (100 ÷ (100 + 방어자 DEF))

이 값은 치명타/가드 감소가 적용되기 전의 순수 방어 배율 적용 값이다.

4. 특수 상태

사망

체력이 바닥나면 캐릭터가 행동 불능 상태에 빠진다. 모든 전투 행위가 즉시 중단되며, 사망 연출 후 래그돌로 전환된다.

발동 조건

피격 대미지에 의해 HP가 0에 도달하면 발동된다. HP가 이미 0인 상태에서 추가 대미지가 들어와도 중복 발동되지 않는다.

진입 시 일어나는 일

  1. 사망 상태 태그가 부여된다.
  2. 진행 중인 모든 어빌리티가 취소된다.
  3. 새로운 어빌리티 활성화가 차단된다.
  4. 사망 모션이 재생된다 (없으면 즉시 다음 단계).
  5. 래그돌이 활성화된다: 물리 시뮬레이션 시작, 충돌 캡슐 비활성화, 이동 차단.
  6. 사망은 서버에서만 판정되어 모든 클라이언트에 동기화된다.

해제 조건

현재 자동 부활 시스템은 구현되어 있지 않다. 사망 상태 태그를 제거하면 해제된다.

그로기

대미지를 받을 때마다 누적되는 DP가 한계에 도달하면, 캐릭터가 잠시 무방비 상태에 빠진다. 이 동안에는 가드나 회피를 할 수 없어 일방적으로 공격받게 된다.

발동 조건

DP가 MaxDP에 도달하면 발동된다.

진입 시 일어나는 일

  1. 그로기 상태 태그가 부여된다.
  2. 진행 중인 모든 어빌리티가 취소된다.
  3. 새로운 어빌리티 활성화가 차단된다 (단, 피격 경직은 발동 가능).
  4. PP가 0으로 설정된다.
  5. 그로기 모션이 재생된다.
  6. DP가 일정 속도로 감소하기 시작한다.

DP 감소 메커니즘

DP 감소 속도 = MaxDP ÷ 그로기 지속 시간(5초) × 틱 간격(1/30초)

1/30초 간격으로 DP를 균등하게 감소시킨다. 그로기 지속 시간 기본값은 5초이다. 예를 들어 MaxDP가 100이면 매 틱마다 약 0.67씩 감소하여 5초 후 0에 도달한다.

그로기 중 피격

  • 추가 DP 누적이 무시된다.
  • PP가 0으로 고정되어 있으므로 피격 시 매번 피격 경직이 발동된다.
  • 피격 경직 모션이 재생되는 동안 그로기 모션이 중단되지만, 경직이 끝나면 그로기 모션으로 자동 복귀한다.

해제 조건

DP가 0에 도달하면 그로기 상태 태그가 제거되고, PP가 MaxPP로 회복된다.
