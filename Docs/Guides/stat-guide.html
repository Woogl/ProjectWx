MaxHP, MaxPP, MaxSP, MaxDP, MaxMP, MaxUP가 변경되면 대응하는 현재값(HP, PP, SP, MP)은 비율을 유지한 채 자동 조정된다. 예를 들어 MaxHP가 100에서 200으로 늘어나면, HP 80은 160으로 변경된다.

2. 스탯 상세

HP (체력)

캐릭터의 생존을 결정하는 가장 기본적인 스탯이다. 공격을 받으면 최종 데미지만큼 HP가 감소하며, HP가 0에 도달하면 사망한다.

  • 범위: 0 ~ MaxHP
  • MaxHP의 최솟값은 1이다 (0 이하로 설정할 수 없다)
  • MaxHP가 변경되면 HP는 기존 비율을 유지한다
  • 가드 상태에서 피격 시 대미지가 50% 감소한다
  • 무적 상태에서는 HP가 감소하지 않는다

PP (강인도)

피격 시 경직 없이 버틸 수 있는 내성이다. 비가드 상태에서 공격을 맞으면 PP가 대미지만큼 감소하며, PP가 0 이하로 떨어지면 피격 경직(HitReact)이 발동한다.

  • 범위: 0 ~ MaxPP
  • 피격 경직 발동 시 PP는 MaxPP만큼 즉시 회복된다
  • 넉백, 넉다운, 넉업 등 강제 경직 공격은 PP 잔량과 무관하게 발동한다
  • 그로기 상태 진입 시 PP가 0으로 설정되고, 그로기 종료 시 MaxPP로 회복된다

SP (스태미나)

가드의 내구력이다. 가드 상태에서 공격을 받으면 최종 데미지만큼 SP가 감소하며, SP가 0 이하로 떨어지면 가드 브레이크가 발동하여 가드가 강제 해제된다.

  • 범위: 0 ~ MaxSP
  • 가드 중이 아닐 때 자연 회복된다
  • 자연 회복 틱 간격: 1/30초
  • 틱당 회복량: MaxSP / 120
  • 0에서 최대까지 완전 회복에 걸리는 시간: 4초
  • 가드 중에는 자연 회복이 억제된다

DP (그로기 수치)

적에게 피해를 줄 때마다 누적되는 그로기 게이지이다. 대미지를 받을 때마다 최종 데미지량만큼 DP가 증가하며, DP가 MaxDP에 도달하면 그로기 상태에 빠져 일정 시간 행동 불능이 된다.

  • 범위: 0 ~ MaxDP
  • 이미 그로기 상태인 대상에게는 DP가 추가 누적되지 않는다
  • 그로기 상태 진입 시 DP는 즉시 감소하기 시작한다 (자세한 내용은 그로기 섹션 참고)
  • 퍼펙트 가드 성공 시 공격자에게 DP를 반사한다 (반사량 = 방어 배율이 적용된 대미지)

MP (마나)

스킬을 사용하기 위한 자원이다. 스킬마다 정해진 MP를 소모하며, MP가 부족하면 스킬을 사용할 수 없다. 일반 공격이 적중하면 MP가 회복된다.

  • 범위: 0 ~ MaxMP
  • MaxMP의 최솟값은 0이다
  • 소모량: 스킬마다 개별 설정
  • 회복: 일반 공격 적중 시 회복 (회복량은 공격 설정에 따라 결정)

UP (궁극기 수치)

궁극기를 사용하기 위한 자원이다. 스킬 공격이 적중하면 UP가 회복되며, UP가 충분히 쌓이면 궁극기를 발동할 수 있다.

  • 범위: 0 ~ MaxUP
  • 소모량: 궁극기마다 개별 설정
  • 회복: 스킬 공격 적중 시 회복 (회복량은 스킬 설정에 따라 결정)

ATK (공격력)

데미지 계산의 기반이 되는 공격 수치이다. ATK가 높을수록 적에게 더 많은 피해를 입힌다.

  • 데미지 공식에서 공격 계수가 곱해진다 (무기/스킬마다 다른 계수를 가진다)
  • ATK 버프: 5초 동안 ATK를 50% 증가시키는 버프가 존재한다
  • 화상 데미지 계산에도 ATK가 사용된다

DEF (방어력)

받는 피해를 경감하는 방어 수치이다. DEF가 높을수록 받는 데미지가 줄어든다. 경감률은 DEF가 높을수록 효율이 점차 감소하는 체감형 구조이다.

방어 배율 = 100 / (100 + DEF)
최종 데미지 = ATK x 공격 계수 x 방어 배율

DEF 0이면 데미지를 100% 그대로 받고, DEF가 올라갈수록 경감률이 증가하지만 효율은 점차 감소한다.

SPD (이동 속도)

캐릭터의 이동 속도를 결정하는 배율이다. 기본값은 1.0이며, 캐릭터의 기본 걷기 속도에 이 배율을 곱한 값이 실제 이동 속도가 된다.

실제 이동 속도 = 기본 걷기 속도 x SPD
  • 기본값: 1.0
  • 대시 중: SPD에 +0.5가 가산되어 1.5배로 이동한다
  • 대시 효과는 대시 입력을 놓으면 즉시 해제된다

CritRate / CritDMG (치명타)

공격 시 일정 확률로 추가 피해를 입히는 치명타 시스템이다. 치명타가 발동하면 강조된 데미지 표시와 함께 증폭된 피해를 입힌다.

  • CritRate: 치명타 확률. 1당 1%이며, 최대 100%까지 유효하다
  • CritDMG: 치명타 추가 피해 배율. 1당 1% 추가 데미지
치명타 데미지 = 기본 데미지 x (1 + CritDMG x 0.01)

예시: CritDMG가 150이면 치명타 시 기본 데미지의 2.5배(100% + 150%)를 입힌다.

3. 데미지 파이프라인

공격이 적중하면 다음 단계를 순서대로 거쳐 최종 데미지가 결정된다.

1단계: 무적 판정
대상이 무적 상태(회피 무적 등)이면 대미지를 무효화하고 회피 성공 이벤트를 발생시킨다
▼
2단계: 퍼펙트 가드 판정
대상이 퍼펙트 가드 구간이면 대미지를 받지 않고, 공격자에게 DP를 반사한다
▼
3단계: 기본 데미지 계산
ATK x 공격 계수 x 방어 배율
▼
4단계: 치명타 판정
CritRate% 확률로 치명타 발동 시 데미지에 (1 + CritDMG x 0.01) 배율 적용
▼
5단계: 가드 감소
대상이 가드 중이고 막을 수 없는 공격이 아니면 데미지 50% 감소
▼
최종 데미지 확정
▼
6단계: 결과 적용
가드 피격 (일반 공격)
HP 차감, DP 누적, SP 차감
가드 피격 (막을 수 없는 공격)
가드 강제 해제 후
HP 차감, DP 누적, PP 차감
비가드 피격
HP 차감, DP 누적, PP 차감

데미지 공식

기본 데미지 = ATK x 공격 계수 x (100 / (100 + DEF))
치명타 데미지 = 기본 데미지 x (1 + CritDMG x 0.01)
가드 데미지 = 데미지 x 0.5 (막을 수 없는 공격이 아닌 경우)

계산 예시

상황: ATK 150, 공격 계수 1.2, 대상 DEF 100, CritRate 30, CritDMG 120

  • 방어 배율: 100 / (100 + 100) = 0.5
  • 기본 데미지: 150 x 1.2 x 0.5 = 90
  • 치명타 미발동: 최종 데미지 = 90
  • 치명타 발동 (30% 확률): 90 x (1 + 120 x 0.01) = 90 x 2.2 = 198
  • 가드 중일 때: 각각 45 / 99

피격 반응 조건

상황 HP DP PP / SP 피격 반응
비가드 + 일반 경직 공격 차감 누적 PP 차감 PP가 0 이하가 되면 경직 발동
비가드 + 강제 경직 공격 (넉백/넉다운/넉업) 차감 누적 PP 차감 PP와 무관하게 항상 발동
가드 + 일반 공격 차감 (50%) 누적 SP 차감 가드 피격 반응 (SP 0이면 가드 브레이크)
가드 + 강제 경직 공격 차감 (50%) 누적 SP 차감 가드 넉백 반응
가드 + 막을 수 없는 공격 차감 누적 PP 차감 가드 강제 해제 후 피격 경직 발동
퍼펙트 가드 - 공격자에게 반사 - 공격 무효화, 퍼펙트 가드 이벤트
무적 상태 - - - 대미지 완전 무효, 회피 성공 이벤트

화상 데미지

화상은 5초 동안 0.5초 간격으로 총 10틱의 지속 데미지를 입히는 상태이상이다.

틱 데미지 = (공격자 ATK x (100 / (100 + 대상 DEF))) / 10
  • 기본 데미지 공식과 동일한 ATK/DEF 계산을 사용하되, 치명타와 가드 감소는 적용하지 않는다
  • 총 대미지를 10틱으로 균등 분할하여 적용한다
  • 사망 상태이거나 무적 상태인 대상에게는 화상 데미지가 적용되지 않는다

퍼펙트 가드 DP 반사

퍼펙트 가드에 성공하면 대상은 피해를 받지 않고, 대신 공격자에게 DP가 반사된다.

반사 DP = ATK x 공격 계수 x (100 / (100 + DEF))

반사량은 방어 배율까지 적용한 기본 데미지와 동일하다. 치명타와 가드 감소는 적용되지 않는다.

4. 특수 상태

사망

HP가 0에 도달하면 캐릭터는 사망 상태에 진입한다. 사망한 캐릭터는 더 이상 행동할 수 없다.

항목내용
발동 조건 데미지를 받아 HP가 0 이하로 떨어졌을 때
진입 시 동작
  • 사망 상태 태그가 부여된다
  • 사망 이벤트가 브로드캐스트된다
  • 네임플레이트가 숨겨진다
제한 사항
  • 사망 상태에서는 모든 어빌리티의 활성화가 차단된다 (피격 경직, 그로기 포함)
  • 화상 데미지가 적용되지 않는다

그로기

DP가 MaxDP에 도달하면 캐릭터는 그로기 상태에 빠져 일정 시간 동안 행동 불능이 된다. 보스나 강력한 적에게 데미지를 꾸준히 누적해 그로기를 유발하면 안전하게 공격할 기회를 얻을 수 있다.

항목내용
발동 조건 DP가 MaxDP에 도달했을 때 (이미 그로기 상태가 아닌 경우에만)
진입 시 동작
  • 그로기 상태 태그가 부여된다
  • PP가 0으로 설정된다
  • 그로기 전용 모션이 재생된다 (다른 모션이 재생 중이면 그 모션이 끝난 뒤 재생)
  • DP가 서서히 감소하기 시작한다
  • 그로기 상태에서는 추가 DP가 누적되지 않는다
DP 감소
  • 그로기 지속 시간: 기본 5초 (설정 가능)
  • DP는 1/30초 간격으로 감소한다
  • 틱당 감소량: MaxDP / (지속 시간 x 30)
  • 즉, 지속 시간이 끝나면 DP가 정확히 0에 도달한다
해제 조건
  • DP가 0에 도달하면 그로기 상태 태그가 제거된다
  • 태그 제거가 감지되면 그로기 어빌리티가 종료된다
종료 시 동작
  • PP가 MaxPP로 회복된다
  • DP 감소 타이머가 정리된다
  • 다시 정상적으로 행동할 수 있다
그로기 중 피격
  • HP는 정상적으로 차감된다
  • DP는 추가 누적되지 않는다
  • PP는 0인 상태이므로 피격 경직이 바로 발동할 수 있다
  • 피격 경직으로 그로기 모션이 중단되면, 경직 모션 종료 후 그로기 모션이 다시 재생된다
