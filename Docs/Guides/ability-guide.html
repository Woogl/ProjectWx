전투 어빌리티 상세

일반 공격

전투

버튼을 누를 때마다 애니메이션을 하나씩 이어서 실행하는 콤보 공격이다. 최대 콤보 수는 에셋에서 설정한 콤보 애니메이션 배열 수에 따라 결정되며, 마지막 단계까지 이어지거나 콤보 타이밍을 놓치면 어빌리티가 종료된다.

1
공격 버튼을 누르면 첫 번째 콤보 애니메이션이 재생된다.
2
콤보 입력 구간이 열리는 타이밍에 공격 버튼을 다시 누르면 다음 콤보 애니메이션으로 전환된다.
3
콤보 입력 구간에 입력하지 않거나 마지막 콤보 애니메이션이 끝나면 공격 어빌리티가 종료된다.
입력누르기
MP 비용없음
콤보 연결 조건콤보 입력 구간 내 재입력
사용 불가 상황사망 상태
콤보 입력 구간: 각 콤보 애니메이션 내에 설정된 특정 타이밍 구간이다. 이 구간 안에서만 다음 콤보 입력이 수락된다. 구간을 벗어나면 입력이 무시된다.

스킬

전투

단일 스킬 애니메이션을 한 번 재생하는 어빌리티다. MP 비용과 쿨다운이 있으며, 에셋별로 다르게 설정된다. 애니메이션이 정상 완료되거나 외부 요인으로 중단되면 종료된다.

1
스킬 버튼을 누르면 MP 비용과 쿨다운 조건을 확인한다.
2
조건이 충족되면 스킬 애니메이션이 재생된다.
3
애니메이션이 끝나거나 중단되면 스킬이 종료된다.
입력누르기
MP 비용에셋별 설정
쿨다운에셋별 설정
사용 불가 상황사망 상태

궁극기

전투

MP를 100 소모하여 발동하는 강력한 어빌리티다. 발동 즉시 컷씬이 재생되고, 컷씬이 끝나면 강력한 공격 애니메이션을 수행한다. 컷씬 재생 중에는 게임 월드가 거의 정지되며, 캐릭터는 무적 상태가 유지된다.

1
궁극기 버튼을 누르면 MP 100과 쿨다운 조건을 확인한다.
2
조건 충족 시 컷씬 연출이 시작된다. 이 동안 게임 시간이 거의 멈추고 (0.001배) 캐릭터는 무적이다.
3
컷씬이 끝나면 궁극기 공격 애니메이션이 재생된다.
4
공격 애니메이션이 완료되면 어빌리티가 종료된다.
입력누르기
MP 비용100
쿨다운있음 (에셋 설정)
시간 왜곡배속 0.001× (컷씬 구간)
무적컷씬 전체 구간
사용 불가사망, 그로기 상태
컷씬 없이 구성할 경우: 컷씬 에셋이 없으면 컷씬 단계를 건너뛰고 바로 공격 애니메이션으로 진행한다.

방어 어빌리티 상세

가드

방어

버튼을 누르고 있는 동안 방어 자세를 유지하는 어빌리티다. 가드 중에 공격을 받으면 피해가 크게 줄어들며, 타이밍에 맞춰 가드하면 퍼펙트 가드로 피해를 완전히 막고 공격자에게 DP를 되돌려줄 수 있다.

1
가드 버튼을 누르면 방어 애니메이션이 재생되고 방어 판정 구간이 활성화된다.
2
방어 판정 구간에서 공격을 받으면 피해가 50% 감소한다.
3
퍼펙트 가드 판정 구간에서 공격을 받으면 피해가 완전히 무효화되고, 공격자에게 DP를 반사한다.
4
버튼을 놓으면 가드가 즉시 해제된다.
입력홀드 (놓으면 해제)
MP 비용없음
쿨다운있음 (에셋 설정)
가드 시 피해 감소50%
퍼펙트 가드 효과피해 완전 무효
퍼펙트 가드 DP 반사ATK × (100 ÷ (100 + DEF))
사용 불가 상황사망 상태
발동 시 취소 대상진행 중인 모든 어빌리티
방어 판정 구간 vs 퍼펙트 가드 판정 구간: 두 구간은 가드 애니메이션 내 특정 타이밍에 설정된다. 방어 판정 구간은 가드 유지 전체에 걸쳐 넓게 열리고, 퍼펙트 가드 판정 구간은 그 안에 더 좁은 타이밍으로 배치된다. 퍼펙트 가드 반사 DP 공식: ATK × (100 ÷ (100 + DEF)) — 공격자의 ATK가 높을수록 반사량이 크다.

회피

방어

이동 방향으로 구르며 피해를 피하는 어빌리티다. 구르는 애니메이션의 특정 구간 동안 무적이 적용되어 그 시간 안에 공격을 받아도 피해가 전혀 없다.

1
회피 버튼을 누르면 이동 입력 방향으로 캐릭터가 회전한다.
2
회피 애니메이션이 재생되며, 무적 구간 동안은 모든 피격 판정이 무시된다.
3
애니메이션이 끝나거나 중단되면 회피가 종료된다.
입력누르기
MP 비용없음
쿨다운있음 (에셋 설정)
무적 구간애니메이션 내 설정 구간
회전 방향이동 입력 방향
사용 불가 상황사망 상태
무적 구간: 회피 애니메이션 내부에 설정된 특정 프레임 범위다. 이 구간에서는 피격 이벤트 자체가 차단되어 피격 반응 애니메이션도 발동하지 않는다.

이동 어빌리티 상세

질주

이동

버튼을 누르는 동안 이동 속도를 높이는 어빌리티다. 버튼을 놓으면 속도 보너스가 즉시 제거된다.

입력홀드 (놓으면 해제)
속도 보너스+0.5
MP 비용없음
쿨다운없음
사용 불가 상황사망 상태

점프

이동

캐릭터를 위로 도약시키는 어빌리티다. 지면에 있을 때만 사용할 수 있으며, 이미 공중에 있으면 발동되지 않는다. 버튼을 놓으면 점프가 조기 종료된다.

입력누르기 (놓으면 하강)
MP 비용없음
쿨다운있음 (에셋 설정)
사용 불가 상황사망 상태, 공중
점프 가능 조건: 엔진의 캐릭터 이동 컴포넌트가 "점프 가능" 상태일 때만 발동된다. 공중에서는 점프할 수 없다.

락온

이동

적을 고정하고 카메라가 해당 적을 계속 추적하게 만드는 토글 어빌리티다. 락온 중에는 카메라가 타겟을 향하지만 캐릭터 몸통 방향은 이동 입력에 따라 자유롭게 움직인다. 타겟이 사망하거나 너무 멀어지면 자동으로 해제된다.

1
락온 버튼을 누르면 주변 적을 탐색하여 가장 가까운 적을 타겟으로 설정한다.
2
타겟이 발견되면 카메라가 보간 속도 8로 타겟을 향하며, 조준점 UI가 표시된다. 카메라는 아래로 15° 기울어진 각도를 유지한다.
3
락온 버튼을 다시 누르거나 타겟이 소멸/이탈하면 락온이 해제된다.
입력토글 (재입력으로 해제)
최대 탐색 거리2000
카메라 보간 속도8
카메라 피치 오프셋−15°
자동 해제 조건타겟 소멸 또는 최대 거리 초과
사용 불가 상황사망 상태
다른 어빌리티와의 공존: 락온은 공격, 가드, 회피 등 다른 어빌리티와 함께 유지된다. 전투 어빌리티가 발동되어도 락온이 해제되지 않는다.

반응형 어빌리티 상세 자동 발동

아래 어빌리티들은 플레이어가 직접 입력해서 사용하는 것이 아니라, 특정 게임 상황이 되면 시스템이 자동으로 발동시킨다.

피격 반응

반응

공격을 받았을 때 자동으로 발동되어 피격 애니메이션을 재생하는 어빌리티다. 가드 중에 피격되었는지 아닌지에 따라 서로 다른 애니메이션이 재생된다.

1
피격 이벤트가 발생하면 자동으로 피격 반응이 발동된다.
2
방어 판정 구간이 활성화된 상태로 피격되면 → 가드 피격 애니메이션 재생.
3
방어 판정 구간이 없는 일반 피격이면 → 일반 피격 애니메이션 재생.
발동 조건피격 이벤트 수신
차단 조건사망 상태, 무적 구간 활성
재발동가능 (피격 중 추가 피격 처리)
퍼펙트 가드 시에도 발동: 퍼펙트 가드로 피해를 완전히 막아도 가드 피격 반응 애니메이션은 재생된다.

그로기

반응

DP(기절 게이지)가 최대치에 도달하면 발동되는 기절 상태 어빌리티다. 그로기 상태 동안에는 거의 모든 행동이 불가능하며, DP가 서서히 소진되어 0이 되면 자동으로 해제된다.

1
DP가 최대치에 도달하면 그로기 상태가 자동으로 부여된다.
2
그로기 애니메이션이 재생되고 진행 중인 모든 어빌리티가 취소된다.
3
매 틱마다 DP가 소진된다. 소진 속도: MaxDP ÷ 5초.
4
DP가 0이 되면 그로기 상태가 해제되고 어빌리티가 종료된다.
발동 조건DP = MaxDP
지속 시간5초 (DP 완전 소진까지)
DP 소진 속도MaxDP ÷ 5초
행동 제한모든 어빌리티 차단
차단 조건사망 상태
그로기 중 DP 누적불가 (DP 증가 없음)
그로기 중 피격 반응: 그로기 상태에서 공격을 받으면 피격 반응 애니메이션이 재생될 수 있다. 피격 반응 애니메이션이 끝나면 그로기 애니메이션이 다시 재생된다.

사망

반응

HP가 0이 되면 자동으로 발동되는 어빌리티다. 사망 애니메이션을 재생한 후 캐릭터가 래그돌 상태로 전환된다. 사망 이후에는 모든 어빌리티가 차단된다.

1
HP가 0이 되면 사망 상태가 부여되고 진행 중인 모든 어빌리티가 즉시 취소된다.
2A
사망 애니메이션이 설정된 경우: 애니메이션을 재생하고 완료 후 래그돌로 전환된다.
2B
사망 애니메이션이 없는 경우: 즉시 래그돌 상태로 전환된다.
발동 조건HP = 0
발동 시 취소 대상모든 어빌리티 (HitReact 포함)
사망 이후모든 어빌리티 차단 유지
최종 상태래그돌 (물리 기반 시뮬레이션)

어빌리티 상호작용 다이어그램

공격 → 피격 반응
공격이 적중하면 피격 이벤트가 발생하고, 피격 반응 어빌리티가 자동으로 발동된다.
피격 → DP 누적
일반 피격 시 받은 피해만큼 DP가 누적된다. 그로기 상태에서는 DP가 더 이상 누적되지 않는다.
DP 최대 → 그로기
DP가 최대치에 도달하면 그로기가 발동된다. 5초에 걸쳐 DP가 소진되면 그로기가 해제된다.
가드 → 피해 감소
방어 판정 구간에서 피격 시 피해가 50% 감소한다. 피격 반응 애니메이션은 가드용으로 교체된다.
퍼펙트 가드 → DP 반사
퍼펙트 가드 판정 구간에서 피격 시 피해가 완전히 무효화되고, 공격자의 DP 게이지에 피해가 반사된다.
무적 → 피격 무시
회피 중 무적 구간에서는 피격 이벤트 자체가 차단되어 DP 누적도, 피격 반응도 발동하지 않는다.

상태 및 판정 구간 정리

게임 상태

사망 상태
HP가 0이 되면 진입하는 상태다. 이 상태에서는 모든 어빌리티(공격, 방어, 이동 등)가 차단된다. 부활 처리가 없으면 영구 유지된다.
공중 상태
점프 또는 낙하 중에 부여되는 상태다. 공중 상태에서는 점프를 다시 사용할 수 없다.
그로기 상태
DP가 최대치에 도달하면 부여되는 기절 상태다. 모든 어빌리티가 차단되며, DP가 0이 되면 자동 해제된다. 그로기 중에는 DP가 더 이상 누적되지 않는다.
락온 상태
락온 어빌리티가 활성화된 동안 유지되는 상태다. 이 상태에서는 시선 입력이 억제되고 카메라가 타겟을 자동으로 추적한다.

판정 구간

무기 충돌 구간
공격 애니메이션 중 실제로 무기 히트박스가 활성화되는 구간이다. 이 구간 안에서만 적에게 피해를 줄 수 있다.
콤보 입력 구간
콤보 애니메이션 중 다음 콤보 입력을 수락하는 타이밍 구간이다. 이 구간 안에서 공격 버튼을 누를 때만 다음 콤보로 이어진다.
무적 구간
회피 애니메이션 내 특정 프레임에 설정되는 판정 구간이다. 이 구간에서는 피격 이벤트 자체가 차단된다 — 피해도 없고 피격 반응도 없다.
방어 판정 구간
가드 애니메이션 중 방어 효과가 적용되는 구간이다. 이 구간에서 피격되면 피해가 50% 감소하고 가드 피격 반응이 재생된다.
퍼펙트 가드 판정 구간
방어 판정 구간 안에 더 짧게 설정된 타이밍 구간이다. 이 구간에서 피격되면 피해가 완전히 무효화되고 공격자의 DP에 피해가 반사된다.
