플레이어가 직접 조작하는 것이 아니라, 게임 상황에 의해 자동으로 발동되는 어빌리티이다.

어빌리티 카테고리 발동 조건 설명
피격 반응 반응형 대미지를 받을 때 피격 또는 가드 피격 애니메이션을 재생한다
그로기 반응형 DP가 최대치에 도달할 때 일정 시간 동안 행동 불가 상태에 빠진다
사망 반응형 HP가 0이 될 때 모든 행동이 중단되고 사망 연출이 재생된다

2. 전투 어빌리티 상세

일반 공격 전투

콤보 배열에 설정된 순서대로 연속 공격을 수행하는 기본 공격 수단이다. 콤보 윈도우 구간에서 공격 버튼을 다시 누르면 다음 단계로 이어진다.

입력
공격 버튼 누르기
콤보 단계 수
데이터 에셋에서 설정 (배열 크기)
사용 불가
사망 상태

사용 흐름

  1. 공격 버튼을 누르면 첫 번째 콤보 애니메이션이 재생된다
  2. 애니메이션 중 콤보 윈도우 구간이 열리면, 공격 버튼을 다시 눌러 다음 단계로 전환할 수 있다
  3. 콤보 윈도우를 놓치거나 마지막 단계가 끝나면 공격이 종료된다

콤보 진행 중 캐릭터는 타겟 방향으로 자동 회전한다. 애니메이션의 무기 충돌 구간에서만 실제 대미지가 발생한다.

스킬 전투

하나의 스킬 애니메이션을 재생하는 단일 액션 공격이다. 일반 공격보다 강력하지만 MP 비용과 쿨다운이 있을 수 있다.

입력
스킬 버튼 누르기
MP 비용
데이터 에셋에서 설정
쿨다운
데이터 에셋에서 설정
사용 불가
사망 상태

사용 흐름

  1. 스킬 버튼을 누르면 스킬 애니메이션이 재생된다
  2. 애니메이션이 완료되거나 다른 행동에 의해 중단되면 종료된다

콤보 공격과 마찬가지로 스킬 발동 시 캐릭터가 타겟 방향으로 자동 회전한다.

궁극기 전투

강력한 연출과 함께 대규모 공격을 수행하는 궁극 스킬이다. 컷씬이 재생되는 동안 게임 월드의 시간이 정지되며, 캐릭터는 무적 상태가 된다.

입력
궁극기 버튼 누르기
MP 비용
100
쿨다운
데이터 에셋에서 설정
사용 불가
사망 상태, 그로기 상태

사용 흐름

  1. 궁극기 버튼을 누르면 MP 100이 소모된다
  2. 컷씬이 재생된다. 이 동안 게임 월드는 시간 정지 상태이며, 캐릭터는 무적이다
  3. 컷씬이 끝나면 공격 애니메이션이 이어서 재생된다
  4. 공격 애니메이션이 완료되면 궁극기가 종료된다

기존에 사용 중이던 다른 어빌리티는 궁극기 발동 시 모두 취소된다. 궁극기 사용 중에는 다른 어빌리티를 사용할 수 없다. 컷씬 에셋이 설정되지 않은 경우 바로 공격 애니메이션 단계로 진행된다.

3. 방어 어빌리티 상세

가드 방어

버튼을 누르고 있는 동안 방어 자세를 유지한다. 방어 중 피격되면 대미지가 절반으로 감소하며, 타이밍을 맞추면 퍼펙트 가드로 적의 공격을 반사할 수 있다.

입력
가드 버튼 홀드
MP 비용
-
쿨다운
데이터 에셋에서 설정
사용 불가
사망 상태

가드 판정

방어 애니메이션에는 가드 판정 구간이 설정되어 있다. 이 구간 동안 피격되면 대미지가 50% 감소한다.

퍼펙트 가드

가드 판정 구간의 초반에는 퍼펙트 가드 구간이 포함되어 있다. 이 짧은 타이밍에 피격되면 다음과 같은 효과가 발생한다:

  • 받는 대미지가 완전히 무효화된다
  • 공격자에게 DP를 반사한다
퍼펙트 가드 DP 반사량 = 공격자 ATK × (100 ÷ (100 + 방어자 DEF))

가드 발동 시 진행 중이던 다른 어빌리티가 취소되며, 가드 중에는 다른 어빌리티를 사용할 수 없다. 버튼을 떼면 가드가 즉시 해제된다. 가드 중 피격되면 전용 가드 피격 애니메이션이 재생되고, 가드 피격 애니메이션이 끝난 뒤에도 버튼을 누르고 있으면 가드 자세가 자동으로 재개된다.

회피 방어

현재 이동 방향으로 빠르게 회피한다. 회피 애니메이션의 특정 구간 동안 캐릭터가 무적 상태가 되어 모든 공격을 무시한다.

입력
회피 버튼 누르기
MP 비용
-
쿨다운
데이터 에셋에서 설정
사용 불가
사망 상태

무적 구간

회피 애니메이션에 설정된 무적 구간 동안에는 어떤 공격도 대미지를 입히지 못하고, 피격 반응도 발생하지 않는다.

회피 발동 시 진행 중이던 다른 어빌리티가 취소된다. 이동 입력이 있으면 그 방향으로 부드럽게 회전한 뒤 회피 동작이 시작된다.

4. 이동 어빌리티 상세

질주 이동

버튼을 누르고 있는 동안 이동속도가 증가하여 빠르게 달릴 수 있다.

입력
질주 버튼 홀드
속도 보너스
SPD +0.5
사용 불가
사망 상태

질주 중에는 SPD 스탯에 +0.5가 가산된다. 기본 SPD가 1.0인 캐릭터의 경우 이동속도가 50% 증가하는 효과이다. 버튼을 떼면 즉시 원래 속도로 복귀한다.

점프 이동

캐릭터를 공중으로 도약시킨다.

입력
점프 버튼 누르기
사용 불가
사망 상태, 점프할 수 없는 상황 (공중 등)

점프 버튼을 누르면 캐릭터가 도약한다. 버튼을 빨리 떼면 상승이 중단되어 낮은 점프가 가능하다. 캐릭터가 이미 공중에 있거나 점프가 불가능한 상태에서는 발동되지 않는다.

락온 이동

가장 가까운 적에게 카메라를 고정한다. 락온 중에는 카메라가 대상을 자동으로 추적하며, 캐릭터의 회전은 이동 방향을 유지한다.

입력
락온 버튼 토글
최대 거리
2,000 (언리얼 유닛)
카메라 보간 속도
8
카메라 피치 오프셋
-15°
사용 불가
사망 상태

사용 흐름

  1. 락온 버튼을 누르면 주변에서 가장 가까운 적을 탐색한다
  2. 적이 발견되면 대상에 조준점이 표시되고 카메라가 대상을 추적한다
  3. 락온 버튼을 다시 누르면 해제된다

락온 대상이 사망하거나 최대 거리를 벗어나면 자동으로 해제된다. 락온은 다른 어빌리티(공격, 가드, 회피 등)와 동시에 유지되므로, 전투 중에도 락온 상태가 풀리지 않는다.

5. 반응형 어빌리티

아래 어빌리티들은 플레이어가 직접 발동하는 것이 아니다. 특정 게임 상황이 되면 시스템이 자동으로 발동시킨다.

피격 반응 자동

대미지를 받으면 자동으로 피격 애니메이션이 재생되어 캐릭터의 현재 행동이 중단된다. 가드 중이었다면 전용 가드 피격 애니메이션이 재생된다.

발동 조건
대미지를 받았을 때
발동 불가
사망 상태, 무적 구간 중

분기

피격 상황재생 애니메이션비고
일반 피격일반 피격 반응진행 중인 어빌리티가 취소된다
가드 중 피격가드 피격 반응가드 자세가 유지된다
무적 중 피격-피격 반응이 발동하지 않는다
퍼펙트 가드가드 피격 반응대미지 무효화, 공격자에게 DP 반사

피격 반응은 연속으로 발동할 수 있다(재트리거 허용). 피격 반응이 발동되면 진행 중인 다른 어빌리티가 취소되며, 피격 반응 중에는 다른 어빌리티를 사용할 수 없다.

그로기 자동

DP(충격 누적치)가 최대치에 도달하면 기절 상태에 빠진다. 일정 시간 동안 아무 행동도 할 수 없으며, 시간이 지나면 자동으로 회복된다.

발동 조건
DP가 MaxDP에 도달
지속 시간
5초 (기본값)
DP 드레인 속도
MaxDP ÷ 지속시간 매 프레임 감소 (초당 약 30회 갱신)
발동 불가
사망 상태

진행 과정

  1. DP가 MaxDP에 도달하면 그로기 상태에 진입한다
  2. 진행 중이던 모든 어빌리티가 취소되고 기절 애니메이션이 재생된다
  3. 그로기 중에는 피격 반응만 발생할 수 있으며, 피격 반응이 끝나면 기절 애니메이션이 재개된다
  4. DP가 매 프레임 자동으로 감소하며, 5초 후 DP가 0이 되면 그로기가 해제된다
프레임당 DP 감소량 = (MaxDP ÷ 그로기 지속시간) × (1 ÷ 30)

사망 자동

HP가 0이 되면 캐릭터가 사망한다. 모든 행동이 즉시 중단되며, 사망 연출이 재생된다.

발동 조건
HP가 0이 됨

진행 과정

  1. HP가 0에 도달하면 사망 상태에 진입한다
  2. 진행 중이던 모든 어빌리티가 즉시 취소된다
  3. 사망 애니메이션이 설정되어 있으면 재생 후 래그돌로 전환된다
  4. 사망 애니메이션이 없으면 즉시 래그돌이 활성화된다

사망 상태에서는 피격 반응을 포함한 모든 어빌리티가 차단된다. 래그돌은 멀티플레이에서 모든 클라이언트에 동기화된다.

6. 어빌리티 상호작용 다이어그램

어빌리티 간의 관계와 대미지 흐름을 시각적으로 표현한 다이어그램이다.

7. 상태 및 판정 구간 정리

캐릭터 상태

캐릭터에 지속적으로 부여되는 상태이다. 어빌리티 발동 조건이나 차단 조건으로 사용된다.

사망 HP가 0이 되면 부여된다. 피격 반응을 포함한 모든 어빌리티의 발동을 차단한다.
그로기 DP가 MaxDP에 도달하면 부여된다. 피격 반응을 제외한 모든 어빌리티를 차단하며, DP가 0이 되면 해제된다.
공중 캐릭터가 낙하 또는 비행 중일 때 부여된다. 착지하면 해제된다.
락온 락온 어빌리티가 활성 중일 때 부여된다. 카메라 회전(Look) 입력이 억제된다.

판정 구간

애니메이션의 특정 구간에서만 활성화되는 일시적 판정이다. 전투 시스템의 핵심 타이밍을 결정한다.

무기 충돌 공격 애니메이션 중 이 구간에서만 적에게 실제 대미지를 입힐 수 있다.
콤보 윈도우 일반 공격 애니메이션 중 이 구간에서 공격 버튼을 누르면 다음 콤보 단계로 연결된다.
무적 회피 및 궁극기 컷씬 중 활성화된다. 어떤 공격도 대미지를 입히지 못하고, 피격 반응도 발생하지 않는다.
가드 가드 애니메이션 중 활성화된다. 받는 대미지가 50% 감소한다.
퍼펙트 가드 가드 구간 초반의 짧은 타이밍이다. 대미지를 완전히 무효화하고 공격자에게 DP를 반사한다.

참고: MP 비용 및 쿨다운 시스템

MP 비용

각 어빌리티에는 MP 비용을 설정할 수 있다. 현재 MP가 비용보다 적으면 어빌리티가 발동되지 않는다. 어빌리티 발동 시 설정된 MP가 즉시 차감된다.

공격이 적에게 적중하면 공격자의 MP가 5씩 회복된다. 이 회복은 적중당 1회 발생한다.

쿨다운

각 어빌리티에는 쿨다운 시간(초 단위)을 설정할 수 있다. 쿨다운 중에는 해당 어빌리티를 다시 사용할 수 없다. 쿨다운은 어빌리티별로 독립적으로 관리된다.

이 문서는 소스 코드를 기반으로 자동 생성되었다.
