3. 전투 어빌리티 상세

전투 일반 공격

약공격과 강공격을 자유롭게 조합하여 적을 연속으로 타격하는 기본 전투 수단이다. 적에게 적중할 때마다 MP를 5 회복하므로, 스킬 사용을 위한 자원 확보 수단이기도 하다.

발동 조건 및 입력

  • 약공격 또는 강공격 버튼을 눌러 발동한다.
  • 사망 상태에서는 사용할 수 없다.
  • 이미 공격 중일 때 다시 공격을 발동할 수 없다 (콤보 입력은 별도 처리).

사용 흐름

  1. 약공격 또는 강공격 입력 시 해당 방향의 첫 번째 콤보 모션이 재생된다.
  2. 모션 중 콤보 윈도우 구간이 열리면, 그 안에서 약/강공격을 입력하여 다음 콤보로 연결할 수 있다.
  3. 콤보 윈도우를 놓치거나 더 이상 연결 가능한 콤보가 없으면 자연스럽게 종료된다.
  4. 모션 재생 시 자동으로 타겟 방향을 향해 회전한다.

주요 수치

  • 비용: 없음
  • 쿨다운: 없음
  • 적중 시 MP +5 회복 (공격자)

특수 메커니즘: 콤보 시스템

콤보 경로는 약공격(L)과 강공격(H)의 조합으로 구성된다. 예를 들어 "LLH"는 약공격 두 번 후 강공격 한 번을 의미한다. 각 경로마다 고유한 공격 모션이 매핑되어 있으며, 데이터 에셋에서 자유롭게 확장할 수 있다.

전투 스킬

MP를 소모하여 일반 공격보다 강력한 기술을 사용한다. 적에게 적중할 때마다 UP을 5 회복하여 궁극기 게이지를 충전하는 역할도 한다.

발동 조건 및 입력

  • 스킬 버튼을 눌러 발동한다.
  • MP가 비용 이상 남아 있어야 사용 가능하다.
  • 사망 상태에서는 사용할 수 없다.

사용 흐름

  1. 스킬 버튼 입력 시 MP를 소모하고 스킬 모션이 재생된다.
  2. 모션 중 자동으로 타겟 방향을 향해 회전한다.
  3. 모션이 완료되거나 다른 어빌리티에 의해 중단되면 종료된다.

주요 수치

  • 비용: MP (캐릭터별 설정값)
  • 쿨다운: 캐릭터별 설정값
  • 충전 시스템: 최대 충전 수가 2 이상이면, 충전이 남아 있는 한 쿨다운 중에도 사용 가능하다. 쿨다운이 만료될 때마다 충전이 1씩 회복된다.
  • 적중 시 UP +5 회복 (공격자)

전투 궁극기

축적한 UP을 전부 소모하여 화려한 컷신 연출과 함께 강력한 필살기를 시전한다. 컷신 동안 시간이 거의 멈추며, 시전자는 무적 상태가 된다.

발동 조건 및 입력

  • 궁극기 버튼을 눌러 발동한다.
  • UP 100 이상이어야 사용 가능하다.
  • 사망 또는 그로기 상태에서는 사용할 수 없다.
  • 발동 시 진행 중인 모든 어빌리티가 취소되며, 궁극기 중 다른 어빌리티 사용이 차단된다.

사용 흐름

  1. UP을 소모하고 컷신(레벨 시퀀스)이 재생된다.
  2. 컷신 동안 게임 월드의 시간이 거의 정지(Time Dilation 0.001)되며, 시전자에게 무적 태그가 부여된다.
  3. 컷신이 끝나면 무적이 해제되고, 공격 모션이 재생된다.
  4. 공격 모션이 완료되면 종료된다.

주요 수치

  • 비용: UP 100
  • 쿨다운: 캐릭터별 설정값
  • 컷신 중 무적
  • 컷신 중 글로벌 타임 딜레이션: 0.001 (실질적 시간 정지)

4. 방어 어빌리티 상세

방어 가드

가드 버튼을 누르고 있는 동안 방어 자세를 유지하여 받는 대미지를 절반으로 줄인다. 가드 성공 직후 잠깐 열리는 퍼펙트 가드 구간에 피격되면 대미지를 완전히 무효화하고, 공격자에게 그로기 수치를 반사할 수 있다.

발동 조건 및 입력

  • 가드 버튼을 홀드하여 발동한다. 버튼을 놓으면 가드가 해제된다.
  • 사망 상태에서는 사용할 수 없다.
  • 발동 시 진행 중인 다른 어빌리티를 취소하며, 가드 중 다른 어빌리티 사용이 차단된다.

사용 흐름

  1. 가드 버튼 홀드 시 가드 모션이 재생되고, 가드 판정이 활성화된다.
  2. 가드 중 피격 시 가드 피격 모션이 재생된다. 이때 가드 판정은 끊기지 않는다.
  3. 가드 피격 모션 종료 후 자동으로 가드 자세로 복귀한다.
  4. 버튼을 놓으면 가드가 즉시 해제된다.

주요 수치

  • 비용: 없음
  • 쿨다운: 캐릭터별 설정값
  • 일반 가드 대미지 감소율: 50%
  • 가드 중 피격 시 SP가 감소된 대미지만큼 소모된다
  • 가드 중 피격 시 강인도(PP)가 최대치로 회복된다 (그로기 상태가 아닌 경우)

특수 메커니즘: 퍼펙트 가드

가드 모션 시작 직후 짧은 구간 동안 퍼펙트 가드 판정이 활성화된다. 이 구간에 피격되면:

  • 대미지가 완전히 무효화된다 (HP, PP 차감 없음).
  • 공격자에게 DP가 반사된다. 반사량은 공격력 × 방어 배율과 동일하다.
  • 방어자의 MP가 5 회복된다.
  • 막을 수 없는 공격에도 퍼펙트 가드는 동일하게 적용된다.

방어 회피

이동 방향으로 빠르게 구르면서 짧은 무적 구간을 활용해 공격을 피하는 기동이다. 무적 중 피격에 성공하면 극한 회피가 발동되어 시간이 느려지는 특수 모션으로 전환되며, 여기서 공격 입력으로 반격까지 연결할 수 있다.

발동 조건 및 입력

  • 회피 버튼을 눌러 발동한다.
  • 사망 상태에서는 사용할 수 없다.
  • 발동 시 진행 중인 다른 어빌리티를 취소한다.
  • 충전제로 운용된다: 최대 2회까지 연속 사용 가능하며, 2초마다 1회씩 재충전된다.

사용 흐름

  1. 회피 버튼 입력 시 이동 입력 방향으로 캐릭터가 회전하고 회피 모션이 재생된다.
  2. 모션 중 무적 구간이 존재한다.
  3. 무적 구간에서 적의 공격이 닿으면 극한 회피가 발동되어 특수 모션으로 전환된다.
  4. 극한 회피 모션 중 콤보 윈도우 구간에서 공격 버튼을 누르면 반격 모션으로 전환된다.
  5. 모션이 완료되면 종료된다.

주요 수치

  • 비용: 없음
  • 쿨다운: 2초 (충전당)
  • 최대 충전: 2회
  • 무적 구간 중 피격 시 (극한 회피): MP +5 회복

특수 메커니즘: 극한 회피 → 반격

무적 구간에서 적의 공격을 회피하면 극한 회피 모션이 자동으로 재생된다. 이 모션 중 콤보 윈도우가 열리며, 그 안에서 공격(약/강) 버튼을 누르면 반격 모션으로 즉시 전환된다. 반격을 입력하지 않으면 극한 회피 모션이 끝난 뒤 자연스럽게 종료된다.

5. 이동 어빌리티 상세

이동 점프

캐릭터가 점프한다. 버튼을 오래 누를수록 더 높이 점프하며, 놓는 순간 상승이 멈춘다.

발동 조건 및 입력

  • 점프 버튼을 눌러 발동한다.
  • 사망 상태이거나 점프 불가능 상황(공중 등)에서는 사용할 수 없다.

사용 흐름

  1. 점프 버튼을 누르면 캐릭터가 점프한다.
  2. 버튼을 놓으면 점프가 중단되고 어빌리티가 종료된다.

주요 수치

  • 비용: 없음
  • 쿨다운: 없음

이동 스프린트

달리기 버튼을 유지하는 동안 이동 속도가 빨라진다. 전투 중 위치를 빠르게 조정하거나 필드를 탐색할 때 유용하다.

발동 조건 및 입력

  • 스프린트 버튼을 홀드하여 발동한다. 놓으면 즉시 해제된다.
  • 사망 상태에서는 사용할 수 없다.

사용 흐름

  1. 버튼 홀드 시 이동 속도 증가 효과가 적용된다.
  2. 버튼을 놓으면 속도 증가 효과가 제거되고 어빌리티가 종료된다.

주요 수치

  • 비용: 없음
  • 쿨다운: 없음
  • 이동 속도 증가: SPD +0.5 (기본 속도 대비 50% 증가)

6. 기타 어빌리티 상세

기타 락온

전투 중 특정 적을 고정하여 카메라가 해당 적을 자동으로 추적하게 한다. 락온 중에도 다른 어빌리티(공격, 가드, 회피 등)를 자유롭게 사용할 수 있으며, 공격/스킬 시 자동으로 락온 대상을 향해 회전한다.

발동 조건 및 입력

  • 락온 버튼을 눌러 토글한다. 한 번 누르면 활성화, 다시 누르면 해제된다.
  • 사망 상태에서는 사용할 수 없다.
  • 범위 내에 유효한 적이 없으면 활성화되지 않는다.

사용 흐름

  1. 락온 버튼 입력 시 가장 가까운 적을 자동으로 탐색한다.
  2. 대상이 발견되면 카메라가 해당 적을 향해 부드럽게 회전하며 추적을 시작한다. 대상 위에 조준점 위젯이 표시된다.
  3. 다시 버튼을 누르면 락온이 해제된다.
  4. 대상이 사망하거나, 최대 거리(2000)를 벗어나면 자동으로 해제된다.

주요 수치

  • 비용: 없음
  • 쿨다운: 없음
  • 최대 락온 거리: 2000
  • 카메라 보간 속도: 8
  • 카메라 피치 오프셋: -15°

특수 메커니즘

락온은 다른 전투 어빌리티와 독립적으로 동작한다. 공격이나 피격 반응에 의해 취소되지 않으므로, 전투 중 일관되게 대상을 추적할 수 있다.

7. 반응형 어빌리티 상세

반응형 피격 반응

공격을 받아 강인도(PP)가 바닥나면 캐릭터가 잠시 경직되는 모션이 재생된다. 이때 강인도가 최대치로 즉시 회복되므로, 연속 피격 시에도 일정 간격으로만 경직이 발생한다.

발동 조건

  • 피격 시 PP가 0 이하로 떨어지면 자동 발동된다.
  • 사망 상태, 무적 상태, 가드 상태에서는 발동하지 않는다.
  • 같은 대상에게 연속 피격 시 재발동 가능하다.

사용 흐름

  1. 피격 판정 시 PP를 대미지만큼 차감한다.
  2. PP가 0 이하이면 피격 경직 모션이 재생된다.
  3. 그로기 상태가 아닌 경우, PP가 최대치로 회복된다.
  4. 모션이 완료되면 종료된다.

특수 메커니즘

발동 시 진행 중인 다른 어빌리티(공격, 스킬 등)를 취소한다. 단, 가드 중에는 가드 어빌리티가 자체적으로 가드 피격 반응을 처리하므로, 이 어빌리티는 발동되지 않는다.

반응형 그로기

적의 공격을 계속 받아 그로기 수치(DP)가 최대에 도달하면 무방비 상태에 빠진다. 일정 시간 동안 행동이 불가능해지며, 그 사이 DP가 점차 감소하여 0이 되면 회복된다.

발동 조건

  • DP가 최대치(MaxDP)에 도달하면 자동 발동된다.
  • 사망 상태에서는 발동하지 않는다.

사용 흐름

  1. DP가 최대에 도달하면 그로기 상태 태그가 부여되고, 그로기 모션이 재생된다.
  2. PP가 0으로 설정된다.
  3. 그로기 동안에도 피격 반응(경직)은 발생할 수 있으며, 피격 모션이 끝나면 그로기 모션으로 복귀한다.
  4. DP가 설정된 시간(기본 5초) 동안 균등하게 감소한다 (초당 30틱 속도).
  5. DP가 0에 도달하면 그로기 상태가 해제되고, PP가 최대치로 회복된다.

주요 수치

  • 그로기 지속 시간: 5초 (기본값)
  • DP 감소 속도: MaxDP를 그로기 지속 시간으로 나눈 값을 초당 30틱으로 분할

특수 메커니즘

그로기 상태에서는 추가로 누적되는 DP가 무시된다. 그로기 발동 시 진행 중인 모든 어빌리티가 취소된다.

반응형 사망

체력이 바닥나면 캐릭터가 사망한다. 사망 모션이 재생된 뒤 래그돌(물리 시뮬레이션) 상태로 전환되어 자연스럽게 쓰러진다.

발동 조건

  • 피격 대미지에 의해 HP가 0이 되면 자동 발동된다.

사용 흐름

  1. HP가 0이 되면 사망 상태 태그가 부여된다.
  2. 진행 중인 모든 어빌리티가 취소되며, 새로운 어빌리티 사용이 차단된다.
  3. 사망 모션이 있으면 재생 후 래그돌로 전환된다. 없으면 즉시 래그돌이 활성화된다.

특수 메커니즘

래그돌 활성화 시 캡슐 충돌이 비활성화되고, 메시의 물리 시뮬레이션이 시작되며, 캐릭터 이동이 차단된다. 사망은 서버에서만 판정되어 모든 클라이언트에 동기화된다.

8. 콤보 시스템

콤보 경로 표기법

콤보 경로는 L(약공격)과 H(강공격) 문자의 조합으로 표현된다. 왼쪽부터 순서대로 입력한 공격을 의미한다.

경로의미
L약공격 1타
H강공격 1타
LL약공격 → 약공격
LH약공격 → 강공격
LLL약공격 → 약공격 → 약공격
LLH약공격 → 약공격 → 강공격
LHLH약공격 → 강공격 → 약공격 → 강공격

위 예시는 데이터 에셋에 등록하는 콤보 경로의 사례이며, 캐릭터마다 다른 콤보 구성이 가능하다.

콤보 윈도우

각 공격 모션에는 콤보 윈도우라는 특정 구간이 설정되어 있다. 이 구간 동안에만 다음 공격 입력이 유효하며, 구간 밖에서 입력하면 무시된다.

  • 콤보 윈도우가 열려 있는 동안 약공격 또는 강공격을 입력하면, 현재 경로에 L 또는 H가 추가된다.
  • 추가된 경로에 매핑된 모션이 있으면 해당 모션으로 즉시 전환된다.
  • 매핑된 모션이 없으면 입력이 무시되고, 현재 모션이 끝까지 재생된다.

콤보 경로와 모션의 매핑

각 콤보 경로에는 고유한 공격 모션이 1:1로 매핑된다. 기획 단계에서 데이터 에셋의 콤보 맵에 경로와 모션을 등록하면, 코드 수정 없이 콤보 트리를 확장할 수 있다.

10. 상태이상 시스템

화상

화상에 걸린 캐릭터는 일정 시간 동안 지속적으로 체력이 감소한다. 불 속성 공격이나 특정 환경에 의해 부여된다.

기본 수치

  • 지속 시간: 5초
  • 틱 간격: 0.5초
  • 총 틱 수: 10회

대미지 공식

화상 총 대미지는 일반 대미지 공식과 동일하게 공격력 × (100 / (100 + 방어력))으로 계산된다. 이 총 대미지를 10틱으로 균등 분할하여 매 틱마다 적용한다.

특수 규칙

  • 가드, 퍼펙트 가드에 의한 대미지 감소가 적용되지 않는다.
  • 치명타 판정이 적용되지 않는다.
  • 무적 상태에서는 화상 틱 대미지가 무효화된다.
  • 화상 공격력은 화상을 부여한 시점의 공격자 공격력이 적용된다 (스냅샷).

공격력 증가 (버프)

특정 조건에 의해 캐릭터의 공격력이 일시적으로 상승한다.

  • 지속 시간: 5초
  • 공격력 증가: ATK +50%

12. 상태 태그 정리

캐릭터 상태

사망 HP가 0이 되면 부여. 모든 어빌리티 활성화가 차단된다.
공중 낙하/비행 중 부여, 착지 시 제거. 점프 가능 여부 판단에 사용된다.
그로기 DP가 MaxDP에 도달하면 부여. 그로기 어빌리티를 트리거하며, 해당 시간 동안 DP 누적이 무시된다.
락온 락온 어빌리티 활성 중 부여. 카메라 회전 입력(Look)을 억제한다.

판정 구간

무기 충돌 무기의 히트 판정이 활성화되는 구간. 이 구간에서만 적에게 대미지가 적용된다.
콤보 윈도우 다음 공격 입력을 수용하는 구간. 이 구간에서 입력해야 콤보가 연결된다.
무적 모든 대미지가 무효화되는 구간. 회피 모션과 궁극기 컷신에서 부여된다.
가드 가드 판정이 활성화된 구간. 대미지 50% 감소, 피격 경직 대신 가드 피격 반응이 발생한다.
퍼펙트 가드 가드 시작 직후의 짧은 판정 구간. 대미지 완전 무효, DP 반사, MP 회복 효과가 발생한다.

대미지 판정

치명타 치명타 발생 시 부여. 대미지 플로터에서 치명타 연출을 표시하는 데 사용된다.
막을 수 없는 공격 일반 가드의 대미지 감소를 무시하는 공격. 퍼펙트 가드로는 여전히 방어 가능하다.
