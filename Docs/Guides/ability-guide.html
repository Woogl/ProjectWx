2. 전투 어빌리티

일반 공격

약공격과 강공격을 조합하여 다양한 콤보를 이어가는 기본 전투 수단이다. 콤보 경로에 따라 재생되는 애니메이션이 달라진다.

입력 방식 — 약공격 또는 강공격 버튼을 눌러 발동한다.

사용 흐름

약/강 입력 → 첫 번째 공격 애니메이션 재생 → 콤보 연결 구간 내 재입력 → 다음 콤보 애니메이션 재생 → 콤보 종료 또는 미입력 시 종료

콤보 시스템

  • 공격할 때마다 약(L) 또는 강(H)이 콤보 경로에 추가된다.
  • 콤보 연결 구간 내에 입력해야 다음 콤보로 이어진다. 구간 밖이면 무시된다.
  • 등록된 콤보 경로에 매칭되는 애니메이션이 없으면 콤보가 종료된다.
  • 예시: L → LL → LLL, L → LH → LLH, H 등 다양한 분기 가능

자원 회복 — 공격이 적에게 적중할 때마다 MP를 5 회복한다.

사용 불가 조건 — 사망 상태, 또는 이미 공격 중일 때 발동할 수 없다.

스킬

MP를 소모하여 강력한 기술을 발동한다. 충전 시스템을 지원하여, 충전이 남아 있으면 쿨다운 중에도 사용할 수 있다.

입력 방식 — 스킬 버튼을 눌러 발동한다.

사용 흐름

스킬 입력 → MP 소모 + 충전 1회 소모 → 스킬 애니메이션 재생 → 애니메이션 완료 시 종료

비용 — MP 소모량은 스킬마다 다르게 설정된다.

충전 시스템

  • 최대 충전 횟수가 2회 이상인 스킬은 충전 방식으로 동작한다.
  • 사용할 때마다 충전이 1 감소하고, 쿨다운이 만료될 때마다 충전이 1 회복된다.
  • 충전이 남아 있으면 쿨다운 진행 중에도 사용 가능하다.
  • 충전이 최대치 미만이면 쿨다운이 자동으로 반복 적용되어 순차적으로 재충전된다.

자원 회복 — 적에게 적중할 때마다 UP를 5 회복한다.

사용 불가 조건 — 사망 상태이거나 MP가 부족하면 발동할 수 없다.

궁극기

UP를 전부 소모하여 컷씬 연출과 함께 강력한 일격을 가한다. 컷씬 동안 게임 월드의 시간이 거의 정지하며, 캐릭터는 무적 상태가 된다.

입력 방식 — 궁극기 버튼을 눌러 발동한다.

사용 흐름

궁극기 입력 → UP 소모 → 컷씬 재생 (시간 왜곡 0.001배속) → 공격 애니메이션 재생 → 종료

비용 — UP 100을 소모한다. (기본값, 서브클래스에서 변경 가능)

컷씬 연출

  • 컷씬이 설정된 경우, 레벨 시퀀스로 연출을 재생한다.
  • 컷씬 동안 게임 월드의 시간이 0.001배속으로 거의 정지한다.
  • 컷씬이 없으면 바로 공격 애니메이션으로 진행한다.

사용 불가 조건 — 사망, 그로기 상태이거나 UP가 부족하면 발동할 수 없다.

3. 방어 어빌리티

가드

버튼을 누르고 있는 동안 방어 자세를 취한다. 가드 중 피격 시 대미지가 절반으로 감소하며, 가드 시작 직후에는 퍼펙트 가드가 발동하여 대미지를 완전히 무효화한다.

입력 방식 — 가드 버튼을 홀드하여 유지한다. 버튼을 놓으면 즉시 해제된다.

사용 흐름

가드 홀드 → 방어 자세 유지 → 피격 시 가드 피격 연출 → 방어 자세로 자동 복귀 → 버튼 릴리즈 시 종료

가드 판정

  • 일반 가드 — 받는 대미지가 50% 감소한다. 감소된 대미지만큼 SP도 함께 차감된다.
  • 퍼펙트 가드 — 가드 시작 직후 짧은 구간에서 발동. 대미지를 완전 무효화하고, 공격자에게 DP를 반사한다. 반사량은 공격력 × 방어 계수이다. 방어자는 MP를 5 회복한다.
  • 가드 불가 공격 — 가드 불가 속성이 붙은 공격은 가드와 퍼펙트 가드를 모두 무시하고 전체 대미지를 적용한다.

가드 피격 시 PP 회복 — 가드 상태에서 피격되면 PP가 최대치로 즉시 회복된다(그로기 중은 제외).

사용 불가 조건 — 사망 상태일 때 발동할 수 없다. 발동 시 다른 모든 어빌리티를 취소한다.

회피

입력 방향으로 빠르게 구르며 적의 공격을 피한다. 무적 구간에서 적의 공격을 회피하면 극한 회피가 발동하여 반격 기회가 주어진다.

입력 방식 — 회피 버튼을 눌러 발동한다. 이동 입력 방향으로 구른다.

사용 흐름

회피 입력 → 이동 방향으로 구르기 → 무적 구간 중 피격 시 극한 회피 → 극한 회피 중 공격 입력 시 반격 → 종료

충전 시스템 — 최대 2회 충전, 쿨다운 2초마다 1회 재충전된다.

극한 회피

  • 무적 구간에서 적의 공격이 감지되면 극한 회피가 자동 발동한다.
  • 극한 회피 시 전용 애니메이션으로 전환되고, MP를 5 회복한다.
  • 극한 회피 애니메이션의 콤보 연결 구간 내에 공격 버튼을 누르면 반격 애니메이션이 발동한다.

사용 불가 조건 — 사망 상태일 때 발동할 수 없다. 발동 시 다른 모든 어빌리티를 취소한다.

4. 이동 어빌리티

질주

버튼을 누르고 있는 동안 이동 속도가 증가한다.

입력 방식 — 질주 버튼을 홀드하여 유지한다. 버튼을 놓으면 즉시 해제된다.

속도 보너스 — 이동 속도가 +0.5 (기본 이동 속도 대비 50% 증가) 만큼 상승한다.

사용 불가 조건 — 사망 상태일 때 발동할 수 없다.

점프

캐릭터가 점프한다. 캐릭터가 점프 가능한 상태일 때만 사용할 수 있다.

입력 방식 — 점프 버튼을 눌러 발동한다. 버튼을 놓으면 점프를 중단한다.

발동 조건 — 캐릭터가 점프 가능한 상태(지상)여야 하며, 사망 상태가 아니어야 한다.

락온

가장 가까운 적을 카메라가 지속적으로 추적한다. 다시 눌러 해제하거나, 대상이 사라지면 자동 해제된다.

입력 방식 — 락온 버튼을 눌러 토글한다. 활성 중 다시 누르면 해제된다.

사용 흐름

락온 입력 → 가장 가까운 적 탐색 → 카메라 추적 시작 + 조준점 표시 → 재입력 또는 대상 소실 시 해제

카메라 설정

  • 카메라 보간 속도: 8.0
  • 카메라 피치 오프셋: -15°
  • 최대 추적 거리: 2000

자동 해제 조건 — 대상이 사망하거나, 최대 거리를 벗어나거나, 소멸하면 자동 해제된다.

특수 사항 — 락온은 다른 어빌리티(공격, 가드 등)에 의해 취소되지 않으며 공존한다. 캐릭터의 몸 방향은 이동 방향을 유지하고, 카메라만 대상을 추적한다.

사용 불가 조건 — 사망 상태일 때 발동할 수 없다.

5. 반응형 어빌리티

이 어빌리티들은 플레이어가 직접 발동하지 않으며, 게임 상황에 의해 자동 발동된다.

피격 반응

대미지를 받아 경직 게이지(PP)가 소진되면 피격 경직 애니메이션이 재생된다. 연속으로 맞더라도 매 피격마다 PP가 즉시 최대치로 회복된다.

발동 트리거 — 피격 시 PP가 0 이하로 내려가면 자동 발동한다.

진행 과정

PP 소진 후 피격 → PP 최대치로 회복 → 다른 모든 어빌리티 취소 → 피격 애니메이션 재생 → 완료 시 종료

면역 조건 — 다음 상태에서는 피격 반응이 발동하지 않는다:

  • 사망 상태
  • 무적 구간 (회피 중)
  • 가드 판정 구간 (가드 전용 피격 처리가 별도로 진행됨)

연속 피격 — 피격 반응 중에 다시 피격 조건이 충족되면, 현재 피격 반응을 취소하고 새로운 피격 반응이 즉시 재발동한다.

그로기

DP가 최대치에 도달하면 일정 시간 기절 상태에 빠진다. 기절 동안 DP가 서서히 감소하며, DP가 0이 되면 기절에서 해제된다.

발동 트리거 — DP가 최대치(MaxDP)에 도달하면 자동 발동한다.

진행 과정

DP 최대치 도달 → PP를 0으로 초기화 → 다른 모든 어빌리티 취소 → 기절 애니메이션 재생 → DP 자동 감소 → DP 0 도달 시 해제, PP 최대치 회복

기절 지속

  • 기본 기절 시간: 5초 (DP가 MaxDP에서 0까지 감소하는 데 걸리는 시간)
  • DP 감소 속도: 1/30초 간격으로 MaxDP / (5초 × 30틱)씩 감소
  • 기절 중 피격 시 DP가 누적되지 않으므로, 기절 시간이 연장되지 않는다.

기절 중 피격 — 기절 중에도 피격 반응은 발동한다. 피격 반응 애니메이션이 끝나면 기절 애니메이션이 자동으로 다시 재생된다.

사용 불가 조건 — 사망 상태에서는 발동하지 않는다.

사망

HP가 0에 도달하면 모든 행동이 즉시 중단되고, 사망 연출이 진행된다.

발동 트리거 — HP가 0이 되어 사망 상태가 부여되면 자동 발동한다.

진행 과정

HP 0 → 사망 상태 부여 → 모든 어빌리티 취소 + 차단 → 사망 애니메이션 재생 (없으면 생략) → 래그돌 활성화

특수 사항

  • 피격 반응을 포함한 모든 어빌리티가 즉시 취소되고 차단된다.
  • 사망 애니메이션이 설정되지 않은 경우 즉시 래그돌이 활성화된다.
  • 사망 상태가 유지되는 한 어떤 어빌리티도 발동할 수 없다.

6. 대미지 공식

기본 대미지

최종 대미지 = 공격력(ATK) × 100 / (100 + 방어력(DEF))

  • 치명타 — 치명타 확률(CritRate)에 따라 판정. 치명타 시 배율 = 1 + (CritDMG × 0.01)
  • 일반 가드 — 대미지 50% 감소
  • 퍼펙트 가드 — 대미지 완전 무효화, 공격자에게 DP 반사
  • 가드 불가 공격 — 가드 감소 무시, 전체 대미지 적용

화상 대미지

5초 동안 0.5초 간격(총 10틱)으로 HP 대미지를 입힌다. 기본 대미지 공식과 동일하되 가드, 퍼펙트 가드, 치명타가 적용되지 않는다. 총 대미지를 틱 수로 균등 분할한다.

버프 효과

ATK 버프 — 5초 동안 공격력(ATK)을 50% 증가시킨다.

SP 자연 회복 — 상시 적용. SP가 0인 상태에서 4초 후 최대치에 도달한다. (1/30초 간격, 틱당 MaxSP / 120 회복)

7. 상태 및 판정 구간 정리

캐릭터 상태

상태게임 플레이 영향
사망HP가 0이 되면 부여된다. 모든 어빌리티가 차단된다.
그로기DP가 최대치에 도달하면 부여된다. 피격 반응을 제외한 모든 어빌리티가 차단된다.
공중낙하 또는 비행 중 부여된다. 착지 시 제거된다.
락온락온 어빌리티 활성 중 부여된다. 카메라 조작 입력이 억제된다.

판정 구간

판정 구간게임 플레이 영향
무기 충돌공격 애니메이션 중 무기의 충돌 판정이 활성화되는 구간이다.
콤보 연결이 구간 내에 공격 입력 시 다음 콤보로 이어진다. 회피 반격도 이 구간에서만 가능하다.
무적이 구간에서는 대미지를 받지 않는다. 회피 중 이 구간에서 적의 공격이 감지되면 극한 회피가 발동한다.
가드이 구간에서 피격 시 대미지가 50% 감소하며, SP도 대미지만큼 차감된다.
퍼펙트 가드가드 시작 직후 짧은 구간. 대미지를 완전 무효화하고 공격자에게 DP를 반사한다.
