3-1. 전투 전투

일반 공격 전투

약공격과 강공격을 조합하여 다채로운 콤보를 만들어낸다. 적을 때릴수록 마나가 차오르며, 콤보 윈도우 내에 다음 공격을 입력하면 연속 공격이 이어진다.

입력 방식
약공격 또는 강공격 버튼 누르기
비용
없음
적중 시 보상
MP +5 회복 (타격당)

사용 흐름

  • 약공격 또는 강공격 버튼을 누르면 첫 번째 공격 모션이 재생된다.
  • 콤보 윈도우(연결 가능 구간) 중에 다시 약공격 또는 강공격을 입력하면 다음 콤보로 이어진다.
  • 콤보 경로에 해당하는 모션이 없거나, 콤보 윈도우를 놓치면 공격이 종료된다.
  • 적을 타격할 때마다 공격자의 MP가 5씩 회복된다.

특수 메커니즘: 콤보 경로

  • L = 약공격, H = 강공격으로 경로를 표기한다.
  • 예: L → LL → LLL (약약약), L → LH (약강), H (강공격 시작) 등
  • 경로와 모션은 캐릭터별로 다르게 설정할 수 있다.

스킬 전투

MP를 소모하여 강력한 고유 기술을 사용한다. 스킬로 적을 타격하면 궁극기 게이지(UP)가 충전되므로, 일반 공격으로 MP를 모은 뒤 스킬을 사용하는 것이 기본 전투 사이클이다.

입력 방식
스킬 버튼 누르기 (스킬 1~4 슬롯)
비용
MP (스킬별 개별 설정)
쿨다운
스킬별 개별 설정 (BP에서 지정)
충전
스킬별 개별 설정 (BP에서 지정)
적중 시 보상
UP +5 회복 (타격당)

사용 흐름

  • MP가 스킬 비용 이상이고 쿨다운이 충전되어 있으면 사용할 수 있다.
  • 버튼을 누르면 스킬 모션이 재생된다.
  • 적을 타격할 때마다 공격자의 UP가 5씩 회복된다.
  • 모션이 끝나거나 중단되면 스킬이 종료된다.

충전 시스템

  • 스킬에 충전 수가 2 이상으로 설정되어 있으면, 쿨다운마다 충전이 1개씩 복구된다.
  • 충전이 남아 있는 한 쿨다운 중에도 스킬을 재사용할 수 있다.

궁극기 전투

UP 게이지를 전부 소모하여 발동하는 필살기이다. 시전 시 연출용 컷씬이 재생되며, 이 동안 게임 월드가 일시 정지하고 캐릭터는 무적 상태가 된다. 컷씬이 끝나면 강력한 공격 모션이 이어진다.

입력 방식
궁극기 버튼 누르기
비용
UP 100
차단 조건
사망 또는 그로기 상태에서는 사용 불가

사용 흐름

  • UP가 100 이상일 때 궁극기 버튼을 누르면 발동된다.
  • 컷씬이 설정되어 있으면 컷씬이 먼저 재생된다. 이 동안 게임 월드의 시간이 거의 정지(0.001배 속도)하며, 캐릭터는 무적 상태가 된다.
  • 컷씬이 끝나면 궁극기 공격 모션이 재생된다.
  • 발동 시 다른 모든 어빌리티가 취소되고 차단된다.

3-2. 방어 방어

가드 방어

가드 버튼을 누르고 있으면 방패를 들어 공격을 막는다. 대미지가 50% 감소하지만 스태미나(SP)를 소모한다. SP가 바닥나면 가드가 깨지며 큰 경직이 발생한다. 가드 시작 직후의 짧은 구간에 타이밍을 맞추면 퍼펙트 가드가 발동되어 공격자에게 그로기 수치를 반사한다.

입력 방식
홀드 (누르고 있는 동안 유지, 버튼을 떼면 해제)
비용
없음 (피격 시 SP 소모)
퍼펙트 가드 MP 회복
+5

사용 흐름

  • 가드 버튼을 누르면 가드 자세에 들어간다. 다른 진행 중인 어빌리티는 모두 취소된다.
  • 가드 중 피격 시 SP가 대미지만큼 차감되고 대미지가 50% 감소한다.
  • 넉 계열(넉백/넉다운/넉업) 공격을 가드하면 전용 가드 넉백 모션이 재생된다.
  • SP가 0 이하가 되면 가드 브레이크가 발생하여 가드 상태가 해제되고 경직 모션이 재생된다. 가드 브레이크 중에는 버튼을 떼도 모션이 끝날 때까지 대기한다.
  • 버튼을 떼면 가드가 즉시 해제된다 (가드 브레이크 중이 아닌 경우).

퍼펙트 가드

  • 가드 시작 직후 짧은 퍼펙트 가드 판정 구간이 존재한다.
  • 이 구간에서 피격되면 대미지를 완전히 무효화하고, 공격자에게 대미지만큼의 그로기 수치(DP)를 반사한다.
  • 퍼펙트 가드 성공 시 MP가 5 회복된다.
  • 퍼펙트 가드는 막을 수 없는 공격(Unblockable)도 차단한다.

막을 수 없는 공격(Unblockable) 처리

  • 일반 가드 중 막을 수 없는 공격에 피격되면 가드가 강제 해제되고 일반 피격 반응이 발생한다.
  • 단, 퍼펙트 가드 구간에서는 막을 수 없는 공격도 차단된다.

회피 방어

이동 방향으로 빠르게 구르며 공격을 피한다. 구르기 모션 중 일정 구간은 무적이며, 이 무적 구간에서 적의 공격을 회피하면 "극한 회피"가 발동된다. 극한 회피 성공 후에는 전용 반격 모션으로 이어갈 수 있다.

입력 방식
누르기
비용
없음
쿨다운
캐릭터별 개별 설정 (BP)
충전
캐릭터별 개별 설정 (BP)
극한 회피 MP 회복
+5

사용 흐름

  • 회피 버튼을 누르면 현재 이동 입력 방향으로 회피 모션이 재생된다. 이동 입력이 없으면 캐릭터 정면 방향으로 회피한다.
  • 회피 모션 중 무적 구간이 존재한다.
  • 발동 시 다른 진행 중인 어빌리티는 모두 취소된다.

극한 회피 (퍼펙트 회피)

  • 무적 구간에서 적의 공격이 맞을 타이밍이었으나 회피에 성공하면 극한 회피가 발동된다.
  • 극한 회피 성공 시 전용 모션으로 전환되고 MP가 5 회복된다.
  • 극한 회피 모션의 콤보 윈도우 구간에서 공격 버튼을 누르면 반격 모션이 재생된다.

3-3. 이동 이동

스프린트 이동

스프린트 버튼을 누르고 있으면 캐릭터가 빠르게 달린다. 버튼을 떼면 원래 속도로 돌아온다.

입력 방식
홀드 (누르고 있는 동안 유지)
비용
없음
속도 증가
이동 속도 +50%

사용 흐름

  • 스프린트 버튼을 누르면 이동 속도가 1.5배가 된다.
  • 버튼을 떼면 속도 증가 효과가 즉시 제거된다.

점프 이동

점프 버튼을 누르면 캐릭터가 수직으로 도약한다. 버튼을 일찍 떼면 더 낮게 점프할 수 있다.

입력 방식
누르기 (누르는 시간에 따라 높이 조절)
비용
없음

사용 흐름

  • 점프 버튼을 누르면 도약한다.
  • 버튼을 떼면 상승이 멈추며 착지한다.
  • 캐릭터가 점프할 수 없는 상태(공중 등)에서는 발동되지 않는다.

3-4. 기타 기타

락온 기타

락온 버튼을 누르면 가장 가까운 적을 카메라가 자동으로 추적한다. 다시 누르면 해제된다. 락온 중에도 공격, 가드, 회피 등 다른 모든 어빌리티를 자유롭게 사용할 수 있다.

입력 방식
토글 (한 번 누르면 활성, 다시 누르면 해제)
비용
없음
최대 락온 거리
2,000 (언리얼 유닛)
카메라 보간 속도
8
카메라 피치 오프셋
-15°

사용 흐름

  • 락온 버튼을 누르면 범위 내 가장 가까운 적을 찾아 카메라가 해당 대상을 추적하기 시작한다.
  • 락온 대상 위에 조준점 위젯이 표시된다.
  • 다시 버튼을 누르면 락온이 해제된다.
  • 대상이 사망하거나, 최대 거리를 벗어나면 자동으로 해제된다.
  • 다른 전투 어빌리티(공격, 가드, 회피 등)와 공존하며 동시에 사용할 수 있다.

3-5. 반응형 반응형

피격 반응 반응형

적의 공격에 맞았을 때 자동으로 발동되는 경직 모션이다. 일반 피격은 강인도(PP)가 모두 소진되었을 때만 경직이 발생하지만, 넉백/넉다운/넉업 계열 공격은 강인도와 무관하게 즉시 경직이 발생한다.

발동 조건
대미지 판정에서 피격 반응 이벤트가 발송될 때 자동 발동
차단 조건
사망, 무적, 가드 상태에서는 발동하지 않는다

피격 유형

  • 일반 피격: 기본 경직 모션. 강인도(PP)가 소진되었을 때만 발동된다.
  • 넉백: 피격자를 뒤로 밀어내는 모션. PP와 무관하게 강제 발동. 공격자를 바라보도록 회전한다.
  • 넉다운: 피격자를 쓰러뜨리는 모션. PP와 무관하게 강제 발동. 공격자를 바라보도록 회전한다.
  • 넉업: 피격자를 공중으로 띄우는 모션. PP와 무관하게 강제 발동. 착지 시 전용 착지 모션으로 전환된다.

강인도(PP) 초기화

  • 피격 반응이 발동하면 강인도(PP)가 최대치로 초기화된다.
  • 단, 그로기 상태에서의 피격 시에는 초기화되지 않는다.

그로기 반응형

적의 공격을 계속 받아 그로기 수치(DP)가 최대치에 도달하면 캐릭터가 힘없이 쓰러져 무방비 상태가 된다. 이 상태에서는 일정 시간 동안 아무 행동도 할 수 없으며, 시간이 지나면 자동으로 회복된다.

발동 조건
DP가 최대치에 도달하면 자동 발동
지속 시간
5초
차단 조건
사망 상태에서는 발동하지 않는다

동작 상세

  • 그로기가 발동되면 PP가 0으로 설정되고 다른 모든 어빌리티가 취소된다.
  • 그로기 모션이 재생된다. 다른 모션이 재생 중이면 그것이 끝날 때까지 대기한 뒤 그로기 모션을 재생한다.
  • 그로기 상태에서 피격 반응(넉백 등)에 의해 모션이 중단되면, 해당 피격 모션이 끝난 뒤 다시 그로기 모션으로 복귀한다.
  • 그로기 중에는 DP 누적이 무시된다 (추가 대미지를 받아도 DP가 오르지 않는다).
  • 5초에 걸쳐 DP가 점진적으로 감소(초당 30틱)하고, DP가 0이 되면 그로기가 해제된다.
  • 그로기 해제 시 PP가 최대치로 회복된다.

사망 반응형

HP가 0이 되면 캐릭터가 사망한다. 사망 모션이 재생된 후 래그돌(물리 시뮬레이션) 상태로 전환된다.

발동 조건
HP 0 도달 시 사망 상태 태그가 부여되면 자동 발동

동작 상세

  • 사망 발동 시 다른 모든 어빌리티가 즉시 취소되고, 이후 어떤 어빌리티도 사용할 수 없다.
  • 사망 모션이 설정되어 있으면 모션 재생 후 래그돌이 활성화된다.
  • 모션이 없으면 즉시 래그돌로 전환된다.

4. 콤보 시스템

콤보 경로 표기법

콤보 경로는 L(약공격)과 H(강공격)의 조합으로 표현된다. 각 문자는 순서대로 입력한 공격 종류를 나타낸다.

경로의미입력 순서
L약공격 시작약
H강공격 시작강
LL약약 콤보약 → 약
LH약강 콤보약 → 강
LLL약약약 콤보약 → 약 → 약
LLH약약강 콤보약 → 약 → 강
LHLH약강약강 콤보약 → 강 → 약 → 강

콤보 윈도우

각 공격 모션에는 콤보 윈도우라는 구간이 설정되어 있다. 이 구간 안에서만 다음 공격 입력이 유효하다. 콤보 윈도우 밖에서 버튼을 눌러도 다음 콤보로 이어지지 않는다.

콤보 경로와 모션 매핑

캐릭터마다 콤보 경로-모션 매핑 테이블이 설정되어 있다. 다음 경로에 해당하는 모션이 등록되어 있지 않으면 콤보가 거기서 끝난다. 예를 들어 "LH"까지만 등록되어 있고 "LHL"이 없다면, 약→강 이후에는 콤보를 이을 수 없다.

6. 상태이상 시스템

발동 조건

대미지 공식

  • 총 대미지 = 공격자 공격력 × (100 ÷ (100 + 대상 방어력))
  • 틱당 대미지 = 총 대미지 ÷ 10
  • 가드, 퍼펙트 가드, 치명타 판정이 적용되지 않는다.

상호작용

  • 무적 상태에서는 화상 틱 대미지가 무효화된다.
  • 가드 상태에서도 화상 대미지는 정상적으로 적용된다 (가드 감소 없음).

8. 상태 태그 정리

캐릭터 상태

상태설명
사망HP가 0이 된 캐릭터에 부여된다. 사망 상태에서는 모든 어빌리티가 차단된다.
공중낙하 또는 비행 중인 캐릭터에 부여된다. 착지 시 제거된다.
그로기DP가 최대치에 도달한 캐릭터에 부여된다. 5초 후 자동 해제된다. 그로기 중에는 DP 누적이 무시된다.
락온락온 어빌리티가 활성 중인 캐릭터에 부여된다. 시선(Look) 입력이 억제된다.
무적회피의 무적 구간 또는 궁극기 컷씬 중에 부여된다. 모든 대미지가 무효화된다.

판정 구간

판정설명
무기 충돌공격 모션 중 무기의 히트 판정이 활성화되는 구간이다.
콤보 윈도우공격 모션 중 다음 콤보 입력을 받아들이는 구간이다. 극한 회피 반격도 이 구간에서만 가능하다.
가드가드 어빌리티가 활성 중일 때 부여된다. 피격 시 대미지가 50% 감소하고 SP가 소모된다.
퍼펙트 가드가드 시작 직후의 짧은 구간이다. 이 구간에서 피격되면 대미지를 완전히 무효화하고 공격자에게 DP를 반사한다.

대미지 속성

속성설명
치명타치명타가 발동된 공격에 부여된다. 대미지가 (1 + 치명타 피해 × 0.01)배로 증가한다.
막을 수 없는 공격일반 가드를 무시하는 공격이다. 퍼펙트 가드로만 방어할 수 있다.
