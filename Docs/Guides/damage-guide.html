데미지 가이드

생성일: 2026-04-11

기획자가 새 공격을 설계할 때 참고하는 데미지 시스템 설명서입니다. 데미지가 어떻게 계산되는지, 어떤 입력값을 만질 수 있는지, 그리고 상황별로 양쪽의 스탯이 어떻게 움직이는지를 정리했습니다.

목차

  1. 1. 데미지 파이프라인
  2. 2. 데미지 입력값
  3. 3. 상태별 스탯 증감표

1. 데미지 파이프라인

공격이 적중한 순간 어떤 분기를 거쳐 최종 데미지가 결정되는지를 한눈에 보여줍니다. 트렁크(가운데 세로 흐름)는 항상 위에서 아래로 흐르며, 오른쪽으로 빠지는 분기는 두 가지입니다. 보라/청록 분기는 그대로 계산이 끝나는 종료 분기, 주황 분기는 배수만 곱한 뒤 흐름으로 돌아오는 분기입니다.

주석
  • 치명타 발동 시 (1 + CritDMG × 0.01)배가 추가로 곱해집니다. CritRate · CritDMG는 포인트 값이며 1포인트 = 1%입니다.
  • 가드 중인 적에게는 위 값에 0.5를 곱한 값이 들어갑니다. 가드 불가 공격은 가드 중이어도 그대로 들어갑니다.
  • 판정 순서가 중요합니다. 퍼펙트 가드 판정이 가드 불가 판정보다 먼저 일어나므로, 가드 불가 공격이라도 퍼펙트 가드 윈도우 중에는 완전 방어됩니다.

계산식에 등장하는 스탯

  • ATK — 공격자의 공격력. 데미지의 기본이 되는 수치입니다.
  • DEF — 방어자의 방어력. 100 + DEF가 분모에 들어가서 데미지를 깎습니다.
  • CritRate — 공격자의 치명타 확률(포인트). 1포인트 = 1%.
  • CritDMG — 공격자의 치명타 추가 피해(포인트). 1포인트 = 1% 추가 데미지.

2. 데미지 입력값

공격 노티파이에서 직접 만지는 값들입니다. 수치·토글 값과 HitReact 태그 두 종류로 나뉩니다.

2-1. 파라미터

파라미터 기본값 의미
공격력 계수 1.0 공격자의 ATK에 곱해지는 배수. 한 공격이 ATK의 몇 배 데미지를 내는지를 결정합니다.
MP 회복량 0 적중 시 공격자가 회복하는 MP 양. 적중 한 번당 입력값만큼 들어옵니다.
UP 회복량 0 적중 시 공격자가 회복하는 UP(궁극기 게이지) 양. 적중 한 번당 입력값만큼 들어옵니다.
가드 불가 꺼짐 켜면 일반 가드를 무시하고 그대로 데미지가 들어갑니다. 가드 중인 적의 가드는 즉시 해제되며, PP가 데미지만큼 깎입니다. 단, 퍼펙트 가드 윈도우 중에는 여전히 막힙니다.
추가 이펙트 (없음) 적중 시 데미지와 함께 적용할 효과 목록(상태이상, 디버프 등). 비워 두면 데미지만 들어갑니다.

2-2. HitReact 태그

피격 시 어떤 종류의 경직을 줄지 고르는 태그입니다. Knock 계열은 PP 잔량과 무관하게 강제로 발동되고, Normal은 PP가 다 닳았을 때만 경직이 일어납니다.

태그 플레이 체감 사용 예시
Normal 맞아도 보통은 그대로 버티고, 강인도가 다 닳았을 때만 잠깐 경직. 보통 약공격, 콤보 사이의 견제용 타격
Knockback 강인도와 무관하게 뒤로 밀려난다. 발차기, 둔기 강타, 밀어내는 마법
Knockdown 강인도와 무관하게 그 자리에서 쓰러진다. 다리 후리기, 강한 마무리 일격
Knockup 강인도와 무관하게 공중으로 떠오른다. 어퍼컷, 아래에서 솟구치는 마법
