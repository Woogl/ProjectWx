02데미지 입력값

기획자가 공격 노티파이에서 직접 고르는 값들. 수치·토글 파라미터는 위 표, HitReact 태그는 아래 표로 나눠 정리했다.

파라미터

파라미터 기본값 의미 체감
공격력 계수 1.0 ATK에 곱해지는 배율. 데미지의 핵심 다이얼 약공격 0.7 · 기본 공격 1.0 · 강공격 1.5~2.0 · 스킬 2~4 · 궁극기 5+
MP 회복 0 적중 시 공격자가 얻는 마나량 0이면 회복 없음. 기본 공격에 소량 주면 마나 순환이 생긴다
UP 회복 0 적중 시 공격자가 얻는 궁극기 게이지량 0이면 회복 없음. 기본 공격에 소량 주면 궁극기 회전율이 올라간다
HitReact 태그 Normal 피격자에게 강제할 리액션 종류 Normal은 강인도가 버텨주지만, Knock 계열은 무조건 경직시킨다
가드 불가 false 일반 가드를 무시하고 그대로 들어가는 공격 가드 위주 상대를 흔드는 용도. 남발하면 가드 자체가 의미 없어진다
추가 이펙트 — 데미지와 함께 부여할 상태이상/디버프 목록 출혈·화상·둔화 같은 지속 효과를 얹고 싶을 때 사용

HitReact 태그

태그 플레이어 체감 언제 쓰나
Normal 강인도로 버티다가 소진 시에만 짧은 경직. 평상시엔 흔들림만 기본 공격, 연타 중간 히트
Knockback 뒤로 크게 밀려난다. 콤보 연결이 끊긴다 강공격 마무리, 밀치기, 카운터 반격
Knockdown 넘어져서 바닥에 눕는다. 일어나는 시간 동안 무방비 스윕, 내려찍기, 강한 일격의 피니시
Knockup 공중으로 떠오른다. 공중 콤보로 이어가기 좋은 상태 어퍼컷, 공중 콤보 시동기
