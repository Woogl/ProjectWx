# 리스폰 시스템 기획서

## 1. 문서 개요

WX 던전 내 플레이어 사망 후 부활 및 배치물의 리젠 시스템의 규칙, 동작 방식, 장치 및 적별 초기화 기준을 정의한다. 

---

## 2. 용어 정의

**리스폰 (respwan)**
부활 시스템과 리젠 시스템을 통칭한다.

**부활 (resurrection)**
플레이어가 사망한 후 가장 최근에 활성화된 체크포인트에서 다시 시작하는 전체 과정을 의미한다.

부활은 사망을 통해서만 발생한다. 현재 기획 기준으로 자발적 귀환 기능은 없다.

**리젠 (Regen)**
던전 내 스포너블 및 일반 적들이 다시 등장하는 것을 의미한다. 리젠은 두 가지 상황에서 발생한다.

- **사망 부활 시:** 부활 프로세스의 일부로 자동 처리된다.
- **체크포인트 상호작용 시:** 플레이어가 F키로 체크포인트를 사용할 때 발생한다. 플레이어는 제자리에서 회복되며, 동시에 스포너블이 리젠된다.

두 경우 모두 리젠 대상과 유지되는 항목의 규칙은 동일하다. 대상 여부는 섹션 5에서 정의한다.

---

## 3. 리스폰 규칙

부활은 가장 최근에 활성화된 체크포인트를 기준으로 처리된다.

**리젠 대상:** 던전 내 모든 스포너블. 사망 부활 시에는 페이드 전환 중에 즉시 재배치된다. 체크포인트 상호작용 시에는 플레이어가 제자리에 있는 상태에서 즉시 재배치된다.

**유지되는 것:** 플레이어가 상호작용으로 변경한 기믹  상태(레버, 문, 엘리베이터 활성화), 네임드 적 처치 여부, 상자 개봉 여부, 체크포인트 활성화 여부. 

**플레이어 상태:** 부활 시 HP/MP 전량 회복.

**던전 재진입 시:** 사망 부활과 동일한 규칙을 따른다. 저장 데이터를 기준으로 상태가 복원되며, 일반 적은 다시 등장하고 유지 항목은 그대로 유지된다.

---

## 4. 부활 진행 흐름

플레이어 HP가 0이 되면 아래 순서로 처리된다.

1. 사망 처리 — 플레이어 HP 0 감지
2. 페이드 아웃
3. 저장 데이터 로드 — 마지막 활성 체크포인트 기준
4. 초기화 처리 — 일반 적 즉시 재배치
5. 플레이어 위치를 체크포인트 위치로 이동
6. HP/MP 전량 회복
7. 페이드 인

## 5. 리스폰 대상 및 예외

### 5.1 적

| 대상 | 리젠 | 비고 |
|---|:---:|---|
| 일반 적 | O | 부활 시 던전 내 모든 구역의 일반 적 즉시 재배치 |
| 스포너 (레버) 소환 적 | X | 레버가 재작동되지 않으므로 소환 조건 자체가 사라짐 |
| 네임드 적 | X | 한 번 처치하면 영구 제거 |
| 보스 | X | 소멸·재생성되지 않음. 단, 플레이어 사망 후 재도전 시 보스 HP 전량 초기화 |

### 5.2 장치

| 대상 | 상태 유지 | 비고 |
|---|:---:|---|
| 레버 | O | 작동한 레버는 되돌아오지 않음. |
| 문 | O | 레버로 열린 문은 열린 채 유지 |
| 엘리베이터 | O | 활성화된 엘리베이터는 계속 사용 가능 |
| 체크포인트 | O | 활성화된 체크포인트는 유지 |
| CCTV 관측기 | O | 반복 열람 가능 |
| 상자 (Normal / Special) | O | 개봉 후 영구 소비. 종류 무관하게 동일 규칙 적용 |
| 레이저 통로 | — | 리스폰 규칙 적용 대상 아님. 레벨 시작부터 일정 주기로 작동하며 사망과 무관하게 항상 동일하게 작동 |
