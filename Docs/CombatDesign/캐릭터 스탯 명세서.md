# PC 스탯 명세서 초안

## 1. 문서 개요

본 문서는 프로젝트 WX의 **PC 및 전투 대상 공통 스탯 규격**을 정의하기 위한 초안이다.

PC 규격서에서 정의한 공통 자원, 회피, 극한회피, 가드, 패링, 전투 루프를 기반으로 하며, 언리얼 데이터 테이블 `DT_CharacterAttribute`에 존재하는 스탯 항목과 기획상 추가 예정인 스탯을 함께 정리한다.

본 문서의 목적은 다음과 같다.

- 스탯의 의미를 명확히 정의한다.
- 현재값 / 최대값 스탯의 관계를 정리한다.
- PC와 적이 사용하는 스탯을 구분한다.
- 전투 시스템, 어빌리티 시스템, UI, 밸런스 작업에서 같은 기준을 사용하도록 한다.
- 아직 의미가 확정되지 않은 스탯은 가칭으로 표시하여 추후 결정 사항을 분리한다.

---

## 2. 스탯 표기 규칙

문서 내 스탯명은 코드 / 데이터 기준 표기를 우선 사용한다.

| 문서 표기 | 에디터 표시 예시 | 설명 |
|---|---|---|
| `MaxHP` | `Max HP` | HP의 최대값 |
| `CritRate` | `Crit Rate` | 치명타 확률 |
| `CritDMG` | `Crit DMG` | 치명타 피해량 |

에디터에서 띄어쓰기가 들어간 컬럼으로 보이더라도, 본 문서에서는 가독성과 명세 통일을 위해 붙여 쓴 표기를 사용한다.

## 4. 스탯 공통 규칙

### 4.1 현재값 / 최대값 관계

`HP`, `MP`, `UP`, `SP`, `DP`는 현재값과 최대값의 쌍으로 관리한다.

| 현재값 | 최대값 | 기본 규칙 |
|---|---|---|
| `HP` | `MaxHP` | `0 <= HP <= MaxHP` |
| `MP` | `MaxMP` | `0 <= MP <= MaxMP` |
| `UP` | `MaxUP` | `0 <= UP <= MaxUP` |
| `SP` | `MaxSP` | `0 <= SP <= MaxSP` |
| `DP` | `MaxDP` | `0 <= DP <= MaxDP` |


공통 처리 규칙은 다음과 같다.

- 현재값은 최대값을 초과할 수 없다.
- 현재값은 0 미만으로 내려가지 않는다.
- 최대값이 0인 스탯은 해당 캐릭터 / 대상이 그 시스템을 사용하지 않는 것으로 본다.
- 최대값이 0인 스탯에 대한 충전 / 회복 / 감소 처리는 무시하거나 별도 예외 처리한다.
- 최대값이 변경될 경우, 현재값 보정 방식은 시스템별로 정의한다.

### 4.2 최대값 변경 시 권장 처리

| 상황 | 권장 처리 |
|---|---|
| 최대값 증가 | 현재값은 유지. 필요 시 별도 회복 효과로 증가 |
| 최대값 감소 | 현재값이 새 최대값을 초과하면 새 최대값으로 보정 |
| 전투 시작 | 데이터 테이블 Row 기준으로 초기값 세팅 |
| 리스폰 / 재도전 | 전투 대상의 초기값 재적용 |

## 5. 개별 스탯 명세

### 5.1 HP / MaxHP

#### 정의

`HP`는 캐릭터의 현재 생존 수치이다. `MaxHP`는 HP의 최대값이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙

- 피격 시 `HP`가 감소한다.
- `HP`가 0이 되면 사망 어빌리티를 실행한다.
- PC는 자연 회복을 기본으로 가지지 않는다.
- 회복은 아이템, 스킬, 특정 기믹에 의해 발생한다.
- `HP`는 `MaxHP`를 초과할 수 없다.

#### 처리 예시

```text
최종 피해량 계산
→ 대상 HP 감소
→ HP가 0 이하인지 검사
→ 0 이하라면 사망 어빌리티 실행
```

---

### 5.2 MP / MaxMP

#### 정의

`MP`는 PC가 스킬을 사용하기 위해 소비하는 현재 자원이다. `MaxMP`는 MP의 최대값이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 미사용 |

#### 기본 규칙

- 공격 적중 시 MP를 획득할 수 있다.
- 패링 성공 시 MP를 획득할 수 있다.
- 극한회피 성공 시 MP를 획득할 수 있다.
- 스킬 사용 시 MP를 소모한다.
- 스킬 코스트보다 보유한 MP가 부족하면 사용할 수 없다.
- `MP`는 `MaxMP`를 초과할 수 없다.

#### 설계 의도

MP는 시간이 지나면 자동으로 차는 자원이 아니라, 공격과 정확한 방어 성공을 통해 얻는 자원이다.

#### 처리 예시

```text
약공격 적중
→ MP 획득량 계산
→ MP += 획득량
→ MP를 MaxMP 이하로 보정
```

```text
스킬 입력
→ 필요 MP 확인
→ MP가 충분하면 스킬 발동
→ MP -= 스킬 소모량
```

---

### 5.3 UP / MaxUP

#### 정의

`UP`는 궁극기 발동을 위한 현재 자원이다. `MaxUP`는 궁극기 사용 가능 기준이 되는 최대값이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 미사용 |

#### 기본 규칙

- 스킬 발동 또는 스킬 적중 시 UP를 획득할 수 있다.
- UP 충전 조건은 캐릭터별 문서에서 정의한다.
- `UP >= MaxUP` 상태가 되면 궁극기 사용 가능 상태가 된다.
- 궁극기 사용 시 UP를 전량 소모한다.
- `UP`는 `MaxUP`를 초과할 수 없다.

#### 처리 예시

```text
스킬 적중
→ UP 획득량 계산
→ UP += 획득량
→ UP가 MaxUP 이상이면 궁극기 사용 가능 상태 표시
```

```text
궁극기 사용
→ UP가 MaxUP 이상인지 확인
→ 궁극기 발동
→ UP = 0
```

---

### 5.4 SP / MaxSP

#### 정의

`SP`는 일반 가드에 소모되는 방어 자원이다. `MaxSP`는 SP의 최대값이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 미사용 |

#### 기본 규칙

- 가드 상태에서 공격을 받으면 피해가 경감된다.
- 일반 가드는 피해를 50% 경감한다.
- 일반 가드 상태에서 공격을 받으면 **경감된 피해량만큼** SP를 소모한다.
- SP가 0이 되면 가드는 즉시 해제된다.
- SP가 0이 된 PC는 1초간 그로기 상태에 빠진다.
- 그로기 상태에서는 모든 조작이 불가능하다.
- 가드 상태 해제 후 SP 회복이 시작된다.
- 회복 시작 후 4초가 지나면 SP가 전부 회복된다.
- SP를 초과한 피해는 별도로 적용하지 않는다.

#### 처리 예시

```text
피해량 40의 공격을 가드
→ HP 피해량 = 20
→ SP 소모량 = 20
→ SP -= 20
```

```text
SP가 0 이하가 됨
→ 가드 해제
→ 그로기 1초 적용
→ 조작 불가
```

#### 설계 의도

SP는 일반 가드를 무한히 유지하지 못하게 만드는 제한 자원이다. 초보자는 가드로 생존할 수 있지만, 장기적으로는 패링과 회피를 섞어야 한다.

---

### 5.5 DP / MaxDP

> 현재 가칭: Down Point / Daze Point / Stagger Point

#### 정의

`DP`는 적의 스태거, 다운, 브레이크 등 피격 누적 상태를 표현하기 위한 현재 누적값이다. `MaxDP`는 DP의 최대 누적 기준이다.

PC 규격서에서 패링 성공 시 적의 스태거 게이지를 쌓는다고 정의되어 있으므로, `DP`는 해당 스태거 게이지의 구현 후보로 볼 수 있다.

#### 사용 대상

| PC | 적 |
|---|---|
| 미사용 | 사용 |

#### 기본 규칙 초안

- 적이 특정 공격에 피격되면 DP가 증가한다.
- 패링 성공 시 대상의 DP가 증가한다.
- DP가 `MaxDP`에 도달하면 그로기 상태가 발생한다.
- 상태 발생 후 천천히 회복되며 5초 후 스태거 게이지는 0이되며 그로기 상태에서 회복된다.
- 보스는 일반 적보다 `MaxDP`를 높게 설정하여 스태거 발생 빈도를 조절할 수 있다.

#### DP와 PP의 차이

| 항목 | DP | PP |
|---|---|---|
| 목적 | 누적형 그로기 관리 | 순간 피격 경직 저항 관리 |
| 사용 대상 | 적 중심 | PC / 적 모두 사용 |
| 처리 방식 | 공격이나 패링으로 누적 증가 | 공격 경직치와 대상 PP 비교 |
| 발생 조건 | `DP >= MaxDP` | `공격 경직치 >= 대상 현재 PP` |
| 결과 | 그로기 | 해당 공격의 히트 리액션 재생 |

### 5.6 PP 

> 현재 가칭: Poise Point

#### 정의

`PP`는 캐릭터가 가진 경직 저항 수치이다. 

공격을 받으면 해당 공격의 `경직치`와 대상의 현재 `PP`를 비교한다.  
공격의 경직치가 대상의 현재 `PP` 이상이면 경직이 발생한다.

캐릭터는 특정 어빌리티를 사용하는 동안 자신의 `PP`를 일시적으로 증가시킬 수 있다.
#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙 초안

- 캐릭터가 공격을 받으면 해당 공격의 경직치와 `PP`를 비교한다.
- `PP` 이상의 경직치를 가진 공격에는 히트 리액션이 재생된다.
- `PP`보다 낮은 경직치를 가진 공격에는 히트 리액션이 재생되지 않는다.


#### 처리 예시

```text
대상 PP 30
→ 경직치 10의 공격 피격
→ 공격 경직치 < 대상 PP
→ 대상 PP가 더 높으므로 경직 없음
```

```text
대상 PP 10
→ 경직치 15의 공격 피격
→ 공격 경직치 >= 대상 PP
→ 해당 공격의 히트 리액션 재생
```

```text
대상 기본 PP 30
→ 보스가 공격 어빌리티 사용 중 PP +60
→ 현재 PP 90
→ 경직치 30의 일반 공격 피격
→ 공격 경직치 < 현재 PP
→ 보스 공격은 끊기지 않음
```

```text
대상 기본 PP 30
→ 보스가 공격 어빌리티 사용 중 PP +60
→ 현재 PP 90
→ 경직치 100의 스킬 공격 피격
→ 공격 경직치 >= 현재 PP
→ 보스 공격은 끊김
→ 해당 공격의 히트 리액션 재생
```

### 5.7 ATK

#### 정의

`ATK`는 공격자의 기본 공격력이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙 초안

- 피해량 계산 시 공격자의 `ATK`를 참조한다.
- 스킬별 피해 계수와 결합하여 최종 피해량 계산에 사용한다.
- 실제 최종 피해 공식은 별도 `DamageSpec` 또는 전투 공식 문서에서 정의한다.

#### 처리 예시

```text
기본 피해량 = 공격자 ATK * 어빌리티 피해 계수
```

해당 공식은 임시 예시이며, 최종 전투 공식은 별도 확정이 필요하다.

---

### 5.8 DEF

#### 정의

`DEF`는 대상의 기본 방어력이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙 초안

- 피격 피해량 계산 시 대상의 `DEF`를 참조한다.
- 방어력은 피해량을 감소시키는 역할을 한다.
- 실제 감소 공식은 별도 전투 공식 문서에서 정의한다.

#### 처리 예시

```text
최종 피해량 = 피해 공식 결과 - 대상 DEF 보정량
```

방어력이 피해를 지나치게 0으로 만들지 않도록 최소 피해량 규칙을 둘지 결정해야 한다.

#### 결정 필요 사항

| 항목 | 결정 필요 내용 |
|---|---|
| 방어 공식 | 감산식, 비율식, 레벨 보정식 중 선택 |
| 최소 피해량 | 최소 1 피해 보장 여부 |
| 가드와 관계 | 가드 50% 경감 전 / 후 어느 시점에 DEF를 적용할지 |
| 치명타와 관계 | 치명타 피해 계산 전 / 후 어느 시점에 DEF를 적용할지 |

---

### 5.9 CritRate

#### 정의

`CritRate`는 치명타가 발생할 확률이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 기본 미사용 |

#### 기본 규칙 초안

- 공격 적중 시 치명타 판정을 수행한다.
- `CritRate` 값은 `%` 단위로 해석한다.
- `CritRate`는 기본적으로 0~100 범위로 제한한다.
- 100%를 초과하면 100%로 취급한다.

#### 처리 예시

```text
공격 적중
→ 0~100 난수 생성
→ 난수 값이 CritRate 이하이면 치명타 발생
```

---

### 5.10 CritDMG

#### 정의

`CritDMG`는 치명타 발생 시 추가로 적용되는 피해 증가량이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 기본 미사용 |

#### 기본 규칙 초안

- 치명타 발생 시 최종 피해량에 `CritDMG` 보정을 적용한다.
- `CritDMG`는 `%` 단위로 해석한다.
- 현재 기준에서는 `CritDMG` 50을 기본 피해량의 50% 추가 피해로 해석한다.

#### 값 해석 예시

| 값 | 의미 |
|---:|---|
| 50 | 기본 피해량의 50% 추가 피해 |
| 100 | 기본 피해량의 100% 추가 피해 |

#### 처리 예시

```text
치명타 피해량 = 기본 피해량 * (1 + CritDMG / 100)
```

```text
기본 피해량 100, CritDMG 50
→ 100 * (1 + 50 / 100)
→ 150 피해
```

### 5.11 SPD

#### 정의

`SPD`는 캐릭터의 이동 속도에 영향을 주는 속도 계수이다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙 초안

| 값 | 의미 |
|---:|---|
| 1.0 | 기본 이동 속도 |
| 0.5 | 기본의 50% 이동 속도 |
| 1.5 | 기본의 150% 이동 속도 |
| 2.0 | 기본의 200% 이동 속도 |

#### 적용 범위

- 이동 속도 보정

#### 주의 사항

- `SPD`는 이동 속도에만 적용한다.
- 공격 AM 재생 속도는 `ASPD`에서 별도로 관리한다.
- 회피, 가드, 패링, 사망, 피격 리액션 등 판정 안정성이 중요한 AM에는 직접 적용하지 않는다.

---

### 5.12 ASPD

#### 정의

`ASPD`는 캐릭터의 공격 AM 재생 속도에 영향을 주는 속도 계수이다.

AM은 Animation Montage를 의미하며, 본 문서에서는 공격 어빌리티에 사용되는 애니메이션 몽타주를 기준으로 한다.

#### 사용 대상

| PC | 적 |
|---|---|
| 사용 | 사용 |

#### 기본 규칙 초안

| 값 | 의미 |
|---:|---|
| 1.0 | 기본 공격 AM 속도 |
| 0.5 | 기본의 50% 공격 AM 속도 |
| 1.5 | 기본의 150% 공격 AM 속도 |
| 2.0 | 기본의 200% 공격 AM 속도 |

#### 적용 범위

- 공격 AM 속도 보정

#### 적용 제외

다음 AM은 `ASPD`의 영향을 받지 않는다.

- 가드 AM
- 회피 AM
- 사망 AM

#### 주의 사항

- `ASPD`를 적용하면 공격 판정 타이밍, 콤보 입력 타이밍, 캔슬 가능 타이밍이 함께 흔들릴 수 있다.
- 따라서 `ASPD`가 적용되는 공격 AM은 판정 발생 시점과 입력 가능 구간을 함께 검증해야 한다.
- 방어, 회피, 사망처럼 전투 안정성과 직결되는 AM은 `ASPD`의 영향을 받지 않도록 분리한다.

## 6. 전투 처리 흐름 내 스탯 사용

### 6.1 기본 피해 처리 흐름 초안

```text
1. 공격 어빌리티 발동
2. 공격 판정 발생
3. 대상 피격 판정 성공
4. 공격자의 ATK와 어빌리티 피해 계수 확인
5. 대상의 DEF 확인
6. 치명타 판정 확인
7. 가드 / 패링 / 회피 여부 확인
8. 최종 피해량 계산
9. 대상 HP 감소
10. 필요 시 PP 비교
11. 필요 시 DP 증가
12. HP 0 여부, pp비교, DP Max 도달 여부 확인
13. 사망 / 경직 / 스태거 / 그로기 / 넉다운 등 상태 전환
```

### 6.2 패링 성공 시 스탯 처리 초안

```text
1. 적 공격이 PC에게 적중하기 직전 가드 입력 성공
2. 패링 성공 판정
3. PC HP 피해 무효화
4. PC SP 소모 없음
5. PC MP 획득
6. 공격자 또는 대상의 DP 증가
7. 패링 성공 애니메이션 / 이펙트 출력
8. 후속 반격 또는 연계 가능 상태 진입
```

### 6.3 일반 가드 성공 시 스탯 처리 초안

```text
1. PC가 가드 키를 홀드한 상태에서 피격
2. 패링 타이밍이 아니므로 일반 가드 처리
3. 피해량 50% 경감
4. 경감된 피해량만큼 SP 소모
5. 남은 피해량만큼 HP 감소
6. SP가 0이면 가드 해제 및 1초 그로기
```

### 6.4 극한회피 성공 시 스탯 처리 초안

```text
1. 적 공격 적중 직전 회피 입력 성공
2. 극한회피 판정
3. 피격 회피
4. MP 획득
5. 회피 스택 1 회복
6. 짧은 슬로우 / 전용 애니메이션 출력
7. 회피 반격 또는 캐릭터별 후속 연계 가능
```
