# 보스 공통 BT 기획 초안

## 1. 문서 목적

본 문서는 보스 몬스터의 **공통 BT(Behavior Tree) 설계 기조**를 정의한다.  
개별 보스는 본 문서의 상위 규칙을 기반으로, 각 보스의 콘셉트와 패턴에 맞는 세부 BT를 추가 설계한다.

본 문서는 다음 내용을 다룬다.

- 보스 BT의 상위 우선순위 구조
- 패턴군 분류 방식
- 패턴군 선택 기준
- 패턴 재사용 제한 방식
- 전투 루프에서의 기본 행동 흐름

---

## 2. BT 설계 기본 방향성

보스 BT는 개별 패턴을 직접 나열하는 구조보다,  
**패턴군을 먼저 선택한 뒤 그 안에서 실제 패턴을 결정하는 구조**를 기본으로 한다.

이를 통해 다음을 기대한다.

- 상위 우선순위가 명확한 BT 구성
- 패턴 추가 및 교체가 쉬운 확장 구조
- 같은 패턴 반복을 줄이고 전투 리듬을 안정적으로 유지
- 개별 보스 기획 시 공통 문법 위에 차별화를 얹기 쉬움

---

## 3. 상위 행동 우선순위

보스 BT의 상위 우선순위는 아래 순서를 기본으로 한다.

1. **페이즈 전환 패턴**
2. **거리 조정 패턴**
3. **강공격 패턴군**
4. **일반공격 패턴군**
5. **비공격 행동 패턴** (도발 / 타겟 재설정 등)

이 우선순위는 상위 Selector 기준으로 판단한다.  
상위 노드가 실패할 경우, 다음 우선순위 노드로 넘어간다.

---

## 4. 상위 패턴군 정의

### 4.1 페이즈 전환 패턴
보스의 체력이 특정 기준 이하로 내려갔을 때 발동하는 전환 패턴.

역할:
- 페이즈 전환 연출 실행
- 새로운 패턴 테이블 또는 BT로 전환
- 전투 흐름 재정의

기본 규칙:
- 상위 우선순위 1순위
- 체력 조건 충족 시 가장 먼저 검사
- 동일 페이즈 전환은 중복 발동하지 않도록 1회성 체크 필요

예시:
- HP 70% 이하 진입 시 Phase 2 전환기
- HP 30% 이하 진입 시 Phase 3 전환기

---

### 4.2 거리 조정 패턴
플레이어가 유효 공격 거리 밖에 있을 때 사용하는 위치 보정 행동.

역할:
- 보스와 플레이어의 전투 거리 재성립
- 공격 가능한 상태로 복귀
- 전투 흐름 공백 방지

포함 가능 행동:
- 추격
- 돌진 접근
- 점프 접근
- 위치 재정렬
- 짧은 거리 압박 후 재진입

기본 규칙:
- 페이즈 전환 조건이 아닐 때 검사
- 플레이어가 유효 공격 거리 밖일 경우 우선적으로 실행
- 공격 패턴보다 먼저 판단한다

---

### 4.3 강공격 패턴군
보스의 강한 공격군. 일반공격보다 높은 위협을 가지며, 재사용 제한을 둔다.

역할:
- 플레이어에게 명확한 대응 판단 강요
- 전투 긴장감 상승
- 기본 공격 루프와 차별되는 위협 제공

포함 가능 행동:
- 넓은 범위의 강타
- 대응 타이밍을 강하게 요구하는 공격
- 브레이크/그로기 누적 압박이 큰 공격
- 연속 강압 패턴

기본 규칙:
- 거리 조건 충족 시 검사
- 쿨타임 또는 재사용 제한이 끝났을 때만 후보로 사용
- 같은 강공격의 연속 사용은 제한 가능
- 실제 실행 전에는 패턴군 내부에서 후보를 선택한다

---

### 4.4 일반공격 패턴군
보스의 기본 루프를 구성하는 가장 빈번한 공격군.

역할:
- 전투의 기본 리듬 형성
- 플레이어에게 회피/패링/가드 학습 기회 제공
- 상위 패턴이 불가능할 때 fallback 행동으로 동작

포함 가능 행동:
- 짧은 일반 공격
- 기본 2~3타 연속 공격
- 기본 견제 공격
- 짧은 연계 공격

기본 규칙:
- 별도 쿨타임 없이 사용 가능
- 단, 같은 공격의 연속 사용은 제한
- 실제 실행 시 랜덤값과 최근 사용 패턴 체크를 통해 후보 선택
- 강공격 패턴군이 실행 불가일 경우 기본 fallback 루프로 작동

---

### 4.5 비공격 행동 패턴
도발, 타겟 재설정 등 직접적인 공격이 아닌 행동군.

역할:
- 전투 리듬 환기
- 타겟 보정
- 패턴 흐름 재정렬
- 전투 중 짧은 연출적 완급 조절

포함 가능 행동:
- 도발
- 포효
- 타겟 재설정
- 짧은 준비 동작
- 전투 중 비공격성 상태 전환

기본 규칙:
- 메인 공격 루프보다 우선하지 않음
- 특정 조건 또는 낮은 우선순위에서 실행
- 과도한 빈도로 발생하지 않도록 제한 필요

---

## 5. 상위 BT 구조 초안

보스의 상위 BT는 Selector 기반으로 아래처럼 구성한다.

### Root Selector
1. Phase Transition Sequence
2. Reposition Sequence
3. Heavy Attack Sequence
4. Normal Attack Sequence
5. Utility / Taunt Sequence

---

## 6. 각 Sequence의 기본 구조

### 6.1 Phase Transition Sequence
- 체력 조건 확인
- 해당 페이즈 전환 미사용 여부 확인
- 페이즈 전환 패턴 실행
- 페이즈 값 갱신
- 다음 페이즈용 BT 또는 패턴 테이블로 전환

---

### 6.2 Reposition Sequence
- 플레이어가 유효 공격 거리 밖인지 확인
- 거리 조정 가능 상태인지 확인
- 거리 조정 패턴 실행

---

### 6.3 Heavy Attack Sequence
- 플레이어가 강공격 유효 거리 안인지 확인
- 강공격 패턴군의 재사용 제한 해제 여부 확인
- 사용 가능한 강공격 후보 수집
- 최근 사용 패턴 제외
- 후보 중 1개 선택
- 강공격 실행
- 강공격 재사용 제한 시작

---

### 6.4 Normal Attack Sequence
- 사용 가능한 일반공격 후보 수집
- 최근 사용 패턴 제외
- 후보 중 1개 선택
- 일반공격 실행

---

### 6.5 Utility / Taunt Sequence
- 도발 또는 타겟 재설정 필요 여부 확인
- 사용 가능 조건 충족 시 실행

---

## 7. 패턴 선택 규칙

### 7.1 페이즈 전환 패턴
선택 조건:
- 체력 임계치 이하
- 해당 페이즈 전환 미사용
- 전환 중이 아님

---

### 7.2 거리 조정 패턴
선택 조건:
- 플레이어가 유효 공격 거리 밖
- 현재 다른 상위 우선순위 행동을 수행 중이 아님

---

### 7.3 강공격 패턴군
선택 조건:
- 플레이어가 강공격 유효 거리 안
- 강공격 재사용 제한 종료
- 최근 사용 패턴과 중복되지 않음

---

### 7.4 일반공격 패턴군
선택 조건:
- 상위 패턴군이 실행되지 않음
- 일반공격 후보가 존재함
- 최근 같은 공격을 사용하지 않음

---

### 7.5 비공격 행동 패턴
선택 조건 예시:
- 특정 시간 동안 패턴 루프 반복
- 타겟 유실 또는 타겟 재설정 필요
- 특정 패턴 종료 후 저확률
- 특정 페이즈 진입 후 1회

---

## 8. 패턴군 내부 선택 방식

보스의 실제 행동은 상위 패턴군이 선택된 뒤,  
해당 패턴군 내부에서 후보를 추린 후 최종 선택한다.

기본 원칙:
- 사용 가능한 패턴만 후보로 포함
- 최근 사용 패턴 제외
- 같은 패턴 연속 사용 금지 가능
- 남은 후보 중 랜덤 또는 가중치 기반 선택 가능

---

## 9. 현재 기준 보스 전투 루프 해석

현재 구조를 전투 흐름으로 풀면 다음과 같다.

1. 체력 조건이 충족되면 즉시 페이즈 전환기를 사용한다
2. 플레이어가 멀리 있으면 거리 조정 패턴으로 전투 거리를 다시 맞춘다
3. 공격 거리 안에 있고 강공격 조건이 충족되면 강공격 패턴군을 우선 사용한다
4. 강공격이 불가능하면 일반공격 패턴군 중 하나를 사용한다
5. 필요 시 도발 또는 타겟 재설정 행동으로 전투 흐름을 조정한다

즉 보스는  
**전투 전환 → 거리 성립 → 고위협 패턴 → 기본 루프**  
순으로 행동한다.

---

## 10. 현재 구조의 장점

- 상위 우선순위가 명확함
- 전투 거리 문제를 먼저 해결함
- 강공격 남용을 쿨타임으로 제어 가능
- 일반공격을 fallback 루프로 사용 가능
- 도발/타겟 재설정을 메인 공격 루프와 분리 가능
- 패턴 추가 시 패턴군 단위 확장 가능

---

## 11. 추후 세부화가 필요한 항목

다음 항목은 이후 개별 보스 기획 또는 BT 상세 문서에서 구체화한다.

- 유효 공격 거리 기준값
- 강공격 패턴군 내부 후보 목록
- 일반공격 패턴군 내부 후보 목록
- 최근 사용 패턴 체크 방식
- 랜덤 / 가중치 선택 규칙
- 도발 패턴의 실행 조건
- 페이즈별 BT 교체 방식
- 그로기 상태 처리 여부 및 상위 우선순위 반영 방식
