# PC 규격 정리

## 1. 문서 개요

본 문서는 프로젝트의 **PC 규격**을 정리한 문서이다.  
모든 플레이어블 캐릭터 전투 설계는 본 문서의 규칙을 기반으로 구축한다.

본 문서는 개별 캐릭터 기획서가 아니라, 다음 요소를 정의하는 **PC 규격 문서**이다.

- 전투 컨셉 및 핵심 방향성
- 공통 자원 규격
- 공통 액션 규격
- 공통 회피 / 극한회피 규격
- 공통 가드 / 패링 규격
- 전투 전반의 리듬과 설계 의도

---

## 2. 전투 컨셉

### 2.1 장르 / 전투 방향성
- 장르: 3인칭 백뷰 액션 RPG
- 전투 기조: 고속 액션, 짧은 판단, 빠른 공방 전환
- 목표 감각: **초인적 전사의 감각**
  - 총알을 피한다
  - 날아오는 마법을 베어낸다
  - 공격 도중에도 방어 판단을 이어간다
  - 짧은 빈틈에 고화력을 꽂는다

### 2.2 전투의 핵심 철학
본 프로젝트의 전투는 복잡한 커맨드 입력보다,  
**전투 상황을 읽고 즉시 대응하는 판단 중심 액션**을 목표로 한다.

핵심은 다음과 같다.

- 평타와 강공격을 활용한 직관적인 전투 문법
- 공격 도중에도 이어지는 방어 선택
- 회피 / 패링 / 가드의 명확한 역할 분리
- 숙련될수록 더 큰 보상을 받는 방어 시스템
- 모든 캐릭터가 같은 공통 문법 위에 고유 플레이를 얹는 구조

---

## 3. 공통 자원 규격

### 3.1 HP
캐릭터의 생존 수치.

- 피격 시 감소
- 0이 되면 전투 불능
- 자연 회복 없음
- 회복은 아이템 또는 특정 스킬에 의존

### 3.2 MP
스킬 발동 자원.

- 공격 적중
- 패링 성공
- 극한회피 성공

등을 통해 수급한다.

- 캐릭터 스킬 발동 시 소모한다

### 3.3 UP (Ultimate Point)
궁극기 발동 자원.

- 스킬 발동, 혹은 적에게 적중할 때 충전(충전 조건은 캐릭터 개별 문서에서 작성)
- 최대치 도달 시 궁극기 사용 가능
- 궁극기 사용 시 전량 소모

### 3.4 SP (Shield Point)
일반 가드에 소모되는 자원.

- 일반 가드 상태에서 공격을 받으면 감소한다
- SP가 0인 상태에서 일반 가드로 피격 시 가드가 풀리고 판정에 따른 히트 리액션이 발생하며, 피해 경감률이 감소한다
- 가드를 해제한 뒤 1초 후부터 자동 회복을 시작한다
- 회복 시작 후 4초가 지나면 전부 회복된다

## 4. 공통 액션 규격

액션은 PC가 조작을 통해 수행하거나, 특정 조건에 의해 발생하는 모든 동작을 의미한다.  
본 문서에서는 액션을 전투 액션, 이동 액션, 상태 액션으로 구분한다.

모든 플레이어블 캐릭터는 아래 공통 액션 규격을 공유한다.

- 전투 액션
- 이동 액션
- 상태 액션
- 히트 리액션

### 4.1 전투 액션

#### 4.1.1 약공격
- 가장 빠르고 기본적인 공격 수단
- MP 수급의 주요 기반
- 연계의 시작점

#### 4.1.2 강공격
- 약공격보다 더 무겁고 강한 공격
- 약공격과 조합하여 연계 공격 가능
- 캐릭터별 연계의 피니시, 절단, 마무리 역할을 주로 담당

#### 4.1.3 스킬
- 캐릭터별 고유 액션
- MP를 사용하여 발동
- 강한 피해, 유틸리티, 전장 제어, 강화 효과 등을 담당

#### 4.1.4 궁극기
- UP 최대치에서만 사용 가능
- 전황을 뒤집는 고가치의 액션
- 궁극기는 원칙적으로 캔슬할 수 없다

#### 4.1.5 연계
- 약공격과 강공격은 조합하여 연속 공격을 구성할 수 있다
- 연계는 각 캐릭터의 기본 전투 리듬을 형성하는 핵심 구조이다
- 연계의 구체적인 구성은 캐릭터별 기획에서 정의한다

#### 4.1.6 회피
- 기본 회피 액션
- PC의 주된 회피 수단이다

#### 4.1.7 극한회피
- 정확한 타이밍에 회피 성공 시 발동하는 특수 회피 액션

#### 4.1.8 가드
- 가드 상태에서 공격을 받아 피해를 경감하는 방어 액션

#### 4.1.9 패링
- 저스트 가드 성공 시 발동하는 특수 방어 액션

### 4.2 이동 액션

#### 4.2.1 걷기
- 캐릭터가 걷는 상태
- 기본 이동 상태이며 대부분의 액션으로 전환 가능하다

#### 4.2.2 뛰기
- 캐릭터가 뛰는 상태
- 빠른 이동 상태이며 대부분의 액션으로 전환 가능하다

#### 4.2.3 점프
- 캐릭터가 점프하여 공중에 있는 상태
- 일부 액션 사용이 제한된다

### 4.3 상태 액션
상태 액션은 플레이어의 조작 없이 특정 조건 충족 시 발생하는 상태 변화를 의미한다.

#### 4.3.1 기상
- 넉다운 상태 이후 일정 시간이 지나 다시 일어나는 상태

#### 4.3.2 일반 대기
- 적을 인식하지 않았고, 별도의 입력도 없는 상태

#### 4.3.3 전투 대기
- 적을 인식한 상태에서, 별도의 액션을 수행하지 않고 전투를 준비하는 상태

#### 4.3.4 사망
- HP가 0이 되었을 때의 상태
- 행동할 수 없으며 게임오버 상태로 이어진다

### 4.4 히트 리액션
히트 리액션은 적의 공격에 피격되었을 때, 공격 판정에 따라 발생하는 액션이다.

#### 4.4.1 경직
- 적의 기본적인 공격에 피격당했을 때 발생하는 히트 리액션

#### 4.4.2 넉다운
- 넉다운 판정을 가진 강력한 공격에 맞아 뒤로 넘어진 히트 리액션

#### 4.4.3 에어본
- 에어본 판정을 가진 공격을 맞아 공중으로 뜬 히트 리액션
- 지면에 떨어지면 넉다운 상태로 이어진다

## 5. 공통 회피 / 극한회피 규격

### 5.1 기본 방향성
회피와 극한회피는 모든 PC가 공유하는 공통 전투 규격이다.  
회피는 플레이어의 기본적인 생존 수단이며, **회피 스택**을 통해 연속 사용 횟수를 관리한다.

이 구조의 목표는 다음과 같다.

- 스태미나 없는 게임에서도 회피 난사를 억제
- 연속 회피는 허용하되 무한 회피는 방지
- 정확한 회피 성공 여부에 따라 회피 지속력이 달라지도록 설계
- 숙련자에게는 연속 패턴 대응 보상을 제공

### 5.2 회피
회피는 PC의 기본 회피 액션이다.

기본 규칙:
- 회피는 최대 2스택을 가진다
- 회피를 사용하면 1스택을 소모한다
- 회피 스택은 1초마다 1개씩 회복된다
- 회피는 위치 이동과 생존을 위한 기본 대응 수단이다

### 5.3 극한회피
극한회피는 적 공격이 적중하기 직전에 회피를 성공시켰을 때 발동하는 특수 회피 액션이다.

발동 조건:
- 적 공격이 적중하기 직전, 저스트 타이밍에 회피 성공

기본 효과:
- 피격 회피 성공
- 화면이 짧게 슬로우로 전환된다
- 일반 회피와 다른 전용 애니메이션이 출력된다
- MP를 수급한다
- 캐릭터별 후속 연계의 기점이 될 수 있다

핵심 규칙:
- 극한회피 성공 시 회피 스택을 1 회복한다
- 회피 스택 전체를 즉시 초기화하지는 않는다

### 5.4 설계 의도
이 구조를 통해 다음 리듬을 만든다.

- 회피를 많이 쓰는 게임이 아니라, **정확하게 쓰는 게임**
- 연속 공격을 모두 피하려면 매 타이밍을 정확히 맞춰야 함
- 부정확한 회피는 다음 공격에서 리스크로 이어짐
- 숙련자는 연속 공격을 전부 흘려낼 수 있음

## 6. 공통 가드 / 패링 규격

가드와 패링은 모든 PC가 공유하는 공통 전투 규격이며, 본 장에서 해당 액션의 상세 동작 규칙과 자원 소모, 성공 조건, 보상 구조를 정의한다.

### 6.1 기본 방향성
가드와 패링은 하나의 가드 입력을 기반으로 동작한다.

- 저스트 타이밍 성공 시 패링
- 그렇지 않으면 일반 가드

이 구조의 목표는 다음과 같다.

- 입력은 단순하게 유지
- 패링을 배우기 쉽게 만들기
- 패링 실패를 완전한 실패로 두지 않기
- 일반 가드 남용은 SP로 제어하기

### 6.2 가드
가드는 가드 키를 홀드하여 유지하는 기본 방어 액션이다.

기본 효과:
- 피해를 약 50% 경감한다
- 일반 가드 상태에서 공격을 받을 때마다 SP를 소모한다
- 패링에 실패했더라도 가드 입력을 유지하고 있다면 일반 가드로 전환된다
- SP가 0인 상태에서 일반 가드로 피격 시 공격 판정에 따른 히트 리액션이 발생하며, 피해 경감률이 감소한다

설계 의도:
- 가드는 가장 쉬운 생존 수단이다
- 다만 강한 보상을 주는 수단은 아니며, SP를 소모하므로 장기적으로 의존할 수 없게 설계한다

### 6.3 패링
패링은 적 공격 적중 직전에 가드 입력에 성공했을 때 발동하는 특수 방어 액션이다.

성공 시 효과:
- 피해를 무효화한다
- 일반 가드와 다른 전용 애니메이션이 출력된다
- 적의 스태거 게이지를 쌓는다
- MP를 수급한다
- 캐릭터별 반격 및 후속 연계의 기점이 될 수 있다
- SP를 소모하지 않는다

설계 의도:
- 패링은 단순 생존이 아니라, **공격적으로 이득을 보는 방어 수단**이다
- 회피가 위치를 바꾸며 살아남는 수단이라면, 패링은 제자리에서 받아치며 전세를 뒤집는 수단이다

### 6.4 패링 실패 완충 구조
본 시스템은 패링 실패를 지나치게 가혹하게 만들지 않는다.

기본 규칙:
- 저스트 타이밍에 실패하더라도
- 가드 키를 계속 누르고 있다면
- 일반 가드로 전환되어 피해를 완전히 다 맞지는 않는다

이를 통해 다음을 기대한다.

- 유저가 패링을 시도하기 쉬움
- 학습 진입장벽이 낮아짐
- 하지만 패링 성공과 일반 가드의 보상 차이는 분명히 유지됨

## 7. 회피 / 패링 / 가드의 역할 분리

### 7.1 회피
- 위치 이동 가능
- 연속 패턴 대응에 유리
- 정확한 사용 시 회피 스택을 회복한다
- 틀리면 다음 공격 대응이 어려워진다

### 7.2 패링
- 제자리에서 받아치는 방어
- 적의 스태거 게이지를 쌓아 공격 기회를 창출
- 성공 시 공격적 이득이 큼
- 실패해도 가드로 완충 가능

### 7.3 가드
- 가장 쉬운 생존 수단
- 피해 경감 제공
- 대신 SP를 소모
- 남용 시 가드 성능 붕괴

이 세 요소는 서로 대체재가 아니라, 상황에 따라 선택되는 공통 전투 문법이다.

## 8. 전투 루프 관점의 해석

본 프로젝트의 전투 루프는 다음처럼 흐른다.

1. 약공격 / 강공격으로 전투를 전개
2. 적 공격에 대해 회피 / 패링 / 가드를 선택
3. 정확한 방어 성공 시 MP 및 전투 주도권 획득
4. 확보한 MP로 스킬 사용
5. 스킬 적중으로 UP 수급
6. UP를 통해 궁극기 사용

즉 방어는 단순 생존이 아니라,  
**공격 자원과 전투 리듬을 만들어내는 핵심 장치**다.

## 9. 설계 규격 요약

### 9.1 전 PC 액션 규격
다음 요소는 일반적으로 모든 PC가 공유한다.

- 전투 액션
- 이동 액션
- 상태 액션
- 히트 리액션

### 9.2 PC 설계 시 전제
앞으로 설계하는 모든 PC는 다음을 전제로 한다.

- 회피 / 극한회피 공통 문법 위에서 동작
- 패링 / 가드 공통 문법 위에서 동작
- 고유 기믹은 공통 방어 문법을 대체하지 않고 그 위에 추가된다
- 이동, 피격, 사망 등 기본 액션과 상태는 모든 PC가 공유한다

### 9.3 의도하는 최종 감각
- 초보자는 가드와 기본 회피로 버틴다
- 중급자는 패링과 극한회피를 섞는다
- 숙련자는 방어 성공을 통해 전투 리듬 자체를 지배한다

## 10. 한 줄 요약

**이 게임의 전투는 공통 회피 / 극한회피 / 가드 / 패링 문법 위에서, 정확한 방어 성공을 공격 기회와 자원 획득으로 연결하는 고속 액션 전투를 지향한다.**
