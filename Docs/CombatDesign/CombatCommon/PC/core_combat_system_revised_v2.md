# 공통 전투 시스템 기조 정리

## 1. 문서 개요

본 문서는 프로젝트의 **전 캐릭터 공통 전투 시스템 기조**를 정리한 문서이다.  
모든 플레이어블 캐릭터와 몬스터 설계는 본 문서의 규칙을 기반으로 구축한다.

본 문서는 개별 캐릭터 기획서가 아니라, 다음 요소를 정의하는 **공통 전투 규격 문서**이다.

- 전투 컨셉 및 핵심 방향성
- 공통 자원 구조
- 공통 액션 구조
- 공통 공격 등급 문법
- 공통 회피 / 극한회피 시스템
- 공통 가드 / 패링 시스템
- 전투 전반의 리듬과 설계 의도

---

## 2. 전투 컨셉

### 2.1 장르 / 전투 방향성
- 장르: 3인칭 백뷰 액션 RPG
- 전투 기조: 고속 액션, 짧은 판단, 빠른 공방 전환
- 목표 감각: **초인적 전사의 감각**
  - 총알을 피한다
  - 날아오는 마법을 베어낸다
  - 공격 도중에도 방어 판단을 이어간다
  - 짧은 빈틈에 고화력을 꽂는다

### 2.2 전투의 핵심 철학
본 프로젝트의 전투는 복잡한 커맨드 입력보다,  
**전투 상황을 읽고 즉시 대응하는 판단 중심 액션**을 목표로 한다.

핵심은 다음과 같다.

- 평타와 강공격을 활용한 직관적인 전투 문법
- 공격 도중에도 이어지는 방어 선택
- 회피 / 패링 / 가드의 명확한 역할 분리
- 숙련될수록 더 큰 보상을 받는 방어 시스템
- 모든 캐릭터가 같은 공통 문법 위에 고유 플레이를 얹는 구조

---

## 3. 공통 자원 구조

### 3.1 HP
캐릭터의 생존 수치.

- 피격 시 감소
- 0이 되면 전투 불능
- 자연 회복 없음
- 회복은 아이템 또는 특정 스킬에 의존

### 3.2 MP
스킬 발동 자원.

- 공격 적중
- 패링 성공
- 극한회피 성공

등을 통해 수급한다.

- 캐릭터 스킬 발동 시 소모한다

### 3.3 UP(Ultimate Point)
궁극기 발동 자원.

- MP를 소모하는 스킬이 적에게 적중할 때 충전
- 최대치 도달 시 궁극기 사용 가능
- 궁극기 사용 시 전량 소모

### 3.4 SP(Shield Point)
일반 가드의 지속 가능성을 관리하는 공통 방어 자원.

- 일반 가드로 공격을 받을 때 감소
- 0이 되면 일반 가드 성능이 크게 약화됨
- 가드 남용을 억제하는 공통 시스템으로 사용

---

## 4. 공통 액션 구조

모든 플레이어블 캐릭터는 아래 공통 액션을 공유한다.

### 4.1 일반 공격
- 가장 빠르고 기본적인 공격 수단
- MP 수급의 주요 기반
- 연계의 시작점

### 4.2 강공격
- 일반 공격보다 더 무겁고 강한 공격
- 일반 공격과 조합하여 연계 공격 가능
- 캐릭터별 연계의 피니시, 절단, 마무리 역할을 주로 담당

### 4.3 스킬
- 캐릭터별 고유 액션
- MP를 사용하여 발동
- 강한 피해, 유틸리티, 전장 제어, 강화 효과 등을 담당

### 4.4 궁극기
- UP 최대치에서만 사용 가능
- 전황을 뒤집는 고위력 액션
- 궁극기는 원칙적으로 캔슬할 수 없다

### 4.5 연계
- 일반 공격과 강공격은 조합하여 연속 공격을 구성할 수 있다
- 연계는 각 캐릭터의 기본 전투 리듬을 형성하는 핵심 구조이다
- 연계의 구체적인 구성은 캐릭터별 기획에서 정의한다

---

## 5. 공통 공격 등급 문법

현재 공통 전투 문법상 액션은 크게 **L / H** 두 등급 중심으로 분류한다.

### 5.1 L 등급
전투의 기본이 되는 액션.

예시:
- 약공격 / 강공격 조합으로 만들어지는 기본 연계
- 일반적인 전투 루프에 반복적으로 사용되는 액션

특징:
- 기본 전투의 주력
- 후딜레이 캔슬 가능 전제를 가짐
- 전투 흐름을 빠르게 이어가는 역할

### 5.2 H 등급
강한 위력, 무적, 큰 전투 영향력을 가진 고위력 액션.

예시:
- 필살기급 스킬
- 강한 무적기
- 대형 절단기
- 궁극기

특징:
- 캔슬 불가를 기본으로 함
- L 등급보다 높은 화력 또는 강한 특수 효과를 가짐

### 5.3 등급 적용 원칙
- L / H의 구분은 공통 전투 문법이다
- 각 액션의 실제 등급 지정은 개별 캐릭터 기획 문서에서 정의한다

## 6. 공통 회피 시스템

### 6.1 기본 방향성
회피는 전 캐릭터가 공유하는 공통 시스템이다.  
외형상으로는 하나의 회피처럼 보이지만, 내부적으로는 **Dodge1 / Dodge2** 구조를 가진다.

이 구조의 목표는 다음과 같다.

- 스태미나 없는 게임에서도 회피 난사를 억제
- 연속 회피는 허용하되 무한 회피는 방지
- 정확한 회피 성공 여부에 따라 회피 지속력이 달라지도록 설계
- 숙련자에게는 연속 패턴 대응 보상을 제공

### 6.2 내부 구조
#### Dodge1
- 기본 회피
- 가장 자주 사용하는 회피 동작
- 독립 쿨타임 보유

#### Dodge2
- 연속 회피용 회피 동작
- 외형상으로는 같은 구르기처럼 보이지만, 내부적으로는 별도 회피로 처리한다
- 독립 쿨타임을 가진다
- 일반적으로 Dodge1의 쿨타임이 돌고 있을 때 사용되는 회피 동작이다

### 6.3 회피 연속 사용 규칙
- 플레이어는 기본적으로 Dodge1을 사용한다
- Dodge1과 Dodge2는 독립된 쿨타임을 가진다
- 따라서 연속 회피는 가능하지만, 정확히 사용하지 않으면 다음 대응이 꼬일 수 있다

### 6.4 극한회피 (Perfect Dodge)
극한회피는 전 캐릭터 공통 시스템이다.

발동 조건:
- 적 공격이 적중하기 직전, 회피를 저스트 타이밍에 성공시킬 경우 발동

기본 효과:
- 피격 회피 성공
- 전투 흐름을 유리하게 바꾸는 짧은 보상 연출 가능
- MP 수급
- 캐릭터별 후속 연계 기점이 될 수 있음

핵심 규칙:
- 극한회피 성공 시, **성공에 사용한 닷지의 쿨타임만 일정량 회복한다**
- Dodge1으로 극한회피 성공 → Dodge1 쿨타임만 일정량 회복
- Dodge2로 극한회피 성공 → Dodge2 쿨타임만 일정량 회복
- 모든 회피 쿨타임을 일괄 초기화하지 않는다

### 6.5 설계 의도
이 구조를 통해 다음 리듬을 만든다.

- 회피를 많이 쓰는 게임이 아니라, **정확하게 쓰는 게임**
- 연속 공격을 모두 피하려면 매 타이밍을 정확히 맞춰야 함
- 부정확한 회피는 다음 공격에서 리스크로 이어짐
- 숙련자는 연속 공격을 아름답게 흘려낼 수 있음

예시:
#### 케이스 A
- 1타를 Dodge1으로 극한회피 성공
- Dodge1 쿨 회복
- 2타를 Dodge2로 극한회피 성공
- Dodge2 쿨 회복
- 다음 공격에도 회피 연계 가능

#### 케이스 B
- 1타를 Dodge1으로 일반 회피
- Dodge1 쿨은 남아 있음
- 2타를 Dodge2로 극한회피 성공
- Dodge2만 회복
- 3타 시점에 Dodge1이 아직 비어 있지 않다면 추가 대응이 불안정해질 수 있음

## 7. 공통 가드 / 패링 시스템

### 7.1 기본 방향성
패링과 가드는 전 캐릭터가 공유하는 공통 시스템이다.

입력은 하나의 가드 키를 사용하며,
- 저스트 타이밍 성공 시 패링
- 그렇지 않으면 일반 가드

로 처리한다.

이 구조의 목표는 다음과 같다.

- 입력은 단순하게 유지
- 패링을 배우기 쉽게 만들기
- 패링 실패를 완전한 실패로 두지 않기
- 일반 가드 남용은 실드 포인트로 제어하기

### 7.2 패링
발동 조건:
- 가드 키를 적 공격 적중 직전에 저스트 타이밍으로 입력할 경우 발동

성공 시 효과:
- 피해 무효
- 적의 스태거 게이지 증가
- MP 수급 가능
- 캐릭터별 반격 / 후속 연계 기점이 될 수 있음
- Shield Point 감소하지 않는다

설계 의도:
- 패링은 단순 생존이 아니라, **공격적으로 이득을 보는 방어 수단**
- 회피가 위치를 바꾸며 살아남는 수단이라면, 패링은 제자리에서 받아치며 전세를 뒤집는 수단

### 7.3 일반 가드
발동 조건:
- 가드 키를 홀드할 경우 유지

효과:
- 피해를 약 70% 경감
- 일반 가드로 공격을 받을 때마다 Shield Point 감소
- 패링에 실패했더라도 가드 입력을 유지하고 있다면 일반 가드로 전환됨

설계 의도:
- 일반 가드는 가장 쉬운 방어 수단
- 다만 강한 보상을 주는 수단은 아니며, Shield Point를 소모하므로 장기적으로 의존할 수 없게 설계

### 7.4 Shield Point 붕괴 상태
Shield Point가 0이 된 상태에서 일반 가드로 피격 시:
- 피해 경감량이 약 20% 수준으로 감소
- 피격 경직 발생
- 사실상 정상적인 방어 성능을 잃은 상태로 취급

설계 의도:
- 일반 가드는 편하지만 무한정 안전하지 않아야 함
- Shield Point가 0이 되면 가드 의존 플레이가 무너지도록 설계

### 7.5 패링 실패 완충 구조
본 시스템은 패링 실패를 지나치게 가혹하게 만들지 않는다.

- 저스트 타이밍 실패
- 그러나 가드 키를 계속 누르고 있다면
- 일반 가드로 전환되어 피해를 완전히 다 맞지는 않음

이를 통해 다음을 기대한다.

- 유저가 패링을 시도하기 쉬움
- 학습 진입장벽이 낮아짐
- 하지만 패링 성공과 일반 가드의 보상 차이는 분명히 유지됨

## 8. 회피 / 패링 / 가드의 역할 분리

### 8.1 회피
- 위치 이동 가능
- 연속 패턴 대응에 유리
- 정확한 사용 시 해당 닷지 리소스를 회복
- 틀리면 다음 공격 대응이 어려워짐

### 8.2 패링
- 제자리에서 받아치는 방어
- 적 스태거를 쌓아 공격 기회를 창출
- 성공 시 공격적 이득이 큼
- 실패해도 가드로 완충 가능

### 8.3 일반 가드
- 가장 쉬운 생존 수단
- 높은 피해 경감 제공
- 대신 Shield Point를 소모
- 남용 시 가드 성능 붕괴

이 세 요소는 서로 대체재가 아니라, 상황에 따라 선택되는 공통 전투 문법이다.

---

## 9. 전투 루프 관점의 해석

본 프로젝트의 전투 루프는 다음처럼 흐른다.

1. 일반 공격 / 강공격으로 전투를 전개
2. 적 공격에 대해 회피 / 패링 / 가드를 선택
3. 정확한 방어 성공 시 MP 및 전투 주도권 획득
4. 확보한 MP로 스킬 사용
5. 스킬 적중으로 UP 수급
6. UP를 통해 궁극기 사용

즉 방어는 단순 생존이 아니라,
**공격 자원과 전투 리듬을 만들어내는 핵심 장치**다.

## 10. 설계 원칙 요약

### 10.1 전 캐릭터 공통 시스템
다음 요소는 모든 캐릭터가 공유한다.

- 회피
- 극한회피
- 가드
- 패링
- Shield Point 기반 일반 가드 약화 구조

### 10.2 캐릭터 설계 시 전제
앞으로 설계하는 모든 캐릭터는 다음을 전제로 한다.

- 회피/극한회피 공통 문법 위에서 동작
- 패링/가드 공통 문법 위에서 동작
- 고유 기믹은 공통 방어 문법을 대체하지 않고 그 위에 추가된다

### 10.3 의도하는 최종 감각
- 초보자는 가드와 기본 회피로 버틴다
- 중급자는 패링과 극한회피를 섞는다
- 숙련자는 방어 성공을 통해 전투 리듬 자체를 지배한다

---

## 11. 한 줄 요약

**이 게임의 전투는 공통 회피 / 극한회피 / 가드 / 패링 문법 위에서, 정확한 방어 성공을 공격 기회와 자원 획득으로 연결하는 고속 액션 전투를 지향한다.**
