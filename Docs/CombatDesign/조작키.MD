# 🎮 조작키 정리

| 번호 | 기능            | 엑스박스 입력        | 키보드/마우스 입력        | 아웃게임 기능             |
|------|----------------|----------------------|----------------------------|--------------------------|
| 1    | 평타           | X 버튼               | 마우스 좌클릭             | -                        |
| 2    | 강공격         | Y 버튼               | 마우스 우클릭             | -                        |
| 3    | 점프           | A 버튼               | 스페이스바                | 확인                     |
| 4    | 구르기         | B 버튼               | 쉬프트                    | 취소                     |
| 5    | 이동           | 왼쪽 조이스틱        | WASD                      | 리스트 이동              |
| 6    | 리스트 이동    | 방향키 (왼쪽)        | -                          | 리스트 이동              |
| 7    | 가드           | LB                   | Q                         | -                        |
| 8    | 스킬           | LB + XYAB            | 1, 2, 3, 4                | -                        |
| 9    | 특수입력       | LT                   | E                         | -                        |
| 10   | 상호작용       | RB                   | F                         | -                        |
| 11   | 락온           | 오른쪽 조이스틱 클릭 (R3) | 마우스 휠 클릭          | -                        |
| 12   | 메뉴화면           | 엑스박스 삼자버튼  | ESC          | -        인게임 화면으로 이동                |
