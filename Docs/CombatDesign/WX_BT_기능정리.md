# WX BT 기능 정리

## 1. 문서 개요

### 1.1 문서 목적

본 문서는 WX에서 자체 개발한 기능 중 **BT(Behavior Tree)** 관련 기능을 정리하기 위한 문서이다.

언리얼 엔진 기본 제공 기능이 아닌, WX 프로젝트에서 별도로 개발한 BT 기능을 대상으로 하며, 기능의 목적과 사용 방식을 명확히 기록하는 것을 목표로 한다.

### 1.2 문서 범위

WX 자체 개발 기능은 아래 3종류의 문서로 구분하여 정리한다.

| 구분 | 내용 |
|---|---|
| BT 기능 문서 | Behavior Tree 관련 자체 개발 기능 |
| AM 기능 문서 | Animation Montage 관련 자체 개발 기능 |
| GA 기능 문서 | Gameplay Ability 관련 자체 개발 기능 |

본 문서는 위 항목 중 **BT 기능**을 다룬다.

## 2. BT 컴포지트 

### 2.1 RandomChoice

#### 기능 개요

`RandomChoice`는 기본적으로 `Selector`와 유사하게 하위 노드 중 하나를 선택하여 실행하는 BT 컴포지트이다.

다만 일반 `Selector`처럼 위에서 아래로 순차 평가하는 것이 아니라, 하위 노드 중 하나를 **균등한 확률로 랜덤 선택**하여 실행한다.

#### 기본 동작

- 하위 노드 중 하나를 랜덤으로 선택한다.
- 각 하위 노드는 동일한 선택 확률을 가진다.
- 선택된 하위 노드를 실행한다.
- 기본적인 실행 구조는 `Selector`와 유사하다.

#### 세부 옵션

| 옵션명 | 설명 |
|---|---|
| `AvoidRepeat` | 체크 시 직전에 실행된 하위 노드는 다음 선택 대상에서 제외한다. |


#### 사용 목적

`RandomChoice`는 몬스터의 행동 패턴이 항상 같은 순서로 반복되는 것을 방지하고, 동일한 조건에서도 다양한 행동이 나오도록 만들기 위해 사용한다.

예를 들어 여러 공격 패턴 중 하나를 무작위로 선택하거나, 같은 패턴이 연속으로 반복되지 않도록 제어할 때 사용할 수 있다.

## 3. BT 데코레이터

### 3.1 CompareAttributeRatio

#### 기능 개요

`CompareAttributeRatio`는 특정 능력치 비율을 계산한 뒤, 설정된 상수값과 비교하여 조건 충족 여부를 판단하는 BT 데코레이터이다.

분자 능력치와 분모 능력치를 각각 지정하고, 계산된 비율이 설정한 비교 조건에 부합할 경우 연결된 노드의 실행을 허용한다.

#### 기본 동작

- 분자에 사용할 능력치를 지정한다.
- 분모에 사용할 능력치를 지정한다.
- `분자 능력치 / 분모 능력치` 비율을 계산한다.
- 계산된 비율을 설정된 상수값과 비교한다.
- 비교 조건을 만족하면 연결된 태스크 또는 하위 노드를 실행한다.

#### 사용 예시

| 사용 목적 | 예시 |
|---|---|
| 체력 비율 조건 판단 | 현재 HP / 최대 HP가 50% 이하일 때 특정 패턴 실행 |
| 자원 비율 조건 판단 | 현재 MP / 최대 MP가 일정 비율 이상일 때 스킬 사용 |
| 스태거 상태 판단 | 현재 스태거 게이지 / 최대 스태거 게이지가 일정 비율 이상일 때 행동 변경 |

#### 사용 목적

`CompareAttributeRatio`는 몬스터 AI가 단순한 수치 비교가 아니라 **현재 상태의 비율**을 기준으로 행동을 선택할 수 있도록 하기 위해 사용한다.

이를 통해 체력 구간별 패턴 변경, 특정 자원 비율에 따른 행동 분기, 그로기 직전 상태 판단 등 다양한 조건 분기를 BT에서 처리할 수 있다.
