# 현휘 스킬 기획서

> 회절 속성 / 장검 / 메인 딜러

---

## 1. 전투 구조

현휘는 **반추의 그림자**를 3개 모아 **대련**을 발동하고, **반성 상태**에서 **극복**을 100포인트까지 축적한 뒤 **특수 강공격**과 **공명해방**으로 사이클을 마무리하는 메인 딜러다.

현휘는 일반적인 공명 에너지를 사용하지 않으며, 특수 강공격 발동에 성공하면 공명해방을 사용할 수 있다.

```text
반추의 그림자 3개 획득
→ 강공격으로 대련 발동
→ 반성 상태 진입
→ 극복 100포인트 축적
→ 특수 강공격 발동
→ 공명해방 발동
→ 일반 상태 복귀
```

- 반추의 그림자와 극복은 교대해도 유지된다.
- 대련과 공명해방 중에는 게임 시간이 정지한다.
- 반추의 그림자는 확정 경로만으로 3개를 획득할 수 있다.
- 심마 관련 효과는 피격으로 발생한 손실을 보전하는 안전장치이며, 일부러 피격되는 플레이가 이득이 되지 않도록 설계한다.

---

## 2. 고유 자원

### 2.1 반추의 그림자

필드에 생성되는 고유 자원으로, **환희**와 **심마** 두 종류가 있다.

- 환희와 심마를 합산하여 최대 3개까지 보유할 수 있다.
- 최대 보유량을 초과하여 생성된 그림자는 생성되지 않는다.

| 종류 | 생성 조건 |
|---|---|
| 환희 | 변주 스킬 발동 |
| 환희 | 공명 스킬 발동 |
| 환희 | 일반공격 5타 적중 |
| 심마 | 피격 시 생성되며, 10초에 1회만 발동 |

확정 획득 경로는 다음과 같다.

```text
변주 스킬 + 공명 스킬 + 일반공격 5타
= 반추의 그림자 3개
```

피격으로 생성되는 심마 그림자는 대련 진입을 앞당기는 보조 수단이다.

### 2.2 극복

반성 상태에서만 축적할 수 있는 게이지형 자원이다.

- 최대 보유량: 100포인트
- 극복 100포인트에서 특수 강공격을 발동할 수 있다.

| 획득 행동 | 획득량 |
|---|---:|
| 일반공격 1타 적중 | 4 |
| 강화 공명 스킬 적중 | 20 |
| 강공격 적중 | 8~12(미확정) |
| 심마 협동 발동 | 20 |

## 3. 스킬 구성

### 3.1 일반공격

#### 일반 상태

- 장검을 사용하는 기본 연속 공격이다.
- 일반공격 5타 적중 시 환희를 1개 생성한다.

#### 반성 상태

- 그림자의 협동 공격이 추가되어 공격 범위가 확대된다.
- 일반공격 1타가 적중할 때마다 극복을 4포인트 획득한다.

### 3.2 강공격

#### 일반 상태 — 대련

평상시에는 기본 강공격을 발동한다. 반추의 그림자를 3개 보유한 상태에서 강공격을 입력하면 **대련**으로 변경된다.

#### 대련 발동 효과

- 반추의 그림자 3개를 전부 흡수한다.
- 게임 시간을 정지하고 심상 공간을 전개한다.
- 흡수한 그림자들과 합을 나누는 연출 후 반성 상태에 진입한다.
- 대련 자체는 피해를 주지 않는다.

#### 심마 QTE

흡수한 그림자에 심마가 하나 이상 포함되어 있으면 QTE가 발생한다.

- QTE 성공 시 협주 게이지를 회복한다.
- 회복량은 일반공격 5타로 획득할 수 있는 양과 동일하게 설정한다.
- 환희만 흡수한 경우에는 QTE 없이 대련 연출만 재생한다.

#### 반성 상태

- 극복이 100포인트 미만이면 기본 강공격을 발동한다.
- 기본 강공격 적중 시 극복을 8~12포인트 획득한다.
- 극복이 100포인트에 도달하면 강공격이 특수 강공격으로 변경된다.

#### 특수 강공격

- 심마와 대련을 벌이며 주변에 강한 범위 피해를 준다.
- 대련이 끝나면 현휘의 검과 심마의 검이 하나로 합쳐진다.
- 발동에 성공하면 공명해방을 사용할 수 있다.

### 3.3 공중공격

- 일반 상태와 반성 상태 모두 기본 공중공격을 사용한다.

### 3.4 회피반격

- 극한회피 중 일반공격을 입력하면 발동한다.
- 일반 상태와 반성 상태에서 동일하게 사용할 수 있다.

### 3.5 공명 스킬

#### 일반 상태

- 공명 스킬 발동 시 환희를 1개 생성한다.

#### 반성 상태 — 강화 공명 스킬

- 현휘의 곁에 있는 그림자를 전방 5미터 지점으로 이동시킨다.
- 현휘와 그림자가 서로를 향해 정면으로 돌진한다.
- 두 대상이 교차하는 구간에 난격을 발생시켜 범위 피해를 준다.
- 돌진 중에는 적을 통과하므로 보스의 히트박스 크기와 관계없이 공격 범위를 형성한다.
- 적중 시 극복을 20포인트 획득한다.

### 3.6 심마 협동

반성 상태에서 피격 중이거나 피격으로 공중에 뜬 상태일 때 일반공격을 입력하면 발동한다.

- 심마 협동을 1개 소모한다.
- 현재 피격 상태에서 즉시 이탈한다.
- 회피 성공으로 간주한다.
- 체력을 회복한다.
- 협주 게이지를 획득한다.
- 극복을 20포인트 획득한다.

### 3.7 공명 회로 — 반성

공명 회로는 **반추의 그림자**, **대련**, **반성**, **심마 협동**, **극복**과 관련된 상태 전이를 관리한다.

#### 반성

대련 종료 후 공명 회로 **반성**이 활성화된다. 별도의 지속시간은 없다.

- 흡수한 그림자가 현휘의 곁에서 함께 공격한다.
- 현휘와 그림자는 서로 반대 방향의 궤적으로 공격한다.
- 일반공격의 공격 범위가 확대된다.
- 공명 스킬이 강화 공명 스킬로 변경된다.
- 반성 활성화 시 심마 협동을 1개 획득한다.
- 고유 자원 극복을 축적할 수 있다.
- 공중공격은 일반 상태와 동일하다.
- 극복이 100포인트에 도달하면 강공격이 특수 강공격으로 변경된다.

#### 상태 전이

| 현재 상태 | 조건 | 전이 결과 |
|---|---|---|
| 일반 상태 | 대련 종료 | 공명 회로 반성 활성화 |
| 반성 | 극복 100포인트에서 특수 강공격 발동 | 공명해방 사용 가능 |
| 공명해방 사용 가능 | 공명해방 발동 종료 | 반성 종료 및 일반 상태 복귀 |

### 3.8 공명해방

특수 강공격 발동 후, 현휘의 검과 심마의 검이 하나로 합쳐진 상태에서 사용할 수 있다.

- 일반 상태에서는 사용할 수 없다.
- 일반적인 공명 에너지를 요구하지 않는다.
- 발동 중에는 게임 시간이 정지한다.
- 발동 후 반성 상태가 종료되고 일반 상태로 복귀한다.
- 반추의 그림자를 다시 모을 수 있는 상태로 전환된다.

### 3.9 변주 스킬

- 현휘가 전투에 등장할 때 발동한다.
- 환희를 1개 생성한다.
- 공명 스킬 연계 창을 개방한다.

### 3.10 반주 스킬

- 현휘가 전투에서 퇴장할 때 강한 피해를 준다.
- 구체적인 피해량과 연출은 미정이다.

### 3.11 조화도 파괴

- 조화도 파괴 발동 후 일정 시간 안에 일반공격을 짧게 입력하면 일반공격 3단이 발동한다.
- 조화도 파괴로는 반추의 그림자가 생성되지 않는다.

## 4. 상황별 입력 기능

### 4.1 일반공격 버튼

| 상황 | 입력 결과 |
|---|---|
| 평상시 | 일반공격 |
| 극한회피 중 | 회피반격 |
| 반성 상태에서 피격 중 또는 공중에 뜬 상태 | 심마 협동 |
| 조화도 파괴 직후 | 일반공격 3단 |

조화도 파괴 시 적이 큰 경직에 빠지므로, 심마 협동과 일반공격 3단의 입력 조건은 충돌하지 않는다.

### 4.2 강공격 버튼

| 상황 | 입력 결과 |
|---|---|
| 일반 상태에서 반추의 그림자 3개 미만 보유 | 기본 강공격 |
| 일반 상태에서 반추의 그림자 3개 보유 | 대련 |
| 반성 상태에서 극복 100포인트 미만 보유 | 기본 강공격 |
| 반성 상태에서 극복 100포인트 보유 | 특수 강공격 |

### 4.3 공명해방 버튼

| 상황 | 입력 결과 |
|---|---|
| 특수 강공격 발동 전 | 공명해방 사용 불가 |
| 특수 강공격 발동 후 | 공명해방 발동 |

## 5. 기본 로테이션

현휘는 변주 스킬로 등장한 뒤 약 14초 동안 필드에 머물며 한 번의 사이클을 완료한다.

```text
변주 스킬 — 환희 1개
→ 공명 스킬 — 환희 1개
→ 일반공격 5타 — 환희 1개
→ 반추의 그림자 3개 보유
→ 강공격으로 대련 발동
→ 반성 상태 진입
→ 강화 일반공격·강화 공명 스킬로 극복 100포인트 축적
→ 특수 강공격 발동
→ 공명해방 발동
→ 일반 상태 복귀
→ 반주 스킬로 퇴장
```

- 대련과 공명해방은 게임 시간 정지 구간이므로 14초의 온필드 시간에서 제외한다.
- 심마가 포함된 경우 대련 중 QTE가 추가되지만, 피격으로 손실된 자원을 보전하는 효과이므로 전체 자원 기댓값은 동일하다.
