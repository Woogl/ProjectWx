# 전투 방향 변경에 따른 시스템 수정 요구사항

게임의 전투 방향이 스텔라 블레이드에서 명조로 변경되면서 여러 요소를 수정해야 한다.

데이터로 관리할 수 있는 요소는 직접 변경하고, 추가 개발이나 기존 기능의 수정이 필요한 부분을 아래에 정리한다.

## 1. 패링

### 1.1 발동 방식

| 구분 | 내용 |
| --- | --- |
| 기존 | 적의 패링 가능한 타격을 저스트 가드하는 데 성공하면 패링이 발생한다. |
| 변경 | 적의 애니메이션 중 패링 가능한 타이밍에 PC의 공격이 적중하면 패링이 발생한다. |

### 1.2 발동 결과

| 기존 | 변경 |
| --- | --- |
| 1. 슬로 모션 발생<br>2. PC의 패링 성공 애니메이션 출력<br>3. 적의 패링 히트 리액션 발생<br>4. 적의 스태거 게이지 감소 | 1. 슬로 모션 발생<br>2. 적의 패링 성공 히트 리액션 발생<br>3. 적의 최대 스태거 게이지 중 10%에 해당하는 수치만큼 현재 스태거 게이지 증가 |

### 1.3 필요한 기능

1. 적이 특정 프레임에 공격받으면 패링 히트 리액션이 발생하는 기능
2. 패링 가능한 프레임을 시각적으로 보여주는 이펙트
3. 패링 히트 리액션이 발동하면 적의 최대 스태거 게이지 중 10%에 해당하는 수치만큼 현재 스태거 게이지가 증가하는 기능

## 2. 그로기

### 2.1 발동 방식

| 구분 | 내용 |
| --- | --- |
| 기존 | 적의 스태거 게이지가 최대치에 도달하면 그로기가 발생한다. |
| 변경 | 변경 없음 |

### 2.2 발동 결과

| 기존 | 변경 |
| --- | --- |
| 1. 적이 그로기 애니메이션 실행<br>2. 앞잡 버튼 활성화 | 1. 적이 그로기 애니메이션 실행<br>2. 앞잡 버튼 비활성화 |

### 2.3 필요한 기능

1. 적이 그로기 상태가 되어도 앞잡이 활성화되지 않도록 변경

## 3. 가드 및 저스트 가드

가드와 저스트 가드가 발생하지 않도록 막아야 한다.

## 4. 스킬

### 4.1 발동 방식

| 구분 | 내용 |
| --- | --- |
| 기존 | `1~4` 키를 누르면 각 키에 할당된 스킬이 발동한다. |
| 변경 | 스킬 키는 `E` 하나만 사용한다. 특정 어빌리티의 도중이나 후딜레이 또는 특정 상태에서 `E` 키를 누르면 상황에 따라 서로 다른 스킬이 발동한다. |

### 4.2 발동 결과

| 기존 | 변경 |
| --- | --- |
| `1~4` 키를 누르면 해당 키에 매핑된 GA가 실행된다. | `E` 키를 누른 시점과 PC의 상태에 따라 서로 다른 스킬이 발동한다. |

### 4.3 필요한 기능

1. `E` 키의 입력 시점과 PC의 상태에 따라 발동할 스킬을 분기하는 기능

## 5. 앞잡 (우선도 낮음)

### 5.1 발동 방식

| 구분 | 내용 |
| --- | --- |
| 기존 | 그로기 상태의 적이 근처에 있으면 앞잡을 사용할 수 있다. |
| 변경 | 부조화 게이지가 가득 찬 적이 근처에 있으면 앞잡을 사용할 수 있다. |

### 5.2 필요한 기능

1. HP 피해와 스태거 피해에 이은 세 번째 피해 유형인 부조화 피해량과 이를 축적할 부조화 게이지 추가
2. 앞잡 활성화 조건을 적의 그로기 상태에서 부조화 게이지 최대 상태로 변경
3. 앞잡 사용 시 적의 스태거 게이지를 전부 회복시키는 기능을 부조화 게이지를 전부 회복시키는 기능으로 변경

### 5.3 대체안

해당 기능의 개발 공수가 크다면 밸런스 테스트를 위해 별도의 스킬 키를 추가한다. 해당 스킬은 적 앞으로 순간이동한 뒤 큰 피해와 경직을 가하는 방식으로 구현하고, 이를 기준으로 밸런싱한다.
