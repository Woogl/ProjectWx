# PCG 개발 방향성

## 원칙

PCG는 사용 방법이 고정된 것이 아니며, 프로젝트마다 사용 범위가 다릅니다.

우리 프로젝트에서 PCG는 각 환경에 어울리는 아트 에셋을 자동으로 배치해주는 정도로만 씁시다.

### 이유

레벨디자이너, 프로그래머가 장식성 아트 리소스 때문에 고민하거나 시간낭비하지 않았으면 합니다.  

레벨디자인 설계가 먼저고, 아트 리소스는 나중입니다. 아트 리소스는 개발 막바지나 폴리싱 과정에서 자주 교체됩니다.

레벨디자이너나 AI가 아트 에셋을 하나하나 배치하면서 노가다하는 수고를 줄여드리고 싶습니다.  

### 직군별 PCG 중점
- 프로그래머: 적당히 자연스럽게 자동 배치되는 로직을 성능 최적화를 고려해 구현합니다.
- 레벨디자이너: 그레이박싱, 동선 설계, 컨텐츠 배치만 합니다.
- 아트: PCG에서 사용할 아트 리소스를 제작하고, 적절하게 바이옴 PCG를 배치합니다.

### 주의사항

정교하게 레벨디자인 의도를 담아야하는 부분에는 PCG를 사용하지 않습니다.
- PCG로 자동 배치되는 나무가 의도한 곳에서 정확하게 길을 막아주길 기대하지 마세요.
- 랜드마크나 컨텐츠적으로 중요한 부분은 레벨에 직접 배치하세요.

## 예시
### 숲 바이옴
- 바닥 머터리얼: 흙, 이끼
- 포인트 샘플러: 나무, 바위, 풀, 잔디, 절벽
- 스플라인 샘플러: 오솔길(Road), 개울가(Water)

### 사막 바이옴
- 바닥 머터리얼: 모래
- 포인트 샘플러: 선인장, 바위, 바위절벽
- 스플라인 샘플러: 순례길(Road), 오아시스(Water)
