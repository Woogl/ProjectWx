# 그로기 피니시 — 구현 체크리스트

> `Docs/CombatDesign/그로기_피니시_시스템_기획서.md` 기준의 **예상 작업 목록**이다. 구체적 구현 방법·로직·수치 설계는 담지 않는다 — 실제 설계는 구현 단계(plan mode·worklog)에서 정한다.

## 개요
그로기 상태의 적에게 상호작용 키로 발동하는 강력한 처형 공격. 큰 피해와 다운을 주고 스태거 게이지를 제거해 그로기에서 회복시킨다. 걸치는 도메인: **전투(GAS)** 중심 + **UI(상호작용 프롬프트 재사용)** + **입력** + **애니메이션**.

## 작업 목록

### 전투 — 어빌리티/발동
- [ ] 그로기 피니시 어빌리티 추가 — 그로기 적 대상 처형 공격 (1)
- [ ] 발동 게이팅 — 다른 GA 미발동 중이거나 후딜(캔슬 윈도우) 상태에서만 발동 가능 (3.1)
- [ ] 발동 중 PC 무적 부여 (3.2-3)
- [ ] 피해 적용 후 대상 스태거 게이지 전량 제거 + 그로기 상태 회복 (3.2-4, 1)
- [ ] 피해 적용 후 대상 다운 처리 (3.2-5)
- [ ] 발동 중 `Ability` 계열 능력 차단, `State.Dead`면 발동 차단 (5)

### 전투 — 대상 탐지/선정
- [ ] 반경 3m 내 그로기 상태 적 탐지 (3.1)
- [ ] 발동 대상 우선순위: 가장 가까운 적 (3.1) — ※플로우차트의 락온 분기와 불일치(열린 질문 참조)
- [ ] 발동 중 대상 스태거 게이지 증감 정지 (3.2-2)
- [ ] 발동 시 대상을 PC 근처로 이동/위치 조정 (3.2-1)

### 입력
- [ ] 상호작용 키(F)로 발동 — 기존 상호작용 입력 경로 재사용 (3.1)

### UI — 상호작용
- [ ] 조건 충족 시 그로기 피니시 프롬프트를 상호작용 UI로 표시 (3.1)
- [ ] 상호작용 목록 우선순위: 그로기 피니시를 최상단·기본 선택, 다른 상호작용 오브젝트보다 우선 (3.1)

### 애니메이션
- [ ] 그로기 피니시 몽타주 (가해자·피해자) (1, 3.2)
- [ ] 대상 위치 조정(스냅) 타이밍 (3.2-1)
- [ ] 무적 구간 (3.2-3)
- [ ] 피해 발생 타이밍 (3.2-4, 3.2-5)

### 예외 처리
- [ ] 낭떠러지 발동: 바닥 유무 무관 전 과정 재생 후 중력 처리 (6-1)
- [ ] 발동 중 대상이 도트 데미지 등으로 사망해도 애니메이션 전부 재생 (6-2)
- [ ] 좁은 통로 끼임: 발동 전 위치로 복귀 (6-3)

### GameplayTag
- [ ] `Ability.GroggyFinish` 에셋 태그 (5) — 기존에 없으면 추가

## 열린 질문 / 기획 공백
- **피해량 미정** — 계수/고정값이 기획서에 없다. 데이터 수치 필요.
- **대상 우선순위 모순** — 본문(3.1)은 "가장 가까운 적"인데 플로우차트(4)는 "락온된 그로기 적 우선 → 없으면 가장 가까운 적" 분기다. 어느 쪽이 최종인가?
- **위치 조정 기준 미정** — "PC 근처로 이동"의 목표 거리·정면 정렬 여부가 없다.
- **무적 범위 미정** — 발동 전체인지 특정 구간인지, 시작·종료 프레임이 3.2와 노티파이 배치에 따라 갈린다.
- **다운 처리 미정** — 다운 지속 시간·기상 방식이 없다.
- **후딜 판정 기준 미정** — "GA 후딜 상태"에서 발동 허용이라 했는데, 어떤 어빌리티의 어느 구간까지를 후딜로 볼지 불명확.
