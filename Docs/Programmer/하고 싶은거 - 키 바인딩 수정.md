# 키 바인딩 수정 필요성

* 잠시 창영님의 포폴을 위해서 명조를 많이 참고했지만, 명조를 재현하는 것이 최종 개발 목적이 아님.
* 스텔라 블레이드, 명조, 젠레스존제로, 원신의 조작법의 절충안을 생각하여 키 재배치

# 키 바인딩 제안

| 행동 | KMB | XBOX |
| :-: | :-: | :-: |
| 이동 | WASD | L Stick |
| 시야 | Mouse Move | R Stick |
| 공격 | L Click | X |
| 특수기 | R Click | Y |
| 회피 / 달리기 | Shift | A |
| 점프 | Space | B |
| 스킬 | E | RB |
| 궁극기 | R | RT |
| 상호작용 | F | LT | 
| 아이템 사용 | Z | D-Pad down |
| 숙이기 | C | L Stick Press |
| 락온 | M Click | R Stick Press |

# 비고

* 특수기: 캐릭터마다 다를 수 있음. 명조 공명 회로 같은 것. 강공격, 가드, 조준 등.
* 캐릭터 교체: 캐릭터 교체 시스템을 추가할지 확정되지 않았으나, 추가된다면 123 키 사용 예상.
