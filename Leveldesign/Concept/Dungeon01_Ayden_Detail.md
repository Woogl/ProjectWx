## 1. 던전 전체 구조

```
[입구]
  ↓
[1구역]   ← 도굴꾼 전투 구역
  ↓
[2구역]   ← 빛 기믹 첫 등장 (레버 + 거울 퍼즐)
  ↓
[3구역]   ← 전투 + 빛 기믹 결합 / 비밀방 포함 (가드 반사로 개방)
  ↓
[최종 관문]  ← 조각상 3개 순서 반사 기믹 (반사 방식 팀 회의 예정)
  ↓
[보스방]
```

## 2. 등장 적

### 도굴꾼 무리 (신전 침입자)
플레이어보다 먼저 신전에 들어온 도적단. 내부를 탐색하며 유물을 노리고 있다.
전투력은 낮지만 수적 우위를 활용한다.

| 이름 | 역할 | 특징 |
|---|---|---|
| 도굴꾼 | 기본 근접 | 낮은 체력, 단순 공격 패턴. 구르기로 쉽게 회피 가능. |
| 도굴꾼 궁수 | 원거리 | 떨어진 거리에서 화살 발사. 플레이어를 이동시키는 역할. |
| 도굴꾼 대장 | 강화 근접 | 일반보다 체력과 공격력이 높음. 가드로 막을 수 있는 강공격 1종 보유. |

### 신전 수호 기제 (미확정)
- 도굴꾼 외에 신전 자체의 함정이나 작은 석상 기제 등을 추가할 수 있음
- 추후 검토

## 3. 구역별 상세

---

### 입구

**공간 성격**
신전 건물 외부. 풀이 우거진 돌계단과 무너진 기둥들이 늘어선 야외 공간.
던전 입장 전 분위기를 쌓는 구간으로, 전투는 없다.

**주요 요소**
- 반쯤 무너진 신전 입구 문 (열려있음)
- 도굴꾼들이 남긴 흔적 — 야영 도구, 버려진 횃불, 발자국
- 벽에 새겨진 오래된 부조 (신전의 역사를 암시하는 세계관 텍스트)

**연출 포인트**
- 플레이어가 입구 계단을 오르면 신전 내부에서 도굴꾼들의 소리가 들려옴
- 안쪽에서 희미한 빛이 새어나오는 것이 보임 → 호기심 유도

---

### 1구역

**공간 성격**
신전 입구를 지나면 나오는 큰 홀. 중앙에 거대한 신 동상이 있고, 그 앞에 도굴꾼들이 모닥불을 피워놓고 쉬고 있다. 전투 집중 구간. 빛 기믹은 등장하지 않는다.

**레이아웃**
- 아담한 홀. 좌우로 기둥 2~3쌍
- 홀 안쪽에 거대한 신 동상 (천창 셔터와 연결 — 레버 당기기 전까지 빛이 막혀있음)
- 동상 바로 앞에 도굴꾼 야영지 (모닥불 중심, 상자와 천막)
- 동상 옆에 천창 셔터와 연결된 레버
- 홀 한쪽 구석에 보물상자 1개 (탐색 보상)
- 홀 안쪽에 2구역으로 이어지는 봉인된 문

**입장 연출**
- 플레이어가 홀에 들어서는 순간 카메라가 신 동상을 비추는 연출 재생
- 동상 앞 모닥불과 도굴꾼들이 함께 보임
- 연출 종료 후 플레이어 조작권 반환

**2단계 인지 시스템**

```
[감지 범위] 진입
  → 도굴꾼들이 모닥불에서 고개를 들고 경계 시작
  → "넌 누구야?" 대사 + 일어서는 동작 (약 2초)
  → 이 시간 동안 플레이어가 먼저 공격하면 선제 가능

[전투 범위] 진입 또는 2초 경과
  → 본격 전투 시작
```

**적 배치 — 야영지 조우 (전투 1)**

| 위치 | 적 구성 | 비고 |
|---|---|---|
| 모닥불 앞쪽 | 도굴꾼 2명 | 삼각형 배치의 앞 꼭지점 둘 |
| 모닥불 뒤쪽 | 도굴꾼 궁수 1명 | 삼각형 배치의 뒤 꼭지점. 지상 배치. |

- 모닥불이 삼각형 중앙에 위치 → 적 구분이 시각적으로 명확
- 궁수는 뒤쪽에 있어 자연스럽게 나중에 눈에 띔

**진행 조건**
- 야영지 도굴꾼 3명 처치 → 레버 조작 가능 상태로 변경
- 플레이어가 레버를 당김 → 천창 셔터 개방 → 빛이 동상을 비춤 → 봉인된 문 개방

**레버 + 빛 연출 (블루프린트 연출 포인트)**
```
레버 당김
  → 천장 셔터가 열리는 기믹 작동 (Timeline으로 회전/이동)
  → 빛줄기가 동상에 닿음 (Niagara Beam)
  → 동상 문양 서서히 점등 (Dynamic Material Instance)
  → 봉인된 문 개방 연출
```

**디자인 의도**
- 2단계 인지로 플레이어에게 선택권과 짧은 긴장감 부여
- 삼각형 배치로 적 구분을 명확히 하고 궁수 위협을 자연스럽게 인식하게 함
- 레버 조작이 빛 연출과 직결 → 플레이어 행동이 세계에 영향을 준다는 느낌
- 동상이 던전 전체 광원임을 첫 구역에서 자연스럽게 인지시킴

### 2구역

**공간 성격**
조용하고 밝은 복도형 공간. 천장 곳곳에 셔터가 달린 채광창이 있어 빛이 내려온다.
전투 없이 빛 기믹을 처음 접하고 이해하는 구간.

**레이아웃**
- 복도 형태. 중간에 봉인된 문 하나가 있어 앞/뒤 공간으로 나뉨
- 앞쪽 공간: 거울 1번, 거울 2번
- 문 너머 공간: 거울 3번, 보물상자, 3구역으로 이어지는 문

**빛 퍼즐 구성**

**거울 1번 — 기본 반사 (관찰로 이해)**

```
[천창 빛] → [거울 1, 살짝 어긋남] → 빛이 거울 2 바로 옆을 지나침
```
- 거울 1은 이미 대략 맞춰져 있지만 각도가 미세하게 틀린 상태
- 빛줄기가 목표 바로 옆을 지나가는 게 보임
- 플레이어가 "조금만 돌리면 되겠다"를 스스로 깨닫게 유도
- 레버 조작으로 거울 각도 조정

**거울 2번 — 체인 반사 (문 개방)**

```
[거울 1] → [거울 2] → [문양] → 봉인된 문 개방
```
- 거울 1의 빛을 받아 문양에 반사시키면 봉인된 문이 열림
- 거울 2도 레버로 각도 조정 가능
- 두 거울을 함께 맞춰야 한다는 체인 개념 처음 경험

**거울 3번 — 응용 (3구역 문 개방)**

```
[천창 빛] → [거울 3] → [안쪽 문양] → 3구역 문 개방
```
- 문이 열리면 새 공간이 보이고 거울 3번이 눈에 들어옴
- 거울 3번 맞추면 3구역으로 이어지는 문 개방
- 거울 3번 옆에 보물상자 1개

**진행 흐름 요약**

```
입장
  ↓
거울 1 살짝 어긋난 것 발견 → 레버로 각도 수정
  ↓
거울 2로 빛 연결 → 봉인된 문 개방 연출
  ↓
문 너머 공간 진입 → 거울 3 발견
  ↓
거울 3 조작 → 3구역 문 개방 + 보물상자 획득
```

**디자인 의도**
- 전투 없는 조용한 구간 → 1구역 긴장과 대비, 기믹 탐색에 집중하게 함
- 거울 1의 "살짝 어긋난" 상태 → 말 없이 조작법을 환경으로 가르침
- 보물상자를 퍼즐 끝에 배치 → "끝까지 풀면 보상"이라는 기대감 형성
- 천창 광원으로 1구역과 일관된 빛 메커니즘 유지

### 3구역

**공간 성격**
높낮이가 있는 긴 복도형 공간. 계단과 발판으로 상하 구조가 나뉜다.
전투 후 빛 퍼즐로 진행하는 구간. 이 던전에서 전투 강도가 가장 높다.

**레이아웃**
- 입구에서 안쪽으로 이어지는 긴 복도
- 중간중간 계단과 낮은 발판으로 높낮이 구성
- 높은 위치에 궁수 정찰 구역
- 복도 안쪽에 큰 몬스터 위치
- 복도 곳곳에 거울 장치 (도굴꾼들이 주변에서 살펴보고 있음)
- 안쪽 끝에 최종 관문으로 이어지는 봉인된 문

**적 배치**

| 위치 | 적 구성 | 상태 |
|---|---|---|
| 높은 발판 | 도굴꾼 궁수 1~2명 | 정찰 중. 2단계 인지 시스템 적용. |
| 거울 주변 | 도굴꾼 2~3명 | 거울을 살펴보며 분산 배치. 개별 감지. |
| 복도 안쪽 | 도굴꾼 대장 1명 | 경계 상태. 플레이어 접근 시 집결 신호. |

**전투 흐름**

```
입장
  ↓
높은 곳 궁수가 먼저 감지 가능 (2단계 인지)
  ↓
[선택] 주변 잡몹 먼저 정리 → 도굴꾼 대장 단독 상대
[선택] 바로 돌진 → 도굴꾼 대장 집결 신호 → 전체 전투
  ↓
전체 처치 → 거울 장치 활성화
```

**빛 퍼즐 (전투 후)**

```
[천창 빛] → [거울 1] → [거울 2] → [문양] → 봉인된 문 개방
```
- 거울 2개. 수평 반사. 2구역보다 단순하게 유지.
- 전투가 끝난 후 조용히 마무리하는 느낌

**비밀방 (선택)**

```
[천창 빛] → [별도 거울 (고정, 레버 없음)] → 빛이 특수 문양 근처를 지나침
→ 플레이어가 가드로 빛을 특수 문양에 반사 → 비밀방 문 개방
```
- 퍼즐용 거울(1,2번)과 별개인 고정 거울이 복도 한쪽에 있음
- 이 거울은 레버가 없어 조작 불가 — 빛이 벽 쪽을 향하고 있음
- 플레이어가 빛 경로 위에 서서 가드를 취하면 특수 문양에 반사됨
- 최종 관문 기믹을 미리 시도하는 플레이어 또는 재방문 플레이어만 발견 가능
- 내부 보상: 미확정

**디자인 의도**
- 거울 주변에서 헤매는 도적들 → 말 없이 "이 퍼즐이 어렵다"는 것을 환경으로 표현
- 높낮이로 시각적 변화를 주되 퍼즐은 단순하게 유지 → 전투가 이 구역의 핵심
- 선택 가능한 전투 진입 방식 → 플레이어에게 전략적 자유도 부여
- 비밀방은 가드 반사를 먼저 시도한 플레이어에게 주는 보상 — 강제하지 않고 발견하게 함

### 최종 관문

**공간 성격**
보스방 바로 앞의 방. 도굴꾼들이 여기서 막혀 진입하지 못한 흔적이 남아있다.
방 중앙 천창에서 빛기둥이 내려오고, 빛을 조각상에 순서대로 비춰야 문이 열린다.

**레이아웃**
- 정사각형에 가까운 방. 중앙에 천창 빛기둥이 내려옴.
- 방 안쪽 세 방향(삼각형 형태)에 고대 석조각상 3개 배치.
- 각 조각상 앞에 문양 장치 — 빛을 받으면 활성화됨.
- 안쪽 벽에 보스방으로 이어지는 봉인된 문.
- 입구 쪽에 도굴꾼들이 막혀 돌아간 흔적 (쓰러진 횃불, 주저앉은 자국 등).

**진행 흐름**

```
플레이어 입장
  ↓
조각상 1개가 먼저 빛을 발하며 신호 (눈 또는 가슴 문양이 켜짐)
  ↓
플레이어가 빛기둥에 서서 해당 조각상 방향으로 빛을 반사
  → 조각상 문양 활성화
  ↓
조각상 2번 신호 → 반사 → 활성화
  ↓
조각상 3번 신호 → 반사 → 활성화
  ↓
3개 모두 활성화 → 봉인된 문 개방 연출
```

**반사 방식 (미확정 — 회의 필요)**
> ⚠️ 아래 두 방식 중 하나로 확정 예정. 팀 회의 후 결정.
>
> - **방식 A — 가드 반사 (패링):** 3구역 비밀방과 동일한 메커니즘. 플레이어가 빛기둥 위에 서서 조각상 방향 바라보고 가드 입력. 보스 기믹의 직접적인 예행연습 느낌.
> - **방식 B — 거울 조작 (레버):** 2구역처럼 레버로 거울 각도를 조절해 빛을 반사. 기존 퍼즐 메커니즘의 응용이라 튜토리얼 흐름에 더 자연스러울 수 있음.

**난이도 설계**
- 조각상 신호 순서는 매 도전마다 동일 (랜덤 아님) — 학습 가능한 구조.
- 신호 지속 시간: 첫 번째 조각상은 여유롭게, 세 번째는 짧게. 갈수록 빨라지는 느낌.
- 순서를 틀리거나 신호 시간 내에 반사하지 못하면 처음부터 재시작.
- 3구역 비밀방(가드 한 번)보다 높은 난이도 — 순서 암기 + 반응 요구.

**디자인 의도**
- 신호를 읽고 반응하는 구조가 보스의 빛 방출 기믹과 동일한 패턴 → 자연스러운 예행연습.
- 도굴꾼들이 이 방에서 막혔다는 흔적 → 이 관문이 신전의 진짜 수호 장치임을 환경으로 표현.
- 보스방 진입 직전이라 긴장감이 자연스럽게 올라오는 위치.

**블루프린트 연출 포인트**
- 조각상 신호: `Timeline` + `Dynamic Material Instance (Emissive)` — 눈 또는 문양 점등
- 빛 궤적: `Niagara Beam` (플레이어 → 조각상 방향)
- 반사 판정 (방식 A): `Has Matching Gameplay Tag (ANS.Guard)` + `Reflect Vector`
- 거울 조작 (방식 B): `Line Trace` + `Reflect Vector` + `Niagara Beam`
- 문양 활성화: `Timeline` + `Dynamic Material Instance (Emissive)`
- 전체 활성화 시 문 개방: `Timeline` 체인 + 카메라 연출

## 4. 보스 — 신전의 수호자

### 기본 설정

| 항목 | 내용 |
|---|---|
| 이름 (임시) | 신전의 수호자 |
| 외형 | 거대한 석인상. 높이 약 4~5m. 전신에 고대 문자 문양이 새겨져 있음. |
| 등장 | 보스방 중앙에 석상으로 서있다가 플레이어 입장 시 눈에 빛이 켜지며 각성. |
| 전투 성격 | 크고 느린 타입. 하나하나의 공격은 강하지만 예측하기 쉬움. |

### 보스방 구조
- 넓은 원형 방. 중앙에 수호자가 위치.
- 방 벽면에 고대 문양 부조 (장식 + 힌트 역할)
- 기둥 없음 — 회피 공간이 넓어 구르기 충분히 활용 가능

---

### 페이즈 1 (체력 100% ~ 50%)

**전반적인 패턴 방향**
느리지만 범위가 넓은 공격 위주. 타이밍만 읽으면 구르기로 모두 회피 가능.
공격 전 항상 예고 동작(자세 변경, 빛이 팔에 모임 등)이 선행된다.

| 패턴 이름 | 설명 | 회피 방법 |
|---|---|---|
| 대지 강타 | 팔을 들어 바닥을 내리침. 충격파가 앞으로 퍼짐. | 옆으로 구르기 |
| 횡쓸기 | 팔을 크게 옆으로 휘두름. 앞 넓은 범위. | 안쪽 또는 뒤로 구르기 |
| 발구르기 | 제자리에서 발을 크게 구름. 주변 좁은 범위 AoE. | 뒤로 물러나기 |

---

### 페이즈 2 (체력 50% ~ 0%)

**전환 연출**
체력 50% 도달 시 수호자가 잠시 멈추고 전신 문양이 한꺼번에 빛난다.
지면에 충격파가 퍼지며 카메라가 흔들림 → 이후 움직임이 빨라짐.

**추가 패턴**

| 패턴 이름 | 설명 | 회피 방법 |
|---|---|---|
| 연속 강타 | 대지 강타를 2회 연속으로 사용 | 2번 연속 구르기 |
| 빛 기둥 소환 | 바닥에 원형 마커가 생기고 1.5초 후 빛기둥 폭발 | 마커 범위 밖으로 이동 |
| **[기믹] 빛 방출** | *아래 상세 참조* | 가드 → 반사 또는 옆 구르기 |

---

### 기믹 패턴 — 빛 방출

**발동 조건**
페이즈 2에서 체력 40%, 20% 부근에서 각 1회씩 사용 (총 2회).

**흐름**

```
수호자가 멈추고 가슴 문양에 빛이 모이기 시작 (약 3초)
  ↓
[선택 A] 플레이어가 수호자 정면 일정 범위 안에서 가드를 취함
  → 빛이 플레이어 무기에 반사 → 수호자 눈 명중
  → 수호자 스턴 (약 4초) — 큰 피해 딜 타임
  ↓
[선택 B] 플레이어가 옆으로 피함
  → 빛이 벽에 닿고 소멸 (데미지 없음)
  → 스턴 없이 전투 계속
```

**디자인 의도**
- 반사에 성공하면 보너스 딜 타임 획득 — 보상 있는 선택지
- 실패(옆으로 피함)해도 피해 없음 — 첫 던전이므로 강제하지 않음
- 최종 관문의 가드 반사 기믹을 전투에서 다시 한 번 활용하는 구조
- 처음에는 모르고 피할 수 있고, 두 번째 발동 때 자연스럽게 시도하게 유도

---

### 처치 연출 (블루프린트 연출 포인트)

```
수호자 쓰러짐 → 전신 문양 빛이 서서히 꺼짐
  ↓
보스방 천장에서 빛이 내려와 중앙 제단을 비춤
  ↓
제단에서 던전 보상(아이템) 등장
  ↓
벽의 봉인 문양 전부 활성화 → 출구 문 개방
```

## 5. 블루프린트 연출 포인트 전체 정리

| 위치 | 연출 내용 | 주요 노드/기법 |

| 2구역 — 거울 퍼즐 | 빛 체인 실시간 렌더링, 문양 활성화 | Niagara Beam (Line Trace 체인) + Timeline + Dynamic Material Instance |

| 3구역 — 비밀방 | 가드 반사로 특수 문양 활성화 | Has Matching Gameplay Tag (ANS.Guard) + Reflect Vector + Niagara Beam |
