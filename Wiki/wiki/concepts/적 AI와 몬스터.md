# 적 AI와 몬스터

일반·정예 몬스터 규격, BT·AI 제어, 순찰에 관한 원자료 요약을 모은 주제 페이지입니다. 문장마다 끝의 링크가 출처이며, 절 이름으로 기획 요구사항·사람의 확정 결정·코드 구현 관찰·검증 범위·미결정을 구분합니다. 구현 관찰은 원자료 작성 시점의 코드 기준이고, 문서 갱신이나 Wiki lint 통과는 게임 동작 검증이 아닙니다.

## 요구사항

- Nameplate_System 기획서는 일반/정예 적이 시야(정면 콘 15M, 120도), 청각(원형 1M, 소리 쪽으로 돌아보기만 함), 피격(즉시 인식)으로 플레이어를 인식하도록 요구한다. ([[기획서 - Nameplate_System]])
- Nameplate_System 기획서는 적이 배치 지점에서 30M 이상 멀어지거나 플레이어가 CCTV룸 같은 인식 불가능 지역에 들어가면 추적을 끝내고, 걸어서 귀환한 뒤 HP/DP를 가득 채우도록 요구한다. ([[기획서 - Nameplate_System]])
- Patrol_Design 기획서는 정찰 역할 적이 순찰 중 플레이어를 인식하면 추격·공격하고, 추적 종료 조건을 만족하면 정찰 시작 지점으로 돌아가 순찰을 재개하도록 요구한다. ([[기획서 - Patrol_Design]])
- Patrol_Design 기획서는 순찰 속도를 기본 걷는 속도의 0.75배, 경로를 A -> B -> A 왕복, 지점 도착 시 5초 정지로 정한다. ([[기획서 - Patrol_Design]])
- Patrol_Design 기획서는 정찰 적의 감지·추적 종료 규칙을 Nameplate_System 기획서와 같게 두고, 감지 결과를 주변 적에게 전파하지 않도록 요구한다. ([[기획서 - Patrol_Design]])
- WX_BT_기능정리 문서는 RandomChoice 컴포지트가 하위 노드를 균등 확률로 무작위 선택하고, AvoidRepeat를 켜면 직전 실행 노드를 다음 선택에서 제외한다고 적는다. ([[기획서 - WX_BT_기능정리]])
- WX_BT_기능정리 문서는 CompareAttributeRatio 데코레이터가 두 능력치의 비율을 상수와 비교해 HP 50% 이하 패턴 전환 같은 비율 기반 분기를 BT에서 처리하게 한다고 적는다. ([[기획서 - WX_BT_기능정리]])
- WX_BT_기능정리 문서는 현재 WX 자체 BT 태스크가 없고, 추가 시 기능 개요·기본 동작·세부 옵션·사용 목적·사용 예시 양식으로 정리하도록 정한다. ([[기획서 - WX_BT_기능정리]])
- 레벨_배치용_잡몹 기획서는 잡몹이 PC를 인지하면 전투를 시작하고, PC가 8m 이내이면 3m 이내로 접근하도록 요구한다. ([[기획서 - 레벨_배치용_잡몹]])
- 레벨_배치용_잡몹 기획서는 3초 안에 3m 이내 접근에 성공하면 패턴 1·2 중 무작위로, 실패하면 돌진 패턴 3을 쓰고, 패턴 후 2초간 PC를 바라보며 걷도록 요구한다. ([[기획서 - 레벨_배치용_잡몹]])
- 레벨_배치용_잡몹 기획서는 모든 패턴이 신호 후 공격하며 1타 AM에 위치 보정을 넣도록 요구한다. ([[기획서 - 레벨_배치용_잡몹]])

## 확정 결정

- ABS_Soldier의 속성 행은 지금 동작을 유지하도록 TemplateEnemy로 재연결하기로 사용자가 정했고, 분신과 도플갱어는 함께 존재할 수 없다고 사용자가 확인했다. ([[작업 - ability-table-driven]])
- Patrol_Design 기획서는 정찰을 적 타입이 아닌 인스턴스 단위 정찰 역할로 정하고, 보스는 정찰 역할을 받을 수 없다고 정한다. ([[기획서 - Patrol_Design]])
- Patrol_Design 기획서는 정찰을 전투 트리거로 정하고 은신/잠입 처치 전용 시스템을 전제하지 않는다. ([[기획서 - Patrol_Design]])

## 구현 관찰

- BT 노드(ActivateAbility·ObserveAbility·MirrorMovement)는 GA_ 복귀 후 스펙 동적 태그 없이 CDO 에셋 태그로 어빌리티를 고르며, 솔저 BT가 Ability.Pattern.N 에셋 태그로 패턴을 발동함을 PIE로 확인했다. ([[작업 - ability-table-driven]])

## 미결정·충돌

- Nameplate_System 기획서는 인식 전파(군집 인식)를 레퍼런스에서만 확인 필요로 언급하고 자체 규칙으로는 정하지 않았다. ([[기획서 - Nameplate_System]])
- Patrol_Design 기획서의 복귀 지점(정찰 시작 지점)과 Nameplate_System 기획서의 귀환 지점(원래 배치 위치)이 같은지, 순찰 중 30M 기준점이 어디인지는 정해져 있지 않다. ([[기획서 - Patrol_Design]])
- WX_BT_기능정리 문서는 CompareAttributeRatio의 비교 연산자 종류와 분모가 0일 때의 처리를 정하지 않았다. ([[기획서 - WX_BT_기능정리]])
- 레벨_배치용_잡몹 기획서는 PC가 8m보다 멀 때의 행동과 2초 배회 뒤 반복 흐름을 정하지 않았다. ([[기획서 - 레벨_배치용_잡몹]])

## 원자료

- [[기획서 - Nameplate_System]] — 일반·네임드 몬스터 네임플레이트의 HP·DP 표시 구성, 시야·청각·피격 인식 규칙, 표시·숨김 조건과 보스 전용 규칙을 정의한 기획서
- [[기획서 - Patrol_Design]] — 정찰을 적 타입이 아닌 인스턴스 단위 정찰 역할로 정하고, 순찰·추격·귀환 단계와 A-B-A 순찰 경로, 무전파 감지 규칙을 정의한 기획서
- [[기획서 - WX_BT_기능정리]] — WX 자체 BT 기능으로 균등 확률 랜덤 컴포지트 RandomChoice와 능력치 비율 비교 데코레이터 CompareAttributeRatio를 정리하고 작성 규칙을 둔 문서
- [[기획서 - 레벨_배치용_잡몹]] — 명조 기관인형을 레퍼런스로 한 레벨 배치용 잡몹의 거리 기반 행동 흐름(8m 인지, 3m 접근, 3초 제한)과 패턴 3종을 정의한 짧은 기획서
- [[작업 - ability-table-driven]] — 어빌리티를 DataTable 행으로 구동하려던 전환 작업 기록으로, 여러 단계 구현 끝에 GA_ 에셋 방식으로 복귀해 테이블화 없이 체크리스트 7/7 통과로 마무리됐다.
