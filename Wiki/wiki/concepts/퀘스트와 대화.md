# 퀘스트와 대화

퀘스트 기획과 퀘스트·대화 표시 구조에 관한 원자료 요약을 모은 주제 페이지입니다. 문장마다 끝의 링크가 출처이며, 절 이름으로 기획 요구사항·사람의 확정 결정·코드 구현 관찰·검증 범위·미결정을 구분합니다. 구현 관찰은 원자료 작성 시점의 코드 기준이고, 문서 갱신이나 Wiki lint 통과는 게임 동작 검증이 아닙니다.

## 요구사항

- Wx_Quest 기획서는 메인 퀘스트 홀로 남은 마을 생존자를 마을 도착, 이장 대화, 진지 이동, 밸브 3개 작동, 엘리베이터 이동, 패널 코드 입력, 웨이브 전투, 공성포 발사 컷신의 8단계 목표로 구성한다. ([[기획서 - Wx_Quest]])
- Wx_Quest 기획서는 각 퀘스트 목표마다 목표 문구(Text)와 목표 인디케이터 대상(Vector 또는 Actor Reference)과 완료 조건을 정의하도록 요구한다. ([[기획서 - Wx_Quest]])
- Wx_Quest 기획서는 이장을 대화 목표 동안에만 대화 가능하게 하고, 대화 뒤에는 상호작용할 수 없게 하도록 요구한다. ([[기획서 - Wx_Quest]])

## 확정 결정

- 아직 없음

## 구현 관찰

- 대화 진행 입력은 WBP_DialogueScreen의 AdvanceButton.OnClicked가 WxViewModel_Dialogue.RequestAdvance를 부르고 리졸버가 이를 세션 Advance로 전달하는 경로로 처리된다. ([[작업 - dialogue-presentation-vm]])
- FWxOnQuestJournalChanged는 네이티브 멀티캐스트 델리게이트이며 UWxViewModelResolver_Quest가 VM을 소유자로 한 약한 람다를 걸고 DestroyInstance에서 RemoveAll(VM)로 끊는다. ([[작업 - quest-presentation-vm]])

## 검증 범위

- 퀘스트 수주·목표 갱신·완료 시 추적기 표시는 2026-09-23 사용자가 인게임에서 통과로 확인했다. ([[작업 - quest-presentation-vm]])

## 미결정·충돌

- Wx_Quest 기획서는 초안 상태이며, 5단계 목표 문구(공성포에 코드를 입력하십시오)와 완료 조건(엘리베이터 도착)이 서로 맞지 않는다. ([[기획서 - Wx_Quest]])
- Wx_Quest 기획서는 웨이브 스포너 구성을 담당자 재량으로 비워 두었고, 퀘스트 도중 사망 시 웨이브 처리 방식을 정하지 않았다. ([[기획서 - Wx_Quest]])
- 퀘스트 추적기 위젯이 GameState·퀘스트 컴포넌트보다 먼저 생기면 나중에 연결하지 않는 클라 복제 지연 제약이 남아 있다. ([[작업 - quest-presentation-vm]])
