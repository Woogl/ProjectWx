# 에디터 도구

AnimNotify 분류·라벨, DataTable 행 미리보기·참조 갱신 등 편집기 기능에 관한 원자료 요약을 모은 주제 페이지입니다. 문장마다 끝의 링크가 출처이며, 절 이름으로 기획 요구사항·사람의 확정 결정·코드 구현 관찰·검증 범위·미결정을 구분합니다. 구현 관찰은 원자료 작성 시점의 코드 기준이고, 문서 갱신이나 Wiki lint 통과는 게임 동작 검증이 아닙니다.

## 요구사항

- DataTable 행 미리보기는 데이터 없는 구조체를 {}로 간략히 표시하고 셀 툴팁도 셀과 같은 텍스트를 보여야 한다. ([[작업 - datatable-row-preview]])

## 확정 결정

- 타입별 ValidateMontage와 UWxAbilityMontageValidator는 사용자 지시로 제거했고, GA_와 세트의 IsDataValid 검증만 남겼다. ([[작업 - ability-table-driven]])
- AnimNotify 17종은 Attack·AbilityFlow·Effect·Movement·Presentation·Misc 6개 분류 색상으로 몽타주 타임라인에 표시하기로 확정됐다. ([[작업 - animnotify-categories]])
- 노티파이 색상 필드와 초기화는 WITH_EDITORONLY_DATA로, 17종 GetEditorColor 선언·정의는 WITH_EDITOR로 보호하기로 했다. ([[작업 - animnotify-categories]])
- AnimNotify 17종의 타임라인 라벨은 종류: 대표 값 하나 형식으로 쓰며, 클래스명 끝 _C를 떼고 미설정은 None, 스냅 비활성은 Off로 표시한다. ([[작업 - animnotify-labels]])
- DataTable 행 이름 변경 시 FDataTableRowHandle 참조를 자동 갱신하되 에셋은 Dirty로만 두고 저장은 사용자가 하기로 사용자가 정했다. ([[작업 - datatable-row-rename-reference-update]])
- 행 참조 갱신 기능은 위험할 수 있어 Wx 접두사 없는 범용 에디터 플러그인 DataTableRowFixup으로 분리하고, Editor Preferences > Wx에서 켜고 끄며 기본값은 켜짐으로 정했다. ([[작업 - datatable-row-rename-reference-update]])
- DataTable 행 이름 변경 시 FDataTableRowHandle 참조를 자동 갱신하되 에셋은 Dirty로만 두고 저장은 사용자가 하도록 사용자가 정했다. ([[결정 노트 - 2026-09-23-datatable-row-fixup]])
- 행 참조 갱신 기능은 범용 에디터 플러그인 DataTableRowFixup으로 분리하고 개인 설정 기본값을 켜짐으로 정했다. ([[결정 노트 - 2026-09-23-datatable-row-fixup]])
- WxToolset의 AddEnumVariable과 WxMVVMToolset 도구는 재사용을 위해 유지하기로 했다. ([[결정 노트 - 2026-09-23-item-viewmodel-unification]])
- 2026-09-25 사용자는 AnimNotify 타임라인 라벨을 종류: 대표 값 하나 형식으로 줄이기로 승인했고, 소켓·프리셋·오프셋·정지 거리·FOV는 Details에서 확인한다. ([[결정 노트 - 2026-09-25-animnotify-labels]])
- AnimNotify 라벨은 Row·에셋 이름을 임의로 자르지 않고 클래스 이름 끝 _C만 제거하며, 미설정은 None, 스냅 이동·회전 모두 비활성은 Off로 표시한다. ([[결정 노트 - 2026-09-25-animnotify-labels]])

## 구현 관찰

- WxAnimMontageToolset에는 몽타주 병합용 AppendMontage·RenameSection과, 섹션 경계 근처 노티파이 구간을 맞추는 SnapNotifyEndsToSections·SnapNotifyStartsToSections가 있다. ([[작업 - ability-table-driven]])
- 노티파이 색상은 프로젝트 설정 Wx → Wx Anim Notify Settings에서 조정하며 DefaultEditor.ini에 저장된다. ([[작업 - animnotify-categories]])
- DataTable 행 미리보기는 CustomizeChildren에서 현재 값과 초기 기본값의 엔진 JSON 표현을 재귀 비교해 빈 하위 구조체까지 {}로 축약하고 설정된 태그·컨테이너 값은 유지한다. ([[작업 - datatable-row-preview]])
- DataTableRowFixup은 INotifyOnDataTableChanged 리스너로 같은 행 메모리가 새 키로 옮겨진 경우만 이름 변경으로 판정하고, Asset Registry의 SearchableName 참조와 Dirty 패키지에서 대상을 찾는다. ([[작업 - datatable-row-rename-reference-update]])
- DataTableRowFixup은 수정한 StateTree를 UStateTreeEditingSubsystem::CompileStateTree로 재컴파일하고, RenameRow 트랜잭션 안에서 실행되어 Ctrl+Z 한 번에 함께 되돌아간다. ([[작업 - datatable-row-rename-reference-update]])
- 2026-09-23 추가된 WxMVVMToolset.SetBindingSourcePath는 WBP 바인딩 소스 경로 또는 S→D 변환 함수 인자 하나의 경로를 바꾸며 Python에서도 호출할 수 있고 D→S 방향은 지원하지 않는다. ([[결정 노트 - 2026-09-23-boss-battle-three-layer]])
- DataTableRowFixup은 행 수가 같고 사라진 이름이 하나이며 새 이름이 같은 행 메모리를 가리킬 때만 이름 변경으로 감지하고, 수정한 StateTree를 다시 컴파일한다. ([[결정 노트 - 2026-09-23-datatable-row-fixup]])
- WxMVVMToolset은 MVVM 바인딩 변환 함수 지정과 이벤트 목적지 변경을 UMVVMEditorSubsystem을 통해 수행하고 잘못된 인자 키는 스크립트 에러로 거부한다. ([[결정 노트 - 2026-09-23-item-viewmodel-unification]])
- WxToolset의 MVVM 이벤트 목적지 도구는 SetEventDestination으로 일반화되어 Self.함수 또는 뷰모델이름.함수 경로를 받는다. ([[결정 노트 - 2026-09-23-screen-classes-to-resolvers]])
- 커밋 5153da936으로 몽타주 도구에 섹션 경계 구간 시작을 옮기는 SnapNotifyStartsToSections가 추가되고 AM_Shared_Dodge 구간 9개가 보정됐다. ([[결정 노트 - 2026-09-25-ability-data-on-ga]])
- 2026-09-25 정적 확인 기준 AnimNotify 17종이 GetNotifyName_Implementation을 재정의해 Attack·Area·Finisher·Victim·Cutscene·Projectile·Summon·Despawn·Effect·Slow·Rush·Snap·Camera·Noise 종류와 Recovery·Combo Window·Use Item 고정 표식을 쓴다. ([[결정 노트 - 2026-09-25-animnotify-labels]])

## 검증 범위

- AnimNotify 분류 색상은 AI 정적 검사와 WxEditor Development 빌드를 통과했고, 사람이 에디터 재시작 후 6색·라벨 가독성·설정 저장 재로드를 확인했다. 패키지 빌드는 실행하지 않았다. ([[작업 - animnotify-categories]])
- AnimNotify 라벨 변경은 AI가 실행 코드 불변 비교와 Editor Development 빌드로 확인했고, 사람이 에디터 타임라인에서 17종 값 일치와 가독성을 통과로 확인했다. ([[작업 - animnotify-labels]])
- DataTable 행 미리보기 축약은 Editor Development 빌드와 제출 전 제거된 임시 회귀 테스트로 AI가 확인했고, 사람이 에디터에서 빈 구조체 축약·설정값 표시·툴팁을 통과로 확인했다. ([[작업 - datatable-row-preview]])
- DataTableRowFixup은 Development 빌드와 삭제된 임시 헤드리스 자동화 테스트로 AI가 확인했고, 사용자는 잘 된다고 수용했지만 확인한 구체 시나리오는 기록되지 않았다. ([[작업 - datatable-row-rename-reference-update]])
- DataTableRowFixup은 헤드리스 에디터 임시 자동화 테스트를 통과했고 사용자가 2026-09-23 에디터에서 동작을 확인했으나 구체 시나리오는 기록되지 않았다. ([[결정 노트 - 2026-09-23-datatable-row-fixup]])
- AnimNotify 라벨 축약 노트는 코드 정적 확인이며 에디터 타임라인 화면 표시는 검증하지 않았다. ([[결정 노트 - 2026-09-25-animnotify-labels]])

## 미결정·충돌

- DataTableRowFixup은 열려 있지 않은 레벨의 값 지정 배치 액터와 BP 그래프 핀 리터럴을 갱신하지 못하며, 저장 직후 1~2초 안의 재변경은 레지스트리 재스캔 전이라 놓칠 수 있다. ([[작업 - datatable-row-rename-reference-update]])
- DataTableRowFixup은 닫힌 레벨의 배치 액터, BP 그래프 리터럴, FName 행 참조, FCurveTableRowHandle은 갱신하지 않는다. ([[결정 노트 - 2026-09-23-datatable-row-fixup]])
