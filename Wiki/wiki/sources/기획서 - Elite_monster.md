# 기획서 - Elite_monster

- 원본: `Docs/CombatDesign/Elite_monster.md`
- 원자료 사본: `.raw/captured/cbaedec2f43d791ee90da776e29260366415dfd55a6aaf50b64f9e6de53d296f.md` (수집 2026-09-26, 재확인 기한 2026-10-26)

## 개요

`Docs/CombatDesign/Elite_monster.md`는 엘리트급 몬스터(중간보스) 기획서(요구사항)다. 적 규격은 `C:\ProjectWx\Docs\CombatDesign\CombatCommon\Enemy\적 규격서.md`를 따른다고 적혀 있다([[기획서 - 적 규격서]]). 엘리트는 조우·추적·일반공격·연속공격(붉은빛)·가드 불가(노란빛)까지 쓰고 필살기·페이즈 전환기는 쓰지 않는다. 일반급보다 체력·경직도·스태거 최대치가 모두 높고, 던전 핵심 동선에 배치되어 숏컷 개방·보상·지역 보스 패턴 예습 역할을 한다.

## 엘리트 01 — 양손 망치형(가칭)

### 확정 결정(문서에 "확정"으로 표시된 항목)

- **무기**: 양손 망치(확정). 자루 대비 헤드가 비정상적으로 큰 워해머, 다크소울 스모우 톤.
- **보스와의 관계**: 무기는 다르고, 느린 전조 + 패링 학습 톤만 공유. 보스(커스터, 창) 패턴 중 패링 학습 계열을 단순화해 가져온다.
  - 단발 패링: 보스 "크게 휘두르기" 열화판, 한 방 패링 성공 시 스태거 큰 폭 누적.
  - 연속 패링: 보스 "둔하게 치기" 열화판, 보스 6연타보다 짧게 압축.
- **가드 불가 패턴**: 1개만 채택(회피 학습, "연속 패링만 하면 안 되는 적" 신호).
- **외형**: 엣지 오브 투모로우 톤 외골격 파워드 슈트. 보스보다 더 기계적, 노출 메카닉 구조, 외골격 위 갑판, 풀커버.

### 요구사항: 배치

- 던전 01 2구역 2층(`Dungeon01_Detail.md` 2구역 리메이크 후 정면 동선). 약간 긴 좁은 직사각 통로, 측면 회피는 가능.
- 처치 시 2구역 엘리베이터 숏컷 개방 게이트이자 보스 패링 학습 예습.

### 요구사항: 패턴 구성(구성 확정, 디테일 작성 예정)

| 분류 | 동작 |
|---|---|
| 조우 | 플레이어와 5M까지 걸어서 접근(조우 시에만) |
| 추적 | 15M 이상 멀어지면 웅크렸다가 점프하며 망치 내려침 |
| 일반공격(단발 패링형) | 오른 어깨에서 망치를 크게 휘두름 |
| 연속공격(붉은빛, 연속 패링형) | 오른손 휘두르기 → 왼팔 올려치기 → 오른팔 망치 크게 내려침 |
| 가드 불가(노란빛, 회피 학습형) | 망치가 붉게 빛나며 머리 위에서 5번 빠르게 내려침 |

### 요구사항: 차별화 기믹 — 갑옷 파괴

- 그로기 진입 순간 갑옷 파편이 떨어지는 1회성 연출.
- 그로기 중에는 규격서 기본값대로 받는 피해 +30%.
- 그로기 종료 후 갑옷 파괴 상태가 유지되어 일정 시간(예: 10초) 받는 피해 +15% 추가.
- 갑옷 파괴는 전투당 1회. 재차 그로기 시에는 연출 없이 기본 그로기 규격만.
- 설계 의도: 패링 → 스태거 누적 → 그로기 → 갑옷 파괴 → 딜링 윈도우 확대라는 패링 보상 루프를 한 전투 안에서 학습시킨다.

## 미결정·충돌

- 원문 미확정 항목: 패턴 모션·전조 디테일, 복도 길이·폭(레벨디자인 확인), 갑옷 파괴 시각 표현, 스탯 전반(HP·경직도·스태거 최대치·그로기 지속 시간 미정, 갑옷 파괴 후 추가 피해 +15%는 후보).
- "행동 방침"은 "(무기 결정 후 작성)"으로 남아 있으나 무기는 이미 확정으로 표시돼 있다.
- 연속 패링이 "DP 누적"으로 갑옷 파괴를 트리거한다고 적지만, 같은 문서의 기믹 절과 [[기획서 - 그로기_시스템]]은 스태거 게이지 최대치 도달(그로기 진입)을 트리거로 쓴다. DP가 스태거 게이지와 같은 것인지 불명확하다.
- "그로기 지속 시간"을 별도 스탯으로 두는데, [[기획서 - 그로기_시스템]]은 그로기 종료를 스태거 게이지 자연 감소로 정의한다.
- 규격서 경로가 `CombatCommon/Enemy/` 하위로 적혀 있으나 이번 배정 원자료는 `Docs/CombatDesign/적 규격서.md`다. 보스 패턴 요약 출처도 `WX_첫_보스_기획서.docx`로 적혀 있다([[기획서 - WX_첫_보스_기획서]]).
