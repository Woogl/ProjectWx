# 기획서 - Patrol_Design

- 원본: `Docs/CombatDesign/Patrol_Design.md`
- 원자료 사본: `.raw/captured/0ff318ce2a70b1f95379fb31f827ed7c4462b133440d3560a949c6475c363698.md` (수집 2026-09-26, 재확인 기한 2026-10-26)

## 개요

`Docs/CombatDesign/Patrol_Design.md`는 적 정찰 기능의 **요구사항** 문서다. 문서 안에서 여러 항목이 "결정"으로 표시되어 있는데, 이것은 기획서 작성자가 정한 설계 결정이다(사용자 발화 기록이 아니다). 감지·추적 종료·귀환 규칙은 따로 정의하지 않고 [[기획서 - Nameplate_System]]을 따른다.

## 적용 방식 (기획서의 결정)

- 정찰은 적 "타입"이 아니라 **인스턴스 단위로 지정하는 "정찰 역할"**이다. 레벨디자이너가 필드에 배치한 개별 적에게 켠다.
- 일반/엘리트 몬스터는 지정할 수 있고 보스는 지정할 수 없다.
- 명칭은 "정찰 역할"로 통일한다.

## 정찰의 목적 (기획서의 결정)

- 정찰은 **전투 트리거 중심**이다. "들키면 교전 시작"하는 스위치 역할을 한다.
- 우회·타이밍 회피는 선택지로 남기지만 기본 흐름은 전투로 수렴한다. 잠입 실패의 페널티는 전투 진입뿐이다.
- 은신/잠입 처치 전용 시스템을 전제하지 않고, 긴 은신 구간이나 잠입 강제 같은 본격 잠입 게임 문법도 채택하지 않는다(전투 템포 손상을 줄이려는 목적).

## 행동 단계 (요구사항)

| 단계 | 행동 → 전환 조건 |
|---|---|
| 순찰 | 지정 경로를 천천히 순찰 → 플레이어를 인식하면 추격 |
| 추격 | 추격하며 사정거리에 들어오면 공격 → 추적 종료 조건을 만족하면 귀환 |
| 귀환 | 정찰 시작 지점으로 돌아간 뒤 순찰 재개 |

## 순찰 방식 (기획서의 결정)

- 지정 경로를 순찰한다.
- 순찰 속도는 기본 걷는 속도의 0.75배다.
- 순찰 지점은 점에서 점으로 A → B → A 구조다.
- 순찰 지점에 도착하면 5초간 멈춘다.

## 감지·추적 종료 (요구사항)

- 감지 규칙은 네임플레이트 기획과 같다.
- 감지해도 주변 다른 적은 영향을 받지 않는다(전파 없음).
- 추적 종료 조건과 복귀는 네임플레이트 기획과 같고, 복귀 후 정찰 시작 지점에서 정찰을 다시 시작한다.

## 미결정·충돌

- [[기획서 - Nameplate_System]]은 추적 종료 후 "원래 배치 위치"로 귀환한다고 적고, 이 문서는 "정찰 시작 지점"으로 복귀한다고 적는다. 정찰 역할 적에게 두 지점이 같은지는 명시되어 있지 않다.
- [[기획서 - Nameplate_System]]의 추적 종료 기준은 "원 위치(배치 지점) 기준 30M"이다. 순찰로 이동 중인 적에게 기준점을 순찰 경로로 볼지 시작 지점으로 볼지는 정해져 있지 않다.

- Patrol_Design 기획서는 정찰을 적 타입이 아니라 레벨디자이너가 개별 배치 적에게 켜는 정찰 역할로 정하며, 일반/엘리트는 지정할 수 있고 보스는 지정할 수 없다고 정한다. ^c1
- Patrol_Design 기획서는 순찰 속도를 기본 걷는 속도의 0.75배로, 순찰 경로를 A -> B -> A 구조로 정하고 순찰 지점 도착 시 5초간 정지하도록 요구한다. ^c2
- Patrol_Design 기획서는 정찰 적이 플레이어를 감지해도 주변 다른 적에게 전파하지 않도록 요구한다. ^c3
