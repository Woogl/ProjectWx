# 기획서 - 캐릭터 스탯 명세서

- 원본: `Docs/CombatDesign/캐릭터 스탯 명세서.md`
- 원자료 사본: `.raw/captured/3197c6a60425d04df84a8e196561a46a572178659f59e6827cce0facd204a5f9.md` (수집 2026-09-26, 재확인 기한 2026-10-26)

## 개요

`Docs/CombatDesign/캐릭터 스탯 명세서.md`는 PC와 적이 공통으로 쓰는 스탯 규격 **초안**이다. [[기획서 - PC규격서]]의 자원·회피·가드·패링을 바탕으로, 데이터 테이블 `DT_CharacterAttribute`에 있는 항목과 추가 예정 스탯을 함께 정리한다. 스탯명은 코드·데이터 표기(`MaxHP`, `CritRate`, `CritDMG`)를 우선하며, 에디터에 띄어쓰기로 보여도 붙여 쓴다.

## 스탯 목록 (요구사항)

| 스탯 | 대상 | 요약 |
|---|---|---|
| `HP`/`MaxHP` | PC·적 | 0이면 사망 어빌리티. PC 자연 회복 없음 |
| `MP`/`MaxMP` | PC | 공격 적중·패링·극한회피로 획득, 스킬에 소모 |
| `UP`/`MaxUP` | PC | 스킬 발동·적중으로 획득, `UP >= MaxUP`면 궁극기 가능, 사용 시 0 |
| `SP`/`MaxSP` | PC | 일반 가드 자원 |
| `DP`/`MaxDP`(가칭) | 적 | 그로기용 누적값(스태거 게이지 구현 후보) |
| `ATK`, `DEF` | PC·적 | 피해 계산 공격·방어 수치 |
| `CritRate`, `CritDMG` | PC | `%` 단위 |
| `SPD`, `ASPD` | PC·적 | 이동 속도·공격 AM 속도 배율 |
| `PP`(가칭) | PC·적 | 경직 저항 |

## 공통 규칙 (요구사항)

- 현재값은 `0 <= 현재 <= Max`로 제한한다.
- 최대값이 0이면 그 대상은 해당 시스템을 쓰지 않는 것으로 보고 충전·감소를 무시하거나 예외 처리한다.
- 최대값 증가 시 현재값 유지, 감소 시 초과분을 새 최대값으로 보정. 전투 시작은 데이터 테이블 Row 기준 초기화, 리스폰·재도전은 초기값 재적용.

## 개별 규칙

- `SP`: 가드 50% 경감, 경감량만큼 SP 소모(피해 40 가드 → HP 20, SP 20), SP 0이면 가드 해제·1초 그로기, 해제 후 4초에 전부 회복.
- `DP`(초안): 특정 공격 피격과 패링 성공 시 증가, `DP >= MaxDP`면 그로기, 이후 천천히 회복해 5초 후 0이 되며 그로기에서 회복. 보스는 `MaxDP`를 높게 둔다.
- `PP`(초안): 공격 경직치 >= 대상 현재 `PP`면 해당 히트 리액션 재생, 낮으면 무시. 어빌리티 사용 중 `PP`를 일시 증가(예: 보스 기본 30 + 공격 중 60 = 90이면 경직치 30은 무시, 100은 끊김). `DP`는 누적형 그로기, `PP`는 순간 경직 저항으로 구분한다.
- `ATK`: 임시 예시 `기본 피해량 = ATK × 어빌리티 피해 계수`. 최종 공식은 별도 확정 필요.
- `DEF`: 방어 공식(감산·비율·레벨 보정), 최소 1 피해 보장, 가드 50%·치명타 전후 적용 순서가 결정 필요로 남아 있다.
- `CritRate`: 0~100 난수가 `CritRate` 이하이면 치명타, 100 초과는 100으로 취급.
- `CritDMG`: `기본 피해 × (1 + CritDMG / 100)`, 50이면 50% 추가.
- `SPD`: 이동 속도에만 적용. `ASPD`: 공격 AM 재생 속도에만 적용하고 가드·회피·사망 AM은 제외. `ASPD`는 판정·콤보 입력·캔슬 타이밍을 흔들 수 있어 함께 검증해야 한다.

## 처리 흐름 초안

기본 피해: 공격 판정 → ATK·계수 → DEF → 치명타 → 가드/패링/회피 확인 → 최종 피해 → HP 감소 → PP 비교 → DP 증가 → 사망·경직·스태거·그로기·넉다운 전환. 패링·일반 가드·극한회피 각각의 스탯 처리 흐름도 초안으로 적혀 있다(극한회피는 MP 획득 + 회피 스택 1 회복).

## 미결정·충돌

- 문서가 스스로 미정으로 둔 항목: PP 증가 적용 방식, 어빌리티별 공격 경직치 기준표, 보스 핵심 패턴·페이즈 전환 중 히트 리액션 면역, 슈퍼아머 브레이크 기준, ATK·DEF·스킬 계수 피해 공식.
- `DP`·`PP`는 이름부터 가칭이다.
- [[기획서 - 전투 방향 변경에  따른 시스템 수정 요구사항]]가 가드·저스트 가드를 막으므로 `SP`와 패링·가드 처리 흐름이 바뀌어야 한다. 이 문서의 패링 흐름(가드 입력 성공)은 변경 문서의 공격 적중형 패링과 다르다.
- `CritDMG` 50 = 50% 추가 해석은 [[기획서 - 명조 PC 시스템 역기획서]]의 치명타 피해 150% 배율 표현과 다르다.
- [[기획서 - WA_PC_규격서]]의 궁극기 게이지·스태미나·고유 자원 체계와 이 문서의 `MP`/`UP`/`SP`가 어떻게 대응하는지 정해져 있지 않다.
