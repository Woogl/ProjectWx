# 기획서 - 에스트병 기획서

- 원본: `Docs/CombatDesign/에스트병 기획서.md`
- 원자료 사본: `.raw/captured/af0d44bf8a57ec6faa9a5a46b78a004fb1addee291ac72a11deef26ab96d9b85.md` (수집 2026-09-26, 재확인 기한 2026-10-26)

## 개요

`Docs/CombatDesign/에스트병 기획서.md`(문서 제목: 포션 시스템 초안)는 전투 중 제한 횟수만 쓸 수 있고 특정 지점에서 다시 충전되는 회복 수단을 정의한다. 일반 소비형 아이템이 아니다. 현재 단계에서는 성장 요소(최대 수량·회복량 증가, 강화)를 넣지 않고 후순위로 미룬다. [[기획서 - PC규격서]]가 포션 마시기 규칙을 이 문서로 위임한다.

## 목적

전투 지속성(실수 1~2번에 바로 죽지 않는 완충), 보스 패턴 학습 시간 확보, 사용 중 빈틈으로 리스크/리턴 제공, 향후 성장 요소로 확장 가능성.

## 기본 규칙·수치 (요구사항)

- 임시명 회복통, 대상 PC, 기본·최대 소지 4개, 회복량 최대 체력 40%.
- 버튼 입력 시 포션 사용 애니메이션 재생. 포션 사용 GA 실행 시 수량 1 감소. 수량 0이면 GA가 실행되지 않는다.
- 사용 중 걷기·대시 이동 가능, 기본적으로 캔슬 불가.
- 회복은 애니메이션 지정 프레임에 적용된다(즉시 아님).

## 사용 가능 상태 (요구사항)

- 가능: 일반 이동, 달리기.
- 불가: 기본 공격, 강공격, 스킬, 회피, 가드, 패링, 피격 리액션, 다운, 사망 중.
- 사용 중 가능: 이동, 달리기, 피격, 사망. 사용 중 불가: 공격, 스킬, 회피, 가드, 포션 중복 사용.

## 피격 처리 (요구사항)

- 포션은 GA 실행 즉시 소비된다.
- 사용 중 피격되면 경직이 발생해 GA가 캔슬된다.
- 회복 프레임 전 피격: 사용 실패(회복 없음, 포션은 이미 소비). 회복 후 피격: 회복 적용 후 피격 리액션.
- 회복 전 회피·캔슬 입력은 기본적으로 불가. 사망 피해를 받으면 사망 처리가 우선.

## 충전 규칙 (요구사항)

화톳불, 보스전 재도전, 사망 후 재시작에서 최대 수량으로 충전한다.

## 미결정·충돌

- 포션 이름은 임시명이며 성장 요소는 추후 추가 예정이다.
- 사용 가능 상태 표에 가드·패링이 있지만 [[기획서 - 전투 방향 변경에  따른 시스템 수정 요구사항]]는 가드·저스트 가드를 막는다.
- [[기획서 - PC규격서]]의 후딜 캔슬 목록에는 포션 마시기가 AN_StartRecovery 이후 다른 GA를 캔슬하고 발동할 수 있는 GA로 들어 있다. 이 문서의 기본 공격·강공격·스킬 중 사용 불가 규칙과 어떻게 맞물리는지 명시되어 있지 않다.

## 핵심 주장

- 에스트병 기획서는 포션을 기본 4개 소지, 최대 체력 40% 회복으로 두고 화톳불·보스 재도전·사망 후 재시작에서 최대 수량으로 충전하도록 요구한다. ^c1
- 에스트병 기획서는 포션을 GA 실행 즉시 1개 소비하고, 애니메이션 회복 프레임 전에 피격되면 회복 없이 실패하도록 요구한다. ^c2
- 에스트병 기획서는 포션 사용 중 이동·달리기는 허용하고 공격·스킬·회피·가드·중복 사용은 막도록 요구한다. ^c3
