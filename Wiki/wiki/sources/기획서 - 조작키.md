# 기획서 - 조작키

- 원본: `Docs/CombatDesign/조작키.MD`
- 원자료 사본: `.raw/captured/e01725c9c8a679b5977bf257c832757663de20fde4cbbd961e78c7d49ed92d94.md` (수집 2026-09-26, 재확인 기한 2026-10-26)

## 개요

`Docs/CombatDesign/조작키.MD`는 인게임 기능별 엑스박스 패드 입력, 키보드/마우스 입력, 아웃게임 기능을 한 표로 정리한 문서다. 스텔라블레이드 방향(가드·스킬 4종·그로기 피니시) 기준의 배치다.

## 조작 배치 (요구사항)

| 기능 | 엑스박스 | 키보드/마우스 | 아웃게임 |
|---|---|---|---|
| 평타 | X | 마우스 좌클릭 | - |
| 강공격 | Y | 마우스 우클릭 | - |
| 점프 | A | 스페이스바 | 확인 |
| 구르기 | B | 쉬프트 | 취소 |
| 이동 | 왼쪽 스틱 | WASD | 리스트 이동 |
| 리스트 이동 | 방향키(왼쪽) | - | 리스트 이동 |
| 가드 | LB | Q | - |
| 스킬 | LB + XYAB | 1, 2, 3, 4 | - |
| 특수입력 | LT | E | - |
| 상호작용, 그로기 피니시 | RB | F | - |
| 락온 | R3 | 마우스 휠 클릭 | - |
| 메뉴화면 | 삼자 버튼 | ESC | 인게임 화면으로 이동 |

패드에서 가드(LB)와 스킬(LB + XYAB)이 같은 LB를 공유한다.

## 미결정·충돌

- [[기획서 - 전투 방향 변경에  따른 시스템 수정 요구사항]]는 가드를 막고 스킬 키를 `E` 하나로 바꾸므로 `Q` 가드, `1, 2, 3, 4` 스킬, `E` 특수입력 배치와 충돌한다.
- 같은 변경 문서는 그로기 시 앞잡을 비활성화하므로 `F`의 그로기 피니시 역할과 맞지 않는다.
- [[기획서 - 명조 PC 시스템 역기획서]]는 대시를 Shift·마우스 우클릭, 강공격을 좌클릭 길게, 공명 해방을 R, 에코를 Q로 적어 이 표의 우클릭 강공격·Q 가드와 다르다.

## 핵심 주장

- 조작키 문서는 키보드에서 평타를 마우스 좌클릭, 강공격을 우클릭, 가드를 Q, 스킬을 1~4, 특수입력을 E, 상호작용·그로기 피니시를 F로 배치한다. ^c1
- 조작키 문서는 엑스박스 패드에서 스킬을 LB + XYAB 조합으로, 가드를 LB로 배치한다. ^c2
