# 보스 공통 BT 기획 초안

- 종류: 기획서(공통 BT 설계)
- 상태: 초안

## 요지
- 패턴군을 먼저 고르고 그 안에서 실제 패턴을 정한다. 우선순위가 분명하고 확장이 쉬우며 반복이 준다.
- 루트 Selector는 페이즈 전환 → 거리 조정 → 강공격군 → 일반공격군 → 비공격 순이다.
- 페이즈 전환은 HP가 임계치 아래이고, 아직 안 썼고, 전환 중이 아닐 때 1회 실행한다. 예시는 HP 70% 이하 P2, 30% 이하 P3이다.
- 거리 조정은 유효 거리 밖일 때 추격·돌진·점프 접근·재정렬을 한다. 공격보다 먼저 판단한다.
- 강공격군은 후보 수집 → 최근 패턴 제외 → 1개 선택 → 실행 → 재사용 제한 시작 순이다.
- 일반공격군은 별도 쿨 없이 같은 공격의 연속만 막고, 강공격이 불가능할 때의 기본 루프가 된다.
- 비공격(도발·포효·준비 동작)은 빈도를 제한하고 메인 루프보다 우선하지 않는다.

## 미정
- 유효 거리, 패턴 후보, 최근 사용 판정, 랜덤·가중치 규칙, 도발 조건, 페이즈별 BT 교체 방식, 그로기 처리.
