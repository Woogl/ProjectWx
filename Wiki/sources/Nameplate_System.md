# 네임플레이트 기획서

- 자료: `Docs/CombatDesign/Nameplate_System.md` (1735fc787)
- 종류: 기획서(UI·적 인식 규칙)
- 상태: 확정. 락온 시 은폐 적 제외만 잠정이다.

## 요지
- 구성은 HP 게이지, DP 게이지(정의는 전투 기획서에 위임), 하단 디버프다. 일반·네임드 적은 이름을 표시하지 않는다.
- 인식: 시야는 정면 부채꼴 15m·120°, 청각은 원형 1m(소리 쪽으로 돌아보지만 바로 인식하지 않음), 피해를 받으면 즉시 인식한다.
- 추적 종료: 배치 지점에서 30m 넘게 멀어지거나 인식 불가 지역에 들어가면 인식을 풀고 걸어서 돌아간다. 돌아오면 HP·DP가 가득 찬다.
- 표시: 기본 숨김, 인식·락온 시 노출, 추적 종료 시 즉시 숨김이다. 벽에 가려도 그대로 그리고, 동시 표시 상한이 없으며, 겹치면 카메라에 가까운 적이 위다.
- 보스는 보스룸에 들어오면 상시 표시하고, 화면 상단에 큰 이름과 HP·DP를 둔다.
- 레퍼런스는 스텔라 블레이드와 엘든 링이다.

## 결정
- 위 표시 규칙과 인식 수치. 06-26에 청각 거리를 3m에서 1m로 줄였다.

## 미정
- 은폐된 적을 락온 대상에서 뺄지, DP의 정의.
