# 초반 구간 퀘스트 기획서

- 자료: `Docs/LevelDesign/Wx_Quest.md` (ba33d69ec)
- 종류: 기획서
- 상태: 초안(헤더에 명시)

## 요지
- 메인 퀘스트 '홀로 남은 마을 생존자'다. 시작은 불타는 마을, 보상은 적 기지 보호막 1겹 제거와 많은 골드, 소요 15분이다.
- 이장이 공성포 코드를 건네고 복수를 부탁한 뒤 기절한다. 코드는 아이템이 아니라 대화와 시스템 메시지로 얻는다.
- 단계: 마을 도착 → 이장 대화 → 진지로 이동 → 밸브 3개 작동 → 엘리베이터 도착 → 패널에 코드 입력 → 웨이브 격퇴 → 발사 컷신.
- 밸브는 순서가 없고 작동 후 상호작용할 수 없으며, 옆 파이프의 머티리얼이 바뀐다.
- 진지 앞 경비병 시신의 명령서 3장이 밸브 3기를 다 열어야 발전기 패널이 켜진다는 힌트를 준다.
- 상호작용 문구는 "F - 대화하기", "F - 문서 읽기", "F - 밸브 작동", "F - 코드 사용", "F - 열기"다.

## 결정
- 07-31 화포를 공성포로 바꿨다.
- 08-28 보상을 보물상자 생성에서 골드 직접 지급으로 바꿨다.
- 08-29 하부 장치를 기어에서 밸브로 확정했다.

## 미정
- 웨이브 구성, 골드 수량, 찢긴 메시지 원문, 관련 문서 3종(저장소에 없음).
- 소요 15분인데 구간 합은 20분이다. 이장과 촌장, 시작 지점 서술이 섞여 있다.
