# Project WX PC 규격서

## 1. PC 구조

PC(Player Character)는 다음 요소로 구성한다.

1. 속성
2. 캐릭터 스탯
3. 캐릭터 보유 자원
4. 공용 어빌리티
5. 개별 어빌리티

---

## 2. 속성

캐릭터 속성은 총 6종으로 구성한다.

| 속성 ID | 속성 |
|---:|---|
| 1 | 회절 |
| 2 | 인멸 |
| 3 | 기류 |
| 4 | 전도 |
| 5 | 용융 |
| 6 | 응결 |

- 회절을 1번으로 지정하며, 속성 ID는 1번부터 6번까지 사용한다.
- 캐릭터는 6종 중 하나의 속성을 보유한다.
- 무속성 피해는 존재하지만 캐릭터 속성에는 포함하지 않는다.
- 무속성 여부는 피해 데이터에서 별도로 관리한다.

---

## 3. 캐릭터 스탯


### 3.1 기본 스탯

| 스탯 | 설명 |
|---|---|
| 최대 HP | 캐릭터가 보유할 수 있는 HP의 최대치 |
| 최대 궁극기 게이지 | 캐릭터가 보유할 수 있는 궁극기 게이지의 최대치 |
| 최대 스태미나 | 캐릭터가 보유할 수 있는 스태미나의 최대치 |
| 고유 자원 최대 보유치 | 캐릭터가 보유할 수 있는 고유 자원의 최대치 |
| 공격력 | 피해량 계산에 사용하는 공격 능력치 |
| 방어력 | 받는 피해량 계산에 사용하는 방어 능력치 |
| 치명타 확률 | 공격이 치명타로 적용될 확률 |
| 치명타 피해 | 치명타 발생 시 적용되는 피해 배율 |
| 공명 효율 | 궁극기 게이지 획득량에 적용되는 효율 기존 얻는 회복량에 곱해서 적용 |

## 4. 캐릭터 보유 자원

캐릭터 보유 자원은 전투 중 변동하는 현재 값을 관리한다.

| 자원 | 상한 기준 | 주요 사용처 및 감소 조건 |
|---|---|---|
| 현재 HP | 최대 HP | 피해를 받거나 HP를 소모하는 어빌리티를 사용할 때 감소한다. |
| 현재 궁극기 게이지 | 최대 궁극기 게이지 | 궁극기를 발동할 때 사용한다. |
| 현재 스태미나 | 최대 스태미나 | 일반적으로 강공격, 회피, 달리기를 사용할 때 소모한다. 캐릭터에 따라 공중 공격 등에도 사용할 수 있다. |
| 현재 고유 자원 | 고유 자원 최대 보유치 | 캐릭터별 고유 어빌리티를 발동하거나 유지할 때 사용한다. 구체적인 사용처와 소모량은 개별 어빌리티에서 정의한다. |

- 각 자원은 대응하는 최대치 스탯을 초과할 수 없다.
- 최대치가 감소하여 현재 보유량보다 낮아질 경우 현재 보유량이 낮아진 최대치와 같아진다.
- 자원의 최솟값은 0이다.
- 최대치가 변경되더라도 현재 값과 최대 값은 별도로 관리한다.
- 자원을 사용하는 어빌리티는 발동 조건, 소모량 및 소모 시점을 개별 어빌리티에서 정의한다.
- 자원이 부족한 경우 해당 자원을 사용하는 어빌리티를 발동할 수 없다.

## 5. 공용 어빌리티

공용 어빌리티는 모든 PC가 공통된 입력과 판정 구조로 사용하는 행동이다.
일반적으로 공격 스킬 이외의 시스템으로 느껴지는 요소들이 공용 어빌리티로 관리된다.

| 분류 | 어빌리티 |
|---|---|
| 회피 | 회피, 극한 회피|
| 이동 | 점프, 달리기 |
| 피격 | 경직, 에어본 |
| 락온 | 락온 |
| 상호작용 | 상호작용 |

### 5.1 공용 어빌리티 규칙

- 모든 PC는 공용 어빌리티에 대응하는 실행 수단을 보유한다.
- 입력 체계와 기본 판정 규칙은 공통으로 사용한다.

## 6. 개별 어빌리티

개별 어빌리티는 캐릭터마다 따로 관리하는 어빌리티를 뜻한다.
일반적으로 개별 캐릭터 기획에 들어가는 요소를 개별 어빌리티로 관리한다.
개별 어빌리티 중 공용 어빌리티 대신 사용되는 것이 있을 수 있다.

| 분류 | 어빌리티 |
|---|---|
| 공격 | 일반 공격, 강공격, 낙하공격, 공중공격, 회피반격 |
| 앞잡 | 앞잡 |
| 스킬 | E스킬, 고유스킬 |
| 궁극기 | 궁극기 |
개별 어빌리티는 다음 항목을 포함할 수 있다.

- 캐릭터 고유 자원을 획득하거나 소모하는 행동
- 특정 조건에서 활성화되는 추가 입력 및 후속 공격
- 캐릭터 전용 강화 상태 또는 자세
- 캐릭터 전용 패시브 효과
- 캐릭터 고유 이동 및 방어 행동

### 6.1 개별 어빌리티 규칙

- 개별 어빌리티는 해당 캐릭터의 폴더를 따로 파서 관리한다.
- 공용 어빌리티와 동일한 입력을 사용할 경우 별도의 발동 조건이나 판정을 가지면 개별 어빌리티로 분류 공용 어빌리티를 해당 캐릭터의 ABS에서 제거, 어빌리티를 따로 관리한다.
- 고유 자원을 사용하는 개별 어빌리티는 소모량, 획득량, 최대 보유치 및 초기화 조건을 GA에서 정의한다.
- 강화 상태를 사용하는 개별 어빌리티는 진입 조건, 유지 조건, 종료 조건 및 상태 중 변경되는 행동을 GA에서 정의한다.
