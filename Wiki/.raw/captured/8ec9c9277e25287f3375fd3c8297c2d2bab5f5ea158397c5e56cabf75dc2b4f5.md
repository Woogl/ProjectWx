# 상호작용 목록과 엘리베이터 버튼의 사람 확인 범위

## 출처

[작업 기록](../../../.agents/workflow/tasks/interaction-list-vm-simplification.md)의 상태·다음 행동·확정 설계·구현·테스트 체크리스트·사용자 결과를 2026-09-26 읽었다. 파일 SHA-256은 `19a65edd6b81898aab59ec5ce562a265be8f726d66eebf4c0726aad6051ded1e`이며 접수 해시와 일치한다.

사람 체크리스트 6/6 통과의 근거는 `이우성 2026-09-25`다. 결과 기록 시각은 `2026-09-25T17:21:48.320Z`다. 결과 원문:

> 통과 · 목록 표시
> 통과 · 휠 선택
> 통과 · 범위 이탈·리스폰
> 통과 · 행 표시
> 통과 · 탑승칸 버튼 잠금
> 통과 · 코드 리뷰

## 확인 범위

- 겹친 대상들의 목록이 보이고 선택지가 여러 개인 장치는 행이 여러 개 표시된다.
- 휠로 선택 표시와 외곽선이 함께 움직이며 선택한 선택지가 실행된다.
- 범위를 벗어나면 목록이 사라지고 리스폰 뒤에도 동작한다.
- 엘리베이터 탑승칸 버튼은 `Floor N`으로 표시되고 픽업 행의 키 아이콘과 이름은 한 번씩만 보인다.
- 비활성 상태에서 탑승칸 버튼이 잠기고 대기 상태의 목록에는 다른 층만 표시된다. 대기 상태에서 엘리베이터가 와 있는 층의 호출 버튼은 잠긴다.
- 상호작용 목록 VM과 엘리베이터 버튼 잠금 변경의 코드 리뷰가 통과했다.

호출 버튼 잠금은 작업 기록의 B안과 함께 해석한다. `bWakeOnCall=true`인 비활성 상태에서는 밖 호출로 깨울 수 있고 현재 층 호출도 허용한다. 체크리스트의 잠금 결과를 모든 상태에서 현재 층 호출을 금지한다는 뜻으로 확대하지 않는다.

## 검증 경계

기존 [목록 VM 원자료](2026-09-23-interaction-list-vm.md)와 [엘리베이터·FText 저장 원자료](2026-09-23-instanced-struct-ftext-default-save-fail.md)의 인게임 미검증 설명을 위 항목 범위에서 보완한다. 기존 원자료는 당시 관찰로 보존한다.

이번 처리는 사람 결과의 편찬이며 AI가 빌드·BP 컴파일·게임·에셋 저장을 다시 실행한 결과가 아니다. 사람 결과에는 네트워크 모드와 테스트 맵이 명시되어 있지 않다. 선택 전환 애니메이션, 스캐너의 늦은 주입, 활성화 레버와 초기 활성화 여부는 이번 확인으로 검증되거나 구현된 것이 아니다. 작업 상태·승인 정본은 Workflow에 유지한다.
