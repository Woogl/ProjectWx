# WX 게임 루프

- 자료: `Docs/SystemDesign/WX게임루프.pdf` (d1c27650b)
- 종류: 사양서(아웃게임 화면 흐름, 04-25)
- 상태: 사실상 낡음. 스테이지·세이브 슬롯 구조이고, 이후 오픈월드로 바뀌었다.

## 요지
- 새 게임: 메인 → 캐릭터 3명 중 선택 → 1스테이지 → 클리어 → 세이브 화면 → 다음 스테이지.
- 이어하기: 메인 → 세이브 슬롯 선택 → 저장된 스테이지에서 시작.
- 세이브 화면은 슬롯 5칸(이름·초상화·진행 스테이지)이고, 덮어쓰기 확인 팝업이 있다.
- 패드 A는 확인, B는 뒤로다.

## 미정
- 환경설정 화면, 스테이지 수, 실패·재도전 흐름.
