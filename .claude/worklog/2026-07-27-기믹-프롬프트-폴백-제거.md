# 기믹 프롬프트 폴백 제거

## 계획

### 목표
상호작용 프롬프트는 `Enable Interaction` ST 태스크가 상태 진입 시 영역별로 주입하는 것이 현재 설계다. 그 이전의 잔재인 베이스 필드 `InteractionPrompt` 와 폴백 훅 `GetDefaultInteractionPrompt` 를 없애, 프롬프트의 출처를 ST 한 갈래로 좁힌다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmick.h` | `InteractionPrompt` 필드와 `GetDefaultInteractionPrompt` 선언 삭제, `GetInteractionPrompt` doc 갱신 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmick.cpp` | `GetInteractionPrompt` 를 현재 값 조회 후 없으면 공백 반환으로 축약 | 수정 |
| `Plugins/WxWorld/.../Public/Gimmick/WxElevator.h`, `Private/Gimmick/WxElevator.cpp` | 폴백 override 와 영역별 프롬프트 필드 3개 삭제, 클래스 doc 정리 | 수정 |
| `WxDoor.h`·`WxCheckPoint.h`·`WxTreasureChest.h`·`WxSpawnConsole.h`·`WxCutsceneTrigger.h`·`WxAlarmConsole.h`·`Source/WxGame/WorldObject/WxLaserCorridor.h` | "프롬프트는 베이스 InteractionPrompt" 주석 갱신 | 수정 |
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | 태스크 doc 의 기본 프롬프트 폴백 언급 2곳 갱신 | 수정 |

### 접근 방식
- **폴백 층 제거**: `GetInteractionPrompt` 는 ST 가 그 메시에 세팅한 값을 돌려주고, 없으면 공백이다. 자식이 문구를 고르는 훅도 사라져 프롬프트는 전부 ST 에셋에서 author 된다.
- **엘리베이터 영역별 문구도 ST 로**: 영역별 고정 문구 필드 3개는 어떤 에셋에서도 author 된 적이 없어(전부 공백) 제거해도 표시가 달라지지 않는다. 이미 ST_Elevator 가 상태별로 세 영역의 문구를 채우고 있다.
- **에셋은 사용자 몫**: 폴백에만 의존하던 5개(문·경보 콘솔·스폰 콘솔·컷신 트리거·레이저 복도)는 제거 후 프롬프트가 공백이 된다. 앞의 셋은 기존 `Enable Interaction` 에 `Prompt` 를 채우면 되고, 뒤의 둘은 태스크 자체가 없어 새로 추가해야 한다. 이번 작업은 코드까지만 한다.

### 구현·결정과 그 이유
- **폴백 층을 통째로 걷어냄**: 프롬프트가 ST 태스크와 코드 두 곳에서 올 수 있으면 "왜 이 문구가 나오는가"가 두 갈래로 갈린다. 조회를 영역별 현재 값 한 번으로 줄여 상태가 문구의 단일 원천이 되게 했다.
- **엘리베이터 영역별 필드도 함께 제거**: 어떤 에셋에서도 author 된 적 없는 빈 값이라 지워도 표시가 달라지지 않고, ST_Elevator 가 이미 세 영역의 문구를 상태별로 채우고 있어 자리만 중복이었다.
