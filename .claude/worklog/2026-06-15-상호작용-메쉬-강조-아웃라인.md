# 상호작용 대상 메쉬 강조(아웃라인) 효과

## 계획

### 목표
상호작용 범위 진입 시 대상 오브젝트에 시각 피드백이 없어 무엇이 상호작용 가능한지 알기 어렵다. 로컬 플레이어가 `UWxInteractionComponent` 범위에 들어오면 대상 메쉬 테두리에 아웃라인 강조를 넣는다. 렌더링 방식은 Custom Depth + Stencil + 포스트프로세스 아웃라인 머티리얼.

### 수정 범위
| 모듈 | 파일 | 수정할 내용 |
|---|---|---|
| `WxWorld` | `Public/Interaction/WxInteractionComponent.h` | 설정 프로퍼티 2개(`bEnableHighlight`, `HighlightStencilValue`) + private 헬퍼 `SetHighlightEnabled` 선언 |
| `WxWorld` | `Private/Interaction/WxInteractionComponent.cpp` | `SetHighlightEnabled` 구현 + 위젯 토글과 동일 지점 4곳에 호출 추가 |

### 접근 방식
기존 프롬프트 위젯과 동일하게 컴포넌트 내부에 자기완결로 둔다(기믹별 BP 배선 없음). `SetHighlightEnabled(bool)`은 `GetOwner()`의 `UMeshComponent`를 순회하되 `UWidgetComponent`(프롬프트 위젯, MeshComponent 파생)는 제외하고 각 메쉬에 `SetRenderCustomDepth` + `SetCustomDepthStencilValue(HighlightStencilValue)`를 토글한다. 메쉬 목록은 캐싱 없이 토글 시점에 조회.

호출 지점은 `SetInteractionWidgetVisible` 토글과 1:1로 짝지어 추가:
- `HandleBeginOverlap`(로컬 폰) → on
- `HandleEndOverlap` → off
- `BeginPlay`의 "이미 오버랩 중" 분기 → on
- `SetInteractionEnabled(false)` → off

실제 외곽선은 콘텐츠 작업(에디터): `M_Outline` 포스트프로세스 머티리얼(`SceneTexture:CustomStencil` 비교)을 PostProcessVolume/카메라에 적용. 코드 범위 밖이며 사용자가 진행.

#### 알려진 한계
한 액터에 InteractionComponent를 여러 개 두고 영역이 겹치면 한 영역의 EndOverlap이 다른 영역의 강조를 끌 수 있다(공유 메쉬 ref-count 없음). 다중 영역은 흔치 않아 단순성 우선, 후속 과제로 남김.

## 완료

### 수정한 파일
| 모듈 | 파일 | 수정 내용 |
|---|---|---|
| `WxWorld` | `Public/Interaction/WxInteractionComponent.h` | `bEnableHighlight`, `HighlightStencilValue` 프로퍼티 + `SetHighlightEnabled` 선언 추가 |
| `WxWorld` | `Private/Interaction/WxInteractionComponent.cpp` | `Components/MeshComponent.h` include, `SetHighlightEnabled` 구현, 위젯 토글 4지점에 호출 추가 |

### 구현·결정과 그 이유
- **컴포넌트 자기완결**: 강조 토글을 InteractionComponent 내부에 넣어 기믹별 BP 배선을 없앴다. 기존 프롬프트 위젯 토글과 동일한 4지점(BeginOverlap/EndOverlap/BeginPlay 선오버랩/SetInteractionEnabled)에 1:1로 붙여 두 피드백이 항상 동기화되게 했다.
- **위젯 제외 필터**: 프롬프트 `UWidgetComponent`가 `UMeshComponent` 파생이라 `IsA<UWidgetComponent>()`로 외곽선 대상에서 제외했다. 안 그러면 화면 공간 위젯에도 스텐실이 찍힌다.
- **토글 시점 조회**: 메시 목록을 캐싱하지 않고 `GetComponents`로 그때그때 조회. 오버랩은 빈도가 낮아 비용이 무시할 만하고, 보물상자처럼 런타임에 메시가 바뀌어도 견고하다.
- **C++는 스텐실만**: 실제 외곽선은 콘텐츠(PP 머티리얼) 책임으로 분리. 엔진 `UPrimitiveComponent` API만 써서 플러그인 참조 규칙 영향 없음.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **콘텐츠(에디터, 사용자)**: `M_Outline` 포스트프로세스 머티리얼(`SceneTexture:CustomStencil` == `HighlightStencilValue` 경계 검출) 제작 후 PostProcessVolume/카메라에 적용. Project Settings > Rendering > Custom Depth-Stencil Pass = Enabled with Stencil 확인. 이 작업 전까지는 스텐실만 찍히고 외곽선은 보이지 않는다.
- **다중 영역 한계**: 한 액터에 InteractionComponent를 여러 개 두고 영역이 겹치면 강조 토글이 충돌할 수 있음(ref-count 없음). 필요 시 액터 단위 카운팅 도입.
