# OnRep 명명 통일

## 계획

### 목표

`UWxItemInstance` 한 클래스 안에서 RepNotify 명명이 갈려 있다 — `ItemDef` 는 `HandleItemDefReplicated`, `CurrentCharges` 는 `OnRep_CurrentCharges`. 저장소 관행인 `OnRep_` 으로 통일한다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxInventory/Source/WxInventory/Public/Items/WxItemInstance.h` | 함수 선언과 `ReplicatedUsing` 지정자를 `OnRep_ItemDef` 로 개명 | 수정 |
| `Plugins/WxInventory/Source/WxInventory/Private/Items/WxItemInstance.cpp` | 함수 정의를 `OnRep_ItemDef` 로 개명 | 수정 |

### 접근 방식

- **순수 개명**: `protected` 이고 외부 호출부·에셋 참조가 모두 0건이라 동작 변화가 없다. `AWxItemPickup::OnRep_ItemDef` 는 다른 클래스라 충돌하지 않는다.

- **규칙 해석**: CLAUDE.md 규칙 4(델리게이트 콜백은 `Handle` 접두)는 RepNotify 에 적용되지 않는다. 저장소의 다른 RepNotify(`OnRep_LockOnTarget`, `OnRep_StateSnapshot`, `AWxItemPickup::OnRep_ItemDef`, AttributeSet 전체)가 모두 `OnRep_` 을 쓴다.
