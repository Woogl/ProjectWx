# 무기 히트 목록 GC 추적 누락 수정

## 계획

### 목표

`AWxWeaponBase::HitActorsThisSwing`(`TSet<TObjectPtr<AActor>>`)에 `UPROPERTY()`가 없어 GC 참조 그래프 밖에 있다. 리플렉션에 등록되지 않은 `TObjectPtr`은 GC가 살려주지도, 파괴 시 null로 정리해주지도 않으므로, 스윙이 열린 동안 피격된 적이 파괴되고 그 사이 GC가 돌면 `Tick`의 `Params.AddIgnoredActor(AlreadyHit.Get())`가 해제된 메모리를 만진다. 바로 위 `if (AlreadyHit)` 가드는 추적되지 않는 포인터에 대해 무의미하다.

동일 원인(리플렉션 미등록으로 UObject 참조가 GC 추적 밖)의 3건을 함께 고친다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/Weapon/WxWeaponBase.h` | `HitActorsThisSwing`에 `UPROPERTY()` 추가 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/Weapon/WxWeaponBase.h` | `DamageInfo`에 `UPROPERTY()` 추가 — 내부 `AdditionalEffects`의 GE 클래스 참조가 추적 밖 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Task/WxAbilityTask_LockOnTarget.h` | `ReticleWidgetClass`에 `UPROPERTY()` 추가 | 수정 |

동작 로직·시그니처 변경 없음. cpp는 손대지 않는다.

### 접근 방식

- **`UPROPERTY()` 부착 (`TWeakObjectPtr` 전환 아님)**: 리플렉션에 등록되는 순간 GC가 참조를 추적하므로 포인터는 항상 유효하거나 null이 되고, 기존 null 가드가 그제서야 실제로 동작한다. 같은 클래스가 이미 `UPROPERTY() + TObjectPtr`(`GripPoint`/`Mesh`/`HitCollision`)를 쓰고 있어 방식이 일치하며 cpp 변경이 필요 없다.
- **수명 연장은 무시할 수준**: `HitActorsThisSwing`은 `BeginAttack`/`EndAttack`/`CancelAttack`에서 매번 `Empty()`되므로 죽은 액터를 붙잡는 최대 구간이 스윙 1회다. `TWeakObjectPtr`이 소유 의미상 더 정확하지만 cpp 순회부까지 고쳐야 해 diff만 커지고 실익이 없다.

## 완료

### 수정한 파일

| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/Weapon/WxWeaponBase.h` | `DamageInfo`·`HitActorsThisSwing`에 `UPROPERTY()` 부착 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Task/WxAbilityTask_LockOnTarget.h` | `ReticleWidgetClass`에 `UPROPERTY()` 부착 | 수정 |

### 구현·결정과 그 이유

- **`UPROPERTY()` 부착으로 해결**: 리플렉션 등록만으로 GC가 참조를 추적하게 되어 포인터가 항상 유효하거나 null이 된다. 즉 기존 null 가드가 비로소 실제 방어가 된다. `TWeakObjectPtr` 전환은 소유 의미상 더 정확하지만 cpp 순회부까지 건드려야 하고, 히트 목록이 스윙마다 비워지는 구조라 수명 연장 리스크가 없어 실익이 없었다.
- **`DamageInfo`도 함께**: 구조체 내부 `AdditionalEffects`의 GE 클래스 참조가 바깥 멤버가 미등록이면 통째로 추적 밖이다. 히트 목록과 같은 원인이라 같이 처리했다.

### 계획 대비 달라진 점

계획대로.

### 후속 과제

없음. 런타임 재현 검증은 GC 타이밍 의존이라 수행하지 않았고, 변경이 참조를 추적 그래프에 넣는 것뿐이라 컴파일 검증으로 갈음했다.
