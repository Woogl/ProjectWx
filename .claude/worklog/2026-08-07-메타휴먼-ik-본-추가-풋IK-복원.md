# 메타휴먼 바디에 ik 본 추가 — 풋 IK 복원

## 계획

### 목표
메타휴먼 전환으로 죽은 풋 IK를 되살린다. 전 작업에서 FootIK 컨트롤 리그를 Alpha 0으로 임시 무력화했는데, 엔진의 모든 풋 IK 경로(Control Rig·Foot Placement·Leg IK)가 ik 본 실존을 전제하므로 바디 메시에 UE5 표준 ik 본 7종을 추가해 순정 동작을 복원한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Tools/AddMetaHumanIkBones.py` | USkeletonModifier로 바디 메시에 ik 본 7종 추가하는 스크립트(재어셈블 시 재실행용) | 신규 |
| `Content/MetaHumans/MH_Player/Body/SKM_MH_Player_BodyMesh.uasset` | ik_foot_root/l/r + ik_hand_root/gun/l/r 본 추가(스크립트 실행 산출) | 수정 |
| `Content/Mannequins/Animations/Unarmed/ABP_Unarmed.uasset` | Control Rig 노드 Alpha 0→1 복원 | 수정 |

### 접근 방식
- **ik 본 추가가 유일한 근본 해법**: Foot Placement·Leg IK 노드는 ik 본이 없으면 평가 자체를 건너뛰고, 기존 리그의 ik_foot은 "트레이스 오프셋을 실어 나르는 스크래치 본"이라 foot 직독으로 개조하면 IK가 항등 목표를 받아 무력화된다. 본을 추가하면 로코모션 애님에 이미 실려 있는 ik_foot 트랙이 Compatible Skeletons 리매핑(본 이름 기준)으로 그대로 구동돼 순정 동작이 복원된다.
- **배치·트랜스폼은 엔진 관례**(IKRigAutoCharacterizer 핀 규칙): ik_foot_root·ik_hand_root=root 아래 Identity, ik_foot_l/r=이 메시 foot_l/r 글로벌 레퍼런스와 일치, 손 계열은 hand_r 기준. 값은 하드코딩 없이 실측.
- **손 ik 4종 동반 추가**: 현 리그는 안 쓰지만 표준 세트를 갖춰 같은 부류의 재발을 막는다.
- 재어셈블하면 바디 메시가 재생성돼 본이 사라지므로 스크립트를 리포에 보존한다.

### 구현·결정과 그 이유
- **트랜스폼 실측 계산**: ik 본 배치는 하드코딩 없이 대상 메시의 foot/hand 글로벌 레퍼런스를 실측해 엔진 관례대로 배치했다. 루트 2종의 글로벌이 Identity라 글로벌 실측값을 로컬로 그대로 쓸 수 있었다.
- **실행 경로**: 에디터 콘솔 `py` 명령으로 실행(PythonScriptPlugin 활성 상태). 모달 없이 SimpleMerge로 커밋됐고 메시·스켈레톤 모두 스크립트 안에서 저장됐다.
- C++ 변경이 없어 빌드 검증은 생략했다.

### 계획 대비 달라진 점
- 계획대로. (StartPIE의 스폰 트랜스폼 오버라이드가 Experience 스폰 경로에 안 먹혀, 검증 시 PIE 중 폰 텔레포트로 대체한 것 정도.)

### 검증 결과
- 본 추가 후 재조회: ik 7종 존재, 계층(ik_foot_l→ik_foot_root, ik_hand_gun→ik_hand_root) 정상.
- PIE: **계단 위에서 두 발이 서로 다른 단에 각각 접지**(IK 실동작 확정 — IK 없으면 한 발이 공중에 뜸), 점프 시 다리 들림 유지(ShouldDoIKTrace 게이트 정상), 애님·리그·리매핑 경고 0건.
- Quinn NPC도 같은 ABP를 쓰므로 이전 임시조치로 껐던 NPC 풋 IK가 함께 복원됐다.

- 마네킹 비율 기준 ik 목표로 인한 미세한 발 위치 오차 가능성 — 실플레이에서 미끄러짐 체감 시 조정.
