# 플레이어 외형 메타휴먼 전환 (ABP_Shinbi·VisualOverride 폐기)

## 계획

### 목표
플레이어 외형을 메타휴먼 기반으로 교체하고 이중 메시 구조(숨긴 Quinn 구동 + VisualOverride Shinbi 표시)를 폐기한다. 메타휴먼 바디를 본체 메시로 승격하면 피격 판정·래그돌·큐 부착이 보이는 메시 기준으로 통합돼 정합성 문제도 함께 해소된다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Wx.uproject` | MetaHumanCharacter·MetaHumanSDK·RigLogic·HairStrands·ChaosClothAsset·ChaosOutfitAsset 활성화 | 수정 |
| `Content/MetaHumans/<이름>/` | Creator로 생성·어셈블한 메타휴먼 산출물(사용자 수행) | 신규 |
| `Content/Mannequins/Meshes/SK_Mannequin.uasset` | Compatible Skeletons에 메타휴먼 바디 스켈레톤 등록 | 수정 |
| `Content/Character/Player/BP_Player.uasset` | GetMesh를 메타휴먼 바디로 교체(ABP_Unarmed 유지·Hidden 해제), Face/Groom 이식, VisualOverride 컴포넌트 삭제 | 수정 |
| `Source/WxGame/Character/WxCharacterBase.cpp` | PostInitializeComponents의 VisualOverride 태그 스캔 블록 삭제 | 수정 |

### 접근 방식
- **Compatible Skeletons로 애니메이션 무이전 재사용**: 메타휴먼 바디 스켈레톤은 UE5 마네킹 코어 본을 전부 포함하고, 호환 검사는 양방향이라 프로젝트 소유 SK_Mannequin에만 등록하면 된다. 몽타주 런타임은 본 이름 리매핑으로 동작하므로 기존 몽타주·노티파이를 그대로 쓴다(리타게팅·재배치 불필요).
- **본체 승격**: 리타게팅 중계 메시를 없애고 메타휴먼 바디가 직접 구동·표시·판정을 담당한다. 무기는 스캔 블록 삭제로 생성자 부착(hand_r)에 자연 복귀한다.
- **품질 폴백**: 비율 차이로 그립·접지가 어긋나면 ABP 보정 노드, 최후 수단으로 IK Retargeter 일괄 리타겟.

### 구현·결정과 그 이유
- **Compatible Skeletons 단방향 등록**: 호환 검사가 양방향이라 프로젝트 소유 SK_Mannequin에만 등록했다. 엔진 플러그인 에셋은 건드리지 않는다.
- **조립 BP를 기준으로 이식**: 어셈블 산출 BP의 컴포넌트 구성·프로퍼티를 실측해 그대로 BP_Player에 재현했다. 페이스·바디의 배선은 메시 에셋의 포스트프로세스 ABP에 내장돼 있어 이식이 자동으로 성립하고, 유일한 런타임 배선인 복장 리더포즈만 컨스트럭션 스크립트 1줄로 옮겼다(조립 BP의 EnableMasterPose 판정과 동일 조건).
- **컴포넌트 명명**: 복장은 조립 BP의 무의미한 이름(SkeletalMesh) 대신 Outfit으로 명명하고 LODSync 항목도 실제 컴포넌트 이름(CharacterMesh0 등) 기준으로 재작성했다.
- **작업 방식**: 에셋 편집 전 과정을 unreal-mcp(HTTP JSON-RPC 직결)로 수행하고, 저장 유실 함정 대비로 전 항목을 재조회 검증했다.

### 계획 대비 달라진 점
- **발 소켓 이식 생략**: foot_l/r_Socket은 스켈레톤 자신과 CR_Mannequin_FootIK만 참조하고 게임플레이 사용처가 없어 이식하지 않았다.
- **캡슐·카메라 무조정**: 선택된 체형의 전신 높이(~180cm)가 기존 캡슐(176cm)과 거의 일치해 보정이 불필요했다.
- **FootIK 무력화 (사후 수정)**: "무동작 예상"은 오판이었다. ik_* 본이 없으면 리그의 IK 타깃이 레퍼런스 포즈(바닥)에 고정된 채 발을 계속 붙잡아, 공격·점프·달리기에서 다리가 들리지 않는 증상이 발생했다. 포즈 체인이 [스테이트 머신→슬롯→ControlRig→출력]이라 몽타주까지 전부 통과한다. ABP_Unarmed의 Control Rig 노드 Alpha를 0으로 내려 해소했고 점프 시 다리 들림을 PIE로 확인했다.

### 검증 결과
- WxEditor(Development) 빌드 성공(플러그인 활성화 후 1회, C++ 정리 후 1회).
- PIE(LV_DevCombat): 메타휴먼 외형·헤어·복장 표시, 접지 정상, ABP_Unarmed 로코모션 구동, 공격 몽타주 재생(입력 시뮬레이션으로 발동, 스윙 포즈·무기 추종 확인), 카타나 hand_r 부착(스케일 1), HUD·게임 플로우 정상. 애니메이션·스켈레톤·그룸 관련 경고 0건.
