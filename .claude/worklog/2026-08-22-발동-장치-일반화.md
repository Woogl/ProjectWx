# AWxLeverDevice 를 AWxTriggerDevice 로 일반화

## 계획

### 목표
`AWxLeverDevice` 에서 레버 전용 연출(손잡이 회전·사운드·핑퐁 타이머)을 걷어내고 `AWxTriggerDevice` 로 옮긴다. C++ 에는 "상호작용을 받아 지목한 장치들에 `Event.Interact` 를 민다"는 발동 장치 공통부만 남기고, 생김새와 연출은 파생 BP 가 정한다. 버튼·페달 같은 다른 발동 장치가 이 클래스를 상속해 만들어진다.

순수 삭제가 아니다 — 지금 `IsPulling()` 은 연출 타이머이면서 동시에 재조작 차단 게이트라, 연출을 빼면 명시적인 `RetriggerCooldown` 을 대신 둬야 한다.

### 접근 방식
- **남기는 것**: `BodyMesh`(루트·상호작용 영역) · `Prompt` · `Gimmicks` · `GimmickStateRequirements` · `IWxInteractable` 구현 · `BeginPlay` 배선 검증.
- **빼는 것**: `HandleMesh` · `PullDuration` · `HandlePulledRotation` · `PullSound` · `Tick` 핑퐁 회전 · `HandleRestRotation` · `IsPulling()` · 생성자의 `PrimaryActorTick` 설정.
- **연출 훅**: `BlueprintImplementableEvent OnTriggered()` 를 `Multicast_Trigger`(Unreliable) 가 전 피어에서 부른다. 같은 멀티캐스트가 `LastTriggerTime` 을 찍어 쿨다운 기준이 된다 — 지금 `PullStartTime` 이 하던 자리를 그대로 물려받아, 클라 프롬프트와 서버 활성 검증이 계속 같은 답을 낸다.
- **프로퍼티 이름 보존**: `Prompt`·`Gimmicks`·`GimmickStateRequirements`·`BodyMesh` 를 그대로 둬 배치 인스턴스의 배선이 살아남는다.
- **CoreRedirect 필수**: 없으면 `BP_LeverDevice` 와 `LV_DevCombat` 배치 인스턴스가 클래스를 잃는다.

### 에디터 작업 (코드 밖)
1. `BP_LeverDevice` 열기 — 리다이렉트로 부모가 자동 전환된다. 이름은 그대로 둔다(이 BP 는 실제로 레버다).
2. 사라진 `HandleMesh` 를 SCS 컴포넌트로 다시 추가해 `BodyMesh` 아래 부착(원래 메시 `/Engine/BasicShapes/Cylinder`, 콜리전 없음).
3. `OnTriggered` 를 Timeline 핑퐁으로 구현(원래 값: 1초, Pitch -60°) + 필요 시 사운드.
4. `RetriggerCooldown` 이 연출 길이와 어긋나지 않는지 확인(기본 1초).

### 구현·결정과 그 이유
- **연출을 클래스 밖으로**: 손잡이 회전·사운드·핑퐁 타이머는 레버 한 종류의 표현일 뿐이라, 버튼·페달이 같은 클래스를 쓰지 못하게 막고 있었다. 눌림을 `OnTriggered`(BlueprintImplementableEvent)로 내보내고 파생 BP 가 Timeline 으로 재생하게 했다. C++ 이 돌릴 틱이 없어져 생성자의 `PrimaryActorTick` 설정도 걷었다(BP Timeline 은 자체 컴포넌트로 돌아 액터 틱과 무관하다).
- **쿨다운은 제거가 아니라 대체다**: `IsPulling()` 이 연출 타이머이면서 동시에 재조작 차단이었다. 연출 길이를 BP 가 정하는 이상 C++ 이 그 값을 알 수 없으므로 `RetriggerCooldown` 을 명시 프로퍼티로 뒀다.
- **게이트의 피어 대칭을 그대로 물려받았다**: 지금도 `PullStartTime` 은 멀티캐스트가 각 피어에 찍고 로컬 시계로 판정했다. `Multicast_Trigger` 가 `LastTriggerTime` 을 찍는 같은 구조라, 클라의 프롬프트 표시와 서버의 활성 검증이 계속 같은 답을 낸다. 멀티캐스트를 Unreliable 로 둔 근거도 같다 — 유실되면 그 클라의 연출과 로컬 게이트만 빠지고 실제 차단은 서버가 든다.
- **프로퍼티 이름을 보존했다**: `Prompt`·`Gimmicks`·`GimmickStateRequirements`·`BodyMesh` 를 그대로 둬 배치 인스턴스의 배선이 살아남는다. 클래스만 `CoreRedirects` 로 옮긴다.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **에디터 작업**: `BP_LeverDevice` 를 열어(리다이렉트로 부모 자동 전환) 사라진 `HandleMesh` 를 SCS 컴포넌트로 다시 추가해 `BodyMesh` 아래 부착하고(원래 메시 `/Engine/BasicShapes/Cylinder`, 콜리전 없음), `OnTriggered` 를 Timeline 핑퐁으로 구현한다(원래 값: 1초, Pitch -60°). `RetriggerCooldown` 기본 1초가 그 길이와 맞는지 확인.
- 리다이렉트 검증 필요 — `BP_LeverDevice` 와 `LV_DevCombat` 배치 인스턴스가 경고 없이 열리고 `Gimmicks` 배선이 남아 있는지 확인한다.
- 인게임 미검증 — 레버 당김 → 엘리베이터 반응, 쿨다운 중 재조작 차단, 층별 잠금(`GimmickStateRequirements`) 동작.
- `Gimmicks`·`GimmickStateRequirements` 는 `AWxDevice` 어휘에 맞추면 `Devices`·`DeviceStateRequirements` 쪽이 맞지만, 프로퍼티 개명은 `PropertyRedirects` 가 따로 필요해 미뤘다.
- 이번 작업과 무관하게, 앞선 두 이관의 에디터 작업(기믹 BP 4종 리페어런트 등)이 여전히 남아 있다.
