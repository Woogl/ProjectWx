# 가드 대미지 배율을 고정 상수로 명시

## 계획

### 목표
`UWxEffect_Guard::DamageReductionRate`는 저작 메타(`EditDefaultsOnly`·`BlueprintReadOnly`·Clamp)를 달았지만 실제로는 튜닝 경로가 없다. 네이티브 GE라 CDO를 에디터에서 못 열고, 부여도 읽기도 네이티브 클래스 고정이라 BP 자식 값이 닿지 않는다. 고정값이라는 사실을 타입으로 드러낸다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Effect/WxEffect_Guard.h` | UPROPERTY 멤버·`GetDamageReductionRate()` 선언 제거, `static constexpr float DamageMultiplier = 0.5f` 추가 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Effect/WxEffect_Guard.cpp` | `GetDamageReductionRate()` 정의 제거 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Effect/WxEffect_Damage.cpp` | 호출을 상수 참조로 교체 | 수정 |

### 접근 방식
- **static constexpr 상수화**: UPROPERTY를 떼고 컴파일 타임 상수로 만든다. CDO 조회 래퍼도 존재 이유가 사라지므로 함께 제거하고, 클래스 안에 남겨 `UWxEffect_Guard::` 스코프로 소속을 유지한다.
- **DamageMultiplier로 개명**: 값은 곱하는 배율인데 이름은 "감소율"이라 0.5에서만 두 해석이 우연히 일치한다. 호출부가 한 곳뿐이라 비용 없이 정리한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Effect/WxEffect_Guard.h` | UPROPERTY 멤버·정적 getter 선언 제거, `static constexpr float DamageMultiplier = 0.5f` 추가 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Effect/WxEffect_Guard.cpp` | `GetDamageReductionRate()` 정의 제거 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Effect/WxEffect_Damage.cpp` | 가드 히트 감쇠를 상수 참조로 교체 | 수정 |

### 구현·결정과 그 이유
- **래퍼까지 제거**: 정적 getter는 CDO를 대신 읽어 주려고 있던 것이라, 값이 상수가 되는 순간 존재 이유가 사라진다. 상수를 직접 참조하면 호출부가 한 줄로 더 명확하다.
- **클래스 안에 유지**: 소비처는 ExecCalc(WxEffect_Damage) 한 곳이지만, "가드의 감쇠량"이라는 소속을 `UWxEffect_Guard::` 스코프로 남겨 발견 가능성을 유지했다.
- **개명**: 곱하는 값에 "ReductionRate"라는 이름이 붙어 있어 0.5에서만 두 해석이 우연히 일치했다. 리뷰가 지적한 "실제와 다르게 보이는 것"과 같은 부류라 함께 정리했다.
