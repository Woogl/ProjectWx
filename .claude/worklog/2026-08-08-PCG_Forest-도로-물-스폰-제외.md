# PCG_Forest 도로·물 스폰 제외

## 계획

### 목표
`PCG_Forest`가 도로(`BP_RoadSplineMesh`)와 물(`WaterBodyCustom`) 위에도 나무·바위·풀을 깐다. 두 액터 모두 숲 PCG 볼륨 안에 들어와 있고 그래프에는 이들을 걸러내는 장치가 없다. 도로·물 영역을 제외 영역으로 만들어 세 갈래 모두에서 뺀다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/PCG/PCG_Forest.uasset` | 제외 영역 브랜치 신설 + 세 갈래 Difference 배선 | 수정 |

C++ 변경은 없다.

### 접근 방식

기존 그래프는 `World Ray Hit Query` 하나를 표면 삼아 나무·바위·풀 세 갈래로 나뉘고, 갈래끼리 겹침을 빼는 `Difference`가 이미 둘 있다. 같은 방식으로 "도로·물" 제외 영역을 하나 만들어 세 갈래 모두에서 뺀다.

- **도로는 태그로**: 도로 액터에 이미 `Road` 태그가 붙어 있어 `Get Spline Data`가 태그만으로 스플라인을 집는다. 이를 도로 메시를 까는 것과 같은 간격(256)으로 샘플링하고, 각 점의 바운즈를 도로 폭에 맞춰 세워 제외 상자를 만든다. 샘플 점은 로컬 X가 진행 방향이므로 Y가 곧 도로 폭이다. 실제 반폭 250에 갓길 여유 150을 더한 400을 쓴다.
- **물은 클래스로**: 물 액터에는 태그가 없고 앞으로 늘어날 수 있으니 `Get Actor Data`가 `WaterBody` 클래스로 집는다. 단일 점 모드가 액터 바운즈를 그대로 물려주는데, 지금 물은 평면 메시를 키운 것이라 이 바운즈가 수면 사각형과 정확히 일치한다. 바운즈는 아래로만 늘려 호수 바닥까지 덮되, 위로는 늘리지 않아 사각형 안이라도 수면보다 높은 물가 지형에는 나무가 계속 자란다.
- **한 갈래로 합쳐 배선**: 둘을 `Union`으로 합쳐 세 갈래에 한 가닥씩만 끈다. 바위 갈래에는 `Difference`가 없으므로 하나 신설해 스포너 앞에 끼운다.

작업은 실행 중인 에디터에 unreal-mcp `PCGToolset`으로 직접 가한 뒤 저장한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/PCG/PCG_Forest.uasset` | 제외 브랜치 7노드 신설(도로·물·`PCGExclude` 태그), 바위 갈래에 Difference 추가, 세 갈래 모두 제외 영역을 빼도록 배선 | 수정 |

### 구현·결정과 그 이유
- **제외 영역을 하나로 합쳐 세 갈래에 나눠줌**: 나무·풀에는 이미 갈래 간 겹침을 빼는 Difference가 있어 제외 영역을 입력 하나로 더 얹기만 하면 됐다. 바위 갈래만 Difference가 없어 스포너 앞에 하나 끼웠고, 이때 엔진이 점 변환 노드를 자동으로 끼워 넣어 기존 두 갈래와 모양이 같아졌다.
- **도로는 태그, 물은 클래스로 집음**: 도로 액터에는 이미 `Road` 태그가 있어 그대로 썼고, 물은 태그가 없어 `WaterBody` 기반 클래스로 집었다. 둘 다 다중 선택이라 액터가 늘어도 그래프를 고칠 필요가 없다.
- **범용 제외 태그 `PCGExclude` 도입**: 액터 바운즈만으로 충분한 대상(건물·조형물 등)은 태그 하나로 통일해 갈래 하나가 받는다. 앞으로는 액터에 태그만 붙이면 그래프를 건드릴 필요가 없다. 도로는 이 태그로 합칠 수 없다 — 곡선 도로를 바운즈로 잡으면 도로 전체를 감싸는 거대한 사각형이 파여 숲이 통째로 사라지므로, 스플라인을 따라 좁은 상자를 까는 갈래가 따로 필요하다. 물은 태그 대신 클래스로 두어 새 물 액터에 태그를 깜빡할 여지를 없앴다.
- **도로 청소 폭 250**: 도로를 까는 것과 같은 간격으로 샘플링해 이음매에 구멍이 나지 않게 했다. 처음엔 갓길 여유 150을 더했으나, 초목이 도로에 바짝 붙는 그림을 원해 실제 도로 반폭과 같은 250으로 좁혔다. 도로면만 비고 가장자리부터 풀이 자란다.
- **물 바운즈는 아래로만 확장**: 물은 평평한 사각 평면이고 호수 모양은 지형이 그 아래로 파여 만들어진다. 위로 늘리지 않으므로 사각형 안이라도 수면보다 높은 지형에는 초목이 그대로 남는다.

### 계획 대비 달라진 점
- 도로 청소 폭을 400에서 250으로 좁혔다(초목이 도로에 바짝 붙기를 원함).
- 범용 제외 태그 `PCGExclude` 갈래를 추가했다(계획에 없던 항목).
- 바위 갈래 Difference를 스포너에 물릴 때 엔진이 점 변환 노드를 자동 삽입했다(의도한 결과와 동일).

### 후속 과제
- 물가 모래톱 폭: 제외 상자 윗면이 실제 수면보다 메시 바운즈 절반만큼 높아, 물가에 초목 없는 띠가 한 뼘 남짓 생긴다. 지금은 해변처럼 보여 그대로 뒀고, 거슬리면 물 쪽 Bounds Modifier를 Set으로 바꿔 윗면을 수면에 맞추면 된다.
- 다른 PCG 그래프(`PCG_DevScaleRef` 등)에는 같은 제외 브랜치를 붙이지 않았다. 필요해지면 이 브랜치를 서브그래프로 떼어 공유하는 편이 낫다.
- 검증은 그래프 실행과 뷰포트 확인으로 했다. `PCGExclude`는 임시 액터에 태그를 붙여 구멍이 뚫리는 것까지 확인하고 액터를 지웠다. C++ 변경이 없어 빌드는 돌리지 않았다.
