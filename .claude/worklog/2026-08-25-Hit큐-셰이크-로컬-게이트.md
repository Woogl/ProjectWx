# Hit 큐 카메라 셰이크 리슨 서버 이중 재생 수정

## 계획

### 목표
`ClientStartCameraShake`는 client RPC라 리슨 서버 호스트가 원격 클라에 셰이크를 쏘고, 그 클라는 복제로 도착한 같은 큐를 자기 쪽에서도 실행해 셰이크가 두 번 걸린다. 각 머신이 자기 로컬 컨트롤러만 흔들도록 게이트를 추가한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Cue/WxCueNotify_Hit.cpp` | 셰이크 재생 전 `IsLocalController()` 게이트 추가 | 수정 |

### 접근 방식
- **로컬 컨트롤러 게이트**: 공격자·피격자 분기 모두 `IsLocalController()`가 참일 때만 셰이크를 재생한다. 원격 PC로는 아무것도 쏘지 않으므로 해당 플레이어 머신의 큐 실행으로 한 번만 재생된다.
- **조기 return 위치 조정**: 공격자 PC를 찾기만 해도 return 하던 것을, 실제로 재생했을 때만 return 하도록 안쪽으로 옮긴다. 호스트가 피격자이고 공격자가 원격일 때 비로컬 공격자 PC를 건너뛰고 피격자 분기로 내려가야 한다.
- **중간 지역변수 정리**: 게이트로 중첩이 한 겹 늘어나므로 `EffectCauser`·`Controller` 중간 변수를 캐스트에 인라인한다. 동작 변화는 없다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Cue/WxCueNotify_Hit.cpp` | 공격자·피격자 분기에 `IsLocalController()` 게이트 추가, 조기 return을 게이트 안쪽으로 이동, 중간 지역변수 인라인 | 수정 |

### 구현·결정과 그 이유
- **RPC 대신 로컬 재생**: `ClientStartCameraShake`를 남겨두되 로컬 컨트롤러에서만 호출한다. 로컬 PC에 대한 client RPC는 그 자리에서 실행되므로 `PlayerCameraManager->StartCameraShake` 직접 호출로 바꿀 실익이 없었고, 원격 PC로 나가는 경로만 끊으면 이중 재생이 사라진다.
- **return을 게이트 안으로**: 호스트가 피격자이고 공격자가 원격 클라인 경우, 호스트에는 공격자 PC가 존재하지만 비로컬이다. 바깥에서 return 하면 호스트 카메라가 아예 안 흔들리므로 실제 재생 시에만 return 한다.
