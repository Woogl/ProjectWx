# SpawnActor 노드 스폰 기준을 로컬 트랜스폼으로 파라미터화

## 계획

### 목표
`FWxStateTreeTask_SpawnActor`의 스폰 기준을 씬 컴포넌트 참조(`SpawnPoint`, `USceneComponent*`)에서 오너 로컬 트랜스폼(`LocalSpawnTransform`, `FTransform`)으로 교체한다. 디자이너가 컴포넌트를 만들어 바인딩할 필요 없이 오너 기준 로컬 오프셋만 지정하면 스폰하도록 단순화한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | InstanceData의 `SpawnPoint`(USceneComponent*) → `LocalSpawnTransform`(FTransform, 기본 Identity) 교체. 프로퍼티 주석·섹션 배너·struct doc·모듈 doc 갱신 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmickStateTreeNodes.cpp` | `Tick`의 스폰 트랜스폼 계산을 `LocalSpawnTransform * Owner->GetActorTransform()`으로 교체, 주석 갱신 | 수정 |

### 접근 방식
- **로컬 트랜스폼 합성**: `SpawnTransform = LocalSpawnTransform * Owner->GetActorTransform()` (UE 관례 Relative × Parent = World). 이 트랜스폼을 그대로 `SpawnActorDeferred`/`FinishSpawning`에 전달.
- **기본 Identity 폴백 통합**: 기본값이 Identity라 오너 트랜스폼에 스폰 → 기존 "미설정 시 오너 폴백" 분기를 단일 식으로 정리.
- **범위 밖**: `WxLaserCorridor`의 `SpawnPoint` 컴포넌트(노드 파라미터와 별개)는 손대지 않는다. ST 와이어링은 아직 수동 대기라 깨질 바인딩 없음. `USceneComponent` include는 같은 파일 다른 노드가 계속 쓰므로 유지.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |

| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | InstanceData `SpawnPoint`(USceneComponent*) → `LocalSpawnTransform`(FTransform) 교체, 프로퍼티 주석·섹션 배너·struct doc·모듈 doc 갱신 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmickStateTreeNodes.cpp` | `Tick` 스폰 트랜스폼을 `LocalSpawnTransform * Owner->GetActorTransform()` 단일 식으로 교체, 주석 갱신 | 수정 |

### 구현·결정과 그 이유
- **로컬 트랜스폼 합성**: UE 관례(Relative × Parent = World)대로 `LocalSpawnTransform * Owner->GetActorTransform()`을 스폰 트랜스폼으로 써 그대로 Deferred 스폰에 전달. 컴포넌트를 만들어 Context 바인딩할 필요가 사라져 디자이너 셋업이 단순해졌다.
- **폴백 분기 제거**: 기본값 Identity 가 곧 "오너 트랜스폼에 스폰"이라, 기존 `SpawnPoint ? ... : ...` 삼항 폴백을 분기 없는 한 줄로 정리. 동작은 동일하게 보존.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **에디터 수동**: ST_LaserCorridor 와이어링 시 노드의 `LocalSpawnTransform`을 컴포넌트 바인딩이 아닌 로컬 트랜스폼 값/식으로 지정. `WxLaserCorridor`의 `SpawnPoint` 컴포넌트는 더 이상 노드가 참조하지 않으므로, 시각 앵커로 남길지 제거할지는 와이어링 단계에서 판단.
