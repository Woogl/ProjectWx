# WxActionWidget 디자인타임 EI 아이콘 프리뷰 (IMC 자동 탐색)

## 계획

### 목표
스킬 슬롯(`WBP_Ability`)의 키 글리프가 `TriggeringEnhancedInputAction`(EI) 경로에선 런타임엔 뜨지만 **에디터 디자인타임엔 빈칸**이다. 수동 설정 없이 디자인타임에도 EI 키 글리프가 자동으로 보이게 한다. 런타임·DataTable 버튼 동작은 불변.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/WxUI.Build.cs` | `PrivateDependencyModuleNames`에 `EnhancedInput`·`AssetRegistry` 추가 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxActionWidget.cpp` | `GetIcon` 디자인타임 블록에 EI 분기 추가(AssetRegistry로 IMC 자동 탐색) | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxButtonBase.cpp` | `NativePreConstruct` 디자인타임 가시성/피드가 EI를 고려 | 수정 |

### 접근 방식
- **디자인타임 아이콘 해석**: 스톡 `GetIcon`은 `DesignTimeKey`만, 기존 오버라이드는 DataTable만 디자인타임 해석. EI 키는 IA가 아니라 IMC에 있는데 디자인타임엔 서브시스템이 없어 조회 불가. → 에디터 전용이므로 **AssetRegistry로 모든 `UInputMappingContext`를 훑어** 대상 IA에 매핑되고 현재 InputType에 유효한 첫 키를 찾아 브러시로 해석(런타임 `GetFirstKeyForInputType` 재현). KMB/게임패드가 `IMC_PlayerCharacter`·`IMC_Controller`로 나뉘어 있어 전체 스캔이 단일 지정보다 정확. 모든 경로는 `IsDesignTime()` 가드 → 런타임 무영향.
- **가시성 보정**: `WxButtonBase::NativePreConstruct`가 DataTable이 null이면 위젯을 `Collapsed`시켜 EI만 쓰면 디자인타임에 숨겨짐. EI가 있으면 숨기지 않고 `SetEnhancedInputAction`으로 피드해 `GetEnhancedInputAction()`이 값을 돌려주게 함.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/WxUI.Build.cs` | `if (Target.bBuildEditor)` 블록으로 `AssetRegistry`·`EnhancedInput` 에디터 전용 추가 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxActionWidget.cpp` | `GetIcon` 디자인타임 블록에 EI 분기(AssetRegistry로 IMC 자동 탐색) 추가, `#if WITH_EDITOR`로 스코핑 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxButtonBase.cpp` | `NativePreConstruct` 디자인타임 가시성/피드가 `TriggeringEnhancedInputAction`을 고려 | 수정 |

### 구현·결정과 그 이유
- **IMC 자동 탐색(프리뷰 IMC 프로퍼티 폐기)**: 디자인타임엔 서브시스템이 없어 IA→키 해석 불가. 에디터 전용이므로 AssetRegistry로 모든 `UInputMappingContext`를 훑어 현재 InputType에 유효한 첫 키를 찾는다. KMB/게임패드가 `IMC_PlayerCharacter`·`IMC_Controller`로 나뉜 구조라 전체 스캔이 단일 지정보다 정확하고, 수동 설정도 필요 없다.
- **에디터 전용 스코핑(`#if WITH_EDITOR` + `bBuildEditor`)**: 이 코드는 오직 디자인타임에만 돌고 AssetRegistry 동기 로드까지 하므로 패키지 빌드에 흔적을 안 남긴다. UBT상 `WITH_EDITOR=1`은 항상 `bBuildEditor=true`를 함의해(모듈이 코드보다 먼저 빠지는 위험 방향 불가), 매크로/의존성 게이팅이 안전하게 일치.
- **버튼 가시성 보정**: 스톡은 런타임 `NativeConstruct`에서만 아이콘을 갱신하고, WxButtonBase 디자인타임 블록은 DataTable만 다뤄 EI만 쓰면 위젯이 숨겨졌다. EI가 있으면 `SetEnhancedInputAction`으로 피드해 `GetEnhancedInputAction()`이 값을 돌려주게 함.

### 계획 대비 달라진 점
- **프리뷰 IMC 프로퍼티 → AssetRegistry 자동 탐색**(사용자 요청). 파일 수 3개로 축소(헤더·에디터 설정 단계 불필요).
- **에디터 전용 스코핑 추가**(사용자 제안): `#if WITH_EDITOR` + Build.cs `bBuildEditor` 게이팅.

### 후속 과제
- **빌드 검증 미완료**: 에디터가 Live Coding으로 실행 중이라 풀 리빌드 불가(Build.cs 변경이라 Live Coding으론 안 됨). 새 코드의 API 표면은 UE 5.8 헤더로 대조 확인했으나, 에디터 종료 후 `WxEditor(Development)` 빌드로 최종 컴파일 확인 필요.
- 에디터에서 `WBP_PlayerSkills` 슬롯 글리프가 디자인타임에 뜨는지 육안 확인.
