# 에셋 덤프 위치 이동 (Docs → .claude)

## 계획

### 목표

`Docs/AssetDump/`의 에셋 JSON 덤프 163개는 AI 세션만 읽는 기계 생성물인데, 사람이 쓰는 설계 문서 폴더에 섞여 있다. worklog 옆인 `.claude/asset_dump/`로 옮겨 AI 세션용 자료를 `.claude/` 한 곳에 모은다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Docs/AssetDump/**` → `.claude/asset_dump/**` | `git mv`로 이동 (추적·이력 유지) | 이동 |
| `.claude/skills/dump-assets/dump_assets.py` | 기본 출력 경로 + 헤더 주석 2곳 | 수정 |
| `.claude/skills/dump-assets/SKILL.md` | description·본문 경로 3곳, 「참고」에 gitignore 금지 한 줄 | 수정 |
| `.claude/skills/analyze-system/SKILL.md` | 덤프 안내 경로 | 수정 |
| `.claude/skills/module-review/SKILL.md` | 덤프 안내 경로 2곳 | 수정 |
| `.claude/skills/readme-writer/SKILL.md` | 덤프 안내 경로 2곳 | 수정 |

`.gitignore`는 손대지 않는다 — `.claude/**/*.local.json`만 무시하므로 새 폴더는 그대로 추적된다.

### 접근 방식

- **위치는 grep 가시성이 결정한다**: Grep 도구(ripgrep 기반)가 `.gitignore`를 따른다는 것을 실측했다. 처음 후보였던 `Intermediate/` 안은 경로를 직접 지정해도 검색 0건이라 덤프가 조용히 무용지물이 된다. 반대로 `.claude/`는 추적 상태라 루트에서 그냥 검색해도 잡힌다. 여기서 나오는 규칙은 **덤프는 git 추적 상태여야 grep이 된다**이고, "커밋에서 빼기"와 "grep 가능"은 양립하지 않으므로 후자를 택한다.

| 위치 | Grep 도구(루트) | Grep 도구(경로 지정) | 순정 rg(루트) | git |
| --- | --- | --- | --- | --- |
| `Docs/AssetDump` (현행) | ✅ | ✅ | ✅ | 추적 |
| `Intermediate/AssetDump` | ❌ | ❌ | ❌ | 무시 |
| `.claude/asset_dump` | ✅ | ✅ | ❌ (`--hidden` 필요) | 추적 |

- **기각한 대안**: 루트 `AssetDump/`(치우려는 목적에 역행), `Docs/Programmer/` 하위(사람이 읽는 분석 문서 자리라 성격이 다름), `Intermediate/`·`Saved/`(gitignore→grep 불가), 스킬 폴더 하위(2026-08-03 기각 재확인), 카테고리당 1파일 병합(부분 갱신·grep 정밀도 손실).
- **stale 판정은 그대로**: README provenance SHA + `git diff <sha> HEAD` 메커니즘은 위치와 무관하므로 유지한다.

### 구현·결정과 그 이유

- **위치는 grep 가시성이 결정했다**: 후보를 고르는 실질 제약이 취향이 아니라 검색 가시성이었다. Grep 도구가 `.gitignore`를 따르므로 무시된 경로에 두면 덤프가 조용히 검색 불능이 된다 — 처음 검토한 `Intermediate/` 안이 여기 걸려 기각됐다. 여기서 "커밋에서 빼기"와 "grep 가능"이 양립 불가라는 결론이 나왔고, 덤프의 존재 이유가 후자이므로 추적 상태를 유지한다.
- **`.claude/` 최상위를 택했다**: `Docs/`는 사람이 읽는 설계 문서 공간이라 아무도 읽지 않는 JSON 163개가 성격을 흐린다. 이 덤프의 유일한 독자는 AI 세션이므로 worklog와 같은 층에 두는 것이 분류상 맞다. 루트 `AssetDump/`는 오히려 더 눈에 띄어 목적에 역행하고, `Docs/Programmer/` 하위는 그 폴더가 사람이 읽는 분석 문서 자리라 맞지 않았다.
- **잃은 것과 그 처방**: 사람이 터미널에서 치는 순정 `rg`는 닷폴더를 기본 스킵한다. 감수하되, 필요하면 `RIPGREP_CONFIG_PATH`에 `--hidden` 한 줄을 물려 개인 환경에서 해소할 수 있다(리포지토리 밖 설정이라 이번엔 적용하지 않았다).
- **스킬에 가드 문구를 남겼다**: 이 폴더를 gitignore로 옮기면 덤프 전체가 검색에서 조용히 사라지는데, 증상이 없어 알아채기 어렵다. 실수를 막으려고 `dump-assets` SKILL.md 「참고」 첫 줄에 이유와 함께 못 박았다.
