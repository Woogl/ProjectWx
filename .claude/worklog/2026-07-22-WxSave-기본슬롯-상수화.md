# WxSave 부트스트랩 기본 슬롯 이름 상수화 ("Test" 제거)

## 계획

### 목표
`module-review` 첫 리뷰가 짚은 `WxSave` 개선점 해결. `UWxSaveGameSubsystem::Initialize`의 부트스트랩 활성 슬롯 이름이 개발용 placeholder 리터럴 `TEXT("Test")`로 하드코딩돼 디스크 파일명(`Test.sav`)이 되는 문제를, 동작 흐름은 유지한 채 의미 있는 명명 상수 `"Default"`로 승격해 해결한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxSave/Source/WxSave/Public/WxSaveGameSubsystem.h` | 공용 상수 `namespace WxSave { inline const TCHAR* DefaultSaveSlotName = TEXT("Default"); }` 추가 | 수정 |
| `Plugins/WxSave/Source/WxSave/Private/WxSaveGameSubsystem.cpp` | `Initialize`의 `TEXT("Test")` → `WxSave::DefaultSaveSlotName`, 인접 주석 정정 | 수정 |

### 접근 방식
- **전용 기본 슬롯 유지(C++만)**: 부트스트랩 기본 슬롯을 메뉴 명명 슬롯(`WBP_MainMenu`의 `"SaveSlot1"`)과 분리된 전용 슬롯으로 두되, 매직 리터럴을 WxSave 한 곳(서브시스템 헤더)의 `inline` 명명 상수로 승격. BP 미변경.
- **동작 불변**: 호출부·서명·제어 흐름 그대로. 바뀌는 것은 부트스트랩 슬롯 파일명뿐(`Test.sav` → `Default.sav`).

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxSave/Source/WxSave/Public/WxSaveGameSubsystem.h` | 클래스 위에 `namespace WxSave { inline const TCHAR* DefaultSaveSlotName = TEXT("Default"); }` + 용도 주석 추가 | 수정 |
| `Plugins/WxSave/Source/WxSave/Private/WxSaveGameSubsystem.cpp` | `Initialize`의 `TEXT("Test")` → `WxSave::DefaultSaveSlotName`, 인접 주석을 "부트스트랩 기본 슬롯" 취지로 정정 | 수정 |

### 구현·결정과 그 이유
- **명명 상수를 서브시스템 헤더에 배치**: "부트스트랩 기본 슬롯 이름"은 이 서브시스템이 소유하는 정책이라 소유 주체 헤더에 둠. `inline`이라 include하는 두 TU(`WxSaveGameSubsystem.cpp`·`WxSaveLibrary.cpp`)에서 ODR 안전.
- **동작 흐름 불변**: "항상 새로 시작 + 메뉴가 슬롯 재지정"은 의도된 설계라 유지. 부트스트랩 슬롯 파일명만 `Test.sav` → `Default.sav`로 바뀜. 메뉴의 `SaveSlot1`과 분리된 전용 기본 슬롯 특성 그대로.
