# 기본 시작 퀘스트 — 생존자 NPC 대화로 수주

## 계획

### 목표
어제 「퀘스트 시작 게이트」로 ST_Quest 의 Start 상태는 `Quest.Start` 이벤트 대기 게이트가 됐지만 발화자가 없어 첫 퀘스트가 시작되지 않는다. 배치된 생존자 NPC(BP_Npc)의 대화(DT_Dialogue, 마을 습격 서사)가 첫 퀘스트 "Scout the Camp"와 자연스럽게 이어지므로, 대화 말미에 `Quest.Start` 를 발화해 정석 RPG 수주 흐름(스폰→저널 없음→대화→수주·저널 등록)을 완성한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/.../WxDialogueTableRow.h` | `FWxDialogueTableRow` 에 `FGameplayTag EventTag` 추가(노드 진입 시 발행, None 이면 없음) | 수정 |
| `Plugins/WxDialogue/.../WxDialogueSessionComponent.h/.cpp` | `FWxOnDialogueEvent OnDialogueEvent(FGameplayTag)` 델리게이트 추가, `EnterRow` 성공 시 유효 태그면 Broadcast | 수정 |
| `Source/WxGame/Controller/WxPlayerController.h/.cpp` | BeginPlay 구독 + `HandleDialogueEvent` → `UWxQuestLibrary::SendQuestEvent` 전달 | 수정 |
| `/Game/Dialogue/DT_Dialogue` | `Request` 행 신설(캠프 정찰 부탁, `EventTag=Quest.Start`), `Warning.NextRow=Request` 연결, 문구는 영문 | 수정(MCP) |

### 접근 방식
- **태그 발행 디커플링**: 대화 노드에 이벤트 태그(데이터)를 두고 세션이 노드 진입 시 범용 델리게이트로 발행, PC(WxGame)가 받아 퀘스트로 전달한다. WxDialogue 는 WxQuest 를 모른다 — 기존 "OnDialogueStarted → PC 가 위젯 푸시" 글루와 동일 패턴.
- **선형 대화 v1**: 선택지 UI 미배선 상태라 수락/거절 없이 대화 완주로 수주한다. 선택지는 UI 배선 시 후속.
- **비권위 무해**: 발행은 소유 클라 측이지만 `SendQuestEvent` 가 비권위에서 러너 null 가드로 무시된다(싱글/리슨호스트 정상). 수주 후 재대화의 재발화도 게이트 소비 후 수신 전이가 없어 무해.

### 구현·결정과 그 이유
- **태그 발행 디커플링**: 세션은 노드의 태그를 해석 없이 중계만 하고, 양쪽(WxDialogue·WxQuest)을 아는 PC 가 퀘스트로 전달한다 — 기존 대화 위젯 푸시 글루와 나란한 동일 패턴이라 신규 구조가 없다.
- **노드 진입 시 발행**: 종료 시가 아니라 진입 시 발행하면 중간 노드 부수효과와 말미 수주를 한 규칙으로 포괄하고, 수주 순간 저널이 대화 뒤에서 이미 채워진다.
- **선형 대화 v1**: 선택지 UI 가 미배선(VM 에 넘기기만 노출)이라 수락/거절 없이 대화 완주로 수주. 재대화 시 재발화는 게이트 소비 후 수신 전이가 없어 무해함을 확인.

### 계획 대비 달라진 점
- **ST_Quest 게이트가 에셋에 없었다**: 어제 「시작게이트」 작업분(Start 의 Delay 태스크·OnEvent 전이)이 현재 에셋에 부재했다(제거만 남고 추가는 유실 — Start 가 태스크 0개·전이 0개라 시작 즉시 트리 종료). PIE 검증에서 수주 불발로 발견해 게이트를 재작성·컴파일·저장하고 재조회로 잔존을 확인했다. Step1 제목도 "Quest Test"로 남아 있어 "Scout the Camp"로 정정했다.

### 후속 과제
- 선택지 UI 배선 시 수락/거절 선택지 추가(Accept 노드 분리).
- 대화의 서버 권위 이전(세션 헤더 주석의 기존 보류 과제) — 멀티 대비 시 이벤트 발행도 서버 경유로.

### 검증
- WxEditor(Development) 빌드 성공(에러 0).
- PIE E2E(Slate 자동화): 시작 직후 저널 없음 → NPC 프롬프트 "[F] Talk to Survivor" → F 로 대화 시작 → 클릭 진행 → Request 노드 진입 → 대화 종료 후 저널 "Scout the Camp / Move to the marked location." 표시·프롬프트 복귀 확인.
