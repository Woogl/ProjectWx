# GhostTrail 배치를 메시 트랜스폼 기준으로 교정

## 계획

### 목표
잔상은 포즈를 OwnerMesh 컴포넌트 스페이스에서 복사하면서 배치만 ACharacter 기본 메시 오프셋(액터 트랜스폼 + `-CapsuleHalfHeight` + `Yaw -90°`)을 손으로 재구성해 쓴다. 메시 상대 트랜스폼이 기본값이 아닌 캐릭터에서 잔상이 어긋나므로, 포즈 출처와 배치 기준을 일치시킨다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Cue/WxCueNotify_GhostTrail.cpp` | 배치 3줄을 `SetActorTransform(OwnerMesh->GetComponentTransform())`으로 대체, `CapsuleComponent.h` include 제거 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Cue/WxCueNotify_GhostTrail.h` | `LifeSpan`에 `ClampMin` 메타 추가 | 수정 |

### 접근 방식
- **메시 월드 트랜스폼 직접 사용**: 루트가 PoseableMesh이고 포즈를 OwnerMesh 기준으로 복사하므로, 액터 트랜스폼을 메시 컴포넌트 트랜스폼으로 맞추면 위치·회전·스케일이 한 번에 일치한다. 캡슐 역참조도 함께 사라진다.
- **LifeSpan은 ClampMin으로 저작 시점 차단**: `SetLifeSpan(0)`은 "수명 없음"이라 0을 넣으면 잔상 액터가 영구 누적된다. 런타임 `LifeSpan > 0.f` 가드는 누수라는 같은 결과가 되므로 채택하지 않는다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Cue/WxCueNotify_GhostTrail.cpp` | 배치 3줄을 `SetActorTransform(OwnerMesh->GetComponentTransform())`으로 대체, `CapsuleComponent.h` include 제거 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Cue/WxCueNotify_GhostTrail.h` | `LifeSpan`에 `ClampMin = "0.01"` 추가 | 수정 |

### 구현·결정과 그 이유
- **메시 트랜스폼 한 줄로 대체**: 포즈 출처와 배치 기준이 정의상 같아지므로 커스텀 메시 회전·캡슐 크기·메시 상대 스케일을 쓰는 캐릭터에서도 잔상이 본체와 정확히 겹친다. 캡슐을 안 보게 되어 널 검사 없이 역참조하던 지점도 함께 사라졌다.
- **ClampMin으로 0 차단**: 런타임 `LifeSpan > 0.f` 가드는 0일 때 `SetLifeSpan`을 건너뛰어 액터가 영구히 남는 같은 결과가 된다. 저작 시점에 0을 못 넣게 막는 쪽이 실제 해결이다.
