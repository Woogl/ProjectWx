# WxAI 리뷰 잔여 정리(9·10·11번)

## 계획

### 목표

WxAI 코드 리뷰의 🟢 항목 3건을 정리한다. 기능 결함이 아니라 주석·플래그가 실체와 어긋나 있거나 같은 모듈 안에서 규약이 갈린 것들로, 이 모듈은 주석을 사실상 규약 문서로 쓰고 있어 드리프트를 방치하면 해가 크다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Private/WxBTTask_ReturnHome.cpp` | 생성자의 노드 인스턴싱 플래그와 그 근거 주석 제거 | 수정 |
| `Plugins/WxAI/Source/WxAI/Public/WxBTTask_ReturnHome.h` | 클래스 주석에서 실체에 없는 "마지막 인지 위치" 제거 | 수정 |
| `Plugins/WxAI/Source/WxAI/Private/WxBTTask_Wander.cpp` | 방향 후보 배열에 인라인 할당자 적용 | 수정 |

10번(인식 해제 주석이 이미 제거된 BGM 컴포넌트를 근거로 드는 문제)은 직전 리뷰 2번 작업에서 부수 정정으로 처리했다. 저장소에 해당 문자열이 남아 있지 않음을 확인해 추가 수정 없음.

### 접근 방식

- **9번, 인스턴싱 해제**: 복귀 Task 는 과거 속도 캐시가 빠지면서 멤버가 하나도 남지 않은 무상태 노드인데 플래그와 주석만 남았다. 지금은 BT 컴포넌트마다 쓸모없는 노드 인스턴스와 특수 메모리를 하나씩 더 만들 뿐이다. 플래그는 직렬화되지 않는 transient 프로퍼티라 생성자 값이 곧 런타임 값이고, 빼도 에셋 재저장이 필요 없다. 같은 모듈의 배회 Task 는 반대로 실행 상태를 멤버로 들고 있어 인스턴싱이 필요하며 그대로 둔다.
- **9번, 주석 정정**: 억제가 비운다고 적힌 "마지막 인지 위치" 는 블랙보드에 그런 키가 없고 억제 동작에도 없다. 실제로 하는 일(타겟·인식·회전 모드)만 남긴다.
- **11번, 인라인 할당자**: 최대 8개로 고정된 방향 후보라 힙에 갈 이유가 없다. 같은 모듈의 랜덤 컴포지트가 동일 상황에서 이미 인라인 할당자를 쓰고 있어 그쪽에 맞춘다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Private/WxBTTask_ReturnHome.cpp` | 노드 인스턴싱 플래그와 근거 주석 제거, 종료 콜백 주석에서 없어진 속도 복원 언급 삭제 | 수정 |
| `Plugins/WxAI/Source/WxAI/Public/WxBTTask_ReturnHome.h` | 억제 설명에서 "마지막 인지 위치" 제거 | 수정 |
| `Plugins/WxAI/Source/WxAI/Private/WxBTTask_Wander.cpp` | 방향 후보 배열에 인라인 할당자 적용 | 수정 |

### 구현·결정과 그 이유
- **인스턴싱은 상태가 있는 노드에만**: 복귀 Task 는 멤버가 하나도 없는 무상태 노드라 인스턴싱이 순수 낭비였다. 플래그가 직렬화되지 않는 transient 프로퍼티라 생성자에서 빼는 것만으로 끝나고 에셋은 건드릴 필요가 없다. 상태를 멤버로 들고 있는 배회 Task 는 그대로 두어, 이 모듈에서 "인스턴싱 = 노드에 실행 상태가 있다" 는 신호가 되게 했다.
- **주석은 실제 동작만**: 억제가 "마지막 인지 위치" 를 비운다는 서술은 그런 블랙보드 키도, 그런 동작도 없다. 종료 콜백 주석의 속도 복원 언급도 같은 시기에 사라진 기능이라 함께 지웠다. 이 모듈은 주석을 규약처럼 읽으므로 없는 계약을 남겨 두면 잘못된 전제로 코드를 짜게 된다.
- **할당자는 모듈 내에서 통일**: 최대 8개 고정 후보는 힙에 갈 이유가 없고, 같은 상황의 랜덤 컴포지트가 이미 인라인 할당자를 쓰고 있어 그쪽에 맞췄다.

### 계획 대비 달라진 점
- 계획대로. 종료 콜백 주석의 속도 복원 문구 하나를 덤으로 정리했다(같은 생성자 안, 같은 원인의 드리프트).

### 후속 과제
- PIE 실동작 확인 미실시(컴파일 검증까지). 복귀 Task 가 무상태라 인스턴싱 해제로 거동이 바뀔 여지는 없다.
- 리뷰 잔여: 🟡 1·3·4·5·6·7번과 🟢 8번, 12번.
