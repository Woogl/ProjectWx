# 어빌리티 표시 데이터도 IWxUIData로

## 계획

### 목표
이펙트 쪽을 `IWxUIData`(WxCore)로 옮긴 데 이어 어빌리티도 같은 구조로 만든다. 현재 `UWxViewModel_Ability`는 아이콘을 스스로 읽지 못해 `UWxViewModelResolver_Ability`(WxGame)가 밖에서 밀어 넣고, 어빌리티에는 이름·설명 개념 자체가 없다.

### 확인한 사실
- `UWxAbilityBase::GetIcon()`은 이미 인터페이스와 시그니처가 같아 `override`만 붙이면 된다.
- `UWxViewModel_Ability::SetIconSoft` 와 리졸버의 아이콘 주입은 서로만 쓰는 짝이다.
- 어빌리티 VM은 공유본을 재사용하고 `Initialize`가 생성 시 한 번만 도니, 리졸버의 중복 스트리밍 가드는 불필요해진다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../Ability/WxAbilityTableRow.h` | `Title`, `Description` 칼럼 추가 | 수정 |
| `Plugins/WxCombat/.../Ability/WxAbilityBase.h/.cpp` | `IWxUIData` 구현 | 수정 |
| `Plugins/WxUI/.../MVVM/WxViewModel_Ability.h/.cpp` | `Title`/`Description` 추가, `Cast<IWxUIData>`로 직접 읽기, `SetIconSoft` 제거 | 수정 |
| `Source/WxGame/MVVM/WxViewModelResolver_Ability.cpp` | 아이콘 주입 제거 (MaxRecharges 주입 유지) | 수정 |

### 접근 방식
- **앵커 불필요**: 이펙트와 달리 VM이 이미 어빌리티 CDO 포인터를 쥐고 있어 `Cast<IWxUIData>` 한 번이면 된다.
- **필드명 통일**: 두 VM 모두 `Title`/`Description`/`Icon` — 같은 위젯 관례로 바인딩된다.
- `MaxRecharges`는 표시 데이터가 아니라 리졸버 주입으로 남긴다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../Ability/WxAbilityTableRow.h` | `Title`, `Description` 칼럼 추가 | 수정 |
| `Plugins/WxCombat/.../Ability/WxAbilityBase.h/.cpp` | `IWxUIData` 구현 (`GetIcon`은 `override`만, `GetTitle`/`GetDescription` 신규) | 수정 |
| `Plugins/WxUI/.../MVVM/WxViewModel_Ability.h/.cpp` | `Title`/`Description` 필드 추가, Initialize에서 `Cast<IWxUIData>`로 직접 읽기, `SetIconSoft` 제거 | 수정 |
| `Source/WxGame/MVVM/WxViewModelResolver_Ability.h/.cpp` | 아이콘 주입 제거, 주석 정정 | 수정 |

### 구현·결정과 그 이유
- **앵커 없이 직접 캐스팅**: 이펙트는 GE 컴포넌트 배열을 클래스로만 뒤질 수 있어 엔진 베이스를 앵커로 삼아야 했지만, 어빌리티 VM은 이미 CDO 포인터를 쥐고 있어 `Cast<IWxUIData>(InAbility)` 한 번이면 된다.
- **아이콘 주입 경로 제거**: VM이 초기화에서 스스로 읽으므로 `SetIconSoft`와 리졸버의 중복 스트리밍 가드(`if (!GetIcon())`)가 함께 사라졌다. VM은 공유본이고 Initialize는 생성 시 한 번만 돌아 중복 스트리밍이 애초에 없다.
- **`MaxRecharges`는 그대로 주입**: 표시 데이터가 아니라 이 계약에 넣지 않았다. 리졸버는 이 값 때문에 계속 남는다.
- **필드명 통일**: 이펙트 VM과 같은 `Title`/`Description`/`Icon` — 스킬 슬롯과 버프 위젯이 같은 관례로 바인딩된다.
