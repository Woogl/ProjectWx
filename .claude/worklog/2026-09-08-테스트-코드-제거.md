# 자동화 테스트 코드 전면 제거

## 계획

### 목표
프로젝트의 C++ 자동화 테스트를 전부 걷어낸다. 테스트 파일뿐 아니라 테스트만을 위해 남아 있던 프로덕션 코드의 접근 통로(`friend`)와 죽은 모듈 의존까지 함께 정리해, "왜 있는지 모를 선언"을 남기지 않는다.

### 접근 방식
- **테스트가 유일한 소비자였던 의존만 제거**: 비테스트 코드에 심볼이 하나도 없는 것만 뺀다. `UnrealEd`(`WxSpawner`)·`PropertyBindingUtils`(`WxStateTreeTask_SendEvent`)·`GameplayAbilities`(`GameplayEffectUIData.h`) 등은 유지. 전이 include 로 실제 필요했다면 빌드가 곧바로 잡으므로, 실패하면 그 항목만 되돌린다.
- **`WxQuest` 는 이미 죽은 의존**: 테스트와도 무관하게 `WxEditor` 어디서도 안 쓰여 같은 정리 범위에 넣는다.
- **문서는 실행 절차만 손댄다**: `WxDevice-state-synchronization.md` 의 「검증」 절은 지워진 테스트를 돌리라는 지시라 제거하고, `module_review_*.md` 같은 시점 스냅샷 문서는 그대로 둔다.

### 구현·결정과 그 이유
- **의존 제거는 빌드로 증명했다**: 비테스트 코드의 심볼 검색으로 후보를 고른 뒤 실제로 빼고 빌드했다. `WxEditor`·`WxWorld`·`WxUI`·`WxGame` 모두 재컴파일·재링크가 통과했으므로 전이 include 로 필요했던 항목은 없었다.
- **빈 `Tests` 폴더도 지웠다**: 4개 폴더 모두 테스트 파일 외 내용이 없었다.
- **문서는 실행 절차만 손댔다**: `WxDevice-state-synchronization.md` 의 「검증」 절은 지워진 테스트를 돌리라는 지시였다. `module_review_*.md`·`FrontEnd_게임진입_흐름분석.md` 의 테스트 언급은 작성 시점 스냅샷이라 그대로 뒀다.
