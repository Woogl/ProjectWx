# 부활을 체크포인트 PlayerStart 트랜스폼으로 고정

## 계획

### 목표
부활 시 저장된 폰 위치/시선(상호작용 순간 값) 대신 마지막 상호작용 체크포인트의 PlayerStart 트랜스폼(위치+시선)으로 부활하도록 변경한다. 이에 따라 미사용이 되는 폰 트랜스폼/컨트롤 로테이션 캡처·저장 로직을 제거한다. 맵 트래블 데이터·스탯 세이브는 유지.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Framework/WxGameMode.h/.cpp` | `SpawnDefaultPawnFor` 오버라이드 제거(기본=StartSpot 스폰), `FinishRestartPlayer`의 저장 시선 복원 블록 제거(스탯 복원 유지) | 수정 |
| `Source/WxGame/Framework/WxPlayerSpawningComponent.h/.cpp` | `TryGetSavedPawnSpawn` 제거. `ChoosePlayerStart`는 유지 | 수정 |
| `Plugins/WxSave/.../Public/WxPersistenceSaveGame.h` | `FWxPersistenceTravelData`에서 `PawnTransform`·`bHasPawnTransform`·`ControlRotation`·`bHasControlRotation` 제거. `Map` 유지 | 수정 |
| `Plugins/WxSave/.../Private/WxPersistenceWorldSubsystem.cpp` | `FlushMapTravelData`에서 폰 트랜스폼/시선 캡처 제거. `Map` 캡처 유지 | 수정 |
| `Plugins/WxSave/.../Private/WxPersistenceGameSubsystem.cpp` | `LogSaveState`(Wx.Save.Dump)의 폰 위치 덤프 제거 | 수정 |

### 접근 방식
- **부활 위치·시선 = 체크포인트 PlayerStart**: `ChoosePlayerStart` 가 저장 태그로 고른 StartSpot 에 엔진 기본 스폰 경로가 스폰하고 컨트롤 로테이션도 그 회전으로 세팅한다. "폰 트랜스폼 우선" 오버라이드만 제거하면 자동으로 체크포인트 기준이 된다.
- **스탯 복원 유지**: 위치와 무관하므로 `FinishRestartPlayer` 의 `ApplyPlayerStats` 는 남긴다.
- **Map 유지**: 부활 시 이동할 맵 결정에 필요하므로 `TravelData.Map` 캡처/필드는 유지.

### 구현·결정과 그 이유
- **오버라이드 제거로 체크포인트 기준 스폰**: `ChoosePlayerStart` 가 저장 태그로 고른 체크포인트 PlayerStart(StartSpot)에 엔진 기본 스폰 경로가 위치+회전을 적용하므로, "폰 트랜스폼 우선" 오버라이드를 걷어내는 것만으로 정확히 체크포인트 트랜스폼에서 부활한다.
- **폰 트랜스폼/시선 캡처 전면 제거**: 소비처가 사라져 죽은 코드가 되므로 저장 필드·캡처·덤프까지 함께 정리했다. `TravelData.Map`(부활 맵)·`PlayerStartTag`(체크포인트 선택)·스탯 복원은 유지.

### 후속 과제
- **디자이너 확인**: 이제 부활 시선이 체크포인트 PlayerStart 의 배치 회전을 그대로 따르므로, 각 체크포인트의 방향(Yaw)이 자연스러운 부활 시선을 향하는지 확인이 필요하다(이전엔 마지막 플레이어 시선이라 무관했음).
- **메뉴 Load Game 파급**: 로드도 부활과 동일 스폰 경로라, 자유 위치에서 메뉴 저장해도 로드 시 마지막 체크포인트 위치로 스폰된다(소울류엔 일관, "저장 지점 복원"은 불가).
- PIE 실동작 검증 미수행(컴파일만 확인).
