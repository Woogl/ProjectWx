# 이펙트 테이블 표시 칼럼 추가

## 계획

### 목표
`FWxEffectTableRow`(`DT_Effect` 행 타입)가 수치(`Magnitude`, `Duration`)만 들고 있어, 이펙트 표시에 필요한 아이콘·이름·설명을 같은 행에서 저작할 수 없다. 표시용 칼럼 3개를 추가한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/AbilitySystem/Effect/WxEffectTableRow.h` | `Title`, `Description`, `Icon` UPROPERTY 3개 추가 | 수정 |

그 외 C++ 변경 없음. `UWxEffectComponent_Table`, MMC들, `DT_Effect.uasset` 모두 손대지 않는다 — 데이터테이블은 행 구조체에 칼럼이 늘면 기존 행에 빈 값으로 자동 확장된다.

### 접근 방식
- **아이콘 타입**: 프로젝트 선례(`UWxItemDefinition::Icon`, `UWxEffectComponent_UIData::Icon`)와 동일하게 `TSoftObjectPtr<UObject>` + `AllowedClasses`로 Texture2D/MaterialInterface 둘 다 허용한다. 소프트 참조라 행 참조만으로 아이콘 에셋이 로드되지 않는다.
- **Category 분리**: 수치는 `"Effect"`, 표시용은 `"Display"`로 묶는다.
- **범위 한정**: 기존 버프 위젯 경로(`UWxEffectComponent_UIData` → `UWxViewModel_Effect`)는 건드리지 않는다. 새 칼럼을 읽는 소비처는 후속 작업.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../Effect/WxEffectTableRow.h` | `Title`, `Description`, `Icon` UPROPERTY 3개 추가 | 수정 |

### 구현·결정과 그 이유
- **아이콘을 `TSoftObjectPtr<UObject>` + `AllowedClasses`로**: 프로젝트 선례와 맞추고, 행을 읽는 것만으로 아이콘 에셋이 로드되지 않게 한다. 머티리얼 아이콘도 그대로 쓸 수 있다.
- **`Category = "Display"`로 분리**: 행 상세 패널에서 수치와 표시 데이터가 섞이지 않는다.
- **`DT_Effect.uasset` 미변경**: 행 구조체에 칼럼이 늘면 기존 행이 빈 값으로 자동 확장되므로 에셋 마이그레이션이 필요 없다.

### 계획 대비 달라진 점
- 계획대로

### 후속 과제
- 새 칼럼을 읽는 소비처가 아직 없다. 버프 위젯이 쓰게 하려면 `WxUI`→`WxCombat` 직접 참조가 금지이므로, `WxCore`에 표시 데이터 조회 인터페이스를 두고 `UWxEffectComponent_Table`이 구현하는 방식이 필요하다. 그때 `UWxEffectComponent_UIData`(Icon/DisplayName)와의 중복도 정리 대상.
