# AI 컨트롤러 개명 (WxEnemyController → WxAIController)

## 계획

### 목표
소환수처럼 아군인 폰도 같은 컨트롤러가 몰게 됐고 앞으로 파티원도 그럴 텐데, 이름만 "에너미"로 좁게 붙어 있다. 실제 역할에 맞춰 `AWxAIController`로 개명한다. 동작은 바뀌지 않는다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Controller/WxEnemyController.{h,cpp}` | `WxAIController.{h,cpp}`로 이동, 클래스명·정의부·generated 표기 개명, 클래스 주석 갱신 | 수정 |
| `Source/WxGame/Character/WxEnemyCharacter.cpp` | include와 `AIControllerClass` 지정 갱신 | 수정 |
| `Source/WxGame/Character/WxMinion.cpp` | 같음 | 수정 |
| `Plugins/WxAI/README.md` | 상·하위 관계 서술의 클래스 표기 갱신 | 수정 |

### 접근 방식
- **전용 컨트롤러 대신 개명**: 이 클래스가 하는 일(팀 동기화, 퍼셉션 리스너 갱신, 행동트리 실행, 블랙보드 초기화, 사망 시 로직 정지)은 전부 팀과 무관하다. 에너미 전용은 타겟 유무 통보 한 줄뿐이고 이미 캐스트로 갈라져 있어, 소환수용 컨트롤러를 새로 만들면 차이가 0줄인 복사본이 생긴다.
- **리다이렉트 불필요**: `AIControllerClass`를 BP 디폴트가 아니라 캐릭터 C++ 생성자에서만 지정해 와서, 콘텐츠 전역 에셋 참조가 0건이다.
- **리뷰 문서는 손대지 않음**: 특정 시점의 스냅샷이고 `module-review` 스킬이 다시 쓴다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Controller/WxAIController.{h,cpp}` | 옛 `WxEnemyController.{h,cpp}`를 옮겨 개명, 클래스 주석에 팀 무관 사실 반영 | 수정 |
| `Source/WxGame/Character/WxEnemyCharacter.cpp`, `WxMinion.cpp` | include와 `AIControllerClass` 지정 갱신 | 수정 |
| `Plugins/WxAI/README.md` | 상·하위 관계 서술의 클래스 표기 갱신 | 수정 |

### 구현·결정과 그 이유
- **개명만 하고 구조는 그대로**: 에너미 전용인 타겟 유무 통보는 캐스트 분기에 남겨, 소환수·파티원이 늘어도 컨트롤러 본문은 팀을 묻지 않는다.
- **리다이렉트 없이 끝남**: 콘텐츠 전역 에셋 참조가 0건이라 코드 참조만 고치면 됐다. 계획대로 확인 후 생략했다.

### 계획 대비 달라진 점
- 파일 이동을 `git mv`로 스테이징해 둔 사이 같은 저장소에서 작업하던 다른 세션이 커밋해, 이름 변경 두 건이 그 커밋(`88c9d70f`, 타임 딜레이션 제거)에 섞여 들어갔다. 내용 변경은 그 뒤라 워킹 트리에 남아 있다. 히스토리를 되돌리지 않고 그대로 뒀다.

### 후속 과제
- 동시 세션이 도는 동안에는 파일 이동을 마지막에 하거나, 커밋 직전까지 스테이징을 미루는 편이 안전하다.
