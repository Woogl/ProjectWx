# 기믹 State 필드 베이스 호이스트

## 계획

### 목표
앞선 enum→GameplayTag 전환에 이어, 자식마다 복붙되던 `FGameplayTag State` 필드와 그 부속(`SetGimmickState`/`GetGimmickState` 오버라이드, `GetLifetimeReplicatedProps`)을 부모 `AWxGimmick` 으로 올린다. 베이스가 이미 State 쓰기·OnRep·이벤트 송출·복원 전부를 소유하므로, 필드만 자식에 갇혀 만들던 가상 가교를 없앤다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxGimmick.{h,cpp}` | `State`(ReplicatedUsing+SaveGame) + `GetLifetimeReplicatedProps` 베이스로 이동, `Set/GetGimmickState` 가상 제거, Commit/SendEvent 가 `State` 직접 사용 | 수정 |
| 자식 6종(Door/Elevator/SpawnConsole/AlarmConsole/TreasureChest/LaserCorridor) | `State` 필드·`Set/GetGimmickState`·`GetLifetimeReplicatedProps` 제거, 생성자 기본값만 유지, 불필요 `Net/UnrealNetwork.h` 제거 | 수정 |
| `WxCutsceneTrigger.{h,cpp}` | 위와 동일 + **일시 상태 예외**: 베이스 필드가 SaveGame 이므로 복원 시 Playing 고착 방지를 위해 BeginPlay·OnWxSaveRestored 에서 State 를 Idle 로 리셋 | 수정 |

### 접근 방식
- **베이스가 필드까지 소유**: `State` 를 protected 로 올려 자식이 생성자 기본값·핸들러 비교에 직접 접근. `CommitGimmickState` 는 `State = NewState` 직접 대입, `SendGimmickStateEvent` 는 `State` 직접 송출 → `Set/GetGimmickState` 가상 2개 소멸.
- **Cutscene 예외**: 비저장이 7종 중 유일. 단일 SaveGame 베이스 필드로는 표현 불가하므로, Cutscene 만 복원 진입점(BeginPlay 전·OnWxSaveRestored 전)에서 권위 측 State 를 Idle 로 리셋한다(저장값은 무시). 저장 파일에 드물게 Playing 이 들어갈 수 있으나 로드 시 버려져 동작은 동일.

### 구현·결정과 그 이유
- **필드를 베이스로**: 베이스가 이미 쓰기(`CommitGimmickState`)·OnRep·이벤트 송출·복원을 전부 소유했고, `Set/GetGimmickState` 가상은 오직 "필드가 자식에 갇혀서" 건너가려 만든 가교였다. 필드를 올리니 가교 2개가 통째로 사라지고, 자식 6종에서 동일 복붙(필드+오버라이드 2개+rep props)이 제거됐다. `State` 는 protected 라 자식이 생성자 기본값·핸들러 비교에서 직접 접근.
- **Cutscene 만 예외**: 비저장이 7종 중 유일. 단일 SaveGame 베이스 필드로는 표현 불가하므로, Cutscene 은 두 복원 경로(BeginPlay 의 월드 초기화 복원, OnWxSaveRestored 의 스트리밍 인)에서 권위 측 State 를 Idle 로 리셋한 뒤 Super 를 호출한다. 베이스가 Idle 을 ST 에 발행해 Playing 고착(입력 차단·재상호작용 불가)을 막는다. 트레이드: 저장 파일에 드물게 무의미한 Playing 이 들어가나 로드 시 버려진다.
