# 상호작용 per-object 프롬프트 위젯 제거 (리스트 HUD 전용화)

## 계획

### 목표
플레이어 중앙 리스트 HUD(`WBP_InteractionList`) 도입으로 `UWxInteractionComponent`가 객체마다 자동 생성하던 떠다니는 프롬프트 위젯이 잉여가 됨. 텍스트는 리스트가, 공간 지시는 아웃라인이 담당하므로 프롬프트 표시 경로를 들어내고 전용 계약·애셋까지 정리한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Interaction/WxInteractionComponent.h` | `PromptWidgetClass`·`InteractionWidget`·`OnRegister`·`SetInteractionWidgetVisible`·관련 전방선언 제거, `InteractionText` 주석 갱신, 헤더 주석 정리 | 수정 |
| `Plugins/WxWorld/.../Interaction/WxInteractionComponent.cpp` | 위젯 관련 include·정의·호출 제거, `SetInteractionText` 단순화, `SetHighlightEnabled`의 위젯 스킵 제거 | 수정 |
| `Plugins/WxWorld/.../Interaction/WxInteractionWidgetInterface.h` | 파일 삭제 | 삭제 |
| `Plugins/WxWorld/README.md` | 프롬프트 위젯 언급 제거·갱신 | 수정 |

### 접근 방식
- 컴포넌트 책임 축소: 오버랩 감지 → 아웃라인 + 레지스트리 등록 → `TryInteract` → Multicast. 위젯 직접 생성 안 함.
- `InteractionText`/`GetInteractionText()`는 리스트 데이터 소스라 유지. `SetInteractionText`는 텍스트 저장만으로 단순화.
- `IWxInteractionWidgetInterface`는 프롬프트 전용이라 삭제. BP 구현체 `WBP_Interact`는 사용자가 에디터에서 삭제.

### 구현·결정과 그 이유
- **컴포넌트 책임 축소**: `UWxInteractionComponent`가 위젯을 더는 만들지 않고 *오버랩 → 아웃라인 + 레지스트리 등록 → TryInteract → Multicast*만 담당. 표시는 플레이어 HUD 리스트가 전담.
- **`InteractionText` 보존**: 레지스트리가 `GetInteractionText()`로 읽는 리스트 데이터 소스라 유지. `SetInteractionText`는 위젯 푸시를 빼고 텍스트 저장만 — `WxItemPickup`의 동적 텍스트 입구는 그대로 동작.
- **UMG 의존 제거**: 위젯 컴포넌트가 WxWorld의 유일한 UMG 사용처였음을 확인하고 Build.cs·README에서 함께 제거(의존 그래프 슬림화).
- **강조 루프의 위젯 스킵 제거**: 우리가 만들던 위젯 컴포넌트가 사라져 `IsA<UWidgetComponent>` 예외가 불필요해짐(현재 어떤 기믹도 위젯 컴포넌트 미보유).

### 계획 대비 달라진 점
- `UMG` 의존 제거(Build.cs)를 추가 — 위젯 제거로 사용처가 0이 됨을 확인하고 함께 정리.

### 후속 과제
- **사용자 에디터 작업**(미검증): `WBP_Interact.uasset` 삭제, 기믹/액터 BP 재저장(orphaned `PromptWidgetClass` 정리), `clean-stale-snapshots`로 스테일 스냅샷 제거.
- 동적 텍스트 인-레인지 갱신(레지스트리 notify), 다중 객체 시 "선택 항목만 강조"는 별건 개선 여지.
