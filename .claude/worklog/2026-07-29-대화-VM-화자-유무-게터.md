# 대화 VM 에 화자 유무 게터 추가

## 계획

### 목표
화자 이름이 없는 대사에서 WBP_DialogueScreen 의 화자 영역을 접을 수 있도록, 대화 뷰모델이 "지금 화자가 있는가"를 바인딩 가능한 필드로 노출한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/MVVM/WxViewModel_Dialogue.h` | 화자 유무를 반환하는 FieldNotify 게터 선언 | 수정 |
| `Source/WxGame/MVVM/WxViewModel_Dialogue.cpp` | 게터 정의, 대사 변경 시 파생 필드 변경 방송 | 수정 |

### 접근 방식
- **파생 게터 + 명시 방송**: 별도 상태 멤버를 두지 않고 화자 텍스트가 비었는지로 그때그때 판정한다. FieldNotify 함수 제약(인자 없음·반환값 있음·순수)을 만족하며, 화자가 실제로 바뀐 경우에만 파생 필드 변경을 방송해 바인딩을 갱신한다.
- **표시 타입은 뷰의 몫**: VM 은 bool 만 내놓고, Visibility 변환은 WBP 바인딩에서 엔진 기본 컨버전 함수로 처리한다. 프로젝트 컨버전 라이브러리에 새 함수를 만들지 않는다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/MVVM/WxViewModel_Dialogue.h` | 화자 유무 FieldNotify 게터 선언 | 수정 |
| `Source/WxGame/MVVM/WxViewModel_Dialogue.cpp` | 게터 정의, 화자 변경 시에만 파생 필드 변경 방송 | 수정 |

### 구현·결정과 그 이유
- **프로퍼티가 아닌 함수로 노출**: 화자 유무는 화자 텍스트에서 완전히 결정되는 값이라 별도 멤버로 들고 있으면 두 상태가 어긋날 여지만 생긴다. 순수 게터로 매번 계산하면 원본 하나만 관리하면 된다.
- **변경 감지 결과를 그대로 재사용**: 대사 갱신 시 화자가 실제로 달라졌을 때만 파생 필드 변경을 알린다. 세터 매크로가 변경 여부를 되돌려주므로 별도 비교 없이 그 반환값을 조건으로 썼고, 연속 대사에서 화자가 그대로면 불필요한 바인딩 갱신이 일어나지 않는다.
- **Visibility 변환은 뷰로 미룸**: VM 이 Slate 표시 타입을 알 필요가 없고, bool→Visibility 는 엔진이 이미 컨버전 함수로 제공한다. 프로젝트 컨버전 라이브러리를 늘리지 않았다.
