# AI 컨트롤러 피아 판정을 빙의 폰에 위임

## 계획

### 목표
AI 퍼셉션의 팀 주체인 `AWxAIController`는 `GetTeamAttitudeTowards`를 재정의하지 않는다. 그래서 엔진 기본 솔버(`A != B ? Hostile : Friendly`)로 판정하고, 폰의 Neutral 규칙을 따르지 않는다.
컨트롤러가 빙의 폰의 판정에 위임하도록 바꿔, 시야가 캐릭터와 같은 규칙으로 피아를 가르게 한다(`module_review_WxGame.md` 1번).

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Controller/WxAIController.h` | `GetTeamAttitudeTowards` override 선언 | 수정 |
| `Source/WxGame/Controller/WxAIController.cpp` | 빙의 폰에 위임하고, 폰이 없으면 `Super`로 넘기는 구현 | 수정 |

### 접근 방식
- **폰 위임**: 빙의 폰을 `IGenericTeamAgentInterface`로 캐스팅해 `GetTeamAttitudeTowards(Other)`를 그대로 돌려준다. 폰이 없으면 엔진 기본 판정을 쓴다. 이때는 퍼셉션이 해제돼 있어 영향이 없다.
- **고쳐지는 경로**
  - 시야: `AISense_Sight`의 `ShouldSenseTeam(ListenersTeamAgent, TargetActor)`
  - 퍼셉션 `bIsHostile`: `AIPerceptionComponent`의 액터 오버로드 `GetAttitude`
  - 둘 다 리스너 오너인 컨트롤러에게 판정을 묻는다.
- **적용 시점**: `OnPossess`의 `RequestStimuliListenerUpdate()`가 시야 쿼리를 다시 만든다. 새 폰의 규칙은 이때 반영된다.
- **한계(사용자 확인 후 이 방식을 택함)**: 청각은 이 함수를 거치지 않아 고쳐지지 않는다. 청각은 리스너에 캐시된 팀 ID와 가해자 팀 ID를 `FGenericTeamId::GetAttitude(ID, ID)`, 즉 전역 솔버로 비교하기 때문이다. 팀 ID 캐시 갱신(`SetGenericTeamId` + 리스너 갱신)은 청각에 여전히 필요하므로 그대로 둔다.

### 구현·결정과 그 이유
- **위임 대상을 인터페이스로 받음**: 팀 규칙의 주인은 폰 쪽 `IGenericTeamAgentInterface` 구현이다. 컨트롤러가 `AWxCharacterBase`를 알 필요가 없고, `OnPossess`의 팀 ID 복사도 같은 캐스팅을 쓴다.
- **솔버 등록안 대신 컨트롤러 재정의**: `SetAttitudeSolver`로 청각까지 고치는 안도 제시했지만, 사용자가 컨트롤러 재정의를 택했다. 그래서 규칙은 캐릭터 한 곳에 그대로 둔다.
- **리뷰 문서는 수정하지 않음**: `module_review_WxGame.md`는 `/module-review`가 만드는 문서라, WxGame 변경분을 다시 리뷰할 때 새로 쓴다.

### 후속 과제
- **청각 피아 판정은 여전히 Neutral 규칙을 따르지 않는다**
  - 원인: `AISense_Hearing`(엔진 `AISense_Hearing.cpp:157`)은 리스너에 캐시된 팀 ID와 가해자 팀 ID를 전역 솔버로 비교한다. 기본 솔버에서 Neutral(255)은 다른 팀이므로 적대가 된다.
  - 증상: 청각 자극도 `UWxBTService_UpdateTargetActor`가 타겟으로 확정하므로, Neutral 폰이 낸 소음(또는 Neutral AI가 들은 소음)에서 추격만 하고 공격하지 못하는 증상이 남는다.
  - 해결하려면 `FGenericTeamId::SetAttitudeSolver`로 Neutral 규칙을 등록해야 한다.
- **런타임 미검증**: 현재 `EWxTeam::Neutral`을 쓰는 콘텐츠가 없어 컴파일만 확인했다.
