# PCG_RoadSplineMesh: 고가도로(지형 비추종) 지원

## 계획

### 목표
`PCG_RoadSplineMesh`가 샘플한 점을 무조건 랜드스케이프에 투영하는 탓에, 스플라인을 아무리 높이 올려도 도로가 땅으로 끌려 내려온다. 투영을 인스턴스별로 끌 수 있게 만들어 같은 그래프로 지상 도로와 고가도로를 모두 놓을 수 있게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/PCG/PCG_RoadSplineMesh.uasset` | 그래프 파라미터 + `Branch` 추가, 스포너 콜리전 활성화 | 수정 |

`BP_RoadSplineMesh`는 건드리지 않는다. 그래프 파라미터는 PCG 컴포넌트 디테일 패널에 자동 노출된다.

### 접근 방식
```
Get Spline Data → Spline Sampler → Branch ─ Output B ─→ Projection ─┐
                                     │                      ↑        ├→ Transform Points → …
                                     └─ Output A ───────────┼────────┘
                                                    Get Landscape Data

Get Graph Parameter (bUseLandscapeProjection) ──→ Branch 의 Output To B 오버라이드 핀
```

- **투영 경로를 B에 둔다**: `Output To B` == "투영을 쓴다"가 되어 파라미터를 그대로 연결할 수 있다. A에 두면 뜻이 뒤집혀 부정 노드가 하나 더 필요하다.
- **기본값은 둘 다 true**: 오버라이드가 없어도 지금 동작이 유지된다.
- **콜리전을 켠다**: 고가도로 아래에는 받쳐 줄 랜드스케이프가 없어, 꺼 두면 플레이어가 통과해 떨어진다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/PCG/PCG_RoadSplineMesh.uasset` | 그래프 파라미터 `bUseLandscapeProjection`, `Branch`·`Get Graph Parameter` 추가, 스포너 콜리전 `Query And Physics` | 수정 |

### 구현·결정과 그 이유
- **투영 경로를 Output B에 배치**: `Output To B`의 의미가 곧 "투영을 쓴다"가 되어 파라미터를 부정 없이 그대로 연결할 수 있다.
- **오버라이드 핀 이름은 원시 프로퍼티명**: 표시 이름 `Output To B`가 아니라 `bOutputToB`로 연결해야 한다. 표시 이름으로는 핀을 못 찾는다.
- **콜리전 프로파일을 `BlockAll`로 지정**: 콜리전만 켜면 프로파일이 이전의 `NoCollision`으로 남아 채널 응답이 전부 무시된다.

### 계획 대비 달라진 점
- 검증 방법이 달라졌다 — `SetGraphInstanceParams`가 PCGVolume 전용이라 BP 액터 인스턴스에 못 쓴다. 대신 그래프 기본값을 잠시 false로 바꿔 분기를 확인하고 되돌렸다.
- **작업 직후 방향이 바뀌어 파라미터와 투영 경로를 다시 걷어냈다.** 사용자가 항상 비투영으로 가기로 결정해, `bUseLandscapeProjection`·`Branch`·`Get Graph Parameter`·`Projection`·`Get Landscape Data`를 모두 제거했다. 도로는 이제 작성한 스플라인 높이를 그대로 쓴다. 분기 자체는 위 검증으로 동작이 확인됐으므로, 다시 필요해지면 같은 방식으로 복원하면 된다.

### 검증 결과
액터를 z=500에 띄워 배치했다.

| 파라미터 | 스플라인 메시 Z | 판정 |
|---|---|---|
| true (기본) | 5 | 투영이 도로를 지면으로 내림 |
| false | 505 | 작성한 스플라인 높이 유지 |

콜리전은 `QueryAndPhysics` / `BlockAll`로 확인했다. 투영을 끈 쪽은 지형 기울기 반영도 사라져 `startRoll`이 0으로 나온다.

### 덤으로 고친 것
`BP_RoadSplineMesh`의 Spline 컴포넌트가 `Movable`이라, PCG가 만드는 `Static` 스플라인 메시가 부모에 붙지 못하고 세그먼트마다 경고가 났다("cannot attach ... which is static to it. Aborting"). 컴포넌트가 액터에 붙지 않은 채로 월드에 떠 있는 상태였다. Spline을 `Static`으로 바꿔 해결했다 — 도로 스플라인은 런타임에 움직이지 않으므로 Static이 맞고, 정적 라이팅도 받을 수 있다.

### 후속 과제
- 도로가 항상 스플라인 높이를 쓰므로, 지형을 따라가게 하려면 스플라인 점의 Z를 직접 잡거나 지형을 도로에 맞춰 평탄화해야 한다.
- 교각·난간 없음. 고가 구간이 공중에 떠 있는 판으로만 보인다.
