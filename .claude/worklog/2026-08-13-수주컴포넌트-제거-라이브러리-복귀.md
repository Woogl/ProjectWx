# 수주 컴포넌트 제거 — 볼륨 BP + 퀘스트 라이브러리(StartQuest) 복귀

## 계획

### 목표
오늘 새벽 신설한 `UWxQuestActivationComponent`(레벨 액터 부착·오버랩 수주)를 걷어내고, 수주를 `BP_QuestVolume` 그래프 + 퀘스트 BP 진입점 경로로 되돌린다. 오후에 호출자 0이 되어 삭제했던 `UWxQuestLibrary` 를 되살리되, BP 진입점 이름은 `StartQuest` 로 둔다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxQuest/.../Quest/WxQuestActivationComponent.h/.cpp` | 삭제(오늘 새벽 신설분, 추적 전) | 삭제 |
| `Plugins/WxQuest/.../Quest/WxQuestLibrary.h/.cpp` | `git restore` 로 부활 → `ActivateQuest`→`StartQuest` 개명, `SendQuestEvent` 는 제외 | 부활+수정 |
| `Plugins/WxQuest/.../Quest/WxQuestComponent.h` | 클래스 주석의 수주 경로 서술을 라이브러리 경유로 정정 | 수정 |
| `Content/Quest/BP_QuestVolume.uasset` | `git restore`(오버랩 그래프+`QuestAsset` 변수 복원) 후 함수 호출 노드를 `Start Quest` 로 교체 | 복원+수정 |
| `Content/__ExternalActors__/Maps/LV_DevCombat/C/M9/80WPCYCDKX7D5QCD5THX2P.uasset` | `git restore`(볼륨 인스턴스의 `QuestAsset`=ST_Quest_Main1 복원) | 복원 |

### 접근 방식
- **라이브러리는 HEAD 코드 그대로, 이름만 `StartQuest`**: HEAD 구현은 월드 컨텍스트 → GameState → 퀘스트 컴포넌트를 찾아 위임하는 형태이고 컴포넌트의 포인터 오버로드가 그대로라 위임은 수정 없이 맞물린다. 개명 대상은 BP 진입점 하나이고 컴포넌트 API·체인 태스크의 활성화 어휘는 유지한다. `SendQuestEvent` 는 짝이 되는 컴포넌트 API 가 오후에 제거됐고 호출자도 0이라 되살리지 않는다.
- **부활한 doc-comment 의 "Start 게이트" 서술은 뺀다**: 제목 태스크가 진입 즉시 Succeeded 라 게이트가 아니며, 실제 수주 시점은 이 호출 자체다.
- **BP 는 복원 후 노드 1개만 교체**: 복원하면 이름이 바뀐 함수 호출 노드만 미해석으로 남는다. 오버랩 이벤트·플레이어 캐스트·콜리전 오프와 노드 배치는 그대로 살아남고, 변수 이름이 같아 복원한 레벨 인스턴스 값도 그대로 붙는다.
- **콘텐츠 복원은 에디터를 내린 뒤에**: 켜진 채로 되돌리면 메모리의 현재 버전이 다시 저장돼 복원본을 덮을 수 있다.

### 구현·결정과 그 이유
- **개명은 BP 진입점 하나로 한정**: 플레이어가 느끼는 "시작"을 BP 표면에 두고, 컴포넌트 API 와 체인 태스크의 활성화 어휘는 그대로 뒀다. 저작자가 보는 노드 이름과 코드 내부 어휘가 갈리지만, 개명 범위를 넓히면 8/3 에 정리한 2단 구조(탑재 vs 개시)의 구분이 도로 흐려진다.
- **`SendQuestEvent` 는 되살리지 않음**: 짝이 되는 컴포넌트 API 가 없고 호출자도 0이다. 마침 같은 시점에 `Quest.Fail` 태그도 별도로 정리돼, 실패 경로는 지금 ST 전이만 남았다.
- **해석 헬퍼 인라인**: 호출자가 하나뿐이라 익명 네임스페이스 헬퍼를 본문으로 풀어 썼다.
- **BP 는 복원 + 노드 1개 교체**: 오버랩 이벤트·권위 스위치·플레이어 캐스트·콜리전 오프가 그대로 살아남고, 변수 이름이 같아 복원한 레벨 인스턴스 값도 재기입 없이 붙었다.
- **주석의 "Start 게이트" 서술은 빼고 부활**: 제목 태스크가 진입 즉시 Succeeded 라 게이트가 아니며, 실제 수주 시점은 이 호출 자체다.

### 검증
- WxEditor(Development) 빌드 성공(30액션, 에러 0), 에디터 재실행.
- BP 컴파일이 warnings-as-errors 로 통과, 저장 후 그래프 재조회로 `Wx|Quest|StartQuest` 결선 확인.
- 레벨 인스턴스가 컴포넌트 3개(Collision·Sprite·TextRender)로 복귀, `QuestAsset`=ST_Quest_Main1 잔존 확인.
- PIE 실측: 볼륨 안에 스폰 → 저널("모험의 시작"/"NPC와 대화하기") 표시(스크린샷). 복원한 그래프는 캐릭터 캐스트라 조종 여부를 보지 않으므로, 컴포넌트 판정에서 걸렸던 "볼륨 안 스폰 미수주"가 여기선 일어나지 않는다.
