# StateTree 태스크 표시 문구 한글화

## 계획

### 목표
기획자가 한국인이라 StateTree 에디터의 영어 문구가 작업을 막는다. 노드에 뜨는 `GetDescription` 설명과 태스크 추가 메뉴에 뜨는 `DisplayName` 메타를 한국어로 옮겨, 트리를 눈으로 훑고 한글로 검색해 태스크를 고를 수 있게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| Wx 태스크 26개 `.cpp` 의 `GetDescription` | 설명 문구와 폴백 토큰을 한국어로 교체 | 수정 |
| Wx 태스크 27개 `.h` 의 `USTRUCT(meta = (DisplayName = ...))` | 추가 메뉴 이름을 한국어로 교체 | 수정 |
| `Plugins/WxWorld/.../System/WxSpawnerLibrary.cpp` | 스포너 목록 텍스트의 빈 표시 `none` → `없음` | 수정 |

태스크는 총 27개이며, 파라미터가 없어 의도적으로 `GetDescription` 을 두지 않은 `Refill Item Charges` 만 헤더 한 곳으로 끝난다. StateTree Condition·Evaluator 는 프로젝트에 없다.

### 접근 방식
- **형식은 그대로, 어휘만 옮긴다**: `이름 (파라미터)` 구조를 유지해 기획자가 이미 익힌 읽는 법이 바뀌지 않게 한다. 노드 라벨이므로 문장이 아닌 명사·동사구로 맺는다(`사운드 재생 (SFX_Door)`).
- **폴백 토큰까지 함께 옮긴다**: 값이 비었을 때 남는 `unset`·`none`·`unresolved`·`owner`·`player` 를 `미지정`·`없음`·`미해석`·`오너`·`플레이어` 로 바꾼다. 미지정 노드야말로 기획자가 찾아내야 할 노드라 여기가 영어로 남으면 한글화가 반쪽이 된다. 대상 이름을 만드는 `GetTargetDisplayName` 헬퍼가 태스크마다 따로 있어 네 벌을 같이 손대고, 스포너 쪽 빈 표시만 공용 라이브러리 한 곳에 있다.
- **추가 메뉴 이름도 같이 옮긴다**: 설명만 바꾸면 정작 태스크를 고르는 자리가 영어로 남고, 설명이 없는 `Refill Item Charges` 는 노드에서도 영어로 남는다. `Category = "Wx"` 는 그룹 라벨이라 유지한다.
- **표시 문자열만 건드린다**: 에셋에는 노드 구조체 타입만 저장되므로 기존 StateTree 에셋에 영향이 없고, `DisplayName` 을 코드로 조회하는 툴도 없다(MCP 툴셋은 클래스 경로로 노드를 다룬다). 한글 리터럴은 UBT 가 MSVC 에 `/utf-8` 을 넘기므로 BOM 없는 UTF-8 소스에서 그대로 컴파일된다.
- **어긋난 이름은 이참에 맞춘다**: `StartNextQuest` 는 메뉴 이름이 `Start Next Quest`, 설명이 `Activate Next Quest` 로 갈려 있었다. `다음 퀘스트 시작` 으로 통일한다.
