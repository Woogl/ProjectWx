# 상호작용 목록 공급 (집계 컴포넌트 + Resolver)

## 계획

### 목표
출력 VM에 인-레인지 대상 목록을 먹여주는 경로를 붙인다. 선택은 UI 소유(이미 `SetSelectedIndex`)이므로 목록(Entries) 공급만 다룬다. WxCore·AWxPlayerCharacter C++ 무변경(집계 컴포넌트는 사용자가 플레이어 BP SCS에 부착).

### 수정 범위
| 모듈 | 파일 | 내용 |
|---|---|---|
| `WxWorld` | `Interaction/WxInteractionListComponent.h/.cpp` (신규) | 인-레인지 목록 집계 + `OnListChanged` 델리게이트 + `GetPrompts`. 선택/틱/복제 없음 |
| `WxWorld` | `Interaction/WxInteractionComponent.h/.cpp` (수정) | 로컬 오버랩/비활성 시 Pawn의 ListComponent에 register/unregister, `GetInteractionText()` 게터, 등록처 캐시 |
| `WxGame` | `MVVM/WxViewModelResolver_Interaction.h/.cpp` (신규) | Pawn의 ListComponent 찾아 VM 생성·`OnListChanged`→`HandleListChanged` 바인딩·시드 |

### 접근 방식
ListComponent가 register/unregister 이벤트로 목록 재구성 후 `OnListChanged(GetPrompts())` 발사. Resolver(WxGame)가 VM 생성 시 그 델리게이트를 `HandleListChanged`에 AddDynamic하고 초기값 시드. 선택은 월드에 두지 않음(UI). VM 변경 불필요(이미 HandleListChanged/SetSelectedIndex 보유).

### 후속(제외)
- 휠 입력→SetSelectedIndex(UI 위젯)
- WxAbility_Interact 선택 대상 연동 + 엔트리↔월드 매핑 + 복제
- 기존 월드 위젯 제거 + 신규 WBP_Interact 저작·Resolver 지정(사용자)

## 완료

### 수정한 파일
| 모듈 | 파일 | 수정 내용 |
|---|---|---|
| `WxWorld` | `Interaction/WxInteractionListComponent.h/.cpp` (신규) | 인-레인지 목록 집계, `OnListChanged` 델리게이트, `GetPrompts`, register/unregister. 선택/틱/복제 없음 |
| `WxWorld` | `Interaction/WxInteractionComponent.h/.cpp` (수정) | 로컬 오버랩 begin/end·비활성 시 Pawn의 ListComponent에 register/unregister(`RegisteredList` 캐시), `GetInteractionText()` 게터 |
| `WxGame` | `MVVM/WxViewModelResolver_Interaction.h/.cpp` (신규) | Pawn의 ListComponent 찾아 VM 생성, `OnListChanged`→`HandleListChanged` AddDynamic, `Initialize(GetPrompts(), 0)` 시드 |

### 구현·결정과 그 이유
- **집계자는 목록만, 선택은 UI**: ListComponent는 인-레인지 목록만 제공(SelectedIndex/휠/복제 없음). 선택은 VM의 `SetSelectedIndex`(UI 호출)가 담당해 책임이 분리됨.
- **캐릭터 C++ 무수정**: ListComponent는 BlueprintSpawnableComponent라 사용자가 플레이어 BP SCS에 부착. InteractionComponent의 register는 `FindComponentByClass`로 Pawn에서 찾아 캐시 → 캐릭터 코드 불필요.
- **WxCore 무변경 + 경계 보존**: 리졸버(WxGame)가 WxWorld 델리게이트(엔진 타입 인자)를 WxUI VM 핸들러에 AddDynamic. 동적 멀티캐스트 자동 정리로 별도 해제 불요.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **사용자(BP/콘텐츠)**: 플레이어 BP에 `UWxInteractionListComponent` 부착, 신규 `WBP_Interact`(HUD 리스트)에 `UWxViewModelResolver_Interaction` 지정, 휠 입력 → VM `SetSelectedIndex` 배선.
- **C++ 후속**: `WxAbility_Interact`가 선택 대상 사용 + 엔트리↔월드 컴포넌트 매핑 + 서버 전달(복제). 기존 대상별 월드 프롬프트 위젯 제거.
