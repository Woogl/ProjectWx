# 상호작용 스캐너를 GameFrameworkComponent 주입으로 전환

## 계획

### 목표

`UWxInteractionScannerComponent` 를 PC 생성자의 하드코딩 부착에서 GameMode 에셋 `FrameworkComponents` 주입으로 옮긴다. PC 가 WxWorld 의 구체 타입을 멤버로 아는 결합을 끊고, 스캐너 부착 여부를 게임 모드 데이터로 만든다. 이미 `UWxIndicatorManagerComponent`·`UWxPlayerSpawnComponent` 가 같은 경로를 쓰고 있고, 스캐너는 성격(로컬 어포던스 레지스트리)·조건(이미 복제됨, BP 오버라이드 없음)이 모두 맞는 유일한 남은 후보다.

### 접근 방식

- **주입 경로는 기존 인프라 그대로**: PC 는 이미 `PreInitializeComponents` 에서 receiver 로 등록되어 있고 GameMode 가 `InitGame` 에서 요청을 건다. 이번엔 등록할 컴포넌트가 하나 늘 뿐 인프라 변경이 없다.

- **생성자 시그니처가 필수 변경점**: `UControllerComponent` 는 기본 생성자가 없어 파생 컴포넌트는 `(const FObjectInitializer&)` 를 선언해 `Super` 로 넘겨야 한다. WxSave 이관 때 `UGameStateComponent` 에서 겪은 것과 같은 함정이다.

- **복제 유지가 RPC 의 전제**: 기본 서브오브젝트의 안정된 이름을 잃으므로 `ServerInteract` 라우팅이 이제 복제에만 의존한다. 이미 켜져 있는 플래그를 유지하되 이유를 주석으로 남긴다.

- **브리지는 조회로만 바꾸고 자리는 그대로**: PC 의 선택→전역 VM 브리지(WxWorld→WxUI)는 멤버 대신 `FindComponentByClass` 로 스캐너를 얻는다. 브리지 자체를 VM 쪽으로 옮기는 건 별개 작업으로 둔다.

- **호출 순서는 불변**: 주입 컴포넌트는 receiver 등록 경로에서 동기 생성·등록되므로 PC `BeginPlay` 시점에 존재하고, 컴포넌트 `BeginPlay` 의 초기 1회 스캔은 여전히 PC 의 `Super::BeginPlay()` 안에서 구독보다 먼저 돈다 — 기존의 "현재 선택으로 1회 시드" 호출이 계속 필요하다.

- **두 게임 모드 모두 등록**: 미등록은 경고 없이 상호작용이 통째로 죽는 조용한 실패라, `GM_ChangYoung` 맵 확인까지를 완료 조건으로 잡는다.

### 구현·결정과 그 이유

- **PC 의 선택 브리지는 옮기지 않고 삭제**: 이 브리지는 전역 `VM_Selection` 에 push 하는 코드였는데, 그 뷰모델을 바인딩하는 위젯이 컨텐츠 전체에 하나도 없었다(`VM_Selection`·`ViewModel_Selection` 참조 0건). 실제 화면 경로는 `UWxViewModel_InteractionList` 가 리졸버로 스캐너를 직접 구독하는 쪽이라, 브리지용 컴포넌트를 새로 만들 필요 없이 죽은 글루를 걷어내는 것으로 끝났다. PC 에서 빠진 코드 대부분이 이것이다.

- **생성자 시그니처가 필수 변경점**: `UControllerComponent` 에 기본 생성자가 없어 `(const FObjectInitializer&)` 로 바꿔 `Super` 에 전달해야 했다. WxSave 이관 때 `UGameStateComponent` 에서 겪은 것과 같은 함정이다.

- **복제 플래그 유지**: 기본 서브오브젝트의 안정된 이름을 잃어 `ServerInteract` 라우팅이 이제 복제에만 의존한다. 이미 켜져 있던 플래그를 유지하고 이유를 주석에 남겼다.

### 계획 대비 달라진 점

- **게터를 남기려다 되돌렸다**: 작업 중 다른 세션이 커밋한 인벤토리 전례(`GetInventoryManager()` 식 조회 게터 유지)를 따라 `GetInteractionScanner()` 를 두려 했으나, PC 헤더에 WxWorld 타입이 남아 "완전 분리" 요청과 어긋났다. 사용자 지적으로 되돌리고 끝까지 제거했다.
- **원격 클라 늦은 도착 대응 추가 후 철회**: 게터를 없애면서 함께 사라졌다(브리지 자체가 없어졌으므로 바인딩할 것이 없다).

### 후속 과제

- **에셋 등록 미완**: `GM_Combat`·`GM_ChangYoung` 의 `FrameworkComponents` 에 `UWxInteractionScannerComponent` 를 아직 넣지 못했다(에디터를 띄우지 못함). **등록 전까지 상호작용이 통째로 동작하지 않는다.** `BP_PlayerController` 재저장도 함께 필요하다.
- **PIE 검증 미완**: 프롬프트 표시·선택 사이클·상호작용 실행(동적 컴포넌트에서 `ServerInteract` 라우팅)을 확인하지 못했다. 빌드(`Result: Succeeded`, 경고 0)까지만 확인됐다.
- 생산자·소비자가 모두 없어진 `UWxViewModel_Selection`(WxUI) 을 살릴지 지울지 판단 필요.
