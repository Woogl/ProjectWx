# 무한 지속 GE 의 이펙트 링 표시

## 계획

### 목표
무한 지속 GE 의 이펙트 링이 항상 빈 상태로 그려진다. 잔량이 줄지 않는 버프이므로 가득 찬 상태로 표시되게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_Effect.cpp` | 초기화의 지속시간 블록에 무한 분기를 두어 링 비율을 가득 채운다 | 수정 |

### 접근 방식
- **원인**: 무한 지속은 활성 효과의 지속시간 조회가 엔진 상수 -1 을 돌려주는데, 초기화·갱신이 모두 "0 보다 큰 지속시간"으로만 열려 있어 블록을 통째로 건너뛴다. 링 비율이 기본값 0 인 채 남고 티커도 걸리지 않아 영영 0 이다.
- **무한은 "잔량 없음"이 아니라 "줄지 않음"이다**: 초기화에서 엔진의 무한 상수와 직접 비교하는 분기를 두고 링 비율을 1 로 채운 뒤 끝낸다. 엔진 자신도 같은 상수와의 동등 비교로 무한을 판별하므로 부호 조건보다 의도가 드러난다.
- **티커는 걸지 않는다**: 값이 변하지 않으니 매 프레임 재계산할 것이 없다. 스택 수는 지금처럼 스택 변경 통지가 갱신한다.
- **전체 지속·남은 시간은 0 그대로 둔다**: 무한 지속에는 대응하는 값이 없다. 두 필드는 바인딩하는 위젯이 없고, 임의의 센티널을 넣으면 소비자가 생겼을 때 숨은 규약이 된다.
- **갱신 티커는 손대지 않는다**: 유한 GE 에서만 도는 경로이고, 스택 재적용으로 지속시간이 새로 고쳐져도 무한이 되지는 않는다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_Effect.cpp` | 초기화에 무한 지속 분기를 추가해 링 비율을 가득 채우고 바로 끝낸다 | 수정 |

### 구현·결정과 그 이유
- **엔진 무한 상수와 직접 비교했다**: 활성 효과의 지속시간 조회는 무한일 때 -1 을 돌려주는데, 기존 조건은 "0 보다 큼"이라 이 값을 조용히 걸러냈다. 엔진 자신이 남은 시간·종료 시각을 계산할 때 쓰는 것과 같은 상수 비교로 바꾸니, 무한이 예외 취급된다는 사실이 조건에 그대로 드러난다.
- **링만 채우고 갱신은 걸지 않았다**: 무한 지속은 잔량이 줄지 않으므로 매 프레임 다시 계산할 값이 없다. 스택 수는 종전대로 스택 변경 통지가 맡는다.
- **전체 지속·남은 시간은 0 으로 남겼다**: 무한에는 대응하는 값이 없어, 억지로 센티널을 채우면 나중에 이 필드를 바인딩하는 위젯이 생겼을 때 숨은 규약이 된다.
