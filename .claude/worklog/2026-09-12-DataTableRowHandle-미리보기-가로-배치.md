# DataTableRowHandle 미리보기 가로 배치

## 계획

### 목표
행 미리보기가 칼럼마다 자식 행을 하나씩 추가해 세로로 쌓이는 탓에, 어트리뷰트 행처럼 칼럼이 많으면 디테일 패널을 길게 차지한다. 데이터 테이블 에디터의 한 행처럼 칼럼이 가로로 읽히게 바꾼다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxEditor/WxDataTableRowHandleCustomization.cpp` | 자식 행 구성을 칼럼별 N행에서 가로 셀을 담은 1행으로 교체 | 수정 |
| `Source/WxEditor/WxDataTableRowHandleCustomization.h` | 클래스 설명 주석을 가로 배치로 정정 | 수정 |

헤더 행의 테이블·행 선택기, 메타 식별자, 테이블 필터, 변경 통지, 참조 검색은 손대지 않는다.

### 접근 방식
- **자식 행 하나에 전체 폭**: 이름·값 칸으로 나누지 않고 행 전체 폭을 쓴다. 값 칸에만 넣으면 왼쪽 이름 칸 폭이 통째로 빈다.
- **셀은 칼럼명 위·값 아래**: 데이터 테이블 에디터의 헤더와 셀 대응을 그대로 흉내 낸다. 칼럼명은 굵은 글꼴, 값은 보통 글꼴이며 툴팁에 전체 값을 둔다.
- **넘치면 줄바꿈**: 랩 박스가 패널 폭을 넘치는 셀을 다음 줄로 넘긴다. 셀 하나가 패널보다 넓어지지 않도록 셀 폭에 상한을 두어 대사·자막처럼 긴 값은 셀 안에서 줄바꿈된다.
- **검색어 유지**: 지금은 칼럼명 각각이 행 검색어였다. 한 행이 되므로 칼럼명을 이어 붙인 텍스트를 검색어로 넘겨 디테일 검색으로 칼럼명을 계속 찾을 수 있게 한다.

### 구현·결정과 그 이유
- **전체 폭 자식 행 하나**: 이름·값 칸 분할을 쓰지 않아 왼쪽 이름 칸 폭이 비지 않고, 칼럼이 많아도 행 하나만 차지한다.
- **셀은 칼럼명 위·값 아래**: 데이터 테이블 에디터의 헤더/셀 대응을 그대로 흉내 내 어느 값이 어느 칼럼인지 바로 읽힌다. 칼럼명은 굵은 글꼴, 값은 보통 글꼴이고 툴팁에 전체 값을 둔다.
- **랩 박스 + 셀 폭 상한**: 랩 박스는 할당 폭을 기준으로 넘치는 셀을 다음 줄로 넘기지만, 셀 하나가 패널보다 넓으면 그대로 잘린다. 셀 폭 상한을 두어 대사·자막처럼 긴 값은 셀 안에서 줄바꿈되게 했다.
- **검색어는 칼럼명 결합**: 행이 하나가 되면서 검색어도 하나뿐이라, 칼럼 표시명을 이어 붙여 디테일 검색으로 칼럼명을 계속 찾을 수 있게 했다.
