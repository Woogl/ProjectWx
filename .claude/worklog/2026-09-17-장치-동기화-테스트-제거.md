# 장치 동기화 테스트 제거

## 계획

### 목표
사용자 지시로 장치 당사자 동기화 자동화 테스트 `Wx.World.Device.OptionalInteractor`(`WxDeviceInteractorSyncTest`)를 제거한다. 테스트 때문에 컴포넌트 헤더에 넣어 둔 friend 선언과 README 안내도 함께 걷는다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/Source/WxWorld/Private/Tests/WxDeviceInteractorSyncTest.cpp` | 테스트 파일과 비게 되는 `Tests/` 폴더 | 삭제 |
| `Plugins/WxWorld/Source/WxWorld/Public/Device/WxDeviceStateTreeComponent.h` | `WITH_DEV_AUTOMATION_TESTS` friend 블록 | 수정 |
| `Plugins/WxWorld/README.md` | 「여기서부터 읽어라」의 테스트 항목 | 수정 |

### 접근 방식
- **참조만 걷는다**: 코드에서 테스트를 참조하는 곳은 friend 선언 하나뿐이다. 테스트가 들여다보던 멤버(`HasState`, `SyncFailure`, 시리얼 등)는 모두 본 코드가 쓰므로 그대로 둔다.
- **이력 문서는 두기**: 모듈 리뷰 문서는 다음 `/module-review` 갱신 때 반영된다. `.codex` 워크로그는 이력이다.
