# 콜리전 채널 상수를 엔진 스타일 ECC_WxAttack / ECC_WxInteractable 로 전환

## 계획

### 목표
`WxCollision` 네임스페이스 상수를 전역 `ECC_WxAttack`, `ECC_WxInteractable` 로 바꿔 엔진 열거자(`ECC_Pawn` 등)와 표기를 통일한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCore/Source/WxCore/Public/WxCollisionChannels.h` | 네임스페이스 제거, 전역 `inline constexpr` `ECC_Wx*` 상수로 교체 | 수정 |
| `Source/WxGame/AbilitySystem/Ability/WxAbility_Interact.cpp` | 호출부 치환 | 수정 |
| `Source/WxGame/Character/WxCharacterBase.cpp` | 호출부 치환 (2곳) | 수정 |
| `Plugins/WxWorld/Source/WxWorld/Private/Interaction/WxInteractionComponent.cpp` | 호출부 치환 | 수정 |
| `Plugins/WxInventory/Source/WxInventory/Private/Items/WxItemPickup.cpp` | 호출부 치환 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/Weapon/WxWeaponBase.cpp` | 호출부 치환 | 수정 |
| `Docs/Programmer/Interaction_System.md`, `Plugins/WxCore/README.md` | 구명칭 언급 갱신 | 수정 |

### 접근 방식
- **전역 `inline constexpr`**: `#define`(샘플 방식) 대신 타입 안전한 constexpr 상수로 정의한다. 호출부 표기는 매크로와 동일하게 `ECC_WxAttack` 이 된다. 채널 값(ini 등록 대응)은 불변이라 동작 변화 없음.

### 구현·결정과 그 이유
- **매크로 대신 전역 constexpr**: 샘플(ShooterGame/Lyra)의 `#define` 방식과 호출부 표기는 동일하지만, 타입이 붙고 스코프 규칙을 따르므로 UE 컨벤션이 권장하는 쪽을 택했다.
- **채널 값 불변**: ini 등록 대응(`ECC_GameTraceChannel1/2`)은 그대로라 콜리전 동작·에셋 영향 없음.
