# Enable Interaction 의 InteractEvent 필드 제거

## 계획

### 목표

`Enable Interaction` 태스크는 영역마다 발행할 이벤트 태그를 지정할 수 있게 열어 두었다. 영역이 여럿인 기믹이 공용 태그 아래 자식 태그로 갈리도록 만든 장치인데, 방금 그 구분을 전이 조건의 페이로드 `Source` 비교로 옮기면서 소비처가 사라졌다. 남겨두면 노드 UI 와 문서가 이미 폐기한 방식을 계속 권하므로 걷어낸다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Gimmick/WxGimmickStateTreeNodes.h`/`.cpp` | 인스턴스 데이터의 태그 필드 제거, 호출 인자 축소, 노드 설명 정리 | 수정 |
| `Plugins/WxWorld/.../Gimmick/WxGimmickStateTreeComponent.h`/`.cpp` | 영역 구조체를 접고 맵 값을 프롬프트로, 세터·멀티캐스트 인자 축소 | 수정 |
| `Docs/Programmer/Gimmick_State_Authority.md`, `Plugins/WxWorld/README.md` | 발동 이벤트 축 서술 제거 | 수정 |

### 접근 방식

- **필드를 지우면 그것을 나르던 경로가 통째로 상수가 된다**: 영역별 태그 조회 분기가 사라져 발행 태그가 언제나 공용 태그이고, 그러면 멀티캐스트의 태그 인자도 상수라 의미를 잃는다. 세 군데가 함께 접힌다.

- **한 필드만 남는 영역 구조체를 없앤다**: 맵을 `TMap<메시, FText>` 로 바꾼다. 멤버 이름은 유지한다 — 멤버십이 곧 "그 영역이 켜져 있다"는 의미라 이름이 여전히 정확하고, 활성 판정이 멤버십만 읽는 구조도 그대로다.

## 완료

### 수정한 파일

| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Gimmick/WxGimmickStateTreeNodes.h`/`.cpp` | 인스턴스 데이터의 태그 필드 제거, 세터 호출 인자 축소, 노드 개요·doc 정리, 쓰이지 않게 된 태그 헤더 include 제거 | 수정 |
| `Plugins/WxWorld/.../Gimmick/WxGimmickStateTreeComponent.h`/`.cpp` | 영역 구조체 삭제 후 맵 값을 프롬프트로, 세터·멀티캐스트 인자 축소, 발행 태그를 공용 태그로 고정 | 수정 |
| `Docs/Programmer/Gimmick_State_Authority.md` | 규칙 2 에서 발동 이벤트 축 제거, 발행 태그가 하나임을 명시 | 수정 |
| `Plugins/WxWorld/README.md` | 새 기믹 추가 절차에서 발동 이벤트 제거, Source 비교 안내 추가 | 수정 |

### 구현·결정과 그 이유

- **세 군데가 함께 접혔다**: 필드가 사라지자 영역별 태그 조회 분기가 없어져 발행 태그가 상수가 되고, 그 태그를 나르던 멀티캐스트 인자도 의미를 잃었다. 계획대로 한 번에 걷었다. 인자에 달려 있던 "피어마다 영역 설정이 어긋나도 같은 이벤트가 뜬다"는 근거도 함께 사라져 주석을 지웠다.

- **한 필드만 남은 영역 구조체를 없앴다**: 맵을 메시→프롬프트로 바꿨다. 멤버 이름은 그대로 뒀다 — 멤버십이 곧 활성 상태라는 의미가 값의 타입과 무관하게 유지되고, 활성 판정이 멤버십만 읽는 구조도 그대로다.

- **검증**: WxEditor 빌드 성공(include 제거 후 재빌드 포함).

### 계획 대비 달라진 점

- **태그 헤더 include 를 하나 더 걷었다**: 필드를 지우고 나니 노드 헤더에서 `GameplayTagContainer.h` 를 쓰는 선언이 남지 않았다. 제거 후 재빌드로 확인했다.

### 후속 과제

- **PIE 실동작 확인 미완**: 엘리베이터(영역 3개)와 문·상자·체크포인트(영역 1개)에서 프롬프트 표시와 전이가 그대로인지 확인이 남았다.
