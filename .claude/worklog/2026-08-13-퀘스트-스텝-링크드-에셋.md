# 퀘스트 스텝을 Linked Asset 으로 재사용화

## 계획

### 목표
ST_Quest_Main1 안에 리터럴로 저작된 Step1~3(대화·이동·처치)을 독립 StateTree 에셋으로 추출해 다른 퀘스트에서 재활용할 수 있게 한다. 데이터(대상 액터·대사 행·목표 문구 등)만 루트 파라미터로 노출하고, 퀘스트는 LinkedAsset 상태로 스텝을 링크해 파라미터 오버라이드로 값을 지정한다.

### 접근 방식
- **왜 새 툴셋인가**: 링크드 에셋 파라미터화에 필요한 편집 지점(루트 파라미터 백 정의, EditorBindings, 링크 상태 오버라이드, 컴파일)이 전부 편집 플래그 없는 UPROPERTY 또는 에디터 전용 API 라 기존 MCP 도구로 접근 불가. 엔진 C++ API(SetLinkedStateAsset·AddPropertyBinding·CompileStateTree·UStateTreeFactory)는 공개돼 있으므로, ToolsetRegistry 의 UToolsetDefinition 등록 방식(정적 UFUNCTION + AICallable 메타)으로 프로젝트 툴셋을 만들어 뚫는다. 엔진 툴셋 플러그인(GameplayTagsToolset 등)과 같은 구조의 독립 에디터 플러그인으로 둔다 — 게임 코드와 분리되고 패키징에서 자연 제외된다.
- **스텝 에셋 구조**: 일반 UStateTree + StateTreeComponentSchema(퀘스트 마커 타입이 아니므로 ActivateQuest 픽커를 오염시키지 않음). 루트 상태 1개(TasksCompletion=All, 전이 없음) — 대기 태스크 완료 시 서브트리 Succeeded 가 링크 상태 완료로 전파되어 부모 퀘스트의 OnStateCompleted 전이가 그대로 동작한다.
- **파라미터**: Talk=Objective(Text)·Npcs(UOL 배열)·DialogueRow(RowHandle), MoveTo=Objective·Targets·AcceptRadius(Float)·NpcsToLock(UOL 배열, 옵션), Kill=Objective·Spawners·SubtitleRow(옵션). UOL 유지 — ST 컴파일러가 레벨 액터 참조를 소프트 포함 거부하므로 SoftObjectPtr 대체는 불가(기존 실증), UOL 은 순수 구조체라 검증 밖이고 배열 원소 픽커도 정상.
- **퀘스트 쪽**: 상태 객체를 제자리 전환(SetLinkedStateAsset 이 태스크 리셋·파라미터 동기화·더티 마킹까지 수행)하므로 상태 ID 가 보존되어 기존 전이가 깨지지 않는다.

### 구현·결정과 그 이유
- **툴셋을 독립 에디터 플러그인으로**: 사용자 지시. 엔진 툴셋 플러그인(GameplayTagsToolset)과 동일 골격 — UToolsetDefinition 서브클래스 + AICallable 정적 UFUNCTION, 모듈 StartupModule 에서 레지스트리 등록. 게임 코드와 분리되고 EditorOnly 라 패키징에서 자연 제외.
- **루트 파라미터 백은 리플렉션으로 가변 접근**: private UPROPERTY 에 공개 API 가 const 게터뿐이라 FindFProperty 경유가 유일한 비침습 경로.
- **컴파일러 로그 파생 리더**: FStateTreeCompilerLog::Messages 가 protected 라 파생 구조체로 읽기 접근만 열었다.
- **값 기입은 FJsonObjectConverter 단일 경로**: UOL 은 ImportTextItem 을 가져 JSON 문자열 리터럴이 그대로 임포트되고, RowHandle 은 오브젝트 필드 경로 로드로 처리 — 타입별 특수 코드가 필요 없었다.
- **CompileStateTree 도구가 기존 Slate 버튼 클릭 우회를 대체**: UStateTreeEditingSubsystem::CompileStateTree 는 더티 여부와 무관하게 항상 컴파일하므로 기존 "한 번 컴파일 후 버튼 무효" 함정이 사라진다.

### 검증
- WxEditor(Development) 빌드 성공. 에디터 재기동 후 신규 툴셋 MCP 노출 확인.
- 스텝 3종·Main1 전부 CompileStateTree "succeeded", 저장 후 재조회로 링크·오버라이드·바인딩(14건) 잔존 확인.
- PIE 실측: 볼륨 진입 → 퀘스트 활성 → Start → **링크드 에셋 ST_QuestStep_Talk 선택·서브트리 Root 진입·태스크 4종 EnterState** (LogStateTree), HUD 저널에 오버라이드 문구("모험의 시작"/"NPC와 대화하기") 표시·NPC 인디케이터 표시(스크린샷) — 파라미터 전파 확정.

### 계획 대비 달라진 점
- 툴셋 위치가 WxEditor 모듈 → 독립 플러그인 WxStateTreeToolset 으로 변경(사용자 지시).
- RemoveBinding 도구 1종 추가(오바인딩 복구용).

### 후속 과제
- 대화 완료→Step2(이동 판정)→Step3(처치)→Success 의 풀 플로우는 수동 플레이 검증 필요(사용자 진행 예정). LogStateTree 가 Verbose 로 켜져 있어 전이 추적 가능(에디터 재시작 시 원복).
- 링크 상태 파라미터의 에디터 픽커 사용성(UOL 배열 원소·RowHandle 테이블 필터 부재)은 실사용에서 확인.
