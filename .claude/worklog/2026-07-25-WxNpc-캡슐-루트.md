# WxNpc 루트를 캡슐 컴포넌트로 전환

## 계획

### 목표
`AWxNpc` 를 `AWxCharacterBase`(= `ACharacter`) 와 같은 구성으로 맞춘다. 캡슐이 루트가 되어 몸통 볼륨·충돌을 담당하고, 스켈레탈 메시는 그 아래 붙은 외형이 된다. 지금은 메시가 곧 루트이고 콜리전도 꺼져 있어 플레이어가 NPC 를 그대로 통과한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/Source/WxDialogue/Public/WxNpc.h` | 캡슐 컴포넌트 프로퍼티·전방 선언 추가 | 수정 |
| `Plugins/WxDialogue/Source/WxDialogue/Private/WxNpc.cpp` | 캡슐을 루트로 생성, 메시를 캡슐 자식으로 부착·정렬 | 수정 |

### 접근 방식
- **엔진 표준 구성 이식**: 캡슐 크기·프리셋·스텝업·내비 설정은 `ACharacter` 생성자와 동일하게 맞추고, 카메라·공격 채널 응답 override 는 `AWxCharacterBase` 와 동일하게 둔다. 공격 채널은 기본 응답이 Block 이라 Pawn 프리셋 그대로면 NPC 캡슐이 무기 판정에 걸리므로 명시적으로 무시시킨다.
- **메시 정렬은 C++ 디폴트로**: 캐릭터 계열은 메시의 -90 오프셋·요 회전을 BP 에서 주지만, NPC 는 BP 마다 반복시키지 않고 C++ 생성자에서 준다. 기존 BP 에 해당 오버라이드가 없어 그대로 상속된다.
- **메시 콜리전은 그대로 꺼둠**: 상호작용 감지는 콜리전과 무관하게 계약 인터페이스가 답한 메시로 이뤄지므로, 몸통 충돌만 캡슐이 새로 맡고 감지 경로는 바뀌지 않는다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/Source/WxDialogue/Public/WxNpc.h` | 캡슐 컴포넌트 프로퍼티 추가 | 수정 |
| `Plugins/WxDialogue/Source/WxDialogue/Private/WxNpc.cpp` | 캡슐을 루트로 생성·설정, 메시를 캡슐 자식으로 부착·정렬, 배치 시 지면 정렬 플래그 | 수정 |

### 구현·결정과 그 이유
- **캡슐 설정을 캐릭터에서 그대로 가져옴**: 크기·프리셋·스텝업 금지·내비 비반영·동적 장애물은 엔진 캐릭터 기본값, 카메라 채널 무시는 우리 캐릭터 베이스의 값을 따랐다. 같은 구성이라고 했을 때 기대되는 동작이 그대로 나오게 하기 위함이다.
- **메시 정렬을 C++ 에 둠**: 캐릭터는 이 오프셋·회전을 BP 에서 주지만, NPC 는 BP 가 늘어날수록 같은 값을 반복 입력해야 한다. 기존 BP 에 오버라이드가 없어 C++ 디폴트로 옮겨도 충돌이 없다.
- **메시는 쿼리 콜리전만 켬**: 상호작용 사거리를 콜리전 형상으로 재므로 쿼리는 살려 두되, 몸통 충돌은 캡슐이 맡으니 응답은 전부 무시로 둔다. 사거리 판정은 바디에 직접 던지는 테스트라 응답을 보지 않는다.
- **배치 시 지면 정렬 플래그를 켬**: 에디터가 드롭 위치를 잡을 때 쓰는 배치 범위는 이 플래그가 꺼져 있으면 0 으로 나와, 액터 원점(캡슐 중심)이 그대로 지면에 붙어 발이 묻힌다. 폰이 생성자에서 켜는 것과 같은 플래그이고, 루트가 콜리전 켜진 셰이프라 캡슐 절반 높이가 그대로 범위가 된다.

### 계획 대비 달라진 점
- 메시 콜리전을 완전히 끄려던 것을 쿼리 전용 + 전 채널 무시로 바꿨다. 상호작용 사거리 판정이 콜리전 형상을 쓰기 때문이다.
- 캡슐의 공격 채널 무시 override 는 넣지 않았다.
- 레벨 배치 시 발밑 정렬을 위해 배치 플래그를 추가로 켰다(요청 반영).

### 후속 과제
- 액터 원점이 발밑에서 캡슐 중심으로 바뀌었다. LV_DevCombat 에 배치된 NPC 인스턴스 1개는 좌표를 그대로 두면 지면 아래로 내려가므로 에디터에서 Z 를 올려 재배치해야 한다.
- 인게임 확인(캡슐 블록, 대화 프롬프트·진입, 무기 판정 통과)은 미검증.
