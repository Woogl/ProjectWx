# 범용 주기적 스폰 StateTree 노드 (LaserSpawn 일반화)

## 계획

### 목표
박스 통로 전용이던 `FWxStateTreeTask_LaserSpawn`을 어떤 기믹이든 재사용할 수 있는 범용 주기적 스폰 노드 `Wx Spawn Actors`로 일반화한다. 스폰 위치·회전·크기는 SpawnPoint 컴포넌트 월드 트랜스폼으로, 수명은 명시 `Lifetime` 파라미터로 받는다. 이동(`LaserAdvance`)은 이번 범위 밖(후속).

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | `FWxStateTreeTask_LaserSpawn`/InstanceData → `FWxStateTreeTask_SpawnActors`("Wx Spawn Actors") 개명·일반화(ActorClass/SpawnPoint/Interval/Lifetime + 런타임 SpawnedActors/TimeSinceLastSpawn); 모듈 doc 갱신 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmickStateTreeNodes.cpp` | 본문 재작성: 박스 -X/YZ스케일/박스길이수명 제거 → SpawnPoint 트랜스폼 스폰 + Lifetime SetLifeSpan; GetDescription 갱신 | 수정 |
| `Source/WxGame/WorldObject/WxLaserCorridor.{h,cpp}` | `CorridorBox` → `SpawnPoint`(USceneComponent) 교체, `LaserLifetime` 추가, SpawnInterval/MoveSpeed 유지 | 수정 |

`FWxStateTreeTask_LaserAdvance`는 유지(이동 일반화는 후속).

### 접근 방식
- **스폰 트랜스폼 = SpawnPoint 컴포넌트**: `SpawnActorDeferred`에 SpawnPoint 월드 트랜스폼(위치·회전·스케일)을 넘겨 박스 -X 끝 계산·YZ 스케일 맞춤을 한 번에 대체. 미설정이면 오너 트랜스폼 폴백.
- **수명 명시화**: 박스 길이/속도 산출 제거, `Lifetime`(0=무한) 직접 입력.
- **범용 골격 유지**: 권위 스폰, 진입 즉시 첫 스폰, SpawnedActors 추적·컬링, 이탈 시 잔여 파괴, 머무는 태스크. 이 목록을 LaserAdvance가 계속 바인딩.

### 구현·결정과 그 이유
- **스폰 트랜스폼 = SpawnPoint 컴포넌트**: `SpawnActorDeferred`에 SpawnPoint 월드 트랜스폼(위치·회전·스케일)을 그대로 넘겨, 박스 -X 끝 계산·YZ extent 스케일 맞춤을 한 번에 대체. 스폰체 크기는 SpawnPoint 스케일이 정한다. 미설정이면 오너 트랜스폼 폴백.
- **수명 명시화**: 박스 길이/속도 산출 제거, `Lifetime`(0=무한, 양수면 SetLifeSpan) 직접 입력. 레이저는 `LaserLifetime`을 노드에 바인딩.
- **스폰 파라미터 노출(사용자 요청)**: `FActorSpawnParameters`는 리플렉션 불가라 디자이너가 실제로 만질 수 있는 `ESpawnActorCollisionHandlingMethod`(UE5 UENUM)를 `SpawnCollisionHandlingOverride`로 노출. 기본 `AlwaysSpawn`으로 기존 동작 보존, `SpawnActorDeferred`에 그대로 전달.
- **범용 골격 유지**: 권위 스폰, 진입 즉시 첫 스폰, SpawnedActors 추적·컬링, 이탈 시 잔여 파괴, 머무는 태스크. 이 목록을 기존 LaserAdvance가 계속 바인딩해 레이저 이동은 그대로.

### 계획 대비 달라진 점
- 노드명을 승인 시점의 `Wx Spawn Actors`(복수)에서 **`Wx Spawn Actor`(단수)** 로 변경(사용자 요청). 런타임 목록 `SpawnedActors`는 누적 다수라 복수 유지.
- 계획에 없던 **`SpawnCollisionHandlingOverride` 파라미터 추가**(사용자 요청, "SpawnParams 전달").

### 후속 과제
- **에디터 수동**: ST_LaserCorridor의 옛 `Wx Laser Spawn` 노드를 `Wx Spawn Actor`로 교체·재바인딩(ActorClass / SpawnPoint←새 컴포넌트 / Interval←SpawnInterval / Lifetime←LaserLifetime). `Wx Laser Advance`(Actors←SpawnedActors)는 그대로. BP_LaserCorridor에 새 `SpawnPoint` 컴포넌트 배치·스케일(옛 CorridorBox 참조는 컴포넌트 개명으로 끊김).
- **이동 노드 일반화**: `Wx Laser Advance`의 범용화는 다음 단계로 보류.
