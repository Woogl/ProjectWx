# 상호작용 몽타주 + 대상 응시

## 계획

### 목표
`WxAbility_Interact` 활성화 시 상호작용 몽타주를 재생하고, 재생 동안 캐릭터를 대상 쪽으로 서서히 회전(응시)시킨다. 지금은 즉시 실행 후 바로 종료하는 fire-and-forget이라 상호작용에 모션이 없다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/AbilitySystem/Ability/WxAbility_Interact.h` | `InteractMontage`/`FacingInterpSpeed` 프로퍼티, 몽타주·응시 헬퍼·종료 핸들러 선언 | 수정 |
| `Source/WxGame/AbilitySystem/Ability/WxAbility_Interact.cpp` | 몽타주 있을 때 몽타주+응시 후 몽타주 종료 시 EndAbility, 없으면 종전 즉시 종료 | 수정 |

### 접근 방식
- **새 클래스 없이 기존 태스크 2개 조립**: 몽타주는 `UAbilityTask_PlayMontageAndWait`(UseItem과 동일 패턴, `GetMontagePlayRate()`), 응시는 이미 있는 `UWxAbilityTask_TurnAround`(yaw `RInterpTo`→자동 종료).
- **서버 권위 라우팅은 불변**: 로컬선택→TargetData→서버실행 흐름과 `TryInteract` 발동 시점(활성화 즉시)은 그대로. 그 위에 연출만 얹는다. 기믹 반응은 각자 StateTree가 시간에 걸쳐 애니메이트하므로 활성화 즉시 발동이어도 자연스럽다.
- **응시는 로컬 컨트롤 인스턴스에서만** 생성(`IsLocallyControlled()`): 오토노머스 프록시가 회전 권위라 서버는 복제 회전을 따른다. 몽타주는 재생 인스턴스마다(예측 클라 + 서버→시뮬 프록시) 재생.
- **종료 시점 이동**: 몽타주가 있으면 즉시 `EndAbility` 대신 몽타주 종료 델리게이트에서 종료. 몽타주가 없거나 대상이 없으면 종전대로 즉시 종료(하위 호환). InstancedPerActor라 몽타주 재생 중 재입력은 엔진이 자연 차단.

### 구현·결정과 그 이유
- **기존 태스크 조립(새 클래스 0)**: 몽타주는 `UAbilityTask_PlayMontageAndWait`, 응시는 이미 있던 `UWxAbilityTask_TurnAround`를 처음으로 사용. GAS 클래스 증식을 피함.
- **응시는 로컬 컨트롤 인스턴스에서만**: 회전 권위가 오토노머스 프록시라 서버가 같이 돌리면 복제 회전과 충돌. 서버·시뮬은 복제 회전을 따르게 두고, 몽타주만 재생 인스턴스마다 재생해 시뮬 프록시로 복제.
- **종료 시점 이동 + 하위 호환**: 몽타주가 있으면 즉시 종료 대신 몽타주 종료 델리게이트에서 EndAbility. `PlayInteractMontage`가 재생 여부를 bool로 돌려주어, 몽타주/대상이 없으면 호출자가 종전대로 즉시 종료. 서버 권위 라우팅(TargetData 흐름)과 발동 시점은 불변.
- **발동은 활성화 즉시(승인)**: 문·상자 등 기믹 반응이 각자 StateTree로 시간에 걸쳐 애니메이트되므로 캐릭터 몽타주와 동시 시작이 자연스러움. 노티파이 라우팅을 안 늘려 서버 권위 로직에 손대지 않음.

### 계획 대비 달라진 점
- 헬퍼 이름 `TryPlayInteractMontage` → `PlayInteractMontage` (사용자 요청으로 `Try` 제거). 그 외 계획대로.

### 후속 과제
- 몽타주 애셋은 BP CDO의 `InteractMontage`에 지정해야 동작(코드 하드참조 없음).
- (선택) "손이 닿는 순간" 반응을 원하면 몽타주 노티파이 시점 발동으로 리파인 — 현재 보류.
