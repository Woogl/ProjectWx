# 억제 해제 재획득을 Sight 로 한정해 리시 오실레이션 끊기

## 계획

### 목표
리시 복귀가 도착 즉시 스스로 무효화되어 무한 재추격에 빠진다. 억제 해제 시 재획득 판정을 Sight 로 한정해 시야 밖 대상을 다시 집지 않게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Private/WxAIPerceptionComponent.cpp` | 생성자에 Hearing·Damage `SetMaxAge`, 재획득 루프를 Sight 한정 + 최근접 선택으로 교체 | 수정 |
| `Plugins/WxAI/Source/WxAI/Public/WxAIPerceptionComponent.h` | `SetTargetingSuppressed` 주석에 Sight 기준 명시 | 수정 |

### 접근 방식
- **결함**: 재획득 루프가 `HasAnyCurrentStimulus()` 로 판정하는데 이는 모든 센스 슬롯을 훑는다. Hearing·Damage 는 `MaxAge` 미지정이라 `GetMaxAge()` 가 `NeverHappenedAge`(FLT_MAX)를 돌려줘 자극이 영원히 만료되지 않고, Sight 와 달리 해제 이벤트도 없다. 그래서 한 번 싸운 상대는 영구히 "감지 중" 으로 남아 복귀 직후 다시 잡히고, 리시 이탈 → 복귀 → 재획득이 무한 반복된다.
- **Sight 한정**: 이 루프의 존재 이유가 "Sight 는 감지 여부가 바뀔 때만 방송한다" 이므로, `HasActiveStimulus(Target, SightID)` 로 좁히면 원인과 의도가 맞는다. Sight 는 시야 상실 시 엔진이 `SensingFailed` 를 방송해 성공 플래그를 내리므로 이 판정이 곧 "지금 보이는가" 다.
- **최근접 선택**: TMap 순회의 "첫 항목" 의존을 없애기 위해 보이는 적 중 가장 가까운 쪽으로 확정한다.
- **부차**: Hearing·Damage 에 유한 `MaxAge` 를 준다. Sight 한정만으로 이번 결함은 막히지만, 무한히 "현재" 로 남는 자극은 저장소를 계속 키우고 이후 저장 데이터를 읽는 코드가 같은 함정을 밟는다. Sight 는 명시적 상실 이벤트가 있어 만료에 기대지 않는 것이 맞으므로 그대로 둔다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Private/WxAIPerceptionComponent.cpp` | 생성자에 Hearing·Damage `SetMaxAge(5.0f)`, 재획득 루프를 `HasActiveStimulus(Target, SightID)` + 최근접 선택으로 교체, `AISense_Sight.h` include | 수정 |
| `Plugins/WxAI/Source/WxAI/Public/WxAIPerceptionComponent.h` | `SetTargetingSuppressed` 주석에 Sight 기준·최근접 선택과 청각·촉각 제외 사유 명시 | 수정 |

### 구현·결정과 그 이유
- **`HasAnyCurrentStimulus` 대신 `HasActiveStimulus(Target, SightID)`**: 전자는 모든 센스 슬롯을 훑어 만료되지 않는 청각·촉각 자극까지 "감지 중" 으로 친다. 후자는 슬롯 유효성·성공 여부·만료를 한 번에 확인해 주는 엔진 API라, Sight 의 `SensingFailed` 방송과 맞물려 그대로 "지금 보이는가" 가 된다.
- **Sight 의 MaxAge 는 건드리지 않았다**: 시야는 명시적 상실 이벤트가 있어 만료 시간에 기댈 이유가 없다. 오래 보고 있어도 `MaxActiveAge[SightID]` 가 FLT_MAX 라 판정이 막히지 않는 것도 확인했다.
- **최근접 선택으로 바꿨다**: TMap 순회 순서는 보장되지 않아 보이는 적이 둘 이상이면 누가 뽑힐지 결정적이지 않았다. "첫 성공" 이 아니라 최솟값 선택이므로 조기 break 없이 전체를 돈다.
- **재획득 실패 시 별도 분기를 두지 않았다**: `SetTargetActor(nullptr)` 은 억제 진입 때 이미 적용돼 있어 중복 가드에 걸러진다.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- 컴파일까지만 검증했다. PIE 로 (1) 적을 때린 뒤 리시 밖으로 끌고 갔을 때 복귀 후 재추격하지 않는지, (2) 복귀 시점에 플레이어가 시야 안이면 종전대로 즉시 재획득하는지 확인 필요.
- `MaxAge` 5초는 임의값이다. 청각·촉각 자극의 저장 수명일 뿐 어그로 길이에는 영향이 없지만, 나중에 저장 데이터를 읽는 코드가 생기면 값의 의미를 다시 볼 것.
