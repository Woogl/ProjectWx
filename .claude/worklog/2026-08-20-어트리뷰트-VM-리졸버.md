# 어트리뷰트 뷰모델 리졸버 추가

## 계획

### 목표
어트리뷰트 표시 위젯이 뷰모델을 얻으려면 지금은 캐릭터 VM → 어빌리티시스템 VM → 컨버전 함수를 거쳐야 한다. 위젯에서 어트리뷰트 쌍만 지정하면 바로 뷰모델이 붙도록 리졸버를 만든다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_Attribute.h`·`.cpp` | 어트리뷰트 쌍을 인자로 받는 뷰모델 리졸버를 뷰모델과 같은 파일에 추가 | 수정 |

### 접근 방식
- **기존 리졸버와 같은 형태**: 어빌리티·플레이어 캐릭터 리졸버처럼 위젯 소유 컨트롤러의 빙의 폰에서 ASC 를 끌어와 뷰모델을 만들고, 표시 대상만 리졸버 프로퍼티로 지정한다.
- **최대치 생략 허용**: 최대치를 지정하지 않으면 현재값 어트리뷰트를 최대값으로 쓴다 — 어빌리티시스템 VM 의 어트리뷰트 VM 팩토리와 같은 규칙이다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/MVVM/WxViewModelResolver_Attribute.h`·`.cpp` | 어트리뷰트 쌍 지정 뷰모델 리졸버 | 신규 |

### 구현·결정과 그 이유
- **WxGame 에 둔다**: 폰에서 ASC 를 끌어오는 단계가 게임 타입을 보므로 다른 리졸버들과 같은 자리에 뒀다.
- **어트리뷰트가 비면 뷰모델을 만들지 않는다**: 지정하지 않은 슬롯이 빈 값을 표시하는 것보다 바인딩이 붙지 않는 편이 낫다.

### 계획 대비 달라진 점
- 계획대로

### 후속 과제
- 위젯마다 새 뷰모델을 만든다. 같은 어트리뷰트를 여러 위젯이 쓰면 구독이 겹치므로, 미뤄 둔 뷰모델 공유화에서 함께 정리한다.
