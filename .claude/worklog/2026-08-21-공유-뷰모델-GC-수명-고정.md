# 공유 뷰모델 UWxViewModel_AbilitySystem GC 수명 고정

## 계획

### 목표
`UWxViewModel_AbilitySystem` 을 붙잡는 하드 참조가 없어 GC 대상이 되는 문제를 고친다. 부모가 수거되면 다음 `GetOrCreate` 가 빈 상태로 재생성돼 살아 있는 자식 VM 을 못 찾고, 중복 자식 VM 과 함께 ASC 구독·코어 티커가 누적된다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_AbilitySystem.cpp` | 자식 VM 4개 생성 지점의 Outer 를 `ASC`/`InASC` → `this` 로 변경 | 수정 |
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_AbilitySystem.h` | `GetOrCreate` 주석에 수명 규칙 명시 | 수정 |

### 접근 방식
- **자식의 Outer 를 부모 VM 으로 바꿔 참조 사슬을 잇는다**: GC 가 이미 수집하는 `객체 → Outer` 간선을 그대로 쓴다. 새 필드·클래스·등록 인프라가 필요 없다. 사슬은 `Widget → UMVVMView::Sources → 자식 VM → Outer(부모 VM) → Outer(ASC)`.
- **부모의 Outer 는 ASC 로 유지**: `FindSharedViewModel(InASC, StaticClass())` 의 공유 키 역할을 그대로 둔다.

검증한 전제
- 엔진 `FastReferenceCollector.h:1019` 가 객체의 Outer 를 그 객체의 참조(`EMemberlessId::Outer`)로 방출한다 — 자식이 reachable 이면 Outer 체인 전체가 산다.
- `UMVVMView::Sources` 는 UPROPERTY 배열이고 그 안의 `Source` 가 `TObjectPtr<UObject>` 라 뷰가 자식을 하드로 잡는다.
- 자식 VM 은 `GetOuter()`/자기 `GetWorld()` 를 쓰지 않는다 — 월드는 항상 `CachedASC->GetWorld()` 로 얻는다.
- `FindSharedViewModel` 의 `GetObjectsWithOuter` 는 비재귀(`EGetObjectsFlags::None`)이고 클래스 정확 일치라 영향이 없다.

남는 취약점: 자식이 하나도 없는 부모는 여전히 수거될 수 있으나, 고아 자식이 없어 재생성이 무해하고 `Deinitialize` 가 구독을 정상 해제한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |

| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_AbilitySystem.cpp` | 자식 VM 4개 생성 지점(Attribute·Ability·Effect 2곳)의 Outer 를 `ASC`/`InASC` → `this` 로 변경 | 수정 |
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_AbilitySystem.h` | `GetOrCreate` 주석을 수명 규칙(Outer 인 ASC 가 수명을 쥐지 않는다) 명시로 교체 | 수정 |

### 구현·결정과 그 이유
- **자식 Outer 를 부모 VM 으로**: 부모를 살리기 위해 자식에 역참조 UPROPERTY 를 새로 넣거나 컴포넌트·서브시스템에 등록 맵을 두는 대신, GC 가 이미 수집하는 `객체 → Outer` 간선을 썼다. 새 필드·클래스·인프라가 0이고, 부모가 자식을 UPROPERTY 로 소유한다는 기존 구조와 Outer 관계가 일치한다.
- **부모 Outer 는 ASC 유지**: `FindSharedViewModel(InASC, StaticClass())` 이 ASC 를 공유 키로 쓰므로 그대로 뒀다. 자식이 부모 아래로 내려가도 이 조회는 비재귀(`EGetObjectsFlags::None`)라 영향이 없다.
- **주석은 헤더에 한 번**: 네 생성 지점에 같은 설명을 반복하지 않고, 클래스의 수명 계약이라 `GetOrCreate` 문서에 뒀다. 생성 지점에는 되돌림 방지용 한 줄만 남겼다.
