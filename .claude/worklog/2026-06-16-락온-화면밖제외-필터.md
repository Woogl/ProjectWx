# 락온 화면 밖 타겟 제외 필터

## 계획

### 목표
락온 후보에서 현재 카메라 화면(뷰포트) 밖에 있는 타겟을 제외하는 타겟팅 필터를 추가한다. 기존 후방 각도 제외(`CameraDirection`)·차폐(`LineTrace`)와 직교하는 화면 안/밖 경계 판정이다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../Public/Targeting/WxTargetingFilterTask_ScreenBounds.h` | 필터 태스크 클래스 선언 | 신규 |
| `Plugins/WxCombat/.../Private/Targeting/WxTargetingFilterTask_ScreenBounds.cpp` | `ShouldFilterTarget` 구현 | 신규 |

### 접근 방식
- **기존 필터와 동일한 골격**: `UTargetingFilterTask_BasicFilterTemplate` 상속, `ShouldFilterTarget`만 오버라이드. `Blueprintable`로 TP_LockOn 프리셋에 추가해 사용(코드 등록 불필요).
- **판정**: 소스 폰의 컨트롤러를 `APlayerController`로 캐스팅 → 타겟 위치를 화면 좌표에 투영(`ProjectWorldLocationToScreen`). 투영 실패(카메라 뒤)거나 뷰포트 영역(`GetViewportSize`)을 벗어나면 제외. 플레이어 컨트롤러가 없으면(AI) 제외하지 않음.
- **파라미터**: `ScreenEdgeMargin`(뷰포트 대비 비율 여백, 기본 0) — 가장자리에서 안쪽으로 좁힌 영역만 보임으로 인정.

### 구현·결정과 그 이유
- **화면 투영으로 판정**: 각도 기반(`CameraDirection`)은 FOV·종횡비를 반영하지 못해 화면 좌우 끝 너머도 통과시킨다. 실제 "보이는가"는 타겟을 화면 좌표로 투영해 뷰포트 경계 안인지로 판정해야 정확하다. 카메라 뒤(투영 실패)도 같은 경로로 제외된다.
- **플레이어 컨트롤러 전용, 없으면 통과**: 화면 투영은 로컬 플레이어 시점에서만 의미가 있고 락온도 플레이어 전용이다. 컨트롤러를 못 얻으면 기존 필터들의 안전 기본값(제외 안 함)을 따라 후보를 임의로 줄이지 않는다.
- **여백을 비율로**: 해상도에 무관하게 동일한 체감을 주려고 가장자리 여백을 픽셀이 아닌 뷰포트 크기 대비 비율로 뒀다. 기본 0은 정확히 화면 경계.
