# IsHostile: 팀이 없으면 적대가 아니다

## 계획

### 목표
`UWxCombatLibrary::IsHostile`이 판단 재료가 없을 때(널, 공격자에 팀 인터페이스 없음) 적대로 여는 현행을 뒤집어 적대 아님으로 닫는다. 팀을 모르는 공격자가 아무나 때리는 것보다 아무도 못 때리는 쪽이 안전한 기본값.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../WxCombatLibrary.cpp` | 널 조기 반환 true 삭제, 팀 인터페이스 없으면 false | 수정 |
| `Plugins/WxCombat/.../WxCombatLibrary.h` | 주석 정정 | 수정 |

### 접근 방식
- **공격자 쪽만 바뀐다**: 대상 쪽은 캐릭터의 태도 판정이 팀 없는 상대에게 이미 Neutral을 돌려줘 닫혀 있었다. 남은 구멍은 공격자 널·팀 미구현뿐.
- **영향 범위**: 호출자 셋의 공격자는 전부 캐릭터라 실제로 달라지는 건 오너 없는 무기·인스티게이터 없는 투사체의 히트뿐이다. 그 경우 지금도 대미지는 안 들어가고 투사체 임팩트 연출만 나가던 것이 안 나간다.
- 타게팅 필터의 같은 열린 정책(소스에 팀 없으면 제외 안 함)은 후보 수집이라 이번 범위 밖.

---

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../WxCombatLibrary.cpp` | `IsHostile` — 양쪽 모두 팀 인터페이스가 있고 태도가 Hostile일 때만 true | 수정 |
| `Plugins/WxCombat/.../WxCombatLibrary.h` | 주석 — 어느 쪽이든 팀이 없으면(널 포함) 적대가 아니다 | 수정 |

### 구현·결정과 그 이유
- **닫힌 기본값**: 판단 재료가 없을 때 아무나 때리는 것보다 아무도 못 때리는 쪽이 안전하다.
- **대상 쪽도 라이브러리에서 직접 닫음**: 지금까지는 캐릭터의 태도 구현이 팀 없는 상대에게 Neutral을 돌려줘 우연히 닫혀 있었다. 다른 팀 구현체가 소스로 들어와도 같은 규칙이 되도록 인터페이스 유무를 여기서 본다.
- 널 검사는 `Cast<>`가 널에 널을 돌려주는 성질로 인터페이스 검사에 합쳤다.

### 계획 대비 달라진 점
- 계획은 공격자 쪽만 닫는 것이었으나, 구현 중 사용자 지시로 대상 쪽도 함께 닫았다. 실제 동작 차이는 없다(캐릭터 구현이 이미 Neutral).

### 후속 과제
- PIE 미검증: 플레이어↔적 타격이 그대로 들어가는지(둘 다 팀 있음이라 변화 없어야 함).
- 타게팅 필터의 같은 열린 정책(소스에 팀 없으면 제외 안 함)은 별건.
