# 쿨다운 오버라이드 널 가드 일관성 수정

## 계획

### 목표
`UWxAbilityBase`의 쿨다운 오버라이드 4개 중 `CheckCooldown`만 `ActorInfo`를 무조건 역참조하고, 공용 경로 `QueryActiveCooldowns`는 월드를 널 검사 없이 역참조한다. 두 지점을 형제 오버라이드·엔진 순정과 같은 방어 형태로 맞춘다. (`module_review_WxCombat.md` 이슈 9)

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AbilitySystem/Ability/WxAbilityBase.cpp` | `CheckCooldown`의 ASC 조회를 삼항 가드로, `QueryActiveCooldowns`의 월드 조회를 지역 변수 + 조기 반환으로 | 수정 |

### 접근 방식
- **`CheckCooldown`**: `ActorInfo ? ActorInfo->AbilitySystemComponent.Get() : nullptr` 로 바꾼다. 뒤따르는 `if (!ASC) return true;` 가 널 `ActorInfo`까지 흡수하므로 분기를 늘리지 않는다. 엔진 순정 `UGameplayAbility::CheckCooldown` 도 널 `ActorInfo` 에 `true` 를 돌려주므로 의미론이 일치한다.
- **`QueryActiveCooldowns`**: 월드를 지역 변수로 받아 널이면 `return 0`. 진입부에서 out 파라미터를 이미 0으로 초기화하므로 출력 계약이 유지되고, 반환 0("도는 쿨다운 없음")은 네 호출부 모두에서 관대한 폴백으로 수렴한다.

### 구현·결정과 그 이유
- **널 `ActorInfo`를 `true`로 흡수**: 기존 `if (!ASC) return true;` 분기가 그대로 받아 주므로 분기를 늘리지 않았다. 엔진 순정 `UGameplayAbility::CheckCooldown`도 널 `ActorInfo`에 `true`를 돌려주므로(UE 5.8 `GameplayAbility.cpp:1066`) 의미론이 어긋나지 않는다.
- **월드 널은 `return 0`**: 진입부에서 out 파라미터를 이미 0으로 초기화하므로 출력 계약이 지켜지고, 반환 0("도는 쿨다운 없음")이 네 호출부 모두에서 같은 관대한 폴백으로 수렴한다. 월드 조회를 함수 맨 앞으로 올려 가드가 CDO 조회보다 먼저 서게 했다.
