# EXP 시작 아이템 필드 제거

## 계획

### 목표

시작 아이템 필드가 Experience 정의(EXP)와 액션셋(WAS) 양쪽에 있어 어디에 적을지 혼란을 준다. 실사용은 `WAS_StartingItems` 한 곳이고 EXP 쪽은 비어 있으므로, EXP 쪽 필드를 제거해 시작 아이템의 출처를 액션셋 하나로 만든다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Framework/WxExperienceDefinition.h` | `DefaultInventoryItems` 필드와 전용 include 제거 | 수정 |
| `Source/WxGame/Framework/WxGameMode.h/.cpp` | 지급 목록을 액션셋 합산만으로, 주석 갱신 | 수정 |
| `Source/WxGame/Framework/WxExperienceActionSet.h` | 합산 주석에서 본체 언급 제거 | 수정 |
| `Source/WxGame/README.md` | 시작 아이템 규약 문구를 액션셋 기준으로 | 수정 |

### 접근 방식

- **단순 제거**: `EXP_Combat` 에셋에 이 필드의 직렬화 데이터가 없음을 덤프로 확인했으므로(실데이터는 `WAS_StartingItems`) 에셋 무변경·데이터 유실 없음. 유일한 코드 소비처인 GameMode 의 지급 합산에서 본체 항을 빼면 끝난다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Framework/WxExperienceDefinition.h` | `DefaultInventoryItems` 필드와 전용 include 제거 | 수정 |
| `Source/WxGame/Framework/WxGameMode.h/.cpp` | 지급 합산에서 본체 항 제거(액션셋만), 주석 갱신 | 수정 |
| `Source/WxGame/Framework/WxExperienceActionSet.h` | 합산 주석에서 본체 언급 제거 | 수정 |
| `Source/WxGame/README.md` | 시작 아이템 규약을 액션셋 기준으로, 액션 표기 현행화 | 수정 |

### 구현·결정과 그 이유
- **에셋 무변경 제거**: EXP 에셋에 이 필드의 직렬화 데이터가 없음을 사전 덤프로 확인했고, 실데이터는 전부 `WAS_StartingItems`에 있어 코드 제거만으로 끝났다. 지급 경로는 액션셋 합산 루프가 그대로라 동작 변화가 없다.

### 계획 대비 달라진 점
- 계획대로. 같은 시간대에 사용자가 폰 지정 방식을 PawnData→폰 클래스 직접 지정으로 병행 수정 중이어서, 해당 파일들은 충돌 없이 각자 영역만 편집했다.

### 후속 과제
- PIE 시작 지급(DA_Potion) 확인은 다음 에디터 재시작 후 — 현재 떠 있는 에디터는 변경 전 바이너리다.
