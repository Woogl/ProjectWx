# 공격 텔레그래프: 전용 노티파이 → 엔진 순정, User.Duration 결합 제거

## 계획

### 목표
텔레그래프 트리거를 엔진 순정 "GameplayCue (Looping)"(`UAnimNotify_GameplayCueState`)로 옮기면서, 큐가 `Parameters.RawMagnitude`를 NS `User.Duration`에 주입하던 결합을 없앤다. 순정 노티파이는 `RawMagnitude`를 채우지 않아(기본 0.0) NS가 `User.Duration=0`으로 재생돼 안 보이는 문제를 해소한다. 재생 길이는 NS 자체 저작값(루프/고정)에 맡긴다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxCombat/.../Cue/WxCueNotify_AttackTelegraph.cpp` | `OnActive`에서 `User.Duration` 주입 제거, NS를 auto-activate로 스폰(비활성 스폰→SetVariableFloat→Activate 3단계를 1단계로) | 수정 |
| `WxCombat/.../Cue/WxCueNotify_AttackTelegraph.h` | 클래스 doc 주석을 순정 노티파이·NS 자체 길이 기준으로 갱신 | 수정 |
| `WxCombat/.../AnimNotify/WxAnimNotifyState_AttackTelegraph.h` `.cpp` | 전용 노티파이 클래스 삭제(순정 `UAnimNotify_GameplayCueState`로 완전 대체, 코드 참조 없음) | 삭제 |

### 접근 방식
- **RawMagnitude 결합 제거**: 순정 노티파이는 `Instigator`/`AbilityLevel`/`TargetAttachComponent`만 세팅하고 `RawMagnitude`는 0.0 그대로 넘긴다. 큐가 이를 `User.Duration`에 넣으면 NS가 0초로 붕괴한다. 주입을 빼고 NS 자체 길이로 재생.
- **커스텀 노티파이와도 호환**: 큐가 `RawMagnitude`를 무시하므로, 아직 순정으로 안 바꾼 `AM_Pattern`이 남아 있어도(커스텀 노티파이가 여전히 발행) 동일하게 동작한다. 그래서 노티파이 클래스 삭제는 이 변경과 분리해 뒤로 미룬다(지금 지우면 미전환 패턴의 노티파이 참조가 끊김).

### 구현·결정과 그 이유
- **순정 노티파이의 RawMagnitude 미세팅**: 순정 `UAnimNotify_GameplayCueState`는 `Instigator`/`AbilityLevel`/`TargetAttachComponent`만 채우고 `RawMagnitude`는 기본 0.0으로 넘긴다. 큐가 이를 `User.Duration`에 주입하던 탓에 NS가 0초로 붕괴해 안 보였다. 주입을 없애고 재생 길이를 NS 자체 저작값에 맡겨 해결.
- **커스텀 노티파이 완전 삭제**: 큐가 더는 `RawMagnitude`를 안 읽어 순정으로 100% 대체 가능하고, 코드 참조가 없어 안전하게 제거. 신규 GAS 클래스 최소화 방향과도 일치.
- **비복제 로컬 발행**: 순정은 `AddGameplayCue_NonReplicated`로 각 머신에서 로컬 발행하고 복제 몽타주가 타이밍을 실어 나른다. 별도 권위 가드가 필요 없다.

### 계획 대비 달라진 점
- 계획에선 노티파이 클래스 삭제를 후속으로 미루려 했으나, 목표가 완전 순정 전환이라 이번에 함께 삭제.
- 최초 "안 됨"은 재빌드 전 스테일 바이너리로 플레이한 탓. 재실행(새 바이너리) 후 단일 PIE 정상 표시 확인.

### 후속 과제
- **에디터(사용자)**: `AM_Pattern_1~4` 텔레그래프 트랙을 순정 "GameplayCue (Looping)"으로 두고 `GameplayCue` 태그를 색상(`GameplayCue.AttackTelegraph.*`)에 맞게 지정. `NS_AttackTelegraph_*`가 `User.Duration` 없이 자체 길이로 보이도록 확인.
- **검증**: 네트워크 PIE 복제 일치(현재 단일 PIE 표시만 확인).
