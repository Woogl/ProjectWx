# 메타휴먼 조립 관례 보강

## 계획

### 목표
UWxMetaHumanVisualComponent의 NewObject 런타임 조립을 안정성 검토한 결과, 패턴 자체는 엔진 표준(UCameraComponent::OnRegister의 프록시 컴포넌트 생성과 동일 구조)임을 UE 5.8 소스 대조로 확인했다. 구조는 유지하고, 엔진 관례와 어긋나는 두 지점만 맞춘다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/WxMetaHumanVisualComponent.cpp` | OnRegister에 커맨드릿 가드 추가, 동적 생성 부착물 5종에 CreationMethod 전파 | 수정 |

### 접근 방식
- **커맨드릿 가드**: Super::OnRegister 직후 커맨드릿이면 조립을 건너뛴다. 카메라 프록시와 같은 취지로, 에셋 덤프 커맨드릿 등에서 그룸·스켈메시 조립 비용과 부작용을 차단한다.
- **CreationMethod 전파**: NewObject 직후·등록 전에 이 컴포넌트의 CreationMethod를 부착물(페이스·그룸·복장·LODSync·MetaHuman)에 복사한다. 생성 주체와 같은 수명 분류로 취급돼 에디터 부기(디테일 패널 분류, 인스턴스 데이터 캐시 매칭)가 일관해진다.

### 구현·결정과 그 이유
- **구조 유지**: 검토 결과 런타임 조립 패턴 자체가 엔진 표준(카메라 프록시 컴포넌트와 동일 구조)이라, 대안 구조(Child Actor 분리, 베이스 클래스 정적 서브오브젝트, BP식 동적 추가)는 모두 기각하고 관례 정렬만 했다.
- **커맨드릿 가드 위치**: 중복 조립 가드보다 앞에 둬, 커맨드릿에선 조립 여부 판단 자체를 건너뛴다.
- **CreationMethod 전파 시점**: 등록 전에 복사해, 등록 이후의 에디터 부기가 처음부터 생성 주체와 같은 분류로 취급하게 했다.
