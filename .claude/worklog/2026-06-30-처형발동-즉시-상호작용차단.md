# 처형(앞잡/백스탭) 발동 즉시 피해자 상호작용 차단

## 계획

### 목표
피니셔(앞잡)·백스탭(뒤잡)이 발동되는 순간 피해자(적)의 처형 상호작용을 즉시 끄고, 연출이 끝나기 전(자격이 유지되는 동안)에는 다시 노출되지 않게 한다. 앞잡은 연출 내내 그로기를 유지하므로 0.15초 어포던스 타이머가 상호작용을 곧바로 되살리는 문제를 막는다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/WxEnemyCharacter.h` | 래치 멤버 `bool bFinisherTriggered = false;` 추가 | 수정 |
| `Source/WxGame/Character/WxEnemyCharacter.cpp` | `HandleFinisherInteracted`에서 발동 즉시 래치 ON + 상호작용 OFF, `UpdateFinisherAffordance`에서 래치 게이팅 및 자격 소실 시 해제 | 수정 |

### 접근 방식
- **발동 단일 지점 차단 + 래치 게이팅**: 발동 평가가 일어나는 `HandleFinisherInteracted`(권위)에서 `Event.Finisher`/`Event.Backstab` 송출 직후 래치 ON, `SetInteractionEnabled(false)`로 즉시 차단. 주기 타이머 `UpdateFinisherAffordance`는 래치가 켜져 있고 자격이 유효한 동안 상호작용을 켜지 않는다.
- **자격 흐름으로 래치 해제**: 자격(`GetEligibleFinisherEventTag().IsValid()`)이 사라질 때 래치를 해제한다. 앞잡은 연출 종료 시 DP 리셋으로 그로기 해제 → 자격 소실 → 래치 해제. 이후 다시 그로기가 되면 정상 재노출. 백스탭은 사망(`HandleDeath`가 타이머 정지)·방향 전환으로 자격 소실. 별도 상태 태그(`State.HitReact`) 의존 없이 일반 피격과의 혼동·레이스를 피한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/WxEnemyCharacter.h` | 래치 멤버 `bool bFinisherTriggered = false;` 추가 | 수정 |
| `Source/WxGame/Character/WxEnemyCharacter.cpp` | `HandleFinisherInteracted`에서 이벤트 송출 직후 래치 ON + `SetInteractionEnabled(false)`로 즉시 차단, `UpdateFinisherAffordance`에서 `bEligible && !bFinisherTriggered` 게이팅 및 자격 소실 시 래치 해제 | 수정 |

### 구현·결정과 그 이유
- **발동 지점에서 즉시 차단**: 발동 평가가 일어나는 단일 권위 지점(`HandleFinisherInteracted`)에서 이벤트 송출과 함께 상호작용을 끄므로 "발동 즉시"를 보장한다. 0.15초 타이머를 기다리지 않는다.
- **래치로 타이머 재노출 차단**: 앞잡은 연출 내내 그로기를 유지해 자격이 계속 유효하므로, 차단 한 번만으로는 타이머가 곧장 되살린다. 래치(`bFinisherTriggered`)로 자격이 유지되는 동안 재노출을 막는다.
- **자격(eligibility)으로 래치 해제**: 별도 진행-중 신호 대신 기존 단일 평가 결과로 해제 시점을 잡아, 연출 종료(그로기 해제)·사망·방향 전환을 모두 자연 흡수하고 일반 피격과의 혼동·레이스를 피한다.
