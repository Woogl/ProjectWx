# 적 사망 시 State.InCombat 해제 (BGM 잔존 수정)

## 계획

### 목표
적 사망 후에도 `State.InCombat` 이 시체 ASC 에 잔존해, 그 태그를 감시하는 `BGMSourceComponent` 가 등록을 유지 → 보스 BGM 이 시체 위에서 계속 재생되는 문제를 고친다.

### 원인
사망 시 `WxAbility_Death` 가 `Brain->StopLogic` 으로 BT 는 멈추지만, 인식의 리시 폴(`UWxAIPerceptionComponent::BeginPlay` 의 1초 월드 타이머)은 BrainComponent 와 무관하게 계속 돈다. 사망 경로 어디도 `State.InCombat` 을 끄거나 타겟을 비우지 않아, 폴이 죽은 폰을 계속 인식(`SetRecognized(true)`)하거나 태그가 그냥 잔존한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxAI/Private/WxAIPerceptionComponent.cpp` | `UpdateRecognition` 에 사망 가드 추가: 폰 ASC 에 `State.Dead` 있으면 `SetRecognized(false)` 후 return | 수정 |

### 접근 방식
- **인식 판정 단일 지점에 사망 가드**: `UpdateRecognition` 이 target/leash 판정 앞에서 `State.Dead` 를 검사해, 죽었으면 `SetRecognized(false)`(= 내부에서 `RemoveMinimalReplicationGameplayTag(State.InCombat)`) 후 즉시 return. 한 번의 변경이 **태그 끄기 + 재부여 차단**을 모두 처리한다(별도 즉시-제거 불필요).
- **BB 는 건드리지 않음**: 타겟을 비우면 (StopLogic 전 타이밍 등에서) 복귀(MoveTo Home) 로 떨어질 여지가 있어, 전투 태그만 끈다.
- **서버 권위·복제**: 리시 폴은 서버(컨트롤러)에서 돌고, `RemoveMinimalReplicationGameplayTag` 이 클라로 복제 → 각 클라 `BGMSourceComponent` 가 unregister → 베이스라인 폴백.
- **의존성**: `WxAI→WxCore`(`WxGameplayTags::State_Dead`), ASC 헬퍼 모두 이미 파일에서 사용 중 — 신규 include 없음.
- **지연**: 폴 주기 1초라 사망~해제 최대 ≤1초, BGM 페이드(≈2초)가 흡수.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `WxAI/Private/WxAIPerceptionComponent.cpp` | `UpdateRecognition` 상단(BB null 체크 직후, target/leash 판정 앞)에 사망 가드: 폰 ASC 에 `State.Dead` 있으면 `SetRecognized(false)` 후 return | 수정 |

### 구현·결정과 그 이유
- **가드 하나로 끄기+재부여 차단 동시 해결**: `SetRecognized(false)` 가 곧 `RemoveMinimalReplicationGameplayTag(State.InCombat)` 이고, 가드가 재부여 경로(`SetRecognized(true)`)보다 앞에서 return 하므로 별도 즉시-제거 코드가 불필요.
- **BB null 체크 뒤에 배치해도 안전**: `State.InCombat` 은 `SetRecognized` 로만 켜지는데 그 경로들은 모두 BB 유효를 전제로 한다. 즉 태그가 켜진 상황이면 BB 는 항상 유효 → BB 체크 뒤 배치로도 사망 시 반드시 가드에 도달. StopLogic 은 BB 를 파괴하지 않아 시체 구간에도 BB 유효.
- **BB/타겟 미변경**: 타겟을 비우면 복귀(MoveTo Home) 로 떨어질 여지가 있어 전투 태그만 끈다.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- 인게임 미검증(컴파일만): 보스 사망 시 ≤1초 내 `State.InCombat` 해제 → BGM 폴백 확인 필요.
- 즉시성(≤1초 지연 제거)이 필요하면 인식 컴포넌트가 폰 `State.Dead` 를 구독해 바로 반응하게 확장 가능(현재는 폴로 충분).
