# 액션 위젯 디자인타임 아이콘 override 제거

## 계획

### 목표
`UWxActionWidget::GetIcon()` 은 디자인 타임에 프로젝트의 모든 `UInputMappingContext` 를 애셋 레지스트리로 열거해 하나씩 동기 로드한다(캐시 없음, 재드로우마다 반복). 캐시로 최적화하는 대신 엔진(CommonUI)이 디자인 타임에 `DesignTimeKey` 만 읽는 원래 방식으로 되돌린다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxActionWidget.cpp` | `GetIcon()` override 삭제 — 남는 내용이 없어 파일째 제거 | 삭제 |
| `Plugins/WxUI/Source/WxUI/Public/Widget/WxActionWidget.h` | `GetIcon()` 선언 삭제, 클래스 주석 갱신 | 수정 |
| `Plugins/WxUI/Source/WxUI/WxUI.Build.cs` | override 전용이던 `bBuildEditor` 블록(`AssetRegistry`·`EnhancedInput`) 삭제 | 수정 |

### 접근 방식
- **override 제거, 클래스 유지**: `WBP_Button`(`InputActionWidget`)·`WBP_GameHUD`·`WBP_PlayerSkills` 3개 애셋이 `UWxActionWidget` 인스턴스를 물고 있어 클래스를 지우면 로드 시 위젯이 계층에서 사라진다. `UWxButtonBase`·`UWxTabButtonBase` 처럼 프로젝트 전용 확장 지점으로 남긴다.
- **디자인 타임 미리보기**: 필요하면 엔진 규약대로 위젯의 `DesignTimeKey` 를 지정한다. 런타임 아이콘 해석은 CommonUI 기본 경로 그대로라 변화 없다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxActionWidget.cpp` | `GetIcon()` override 제거로 내용이 비어 파일 삭제 | 삭제 |
| `Plugins/WxUI/Source/WxUI/Public/Widget/WxActionWidget.h` | `GetIcon()` 선언 삭제, 클래스 주석을 확장 지점 설명으로 교체 | 수정 |
| `Plugins/WxUI/Source/WxUI/WxUI.Build.cs` | `bBuildEditor` 전용 의존(`AssetRegistry`·`EnhancedInput`) 블록 삭제 | 수정 |

### 구현·결정과 그 이유
- **캐시가 아니라 제거**: 디자인 타임 아이콘 해석은 엔진이 `DesignTimeKey` 로 처리하는 영역이다. 캐시를 얹으면 무효화(애셋 등록·변경) 관리까지 떠안으면서 엔진 규약과 어긋난 경로를 계속 유지하게 된다.
- **클래스는 유지**: `WBP_Button`·`WBP_GameHUD`·`WBP_PlayerSkills` 가 `UWxActionWidget` 인스턴스를 물고 있어 클래스 삭제는 애셋 손상으로 이어진다.
- **에디터 전용 의존 정리**: `AssetRegistry`·`EnhancedInput` 을 쓰던 곳이 이 파일뿐이었다. `WxButtonBase` 의 EnhancedInput 사용은 포인터 전달뿐이라 CommonUI 전파 의존으로 충분하며, 빌드로 확인했다.
