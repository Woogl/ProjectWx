# 상호작용 강조 대상 명시 지정 (부착-부모 폴백 제거)

## 계획

### 목표
강조(외곽선) 대상을 `Cast<UMeshComponent>(GetAttachParent())` 로 암묵 추론하던 것을, 컴포넌트가 명시적으로 지정하는 `HighlightTarget` 으로 전환한다. 부착 부모가 메시가 아닐 때 조용히 강조가 사라지던 footgun 을 없애고, 현재 깨진 엘리베이터 플랫폼 강조를 고친다. 폴백은 두지 않는다(전부 명시).

### 접근 방식
- **명시 지정**: 컴포넌트에 `HighlightTarget`(EditAnywhere) + 공개 `SetHighlightTarget(UMeshComponent*)`. `SetHighlightEnabled` 는 `HighlightTarget` 만 강조하고, 미지정이면 노옵(폴백 없음).
- **C++ 소비자 전부 명시**: 각 액터 생성자에서 인터랙션 컴포넌트 생성·부착 직후 강조 메시를 명시 지정한다. 엘리베이터 플랫폼은 부착 부모(PlatformRoot, SceneComponent)가 메시가 아니라 기존엔 강조가 누락됐는데, PlatformMesh 를 명시해 함께 고친다.
- **픽업은 BP에서**: `AWxItemPickup` 은 `WxInventory` 라 `UWxInteractionComponent` 를 C++ 로도 인터페이스로도 못 만진다. 인터페이스 확장 대신, BP 추가 컴포넌트의 `HighlightTarget`(EditAnywhere)을 BP 디테일 패널에서 직접 지정한다(.uasset 이라 코드로 불가 — 에디터 수동 단계).

### 구현·결정과 그 이유
- **명시 + 폴백 완전 제거**: `SetHighlightEnabled` 는 `HighlightTarget` 이 없으면 노옵. 부착 부모를 캐스트하던 암묵 추론을 없애 silent footgun 을 제거했다.
- **엘리베이터 플랫폼 버그 동시 수정**: `PlatformInteraction` 은 부착 부모가 `PlatformRoot`(SceneComponent)라 기존 캐스트 폴백에서 강조가 누락됐다. `PlatformMesh` 명시로 정상화.
- **픽업은 인터페이스 확장 대신 BP 지정**: `AWxItemPickup`(WxInventory)은 `UWxInteractionComponent` 를 못 만지므로, `HighlightTarget` 을 EditAnywhere 로 노출해 BP 디테일 패널에서 지정하게 했다(인터페이스 불변경).

### 후속 과제
- **에디터 수동 단계(필수)**: `BP_ItemPickup` 의 `WxInteraction` 컴포넌트에서 `HighlightTarget` 을 `MeshComponent` 로 지정해야 픽업 강조가 동작한다. 지정 전까지 픽업은 외곽선이 표시되지 않는다(프롬프트·지급은 정상).
