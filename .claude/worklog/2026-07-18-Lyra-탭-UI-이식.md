# Lyra 탭 UI 프레임워크 이식 (인벤토리 · 메인메뉴 탭 스크린)

## 계획

### 목표
인벤토리·메인메뉴를 탭 구조의 단일 스크린으로 통합하기 위해, Lyra(로컬 `Lyra57`)의 CommonUI 기반 탭 프레임워크 세 클래스를 `WxUI` 플러그인으로 그대로 풀 이식한다. 세 클래스 모두 CommonUI에만 의존해 WxCore 외 참조 금지 규칙을 지킨다.

### 접근 방식
- **그대로 풀 이식**: 동적 탭 등록/숨김 기계(`RegisterDynamicTab`·`SetTabHiddenState`·`PendingTabLabelInfoMap`)까지 Lyra와 1:1. 이식 규칙 — `Lyra*`→`Wx*`, `LYRAGAME_API`/`UE_API`→`WXUI_API`, `#define UE_API` 블록 제거, 첫 줄 저작권 헤더 교체, 주석 한국어.
- **버튼 승격**: 텍스트 렌더를 `UpdateButtonText` BP 이벤트로 위임(TextBlock BindWidget 제거). → WBP_Button에 이벤트 구현이 필수 후속(에디터 작업).
- **BP 조립(에디터)**: WBP_Button UpdateButtonText 구현, WBP_TabButton(parent WxTabButtonBase), WBP_MenuScreen(WxTabListWidgetBase 탭 바 + CommonAnimatedSwitcher 링크, Inventory/Skills 탭 등록). `.uasset`은 바이너리라 단계별 가이드로 진행.

### 구현·결정과 그 이유
- **Lyra 1:1 풀 이식**: 사용자 요청대로 동적 등록/숨김 기계(`RegisterDynamicTab`·`SetTabHiddenState`·`PendingTabLabelInfoMap`)까지 그대로. GameFeature식 런타임 탭 주입 여지를 남겨둠.
- **CommonUI 의존만**: 세 클래스 모두 엔진 CommonUI(`UCommonTabListWidgetBase`·`UCommonAnimatedSwitcher`·`UCommonLazyImage`)에만 의존 → WxCore 외 참조 금지 규칙 유지, Build.cs 무변경.
- **편의층 도입(계획 외, 사용자 결정)**: Lyra 원형은 탭 버튼 배치를 WBP의 `OnTabButtonCreation` 이벤트 그래프로, 텍스트를 `UpdateButtonText` 이벤트로 처리한다. 이벤트 그래프 글루 없이 완전 자동조립하기 위해 편의층을 추가 — `WxTabListWidgetBase`에 `BindWidgetOptional` 패널(`TabButtonContainer`, HandleTabCreation에서 자동 AddChild) + 스위처(`TabContentSwitcher`, NativeOnInitialized에서 자동 `SetLinkedSwitcher`), `WxButtonBase`에 `BindWidgetOptional TextBlock` + 기본 `UpdateButtonText`가 거기에 세팅. WBP는 이름만 맞추면 이벤트 그래프 0.
- **`UpdateButtonText`는 평범한 함수**: 편의층이 바인딩된 TextBlock을 직접 세팅하므로 BP 오버라이드가 불필요 → BlueprintNativeEvent가 아닌 평범한 C++ 함수로 반사 표면 최소화.
- **`WxTabButtonBase`↔`WxButtonBase` 분리 유지**: 탭 전용(인터페이스 계약, `FWxTabDescriptor` 의존, 아이콘)을 범용 버튼에 묻히지 않게 유지. 합치는 것도 검토했으나 분리 확정.
- **`FindByPredicate` 람다 유지**: predicate find는 그 API가 요구하는 필요한 사용으로 보고 원본 형태 보존.

### 계획 대비 달라진 점
- **편의층 추가**: 계획은 순수 Lyra 이식이었으나, 완전 자동조립을 위해 위 편의층을 도입(사용자 승낙).
- **BP 조립을 MCP로 자동 수행**: 바이너리라 불가할 것으로 봤으나, 실행 중 에디터에 unreal-mcp로 WBP를 직접 생성·배선·컴파일까지 완료.

### 완료 (BP 조립, MCP)
- `WBP_TabButton`(parent `WxTabButtonBase`): `TextBlock`(CommonTextBlock) + `LazyImage_Icon`. 컴파일 OK.
- `WBP_TabList`(parent `WxTabListWidgetBase`): `TabButtonContainer`(HorizontalBox) + `TabContentSwitcher`(CommonAnimatedSwitcher). 이름·타입 일치로 자동 바인딩. `PreregisteredTabInfoArray`에 Inventory(→WBP_Inventory, TabButtonType=WBP_TabButton) 등록.
- `WBP_MenuScreen`(사용자가 `WxActivatableWidget` 직접 파생으로 정리): `CanvasPanel_40`에 `MenuTabList`(WBP_TabList) 배치 + 화면 꽉참 앵커. 컴파일 OK.

### 후속 과제
- **Skills 탭 보류**: 사용자가 현재 인벤토리 탭만 필요. 추가 시 `WBP_PlayerSkills`(현재 plain UserWidget)를 `WxActivatableWidget`로 리페어런트해야 `TabContentType`(UCommonUserWidget)·스위처 활성 대상 충족.
- `WBP_MenuScreen`을 `UI.Layer.Menu`로 여는 입력 경로 점검(인벤토리 키 → PushContentToLayer).
- PIE 런타임 탭 전환 미검증.
