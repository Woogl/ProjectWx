# 도로 아랫면 추가와 선택 잠금 철회

## 계획

### 목표
아래에서 볼 때 도로가 사라지는 문제를 없앤다. 함께, 동작하지 않던 선택 잠금 구성을 걷어낸다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/Meshes/SM_RoadSurface.uasset` | 양면 도로 타일 | 신규 |
| `Content/LevelDesign/Meshes/SM_RoadTile.uasset` | 대체됨 | 삭제 |
| `Content/LevelDesign/PCG/PCG_RoadSplineMesh.uasset` | 선택 잠금 구성 제거, 스포너 노드 재생성 | 수정 |

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Content/LevelDesign/Meshes/SM_RoadSurface.uasset` | 256×100 양면 타일 (32삼각형) | 신규 |
| `Content/LevelDesign/Meshes/SM_RoadTile.uasset` | `SM_RoadSurface`로 대체 | 삭제 |
| `Content/LevelDesign/PCG/PCG_RoadSplineMesh.uasset` | `bSelectable` 파라미터·`Add Attribute`·`Get Graph Parameter`·컴포넌트 오버라이드 제거, `Spawn Spline Mesh` 재생성 | 수정 |

### 구현·결정과 그 이유
- **아랫면은 지오메트리로 붙였다**: 윗면 쿼드를 역방향 와인딩과 반대 노멀로 복제했다. 머티리얼의 Two Sided로도 되지만 아직 머티리얼이 없어 기본 머티리얼에서 바로 보여야 했고, 아랫면 노멀이 제대로 아래를 향해 조명도 맞는다. 삼각형은 16 → 32로 늘었다.
- **선택 잠금은 애초에 동작하지 않았다**: PCG 로그에 `ObjectOverride for input 'bSelectable' does not exist or is unsupported`, `Failed to initialize override 'bSelectable'`가 찍혀 있었다. `bSelectable`이 `uint8` 비트필드라 PCG의 프로퍼티 오버라이드가 다루지 못한다. 사용자가 엔진 순정 방식으로 가기로 해 구성을 전부 걷어냈다.

### 함정: 에셋 이름을 바꾸고 같은 이름으로 다시 임포트하지 말 것
`SM_RoadTile`을 `_Old`로 옮기고 같은 이름으로 새로 임포트했더니, 이후 그래프에서 `SM_RoadTile`을 가리켜도 저장된 값이 계속 `SM_RoadTile_Old`로 돌아왔다. 에디터가 세션 내내 유지하는 이름 변경 매핑이 소프트 경로를 옛 대상으로 되돌리기 때문이다. `_Old`는 이미 지운 뒤라 참조가 풀리지 않아 스플라인 메시가 하나도 생성되지 않았다.

노드를 지우고 새로 만들어도 같은 값이 들어갔다. 결국 **충돌하지 않는 새 이름(`SM_RoadSurface`)으로 임포트**해서 벗어났다. 메시를 교체할 때는 처음부터 다른 이름으로 임포트하고 참조를 옮기는 편이 안전하다.

### 계획 대비 달라진 점
- 메시 이름이 `SM_RoadTile` → `SM_RoadSurface`로 바뀌었다. 위 함정 때문에 같은 이름을 재사용할 수 없었다.
- `Spawn Spline Mesh` 노드를 새로 만들었다(`SpawnSplineMesh_0` → `SpawnSplineMesh_1`). 원인을 좁히는 과정에서 지웠던 것이고, 설정은 동일하다.

### 후속 과제
- 저장 시 `PCG_RoadSplineMesh soft references a missing package: SM_RoadTile_Old` 검증 에러가 남아 있을 수 있다. 그래프는 정상 동작하므로 잔여 참조로 보이며, 에디터를 재시작하면 사라질 것으로 예상한다. 재시작 후 확인 필요.
- 도로가 두께 없는 한 겹이라 옆에서 보면 종잇장이다. 고가 구간을 제대로 보이게 하려면 두께 있는 슬래브 메시가 필요하다.
- 머티리얼 없음.
