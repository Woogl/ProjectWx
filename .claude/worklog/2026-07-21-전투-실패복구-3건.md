# 전투 실패복구 3건: 콤보 리셋 · 무적/패링 태그 · 그로기 무한루프

## 계획

### 목표
어빌리티가 **비정상 종료(외부 캔슬/몽타주 강제 정지)** 되는 경로에서 상태가 정리되지 않아 생기는 결함 3건을 각 `EndAbility`/타이머 실패복구로 해결한다. 정상 종료 경로는 이미 문제없고, 캔슬/실패 경로에만 failsafe가 빠져 있다.

전제(엔진 소스 확정): GAS 재발동(`bRetriggerInstancedAbility`)은 `EndAbility(..., bWasCancelled=false)`로 호출된다 (`UE_5.8 AbilitySystemComponent_Abilities.cpp:1842`). 따라서 `bWasCancelled==true`는 "진짜 외부 캔슬"만 뜻하며 재발동(콤보 진행)과 안전히 구분된다.

### 접근 방식
- **#1 콤보 리셋**: 외부 캔슬 시 `EndTask()`가 몽타주 핸들러를 끊어 `CurrentPath`/`CurrentIndex`를 되돌리지 못한다. `EndAbility`에서 `bWasCancelled`일 때만 직접 리셋. 재발동은 `false`라 콤보 진행 보존, 자연종료 핸들러는 이미 비우므로 중복 무해.
- **#7 무적/패링 태그**: `State.Invincible`(회피)·`State.PerfectGuard`(가드)는 ANS의 `NotifyBegin/End` 쌍에만 의존 → 창 도중 캔슬로 `NotifyEnd` 스킵 시 영구 잔존. 두 태그는 각 ANS만 부여하고 ExecCalc는 읽기만 하므로, 어빌리티 `EndAbility`에서 `HasMatchingGameplayTag` 가드 후 제거(기존 `State.Guard` 정리와 동일 패턴).
- **#8 그로기 무한루프**: 종료가 DrainDP→DP=0→`State.Groggy` 제거에만 의존. 드레인 무효/외부 제거 시 무한 지속. `GroggyDuration + 1s` 원샷 안전 타이머로 `WxEffect_ResetDP`(Instant, DP Override 0) 적용 → AttributeSet가 DP≤0에서 `State.Groggy` 제거 → 정상 종료. (force-EndAbility만 하면 DP가 Max로 남아 `OwnedTagPresent` 트리거가 재발동하므로 DP=0 리셋으로 불변식 유지.) `EndAbility`에서 타이머 클리어.

### 구현·결정과 그 이유
- **콤보 리셋 조건을 `bWasCancelled`로 게이팅**: GAS 재발동은 엔진이 `EndAbility(bWasCancelled=false)`로 호출(UE5.8 `AbilitySystemComponent_Abilities.cpp:1842`)하므로, `true`만 리셋하면 콤보 진행(재발동)은 보존하면서 외부 캔슬만 첫타로 되돌린다. 별도 플래그 없이 기존 시그니처만으로 안전하게 구분된다.
- **무적/패링 태그는 `HasMatchingGameplayTag` 가드 후 단일 제거**: 기존 `State.Guard` 정리와 동일 패턴 재사용. 두 태그는 각 ANS만 부여하므로 어빌리티 종료 시 잔존분은 그 어빌리티가 흘린 것 — 타 시스템 영향 없이 안전.
- **그로기 실패복구를 force-EndAbility가 아닌 `WxEffect_ResetDP`로**: 그로기 종료 불변식이 "DP≤0 → State.Groggy 제거"이므로, DP를 Max로 둔 채 종료만 하면 `OwnedTagPresent(State.Groggy)` 트리거가 즉시 재발동한다. DP=0 리셋으로 불변식을 지켜 기존 정상 종료 경로(HandleGroggyTagChanged)를 그대로 태운다.
