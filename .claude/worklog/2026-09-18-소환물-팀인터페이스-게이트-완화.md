# 소환물 팀 인터페이스 게이트 완화

## 계획

### 목표
`UWxMinionSubsystem::SpawnMinion`이 `IGenericTeamAgentInterface` 미구현 클래스를 아예 생성하지 않던 하드 게이트를 없앤다. 팀 상속은 소환물의 부가 속성이므로, 인터페이스가 없으면 팀만 못 물려받고 스폰 자체는 되게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/Minion/WxMinionSubsystem.cpp` | `UGenericTeamAgentInterface` 조기 반환 게이트 제거, 팀 주입 지점에 미구현 경고 로그 추가 | 수정 |
| `Plugins/WxCore/Source/WxCore/Public/WxMinion.h` | "함께 구현해야 한다" 문구를 실제 동작에 맞게 정정 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/AnimNotify/WxAnimNotify_SpawnMinion.h` | `MinionClass` 주석의 팀 관련 문구 정정 | 수정 |
| `Plugins/WxCore/README.md` | 새 소환물 규약 문구 정정 | 수정 |

### 접근 방식
- **게이트 제거만**: 팀 주입은 이미 `Cast<IGenericTeamAgentInterface>(Minion)` 성공 시에만 돌아간다. 앞의 조기 반환만 지우면 미구현 클래스는 팀만 비고 나머지 흐름(상한 정리·로스터 등재·`State.Minion.Active`)은 그대로 탄다. 별도 분기를 새로 만들지 않는다.
- **진단은 남긴다**: 팀을 못 물려받으면 주인과 적대 판정이 어긋나는 게 눈에 띄지 않으므로, 차단하지 않되 경고 로그 한 줄을 남긴다. `IWxMinion` 미구현 게이트는 상한 계약이 성립하지 않으므로 그대로 둔다.
- **호출부 영향 없음**: 유일한 호출부인 소환 노티파이는 반환값을 쓰지 않는다. `MustImplement` 메타는 `IWxMinion`만 걸려 있다.

### 구현·결정과 그 이유
- **분기 신설 없이 게이트만 제거**: 팀 주입은 원래부터 `Cast<IGenericTeamAgentInterface>` 성공 시에만 돌아가므로 앞단 조기 반환만 지우면 미구현 클래스는 팀만 비고 상한 정리·로스터 등재·`State.Minion.Active` 갱신은 그대로 탄다.
- **경고는 스폰 후로 이동**: 차단하지 않는 대신 진단은 남긴다. 클래스가 아니라 실제 인스턴스를 보는 자리라 BP 계층 어디서 빠졌든 같은 답을 낸다.
- **`IWxMinion` 게이트는 유지**: 상한 계약(`Execute_GetMaxCountPerMaster`)이 성립하지 않으면 로스터 관리 자체가 서지 않는다. 팀과 달리 선택적 속성이 아니다.
