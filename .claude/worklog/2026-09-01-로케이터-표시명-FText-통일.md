# 로케이터 표시명 진입점을 FText 로 통일

## 계획

### 목표

`FWxLocatorUtils` 안에서 복수형은 `FText` 를, 단수형 `GetDisplayName` 은 `FString` 을 돌려주는 탓에 모듈 밖 호출부 5곳이 예외 없이 `FText::FromString(...)` 으로 같은 래핑을 되풀이한다. 두 함수 모두 쓰임새가 StateTree 노드 설명·디테일 패널 표시라 최종 형태가 `FText` 이므로, 표시용 진입점의 반환 타입을 `FText` 하나로 맞춰 반복 변환을 없앤다. 표시 문구와 동작은 그대로다.

### 접근 방식

- **단일 진입점**: 표시용 함수의 반환 타입을 `FText` 로 통일한다. `FString::Join` 을 위한 private 헬퍼를 따로 두지 않고 목록 함수 안에서 `.ToString()` 으로 푼다 — 에디터 전용 표시 코드라 왕복 비용이 무의미하고, 선언을 늘리지 않는 쪽이 읽기 쉽다.
- **개명**: `Text` 접미사는 단수형과 반환 타입을 구분하려던 표식이라 둘 다 `FText` 가 되면 남을 이유가 없다.

### 구현·결정과 그 이유
- **헬퍼 없이 지역 변환**: 목록 함수가 Join 을 하려고 다시 문자열이 필요한 지점은 한 곳뿐이라, private 헬퍼를 새로 두는 대신 그 자리에서 문자열로 되돌렸다. 에디터 전용 표시 경로라 왕복 비용이 의미 없고, 선언을 늘리지 않는 쪽이 읽기 쉽다.
- **고정 문구는 `INVTEXT`**: unset·unresolved 는 컴파일 타임 리터럴이라 런타임 변환을 거칠 이유가 없다.
- **개명**: `Text` 접미사는 단수형이 문자열이던 시절의 구분 표식이었으므로, 둘 다 텍스트를 돌려주게 된 지금은 떼는 것이 맞다.
