# 디테일 패널에 Wx 섹션 탭 추가

## 계획

### 목표
레벨 에디터 액터 디테일의 섹션 바(General / Actor / … / All)에 `Wx` 탭을 추가해 프로젝트 고유 프로퍼티만 걸러 볼 수 있게 한다. 섹션은 필터이고 정렬은 직전 작업의 커스터마이제이션이 맡으므로 둘은 보완 관계다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxEditor/WxObjectDetails.h` | 카테고리 이름 `Wx` 를 `public static const FName WxCategoryName` 으로 노출 | 수정 |
| `Source/WxEditor/WxObjectDetails.cpp` | 네임스페이스 상수를 정적 멤버 정의로 교체 | 수정 |
| `Source/WxEditor/WxEditor.cpp` | `StartupModule` 에서 `"Object"` 에 `Wx` 섹션 생성 + `Wx` 카테고리 매핑, `ShutdownModule` 에서 제거 | 수정 |

### 접근 방식
- **`"Object"` 클래스에 섹션 등록**: `FindOrCreateSection("Object", "Wx", INVTEXT("Wx"), -1)->AddCategory("Wx")`. 섹션 조회는 부모 사슬을 거슬러 찾으므로 모든 클래스에 적용되고(엔진 `General` 섹션과 같은 방식), 같은 이름이 있으면 찾아 쓰므로 덮어쓰기 문제가 없다.
- **하위 카테고리**: `AddCategory` 는 `|` 가 든 이름을 거부한다. `Wx|…` 는 부모 `Wx` 안에 중첩되고 섹션 필터는 최상위 카테고리 단위라 `Wx` 하나면 된다.
- **탭 노출·순서**: 탭은 실제 자식이 있는 카테고리의 섹션만 만들어지므로 `Wx` 프로퍼티가 없는 오브젝트에는 생기지 않는다. 엔진 섹션은 전부 기본 `Order` 0 이라 알파벳순이므로 `-1` 로 General 바로 다음에 둔다.
- **범위 한계**: 섹션 바는 `bShowSectionSelector` 를 켠 뷰(스톡에서는 레벨 에디터 액터 디테일과 일부 특수 패널)에만 있다. 블루프린트·에셋 에디터는 카테고리 정렬만 적용된다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxEditor/WxObjectDetails.h` | `public static const FName WxCategoryName` 선언 | 수정 |
| `Source/WxEditor/WxObjectDetails.cpp` | 네임스페이스 상수를 정적 멤버 정의로 교체, 사용처 갱신 | 수정 |
| `Source/WxEditor/WxEditor.cpp` | `WxSectionName` 상수, `StartupModule` 에서 `FindOrCreateSection("Object", "Wx", INVTEXT("Wx"), -1)->AddCategory(Wx)`, `ShutdownModule` 에서 `RemoveSection` | 수정 |

### 구현·결정과 그 이유
- **카테고리 이름을 정적 멤버로 노출**: 정렬 커스터마이제이션과 섹션 매핑이 같은 이름에 의존하므로 출처를 하나로 뒀다.
- **`Order = -1`**: 엔진 섹션은 전부 기본 `Order` 0 이고 `RebuildSectionSelector` 가 General 앞·All 뒤·나머지 `Order` 순(동률이면 알파벳순)으로 배치하므로, 음수 하나로 General 바로 다음이 된다.
- **표시 텍스트는 `INVTEXT`**: 고유명사라 번역 대상이 아니고, 모듈 cpp 에 LOCTEXT 네임스페이스가 없다.

### 계획 대비 달라진 점
- 계획대로. 빌드(WxEditor Development) 에러·경고 없음. 구현 중 `replace_all` 이 정적 멤버 정의 줄까지 바꿔 한 번 깨졌으나 빌드 전 바로잡았다.

### 후속 과제
- 에디터 육안 확인: Wx 액터 선택 시 섹션 바가 `General, Wx, Actor, …, All` 인지, `Wx` 탭에서 하위 `Wx|…` 까지 함께 남는지, `Wx` 프로퍼티가 없는 엔진 액터에는 탭이 없는지.
- 블루프린트·에셋 에디터에는 섹션 바 자체가 없어 탭이 안 보이는 것이 정상.
