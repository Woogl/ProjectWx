# 뒤잡 대미지를 Raw → 표준 대미지 테이블로 전환

## 계획

### 목표
뒤잡(백스탭)이 `ApplyRawDamage`로 ATK·DEF를 우회한 고정 99999 Raw 대미지를 넣던 것을, 다른 공격과 동일한 표준 대미지 테이블(`WxDamageTableRow`) 참조 경로로 바꾼다. 즉사는 코드 고정값이 아니라 테이블 행 `CoeffATK`로 위임한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxCombat/.../WxAbility_Finisher.h` | `float BackstabDamage` 제거, `FDataTableRowHandle BackstabDamageRow`(RowType=WxDamageTableRow) 추가, `Engine/DataTable.h` 포함 | 수정 |
| `WxCombat/.../WxAbility_Finisher.cpp` | `ApplyBackstabDamage`를 RowHandle→ApplyTableRow→ApplyDamage 표준 경로로 재작성, `WxDamageTableRow.h` 포함 | 수정 |

### 접근 방식
- **무기 노티파이 패턴 재사용**: `WxAnimNotifyState_WeaponAttack::ResolveDamageInfo`와 동일하게 `BackstabDamageRow.GetRow<FWxDamageTableRow>` → `FWxDamageInfo::ApplyTableRow` → `UWxCombatLibrary::ApplyDamage(Source, Target, ...)`.
- **HitReact 중복 방지**: 표준 경로의 `WxExecCalc_Damage::ApplyHitReaction`은 GE에 `Event.HitReact.*` 태그가 있을 때만 송출. 뒤잡은 발동 시 짝 피격을 직접 송출하므로 행 `HitReactTag`를 비워 둔다(데이터).
- 앞잡(`ApplyFinisherDamage`)은 범위 밖, 그대로 둔다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `WxCombat/.../WxAbility_Finisher.h` | `float BackstabDamage` 제거 → `FDataTableRowHandle BackstabDamageRow`(RowType=WxDamageTableRow) 추가; `Engine/DataTable.h` 포함; 클래스/멤버 주석 갱신 | 수정 |
| `WxCombat/.../WxAbility_Finisher.cpp` | `ApplyBackstabDamage`를 RowHandle→ApplyTableRow→`ApplyDamage` 표준 경로로 재작성; `WxDamageTableRow.h` 포함 | 수정 |

### 구현·결정과 그 이유
- **무기 노티파이와 동일 패턴 재사용**: `ResolveDamageInfo`(WeaponAttack)처럼 `GetRow<FWxDamageTableRow>` → `FWxDamageInfo::ApplyTableRow` → `UWxCombatLibrary::ApplyDamage`. 뒤잡만 별도 Raw 경로를 쓰던 비일관을 제거하고 ATK 계수 기반 표준 대미지로 통일.
- **즉사를 데이터로 위임**: 코드 고정 99999 대신 행 `CoeffATK`로 결정. 일반 적 즉사 보장은 테이블 수치(디자이너) 영역.
- **HitReact 중복 방지**: 표준 경로의 `ApplyHitReaction`은 GE에 `Event.HitReact.*`가 있을 때만 송출. 뒤잡은 발동 시 짝 피격을 직접 송출하므로 행 `HitReactTag`를 비우도록 주석으로 안내(데이터).
- **로컬 변수명 충돌 회피**: 클래스 멤버 `DamageInfo`(앞잡)와 겹쳐 C4458(=WarningsAsErrors)이 나, 로컬을 `BackstabDamageInfo`로 명명.

### 계획 대비 달라진 점
- 계획대로(로컬 변수명만 빌드 중 충돌 해소).

### 후속 과제
- **콘텐츠 필수**: 대미지 테이블에 뒤잡 행 추가(`HitReactTag` 비움, 일반 적 즉사용 `CoeffATK`), 피니셔 어빌리티 BP의 `BackstabDamageRow`에 지정. float→RowHandle은 타입이 달라 CoreRedirect 불가, BP에서 신규 지정 필요.
- 인게임 거동(표준 대미지로 처치, 짝 피격 1회) 확인은 에디터 플레이로 후속 점검.
- 선택: 앞잡(`ApplyFinisherDamage`)도 테이블 참조로 통일.
