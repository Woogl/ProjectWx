# Wait Dialogue Completed 를 대화 중간·끝 행으로도 게이트

## 계획

### 목표

`Wait Dialogue Completed` 는 지금 세션을 연 시작 행으로만 대화의 신원을 가려, "이 대사까지 읽었는가"를 게이트로 삼을 수 없다. 판정 대상을 대화의 어느 행이든 지정할 수 있게 넓힌다. 완주의 뜻은 그대로 두어, **지정한 행을 거친 대화가 닫히면** 완주로 본다.

### 접근 방식

- **세션이 현재 노드를 행 핸들로 노출**: 세션은 이미 진행 중인 행 포인터와 테이블 강참조를 들고 있다. 행 구조체에 자기 이름이 없으므로 `EnterRow` 에서 현재 행 이름만 함께 기록하고, `GetCurrentRowHandle()` 이 테이블+현재 행 이름을 한 핸들로 조립해 돌려준다. 관찰자는 파라미터와 같은 타입 하나를 비교하면 된다.

- **시작 행 게터는 대체(추가 아님)**: 소비자가 대기 태스크 하나뿐이라 시작 행 게터의 쓰임이 사라진다. API 표면이 늘지 않는다. `CurrentStartRow` 멤버 자체는 테이블 강참조와 진입점 기록을 겸하므로 남긴다.

- **목격과 완주를 분리**: 지금은 "지정 대화가 현재가 아니게 되면 완주"라는 한 규칙이 두 뜻을 겸했지만, 중간 행에서는 "현재가 아니게 됨"이 곧 다음 대사로 넘어감이라 그대로 쓸 수 없다. 목격은 현재 행 비교로, 완주는 세션 종료(`!HasActiveDialogue()`)로 나눈다. 시작 행을 지정하면 결과가 종전과 동일해, 기존 사용법이 특수 케이스로 흡수된다.

- **`HasActiveDialogue()` 가드 유지**: 대화가 없을 때의 빈 핸들과 인자 미지정의 빈 핸들이 같아 보이는 오통과를 막는다. 미지정 시 진입 경고도 유지한다(게이트가 실패 전이로 단계를 건너뛰는 편이 더 나쁘다).

- **틱 샘플링 한계는 감수**: 시작 행은 세션 내내 고정이라 못 놓쳤지만, 중간 행은 플레이어가 다음 대사로 넘기기 전까지만 현재다. 자동 넘김이 없어 최소 수 프레임 이상 머무르므로 지금은 안전하다. 자동 진행·스킵이 생기면 세션에 방문 기록을 남기는 방식으로 옮긴다.

- **인자 이름을 `DialogueRow` 로**: 가리키는 것이 더는 진입점이 아니다. `Play Dialogue` 쪽 `StartRow` 는 실제로 대화를 여는 행이라 그대로 둔다.

- **CoreRedirect 는 쓰지 않음**: 프로퍼티 이름 변경으로 값이 유실되는 에셋은 `ST_Quest_Main1` 하나뿐이다. 일회성 이관에 영구 config 항목을 남기지 않고 재지정으로 처리한다.

### 구현·결정과 그 이유
- **신원을 현재 대사로 옮김**: 세션이 내보내던 값이 시작 행뿐이라 대화 안의 지점을 가리킬 수 없었다. 행 구조체가 자기 이름을 모르므로 진입 시 행 이름을 함께 기록하고, 테이블은 세션이 이미 붙잡고 있는 것을 써 핸들로 조립해 내보낸다. 관찰자는 파라미터와 같은 타입 하나를 비교한다.
- **시작 행 게터는 남기지 않음**: 소비자가 대기 태스크 하나뿐이라 두 게터를 병존시키면 같은 질문에 답이 둘이 된다. 세션의 `CurrentStartRow` 멤버는 테이블 강참조와 진입점 기록으로 남아 있다.
- **목격과 완주를 분리**: 종전의 "지정 대화가 현재가 아니게 되면 완주"는 시작 행에서만 성립한다 — 중간 행에서는 다음 대사로 넘어가는 순간이 곧 그 조건이라 대화 도중에 통과해 버린다. 목격은 대사 일치로, 완주는 세션 종료로 나눠 두 경우가 같은 뜻을 갖게 했다. 시작 행을 넣으면 결과는 종전과 동일하다.
- **부수 효과 — "다른 대화 시작"은 더 이상 완주가 아님**: 완주 조건이 세션 종료로 좁아졌다. 대화 중에는 `State.Dialogue` 태그가 상호작용을 막아 대화가 끊김 없이 교체되는 경로가 사실상 없으므로 실동작 차이는 없다.
- **폴링 한계를 문서화**: 시작 행은 세션 내내 고정이라 못 놓쳤지만 중간 행은 플레이어가 넘기기 전까지만 현재다. 자동 넘김이 없어 지금은 안전하며, 스킵·자동 진행이 생기면 세션에 방문 기록을 남기는 방식으로 옮긴다고 헤더에 남겼다.

### 계획 대비 달라진 점
- **`UniversalObjectLocator` 의존 제거**: 이전 변경(대상 액터 → 행 핸들)에서 `FWxActorTarget` 로케이터가 사라졌는데 모듈 의존과 README 문구만 남아 있었다. 소스 전수 확인 후 제거했고 빌드로 검증했다.
- **README 를 대기 태스크 문구 정정 이상으로 손봄**: 표에 `Play Dialogue` 가 빠져 있고 퀘스트 연동 안내가 옛 대상 지정 방식이라, 같은 stale 묶음으로 함께 고쳤다.
- **`Play Dialogue` 의 주석 한 줄 정정**: "관찰자에도 잡히지 않는다"가 행 기반 판정으로 바뀐 뒤로 사실과 달라져 바로잡았다.

### 후속 과제
- 에셋 재지정(사용자 담당): 프로퍼티 이름이 바뀌어 `ST_Quest_Main1` 의 `Wait Dialogue Completed` 노드 값이 유실된다. 대화 행을 다시 지정해야 한다(전수 확인 결과 이 에셋 하나뿐).
- PIE 실기 확인(사용자 담당): 시작 행 지정은 종전과 동일 통과, 중간 행 지정은 그 대사를 지나 대화가 끝나야 통과(대사가 뜬 순간에는 미통과), 그 대사 전에 대화가 끝나면 미통과.
