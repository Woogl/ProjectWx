# 미사용 선택 뷰모델 제거

## 계획

### 목표
공유 "현재 선택" 뷰모델은 값을 넣는 쪽도 읽는 쪽도 없다. UI 매니저가 시작할 때 만들어 글로벌 컬렉션에 등록하고 종료할 때 지우기만 하므로, 클래스와 등록 코드를 함께 걷는다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_Selection.h`·`.cpp` | 선택 뷰모델 클래스 | 삭제 |
| `Plugins/WxUI/Source/WxUI/Public/System/WxUIManagerSubsystem.h`·`.cpp` | 생성·등록·해제·게터와 MVVM 컬렉션 관련 인클루드 | 수정 |

### 접근 방식
- **양쪽 끝이 모두 비어 있음을 확인하고 지운다**: 값을 채우는 함수는 호출자가 없고 BP 노출도 없으며, 콘텐츠 어디에서도 이 컨텍스트 이름을 가져가지 않는다.

| `Plugins/WxUI/Source/WxUI/Public/System/WxUIManagerSubsystem.h`·`.cpp` | 생성·등록·해제·게터 제거, 남지 않는 MVVM 인클루드 정리 | 수정 |

### 구현·결정과 그 이유
- **등록 코드까지 함께 제거**: 뷰모델이 없어지면 글로벌 컬렉션 등록/해제와 컬렉션 의존성 선언도 쓸 데가 없다.
