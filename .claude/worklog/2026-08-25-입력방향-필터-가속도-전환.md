# InputDirection 필터가 클라이언트 입력 값을 신뢰하도록 전환

## 계획

### 목표
`UWxTargetingFilterTask_InputDirection`이 읽는 `GetLastMovementInputVector()`는 `AddMovementInput`을 실제로 부르는 머신에서만 채워져 서버에서는 항상 0이다. 같은 프리셋이 SnapToTarget 워프 판정에 쓰이므로 서버만 필터가 무력화돼 루트 모션이 갈린다. 서버가 클라이언트가 보낸 입력 값을 그대로 신뢰하도록 값 출처를 바꾼다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/Targeting/WxTargetingFilterTask_InputDirection.cpp` | 입력 방향을 CharacterMovementComponent의 `GetCurrentAcceleration()`에서 읽도록 교체 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/Targeting/WxTargetingFilterTask_InputDirection.h` | 클래스 주석을 값 출처에 맞게 정정 | 수정 |

### 접근 방식
- **엔진이 이미 실어 보내는 값 사용**: 새 RPC·복제 필드를 만들지 않는다. 소유 클라는 `ControlledCharacterMove`가 매 프레임 입력에서 `Acceleration`을 갱신하고, 서버는 `MoveAutonomous`가 ServerMove로 받은 값을 그대로 넣는다. 즉 CMC의 Acceleration이 곧 "서버가 신뢰하는 클라이언트 입력"이다.
- **방향만 사용**: 크기(MaxAcceleration 스케일 vs 시뮬 프록시의 단위 벡터)는 무시하고 정규화한다. 입력이 없으면 Acceleration도 0이라 "스틱 중립이면 아무것도 제외하지 않는다"는 기존 의미가 유지된다.
- **시뮬 프록시**: `UpdateProxyAcceleration`이 복제값(`bRepAcceleration`) 또는 속도 방향 폴백을 넣는다. 정확 일치가 필요해지면 `ACharacter::ShouldReplicateAcceleration`으로 켤 수 있으나 이번 범위 밖.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/Targeting/WxTargetingFilterTask_InputDirection.cpp` | 입력 방향 출처를 `GetLastMovementInputVector()`에서 CMC `GetCurrentAcceleration()`으로 교체, CMC 없는 폰은 필터 미적용 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/Targeting/WxTargetingFilterTask_InputDirection.h` | 값 출처와 머신 간 일치 근거를 클래스 주석에 명시 | 수정 |

### 구현·결정과 그 이유
- **클라 값을 그대로 신뢰**: 별도 RPC나 복제 필드 없이 엔진이 ServerMove로 이미 실어 보내는 값을 읽는다. 소유 클라는 `ControlledCharacterMove`가 입력에서 Acceleration을 갱신하고 서버는 `MoveAutonomous`가 받은 값을 그대로 넣으므로, 두 머신의 콘 판정이 같은 벡터에서 나온다. PvE 코옵 전제라 서버 재검증은 하지 않는 락온 대상 처리와 같은 결이다.
- **CMC 캐스트 실패 시 미적용**: 판정 근거가 없을 때 아무것도 제외하지 않는 것은 기존 `IsNearlyZero` 조기 반환과 같은 태도라, 없는 값으로 후보를 지우지 않는다.
- **크기 무시**: 소유 클라·서버는 MaxAcceleration 스케일, 시뮬 프록시는 단위 벡터라 크기가 다르지만 정규화 후 각도만 쓰므로 영향이 없다. 입력이 없으면 Acceleration도 0이라 스틱 중립 의미도 그대로다.

### 후속 과제
- 시뮬 프록시는 `UpdateProxyAcceleration`의 속도 방향 폴백을 쓰므로 소유 클라·서버와 완전히 같지는 않다. 관전 머신의 워프 연출까지 일치시켜야 하면 `ACharacter::ShouldReplicateAcceleration`(CVar `p.EnableCharacterAccelerationReplication`)을 켜는 선택지가 있다.
- 실제 리슨 서버 PIE 2인 재현 확인은 미실측 — 컴파일 검증까지만 마쳤다.
