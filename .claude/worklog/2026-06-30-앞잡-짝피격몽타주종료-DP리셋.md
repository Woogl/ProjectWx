# 앞잡 짝 피격 몽타주 종료 시 DP 0 리셋 (그로기 해제)

## 계획

### 목표
앞잡(처형) 피해자의 짝 피격 몽타주(`FinisherHitReactMontage`)가 정상 종료되는 시점에 DP를 0으로 리셋해 그로기를 해제한다. DP→`State.Groggy` 해제 캐스케이드가 `PostGameplayEffectExecute`에만 있어 직접 set으로는 안 풀리므로, 반드시 GameplayEffect로 DP=0을 적용한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxCombat/.../Effect/WxEffect_ResetDP.{h,cpp}` | instant GE, DP Override 0. `WxEffect_DrainDP` 패턴 | 신규 |
| `WxCombat/.../Ability/WxAbility_HitReact.h` | private `HandleFinisherMontageCompleted()` UFUNCTION 추가 | 수정 |
| `WxCombat/.../Ability/WxAbility_HitReact.cpp` | `PlayHitReactMontage`에서 OnCompleted를 몽타주로 로컬 분기(앞잡이면 전용 핸들러). 전용 핸들러가 ResetDP GE를 self 적용 후 EndAbility. include 추가 | 수정 |
| `WxCombat/.../Ability/WxAbility_Finisher.{h,cpp}` | DP 해제 책임 이전에 따른 스테일 주석 갱신 | 수정 |

### 접근 방식
- **GE로 DP=0**: `UWxEffect_ResetDP`(instant, Override DP=0)를 짝 피격 종료 핸들러에서 self 적용 → `PostGameplayEffectExecute`가 `State.Groggy` 제거 → `UWxAbility_Groggy`가 EndAbility로 그로기 종료(DrainDP 제거·AI 재개).
- **몽타주 식별은 로컬 분기**: 멤버 플래그 없이 `PlayHitReactMontage`의 바인딩 시점에 `Montage == FinisherHitReactMontage`로 전용 OnCompleted 핸들러를 바인딩.
- **권위**: HitReact는 ServerInitiated라 서버에서 GE 적용(그로기의 DrainDP 적용과 동일 모델).

### 구현·결정과 그 이유
- **DP=0을 GE로 적용**: DP→`State.Groggy` 해제 캐스케이드가 `PostGameplayEffectExecute`에만 있어 직접 set은 그로기를 못 푼다. instant Override GE로 적용해야 캐스케이드가 돌아 `State.Groggy` 제거→`WxAbility_Groggy` 종료(DrainDP 제거·AI 재개)까지 이어진다.
- **C++ GE 클래스 선택**: "=0"은 디자이너 튜닝값이 아니라 고정 정책이라 콘텐츠 배선·오설정 여지가 없는 자체 완결 C++ GE가 적합(사용자 결정). 기존 `WxEffect_DrainDP`/`WxEffect_Reflect`와 동일 패턴.
- **몽타주 식별은 로컬 분기**: 멤버 플래그 없이 바인딩 시점에 `Montage == FinisherHitReactMontage`로 전용 OnCompleted 핸들러만 교체. Interrupt/Cancel은 기존 핸들러 유지(끝까지 재생됐을 때만 리셋).
- **가드 생략**: 그로기 아닐 때 적용해도 무해(DP 0·태그 없으면 no-op)라 진단 가드 불필요.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- 앞잡 대미지 행에 DP Override 0 GE를 넣지 않도록 확인(이중 리셋 방지). DP 해제는 이제 짝 피격 몽타주 종료가 단독 담당.
- 에디터 플레이로 그로기 적 앞잡 → 짝 피격 종료 시 DP 0·`State.Groggy` 해제·AI 재개, 뒤잡/일반 피격엔 영향 없음 점검.
