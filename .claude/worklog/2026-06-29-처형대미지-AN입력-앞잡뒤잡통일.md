# 처형 대미지: AN이 대미지 테이블로 입력, GA는 적용만 (앞잡·뒤잡 통일)

## 계획

### 목표
처형 대미지 데이터(대미지 테이블 행)를 어빌리티(GA)가 아니라 AnimNotify가 들도록 옮긴다. 기존 무기/투사체 AN(`WxAnimNotify_SpawnProjectile`)과 동일한 방식(`DamageDataRow` + 인라인 폴백 + `ResolveDamageInfo`). 어빌리티는 확정 대상에 주어진 `FWxDamageInfo`를 적용만 하므로 앞잡·뒤잡 대미지 경로가 하나로 통일된다. 직전 "뒤잡→표준 테이블" 변경을 발전(GA의 `BackstabDamageRow` 제거, 데이터 AN으로).

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxCombat/.../AnimNotify/WxAnimNotify_FinisherDamage.{h,cpp}` | 단발 AN 신규. `DamageDataRow`+인라인 폴백+`ResolveDamageInfo`+`CanEditChange`, `GetAnimatingAbility`로 어빌리티 찾아 `ApplyExecutionDamage` 호출 | 신규 |
| `WxCombat/.../WxAbility_Finisher.h` | 대미지 데이터 멤버(`DamageInfo`/`BackstabDamageRow`)·`WaitGameplayEvent` 관련 제거, public `ApplyExecutionDamage(const FWxDamageInfo&)` 추가 | 수정 |
| `WxCombat/.../WxAbility_Finisher.cpp` | `ApplyExecutionDamage` 단일 구현, `WaitGameplayEvent`/`HandleDamageEvent`/분리 대미지 함수 제거 | 수정 |

### 접근 방식
- **AN이 대미지 테이블 입력**: `WxAnimNotify_SpawnProjectile`과 1:1 동일 패턴. 몽타주별 AN이 `DamageDataRow`로 데이터를 결정.
- **GA는 적용만**: 어빌리티는 변형 분기 없이 확정 대상(`TargetActor`)에 전달받은 `FWxDamageInfo`로 `ApplyDamage`. 앞잡/뒤잡 통일.
- **권위**: AN이 `ASC->GetAnimatingAbility()`로 서버 어빌리티 인스턴스를 찾음(ServerInitiated라 서버만 적용).

### 구현·결정과 그 이유
- **대미지 데이터를 AN으로 이동**: 기존 무기/투사체 AN(`WxAnimNotify_SpawnProjectile`)과 1:1 동일 패턴. 몽타주별 AN의 `DamageDataRow`가 수치를 결정하므로, 같은 처형 모션에 다른 대미지 행을 꽂는 게 자연스럽다.
- **GA는 적용만 → 앞잡·뒤잡 통일**: 어빌리티는 변형 분기 없이 확정 대상(`TargetActor`)에 전달받은 `FWxDamageInfo`를 적용. `ApplyFinisherDamage`/`ApplyBackstabDamage`/`HandleDamageEvent`/`DamageEventTask`가 모두 사라지고 단일 `ApplyExecutionDamage`로 통합.
- **권위**: AN이 `ASC->GetAnimatingAbility()`로 서버 어빌리티 인스턴스를 찾아 호출. ServerInitiated라 클라 발화는 캐스팅 실패로 무동작, 서버에서만 적용(기존 `WxAnimNotify_SendGameplayEvent`와 동일 모델).
- 변형(`bBackstab`)은 공격 몽타주·짝 피격 태그 선택에만 남는다(대미지와 무관).

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **콘텐츠 필수**: 대미지 테이블에 앞잡 행(`AdditionalEffects`에 DP Override 0 GE, `HitReactTag` 비움)·뒤잡 행(즉사 `CoeffATK`, `HitReactTag` 비움) 추가. 앞잡·뒤잡 공격 몽타주에 `WxAnimNotify_FinisherDamage` 배치하고 `DamageDataRow` 지정(기존 `WxAnimNotify_SendGameplayEvent` 제거). 배치 전엔 대미지 미적용.
- 교체 후 미사용 `Event.Finisher.Damage`/`Event.Backstab.Damage` 태그 정리 검토.
- 인게임 거동(앞잡 DP 0 해제·뒤잡 즉사, 짝 피격 1회) 에디터 플레이 점검.
