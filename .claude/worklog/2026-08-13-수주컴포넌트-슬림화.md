# 수주 컴포넌트 슬림화 + 죽은 퀘스트 진입점 제거

## 계획

### 목표
픽커 작업으로 퀘스트 값이 전부 에셋 오버라이드에 저장되면서 미사용이 된 수주 컴포넌트의 파라미터 주입 능력(FStateTreeReference)을 타입드 포인터로 줄이고, 호출자 0 이 된 BP 진입점 UWxQuestLibrary 와 SendQuestEvent 경로를 제거한다. "호출자 없는 방어적 선언 금지" 규칙 적용.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxQuest/.../WxQuestActivationComponent.h/.cpp` | Quest 를 FStateTreeReference → TObjectPtr<UWxQuestStateTree>(마커 타입 픽커), 포인터 오버로드 호출 | 수정 |
| `WxQuest/.../WxQuestComponent.h/.cpp` | ActivateQuest(FStateTreeReference) 오버로드·SendQuestEvent 제거, 본문을 포인터 버전으로 흡수(마커 검증 소멸) | 수정 |
| `WxQuest/.../WxQuestLibrary.h/.cpp` | 삭제 | 삭제 |
| `WxCore/.../WxGameplayTags.h` | Quest.Fail 주석의 라이브러리 경유 서술 정정(태그는 ST 전이가 참조하므로 유지) | 수정 |
| LV_DevCombat 볼륨 인스턴스 | 타입 교체로 소실되는 Quest 값 재기입 | 수정(레벨) |

### 접근 방식
- **타입드 픽커가 스키마 필터를 대체**: 프로퍼티 타입이 UWxQuestStateTree 라 픽커가 퀘스트 에셋만 나열 — 런타임 마커 검증·경고가 원천 불요가 되어 함께 제거한다.
- **호출자 조사 전수 완료**: 라이브러리·SendQuestEvent 호출자 0(코드·에셋 바이너리), RequestActivateQuest 는 체인 태스크가 사용해 유지.

### 구현·결정과 그 이유
- **타입드 픽커가 스키마 필터·런타임 검증을 동시 대체**: 프로퍼티가 퀘스트 마커 타입이라 픽커가 퀘스트 에셋만 나열하고, 잘못된 ST 가 들어올 경로가 타입 수준에서 사라져 마커 캐스트 검증·경고 로그를 지웠다.
- **SendQuestEvent 까지 제거**: 유일 경유지였던 라이브러리와 함께 호출자 0 — "호출자 없는 방어적 선언 금지" 적용. Quest.Fail 태그는 퀘스트 ST 의 On Event 전이가 참조하므로 태그·전이는 유지(휴면).
