# 선판정 열거형을 ExecCalc 헤더로 이동·개명

## 계획

### 목표
`EWxDamageResult`가 `WxCombatEffectContext.h`에 남아 있는 건 08-11에 컨텍스트가 판정 결과를 들고 있던 흔적이다. 08-20에 필드는 지웠는데 선언만 남았다. 지금은 `CheckDamage`(적용 전 선판정)의 반환값일 뿐이므로 그 함수 옆으로 옮기고, 같은 헤더의 산출값 구조체 `FWxDamageResult`와 이름이 부딪히지 않게 `EWxDamageCheck`로 개명한다. 컨텍스트에 흡수하는 안은 검토 후 기각(시점이 다르고, 값이 의미 있는 경로엔 컨텍스트가 없다).

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/.../Damage/WxCombatEffectContext.h` | 열거형 삭제 | 수정 |
| `Plugins/WxCombat/.../Effect/WxEffect_Damage.h` | 열거형을 `EWxDamageCheck`로 선언, 컨텍스트 헤더 include 제거 | 수정 |
| `Plugins/WxCombat/.../Effect/WxEffect_Damage.cpp`·`WxCombatLibrary.cpp`·`Weapon/WxProjectileBase.cpp` | 식별자 치환 | 수정 |

### 접근 방식
- **선언은 쓰는 곳 옆에**: 선판정 함수의 반환형이므로 그 함수가 선언된 헤더에 둔다. 컨텍스트 헤더는 컨텍스트 구조체만 남는다.
- **이름은 함수·호출부 변수와 한 단어로**: `CheckDamage` → `DamageCheck` → `EWxDamageCheck`. BP 노출이 없는 열거형이라 리다이렉트 불필요(에셋 참조 없음 확인).
- **세 상태 유지**: 투사체는 `Evaded`만 연출을 끊고 `None`은 연출이 나가므로 bool로 줄일 수 없다.

### 구현·결정과 그 이유
- **컨텍스트 흡수 기각**: 선판정은 GE 적용 전에 호출부가 즉시 소비하고, `None`·`Evaded`는 GE가 안 걸리는 결과라 그 경로엔 컨텍스트가 존재하지 않는다. 예측 클라에서는 ExecCalc가 안 돌아 (Source, Target)만 보는 순수 함수여야 양쪽이 같은 결론에 이른다 — 08-20에 컨텍스트의 회피 필드를 지운 이유와 같다. 컨텍스트는 여러 GE가 공유해 판정마다 지워야 하는 함정도 있어 필드를 더하는 건 역행.
- **헤더 이동**: 컨텍스트 헤더의 include 의존을 확인하니 컨텍스트 타입을 쓰는 곳은 전부 그 헤더를 직접 include하고 있어, ExecCalc 헤더에서 include를 떼도 전이 의존이 끊기지 않았다.
- **값 주석 삭제**: `CheckDamage`의 반환 설명과 중복이고, `None`의 "연출 대상이 아니다"는 컨텍스트 시절 문구라 지금은 틀리다(투사체는 `None`에도 임팩트 연출을 낸다). 반환 설명 한 곳만 남겼다.
