# 어트리뷰트 임계값 Tint 변환 함수 추가

> **정정**: 아래 실수 인자를 float 으로 둔 근거는 틀렸다. MVVM 은 float/double 실수 핀을 호환으로 판정하므로(`EdGraphSchema_K2.cpp:4502`) double 로 둬도 바인딩이 물린다. 이후 double 로 전환했다 — `2026-09-03-변환-함수-double-전환.md` 참고.

## 계획

### 목표
어트리뷰트가 특정 수치·퍼센트 이하일 때 위젯 Tint 를 바꾸는 수단을 MVVM 바인딩에 제공한다. 임계값·색은 위젯별 표현 설정이므로 VM 이 아니라 변환 함수 인자로 둔다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxMVVMConversionLibrary.h` | `Conv_FloatToTint` 선언 + `Math/Color.h` 인클루드 추가 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxMVVMConversionLibrary.cpp` | 구현 추가 | 수정 |

### 접근 방식
- **시그니처**: `static FLinearColor Conv_FloatToTint(float Value, float Threshold, FLinearColor BelowTint = FLinearColor::Red, FLinearColor NormalTint = FLinearColor::White)`. `Value <= Threshold` 면 BelowTint. (이후 `Conv_DoubleToTint(double, double, ...)` 로 전환.)
- **VM 에 임계값을 두지 않는 이유**: 어트리뷰트 조합이 같으면 VM 인스턴스를 여러 위젯이 공유한다(`WxViewModel_AbilitySystem.cpp:92`). VM 에 얹으면 같은 VM 을 보는 다른 위젯까지 끌려간다.
- **수치·퍼센트 두 기준을 한 함수로**: 소스 프로퍼티만 `AttributeAmount` / `AttributePercent` 로 바꿔 끼우면 된다. 둘 다 `FieldNotify` 라 변경 시 바인딩이 자동 재평가된다.
- **반환형 `FLinearColor`**: 대상인 `UImage::ColorAndOpacity` / `UProgressBar::FillColorAndOpacity` 가 이 타입이다. `UserWidget`·`Border` 도 같이 커버된다.
- **`Math/Color.h` 명시 인클루드**: `CoreMinimal.h` 에 `Math/Color.h` 가 없다. 지금은 `SlateWrapperTypes.h` 로 전이적으로 딸려오지만 거기 기대지 않는다.

### 함정
`AttributePercent` 는 0~1 이다(`RecalculateAttributePercent()` 가 `Amount / Max` 를 그대로 넣는다). 퍼센트 기준 임계값은 `0.3` 형태로 넣어야 한다.

### 범위에서 제외
`UTextBlock::ColorAndOpacity` 는 `FSlateColor` 라 반환형이 다른 함수가 한 벌 더 필요하다. 엔진에 `FLinearColor → FSlateColor` BP 변환 함수도 없다. 이번엔 Image/ProgressBar 만 대상이라 넣지 않는다.

| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxMVVMConversionLibrary.cpp` | 구현 추가 | 수정 |

### 구현·결정과 그 이유
- **임계값·색을 변환 함수 인자로**: VM 인스턴스가 어트리뷰트 조합 단위로 공유되므로(`WxViewModel_AbilitySystem.cpp:92`) VM 에 임계값 필드를 얹으면 같은 VM 을 보는 다른 위젯까지 영향을 받는다. 변환 함수 인자로 두면 바인딩 패널에서 위젯마다 따로 지정된다.
- **수치·퍼센트를 별도 함수로 나누지 않음**: 소스 프로퍼티를 `AttributeAmount` / `AttributePercent` 중 무엇으로 무느냐로 갈리므로 함수 하나면 충분하다.
- **`Math/Color.h` 명시 인클루드**: `CoreMinimal.h` 에 없고 지금은 `SlateWrapperTypes.h` 를 통해 전이적으로만 들어온다. 인클루드 정리로 언제든 끊길 수 있어 직접 건다.
- **UHT 구조체 기본값 인자 사용**: `KismetRenderingLibrary.h:48` 등 엔진이 같은 형태를 쓰고 있어 `FLinearColor::Red` / `::White` 기본값이 통한다. 빌드로 확인됨.

### 후속 과제
- TextBlock 에 물리려면 `FSlateColor` 반환 함수가 한 벌 더 필요하다(엔진에 `FLinearColor → FSlateColor` BP 변환 함수 없음).
- 다단계·그라데이션이 필요해지면 `UCurveLinearColor` 샘플링 변환 함수를 별도로 검토한다.
