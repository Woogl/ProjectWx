# Footstep 노티파이 게임 로직 → 캐릭터 컴포넌트 이관 (Lyra ContextEffects 참고)

## 계획

### 목표
`WxAnimNotify_Footstep`가 노티파이 내부에서 직접 하던 라인 트레이스(표면 판정)+AI 소음 보고+표면별 사운드 재생을 신규 `UWxFootstepComponent`로 이관한다. 노티파이는 컴포넌트를 찾아 위임만 하는 얇은 신호가 된다. Lyra ContextEffects(노티파이→컴포넌트→서브시스템)의 축소판.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxGame/Character/WxFootstepComponent.{h,cpp}` | `UWxFootstepComponent : UActorComponent`. `HandleFootstep(SoundSet, HearingDistance) const` = 소음 보고(서버)+표면 사운드(로컬/비데디). `UWxFootstepSoundSet` DataAsset을 이 헤더로 이동. `PlaySurfaceSound`·`GetSound` 이관 | 신규 |
| `WxGame/AnimNotify/WxAnimNotify_Footstep.{h,cpp}` | `Notify`를 컴포넌트 포워더로 교체. `SoundSet`/`HearingDistance` UPROPERTY 유지. 이관된 로직·include·TODO 마커 제거 | 수정 |
| `WxGame/Character/WxCharacterBase.{h,cpp}` | `FootstepComponent` 멤버 + 생성자 `CreateDefaultSubobject` 부착 | 수정 |

### 접근 방식
- **행동은 컴포넌트, 데이터는 노티파이**: 로직은 컴포넌트로 옮기되 디자이너 노브(`SoundSet`, `HearingDistance`)는 노티파이 UPROPERTY로 남겨 인자로 전달 → 몽타주별 오버라이드 자유도 보존.
- **모든 캐릭터 자동 부착**: `AWxCharacterBase` 생성자에서 부착(기존 컴포넌트 패턴 동일) → 세팅 부담·자유도 손실 없음.
- **행동 보존**: 트레이스 범위·소음 파라미터·데디서버 분기 그대로 이동(개선 아님).

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `WxGame/Character/WxFootstepComponent.{h,cpp}` | `UWxFootstepComponent`. `HandleFootstep(SoundSet, HearingDistance)`가 소음 보고(서버)+`PlaySurfaceSound`(트레이스+표면+재생, 로컬/비데디). `UWxFootstepSoundSet` DataAsset·`GetSound` 이 헤더로 이동 | 신규 |
| `WxGame/AnimNotify/WxAnimNotify_Footstep.{h,cpp}` | `Notify`가 `FindComponentByClass<UWxFootstepComponent>()→HandleFootstep`로 위임. `SoundSet`/`HearingDistance` UPROPERTY 유지(전방선언). DataAsset 정의·트레이스/소음/사운드 로직·관련 include·TODO 마커 제거 | 수정 |
| `WxGame/Character/WxCharacterBase.{h,cpp}` | `FootstepComponent` 멤버 + 생성자 `CreateDefaultSubobject` 부착(전방선언·include 추가) | 수정 |

### 구현·결정과 그 이유
- **행동/데이터 분리**: 트레이스·`UAISense_Hearing::ReportNoiseEvent`·`PlaySoundAtLocation` 오케스트레이션은 전부 컴포넌트로 이관해 노티파이를 순수 신호로 만들었다. 반면 `SoundSet`/`HearingDistance`는 노티파이 UPROPERTY로 남겨 인자로 전달 → 몽타주별 오버라이드 자유도 보존(Lyra가 노티파이에 이펙트 속성을 두는 것과 동일).
- **베이스 자동 부착**: 기존 ASC/MotionWarping/Equipment와 같은 `CreateDefaultSubobject` 패턴으로 `AWxCharacterBase`에 부착 → 모든 파생 캐릭터가 자동 보유, 세팅 부담·자유도 손실 0. 노티파이는 컴포넌트 미발견 시 무동작.
- **DataAsset 헤더 이동은 안전**: `UWxFootstepSoundSet`을 컴포넌트 헤더로 옮겨도 동일 모듈(WxGame)이라 클래스 경로(`/Script/WxGame.WxFootstepSoundSet`) 불변 → 기존 사운드셋 애셋·노티파이의 SoundSet 참조 유효. 의존 방향도 노티파이→컴포넌트로 정방향.
- **행동 보존**: 트레이스 범위(+50~-200)·소음 파라미터(Loudness 1, Instigator=Owner)·데디서버 오디오 제외 분기를 그대로 옮겨 거동 무변경(기능 개선 아님).
