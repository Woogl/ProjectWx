# WxSave 명시 저장 슬롯의 플레이어 위치 복원

## 계획

### 목표
명시(이름 지정) 저장 시 플레이어 폰의 정확한 위치를 캡처하고, 그 슬롯을 로드할 때 그 위치로 복원한다. 2026-07-07 「부활-체크포인트-위치-고정」이 남긴 한계("자유 위치에서 메뉴 저장해도 로드 시 체크포인트로 스폰")를 해소하되, 체크포인트 오토세이브·사망 리스폰은 지금처럼 체크포인트 PlayerStart 를 유지한다(소울류 일관성).

### 접근 방식
- **명시 저장만 위치 기억**: 캡처 게이트 = `SaveToFile` 의 `SlotName` 비어있지 않음(메뉴 저장). 오토세이브(`SaveToFile()` 무인자)는 미캡처.
- **플래그·클리어 없이 자동 리셋**: `PlayerTransform` 을 `FWxPersistenceTravelData` 안에 둔다. `FlushMapTravelData` 가 매 플러시마다 `TravelData` 를 재구성해 `PlayerTransform` 을 `Identity` 로 리셋하므로, 오토세이브는 별도 코드 없이 위치가 지워지고 명시 저장일 때만 그 뒤 `FlushPlayerTransform` 이 덮어쓴다. 유효성은 `!PlayerTransform.Equals(Identity)` 지역 파생으로 판정(멤버 플래그 없음).
- **위치만**: 컨트롤 로테이션(카메라 시선)은 저장하지 않음.
- **복원**: `SpawnDefaultPawnAtTransform` override 가 저장 위치 존재 + 맵 일치 시 그 트랜스폼으로 스폰, 아니면 인자(PlayerStart)로 `Super::` 스폰. 사망 리스폰은 오토세이브가 위치를 미기록으로 두므로 자동으로 체크포인트 폴백.

### 구현·결정과 그 이유
- **명시 저장만 위치 기억(캡처 게이트 = SlotName 비어있지 않음)**: 메뉴 저장은 `SaveToFile(슬롯명)`, 체크포인트 오토세이브는 `SaveToFile()` 무인자라 이 신호가 두 의도를 정확히 가른다. 오토세이브는 위치를 미기록으로 두어 사망 리스폰이 체크포인트로 폴백(2026-07-07 결정 유지).
- **플래그 없이 sentinel 판정**: 별도 `bHasPlayerTransform` 멤버 대신 `PlayerTransform` 을 `TravelData` 안에 두고 `!Equals(Identity)` 지역 파생으로 유효성 판정. `FlushMapTravelData` 가 매 플러시마다 `TravelData` 를 재구성해 위치를 Identity 로 리셋하므로, 오토세이브는 별도 클리어 코드 없이 자동으로 미기록이 된다(캡처 순서: MapTravelData → PlayerTransform).
- **복원은 SpawnDefaultPawnAtTransform**: 스폰 지점 대신 저장 트랜스폼으로 스폰해 충돌 처리를 정상 유지. 좌표는 맵 종속이라 저장 맵==현재 맵일 때만 적용(`ReportTravelFromSaveFileComplete` 와 동일 비교).
- **PlayerStartPIE 최우선 존중**: "여기서 플레이" 가 있으면 저장 위치로 덮지 않고 인자 그대로 스폰(ChoosePlayerStart 의 priority-0 규칙과 일치) — 개발 중 지정 위치 우선. 이 가드는 공유 헬퍼 `TryGetSavedPlayerTransform` 에 넣었다.
- **시선은 저장 없이 파생**: 컨트롤 로테이션을 별도 저장하지 않는다(사용자 지시). 대신 `FinishRestartPlayer` 가 로드 직후 카메라(컨트롤 로테이션)를 복원된 폰 회전 Yaw 로 맞춰, "카메라가 캐릭터가 바라보는 방향을 향한다" 를 폰 회전에서 파생한다.
- **공유 헬퍼**: 저장 트랜스폼 조회(sentinel·맵 게이트·PIE 가드)를 스폰 위치와 시선 복원 두 곳이 쓰므로 `TryGetSavedPlayerTransform` 로 묶어 로직 중복을 없앴다.

### 계획 대비 달라진 점
- **PlayerStartPIE 가드 추가**: 계획엔 없었으나, `SpawnDefaultPawnAtTransform` 이 PIE "여기서 플레이" 를 덮을 수 있음을 발견해 `ChoosePlayerStart` 와 동일한 최우선 가드를 추가했다.
- **카메라 시선 복원 추가**: 계획·초기 구현은 위치만 복원(시선 비복원)이었으나, 사용자 요청("로드 직후 카메라가 캐릭터가 바라보는 곳을 향하게")으로 `FinishRestartPlayer` 에 복원 폰 회전 Yaw → 컨트롤 로테이션 파생을 추가했다(별도 저장 없음). 이에 스폰·시선 공유 헬퍼로 리팩터.

### 후속 과제
- **런타임 검증 미수행**: WxEditor(Development) 컴파일·링크 성공만 확인. PIE 실동작(자유 위치 명시 저장→로드 시 위치 복원 + 카메라가 저장 시점 방향을 향하는지, 체크포인트 접촉→사망→체크포인트 스폰, `Wx.Save.Dump` 위치 확인)은 미검증.
- **메뉴 로드 슬롯 정합**: 사망 "Restart from Check Point"(`LoadFromFile`) 가 재로드하는 슬롯이 명시 저장 슬롯과 겹치는 경우의 실동작 확인 필요(설계상 오토세이브가 위치를 리셋하면 체크포인트 폴백).
