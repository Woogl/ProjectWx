# 크라우치 기본값을 공용 CMC 로 내린다

## 계획

### 목표
앉기 설정 두 줄이 `AWxPlayerCharacter` 생성자에만 있어 플레이어만 앉을 수 있다. `UWxBTService_MirrorMovement` 가 주인의 앉기를 따라해도 AI 는 `bCanCrouch` 가 꺼져 있어 `Crouch()` 가 조용히 무시된다.
도플갱어 BP 마다 값을 다시 켜게 하는 대신 전 캐릭터 공용 `UWxCharacterMovementComponent` 의 기본값으로 내린다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/Component/WxCharacterMovementComponent.cpp` | 생성자에 `NavAgentProps.bCanCrouch = true` 와 `SetCrouchedHalfHeight(60.f)` 추가 | 수정 |
| `Source/WxGame/Character/WxPlayerCharacter.cpp` | 같은 두 줄 삭제 | 수정 |
| `.claude/worklog/2026-09-09-도플갱어-이동-미러링.md` | 후속 과제에서 BP 저작 항목 정리 | 수정 |

### 접근 방식
- **앉기는 캐릭터 종류가 아니라 이동 컴포넌트의 능력이다**: 생성자가 이미 `JumpZVelocity`·`GravityScale`·`AirControl` 을 정하는 자리이므로 앉기도 같은 자리에 선언한다.
- **`SetCrouchedHalfHeight` 를 쓴다**: 엔진도 생성자에서 이 setter 로 40 을 넣는다(`CharacterMovementComponent.cpp:751`). 값 대입 대신 setter 를 쓰면 눈 높이 재계산 경로를 함께 탄다.
- **`AWxPlayerCharacter::CanCrouch()` 오버라이드는 남긴다**: 공중에서 앉지 못하게 막는 것은 플레이어 조작 규칙이지 컴포넌트의 능력이 아니다.
- **`MaxWalkSpeed` 는 옮기지 않는다**: 플레이어 500, 적 400 으로 서로 달라 공용 기본값이 될 수 없다.

### 뒤따르는 동작 변화
모든 캐릭터가 앉을 수 있게 되고, 앉았을 때 캡슐 절반 높이가 엔진 기본 40 대신 60 이 된다.
`Crouch()` 를 부르는 곳이 플레이어 입력과 미러 서비스뿐이라 적은 능력만 열릴 뿐 실제로 앉지 않는다. `bCanCrouch` 는 내비 데이터 선택 기준(반경·높이·스텝 높이)에 들지 않아 기존 AI 경로에 영향이 없다.

### 구현·결정과 그 이유
- **점프 기본값 옆에 뒀다**: 앉기와 점프는 둘 다 이동 컴포넌트가 여는 능력이라 한자리에 모아 두면 캐릭터마다 다시 켤 이유가 없어진다.
- **`SetCrouchedHalfHeight` 를 썼다**: 엔진 자신도 생성자에서 이 setter 로 40 을 넣는다. 대입 대신 setter 를 타면 눈 높이 재계산이 함께 돈다.
- **`CanCrouch()` 오버라이드는 플레이어에 남겼다**: 공중에서 앉지 못하게 막는 것은 조작 규칙이지 컴포넌트의 능력이 아니다. 도플갱어는 주인이 앉았던 표본을 따라가므로 이 규칙이 필요 없다.
- **`MaxWalkSpeed` 는 옮기지 않았다**: 플레이어 500, 적 400 으로 서로 달라 공용 기본값이 될 수 없다.
