# 상호작용 ViewModel 이름 변경 (List/Entry 재정렬)

## 계획

### 목표
위젯은 `List`/`Entry`로 나뉘는데 리스트 VM만 접미사가 없어 짝이 안 보인다. 도메인 의미에 맞춰 "상호작용 하나"=`WxViewModel_Interaction`(구 Entry), "목록"=`WxViewModel_InteractionList`(구 리스트 VM)로 재정렬한다.

| 현재 | 변경 후 |
|---|---|
| `UWxViewModel_Interaction` (리스트) | `UWxViewModel_InteractionList` |
| `UWxViewModel_InteractionEntry` (항목) | `UWxViewModel_Interaction` |
| `UWxViewModelResolver_Interaction` | `UWxViewModelResolver_InteractionList` |

### 수정 범위
C++ 6파일 rename(`git mv`, 이력 보존) + 식별자/include/주석 갱신. 파일명 회전이라 ① 리스트 VM→`...List`(이름 비움) ② 엔트리 VM→`Interaction`(빈 자리) ③ 리졸버→`...List` 순서.

추가로 `WxInteractionRegistrySubsystem.h` 주석, `WxUI/README.md` L15 참조 갱신.

### 접근 방식
- **CoreRedirects 미사용**: 이름 회전의 리다이렉트 체이닝 위험을 피한다. WBP 2개(`WBP_InteractionList`, `WBP_InteractionEntry`)의 VM/리졸버 재바인딩은 사용자가 에디터에서 직접 처리한다.
- 스냅샷 JSON은 손대지 않음(WBP 저장 시 자동 갱신).

## 완료

| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/.../MVVM/WxViewModel_Interaction.{h,cpp}` | 구 리스트 VM → `WxViewModel_InteractionList`로 이동, 클래스/include/주석 갱신 | 이동·수정 |
| `Plugins/WxUI/.../MVVM/WxViewModel_Interaction.{h,cpp}` (신규 점유) | 구 엔트리 VM(`InteractionEntry`)이 비워진 `Interaction` 자리로 이동, 클래스 `UWxViewModel_Interaction` | 이동·수정 |
| `Source/WxGame/MVVM/WxViewModelResolver_InteractionList.{h,cpp}` | 구 `WxViewModelResolver_Interaction` → 이동, 클래스/include/`NewObject`/델리게이트 타입 갱신 | 이동·수정 |
| `Plugins/WxWorld/.../WxInteractionRegistrySubsystem.h` | 주석 VM 참조 갱신 | 수정 |
| `Plugins/WxUI/README.md` | VM 참조 갱신 | 수정 |

### 구현·결정과 그 이유
- **이름 회전을 `git mv` 순서로 처리**: 구 리스트 파일을 먼저 `...List`로 옮겨 `WxViewModel_Interaction.{h,cpp}` 파일명을 비운 뒤 구 엔트리 파일을 그 자리로 옮겨, 파일명 충돌 없이 이력을 보존했다.
- **리스트 VM 내부의 "항목" 타입 표기 정리**: 리스트 VM이 생성·소유하는 항목 VM 타입이 `UWxViewModel_InteractionEntry`→`UWxViewModel_Interaction`로 바뀌어 의미가 헷갈릴 수 있으므로, 관련 주석을 "상호작용 하나/항목" 기준으로 다듬었다. 바인딩 키인 `Entries` 프로퍼티명은 WBP 소스 경로라 그대로 유지.
- **리졸버 주석 정확도 부수 교정**: VM 참조를 고치는 같은 문장에 있던 실코드 불일치(`UWxInteractionListComponent`)를 실제 사용 타입 `UWxInteractionRegistrySubsystem`으로 함께 바로잡았다.
- **CoreRedirects 미사용**: 사용자가 직접 재바인딩하기로 하여, 회전 이름의 리다이렉트 체이닝 위험을 원천 차단했다.

### 계획 대비 달라진 점
- 계획대로. (리졸버 주석의 `UWxInteractionListComponent` 교정만 부수적으로 추가)

### 후속 과제
- **사용자 에디터 재바인딩 필요**(미검증): `WBP_InteractionList`의 VM 컨텍스트 클래스→`WxViewModel_InteractionList`, 리졸버→`WxViewModelResolver_InteractionList`; `WBP_InteractionEntry`의 VM 컨텍스트 클래스→`WxViewModel_Interaction`. 재저장 시 스냅샷 자동 갱신.
- WBP의 VM 컨텍스트 **이름**(생성 getter/setter용)은 클래스명과 별개라 자동으로 안 바뀜. 깔끔히 맞추려면 컨텍스트 이름도 재정렬(선택).
