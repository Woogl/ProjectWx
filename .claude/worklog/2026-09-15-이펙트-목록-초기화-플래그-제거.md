# 이펙트 목록 초기화 플래그 제거

## 계획

### 목표
어빌리티 시스템 뷰모델은 이펙트 목록을 처음 조회할 때 만든다. 이미 초기화했는지는 bool 멤버로 판단하는데, 같은 사실이 ASC 추가 델리게이트의 구독 상태에도 남아 있다. 두 곳에 있는 사실을 하나로 줄이려고 플래그를 없애고 구독 상태를 직접 조회한다(WxUI 모듈 리뷰 5번). 적 네임플레이트 VM이 이펙트를 추적하지 않게 하는 지연 초기화는 그대로 둔다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_AbilitySystem.cpp` | 지연 초기화 가드를 추가 델리게이트의 `IsBoundToObject(this)`로 교체, 플래그 설정·리셋 제거 | 수정 |
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_AbilitySystem.h` | 플래그 선언 제거 | 수정 |

### 접근 방식
- **구독 상태가 곧 초기화 여부**: 이 VM이 추가 델리게이트에 구독하는 곳은 지연 초기화 한 곳뿐이다. 그래서 "구독돼 있음"과 "초기화함"은 같은 뜻이다. 제거 델리게이트는 같은 자리에서 함께 구독하므로 추가 쪽만 보면 된다.
- **해제 뒤 리셋 불필요**: 해제는 파괴 시점(BeginDestroy)에서만 일어나고, 그때 캐시한 ASC를 먼저 비운다. 그 뒤의 조회는 ASC가 없어 바로 빠지므로 플래그를 되돌리는 줄은 이미 하는 일이 없었다.
- **재진입 방지 유지**: 구독이 목록 구성보다 먼저 일어나고 목록 구성은 FieldNotify를 보내지 않는다. 구성 도중 다시 조회돼도 이미 구독돼 있어 바로 빠진다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |

| `Plugins/WxUI/Source/WxUI/Private/MVVM/WxViewModel_AbilitySystem.cpp` | 지연 초기화 가드를 추가 델리게이트 구독 조회로 교체, 플래그 설정·리셋 제거 | 수정 |
| `Plugins/WxUI/Source/WxUI/Public/MVVM/WxViewModel_AbilitySystem.h` | 플래그 선언 제거 | 수정 |

### 구현·결정과 그 이유
- **구독 상태를 초기화 표시로 삼음**: 엔진 멀티캐스트 델리게이트가 객체 단위 구독 조회를 공개 API로 제공한다. 이 VM의 추가 통지 구독 지점이 하나뿐이라, 조회 결과가 초기화 여부와 어긋날 수 없다. 조회할 수 있는 사실을 멤버에 따로 저장하지 않는다는 방침을 따랐다.
- **지연 초기화는 유지**: 적 네임플레이트마다 생기는 VM이 표시하지도 않는 이펙트를 구독하고 자식 VM을 만드는 비용을 피하려고 도입한 구조라, 이번 범위에서 건드리지 않았다.
- **검증**: UE 5.8.1 WxEditor Win64 Development 빌드 성공.
