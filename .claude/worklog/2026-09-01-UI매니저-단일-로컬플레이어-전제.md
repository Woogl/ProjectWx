# UI 매니저의 단일 로컬 플레이어 전제를 코드로 드러내기

## 계획

### 목표
`UWxUIManagerSubsystem`이 모든 로컬 플레이어를 순회하며 PC 교체를 구독하지만, 정작 레이아웃과 추적 PC는 단수다. 둘째 로컬 플레이어가 붙으면 첫째의 레이아웃을 갈아치우는 구조인데, 순회 코드가 스플릿스크린을 지지하는 것처럼 읽혀 오해를 만든다. 코드가 하는 말을 실제 전제(로컬 플레이어 하나)와 일치시킨다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/.../Private/System/WxUIManagerSubsystem.cpp` | `Initialize`의 로컬 플레이어 순회를 첫 플레이어 한 명 처리로 교체 | 수정 |
| `Plugins/WxUI/.../Private/System/WxUIManagerSubsystem.cpp` | `Deinitialize`의 로컬 플레이어 순회 구독 해제 블록 삭제 | 수정 |
| `Plugins/WxUI/.../Public/System/WxUIManagerSubsystem.h` | 레이아웃·추적 상태가 단수인 전제를 선언부 주석으로 명시 | 수정 |

### 접근 방식
- **상태를 `ULocalPlayer` 키로 묶지 않는다**: 스플릿스크린은 계획에 없고, 이 서브시스템은 Lyra의 per-player 레이아웃 간접층을 의도적으로 걷어내고 단수로 채택한 결과다. 없는 요구를 미리 짓는 대신 전제를 드러내는 쪽을 택한다.
- **초기 캐치업은 첫 로컬 플레이어 하나로**: GameInstance 서브시스템 초기화가 로컬 플레이어 생성보다 앞서므로 실제로 일을 하는 건 `OnLocalPlayerAddedEvent` 쪽이다. 초기 순회는 뒤늦게 만들어진 경우를 위한 캐치업일 뿐이라 한 명이면 족하다.
- **`Deinitialize`의 순회는 이미 빈 루프다**: `UGameInstance::Shutdown`이 모든 로컬 플레이어를 제거한 뒤에야 서브시스템을 내리므로(`GameInstance.cpp:157-167`, GameInstance 서브시스템을 내리는 유일한 지점) 이 시점의 로컬 플레이어 목록은 비어 있다. 구독을 걸어 둔 객체가 이미 사라진 뒤라 끊을 것도 없다. 월드를 넘어 사는 PC·ASC 구독 해제는 그대로 둔다.
- **`HandlePlayerControllerSet`은 건드리지 않는다**: 한 플레이어의 PC가 교체되는 정상 경로(재빙의·PlayerState 재복제)에 필요한 동작이고, 리뷰가 지적한 갈아치우기와는 다른 사안이다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/.../Private/System/WxUIManagerSubsystem.cpp` | `Initialize`의 로컬 플레이어 순회를 첫 플레이어 한 명 캐치업으로 교체 | 수정 |
| `Plugins/WxUI/.../Private/System/WxUIManagerSubsystem.cpp` | `Deinitialize`의 로컬 플레이어 순회 구독 해제 삭제, 이유를 주석으로 | 수정 |
| `Plugins/WxUI/.../Public/System/WxUIManagerSubsystem.h` | 레이아웃·추적 상태가 단수인 전제와 확장 시 방향을 선언부 주석으로 | 수정 |

### 구현·결정과 그 이유
- **전제를 지우는 대신 드러냈다**: 상태를 `ULocalPlayer` 키로 묶으면 스플릿스크린이 열리지만, 그건 계획에 없는 요구다. 이 서브시스템 자체가 Lyra의 per-player 레이아웃 간접층을 걷어내고 단수를 택한 결과라, 간접층을 되돌리는 대신 순회를 없애 코드가 하는 말을 실제 전제와 맞췄다.
- **둘째 플레이어를 막는 가드는 두지 않았다**: 지금 경로로는 로컬 플레이어가 둘이 될 수 없어 발동하지 않을 방어 코드가 된다. 대신 헤더 주석이 전제와 넘어설 때 손볼 곳을 함께 가리킨다.
- **`Deinitialize`의 해제 루프는 이미 죽은 코드였다**: `UGameInstance::Shutdown`은 로컬 플레이어를 전부 제거한 다음에야 서브시스템 컬렉션을 내리고, 그곳이 GameInstance 서브시스템을 내리는 유일한 지점이다. 도달 시점에 목록이 비어 있어 아무것도 끊지 못했고 끊을 대상도 없었다. 남긴 주석은 "왜 안 끊는가"를 답한다. 월드를 넘어 사는 PC·ASC 구독 해제는 성격이 달라 그대로 뒀다.
- **검증**: UE 5.8 `WxEditor Win64 Development` 빌드가 `Result: Succeeded`로 끝났다.
