# SpawnActor 노드 Interval 0 일회성 스폰

## 계획

### 목표
`FWxStateTreeTask_SpawnActor`에서 `Interval`이 0이면 반복 없이 진입 직후 1회만 스폰하도록 한다. 양수면 기존대로 그 간격마다 반복.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | `Interval` ClampMin "0.05"→"0", 프로퍼티 주석에 "0=일회성" 명시. struct doc·모듈 doc 보정 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmickStateTreeNodes.cpp` | `Tick` 주기 차감 `acc -= Interval` → `Interval>0 ? acc-Interval : -TNumericLimits<float>::Max()`. EnterState 주석 보정 | 수정 |

### 접근 방식
- **일회성도 머무는 태스크 유지**: 항상 Running. 스폰만 1회 하고 상태 완료/전이는 종전처럼 에셋이 결정 → "1번만 실행"을 "1회만 스폰"으로 해석.
- **누적기 재사용(새 플래그 없음)**: 일회성은 첫 스폰 직후 누적기를 음의 극값(`-FLT_MAX`)으로 파킹. 이후 `+= DeltaTime`이 포화돼 임계에 다시 도달하지 못하므로 재스폰 영구 차단. 재진입 시 `EnterState`가 누적기를 `Interval`(=0)로 초기화해 다시 1회 스폰.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | `Interval` ClampMin "0.05"→"0", 프로퍼티 주석에 "0=일회성" 명시. struct doc·모듈 doc 보정 | 수정 |
| `Plugins/WxWorld/.../Private/Gimmick/WxGimmickStateTreeNodes.cpp` | `Tick` 주기 차감을 `Interval>0 ? acc-Interval : -TNumericLimits<float>::Max()` 삼항으로 교체. EnterState 주석 보정 | 수정 |

### 구현·결정과 그 이유
- **누적기 파킹으로 일회성 구현**: 첫 스폰 직후 누적기를 `-TNumericLimits<float>::Max()`로 묶으면, 이후 `+= DeltaTime`이 float 포화로 값을 못 키워 임계(`< Interval`)를 영구히 못 넘는다. 새 멤버 플래그 없이 기존 누적기만 재사용 → 분기용 멤버 플래그 추가를 피했다.
- **머무는 태스크 계약 유지**: 일회성도 항상 Running. 스폰 1회만 다르고 완료/전이 정책은 종전처럼 에셋이 결정해, periodic/one-shot 두 모드가 같은 노드 계약을 공유한다.
- **재진입 안전**: `EnterState`가 누적기를 `Interval`(=0)로 재초기화하므로 상태를 다시 들어오면 파킹이 풀려 또 1회 스폰한다.
