# 상호작용 리스트 출력 VM + 셀렉터 (뼈대)

## 계획

### 목표
상호작용 출력을 중앙 HUD 리스트(인-레인지 전부 표시, 추후 휠 선택)로 전환하는 **뼈대**를 세운다. 입력 감지·실제 상호작용 연동·기존 위젯 제거는 후속. WxCore 무변경.

### 수정 범위
| 모듈 | 파일 | 내용 |
|---|---|---|
| `WxWorld` | `Targeting/WxInteractionSelectorComponent.h/.cpp` (신규) | 인-레인지 목록 + 선택 인덱스 + 델리게이트 2종. 입력/틱/복제 없음 |
| `WxWorld` | `Interaction/WxInteractionComponent.h/.cpp` (수정) | 로컬 오버랩/비활성 시 Pawn 셀렉터에 register/unregister, `GetInteractionText()` 게터 |
| `WxUI` | `MVVM/WxViewModel_InteractionEntry.h/.cpp` (신규) | Prompt + bSelected |
| `WxUI` | `MVVM/WxViewModel_Interaction.h/.cpp` (신규) | Entries + SelectedIndex, Handle* 핸들러, Initialize/Deinitialize |
| `WxGame` | `MVVM/WxViewModelResolver_Interaction.h/.cpp` (신규) | Pawn 셀렉터 찾아 VM 생성·델리게이트 연결·시드 |
| `WxGame` | `Character/WxPlayerCharacter.h/.cpp` (수정) | 셀렉터 서브오브젝트 부착(LockOnManager와 동일). 입력 바인딩 없음 |

### 접근 방식
WxCore 금지 → WxGame Resolver가 WxWorld 셀렉터 델리게이트(`const TArray<FText>&`/`int32`)를 WxUI VM 핸들러에 `AddDynamic`로 연결(엔진 타입만 오가 양쪽 헤더 비참조). 셀렉터는 register/unregister 이벤트로만 목록 재구성, SelectedIndex는 0/클램프 고정. 기존 위젯·하이라이트는 그대로 두고 register만 additive 추가.

### 후속(제외)
- 휠 입력(IA_InteractScroll→CycleSelection)
- WxAbility_Interact의 선택 대상 사용 + LockOn식 복제
- 기존 월드 위젯 제거 + 신규 WBP_Interact(HUD) 저작·리졸버 지정(사용자)

## 완료

### 수정한 파일
| 모듈 | 파일 | 수정 내용 |
|---|---|---|
| `WxUI` | `MVVM/WxViewModel_InteractionEntry.h/.cpp` (신규) | Prompt(FText) + bSelected(bool) FieldNotify, setter 2종 |
| `WxUI` | `MVVM/WxViewModel_Interaction.h/.cpp` (신규) | Entries + SelectedIndex(FieldNotify), Initialize(prompts,index)/Deinitialize, HandleListChanged/HandleSelectionChanged, 엔트리 재구성·선택 클램프 |

### 구현·결정과 그 이유
- **VM만 남기고 소스 측 전부 제외**: 구현 중 사용자가 "SelectorComponent 없이, 캐릭터 수정 없이 뼈대만"을 요청. 출력 VM은 `Initialize(TArray<FText>, int32)` + `Handle*` 핸들러로 **소스에 무관**하게 동작하므로 단독으로 성립한다. 데이터 소스(선택자/리졸버/BP)는 추후 무엇으로든 연결 가능.
- **엔트리 = 자식 VM**: ListView 정석 바인딩(엔트리별 Prompt/bSelected). 선택 변경 시 목록 재구성 없이 bSelected만 갱신.
- **선택은 UI 소유**(사용자 결정): 목록(Entries)은 월드가 공급, 선택(SelectedIndex)은 위젯이 결정. 그래서 선택 입구를 월드 이벤트 핸들러(`HandleSelectionChanged`)가 아니라 위젯이 부르는 `SetSelectedIndex(int32)` BlueprintCallable로 둠. 월드 측엔 셀렉터·휠·복제가 불필요.

### 계획 대비 달라진 점
- **범위 대폭 축소**(사용자 요청). 당초 계획의 `UWxInteractionSelectorComponent`(WxWorld), `WxInteractionComponent` register/unregister 수정, `UWxViewModelResolver_Interaction`(WxGame), `AWxPlayerCharacter` 부착은 **모두 만들었다가 제거/원복**. 최종 산출물은 WxUI VM 2개뿐. WxCore 무변경(유지).

### 후속 과제
- VM에 데이터를 공급할 **소스 + 인스턴스화 경로** 결정·구현(예: 선택자 컴포넌트 + 리졸버, 또는 BP에서 직접 채움). VM의 `Initialize`/`HandleListChanged`/`HandleSelectionChanged`가 진입점.
- 휠 입력 선택, `WxAbility_Interact` 선택 대상 연동(+복제), 기존 월드 프롬프트 위젯 제거 + 신규 WBP_Interact 저작.
