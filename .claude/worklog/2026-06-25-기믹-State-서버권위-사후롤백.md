# 기믹 State enum 서버 권위 사후 롤백 개선

## 계획

### 목표
모든 기믹(`AWxGimmick` 파생)의 State enum 을 무조건 서버 권위로 처리하되, 클라가 어떤 경로로든 State 를 선반영(선처리)해 어긋나더라도 서버가 사후에 권위 값으로 재확정(롤백)할 수 있게 한다. 클라 예측은 도입하지 않는다.

### 접근 방식
- **권위/롤백 인프라를 베이스 `AWxGimmick` 에 집약**: typed `State`(effective, ST Enum Compare 바인딩 대상)는 SaveGame 유지하되 `Replicated` 제거. 권위 원본은 effective 와 분리된 복제 미러 `AuthorityStateValue` 에 보관(클라가 effective 를 어긋내도 권위 값 보존). 매 커밋마다 무조건 증가하는 `AuthorityStateRevision` 이 값 무변동 재확정도 클라로 전파(사후 롤백의 핵심). `OnRep_AuthorityState` 가 effective 를 권위 값으로 스냅(확정/롤백). 클라측 typed State 의 유일한 라이터는 OnRep → 구조적 서버 권위 보장.
- **ST 에셋 재바인딩 불필요**: typed `State` 필드명·접근성 유지(replicated 지정자만 제거)라 Enum Compare 바인딩 영향 없음.
- **예측 미도입**: WxGame ability/InteractionComponent 무수정. 인터랙션 핸들러의 비권위 분기는 기존대로 노옵.

```mermaid

    participant C as AWxGimmick (클라 OnRep)

    R->>C: OnRep_AuthorityState
    C->>C: SetGimmickState(AuthorityStateValue) — effective 스냅(확정/롤백)
```

### 구현·결정과 그 이유
- **단일 권위 쓰기 진입점**: State 쓰기를 베이스 `CommitGimmickState`로 모아 권위 가드를 한 곳에서 강제했다. 인터랙션 핸들러와 `Wx Set State` 태스크가 같은 경로를 거치므로 "State 는 무조건 서버 권위로만 쓰인다"가 코드 구조로 보장된다. 클라는 복제된 State 를 ST Enum Compare 전이로 추종하므로, 클라가 비주얼을 로컬로 선반영하더라도 권위 State 로 수렴한다(= 사후 롤백).
- **미러 미도입**: 별도 복제 미러+리비전은 "클라가 State 필드 자체를 덮어쓴 뒤 서버 권위 값이 무변동인 경우"의 롤백에만 필요하다. 클라 예측을 도입하지 않기로 했으므로 그 경우가 성립하지 않고, typed State 의 복제만으로 서버 권위+수렴이 보장된다. 과한 장치를 피하고 `DOREPLIFETIME(State)`를 그대로 유지했다.
- **`SetGimmickState` 훅 활성화**: 기존엔 베이스 노옵이라 `Wx Set State` 태스크가 사실상 휴면이었다. 자식이 uint8→enum 쓰기를 구현하고 태스크를 `CommitGimmickState`로 연결해, ST 가 상호작용 없이 State 전이를 구동하는 경로가 실제로 동작하게 됐다.

### 계획 대비 달라진 점
- 계획(승인본)의 **복제 미러(`AuthorityStateValue`/`AuthorityStateRevision`)·`OnRep_AuthorityState`·`OnWxSaveRestored` 시딩·`GetGimmickStateValue` 훅을 전부 제거**했다. 사용자 피드백("클라 예측 없이 무조건 서버 권위, 미러는 굳이 불필요, `DOREPLIFETIME(State)` 유지")에 따라, 예측이 없으면 "값 무변동 롤백" 케이스가 성립하지 않아 미러가 불필요하다고 판단. typed State 를 복제(+SaveGame)로 유지하고 베이스엔 `CommitGimmickState` 단일 진입점 + `SetGimmickState` 훅만 남겼다.

### 후속 과제
- `Wx Set State` 태스크는 이제 동작 가능하나(자식 `SetGimmickState` 구현됨), 현재 이를 배치한 ST 에셋은 없음 — 채택은 추후.
- 검증은 WxEditor(Development) 컴파일·링크 성공(클린)까지 확인. 멀티플레이 PIE 런타임 패리티·세이브/로드 동작은 미검증.
