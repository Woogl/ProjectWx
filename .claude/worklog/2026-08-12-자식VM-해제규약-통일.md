# 자식 VM 해제 규약 통일

## 계획

### 목표
`module_review_WxUI.md` 이슈 8. `WxViewModel_AbilitySystem.cpp:38-39` 가 "`Empty()` 로 배열에서만 떼면 자식은 GC 의 `BeginDestroy`→`Deinitialize` 까지 티킹·구독을 유지한다"는 규약을 명문화하는데, 같은 파일의 `RefreshActiveEffectViewModels` 의 `Empty()` 와 `HandleActiveEffectRemoved` 의 `RemoveAt` 은 그 규약을 따르지 않는다. `UWxUIManagerSubsystem::Deinitialize` 가 `SelectionViewModel` 을 `Deinitialize()` 없이 null 로 떼는 것도 같은 갈림이다. 규약을 한 갈래로 통일한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/.../MVVM/WxViewModel_AbilitySystem.h` | private `ClearActiveEffectViewModels()` 선언 | 수정 |
| `Plugins/WxUI/.../MVVM/WxViewModel_AbilitySystem.cpp` | 이펙트 배열 해제를 헬퍼로 일원화, `HandleActiveEffectRemoved` 에 `Deinitialize()` 추가 | 수정 |
| `Plugins/WxUI/.../System/WxUIManagerSubsystem.cpp` | `SelectionViewModel` 을 null 로 떼기 전에 `Deinitialize()` 호출 | 수정 |

### 접근 방식
- **이펙트 배열 해제는 헬퍼 하나로**: `ActiveEffectViewModels` 만 두 곳(`Deinitialize`, `RefreshActiveEffectViewModels`)에서 통째로 비워지므로 "각 자식 `Deinitialize()` → `Empty()`" 를 private `ClearActiveEffectViewModels()` 로 묶는다. 브로드캐스트는 호출부 사정이 달라(Deinitialize 는 안 함, Refresh 는 마지막에 한 번) 헬퍼에 넣지 않는다. 어트리뷰트/어빌리티 배열은 해제 지점이 `Deinitialize` 한 곳뿐이라 기존 인라인 루프를 유지한다.
- **단건 제거는 그 자리에서**: `HandleActiveEffectRemoved` 는 찾은 VM 을 로컬로 받아 `Deinitialize()` 후 `RemoveAt`. 실제로 규약이 필요한 지점 — GE 가 사라질 때마다 티커가 한 틱 더 살아남던 것을 즉시 끊는다.
- **Selection VM 도 동일 규약**: `UWxViewModel_Selection` 은 `Deinitialize` 를 재정의하지 않지만 베이스가 진행 중인 아이콘 스트리밍을 취소하므로 호출에 의미가 있다.
