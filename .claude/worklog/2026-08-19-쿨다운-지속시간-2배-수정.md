# 쿨다운 지속시간 2배 수정

## 계획

### 목표
`UWxEffect_Cooldown`을 쓰는 모든 어빌리티의 첫 충전 쿨다운이 `CooldownTime × 2`로 걸리는 버그를 고친다. 지속시간 계산 시점을 GE 생성 이전 한 곳으로 고정해, 계산이 자기 자신을 세는 상황 자체가 성립하지 않게 만든다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxEffect_Cooldown.h` | `UWxMMC_CooldownDuration` 선언 제거, 클래스 주석을 SetByCaller 기준으로 정정 | 수정 |
| `WxEffect_Cooldown.cpp` | 생성자 `DurationMagnitude`를 `FSetByCallerFloat{SetByCaller.Duration}`으로 교체, MMC 구현 제거 | 수정 |
| `WxAbilityBase.h` | `ApplyCooldown` 오버라이드 선언 추가, 클래스 주석의 MMC 서술 정정 | 수정 |
| `WxAbilityBase.cpp` | `ApplyCooldown` 구현 추가 | 수정 |

### 접근 방식
- **원인**: `UWxMMC_CooldownDuration`이 적용 시점의 ASC 활성 GE를 조회해 `최장 잔여 + CooldownTime`을 냈는데, 엔진 `FActiveGameplayEffectsContainer::ApplyGameplayEffectSpec`은 새 GE를 활성 목록에 먼저 삽입한 뒤 지속시간을 다시 계산한다. 재계산 패스에서 MMC가 방금 삽입된 자기 자신을 잔여 2초짜리 쿨다운으로 세어 4초를 확정했다.
- **지속시간은 거는 쪽이 한 번 계산해 스펙에 실어 보낸다**: `UWxAbilityBase::ApplyCooldown` 오버라이드에서 스펙을 만들고, 그 시점에 `QueryActiveCooldowns`로 직렬 회복분을 구해 `SetByCaller.Duration`으로 실어 적용한다. 조회가 GE 적용 이전이므로 자기 참조가 불가능하고, 엔진이 몇 번 재계산해도 스펙에 박힌 같은 값을 되읽어 멱등이다.
- **엔진 순정 경로 유지**: `ApplyCooldown`은 커밋이 모두 지나는 순정 가상 훅, SetByCaller는 런타임 산출값을 싣는 순정 수단(`UWxEffect_NoCooldown`이 이미 같은 패턴). 커스텀 MMC 클래스가 하나 줄어든다.
- **기존 판정 재사용**: 커스텀 GE 탈출구는 다른 오버라이드와 동일한 마커 비교, 쿨다운 없음 판정은 `GetCooldownGameplayEffect()`의 nullptr을 그대로 게이트로 쓴다. 다중 충전용 `CooldownEffect` 인스턴스는 손대지 않는다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `WxEffect_Cooldown.h` | `UWxMMC_CooldownDuration` 제거, 지속시간 출처를 SetByCaller로 명시 | 수정 |
| `WxEffect_Cooldown.cpp` | 생성자 지속시간을 SetByCaller.Duration으로 교체, MMC 구현 제거 | 수정 |
| `WxAbilityBase.h` | `ApplyCooldown` 오버라이드 선언, 마커 주석에 커스텀 GE 계약 추가 | 수정 |
| `WxAbilityBase.cpp` | `ApplyCooldown` 구현 | 수정 |

### 구현·결정과 그 이유
- **지속시간 계산을 GE 생성 이전으로 옮김**: 자기 제외 가드를 덧대는 대신 계산 시점 자체를 앞으로 당겼다. 엔진의 지속시간 재계산 시점이 몇 번이고 어디든, 스펙에 박힌 값을 되읽을 뿐이라 결과가 흔들릴 여지가 없다.
- **커스텀 쿨다운 GE 경로는 손대지 않음**: 마커가 아니면 곧장 순정 구현에 위임해, 커스텀 GE를 쓰는 어빌리티는 적용·판정·잔여시간 전부 엔진 순정 그대로 돈다. 다만 공용 GE를 상속하면 순정 경로가 SetByCaller를 싣지 않아 지속시간이 조용히 1초가 되므로, 그 계약을 마커 주석에 남겼다.
- **쿨다운 없음 판정을 한 곳으로**: Row 부재·0 이하 쿨다운 판정을 새로 쓰지 않고 기존 `GetCooldownGameplayEffect`의 널 반환을 게이트로 삼아, 판정이 갈라지지 않게 했다.
- **다중 충전 GE 인스턴스 유지**: ViewModel에 최대 충전 수를 전달하는 용도라 이번 원인과 무관해 그대로 뒀다.

### 계획 대비 달라진 점
- 마커 주석에 커스텀 GE 계약 한 줄을 추가했다. 커스텀 경로가 앞으로도 안전하도록 해달라는 요청에 따른 것으로, 공용 GE 상속만이 유일한 함정이라 코드 대신 계약 명시로 막았다.

### 후속 과제
- PIE 실동작 확인(회피 쿨다운 2초, 다중 충전 직렬 회복)은 사용자 검증 대기.
