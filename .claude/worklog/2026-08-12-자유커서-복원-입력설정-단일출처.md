# 자유 커서 해제 시 입력 설정 이중 정의 제거

## 계획

### 목표
`module_review_WxUI.md` 이슈 11. Alt 홀드 자유 커서를 뗄 때 `HandleFreeCursorReleased`가 `FUIInputConfig(Game, CapturePermanently)`를 직접 만들어 복원하는데, 같은 값이 `UWxActivatableWidget::GetDesiredInputConfig()`에도 있어 정의가 두 곳으로 갈렸다. HUD WBP 에서 `InputMode` 를 Menu 로 바꾸면 진입 경로만 Menu 가 되고 복원 경로는 Game 으로 되돌아가 눌렀다 뗀 뒤에야 입력 모드가 어긋난다. 복원 값의 출처를 `GetDesiredInputConfig()` 하나로 통일한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/.../WxHUDLayout.cpp` | `HandleFreeCursorReleased` 복원 값을 `GetDesiredInputConfig()` 에서 가져옴 + `HandleFreeCursorPressed` 에 대칭 가드 추가 | 수정 |

헤더 변경 없음. 다른 파일 변경 없음.

### 접근 방식
- **복원은 자신의 희망 설정을 그대로 재적용**: `HandleFreeCursorReleased` 에서 `GetDesiredInputConfig()` 를 호출해 값이 있으면 `SetActiveUIInputConfig` 에 넘긴다. HUD 의 `InputMode` 를 무엇으로 바꾸든 진입·복원이 같은 값을 쓴다.
- **값이 없으면 아무 것도 하지 않음**: `InputMode` 가 Game/Menu 가 아니면 `GetDesiredInputConfig()` 는 미설정을 반환한다(HUD 가 입력 설정에 관여하지 않는 상태). 복원할 대상이 없으므로 Pressed 쪽에서도 자유 커서를 아예 켜지 않는다 — 켜기만 하고 되돌리지 못해 커서가 고정되는 상태를 막는다.
- **누를 때의 설정은 리터럴 유지**: `All`+`NoCapture`+`bIgnoreLookInput` 은 자유 커서 자체의 정의이지 HUD 기본 설정의 복제가 아니므로 중복이 아니다.
- **엔진 API 확인**: `UCommonUIActionRouterBase::RefreshUIInputConfig()` 는 *현재* 적용된 설정을 재적용할 뿐이라 복원에 못 쓴다. 위젯 트리에서 희망 설정을 다시 질의하는 `UpdateLeafNodeAndConfig` 는 protected 라 접근 불가. 따라서 위젯이 직접 재적용하는 방식이 유일한 경로다.
