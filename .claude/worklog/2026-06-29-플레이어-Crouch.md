# 플레이어 Crouch (C 키, 토글)

## 계획

### 목표
플레이어 캐릭터가 C 키를 눌러 앉기/서기를 토글로 전환할 수 있게 한다. 무브먼트(`bCanCrouch=true`)와 로코모션 AnimBP(`isCrouching`)는 이미 준비돼 있으나 이를 트리거할 입력 바인딩이 없어 이를 추가한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Input/WxInputConfig.h` | `JumpAction` 아래에 `CrouchAction` 직접 바인딩 액션 추가 | 수정 |
| `Source/WxGame/Character/WxPlayerCharacter.h` | `ToggleCrouch()` 핸들러 선언 | 수정 |
| `Source/WxGame/Character/WxPlayerCharacter.cpp` | Jump 다음에 `CrouchAction` `Started` 바인딩 + `ToggleCrouch()` 구현 | 수정 |
| `Content/Input/Actions/IA_Crouch` | Digital(bool) 입력 액션 | 신규(에디터) |
| `Content/Input/IMC_PlayerCharacter` | `IA_Crouch` → C 키 매핑 | 수정(에디터) |
| `Content/Input/DA_InputConfig` | `CrouchAction`에 `IA_Crouch` 할당 | 수정(에디터) |

### 접근 방식
- **C++ 직접 바인딩**: Crouch는 `ACharacter`가 네이티브로 처리하는 이동 동작이므로 GAS 어빌리티 라우팅이 아닌 Move/Look/Jump와 동일한 직접 바인딩 부류로 둔다.
- **토글**: 새 멤버 플래그를 만들지 않고 `ACharacter`의 권위 상태 `bIsCrouched`를 직접 읽어 `Crouch()`/`UnCrouch()`를 전환한다. 토글이므로 `Started` 이벤트에만 바인딩.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Input/WxInputConfig.h` | `JumpAction` 아래에 `CrouchAction` 추가 | 수정 |
| `Source/WxGame/Character/WxPlayerCharacter.h` | `ToggleCrouch()` 선언 | 수정 |
| `Source/WxGame/Character/WxPlayerCharacter.cpp` | Jump 다음에 `CrouchAction` `Started` 바인딩, `ToggleCrouch()` 구현 | 수정 |

### 구현·결정과 그 이유
- **C++ 직접 바인딩(어빌리티 라우팅 아님)**: Crouch는 `ACharacter` 네이티브 이동 동작이라 GAS를 거칠 이유가 없다. Move/Look/Jump와 같은 부류로 두어 일관성을 유지했다.
- **`bIsCrouched` 직접 판독으로 토글**: 별도 상태 멤버를 추가하면 무브먼트의 권위 상태와 어긋날 수 있다. `ACharacter`가 가진 복제 상태를 곧 진실로 보고 그대로 분기했다. 토글이므로 `Started`에만 바인딩.

### 계획 대비 달라진 점
- 계획대로. (C++ 3파일 수정, 빌드 성공.)

### 후속 과제
- 에디터 에셋 배선 필요: `IA_Crouch`(Digital) 생성 → `IMC_PlayerCharacter`에 C 키 매핑 → `DA_InputConfig.CrouchAction`에 할당. 이 3가지가 끝나야 인게임에서 동작한다.
