# 메타휴먼 부착물 컴포넌트를 캐릭터 베이스로 이관

## 계획

### 목표
`UWxMetaHumanVisualComponent`가 BP_Player의 SCS에만 얹혀 있어, 에너미를 메타휴먼화하려면 BP마다 컴포넌트를 다시 얹어야 한다. `AWxCharacterBase` 생성자에서 네이티브 기본 서브오브젝트로 만들어 Player·Enemy·Boss가 전부 상속받게 하고, BP는 에셋 슬롯만 채우는 구조로 바꾼다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/WxCharacterBase.h` | 전방선언 + protected `VisibleAnywhere` 멤버 `MetaHumanVisualComponent` | 수정 |
| `Source/WxGame/Character/WxCharacterBase.cpp` | 생성자에서 `CreateDefaultSubobject` | 수정 |
| `Content/Character/Player/BP_Player.uasset` | 상속 컴포넌트로 에셋 값 이전 후 SCS `MetaHumanVisual` 삭제 | 수정 |

### 접근 방식
- **네이티브 서브오브젝트 + BP는 슬롯만**: 컴포넌트 클래스는 손대지 않는다. 에셋 슬롯이 이미 `EditDefaultsOnly`라 상속된 네이티브 컴포넌트로도 각 BP 디테일 패널에서 그대로 채운다.
- **이름을 `MetaHumanVisualComponent`로**: 기존 SCS 변수명 `MetaHumanVisual`과 달라 둘이 한동안 공존해도 이름 충돌·자동 개명이 없다. 이 성질을 이용해 네이티브 쪽을 먼저 채우고 SCS를 나중에 지워, 값이 비는 구간을 만들지 않는다. `EquipmentComponent`·`MotionWarpingComponent` 명명과도 일치.
- **빈 캐릭터는 무비용**: 메타휴먼 에셋이 없는 BP(Enemy·Boss·Sandbag·Custer)는 `OnRegister`가 부착물을 하나도 만들지 않고 빠져나가며 틱도 없다.
- `AWxNpc`(WxDialogue, `AActor` 직상속)는 이 계보 밖이라 NPC 메타휴먼화는 종전대로 SCS 방식.

### 마이그레이션 순서
1. C++ 수정 → 에디터 종료 → WxEditor(Development) 빌드 → 재실행 (새 UPROPERTY·서브오브젝트라 Live Coding 불가).
2. 상속 컴포넌트에 기존 값 9종 기입(Face·FaceAnimClass·그룸 4종·Outfit) → 컴파일·저장.
3. SCS `MetaHumanVisual` 삭제 → 컴파일·저장.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Character/WxCharacterBase.h` | 전방선언 + `VisibleAnywhere` 멤버 `MetaHumanVisualComponent` | 수정 |

### 구현·결정과 그 이유
- **네이티브 이름을 SCS 변수명과 다르게**: 이름이 겹치면 엔진이 로드 시 SCS 노드를 조용히 개명한다. 다르게 두어 둘이 한 세션에 공존하게 만들고, 그 사이에 값을 옮긴 뒤 SCS를 지웠다 — 마이그레이션 도중 BP가 부착물 없는 상태로 남는 구간이 없다.
- **BP는 에디터 디테일 패널 그대로**: 슬롯이 `EditDefaultsOnly`라 상속된 네이티브 컴포넌트에서도 편집이 되고, 값은 BP CDO의 서브오브젝트 델타로 저장된다. SCS 컴포넌트와 달리 인헤리터블 컴포넌트 핸들러를 거치지 않아, MCP로 CDO 서브오브젝트 경로에 직접 기입하는 것으로 충분했다.
- **SCS 노드 삭제만 Slate 자동화**: MCP 블루프린트 툴셋에 SCS 컴포넌트 추가·삭제 도구가 없다. 프로퍼티 기입으로 배열을 직접 수술하면 변수·템플릿 정리가 빠져 BP가 깨지므로, 컴포넌트 패널에서 선택 후 Delete를 눌러 에디터 정식 경로를 태웠다.

### 계획 대비 달라진 점
- 계획대로.

### 검증 결과
- WxEditor(Development) 빌드 성공. 저장된 `BP_Player.uasset`에 SCS 템플릿(`MetaHumanVisual_GEN_VARIABLE`)이 사라지고 네이티브 컴포넌트 오버라이드로 에셋 9종이 남은 것을 확인.
- PIE: 플레이어에 부착물 8종(Face·그룸 4·Outfit·LODSync·MetaHuman)+헤어 나이아가라 2종이 생성, 외형은 이관 전과 동일, 관련 경고 0건.
- BP_Enemy 인스턴스는 `MetaHumanVisualComponent`만 있고 부착물 0개 — 무비용 no-op 확인.
- BP 에디터 프리뷰 뷰포트도 종전대로 부착물 표시.

### 후속 과제
- 에너미 메타휴먼화 시 BP_Enemy의 상속 컴포넌트에 에셋만 채우면 된다(바디 메시 교체·Compatible Skeletons·`Tools/AddMetaHumanIkBones.py`는 별도 절차).
- `AWxNpc`는 계보 밖이라 NPC는 여전히 BP에 컴포넌트를 직접 얹어야 한다.
