# 대화 세션 컴포넌트의 미사용 공개 접근자 제거

## 계획

### 목표
`UWxDialogueSessionComponent` 의 `GetCurrentDialogueTarget()`·`GetCurrentRowHandle()` 을 지운다. 둘 다 호출자가 없는 공개 API인데, 헤더 클래스 주석과 README 는 "현재 행을 관찰하는 소비자(WxQuest 등)가 의미를 판정한다"를 현재 계약처럼 적고, 실패 경로 되돌리기 주석도 이 API 를 근거로 든다. 이를 전제로 한 서술과 죽은 대입을 실제 계약에 맞게 함께 정리한다(`/module-review` WxDialogue 3번 🟢). 동작은 바뀌지 않는다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/Source/WxDialogue/Public/WxDialogueSessionComponent.h` | 두 접근자 선언·doc 주석을 제거한다. 클래스 주석의 "신원·대상 노출, 소비자가 관찰로 판정"을 "종료를 기다린 쪽이 판정"으로, `StartDialogueRow` 주석의 "관찰자 노출용"을 빼는 것으로 정정한다 | 수정 |
| `Plugins/WxDialogue/Source/WxDialogue/Private/WxDialogueSessionComponent.cpp` | 두 접근자 정의를 제거한다. `ClientStartDialogue` 실패 경로에서 죽은 대입 `CurrentRowName = NAME_None` 을 지우고, 되돌리기 주석은 테이블 강참조를 놓는다는 이유로 고친다 | 수정 |
| `Plugins/WxDialogue/README.md` | 요약·담당·경계·관련 절에서 "신원(현재 행 핸들) 노출"과 "관찰 소비자" 서술을 실제 계약으로 정정한다 | 수정 |

### 접근 방식
- **단순 삭제**: 두 이름은 `Source`·`Plugins` 에서 호출부 0건이다. `UFUNCTION` 도 아니라 BP·에셋 참조가 불가능하다. WxQuest 는 `WxCore` 에만 의존해 행 관찰 소비자가 설 수 없고, 실제로도 없다. 관찰 소비자가 생기면 그때 되살린다.
- **`CurrentRowName = NAME_None` 삭제**: 이 대입 시점의 이름은 항상 비어 있어 효과가 없다.
  - 활성 세션이었다면 바로 앞 `EndDialogue()` 가 이미 비웠고, 아니었다면 원래 비어 있다.
  - `EnterRow` 는 실패하면 이름을 건드리지 않는다.
  - 종료 신호에서 동기로 재진입하는 경우도 이 대입으로는 막지 못한다. 유일한 구독자의 `FinishTask` 는 동기로 재진입하지 않는다.
- **`CurrentStartRow` 되돌리기는 유지**: `FDataTableRowHandle::DataTable` 은 `UPROPERTY TObjectPtr` 이다. 되돌리지 않으면 열리지 않은 세션이 테이블 강참조를 쥐게 되어, 헤더가 적은 "세션 동안의 강참조"와 어긋난다.
- **유지하는 것**:
  - 클래스 주석 "권위 측 소비자가 이 로컬 상태를 직접 읽는다"는 태스크의 동기 `HasActiveDialogue` 판정과 상호작용 어빌리티의 태그 게이트를 가리켜 여전히 참이다.
  - `EndDialogue()` 의 `CurrentTarget.Reset()` 은 세션 필드를 함께 비우는 종료 정리라 둔다.
  - 리뷰 문서·README provenance 는 각 스킬이 다음 실행 때 다시 쓴다.

### 구현·결정과 그 이유
- **대체 경로 없이 삭제**: 호출부 0건에 리플렉션 노출도 없어 에셋이 깨질 여지가 없다. 빌드에서 헤더를 포함하는 WxGame 까지 재컴파일돼 성공했다.
- **의미 판정 주체를 "종료를 기다린 쪽"으로 적음**: 대화가 남에게 주는 신호 중 의미 판정에 쓰이는 것은 `OnDialogueEnded` 뿐이다. 실제로 퀘스트 트리는 `Play Dialogue` 완료를 기다려 다음 단계로 넘어간다. 막연한 "소비자"보다 현재 계약을 그대로 드러낸다.
- **`CurrentStartRow` 되돌리기는 유지하고 이유만 교체**: 반쪽 핸들을 답할 접근자는 사라졌다. 그래도 UPROPERTY 핸들이 테이블을 강참조하므로, 열리지 않은 세션이 그것을 쥐지 않게 하는 이유는 남는다.
- **검증**:
  - UE 5.8 `WxEditor Win64 Development` 빌드가 `Result: Succeeded` 로 끝났고, 로그에 경고·에러가 없다.
  - Grep 결과 두 이름은 `Source`·`Plugins` 에 남지 않았다(워크로그·리뷰 문서에만 있음).
  - 동작 변화가 없어 PIE 실측은 하지 않았다.
