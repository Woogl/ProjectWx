# UI 정지에 해제 조건 대리자(FCanUnpause) 등록

## 계획

### 목표
모듈 리뷰(`Docs/Programmer/module_review_WxUI.md` 발견 5)가 지목한 대로, UI 매니저가 정지를 해제할 때 UI 와 무관한 정지까지 함께 지우는 것을 막는다. 엔진이 이미 갖고 있는 "정지 주체마다 자기 해제 조건을 대리자로 등록한다"는 규약에 UI 도 참여시키는 방식으로 고친다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/System/WxUIManagerSubsystem.h` | 정지 희망 판정과 해제 문의 콜백 선언 추가 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/System/WxUIManagerSubsystem.cpp` | 절대값 정지 호출을 PC 의 정지 요청 + 해제 조건 대리자 짝으로 교체, 레이어 순회를 판정 함수로 분리 | 수정 |

### 접근 방식
- **원인**: 지금은 위젯 상태가 바뀔 때마다 정지를 절대값으로 덮어쓴다. 해제 쪽은 게임모드의 `ClearPause` 로 내려가는데, UE 5.8 의 `ClearPause` 는 등록된 정지 주체들에게 되묻고 **해제에 동의했거나 조건을 아예 등록하지 않은 것만** 걷어낸다. UI 는 조건 없이 정지를 걸어 왔으므로 그 "조건 없는" 쪽에 속하고, 같은 처지의 다른 정지도 함께 지워진다.
- **해결**: UI 도 해제 조건을 대리자로 등록한다. 조건은 지금과 같은 재평가 — 정지를 원하는 활성 위젯이 하나도 남지 않았을 때만 해제에 동의한다. 새 멤버 상태는 두지 않고, 레이어 순회를 판정 함수 하나로 모아 재평가와 문의가 같은 답을 쓰게 한다.
- **부수 효과**: 반대 방향도 같이 닫힌다. 정지형 UI 가 열려 있는 동안에는 다른 곳에서 부른 해제에도 정지가 유지된다.
- **남는 구멍**: 엔진은 이미 정지 중이면 새 조건을 등록하지 않으므로, 남이 먼저 건 정지 위에서 UI 가 열리면 그쪽이 풀 때 함께 풀린다. 이를 막으려면 게임모드에 직접 걸어야 하는데 재평가마다 조건이 중복 누적되므로, 순정 경로를 택하고 "새 정지 주체는 자기 조건을 등록한다"는 규약을 주석으로 남긴다.

## 완료

### 수정한 파일

| `Plugins/WxUI/Source/WxUI/Private/System/WxUIManagerSubsystem.cpp` | 절대값 정지 호출을 PC 정지 요청 + 해제 조건 대리자 짝으로 교체, 레이어 순회를 판정 함수로 분리, 쓰이지 않게 된 include 제거 | 수정 |

### 구현·결정과 그 이유
- **해제 조건을 대리자로 등록**: 엔진은 정지를 걸 때 함께 받은 조건을 기억해 두었다가 해제 요청이 오면 등록된 주체들에게 하나씩 되묻고, 동의한 것만 걷어낸다. 조건 없이 걸어 오던 UI 의 정지를 이 규약 안으로 넣으니 우리 해제가 남의 정지를 건드리지 않고, 정지형 UI 가 떠 있는 동안에는 남이 부른 해제에도 정지가 유지된다.
- **판정은 한 곳**: 재평가와 해제 문의가 같은 답을 써야 하므로 레이어 순회를 판정 함수 하나로 모았다. 새 멤버 상태는 두지 않았다 — 누가 걸었는지를 기억하는 대신 지금 떠 있는 위젯에서 매번 파생한다는 기존 설계 그대로다.
- **PC 는 이미 추적 중인 것**: 정지 요청에 PC 가 필요해졌는데, 레이아웃 주인으로 이미 들고 있는 로컬 PC 를 쓰면 엔진 전역 조회가 사라진다. 그 PC 를 놓친 순간에는 아무 것도 하지 않는다.
- **레이아웃 유무는 판정 안으로**: 레이아웃이 없으면 정지를 원하는 위젯도 없다는 뜻이라 판정 함수가 답하게 하고, 재평가 앞단의 조기 반환은 걷어냈다. 해제 문의는 레이아웃이 사라진 뒤에도 들어올 수 있어 이쪽이 안전하다.
- **남는 한계는 그대로**: 엔진은 이미 정지 중이면 새 조건을 등록하지 않으므로, 남이 먼저 건 정지 위에서 UI 가 열리면 그쪽이 풀 때 함께 풀린다. 게임모드에 직접 걸면 막을 수 있지만 재평가마다 조건이 쌓여, 순정 경로를 두고 규약(새 정지 주체는 자기 조건을 함께 건다)을 주석으로 남겼다.
