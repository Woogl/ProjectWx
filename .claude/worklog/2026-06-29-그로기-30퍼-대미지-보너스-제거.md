# 그로기 30% 대미지 보너스 제거

## 계획

### 목표
그로기 상태인 적이 받는 최종 피해량 30% 증가 보너스를 제거해, 그로기 상태에서도 평상시와 동일한 피해를 받도록 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxExecCalc_Damage.cpp` | 그로기 배율 적용 for 루프 제거, `WxAbility_Groggy.h` include 제거. `bIsGroggy` 판정은 DP 미가산·Knock 치환에 쓰이므로 유지 | 삭제 |
| `WxAbility_Groggy.h` | `GetDamageTakenMultiplier()` 선언, `DamageTakenMultiplier` 프로퍼티 제거 | 삭제 |
| `WxAbility_Groggy.cpp` | `GetDamageTakenMultiplier()` 정의 제거 | 삭제 |

### 접근 방식
- **기능 완전 제거**: 배율을 1.0으로 중립화하면 죽은 코드가 남으므로, 보너스 메커니즘(프로퍼티·접근자·ExecCalc 적용 분기)을 모두 삭제한다. 보너스는 이 3개 파일에만 존재하며 외부 참조가 없음을 확인했다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `WxExecCalc_Damage.cpp` | 그로기 배율 적용 for 루프 + `WxAbility_Groggy.h` include 제거 | 삭제 |
| `WxAbility_Groggy.h` | `GetDamageTakenMultiplier()` 선언, `DamageTakenMultiplier` 프로퍼티 제거 | 삭제 |
| `WxAbility_Groggy.cpp` | `GetDamageTakenMultiplier()` 정의 제거 | 삭제 |

### 구현·결정과 그 이유
- **배율 중립화 대신 완전 제거**: `DamageTakenMultiplier`를 1.0으로 두면 의미 없는 멤버와 적용 분기가 남는다. 보너스가 이 3개 파일에만 존재하고 외부 참조가 없어, 죽은 코드를 남기지 않도록 메커니즘 전체를 삭제했다.
- **`bIsGroggy` 판정은 보존**: 같은 함수의 그로기 시 DP 미가산 분기와 `ApplyHitReaction`의 Knock 계열 치환에 여전히 필요하므로 유지했다.
