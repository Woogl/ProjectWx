# 상호작용 실행 시 서버측 거리 재검증

## 계획

### 목표
원격 클라가 TargetData로 보낸 상호작용 대상을 서버가 거리 검증 없이 실행하던 신뢰 경계 구멍을 닫는다. 변조 클라가 월드의 임의 원거리 `UWxInteractionComponent` 를 지정해 상호작용하는 것을 차단한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/AbilitySystem/Ability/WxAbility_Interact.cpp` | `ExecuteInteract` 에서 `TryInteract` 호출 전, 아바타↔대상 거리가 사거리 이내인지 검증. 초과 시 무동작 | 수정 |

### 접근 방식
- **검증 위치**: `ExecuteInteract` 는 두 권위 경로(리슨 호스트 직접 실행 / 원격 클라 TargetData 수신)의 공통 실행 지점이고 항상 권위에서만 호출되므로 여기 한 곳에 둔다. 반경 지식(`ScanRadius`)을 이미 소유한 어빌리티가 검증의 주인이며, 컴포넌트 `TryInteract` 의 권위+enabled 게이트는 그대로 둔다.
- **검증식**: 클라 스캔의 sphere-overlap 과 동일 판정 — `중심간 거리 <= ScanRadius + 대상 구 반경(GetScaledSphereRadius)`. 별도 설정 필드·여유 반경은 두지 않는다(단순화 요청).
- **enabled 중복 안 함**: 활성/비활성은 기존 `TryInteract` 의 `bInteractionEnabled` 권위 체크가 막으므로 거리만 보강한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |

| `Source/WxGame/AbilitySystem/Ability/WxAbility_Interact.cpp` | `ExecuteInteract` 에 `TryInteract` 호출 전 거리 검증 추가(early-return 정리 포함) | 수정 |

### 구현·결정과 그 이유
- **거리 검증을 `ExecuteInteract` 한 곳에**: 리슨 호스트 직접 경로와 원격 클라 TargetData 경로가 모두 이 함수를 거치고 항상 권위에서만 호출되므로, 단일 choke point 에서 검증한다.
- **sphere-overlap 동일식**: `DistSquared <= Square(ScanRadius + GetScaledSphereRadius())`. 클라가 후보를 잡은 판정과 정확히 같아 정상 범위 내 상호작용은 통과하고, 범위 밖 임의 대상만 차단한다. `FMath::Square`·`DistSquared` 로 sqrt 회피.
- **여유 반경 미도입**: 단순화 요청에 따라 설정 필드를 추가하지 않았다. 대상 구 반경이 약간의 슬랙을 주며, enabled 게이트는 기존 `TryInteract` 가 담당.

### 계획 대비 달라진 점
- 계획대로(설계 단계에서 이미 설정 필드를 뺀 단순안 확정).

### 후속 과제
- 미검증: 원격 클라 환경에서 경계 부근 예측 데스싱크로 인한 오거부 여부는 실제 멀티 플레이 테스트로 확인 필요. 발생 시 소폭 여유 반경 추가 검토.
