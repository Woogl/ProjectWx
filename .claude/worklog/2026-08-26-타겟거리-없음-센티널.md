# TargetDistance "타겟 없음" 표현을 0 → 무한대 센티널로 교정

## 계획

### 목표
타겟이 없을 때 Blackboard 의 `TargetDistance` 에 0(=코앞)이 기록되어 근거리 비교가 무조건 통과하는 계약 역전을 없앤다. "타겟 없음 = 무한히 멀다" 로 바로잡아, 근거리 비교가 타겟 부재 시 항상 거짓이 되게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Public/WxBlackboardKeys.h` | `ClearTargetDistance` 선언 제거, 센티널 상수 `NoTargetDistance`(float) 선언 추가, Float 키 주석 정정 | 수정 |
| `Plugins/WxAI/Source/WxAI/Private/WxBlackboardKeys.cpp` | `ClearTargetDistance` 정의 제거, `NoTargetDistance` 정의 | 수정 |
| `Plugins/WxAI/Source/WxAI/Private/WxBTService_TargetDistance.cpp` | 타겟 부재 분기에서 Clear 대신 센티널 기록 | 수정 |
| `Plugins/WxAI/Source/WxAI/Public/WxBTService_TargetDistance.h` | 클래스 주석의 "비워(Clear)" 서술 정정 | 수정 |

### 접근 방식
- **센티널은 `TNumericLimits<float>::Max()`**: 엔진의 Float 키에는 Clear 전용 오버라이드가 없어 Clear 가 메모리를 0 으로 밀 뿐이고, 이 키를 읽는 수단은 arithmetic 비교뿐이라 "값 없음" 을 표현할 길이 없다. 큰 값을 쓰면 근거리 비교는 반드시 거짓, 원거리 비교는 참이 되어 한 방향으로 일관되게 읽힌다. Vector 키의 "값 없음" 에 FLT_MAX 를 쓰는 엔진 관례와도 맞는다. `FAISystem::InvalidRange`(-1.f)는 모든 근거리 비교를 통과시켜 지금 버그와 같아지므로 쓰지 않는다.
- **전용 Clear 함수 대신 "상수 + 기존 setter"**: 호출부가 무엇을 쓰는지 그대로 드러나, 이름(Clear)이 실제 동작(0 기록)을 감추는 문제를 없앤다. 이 서비스가 유일한 호출자라 함수를 남기면 데드 코드다.
- **부수 효과**: BT 디버거에서 `3.4e38` 은 한눈에 "타겟 없음" 으로 읽히지만 `0` 은 "타겟이 발밑" 과 구분되지 않는다.
- **원거리 브랜치 게이팅은 이 변경의 몫이 아니다**: 그 역할은 `TargetActor Is Set` 데코가 맡는다 — Object 키는 null 로 "값 없음" 을 실제로 표현하므로 `IsSet` 이 정상 동작한다.
