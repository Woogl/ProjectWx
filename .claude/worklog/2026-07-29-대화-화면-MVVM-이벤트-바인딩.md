# 대화 화면 클릭 처리를 MVVM 이벤트 바인딩으로 이관

## 계획

### 목표
WBP_DialogueScreen 이벤트 그래프가 쥐고 있던 대사 넘기기·창 닫기를 걷어내, 클릭은 MVVM Event 바인딩으로 선언하고 창 수명은 창을 띄운 PlayerController 가 대칭으로 관리하게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Controller/WxPlayerController.h/.cpp` | push 한 대화 창을 보관했다가 대화 종료 시 닫기 | 수정 |
| `Source/WxGame/MVVM/WxViewModel_Dialogue.h/.cpp` | 종료 플래그와 종료 구독 제거, 명령만 남김 | 수정 |
| `Content/UI/Widget/WBP_DialogueScreen.uasset` | 클릭 이벤트 그래프 삭제, Event 바인딩으로 대체 | 수정 |

### 접근 방식
- **클릭은 선언적 배선으로**: 엔진 MVVM 의 Event 바인딩이 위젯 델리게이트를 뷰모델 함수로 직접 잇는다. 뷰에 그래프 로직이 남지 않고, 호출 대상은 C++ 뷰모델의 명령이라 프로그래머가 관리한다.
- **창 수명은 띄운 쪽이**: 대화 창을 띄우는 곳이 PlayerController 이므로 닫기도 같은 자리에서 대칭으로 한다. 종료 신호를 받아 닫으므로 대화가 어떤 경로로 끝나든 창이 남지 않는다.
- **뷰모델은 표시와 명령만**: 닫기 판정을 위해 두었던 종료 플래그를 없애 뷰모델이 상태를 되읽히는 통로가 되지 않게 한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Source/WxGame/Controller/WxPlayerController.h/.cpp` | 띄운 대화 창을 약참조로 보관, 대화 종료 시 닫기 | 수정 |
| `Source/WxGame/MVVM/WxViewModel_Dialogue.h/.cpp` | 종료 플래그·종료 구독 제거, 주석 갱신 | 수정 |
| `Plugins/WxDialogue/.../WxDialogueSessionComponent.h` | 종료 델리게이트 주석의 구독자 표기 정정 | 수정 |
| `Content/UI/Widget/WBP_DialogueScreen.uasset` | 클릭 이벤트 그래프 삭제, MVVM Event 바인딩 추가 | 수정 |
| `Content/UI/Widget/WBP_Ability.uasset` | 같은 방식으로 이관(자기 자신의 On Clicked → 어빌리티 발동) | 수정 |

### 구현·결정과 그 이유
- **클릭을 Event 바인딩으로**: 위젯 델리게이트를 뷰모델 명령에 직접 잇는 엔진 MVVM 기능이라, 뷰에는 배선만 남고 실행되는 코드는 전부 C++ 쪽에 있다. 이벤트 그래프에는 기본 이벤트 스텁만 남았다.
- **닫기를 컨트롤러로**: 창을 띄우는 주체가 이미 컨트롤러이고 종료 신호도 카메라 복귀 때문에 거기서 받고 있어, 여는 곳과 닫는 곳을 한 자리에 모았다. 넘긴 직후 종료 여부를 되읽던 이전 방식과 달리 대화가 다른 경로로 끝나도 창이 닫힌다.
- **뷰모델에서 종료를 들어냄**: 창 수명은 표시 데이터가 아니므로 뷰모델이 알 이유가 없다. 종료 플래그와 그 구독을 지워 뷰모델은 대사 변경만 구독한다.

- **어빌리티 버튼도 같은 방식으로**: WBP_Ability 는 위젯 자신이 버튼이라 이벤트 소스를 자기 자신(self)의 On Clicked 로 잡았다. 엔진이 기존 BP 이벤트와 이 델리게이트를 같은 함수에서 연달아 발행하므로 발동 시점은 그대로다.

### 계획 대비 달라진 점
- 바인딩 행 추가를 사용자 수작업으로 넘기지 않고 에디터 UI 자동화로 직접 마무리했다. 이벤트 경로 프로퍼티는 편집 불가라 데이터 기입은 실패했고, 바인딩 패널에서 대상 필드를 On Clicked 로 고르면 나타나는 Event 전환 버튼을 눌러 생성했다.
- 요청에 따라 WBP_Ability 의 클릭 처리도 같은 방식으로 옮겼다(계획 범위 밖이었음).

### 후속 과제
- 실행 중인 에디터는 DebugGame 바이너리라 이번 C++ 변경이 아직 반영되지 않았다. 재빌드·재시작 후 PIE 로 대사 넘기기와 종료 시 창 닫힘을 확인해야 한다.
- 키보드·패드로 대사를 넘기는 입력은 여전히 없다. 필요해지면 순정 UButton 을 CommonUI 버튼/액션으로 바꾸는 별도 작업.
