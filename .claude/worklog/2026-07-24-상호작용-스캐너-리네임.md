# 상호작용 스캐너 리네임

## 계획

### 목표

`UWxInteractionRegistryComponent`의 "Registry"가 오해를 부른다. 레지스트리는 통상 외부가 자신을 등록하는 수동 컬렉션을 뜻하는데, 이 컴포넌트는 아무도 등록하지 않고 자신이 주기 폴링한다(`ScanAndPush`가 `ScanInterval` 타이머로 `OverlapMultiByChannel`). 실제 역할인 "플레이어 측 스캐너"를 이름에 반영해 `UWxInteractionScannerComponent`로 바꾼다. 동작 변경 없는 순수 명명 정리다.

근거: WxCore 쪽 주석(`WxCollisionChannels.h:18`, `WxInteractable.h:14`)은 이미 이것을 "플레이어 측 스캐너"라 부른다. 리네임 후 그 주석과 클래스명이 일치한다.

### 수정 범위

| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxWorld/.../Public/Interaction/WxInteractionRegistryComponent.h` | `WxInteractionScannerComponent.h`로 리네임 + 클래스명·`.generated.h` include 변경 | 수정(리네임) |
| `Plugins/WxWorld/.../Private/Interaction/WxInteractionRegistryComponent.cpp` | `WxInteractionScannerComponent.cpp`로 리네임 + 메서드 한정자 전면 변경 | 수정(리네임) |
| `Source/WxGame/Controller/WxPlayerController.h` / `.cpp` | 멤버 `InteractionRegistry`→`InteractionScanner`, `GetInteractionRegistry()`→`GetInteractionScanner()`, 서브오브젝트 FName 문자열, 주석 | 수정 |

### 접근 방식

- **`git mv` 후 내용 치환**: 파일 이력을 보존한다. UHT가 `.generated.h`를 파일명 기준으로 재생성하므로 파일명·클래스명 불일치는 빌드에서 즉시 드러난다.
- **산문까지 포함**: 주석 ~19곳의 "레지스트리"를 함께 고친다. 이걸 빼면 주석이 새 클래스명과 어긋나 리네임 목적이 무산된다. WxCore 쪽 두 주석은 이미 "스캐너"라 수정 대상이 아니다.
- **내부 `Scan*` 식별자는 유지**: `ScanAndPush`·`ScanRadius`·`ScanInterval`·`ScanTimerHandle`은 이미 Scan 계열이라 리네임 후 오히려 클래스명과 정합해진다.
- **Core Redirect 불필요**: 사전 조사에서 `.uasset` 참조가 ASCII·UTF-16 양쪽 0건, BP 스냅샷 0건, `BP_PlayerController`의 컴포넌트 디폴트 오버라이드 없음을 확인했다. 따라서 서브오브젝트 FName 문자열을 바꿔도 유실될 디자이너 데이터가 없다.

### 채택하지 않은 이름

- `UWxInteractorComponent` — `IWxInteractable::OnInteracted(AActor* Interactor, ...)`에서 `Interactor`가 이미 "상호작용을 거는 아바타 폰"을 뜻해 같은 시스템 내 용어가 충돌한다.
- `UWxInteractionComponent` — UE 관례상 상호작용 *대상*에 붙는 컴포넌트로 읽히는데, 이 프로젝트의 대상 측은 `IWxInteractable` + 채널 응답이라 방향이 반대로 오해된다.

### 구현·결정과 그 이유

- **`git mv` 후 sed 일괄 치환**: 파일 이력을 보존하면서 ~40곳의 기계적 치환을 한 번에 처리했다. 긴 심볼(`WxInteractionRegistryComponent`)을 먼저 치환해 짧은 심볼(`InteractionRegistry`)이 클래스명 내부를 잘못 건드리는 것을 막았다.
- **산문의 "레지스트리"까지 치환**: 23곳 전부 "스캐너"로 1:1 대응돼 어색한 문장이 없었다. 이걸 남기면 주석이 새 클래스명과 어긋나 리네임 목적 자체가 무산된다.
- **내부 `Scan*` 식별자 유지**: `ScanAndPush`·`ScanRadius`·`ScanInterval`·`ScanTimerHandle`은 리네임 후 오히려 클래스명과 정합해졌다.
- **Core Redirect 미추가**: 사전 조사에서 `.uasset` 참조가 ASCII·UTF-16 양쪽 0건임을 확인했다. 검색 방법론은 대조군(`WxViewModel_InteractionList` → `WBP_InteractionList.uasset` 정상 검출)으로 검증했다.

### 계획 대비 달라진 점

- 계획에 없던 2개 파일에서 산문 참조를 추가 발견해 함께 고쳤다 — `WxCore/WxInteractable.h`(프롬프트 pull 주석), `WxWorld/WxGimmickStateTreeNodes.cpp`(외곽선 소등 주석). 계획 단계에서 `Source/WxGame` 위주로만 grep한 탓이다.
