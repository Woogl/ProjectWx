### 접근 방식
- **함께 삭제**: `GE_BuffATK`/`GC_BuffATK`는 각각 C++ Abstract 클래스(`UWxEffect_BuffATK`/`AWxCueNotify_BuffATK`)의 BP 자식 → C++ 파일과 uasset을 함께 삭제해야 부모 소실 로드 에러가 없다.
- **Config/스냅샷 무변경**: Cue 폴더는 폴더 단위 등록이고 다른 큐가 남음 → ini 무변경. BuffATK 스냅샷 없음 → 정리 불필요. 네이티브 태그라 DefaultGameplayTags.ini 무관.
- **Metamorphose 병행 요청**: 이미 2026-07-16에 제거 완료. 잔재는 `GA_HR_Ultimate.uasset`의 댕글링 참조 1건뿐이며 바이너리라 CLI 편집 불가 → 에디터 수동 정리 후속 과제로 분리.

### 구현·결정과 그 이유
- **C++ + uasset 동시 삭제**: `GE_BuffATK`/`GC_BuffATK`가 각각 Abstract C++ 클래스의 BP 자식이라 함께 지워야 부모 소실 로드 에러가 없다. `git rm`으로 6개 파일 삭제.
- **ini/스냅샷 무변경**: `GameplayCueNotifyPaths`는 폴더 단위 등록이고 Cue 폴더에 다른 큐가 남아 변경 불필요. BuffATK 스냅샷 부재로 정리 불필요.
- **검증**: WxEditor(Development) 빌드 성공(EXIT 0). source 제거로 UHT 재실행, WxCore/WxCombat/WxGame 재빌드·링크 통과 → 코드/태그 참조 잔존 없음 확인. 잔여 텍스트 참조는 본 worklog(제거 기록)뿐. (경고는 전부 엔진 측 deprecation으로 무관.)
