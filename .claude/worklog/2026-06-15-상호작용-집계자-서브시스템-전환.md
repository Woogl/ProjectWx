# 상호작용 집계자: 컴포넌트 → LocalPlayerSubsystem

## 계획

### 목표
플레이어에 컴포넌트를 붙이는 구조가 헷갈려, 집계자를 `UWxInteractionListComponent`에서 부착이 필요 없는 `ULocalPlayerSubsystem`으로 전환한다. 역할(목록 제공)·제약(WxCore·캐릭터 무수정, 선택은 UI)은 동일.

### 수정 범위
| 모듈 | 파일 | 내용 |
|---|---|---|
| `WxWorld` | `Interaction/WxInteractionRegistrySubsystem.h/.cpp` (신규) | ListComponent와 동일 API의 LocalPlayerSubsystem |
| `WxWorld` | `Interaction/WxInteractionListComponent.h/.cpp` (삭제) | 서브시스템이 대체 |
| `WxWorld` | `Interaction/WxInteractionComponent.h/.cpp` (수정) | 캐시·헬퍼를 레지스트리 서브시스템 버전으로(Pawn→LocalPlayer→Subsystem) |
| `WxGame` | `MVVM/WxViewModelResolver_Interaction.cpp` (수정) | 위젯 소유 PC의 LocalPlayer 서브시스템 조회, VM Outer=LocalPlayer |

### 접근 방식
InteractionComponent가 오버랩 시 `Pawn->GetController<APlayerController>()->GetLocalPlayer()->GetSubsystem<UWxInteractionRegistrySubsystem>()`로 로컬플레이어 서브시스템을 찾아 register/캐시. Resolver는 위젯 소유 PC의 LocalPlayer 서브시스템에서 목록을 시드·바인딩. 서브시스템은 자동 생성이라 플레이어에 부착할 게 없음.

### 후속(제외)
- 휠→SetSelectedIndex(UI), WBP_Interact+Resolver 지정(사용자)
- WxAbility_Interact 선택 연동 + 매핑/복제, 기존 월드 위젯 제거

## 완료

### 수정한 파일
| 모듈 | 파일 | 수정 내용 |
|---|---|---|
| `WxWorld` | `Interaction/WxInteractionRegistrySubsystem.h/.cpp` (신규) | ListComponent와 동일 API의 `ULocalPlayerSubsystem` 집계자 |
| `WxWorld` | `Interaction/WxInteractionListComponent.h/.cpp` (삭제) | 서브시스템이 대체 |
| `WxWorld` | `Interaction/WxInteractionComponent.h/.cpp` (수정) | 캐시 `RegisteredRegistry`(서브시스템), `RegisterWithRegistry`가 Pawn→PlayerController→LocalPlayer→Subsystem 경로로 등록. include 추가(LocalPlayer/PlayerController) |
| `WxGame` | `MVVM/WxViewModelResolver_Interaction.cpp` (수정) | 위젯 소유 PC의 LocalPlayer 서브시스템 조회, VM Outer=LocalPlayer |

### 구현·결정과 그 이유
- **집계자를 LocalPlayerSubsystem으로**: 로컬플레이어마다 자동 생성되어 플레이어 BP/C++에 부착이 전혀 필요 없다. "플레이어에 또 컴포넌트?" 혼란 제거. 역할(목록 집계)·API는 이전 ListComponent와 동일.
- **VM Outer=LocalPlayer**: 레지스트리가 LocalPlayer에 살고 폰 리스폰에도 생존하므로, VM 수명 기준을 폰이 아닌 LocalPlayer로.
- 경계·제약 유지: WxCore 무변경, 캐릭터 무수정, 선택은 UI(`SetSelectedIndex`).

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- **사용자(BP/콘텐츠)**: 신규 `WBP_Interact`(HUD 리스트)에 `UWxViewModelResolver_Interaction` 지정, `Entries`→ListView 바인딩, 휠→`SetSelectedIndex`. (플레이어 부착 단계는 사라짐.)
- **C++ 후속**: `WxAbility_Interact` 선택 대상 연동 + 엔트리↔월드 매핑/복제, 기존 대상별 월드 프롬프트 위젯 제거.
