# WxButtonBase 인풋 아이콘 — 디자인 타임 프리뷰

## 계획

### 목표
`TriggeringInputAction`을 지정한 버튼의 인풋 아이콘을 런타임뿐 아니라 **WBP 에디터(디자인 타임)에서도** 자동으로 보여준다. (리플렉션은 배제. 자동 프리뷰를 위해 액션 위젯 서브클래스는 허용하기로 결정.)

### 배경
- 런타임 아이콘은 엔진 `UCommonButtonBase`가 `TriggeringInputAction`으로 이미 자동 표시한다(코드 불필요).
- 디자인 타임엔 `UCommonActionWidget::GetIcon()`이 위젯의 `DesignTimeKey`만 읽고 `InputActions`(=TriggeringInputAction)는 무시한다. 이 분기는 `virtual`이라 서브클래스로 확장 가능하다. 레거시 DataTable 액션은 키가 정적으로 박혀 있어 디자인 타임에도 유도가 가능하다(Enhanced Input은 불가 — 그 경우 조용히 폴백).

### 접근 방식 (세 조각이 맞물림)
- **(a) `UWxActionWidget::GetIcon()` 오버라이드**: `IsDesignTime()`이면 상속 protected `GetInputActionData()`로 `InputActions[0]` 데이터를 얻고, `FCommonInputBase::GetCurrentPlatformDefaults()`(PC=MouseAndKeyboard) 기준 `GetInputTypeInfo().GetKey()`로 표시 키를 구해 `UCommonInputPlatformSettings::TryGetInputBrush()`로 브러시 반환. 실패·비디자인타임이면 `Super::GetIcon()`(런타임 100% 보존).
- **(b) 버튼 디자인 타임 푸시**: 엔진 `UpdateInputActionWidget()`은 `GetGameInstance()` 가드로 디자인 타임엔 `InputActions`를 안 채운다. 그래서 `NativePreConstruct`에서 디자인 타임 한정으로 `SetInputAction`을 직접 밀어 (a)가 그릴 데이터를 준다.
- **(c) WBP 타입 교체**: 공용 베이스 `WBP_Button`의 `InputActionWidget`을 `WxActionWidget`으로 교체하면 이를 파생한 버튼이 모두 커버된다.

### 구현·결정과 그 이유
- **디자인 타임 아이콘은 서브클래스 `GetIcon()` 오버라이드로**: 엔진 디자인 타임 분기는 `DesignTimeKey`만 읽으므로, `virtual GetIcon()`을 상속해 디자인 타임에 `InputActions`에서 직접 해석. 런타임은 `Super`에 위임해 100% 보존.
- **디자인 타임 가시성은 버튼이 직접 반영**: 엔진의 숨김/collapse 로직(`UpdateInputActionWidgetVisibility`/`UpdateActionWidget`)은 전부 런타임 전용이라(가시성 변경이 `!IsDesignTime()` 가드), 디자인 타임엔 `bHideInputAction`·무액션이 반영되지 않았다. 그래서 `NativePreConstruct`에서 `Collapse`/`SelfHitTestInvisible`을 직접 세팅해 디자인 타임=런타임 이격을 제거.

### 계획 대비 달라진 점
- 초기엔 "아이콘 표시"만 구현했으나, `HideInputAction`을 켜도·`TriggeringInputAction`이 없어도 디자인 타임엔 위젯이 안 접히는 문제가 드러나 **가시성 직접 반영**을 추가했다(계획엔 없던 항목).
- **호버 클릭 폴백을 생성자에서 off**: "Click" 텍스트와 Enter 아이콘의 공통 원인은 엔진의 호버 클릭 폴백(`bShouldUseFallbackDefaultInputAction` 기본 true)이 액션 없는 버튼 호버 시 `InputActionWidget`을 DefaultClickAction으로 채우는 것. 엔진이 이 목적으로 제공하는 per-button 스위치(EditAnywhere)를 `UWxButtonBase` 생성자에서 기본 `false`로 두어 텍스트·아이콘 원인을 **한 곳에서** 해결. 엔진 API 범위 내 설정이라 순정 이탈·hack 아님(개별 WBP에서 재활성 가능).
- **증상 가드 제거**: 폴백을 끄기 전 임시로 `RefreshButtonText`에 넣었던 `!TriggeringInputAction.IsNull()` 가드는, 폴백 off 이후 `GetDisplayText`가 액션 없을 때 빈 문자열을 반환(아래 `!IsEmpty()` 검사가 걸러줌)하므로 불필요해져 제거. 근본 수정(폴백 off) 하나만 남김.
