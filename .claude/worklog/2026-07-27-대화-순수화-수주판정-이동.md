# 대화 순수화 — EventTag 제거, 수주 판정을 퀘스트 측 태스크로 이동

## 계획

### 목표
대화 데이터에 실려 있던 퀘스트 지식(`FWxDialogueTableRow.EventTag` → 세션 중계 → PC 브리지 → SendQuestEvent)을 걷어내고, 대화는 "이 NPC 와의 대화가 완주됐다"는 자기 사실만 기록한다. 수주 판정은 퀘스트 ST 의 태스크(Wait Dialogue Completed)가 스스로 한다 — 지정·판정이 전부 퀘스트 데이터에 모인다(볼륨 탑재와 같은 결).

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `WxDialogueTableRow.h` | `EventTag` 삭제 | 수정 |
| `WxDialogueSessionComponent.h/.cpp` | 이벤트 델리게이트·발행 삭제, 대화 상대 유지, 종료 시 완주 통지 | 수정 |
| `WxDialogueComponent.h(.cpp)` | 완주 카운터 + `NotifyDialogueCompleted()` | 수정 |
| `WxDialogueStateTreeNodes.h/.cpp` | `Wait Dialogue Completed` 태스크(FWxActorTarget, 스냅샷 비교) | 신규 |
| `WxDialogue.Build.cs` | StateTreeModule·UniversalObjectLocator 추가 | 수정 |
| `WxPlayerController.h/.cpp` | `HandleDialogueEvent`·바인딩 삭제 | 수정 |
| `WxGameplayTags.h/.cpp` | `Quest_Start` 삭제(소비처 소멸, Quest_Fail 유지) | 수정 |
| `/Game/Quest/ST_Quest_Main1` | Start: Delay→Wait Dialogue Completed(생존자 UOL), 전이 OnEvent→OnStateCompleted | 수정(MCP) |

### 접근 방식
- **사실 기록은 원천에**: 완주 사실의 주체가 (플레이어, NPC) 쌍이므로 대상 NPC 의 정의 컴포넌트에 카운터로 기록 — 퀘스트 지정(NPC UOL)과 정합. v1 싱글/리슨 전제(소유 클라=권위)는 세션 주석에 명시.
- **태스크는 스냅샷 비교**: 탑재 이후의 새 완주만 인정. 총계 판정이면 완료 퀘스트 재탑재 시 게이트 즉시 통과(저널 즉발)라 기각.
- **게이트 원칙 갱신**: 이벤트형 → 태스크 판정형으로 전 퀘스트 통일(볼륨 탑재 → Start 조건 태스크 → InProgress). 판정 단위는 대화 1회 완주, 분기 결말 구분은 종료 행 이름 기록으로 비파괴 확장.
