# FWxStateTreeTask_PlayFx 를 PlaySound·SpawnNiagara 로 분리

## 계획

### 목표
복합 노드 `FWxStateTreeTask_PlayFx`(Niagara+Sound 동시 보유)를 단일 책임 노드 둘 `FWxStateTreeTask_PlaySound`·`FWxStateTreeTask_SpawnNiagara` 로 분리한다. 각 상태가 필요한 FX 만 골라 붙이게 하고, "채워진 것만 재생"이라는 암묵 규칙을 노드 분리로 명시화한다. 의미(초기 진입 침묵·라이브 1회 재생·무틱)는 그대로 유지.

### 수정 범위

|---|---|---|
| `Plugins/WxWorld/Source/WxWorld/Public/Gimmick/WxGimmickStateTreeNodes.h` | `PlayFx` 구조체/InstanceData/섹션 주석 제거, `PlaySound`·`SpawnNiagara` 2종 신설, 상단 개요 주석 PlayFx 줄을 2줄로 교체 | 수정 |
| `Plugins/WxWorld/Source/WxWorld/Private/Gimmick/WxGimmickStateTreeNodes.cpp` | `PlayFx` 구현 제거, `PlaySound`·`SpawnNiagara` 구현 신설(헤더 선언 순서) | 수정 |

### 접근 방식
- **공통 의미 보존**: 두 노드 모두 기존 PlayFx 골격 계승 — `bShouldCallTick=false`, 초기 진입(`!Transition.SourceStateID.IsValid()`)이면 무재생 즉시 `Succeeded`, 라이브 진입에서만 1회 재생. 피어별 로컬 재생이라 멀티캐스트 없음.
- **SpawnNiagara**: InstanceData `{AttachComponent, Niagara}`. AttachComponent 있으면 `SpawnSystemAttached`, 없으면 `SpawnSystemAtLocation`. DisplayName "Wx Spawn Niagara".
- **PlaySound**: InstanceData `{Sound}`. 액터 위치 `PlaySoundAtLocation`. attach 파라미터 신설 없이 기존 동작 충실 유지. DisplayName "Wx Play Sound".
- **배치/순서**: PlayFx 자리(PlayAnimation↔TriggerSpawners 사이)에 PlaySound→SpawnNiagara 순. cpp 정의도 헤더 선언 순서 추종.
- **에셋 영향 없음**: 기존 ST 에셋 중 PlayFx 사용처 없음(바이너리 확인), ST_AlarmConsole 미존재 → 마이그레이션 불필요.

### 구현·결정과 그 이유
- **복합 노드 분리로 단일 책임화**: 한 노드가 "채워진 필드만 골라 재생"하던 암묵 규칙을 노드 경계로 드러냈다. 사운드만/이펙트만 필요한 상태가 절반 빈 노드를 들 필요가 없고, 노드 이름이 곧 효과라 의도가 읽힌다.
- **의미는 100% 계승**: 무틱·초기진입 침묵·라이브 1회 재생·피어별 로컬 재생이라는 발동 FX 의 복원 안전 규칙을 둘 다 그대로 가져갔다. 분리는 데이터 배치만 바꾸고 동작은 바꾸지 않는다.
- **사운드에 attach 미도입**: 기존 PlayFx 의 사운드는 attach 없이 액터 위치 재생이었다. 분리를 핑계로 기능을 늘리지 않고 동작을 충실히 보존했다(필요해지면 그때 추가).
