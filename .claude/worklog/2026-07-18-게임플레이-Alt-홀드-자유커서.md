# 게임플레이 중 Alt 홀드 자유 커서

## 계획

### 목표
게임플레이 중 Left Alt 를 누르는 동안에만 마우스 커서를 띄우고 게임 포커스를 부분 해제한다. UX 는 MMO 식 자유 커서 — 커서 표시 + WASD 이동 유지 + 마우스 카메라(시선) 정지 + HUD 위젯 클릭 가능. Alt 를 떼면 즉시 게임 플레이로 복귀한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCore/.../WxGameplayTags.h` / `.cpp` | `UI_Action_FreeCursor` 태그 선언·정의 | 수정 |
| `Plugins/WxUI/.../WxHUDLayout.h` / `.cpp` | FreeCursor 액션 Pressed/Released 등록 + Handle 에서 입력모드 전환 | 수정 |
| `Config/DefaultInput.ini` | `UI.Action.FreeCursor = LeftAlt` 매핑 추가 | 수정 |

### 접근 방식
- **HUDLayout + CommonUI 액션**: 커서/포커스/입력모드는 CommonUI 도메인이므로, 이미 CommonUI 액션(Inventory·MainMenu)을 처리하는 HUD(UWxHUDLayout)가 FreeCursor 도 소유한다. PC(WxGame)는 관여하지 않는다.
- **press/release 분리**: CommonUI 액션은 `FBindUIActionArgs::KeyEvent` 로 입력 이벤트를 지정하고 `ProcessNormalInput` 이 정확 매칭한다. 같은 액션을 `IE_Pressed`(→ 커서 켬)·`IE_Released`(→ 복원) 2개로 등록해 홀드 구간을 잡는다. 둘 다 `InputMode=Game`; 홀드 중엔 입력모드가 `All` 이라 Released 는 All 와일드카드로 매칭된다.
- **입력 설정 전환**: Handle 에서 ActionRouter 의 `SetActiveUIInputConfig` 로 `All`+`NoCapture`+`bIgnoreLookInput`(커서·이동유지·시선정지) ↔ `Game`+`CapturePermanently`(복원) 를 전환한다.
- **키 매핑**: Enhanced Input IA 애셋이 아니라 CommonUI Input Settings(ini)에 `UI.Action.FreeCursor=LeftAlt` 로 등록한다. Inventory=B·MainMenu=Escape 와 동일 방식.

### 구현·결정과 그 이유
- **HUDLayout 방식 채택**: 초기엔 PlayerController+Enhanced Input(방식 A)으로 구현했으나, 커서/포커스/입력모드는 CommonUI(UI) 관심사라 HUD 로 이관해 PC 결합을 제거했다.
- **press/release 분리 등록**: CommonUI 액션의 `KeyEvent` 로 `IE_Pressed`·`IE_Released` 를 나눠 등록해 "누르는 동안" 홀드 구간을 잡는다. 홀드 중엔 입력모드가 `All` 이라 Released 는 All 와일드카드로 매칭된다.
- **All 모드 선택**: `Menu` 는 게임 입력을 release 까지 차단해 갇힘·이동정지 위험이 있다. `All`+`NoCapture`+`bIgnoreLookInput` 으로 커서 표시·이동 유지·시선 정지를 모두 만족한다.
- **HUD 버튼 클릭 무결성(엔진 검증)**: 마우스 포인터는 입력모드와 무관하게 Slate 로 위젯에 직접 가고, `NoCapture` 라 빈 영역 클릭도 게임 액션으로 새지 않는다. 단 현재 HUD 엔 클릭 버튼이 없어 토대에 해당한다.

### 계획 대비 달라진 점
- 처리 위치를 방식 A(PlayerController) → 방식 B(HUDLayout)로 전환(사용자 요청). PC 는 원복.

### 후속 과제
- **빌드 검증 미완료**: Live Coding 충돌(에디터 실행 중)로 컴파일 확인을 못 했다. 사용자 요청으로 미검증 상태로 푸시함. 에디터 재시작 후 컴파일·인게임 동작 검증이 필요하다.
- `DefaultInput.ini` 키 매핑은 에디터 재시작 후 반영된다.
- 이름은 `FreeCursor` 로 확정(대안 CursorMode/MouseMode 논의 후 유지).
