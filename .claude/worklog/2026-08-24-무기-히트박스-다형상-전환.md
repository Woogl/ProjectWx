# 무기 히트박스 다형상 전환

## 계획

### 목표
무기 히트 판정을 C++ 고정 캡슐 하나에서, 무기 BP에 디자이너가 직접 부착한 임의 개수의 형상 컴포넌트(박스·캡슐·구)로 전환한다. 참고 문서(Hitbox Rank and Group)의 저작 방식을 채택하되 Rank 우선순위 축은 도입하지 않고, Group의 역할(한 스윙에 대상당 1회)은 기존 피격 기록이 무기 전체 = 단일 그룹으로 이미 수행하므로 그대로 둔다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/Weapon/WxWeaponBase.h` | `HitCollision` 서브오브젝트 제거, `HitShapes` 배열 도입, 멤버·주석 갱신 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/Weapon/WxWeaponBase.cpp` | 형상 수집·콜리전 강제·다형상 스윕으로 전환 | 수정 |

### 접근 방식
- **형상 수집**: `PostInitializeComponents`에서 무기에 부착된 모든 `UShapeComponent`를 수집한다. 무기에 부착된 형상 컴포넌트는 전부 히트박스로 간주하는 것이 계약이다. 수집한 각 형상에 콜리전 구성(비활성 시작, ObjectType=`ECC_WxAttack`, 전 채널 Ignore + Pawn Overlap, 오버랩 바인딩)을 코드가 강제하므로 디자이너는 형상과 트랜스폼만 저작한다.
- **공격 창 on/off**: 기존 레퍼런스 카운팅과 대미지 행 선설정 순서를 유지한 채, 콜리전 켜고 끄기만 전 형상 루프로 바꾼다. 첫 활성화 시 형상별 직전 위치 배열을 현재 위치로 초기화한다.
- **틱 스윕**: 공통 쿼리 파라미터를 한 번 만들고, 형상별로 엔진 순정 `GetCollisionShape()`가 주는 스케일 반영 형상으로 직전 위치→현재 위치를 스윕한다. 형상 타입 분기가 필요 없다. 히트는 기존 공통 진입점으로 합류해 형상 간 중복도 기존 검사에 걸린다.
- **오버랩 핸들러**: 최근접점 폴백 기준을 제거된 고정 캡슐 대신 파라미터로 들어오는 해당 형상 컴포넌트 위치로 바꾼다.
- **에셋(BP_Katana)**: 네이티브 캡슐 제거로 BP가 오버라이드한 기존 값은 소실된다. 에디터가 살아 있으면 제거 전 MCP로 값을 읽어 보고에 남기고, 새 형상 부착은 사용자가 뷰포트에서 직접 저작한다(박스는 BoxComponentVisualizer 핸들 활용).
- **유지**: ANS→BeginAttack/EndAttack 흐름, 스윙당 1회 중복 방지, Overlap+Sweep 병용, 두 경로의 대상 기준 차이(별건), 투사체·장착 구조.

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Public/Weapon/WxWeaponBase.h` | 고정 캡슐 서브오브젝트 제거, 형상 배열·직전 위치 배열 도입, 수집 오버라이드 선언, 오버랩 핸들러 개명, 계약 주석 갱신 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Private/Weapon/WxWeaponBase.cpp` | 형상 수집·콜리전 강제, 공격 창 on/off 루프화, 형상별 틱 스윕 전환, 오버랩 폴백 기준 교체 | 수정 |

### 구현·결정과 그 이유
- **수집 시점은 컴포넌트 초기화 직후**: BP가 추가한 컴포넌트가 전부 생성된 뒤이면서 게임 시작 전이라, 여기서 한 번 수집하고 콜리전 구성을 코드가 강제하면 저작 실수가 원천 차단된다.
- **형상 타입 분기 없음**: 스윕 형상은 엔진 순정 `GetCollisionShape()`가 스케일 반영으로 만들어 주므로 박스·캡슐·구가 한 경로를 탄다.
- **직전 위치는 형상별 평행 배열**: 스윕 시작점이 형상마다 다르기 때문. 첫 활성화 때 현재 위치로 초기화하는 기존 계약(0 거리 첫 스윕)을 형상별로 유지했다.
- **Group·Rank**: 참고 문서의 Group 역할(한 스윙에 대상당 1회)은 기존 피격 기록이 무기 전체 = 단일 그룹으로 이미 수행해 그대로 두었고, Rank 우선순위 축은 도입하지 않았다(사용자 결정).
- **BP_Katana 기존 캡슐 값(저작 참고)**: 반지름 8, 반높이 60, GripPoint 기준 위치 (-10, 3, 40), 회전·스케일 기본값.
