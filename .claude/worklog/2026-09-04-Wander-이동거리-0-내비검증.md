# Wander: 이동 거리 0에서 내비 검증이 무력해지는 문제 수정

## 계획

### 목표
`UWxBTTask_Wander`는 원시 입력으로 움직이므로 걸어갈 구간이 내비메시 위인지 `NavigationRaycast`로 직접 검증하는데, 검증 길이인 `TravelDistance`가 0이면 길이 0 레이가 막힘으로 오지 않아 8방향이 전부 무검증 통과한다. 배회 도중 속박이 풀리면 검증되지 않은 방향으로 내비메시를 벗어나므로, 거리가 0이면 방향을 고르기 전에 실패시킨다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxAI/Source/WxAI/Private/WxBTTask_Wander.cpp` | `TravelDistance` 산출 직후 `IsNearlyZero` 가드 추가, 널 가드 위에 잘못 붙어 있던 거리 주석을 새 가드로 이동 | 수정 |

### 접근 방식
- **거리 한 곳만 본다**: `TravelDistance = GetMaxSpeed() * 배율 * Duration` 이 0이 되는 경로는 `Movement` 널 외에도 `MOVE_None`(엔진이 0 반환), SPD 0 속박 GE, `Duration = 0` 저작, `MoveSpeedMultiplier = 0` 저작이 있다. 원인별 가드를 두지 않고 결과값 하나를 검사해 전부 막는다. `WxBTTask_Wander.cpp:40` 주석이 원래 약속했던 가드가 이것이며, 구현이 널 검사에 그쳐 있었다.
- **`Failed` 반환**: 이 태스크는 이미 fail-closed 정책이다(내비메시 없음·8방향 전부 막힘·`Directions == 0` 모두 `Failed`로 상위 폴백에 넘김). "검증할 수 없으니 배회하지 않는다"는 같은 정책의 연장이라 트리가 이미 처리한다.
- **최소 거리 클램프는 버린다**: 속박이 풀린 뒤 실제 이동 거리는 Execute 시점에 알 수 없어, 임의 최소값으로 검증해도 그 너머를 보증하지 못한다.

엔진 소스(UE 5.8)로 확인한 전제:
- `UCharacterMovementComponent::GetMaxSpeed()` 가 `MOVE_None` 에서 0을 반환한다 (`CharacterMovementComponent.cpp:3602-3605`).
- `UNavigationSystemV1::NavigationRaycast` 는 내비 데이터가 없을 때만 기본값 `bRaycastBlocked = true` 로 오고(`NavigationSystem.cpp:2292`), 데이터가 있으면 `NavData->Raycast` 에 그대로 위임한다 — 길이 0 레이를 막힘으로 만들어 주는 장치가 없다.

### 구현·결정과 그 이유
- **원인이 아니라 결과값을 검사한다**: `MOVE_None`·속박 GE·`Duration 0`·`MoveSpeedMultiplier 0` 은 원인이 다르지만 모두 `TravelDistance == 0` 으로 수렴한다. 원인별 가드를 늘리면 새 원인이 생길 때마다 빠뜨리므로, 레이 길이로 쓰이는 값 자체를 한 번 본다. 원래 주석이 약속했던 가드가 이것이고 구현만 널 검사에 머물러 있었다.
- **널 가드는 그대로 둔다**: 역할이 다르다(널 역참조 방지). 합치면 이중 삼항이 되어 오히려 읽기 나빠진다.
- **`IsNearlyZero`**: `<= 0.f` 로도 동작하지만(세 인자 모두 음수 불가), 코드베이스 관용구이고 극소 배율까지 걸린다.
- **주석에 "지금 못 움직인다고 무해한 것이 아니다" 를 남긴 이유**: 이 가드는 없어도 당장은 증상이 없어, 근거를 적어 두지 않으면 불필요한 코드로 오판해 지우기 쉽다.

### 후속 과제
- 에디터 실측 미수행 — 재현에 속박 GE·`MOVE_None` 상태의 적 배회와 내비메시 경계 배치가 필요하다. 컴파일과 코드 경로 검토까지만 했다.
- `Duration = 0` 저작 시 기존 "즉시 Succeeded(무동작)" 가 `Failed` 로 바뀐다. 의도한 변화이나, 실제 BT 에셋에 `Duration = 0` 인 Wander 노드가 있으면 분기 흐름이 달라지므로 확인이 필요하다.
- 리뷰 1번(Patrol·Wander 감속 GE 부여/제거 중복)은 이번 범위 밖으로 남아 있다.
