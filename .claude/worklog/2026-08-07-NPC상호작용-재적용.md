# EnableNpcInteraction 을 머무는 태스크로 — 스트리밍 대상 재적용

## 계획

### 목표
NPC 상호작용 토글이 대상을 진입 시 한 번만 해석해, 그 순간 셀이 언로드면 잠금/해제가 영영 적용되지 않고 상태 유지 중 스트리밍 아웃→인 되면 적용분이 사라진다. 대상의 스트리밍 상태와 무관하게 그 상태에 머무는 동안 항상 적용되게 한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/.../Public/WxDialogueStateTreeNodes.h` | 적용 기록 필드·Tick 선언 추가, NPC 전방 선언, 문서 주석 갱신 | 수정 |
| `Plugins/WxDialogue/.../Private/WxDialogueStateTreeNodes.cpp` | 진입을 Running 으로 바꾸고 매 틱 재해석·재적용, 경고를 진입 1회로 | 수정 |
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | SpawnActor 완료 판정 문구에 조건 명시(동작 변경 없음) | 수정 |

### 접근 방식
- **MarkIndicators 와 같은 규약**: 진입 후 Running 을 유지하며 매 틱 대상을 다시 해석한다.
- **적용 기록**: 실제로 토글을 걸어 준 NPC 를 약참조로 기록하고, 재해석 결과가 기록과 다를 때만(첫 해석·스트리밍 재로드로 새 액터 생성) 적용한다. 같으면 아무것도 하지 않아 매 틱 콜리전을 다시 쓰지 않는다. 미해석이면 기록을 비워 다음 로드 때 재적용되게 한다.
- **완료 판정 무관**: 판정에서 빠져 있으므로(bConsideredForCompletion=false) Running 으로 바뀌어도 상태 완료에는 영향이 없다.
- **경고 정책 분리**: 미해석(스트리밍 아웃)은 정상 상황이라 침묵하고, 진입 시 1회만 남긴다 — 빈 로케이터(지정 누락)와 해석은 되는데 NPC 가 아닌 경우.
- **되돌리기 없음**: 잠금은 월드에 남는 변경이라는 기존 설계를 유지하므로 ExitState 는 추가하지 않는다.

### 함께 확인한 것(정정)
- `SetQuestTitle` 이 완료 판정에 참여하는 것은 의도다 — 자식을 둔 상태에 홀로 얹히므로 빼면 판정 태스크가 0개가 되어 형제의 완료 비트를 물려받는다. 앞선 보고를 정정하고 그대로 둔다.
- `SpawnActor` 도 같은 이유로 코드 기본값을 바꾸지 않는다. 대기 태스크와 같은 상태에 얹힐 때만 빼야 하므로 헤더 문구에 조건만 명시한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxDialogue/.../Public/WxDialogueStateTreeNodes.h` | 적용 기록 필드·Tick 선언·NPC 전방 선언 추가, 문서 주석을 머무는 태스크로 갱신 | 수정 |
| `Plugins/WxDialogue/.../Private/WxDialogueStateTreeNodes.cpp` | 재해석·재적용 헬퍼 추가, 진입을 Running 으로, 경고를 조립 오류 한정 1회로, 판정 제외를 에디터 전용 가드로 감쌈 | 수정 |
| `Plugins/WxWorld/.../Public/Gimmick/WxGimmickStateTreeNodes.h` | SpawnActor 완료 판정 문구에 조건 명시 | 수정 |

### 구현·결정과 그 이유
- **적용 여부를 액터 동일성으로 판정**: NPC 쪽에 현재 상태를 물을 창구가 없고, 매 틱 콜리전을 다시 쓰는 것도 낭비다. 재로드되면 액터가 새로 만들어져 포인터가 달라지므로, 걸어 준 대상을 약참조로 기억해 두면 "다시 걸어야 하는 순간"이 그대로 드러난다.
- **미해석 시 기록을 비움**: 스트리밍 아웃된 동안 기록을 남겨 두면 같은 주소에 다른 액터가 들어왔을 때 이미 적용한 것으로 오인할 수 있다.
- **경고를 조립 오류로 한정**: 매 틱 재시도하는 구조에서 미해석까지 경고하면 로그가 폭주하고, 스트리밍 아웃은 애초에 정상 상황이라 알릴 것이 없다. 대신 진입 시 빈 로케이터와 NPC 아님을 갈라 남겨 진단은 오히려 또렷해졌다.
- **판정 제외를 `WITH_EDITORONLY_DATA` 로 감쌈**: 엔진이 그 플래그를 에디터 전용 데이터로 선언해 두어 가드가 없으면 비에디터 빌드에서 컴파일이 깨진다(WxQuest 는 이미 감싸 두었다). 계획 밖이지만 같은 줄을 건드리는 김에 맞췄다.

### 계획 대비 달라진 점
- 위의 에디터 전용 가드 한 줄이 추가됐다. 그 외 계획대로.

### 후속 과제
- PIE 실측 미수행: NPC 셀이 언로드된 채 시작해도 로드 순간 잠금이 걸리는지, 멀리 벗어났다 돌아와도 유지되는지.
