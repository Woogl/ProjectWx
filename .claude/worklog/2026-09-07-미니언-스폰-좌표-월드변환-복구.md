# 미니언 스폰 좌표 월드 변환 복구

## 계획

### 목표
`UWxAnimNotify_SpawnMinion` 이 소환자 로컬 오프셋을 월드로 변환하지 않고 그대로 넘겨, 소환물이 소환자 앞이 아니라 항상 월드 절대 좌표 `(200, 0, 0)` 에 나타나는 회귀를 고친다. 커밋 `a20c76af` 에서 프로퍼티를 `FVector SpawnOffset` → `FTransform LocalSpawnOffset` 으로 바꾸며 변환 한 줄이 함께 사라진 것이 원인이다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxCombat/Source/WxCombat/Private/AnimNotify/WxAnimNotify_SpawnMinion.cpp` | `Notify` 에서 `LocalSpawnOffset` 을 소환자 트랜스폼과 합성해 월드 트랜스폼으로 넘긴다 | 수정 |
| `Plugins/WxCombat/Source/WxCombat/Public/Minion/WxMinionSubsystem.h` | `SpawnMinion` 의 `SpawnTransform` 이 월드 기준임을 명시 | 수정 |

### 접근 방식
- **합성은 호출자에서**: 서브시스템의 `SpawnTransform` 은 월드 계약을 그대로 둔다. 형제 격인 `WxAnimNotify_SpawnProjectile` 도 노티파이가 소켓 위치로 월드 트랜스폼을 만들어 넘기는 같은 모양이다.
- **엔진 순정 로컬→월드 합성**: `LocalSpawnOffset * Owner->GetActorTransform()` 로 위치·회전을 한 번에 맞춘다. `FVector` 시절과 달리 오프셋 회전이 소환자 방향 기준으로 반영되는데, 이는 `a20c76af` 가 노린 기능이다.
- **이름과 계약의 충돌을 주석으로 못 박기**: 이번 회귀는 로컬 트랜스폼을 월드 자리에 넘겨서 생겼으므로 서브시스템 헤더에 기준을 남긴다.
- **건드리지 않는 것**: 상한·로스터·태그 발행 로직, 충돌 보정, `LocalSpawnOffset` 기본값.

### 구현·결정과 그 이유
- **합성을 노티파이에 둠**: 서브시스템은 받은 트랜스폼을 그대로 월드 스폰에 쓰는 얇은 창구로 두는 편이 투사체 쪽과 결이 같고, 로컬 기준을 무엇으로 잡을지는 노티파이가 정할 문제다.
- **트랜스폼 곱 한 번으로**: 위치만 변환하고 회전을 따로 얹으면 오프셋 회전이 소환자 방향과 어긋난다. 상대 트랜스폼을 월드로 올리는 엔진 표준 형태를 그대로 써서 위치·회전을 한 번에 맞췄다.
- **주석으로 기준 명시**: 회귀가 로컬 값을 월드 자리에 넘겨 생긴 만큼, 두 이름이 마주치는 지점에 기준을 남겨 재발을 막았다.
