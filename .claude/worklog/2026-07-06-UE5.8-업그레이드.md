# UE 5.7 → 5.8 엔진 버전 업그레이드

## 계획

### 목표
프로젝트를 UE 5.7에서 로컬에 설치된 UE 5.8로 이전해 최신 엔진 기반으로 개발을 계속한다. 코드/빌드 이전까지만 진행하고, 애셋 재저장(비가역)은 사용자 확인 후 별도 진행한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Wx.uproject` | EngineAssociation "5.7" → "5.8" | 수정 |
| `Source/Wx.Target.cs` | BuildSettingsVersion.V6 → V7, IncludeOrderVersion Unreal5_7 → Unreal5_8 | 수정 |
| `Source/WxEditor.Target.cs` | 위와 동일 | 수정 |

### 접근 방식
- **버전 참조 일괄 최신화**: 버전 참조는 위 3곳뿐(Config·.uplugin·.Build.cs에는 버전 고정 없음). 기존 5.7 이전 때와 같이 엔진 버전과 빌드 설정(V7=Latest, Unreal5_8=Latest)을 함께 최신으로 맞춘다.
- **재생성·검증**: EngineAssociation 변경 후 프로젝트 파일을 5.8 UBT로 재생성하고 WxEditor(Development)를 빌드한다. V7에서 ReturnType/Dangling/UnreachableCode 경고가 Error로 승격되므로, 이에 걸리는 코드와 5.8 API 변경분은 빌드 에러 기준으로 수정한다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Wx.uproject` | EngineAssociation 5.7 → 5.8 | 수정 |
| `Source/Wx.Target.cs` | BuildSettingsVersion V6 → V7, IncludeOrderVersion Unreal5_7 → Unreal5_8 | 수정 |
| `Source/WxEditor.Target.cs` | 위와 동일 | 수정 |
| `Plugins/WxBlueprintSnapshot/.../WxBlueprintSnapshotExporter.cpp` | 5.8 FJsonObject 키 타입 변경 대응 (2곳) | 수정 |
| `Plugins/WxBlueprintSnapshot/.../WxBlueprintSnapshotModule.cpp` | GetObjectsWithOuter의 deprecated bool 인자를 EGetObjectsFlags로 교체 | 수정 |

### 구현·결정과 그 이유
- **JSON 키 타입 변경 대응**: 5.8에서 FJsonObject의 키가 FString에서 UE::FSharedString(공유 문자열)으로 바뀌어 스냅샷 정렬 코드 2곳이 컴파일 에러. Contains 호출은 역참조로 임시 FString을 만들어 넘기고, KeySort는 투명 비교자(TLess<>)로 바꿔 새 키 타입의 자체 비교(FString과 동일하게 대소문자 무시)를 쓰게 했다. 동작 변화 없음.

### 계획 대비 달라진 점
- 5.8 API 변경에 따른 코드 수정이 WxBlueprintSnapshot 1개 파일에 그침. V7 경고 승격(ReturnType/Dangling/UnreachableCode)에 걸린 코드는 없었음.

### 후속 과제
- 에디터에서 애셋 재저장 시 5.8 포맷으로 업그레이드됨(비가역, 5.7에서 못 엶) — 에디터 실행·확인은 별도 진행
