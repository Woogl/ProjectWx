# UWxButtonBase 상태별 텍스트 스타일 적용

## 계획

### 목표
`WBP_Button` 사용처에서 호버/클릭 시 폰트(텍스트 스타일)가 안 바뀌던 문제를 고친다. 원인은 스톡 `UCommonButtonBase`가 상태별 텍스트 스타일을 계산·발행만 하고 실제 적용은 위젯 소유자 몫인데(스톡엔 TextBlock 없음), TextBlock을 소유한 `UWxButtonBase`가 그 적용 훅을 비워둔 것. `NativeOnCurrentTextStyleChanged`를 오버라이드해 현재 텍스트 스타일을 TextBlock에 적용한다.

### 수정 범위
| 파일 | 수정할 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/Widget/WxButtonBase.h` | `NativeOnCurrentTextStyleChanged()` override 선언(UCommonButtonBase interface 블록) | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxButtonBase.cpp` | `Super` 호출 후 `TextBlock->SetStyle(GetCurrentTextStyleClass())` | 수정 |

### 접근 방식
- 엔진은 상태 변화(호버/프레스/선택/활성)마다 `NativeOnCurrentTextStyleChanged`를 호출하지만 본체는 BP 이벤트만 발행한다. 이를 오버라이드해 `GetCurrentTextStyleClass()`(상태별 계산 결과)를 `TextBlock`(WxButtonBase 소유)에 `SetStyle`로 적용한다.
- `TextBlock`은 `BindWidgetOptional`이라 null 가드. cpp 정의는 헤더 선언 순서대로 `UpdateInputActionWidget` 뒤에 둔다.

## 완료

### 수정한 파일
| 파일 | 수정한 내용 | 구분 |
|---|---|---|
| `Plugins/WxUI/Source/WxUI/Public/Widget/WxButtonBase.h` | `NativeOnCurrentTextStyleChanged()` override 선언 | 수정 |
| `Plugins/WxUI/Source/WxUI/Private/Widget/WxButtonBase.cpp` | `Super` 호출 후 `TextBlock->SetStyle(GetCurrentTextStyleClass())`(null 가드) | 수정 |

### 구현·결정과 그 이유
- **소유자에서 적용**: 스톡 `UCommonButtonBase`엔 TextBlock이 없어 상태별 텍스트 스타일을 계산·발행만 하고 적용은 하지 않는다(내장 위젯은 `InputActionWidget`뿐). TextBlock을 도입한 `UWxButtonBase`가 소유자이므로 여기서 `GetCurrentTextStyleClass()`를 `SetStyle`로 적용하는 게 스톡 설계 의도와 맞물린다. 상속받는 모든 버튼에 한 번에 적용된다.
- **cpp 배치**: 헤더 선언 순서대로 `UpdateInputActionWidget` 뒤에 정의.

### 계획 대비 달라진 점
- 계획대로.

### 후속 과제
- 에디터/PIE에서 호버·클릭 시 폰트가 `TextStyle_Small`↔`TextStyle_Small_Selected`로 전환되는지 육안 확인(컴파일은 통과).
- (부수 확인) 이번 풀 빌드가 성공하여, 직전 세션에 미검증 푸시했던 디자인타임 EI 프리뷰 변경(WxUI)도 컴파일 통과가 확인됨.
