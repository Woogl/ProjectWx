# 컷신 멤버 상태 정리

## 계획

- 승인된 범위: 로컬 활성/재생 플래그를 Idle / Preparing / Playing 단계 하나로 통합한다.
- 로컬 재생 자원, 서버 실행 상태, 서버 복원 상태를 역할별 구조체로 묶는다.
- 시간 배율과 관련성 복원 여부는 TOptional 값의 존재 여부로 표현한다.
- 네트워크 복제 형식과 공개 API, 재생/완료/취소 순서, 실패 처리, 두 대기 목록의 역할을 유지한다.
- 변경 전후 Development 빌드와 상태 전이/복원 순서 대조로 검증한다. 임시 테스트 코드를 추가하지 않는다.

## 완료

- 로컬 재생을 FWxSkillCutsceneLocalPlayback으로 묶고, bLocalActive/bLocalPlaying을 EWxSkillCutsceneLocalPhase(Idle/Preparing/Playing) 하나로 통합했다.
- 예약·요청 배율·서버 시작 시각은 FWxSkillCutsceneServerExecution, 배율·관련성·무적 효과의 복원 정보는 FWxSkillCutsceneServerRestore로 묶었다. 배율/관련성 복원 여부 플래그 2개를 TOptional의 IsSet/Reset으로 대체했다.
- 컴포넌트 직접 상태 멤버는 23개에서 8개로 정리했다. 복제 State, 재생 대기 목록, 완료 통지 대기 목록과 중복 수신 방지 ID는 별도로 유지한다.
- LocalPlayback과 그 안의 Session/SequenceActor에 UPROPERTY를 유지해 강한 UObject 참조의 GC 추적을 보존했다. 서버 상태는 기존과 같은 약한 참조만 포함한다.
- 전이 및 정리 순서 대조: Preparing 진입 → Playing 진입 → 시퀀스 정지/복원 → 메시 틱 복원 → 로드 핸들 해제 → Idle → 완료 통지. 서버 복원 순서도 배율 → 무적 효과 → 관련성으로 유지했다.
