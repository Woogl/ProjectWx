# Finisher 피해 노티파이 복구

## 계획

- `AM_Finisher`에 누락된 `Event.AbilityAction.ApplyFinisherDamage` 노티파이를, 기존 `AM_BackstabFinisher`의 피해 이벤트 시점을 기준으로 추가한다.
- `GA_Finisher`가 사용하는 두 변형 공격 몽타주에 해당 이벤트가 존재하는지 확인한다.
- WxEditor Development 빌드와 에셋 검증으로 피해 이벤트 전송 경로를 확인한다.

## 완료

- `AM_Finisher`에 누락된 `Event.AbilityAction.ApplyFinisherDamage` 노티파이를 1.121초 지점에 추가했다.
- 뒤잡 몽타주의 설정된 노티파이 객체를 복제해 같은 이벤트 태그와 동작을 보존했다.
- 저장된 `AM_Finisher` 에셋에서 피해 이벤트 태그와 `UWxAnimNotify_ExecuteAbilityAction` 참조를 확인했다.
- 일회성 에셋 복구 도구를 제거한 뒤 `WxEditor Win64 Development` 빌드에 성공했다.
