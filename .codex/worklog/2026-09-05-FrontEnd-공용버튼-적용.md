# FrontEnd 공용 버튼 적용

## 계획

- 사용자 지정 WBP_Button으로 FrontEnd의 캐릭터, 두 레벨, 입장 버튼을 교체한다.
- 공용 버튼의 ButtonText, OnButtonBaseClicked, 선택 상태를 사용하고 기존 선택·입장 동작을 유지한다.
- Blueprint 컴파일, 선택 및 두 맵 입장, Menu 입력 상태, WxEditor Development 빌드를 검증한다.

## 완료

- WBP_FrontEnd의 CharacterButton, CombatButton, OpenWorldButton, EnterButton을 WBP_Button_C로 교체했다. 공용 버튼 에셋과 C++ 클래스는 수정하지 않았다.
- ButtonText 및 OnButtonBaseClicked를 사용한다. 선택 표시는 SetIsSelected, 해제는 ClearSelection으로 처리한다.
- 최초 저장은 실행 중 에디터의 파일 점유로 실패했으며 사용자 에디터 종료 후 저장 완료했다.
- Blueprint 경고 포함 컴파일 성공. 공용 버튼 HandleButtonClicked부터 이벤트 연결, 선택 순서, 레벨 재선택/이전 선택 해제, 미선택 입장 차단, 중복 입력 차단을 검증했다.
- RenderOffscreen PIE에서 LV_DevCombat와 LV_OpenWorld에 BP_Player로 도착하고 입력 복원을 확인했다. 초기/재진입 Menu / NoCapture 및 커서 표시 확인. 물리 마우스 입력 자체는 별도다.
