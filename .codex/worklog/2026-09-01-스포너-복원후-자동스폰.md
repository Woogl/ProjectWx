# 스포너 복원 후 자동 스폰

## 계획

- `IWxSavable`에 LSP의 `PostRestoreLevel`을 그대로 전달하는 기본 no-op 훅을 추가하고, 기존 `FWxSaveModule::HandlePostRestoreLevel()`에서 해당 레벨의 Savable 액터에 전달한다.
- `AWxSpawner`의 Auto Spawn을 `BeginPlay()`와 개별 속성 복원 후처리에서 제거하고, 레벨 속성과 LSP 런타임 액터 복원이 끝난 뒤에만 `SpawnTarget()`을 호출한다.
- `SpawnTarget()`의 처치 상태·기존 인스턴스 사전 판정은 유지해 불필요한 생성을 막는다.
- `AWxEnemyCharacter::OnSpawnedBy()`에서는 처치 상태 검사, 중복 검색, `Destroy()`를 제거하고 스포너 연결과 attachment만 담당하게 한다.
- `bIsKilled`, Manual Spawn, 명시적 `Respawn()` 동작은 유지한다.
- 새 게임·생존 적 복원·처치 적 복원·스트리밍 재진입·Manual 모드의 판정 경로를 정적으로 점검하고 UE 5.8 `WxEditor Development Win64` 빌드로 검증한다.

## 완료

- `IWxSavable::OnPostRestoreLevel()` 기본 no-op 훅을 추가하고, 기존 `FWxSaveModule::HandlePostRestoreLevel()`이 참조 복원 완료 후 해당 레벨의 Savable 액터에 전달하도록 했다. 콜백 중 스폰으로 `ULevel::Actors`가 바뀌어도 안전하도록 대상은 먼저 약참조 배열로 수집한다.
- `AWxSpawner`의 Auto Spawn을 `BeginPlay()`와 개별 속성 복원 후처리에서 제거하고, LSP가 레벨 상태와 런타임 액터 복원을 완료한 뒤에만 `SpawnTarget()`을 호출하도록 옮겼다.
- `SpawnTarget()`의 `bIsKilled`, 비영속 추적 액터, 복원 attachment 사전 검사를 유지해 새 액터를 만들기 전에 생성을 건너뛴다.
- `AWxEnemyCharacter::OnSpawnedBy()`의 처치·중복 검사와 `Destroy()`를 제거하고 스포너 참조 설정과 attachment만 남겼다.
- `AWxSpawner::BeginPlay`, `AWxSpawner::OnSaveRestored`, `OnSpawnedBy()` 사후 제거 로그, `bHasSpawned`, `AdoptSpawnedActor`, `SetOwner(Spawner)` 잔존 참조와 변경 파일의 whitespace 오류가 없음을 정적으로 확인했다.
