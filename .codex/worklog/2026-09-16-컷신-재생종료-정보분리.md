# 컷신 재생 및 종료 정보 분리

## 계획

- 승인된 범위: 재생 정보(Id/Sequence/Avatar/Origin/Duration), 복제 스냅샷(재생 정보+Phase), 종료 정보(Id/Avatar/bCancelled)를 분리한다.
- 시작 RPC와 로컬 재생 목록에는 재생 정보, 종료 RPC와 완료 대기 목록에는 종료 정보만 사용한다.
- 재생·완료·취소 및 참조 갱신 순서를 유지하고 Development 빌드로 검증한다.

## 완료

- FWxSkillCutsceneSession(재생 정보 5개), FWxSkillCutsceneState(Session+Phase), FWxSkillCutsceneCompletion(Id/Avatar/bCancelled)으로 분리했다.
- 시작 RPC와 로컬 재생/대기 목록은 Session, 종료 RPC와 완료 대기 목록은 Completion을 사용한다. 종료 전송에 Sequence/Origin/Duration을 포함하지 않는다.
- 공통 참조 갱신은 SessionId와 Avatar를 받아 재생/종료 정보 모두 갱신한다. 복원 후 완료 전달과 강제 취소 정리 순서는 유지했다.
- UPROPERTY로 중첩 Session과 시전자 참조의 GC/직렬화 추적을 유지했다. 이전 State 필드 접근 잔존 및 diff 공백 오류 없음.
