# FrontEnd 버튼 선택 UI 단순화

## 계획

- WBP_FrontEnd의 기존 위젯 트리와 단계별 선택 로직을 정리한다.
- 한 화면에 캐릭터별 선택 버튼, 레벨별 선택 버튼, 입장 버튼을 기본 위젯으로 배치한다.
- 선택 상태를 표시하고 두 종류를 모두 선택하면 입장을 활성화한다.
- 선택한 참조를 기존 FrontEnd Library에 전달한다.
- 초기 포커스를 지정하고 위젯 컴파일, 입력 상태, 두 레벨 입장, WxEditor Development 빌드를 검증한다.

## 완료

- WBP_FrontEnd의 위젯 트리를 기본 CanvasPanel / VerticalBox / Button / TextBlock 13개로 재작성했다. 이전 단계별 화면과 그래프를 제거했다.
- 플레이어, 전투 테스트, 오픈월드 선택 버튼과 입장 버튼을 연결했다. 선택 표시, 미선택 입장 거부, 전환 중 중복 입력 차단을 확인했다.
- Construct에서 CharacterButton에 사용자 포커스를 지정한다. RenderOffscreen PIE에서 초기 및 재진입 Menu / NoCapture 적용과 커서 표시를 확인했다.
- 두 선택 순서, 레벨 재선택, FrontEnd 복귀 시 미선택 초기화, LV_DevCombat / LV_OpenWorld 도착 시 BP_Player 및 입력 복원을 검증했다.
- 화면 캡처로 기본 버튼 배치를 확인했다. 실제 물리 마우스 클릭 재현은 수행하지 않았다.
- Blueprint 경고 포함 컴파일 성공. WxEditor Win64 Development 빌드 성공 (build_2026-09-05_212630_555_12924.log).
