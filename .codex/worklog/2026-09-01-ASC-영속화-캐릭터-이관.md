# ASC 영속화 캐릭터 이관

## 계획

- `AWxCharacterBase`가 `IWxSavable`을 구현하고 GameplayEffect 영속 상태, 저장 직전 캡처, 복원 대기 및 적용 순서를 소유하도록 이관한다.
- 적 캐릭터는 기존 스포너 참조 저장 훅에서 부모 훅을 호출하고, 플레이어는 `AWxWorldSettings`가 운반한 상태를 AbilitySet 초기화 뒤 캐릭터에 전달하는 현재 흐름을 유지한다.
- `UWxAbilitySystemComponent`는 저장 시스템을 참조하지 않는 전투 컴포넌트로 유지하고 `UWxPersistedAbilitySystemComponent` 파생형을 제거한다.
- LSP 프로퍼티 경로와 기존 클래스 참조 리다이렉트를 갱신하며, 컴포넌트 레코드에서 액터 레코드로 바뀌는 기존 저장 데이터의 호환 한계를 명시한다.
- 변경 전후 동일하게 UE 5.8 `WxEditor Win64 Development` 타겟을 빌드하고, 저장 대상이 없는 경우와 저장 당시 영속 GE가 0개인 경우를 구분하는 복원 경로를 정적으로 확인한다.

## 완료

- `FWxPersistedGameplayEffect`와 `FWxPersistedAbilitySystemState`를 독립 상태 헤더로 옮기고, `AWxCharacterBase`가 `IWxSavable`과 저장용 상태 프로퍼티를 소유하도록 변경했다.
- `AWxCharacterBase`가 `Effect.Savable` GE의 캡처·초기 제거·클래스/Instigator/남은 시간/레벨/스택/SetByCaller 복원을 수행한다. 빈 배열 복원도 현재 영속 GE를 비우도록 별도 대기 플래그를 유지한다.
- 레벨 LSP 후처리, 월드 BeginPlay, ASC/AbilitySet 초기화가 모두 끝난 뒤 적용되도록 복원 게이트를 구성하고, 이를 위해 참조 관리자의 레벨 후처리 완료 조회를 읽기 전용 공개 API로 열었다.
- `AWxEnemyCharacter`는 부모 저장·복원 훅을 호출해 ASC 상태와 스포너 참조를 함께 처리한다. 플레이어는 기존 `AWxWorldSettings` 운반 경로를 유지하면서 새 캐릭터 API로 상태를 전달한다.
- 캐릭터의 기본 ASC 서브오브젝트를 `UWxAbilitySystemComponent`로 되돌리고 `UWxPersistedAbilitySystemComponent`를 제거했다. LSP 프로퍼티 경로를 `AWxCharacterBase::PersistedAbilitySystemState`로 바꾸고 기존 BP/CDO 클래스 참조용 `ClassRedirects`를 추가했다.
- 기존 LSP 파일의 ASC 컴포넌트 레코드는 새 캐릭터 액터 레코드로 자동 이관되지 않는다. 이 변경 이전 저장 파일에서는 GameplayEffect 영속 상태만 유실될 수 있으며, Attribute와 WorldSettings 등 다른 레코드는 기존 경로를 유지한다.
- 변경 전과 변경 후 UE 5.8 `WxEditor Win64 Development` 전체 빌드에 성공했다.
- `BP_Boss`, `BP_Enemy`, `BP_Player`, `BP_Sandbag` 집중 Blueprint 컴파일이 0 errors, 0 warnings, 0 failed loads로 성공해 클래스 리다이렉트와 기본 서브오브젝트 변경을 검증했다.
- 전체 Blueprint 컴파일은 이번 변경 대상은 모두 통과했지만 기존 `EUB_SnapToActor` 오류와 `BP_ItemPickup`의 제거된 `WxInteractionComponent` 경고 때문에 별도로 실패함을 확인했다.
