# 네임플레이트 자가 초기화

## 계획

- `WxCore`에 캐릭터 이름과 초상화를 제공하는 네이티브 표시정보 인터페이스를 추가한다.
- `AWxCharacterBase`가 기존 `CharacterName`과 `Portrait`의 단일 소유권을 유지한 채 표시정보 인터페이스를 구현한다.
- `UWxNameplateComponent`가 `BeginPlay()`에서 소유자의 `IAbilitySystemInterface`와 표시정보 인터페이스를 조회해 ViewModel을 스스로 초기화하도록 변경한다.
- `AWxEnemyCharacter`의 수동 네임플레이트 초기화 호출을 제거하고, 잘못된 소유자에 대한 경고와 기존 데디케이티드 서버 동작을 유지한다.
- 관련 참조와 포맷을 검사하고 UE 5.8 `WxEditor` Win64 Development 빌드로 검증한다.

## 완료

- `WxCore`에 네이티브 `IWxCharacterDisplayProvider`를 추가해 이름과 초상화를 모듈 독립적으로 제공하도록 했다.
- `AWxCharacterBase`가 기존 `CharacterName`과 `Portrait` 프로퍼티를 그대로 소유하면서 표시정보 인터페이스를 구현하도록 했다.
- `UWxNameplateComponent::BeginPlay()`가 소유자의 `IAbilitySystemInterface`와 `IWxCharacterDisplayProvider`를 조회해 ViewModel을 스스로 초기화하도록 변경했다.
- 두 계약을 구현하지 않은 소유자에는 경고를 남기며, ASC 부재 및 데디케이티드 서버·Slate 부재 처리 동작은 유지했다.
- `AWxEnemyCharacter`의 수동 `InitializeViewModels()` 호출을 제거했다.
- 관련 심볼 검색 결과 외부 수동 초기화 호출이 없고 `WxUI`가 `WxGame`을 참조하지 않음을 확인했다.
- `git diff --check`에서 공백 오류가 없음을 확인했다(기존 줄바꿈 변환 경고만 출력).

- 후속 결정에서 `UWxNameplateComponent`를 `WxUI`에 유지하면서 별도 표시정보 인터페이스를 두지 않기로 변경해, `IWxCharacterDisplayProvider` 기반 자가 초기화는 제거하고 기존 데이터 주입 방식으로 되돌렸다.
