# FrontEnd 직접 참조 입장

## 계획

- 승인한 RequestNewGame(WorldContextObject, PawnClass, Level) 구조로 변경한다. WBP가 목록을 직접 가지고 선택한 소프트 참조를 전달한다.
- 추가했던 Definition 3종과 에셋·카탈로그·목록 조회 API·스캔 설정을 제거한다. Experience는 도착 맵 WorldSettings의 기존 설정을 사용한다.
- Definition ID 및 진입점 전용 연결을 정리하고 기존 캐릭터 준비·중복 방지·전환·실패 복구를 유지한다. 로딩·인벤토리는 변경하지 않는다.
- UE 5.8 WxEditor Development 빌드, Blueprint 컴파일, 직접 참조 검증과 선택·왕복 진입·실패 복구 PIE를 실행한다.

## 완료

- RequestNewGame은 TSoftClassPtr<APawn> PawnClass와 TSoftObjectPtr<UWorld> Level을 직접 받는다. GetSelectionOptions를 제거하고 WBP의 기본값 목록에 기존 문구와 소프트 참조를 옮겼다. FWxFrontEndOption은 표시 정보와 두 참조만 보관한다.
- 추가했던 Definition 3종, 데이터 에셋 4개, 카탈로그 설정과 PrimaryAsset 스캔 3개를 제거했다. ID 기반 PlayerState 연결과 전용 진입점 선택 코드도 제거했다. 기본 PlayerStart 선택을 사용한다.
- GameFlow는 확정된 Pawn·맵 소프트 참조를 보관하고 기존 비동기 클래스 준비·중복 차단·도착 준비·실패 복구를 유지한다. Experience URL 옵션은 전달하지 않는다.
