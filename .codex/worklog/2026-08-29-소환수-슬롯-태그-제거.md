# 소환수 슬롯 태그 제거

## 계획

- `UWxAbilityAction_SummonActor`에서 `SummonSlotTag` 설정과 검증을 제거하고, 태그 없이 소환수를 등록한다.
- `UWxSummonComponent`를 활성 소환수 배열 기반 관리로 전환한다. 중복 등록을 막고, 사망·EndPlay·컴포넌트 종료 시 해당 소환수를 안전하게 해제한다.
- `WxEditor(Development)` 타깃을 빌드하여 컴파일을 검증한다.

## 완료

- `UWxAbilityAction_SummonActor`에서 `SummonSlotTag` 설정·검증을 제거하고 태그 없이 소환수를 등록하도록 변경했다.
- `UWxSummonComponent`를 배열 기반 다중 소환수 관리로 전환했다. 중복 등록을 막고 사망·EndPlay·컴포넌트 종료 시 개별 소환수를 정리한다.
- UE 5.8 `WxEditor Win64 Development` 빌드가 성공했다.
