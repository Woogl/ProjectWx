# 캐릭터 이관 호환층 제거

## 계획

- 재리세이브로 이관 완료가 확인된 Projectile·Minion 클래스, 프로퍼티, 네이티브 서브오브젝트 이름 리디렉트를 `DefaultEngine.ini`에서 제거한다.
- `BP_Minion` 부모 이관 중에만 유지한 `AWxMinion` 호환 클래스와 Instigator 단일화 중에만 유지한 `UWxMinionComponent` 호환 클래스를 제거한다.
- 네이티브 `ProjectileManagerComponent`, `MinionManagerComponent` 이름과 실제 매니저 구현은 유지한다.
- `WBP_Nameplate_Boss` 리세이브가 별도로 확인되지 않은 `bHasAITarget` 보스 HUD 프로퍼티 리디렉트는 유지한다.
- 옛 이름과 삭제 타입의 잔여 C++·설정 참조, 공백 오류를 검사하고 UE 5.8 `WxEditor` Win64 Development 빌드로 최종 검증한다.

## 완료

- `DefaultEngine.ini`에서 Projectile·Minion 클래스, 프로퍼티, 네이티브 서브오브젝트 이름 이관 리디렉트를 모두 제거했다.
- 재리세이브된 `WBP_Nameplate_Boss`에서 `bHasAITarget` 문자열이 사라진 것을 확인하고 마지막 프로퍼티 리디렉트도 제거했다.
- 임시 호환 타입 `AWxMinion`과 `UWxMinionComponent`를 제거했다. 기존의 관련 cpp 제거 상태도 유지했다.
- 실행 코드와 설정에서 옛 타입 및 옛 멤버·서브오브젝트 이름 참조가 없음을 확인했다.
- 재리세이브된 캐릭터 에셋 5개에서 `WxProjectileComponent`, `WxMinionComponent`, `ProjectileComponent`, `MinionComponent` 문자열이 남지 않은 것을 확인했다.
- `git diff --check`를 통과했다. 줄 끝 변환 예정 경고만 있었고 공백 오류는 없었다.
- UE 5.8 `WxEditor Win64 Development` 빌드에 성공했다. 삭제 타입 반영 빌드 후 마지막 리디렉트 제거 상태에서도 타깃이 최신임을 확인했다. 최종 로그: `Saved/Logs/BuildDoctor/build_2026-09-05_001123_345_7016.log`
