# 네임플레이트 어그로 표시

## 계획

- 조우 상태를 표현할 `State.Encounter` 네이티브 태그를 `WxCore`에 추가한다.
- 기존 `Engaged`·`Engagement` 식별자를 `EncounterActive`·`Encounter`로 통일하고, `AWxEnemyCharacter::SetEncounterActive()`가 ASC의 `State.Encounter` Loose Tag 카운트를 1 또는 0으로 갱신하게 한다.
- `UWxNameplateComponent`의 기본 표시 쿼리를 `State.LockedOn OR State.Encounter`로 변경한다. 3000cm 거리 제한과 `Ability.Death` 차단은 유지한다.
- 태그 선언·정의·생산·소비 참조와 포맷을 확인하고, UE 5.8 `WxEditor` Win64 Development 빌드로 검증한다.

## 완료

- `WxCore`에 `State.Encounter` 네이티브 태그를 추가했다.
- `AWxEnemyCharacter`의 교전 상태 API를 `IsEncounterActive`·`SetEncounterActive`·`OnEncounterChanged`·`bEncounterActive`로 통일하고, 상태가 바뀐 머신의 ASC에 `State.Encounter` Loose Tag 카운트를 최종값으로 동기화했다.
- 보스 뷰모델의 구독·초기화 경로를 `Encounter` API로 변경했다.
- 네임플레이트의 기본 표시 쿼리를 `State.LockedOn OR State.Encounter`로 구성했다. 3000cm 거리 제한과 `Ability.Death` 차단은 유지했다.
- 소스의 `Engaged`·`Engagement`·`State.Engaged` 참조가 0건임을 확인했고 `git diff --check`를 통과했다.
- UE 5.8 `WxEditor` Win64 Development 빌드 성공: `C:\Wx\Saved\Logs\BuildDoctor\build_2026-09-05_013034_246_2568.log`.

- 후속 용어 결정에서 개별 적의 교전 상태는 `Encounter`보다 `Engaged`가 적합하다고 판단해, 최종 소스는 `State.Engaged`와 `IsEngaged`·`OnEngagementChanged` 계약으로 복구했다.
