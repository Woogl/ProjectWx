# 소환수 어빌리티 명령

## 계획

- `UWxMinionComponent`에 C++ 어빌리티가 호출할 수 있는 서버 전용 명령 API를 추가한다.
- 명령 API는 관리 중인 활성 소환수를 정리한 뒤 스냅샷을 순회하고, 각 소환수 ASC에서 지정한 `Ability` 하위 식별 태그와 정확히 일치하는 어빌리티 후보 중 처음 발동에 성공한 하나만 실행한다.
- 설치물처럼 ASC가 없는 액터, 사망했거나 파괴된 소환수, 유효하지 않은 태그와 분류용 태그는 안전하게 건너뛴다.
- 기존 소환·수명·상한 관리, AI 행동, 어빌리티 취소 및 우선순위 정책은 변경하지 않고 GAS의 기존 발동 판정에 맡긴다.
- 변경점을 검토한 뒤 UE 5.8 `WxEditor` Development 타겟을 빌드해 컴파일을 검증한다.

## 완료

- `UWxMinionComponent::TryActivateAbilityOnMinions`를 추가했다. 서버에서만 동작하며 유효한 `Ability` 하위 리프 태그만 받는다.
- 명령 시 활성 소환수 목록을 정리하고 약참조 스냅샷을 순회해, ASC가 있는 소환수마다 정확히 일치하는 어빌리티 후보 중 처음 발동에 성공한 하나를 실행한다.
- 원격 발동은 허용하지 않고 기존 GAS 비용·쿨다운·태그·활성 그룹 판정과 취소 정책을 그대로 사용한다.
- 기존 작업 트리의 다른 변경은 수정하지 않았다.
- UE 5.8 `WxEditor Win64 Development` 빌드 성공.
- 관리 목록에서 파괴되었거나 죽은 소환수를 제거한다는 뜻이 드러나도록 정리 함수 이름을 `RemoveInvalidOrDeadMinions`로 변경했다.
