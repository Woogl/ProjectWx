# 아이템 뷰모델 범용화

## 계획

- 승인받은 설계: WxUI의 UWxViewModel_Item은 임의의 UObject 원본과 이름·아이콘, 변경 알림을 제공한다. 인터페이스 구현은 요구하지 않고 호출부나 파생 VM이 표시 데이터를 공급한다.
- 기존 인벤토리 전용 동작은 WxGame의 UWxViewModel_InventoryItem으로 분리하고 기존 아이템 리졸버는 WxGame에 유지한다.
- 현재 미커밋 변경을 보존하고 인벤토리 호출부 및 Blueprint 클래스·필드 참조 호환성을 처리한다.
- 변경 전 기존 인벤토리 테스트를 확인하고, 변경 후 일반 UObject 연결·해제와 기존 인벤토리 수명 동작을 검증한다. 런처 정보에서 UE 5.8 경로를 조회하여 WxEditor Development를 빌드한다.

## 완료

- WxUI에 UWxViewModel_Item을 구현했다. Initialize(const UObject*, FText, TSoftObjectPtr<UObject>)로 인터페이스 제약 없이 원본과 표시 데이터를 받고, SourceObject/DisplayName/Icon을 FieldNotify로 노출한다. SetDisplayName/SetIcon으로 표시를 갱신하며 이미지 로드는 기존 공용 비동기 로더를 재사용한다.
- 공용 VM은 원본을 강하게 보관하고 교체·Deinitialize 때 해제한다. BeginDestroy에서는 변경 알림 없이 정리한다.
- 기존 인벤토리 VM을 WxGame의 UWxViewModel_InventoryItem으로 분리했다. 인벤토리 전용 수량·충전·등급·소비 요청과 기존 리졸버를 유지했다. 표시 원본은 ItemDefinition으로 두어 슬롯 인스턴스의 기존 약한 참조 수명을 유지했다. 인벤토리 연결 해제 시 정적 표시 유지 동작도 보존했다.
- 인벤토리 호출부를 새 파생 타입으로 변경하고 이전 클래스 및 이동한 표시 필드에 CoreRedirects를 추가했다. WxUI에 다른 도메인 모듈 의존성은 추가하지 않았다.
- 변경 전 인벤토리 자동화 테스트 2개 통과: Saved/Logs/ItemVM_Baseline.log.
- 최종 자동화 테스트 4개 통과: Wx.MVVM.Item.ObjectLifecycle, Wx.MVVM.Inventory.Lifecycle, DelayedDefinition, LegacyReferences. 로그: C:/Wx/Saved/Logs/ItemVM_Verification_Final.log.
- 기존 WBP_TotalGold, WBP_ItemSlot, WBP_ItemQuickSlot, WBP_AcquiredItemEntry 모두 로드 및 Blueprint 컴파일 성공. 에셋 재저장은 하지 않았다. 로그: C:/Wx/Saved/Logs/ItemVM_Blueprints_Focused.log. 커맨드렛의 경고 1개는 MCP 플러그인의 라이선스 안내이며 Blueprint 컴파일 오류는 0개다.
- git diff --check 통과. 병행 작업의 WxCombat 변경은 수정하지 않았다.
