# WxDevice 부모 틱 호출 수정

## 계획

- 승인된 범위: TickComponent의 부모 호출 조건을 제거하고, 복제 수신 시 정지된 트리는 동기화 경로에서 먼저 복구한다.
- 부모 메시지 처리 및 엔진 틱 예약을 유지하고, 불필요한 정지 트리 틱을 제거한다. 기존 복제·재시도 계약과 사용자 변경은 보존한다.
- 기존 동기화 테스트의 틱 실행을 엔진의 활성 여부에 맞추고 완료 후 수신 시 재시작·미해소 참조 대기를 확인한다. UE 5.8 WxEditor Development 빌드와 Wx.Device 테스트로 검증한다.

## 완료

- TickComponent의 조건부 Super 호출을 제거했다. OnRep는 시작된 트리에 대해 실행 단계 밖에서 동기화를 수행한다. 시작 전 수신은 StartLogic에서, 실행 중 수신과 이미 요청한 전이는 틱 끝에서 처리한다.
- 복제 수신의 SetComponentTickEnabled(true)를 제거했다. 정지된 트리는 필요한 경우 동기화에서 재시작하고 엔진 전이 요청으로 다음 틱을 예약한다.
- 기존 테스트 픽스처는 활성 틱만 실행하도록 수정했다. 기존 완료/복구 테스트에 수신 직후 재시작 및 틱 예약 확인을 추가했다.
- UE 5.8 WxEditor Win64 Development 빌드 성공: `Saved/Logs/BuildDoctor/build_2026-09-06_020326_469_31684.log`.
- Wx.Device 9개 성공, 경고·실패 0: `Saved/Automation/WxDevice/index.json` (2026-09-06 02:04 KST). 정지/일시정지 트리 틱 경고 없음.
- git diff --check는 작업 시작 시 이미 존재한 컴포넌트 cpp의 빈 줄 탭을 지적했다. 사용자 서식 변경을 유지했다. 실제 다중 프로세스 네트워크 실행은 이번 검증에 포함하지 않았다.
