# Finisher 변형 데이터 통합

## 계획

- 앞잡·뒤잡의 공격자 몽타주, 피해자 몽타주, 대미지 행을 각각 하나의 Finisher 변형 데이터로 묶는다.
- `UWxAbilityAction_ApplyFinisherDamage`에서 대미지 행 설정을 제거하고, 현재 Finisher 변형의 대미지를 적용하도록 단순화한다.
- 기존 `GA_Finisher`의 두 몽타주 쌍과 두 대미지 행을 새 변형 데이터로 보존 이전한다.
- WxEditor(Development) 타깃을 빌드해 컴파일을 검증한다.

## 완료

- `FWxFinisherVariant`에 공격자 몽타주, 피해자 몽타주, 대미지 행을 함께 소유하게 했다.
- `GA_Finisher`의 기존 앞잡·뒤잡 몽타주와 대미지 행을 각 변형 데이터로 이전하고 에셋을 다시 저장했다.
- `UWxAbilityAction_ApplyFinisherDamage`는 대미지 행을 소유하지 않고 현재 Finisher 변형의 대미지 적용만 호출하도록 정리했다.
- DataTable 피커가 자식 PropertyHandle로 전역 DataTableRowHandle 커스터마이징을 다시 생성하던 재귀를 제거하고, 행 이름 보정 콜백의 재진입도 차단해 GA_Finisher 열기 시 스택 오버플로를 수정했다.
- `WxEditor Win64 Development`와 `WxEditor Win64 DebugGame` 빌드 성공으로 컴파일을 검증했다.
