# 컷신 복제 및 어빌리티 수명 리뷰 수정

## 계획

- 승인된 리뷰 3건 수정: 연결 중인 플레이어에게 컷신 시작·종료를 Reliable Multicast로 전달하여 프로퍼티 중간 전이 생략에 의존하지 않는다.
- 복제 스냅샷과 이벤트의 중복 수신을 구분하고 시전자 참조가 준비될 때까지 완료 통지를 보존한다.
- 클라이언트 궁극기의 로컬 컷신·후속 몽타주가 남아 있으면 서버의 정상 종료로 끊지 않는다. 강제 취소는 유지한다.
- UE 5.8 Development 빌드와 관련 경로 검증을 수행한다. 사용자가 제거를 요청한 임시 테스트 코드는 다시 남기지 않는다.

## 완료

- 시작과 종료에 각각 Reliable NetMulticast RPC를 추가했다. 서버가 정상 종료 뒤 다음 세션으로 넘어가더라도 종료 이벤트 전달이 단일 복제 프로퍼티의 중간 값 보존에 의존하지 않는다. 복제 스냅샷은 처음 합류했을 때 진행 중인 컷신 준비와 시전자 참조 갱신에 사용한다. 세션 ID로 스냅샷/RPC의 중복 준비 및 종료 통지를 막는다.
- 종료 대기 목록도 시전자 참조 갱신에 포함했다. 종료 RPC의 참조가 없으면 같은 세션의 로컬 참조를 이용하고, 참조가 유효하지 않은 완료 항목은 소비하지 않는다. 예약 취소도 올바른 시전자를 전달하도록 Reserve에서 Avatar를 설정했다.
- 궁극기 EndAbility를 재정의했다. 로컬 컷신/후속 몽타주가 남은 클라이언트에서 GAS 원격 정상 종료를 보류한다. 자체 완료 콜백 또는 취소는 기존 종료 경로로 진행한다. 따라서 지연 중 로컬 어빌리티의 활성 태그도 로컬 연출 완료까지 유지된다.
- UE 5.8 WxEditor Win64 Development 빌드 성공: `Saved/Logs/BuildDoctor/build_2026-09-16_024916_231_27884.log`. Win64 DebugGame 추가 빌드도 성공했다.
- 엔진 `RemoteEndOrCancelAbility`가 원격 종료 플래그 설정 후 EndAbility를 호출하는 경로, 로컬 몽타주 완료/취소가 복제 종료를 요청하는 경로를 대조했다. 공백 오류 검사 통과. 이번 변경은 실제 패킷 손실·지연을 넣은 2인 PIE로 검증하지 않았다.
- 삭제한 임시 컷신 테스트 코드와 friend 선언을 다시 추가하지 않았다. 에디터 종료/재실행을 수행하지 않았다.
