# 흰색 대검 3D 에셋 제작

## 계획

- 사용자가 확정한 2D 시안으로 전체 길이 1.5m의 흰색 대검 FBX를 제작한다.
- 직선 칼등, 비대칭 일체형 가드, 칼날 절반까지만 관통하는 구멍, 넓어진 칼날 폭을 반영한다.
- 칼등 두께 1.8cm와 얇아지는 날 단면, 흰색 감김 손잡이, UV와 재질 슬롯을 구성한다.
- 손잡이 기준 피벗으로 FBX 및 수정 가능한 Blender 원본을 출력하고 실제 메시 렌더와 FBX 재임포트로 크기·형상·UV·메시 상태를 검증한다.
- 게임 소스 변경이 없는 독립 에셋 제작으로, C++ 빌드 대신 FBX 재임포트 검증을 수행한다.

## 완료

- `output/WhiteGreatsword/`에 FBX, Blender 원본, 확정 시안, 실제 모델 렌더 2장, 재생성 스크립트와 한국어 사용 안내를 작성했다.
- 전체 길이 1.5m, 비대칭 가드, 직선 칼등, 절반 길이에서 끝나는 실제 관통 구멍, 흰색 재질 4슬롯과 UV0을 구현했다.
- 최종 메시 9,494버텍스 / 18,972삼각형. FBX 재임포트 후 크기와 메시 수, 재질·UV 보존을 확인했다.
- 비매니폴드 에지 0개. 레이 검사로 관통 구멍과 칼끝 쪽·구멍 아래 솔리드 부분을 검증했다.
- 실제 모델 렌더에서 감김 간격과 칼날 음영을 보완하고 재검증했다.
- Unreal Editor 내부 임포트는 수행하지 않았으며 사용 안내와 검증 보고서에 이를 명시했다.
