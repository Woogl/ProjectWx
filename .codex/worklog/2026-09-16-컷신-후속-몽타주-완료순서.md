# 컷신 후속 몽타주 완료 순서 수정

## 계획

- 승인: 서버 종료 확인과 해당 로컬 컷신 종료·AnimBP 복원이 모두 끝난 후 AbilityTask 완료를 알린다.
- 강제 취소는 즉시 처리하고 기존 개별 재생 및 같은 시전자 바인딩을 유지한다.
- 서버 종료가 먼저/나중에 도착하는 경우, 중복 통지 및 대기 세션을 검증한다. 실제 Template 컷신 복원 후 몽타주 재생을 확인한다.
- UE 5.8 WxEditor Development 빌드와 컷신 회귀 검사를 실행하고 사용자 실행 구성인 DebugGame도 빌드한다.

## 완료

- `OnRep_State`가 서버 정상 종료를 받자마자 완료를 알리던 경로를 수정했다. 클라이언트 종료 통지를 세션별로 보관하고, 해당 로컬 재생 및 대기 세션이 없을 때 전달한다. `CleanupLocalPlayer`의 시퀀스 정지·상태 복원·플래그 정리가 끝난 뒤 통지를 재검사한다.
- 강제 취소는 기존 즉시 정리·통지를 유지한다. 중복 종료 수신은 한 번만 보관하며, 다음 세션 상태가 도착해도 이전 종료 통지를 유지한다. 월드 종료 때 대기 중인 정상 완료 콜백을 실행하지 않도록 정리한다.
- `CompletionBeforeMontage` 회귀 검사 추가: 실제 Template 캐릭터/컷신/궁극기 몽타주를 로드하여 클라이언트 역할에서 서버 종료를 먼저 수신시킨다. 시퀀서 제어 중 완료 보류, 원래 AnimBP 복원 후 완료, 완료 콜백에서 GAS 몽타주 재생 및 재생 위치 진행을 검증했다. 로컬 종료 우선·대기 세션·중복 수신·강제 취소도 통과했다.
- 컷신 회귀 검사 6개 모두 성공. 로그: `Saved/Logs/CutsceneMontageCompletion.log`. 검사는 NullRHI 자동화이며 이번 검증에서 실제 2인 화면 재현까지 실행한 것은 아니다.
- UE 5.8 WxEditor Win64 Development 빌드 성공. 로그: `Saved/Logs/BuildDoctor/build_2026-09-16_023811_241_31952.log`.
- DebugGame 빌드 확인 성공: `Target is up to date`, `Result: Succeeded`. 에디터를 종료하거나 재실행하지 않았다.
