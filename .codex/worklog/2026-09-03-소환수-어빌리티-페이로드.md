# 소환수 어빌리티 페이로드

## 계획

- `UWxMinionComponent::TryActivateAbilityOnMinions`에 `FGameplayEventData`를 받는 오버로드를 추가하고, 기존 페이로드 없는 호출은 유지한다.
- `Event.CommandMinionAbility` 네이티브 태그를 추가해 소환수 어빌리티가 명령 발동임을 식별하게 한다.
- 기존의 정확한 리프 어빌리티 태그 검색은 유지하되, 선택된 스펙은 `TriggerAbilityFromGameplayEvent`로 발동해 `Target`, `TargetData`, `Instigator`, `ContextHandle` 등의 데이터를 `TriggerEventData`로 전달한다.
- 서버 권한, 활성 소환수 정리, 첫 성공 후보 선택, GAS 비용·쿨다운·활성 그룹 판정은 기존 동작을 보존한다.
- 변경점을 검사한 뒤 UE 5.8 `WxEditor` Development 타겟을 빌드해 컴파일을 검증한다.

## 완료

- `TryActivateAbilityOnMinions`에 `const FGameplayEventData&` 오버로드를 추가하고, 기존 오버로드는 빈 페이로드를 만들어 새 경로에 위임했다.
- 빈 `Instigator`는 명령 컴포넌트의 소유자로 보완하며, 그 외 `Target`, `TargetData`, `ContextHandle`, `EventMagnitude` 등은 호출자가 넣은 값을 유지한다.
- 정확 태그로 선택한 소환수 어빌리티를 `TriggerAbilityFromGameplayEvent`로 발동해 `TriggerEventData`를 전달한다.
- 발동 이벤트는 새 네이티브 태그 `Event.CommandMinionAbility`로 고정했다.
- 기존 서버 권한, 리프 태그 제한, 활성 소환수 정리, 첫 성공 후보 선택과 GAS 발동 판정은 유지했다.
- UE 5.8 `WxEditor Win64 Development` 빌드 성공.
