# 공용 스킬 컷신 재설계

## 계획

- 승인받은 구조대로 AbilityTask는 서버 요청과 완료·취소 대기로 축소한다. 사용자의 추가 지시에 따라 별도 액터 대신 GameState에 부착한 WxCombat 공용 컴포넌트가 컷신 수명을 관리한다.
- 사용자의 추가 지시에 따라 궁극기의 LocalPredicted 발동을 유지한다. 서버는 비용·쿨다운 적용 전에 공용 컷신을 예약해 동시 발동을 차단하고, 로컬 태스크는 자신의 시전자에 해당하는 서버 세션의 종료를 기다린다.
- 기존 LevelSequence와 Player 바인딩을 유지하며 시전자와 메시 원점을 공유한다. 클라이언트별 시퀀스 로딩, 시전자 복제, World Partition 주변 스트리밍 준비를 기다린다.
- PlayerController의 WxCombat 컴포넌트로 준비 응답과 실시간 시계 동기화를 전달하고 공통 시작 시각으로 재생한다. 월드 시간 배율의 역수 보정을 제거한다.
- 정상 종료·취소·준비 시간 초과·시전자 이탈에서 카메라와 스트리밍, 기존 시간 배율, 해당 컷신 무적 효과를 정리한다.
- UE 5.8 WxEditor Win64 Development 빌드와 가능한 집중 검증을 수행한다. 실제 다중 클라이언트 실행 여부와 남은 검증 범위를 명시한다.

## 완료

- GameState에 UWxSkillCutsceneComponent를 부착했다. 별도 관리 액터 없이 세션 ID, 시전자, 메시 원점, 준비·재생·종료 상태와 공통 시작 시각을 복제한다.
- PlayerController에는 UWxSkillCutsceneClientComponent를 부착해 각 연결의 준비 응답과 왕복 시간 기반 플랫폼 시계 보정을 전달한다.
- 궁극기의 LocalPredicted 정책을 유지했다. 서버는 비용 확정 전에 공용 세션을 예약하고, 로컬 AbilityTask는 같은 시전자의 공용 종료를 기다린다. 관찰자의 컷신도 같은 GameState 상태로 재생한다.
- 모든 클라이언트의 Player 태그를 State.Avatar에 바인딩한다. 로컬 폰 대체 경로는 없다. 시전자 관련성을 준비 중 강제하고 World Partition 스트리밍 소스를 공유 원점에 등록한다.
- 월드 시간 배율과 무관한 플랫폼 시계 기반 시퀀스 타임 컨트롤러를 사용한다. 준비 응답을 모은 뒤 0.5초 후 시작하며 준비 제한은 실시간 20초다.
- 서버가 컷신 무적 효과 핸들과 기존 시간 배율을 소유한다. 종료·취소에서 해당 핸들만 제거하고 카메라/시퀀스 상태, 스트리밍 소스, 시전자 관련성을 정리한다.
- UE 5.8.2 WxEditor Win64 Development 빌드 성공. 최종 로그: C:/Wx/Saved/Logs/BuildDoctor/build_2026-09-16_014256_128_36136.log. `Result: Succeeded`, `BUILD_DOCTOR_EXIT_CODE=0` 확인.
- UnrealEditor-Cmd -NullRHI 자동화 테스트 2개 성공: Wx.Combat.SkillCutscene.ExistingAssets, Wx.Combat.SkillCutscene.ReservationAndCleanup. 보고서: C:/Wx/Saved/Automation/SkillCutscene/index.json. 로그: C:/Wx/Saved/Logs/SkillCutsceneAutomation.log.
- 기존 HGTest/Template 궁극기 에셋의 Player 바인딩과 LocalPredicted 정책을 실제 로드해 확인했다. 예약 배타성, 요청자별 취소, 시전자 구분, 관련성 복원, 다른 시스템 무적 효과 보존을 검증했다. 테스트 월드 중복 초기화 오류를 수정한 뒤 전체 2개를 재실행했다.

## 실행 검증 범위

- 실제 전용 서버/리스닝 서버와 여러 클라이언트에서 카메라, 지연·패킷 손실, 준비 중 접속 해제, 재생 중 취소의 시각적 결과는 아직 검증하지 않았다. 빌드·자동화 성공을 네트워크 화면 일치 검증으로 간주하지 않는다.
- 시계 보정은 왕복 지연이 대칭이라는 근사다. 프레임 단위의 절대 동시성을 보장하지 않는다.
- 주변 로딩은 시전자 원점과 World Partition 기본 그리드 반경을 사용한다. 비활성 Data Layer를 활성화하거나 카메라 경로 전체의 원거리 셀을 별도로 로드하지 않는다.
- 재생 준비 실패 시 어빌리티를 취소한다. 이미 확정된 서버 비용·쿨다운의 환불 정책은 추가하지 않았다.
