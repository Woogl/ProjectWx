# 장치 당사자 참조와 상태 동기화 분리

## 계획

- 사용자 승인: 당사자가 없어도 상태 태그·진입 번호·실행 상태로 장치를 동기화한다.
- 미해소 참조는 nullptr로 적용해 이전 당사자를 지우고, 참조 해소 시 상태 재진입 없이 당사자만 갱신한다.
- bHasInteractor를 제거하고 서버 발행 시 IsValid로 당사자를 검증한다.
- 미해소·지연 해소·파괴된 당사자 및 중복 진입 방지를 회귀 검증하고, 런처에서 조회한 UE 5.8로 WxEditor Win64 Development를 빌드한다.
- 기존 사용자 변경과 무관한 리뷰 항목은 보존한다.

## 완료

- FollowAuthorityState의 당사자 미해소 조기 반환을 제거했다. 상태 태그·진입 번호·실행 상태가 당사자 유무와 독립적으로 적용된다.
- ApplyInteractor는 무효 참조를 nullptr로 적용해 이전 당사자를 남기지 않는다. 늦은 RepNotify는 기존 진입 번호를 유지하며 당사자를 갱신한다.
- bHasInteractor와 waitingInteractor 진단 필드를 제거했다. 파괴 후 남는 플래그 때문에 상태가 영구 대기하는 표현 자체를 없앴다. 서버 발행은 IsValid로 파괴된 포인터를 nullptr로 정규화한다.
- 실제 BP_Door/문 StateTree를 사용하는 Wx.World.Device.OptionalInteractor 회귀 테스트를 추가했다. 당사자 없는 최초 열림, 이전 당사자 제거, 지연 참조 반영과 중복 요청·진입 방지, GC 전 파괴된 참조를 동반한 닫힘, 당사자 없는 완료, 완료 후 지연 참조와 재시작 방지, 서버 유효/파괴 참조 발행을 검증했다.
- 최종 자동화 결과: 성공 1, 경고 0, 실패 0, 미실행 0. 보고서: C:/Wx/Saved/Automation/WxDeviceInteractor/index.json. 로그: C:/Wx/Saved/Logs/WxDeviceInteractorAutomation.log.
- git diff --check -- Plugins/WxWorld 통과. 기존 사용자 변경은 보존했다.
- 한계: 수신 스냅샷과 RepNotify를 직접 주입한 로컬 자동화 검증이다. 실제 다중 프로세스 네트워크의 relevancy/NetGUID 매핑 및 패킷 지연은 검증하지 않았다. 늦게 해소된 당사자에 대해 이미 끝난 일회성 연출을 재생하지 않는다.
