# 교전 태그 관찰

## 계획

- `FWxOnEnemyEngagementChanged`와 `AWxEnemyCharacter::OnEngagementChanged`를 제거해 `State.Engaged`와 중복되는 알림 경로를 없앤다.
- `AWxCharacterBase::IsEngaged()`도 제거하고, `AWxEnemyCharacter`의 단일 갱신 함수가 사망 상태와 유효한 락온 대상을 `State.Engaged`에 투영하도록 한다.
- 피니셔와 보스 HUD를 포함한 모든 소비자는 `State.Engaged`만 질의하거나 관찰하며, 별도 변경 비교와 수동 브로드캐스트를 제거한다.
- 보스 뷰모델은 보스 ASC의 `State.Engaged` 태그 이벤트를 직접 구독하고, 구독 직후 현재 태그 값으로 HUD 상태를 초기화한다.
- 보스 교체·소멸 시 저장한 델리게이트 핸들로 태그 이벤트 구독을 해제해 기존 수명 계약을 보존한다.
- 직전 성공한 UE 5.8.2 `WxEditor Win64 Development` 빌드를 변경 전 기준선으로 삼고, 변경 후 같은 빌드와 잔여 참조 검색으로 검증한다.

## 완료

- `FWxOnEnemyEngagementChanged`와 `AWxEnemyCharacter::OnEngagementChanged`를 제거했다.
- `HasCombatTarget()`, `IsEngaged()`, `SetEngaged()`, `bEngaged`를 모두 제거하고 소비자 관점의 교전 상태를 `State.Engaged`로 통일했다.
- `AWxEnemyCharacter::RefreshEngagementState()`가 사망 상태와 유효한 락온 대상을 계산하고, `ApplyEngagementProjection()` 한 곳에서만 `State.Engaged`를 갱신하도록 정리했다.
- 피니셔 자격은 `State.Engaged`를 직접 질의하도록 변경했다.
- 보스 뷰모델이 보스 ASC의 `State.Engaged` 태그 이벤트를 직접 구독하고, 현재값 초기화와 보스 교체·소멸 시 핸들 해제를 수행하도록 변경했다.
- UE 5.8.2 `WxEditor Win64 Development` 빌드와 `git diff --check`가 성공했다.
- 소스 검색으로 제거 대상 API와 캐시의 잔여 참조가 없고, `State.Engaged` 쓰기 지점이 한 곳뿐임을 확인했다.
