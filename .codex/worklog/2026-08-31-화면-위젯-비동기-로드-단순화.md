# 화면 위젯 비동기 로드 단순화

## 계획

- 취소·레이아웃 교체·재진입 방어와 공개 인터페이스는 유지한다.
- `UWxAsyncAction_PushWidgetToLayer::HandleWidgetClassLoaded`의 반복된 실패 분기를 이름 있는 로컬 값과 하나의 검증 블록으로 합친다.
- 비동기 로드·위젯 생성·BeforePush·레이어 push·AfterPush·완료 콜백의 실행 순서는 바꾸지 않는다.
- 호출부와 문서에는 기능 변화가 없으므로 손대지 않는다.
- 변경 전 성공한 `WxEditor Win64 Development`와 동일한 빌드를 다시 실행한다.
- 현재 작업 트리의 다른 변경사항은 건드리지 않는다.

## 완료

- `HandleWidgetClassLoaded`의 GameInstance·UI 매니저·대상 레이아웃·위젯 클래스·소유 플레이어 실패 분기를 `bCanPushToTargetLayout` 판정 하나로 합쳤다.
- 정상 완료에서 쓰는 `Finish(..., false)`는 기본 인자로 숨기고 명시적 취소만 `true`를 전달하도록 정리했다.
- 취소·레이아웃 교체·재진입 방어, 공개 인터페이스와 비동기 로드→생성→BeforePush→push→AfterPush→완료 콜백 순서를 유지했다.
- 액션 구현은 172줄에서 148줄로 줄었으며 호출부와 문서는 수정하지 않았다.
- `git diff --check`를 통과했다.
- 런처 정보에서 UE 5.8.2 설치 경로를 조회해 `WxEditor Win64 Development` 빌드에 성공했다. 로그는 `.Codex/skills/build-doctor/logs/build_2026-08-31_022139.log`다.
