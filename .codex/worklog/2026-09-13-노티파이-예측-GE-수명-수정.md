# 노티파이 예측 GE 수명 수정

## 계획

- 최종 지시: 예측 처리는 보류하고 최소 범위로 수정한다.
- NotifyBegin에 서버 권위 검사를 추가하여 기존 서버 전용 NotifyEnd와 일치시킨다. 클라이언트는 서버 GE 복제를 따른다.
- 시도했던 예측 태스크·TargetData·어빌리티 연동·공용 ApplyEffect/ApplyDamage 변경은 모두 되돌린다. 타격 예측·히트스톱 경로는 변경하지 않는다.
- 클라 노티파이의 예측본 미생성과 반복 호출 후 비누적, 서버의 적용·제거를 회귀 테스트로 확인하고 UE 5.8 WxEditor Win64 Development를 빌드한다.
- 같은 GE 클래스의 중첩 제거 문제와 다른 호출부의 과거 예측 키 재사용은 별도 미해결 사항으로 남긴다.
