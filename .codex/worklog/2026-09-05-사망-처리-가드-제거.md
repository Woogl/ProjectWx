# 사망 처리 가드 제거

## 계획

- `AWxEnemyCharacter::bDeathHandled` 멤버와 `HandleOwnerDeath()`의 중복 실행 방지 분기를 제거한다.
- `Ability.Death`의 단일 생명주기와 `NewOrRemoved` 태그 이벤트 계약, `BeginPlay` 초기 사망 처리와 런타임 태그 이벤트의 배타성을 전제로 기존 보상·스포너 집계 동작을 보존한다.
- 교전 태그 갱신과 서버 권위 검사 위치는 유지한다.
- 직전 성공한 UE 5.8.2 `WxEditor Win64 Development` 빌드를 변경 전 기준선으로 삼고, 변경 후 같은 빌드와 잔여 참조 검색으로 검증한다.

## 완료

- `AWxEnemyCharacter::bDeathHandled` 멤버를 제거했다.
- `HandleOwnerDeath()`의 중복 실행 방지 분기와 상태 대입을 제거했다.
- 교전 태그 갱신 후 서버 권위에서 스포너 처치 집계와 보상을 수행하는 기존 순서를 유지했다.
- UE 5.8.2 `WxEditor Win64 Development` 빌드와 `git diff --check`가 성공했다.
- 소스 검색으로 `bDeathHandled` 잔여 참조가 없음을 확인했다.
