# FrontEnd 선택 구조 단순화

## 계획

- 승인한 구조에 따라 WBP_FrontEnd가 임시 선택과 단계 전환, 버튼·텍스트 표시를 직접 관리한다.
- WxFrontEndLibrary는 목록 조회, 입장 요청, 전환 상태·오류 조회만 제공한다. WxGameFlowSubsystem의 검증·전환·확정 상태는 유지한다.
- WxFrontEndFlowComponent, WxViewModel_Selection, FrontEnd Resolver와 에셋 연결을 제거한다. 새 ScreenWidget 클래스, 로딩 기능, 인벤토리 변경은 추가하지 않는다.
- 기존 검증을 기준으로 Blueprint 컴파일, UE 5.8 WxEditor Development 빌드, 선택·왕복 전환·실패 복구 PIE를 확인한다.

## 완료

- WBP_FrontEnd가 목록·단계별 인덱스·선택 표시·버튼 동작을 직접 관리한다. 기존 부모와 화면 배치, 뒤로 가기 시 선택 유지, 확정 ID 전달을 보존했다.
- WxFrontEndLibrary에는 GetSelectionOptions, GetTravelStatus, RequestNewGame 세 함수만 남겼다. FWxFrontEndOption은 ID·제목·설명을 전달하는 값 구조체다.
- WxFrontEndFlowComponent, WxViewModel_Selection, WxViewModelResolver_FrontEnd 소스 6개 및 WBP MVVM 바인딩·WAS_FrontEnd 주입 액션을 제거했다. GameFlow와 인벤토리 코드는 수정하지 않았다.
