# 타격 GE 및 적중 연출 서버 권위 적용

## 계획

- 사용자가 승인한 정책: 공격 시작·몽타주·적중과 무관한 연출의 예측은 유지하고, 피해·추가 효과·적중 Cue·히트스톱·피격 반응은 서버 판정을 따른다.
- ApplyDamage와 HitStop::Apply에서 소스 ASC 권위를 검사하고 활성화 예측 키 재사용을 제거한다. 타격 GE의 자식 효과와 Cue에는 빈 키가 전달되도록 한다.
- 변경된 계약에 맞게 관련 주석을 정정한다. 공용 ApplyEffect 및 별도 작업 중인 무적 GE는 변경하지 않는다.
- 타격 호출 경로와 빈 키 전달을 점검하고 git diff --check 및 런처에서 조회한 UE 5.8의 WxEditor Win64 Development 빌드로 검증한다. 실제 네트워크 PIE를 실행하지 못하면 제한을 기록한다.

## 완료

- ApplyDamage와 HitStop::Apply에 소스 ASC 권위 검사를 추가했다. 클라이언트는 적용하지 않으며, 서버는 명시적인 빈 FPredictionKey로 GE를 적용한다.
- 타격 래퍼가 자식 Damage·AdditionalEffects·Hit Cue에 동일한 빈 키를 전달하는 경로를 확인했다. 무기·투사체의 히트스톱 호출은 공통 서버 권위 진입점을 사용한다. 공격 활성화·몽타주 및 공용 ApplyEffect는 변경하지 않았다.
- 관련 API·무기·광역 노티파이·투사체 주석을 현재 정책에 맞게 정정했다. 작업 시작 전에 있던 무적 GE 변경은 보존했다.
- git diff --check 통과. UE 5.8 WxEditor Win64 Development 빌드 성공(종료 코드 0, Result: Succeeded). 로그: C:/Wx/Saved/Logs/BuildDoctor/build_2026-09-14_233126_722_13236.log.
- 최초 샌드박스 내 빌드는 UBT 로그 생성 전 종료 코드 1로 끝났다. build-doctor 실행기로 샌드박스 외 빌드를 수행해 성공했다.
- 검증은 소스 경로 점검 및 컴파일·링크까지다. 네트워크 PIE의 반복 타격 GE 비누적, Cue 중복·누락, 실제 타격 지연은 미실측이며 런타임 회귀 테스트는 추가하지 않았다. 에디터는 실행하지 않았다.
