# 태그 발동 조건 면제 GE

## 계획

- C++ `UWxEffect_IgnoreTagRequirements`를 WxCombat에 추가한다. GE가 유지되는 동안 발동 태그 조건을 면제한다.
- WxCore를 수정하지 않고 면제 태그를 WxCombat에 선언·정의한다.
- `UWxAbilityBase::DoesAbilitySatisfyTagRequirements()`에서 면제 태그를 검사한다. 기존 콤보 창 예외와 쿨다운·코스트·동작 점유 검사는 유지한다.
- 이번 요청 범위는 GE와 기반 어빌리티 수정이다. MirrorAbility Task 및 에셋의 GE 적용 설정은 변경하지 않는다.
- UE 5.8 WxEditor Development 빌드와 변경 범위 검증을 수행한다.

## 완료

- `UWxEffect_IgnoreTagRequirements` C++ GE를 추가했다. Infinite 효과로 `Effect.IgnoreTagRequirements`를 부여하며 기존 IgnoreCosts GE와 동일하게 에셋 태그도 설정한다.
- 태그는 WxCombat에 선언·정의했다. WxCore 변경 없음.
- `DoesAbilitySatisfyTagRequirements()`는 해당 태그 보유 시 true를 반환한다. 기존 콤보 창 분기와 GE가 없는 경우의 기본 검사는 유지했다. 코스트·쿨다운·동작 점유 코드는 변경하지 않았다.
- Task 및 에셋 설정은 변경하지 않았다. 실제 분신에 사용하려면 AbilitySet 등에서 신규 GE를 적용해야 한다. 플레이 검증은 미실시.
