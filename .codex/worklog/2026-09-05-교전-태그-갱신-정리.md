# 교전 태그 갱신 정리

## 계획

- `AWxEnemyCharacter::ApplyEngagementProjection()`을 제거한다.
- `RefreshEngagementState()`를 `RefreshEngagementTag()`로 변경하고, 사망 태그·락온 대상 판정과 `State.Engaged` 갱신을 함수 하나에서 수행한다.
- `EndPlay()`에서는 종료 정리임을 드러내도록 `State.Engaged` 태그를 직접 0으로 초기화한다.
- 기존 갱신 호출 시점과 태그 결과를 유지한다.
- 직전 성공한 UE 5.8.2 `WxEditor Win64 Development` 빌드를 변경 전 기준선으로 삼고, 변경 후 같은 빌드와 잔여 참조 검색으로 검증한다.

## 완료

- `ApplyEngagementProjection()`을 제거했다.
- `RefreshEngagementState()`를 `RefreshEngagementTag()`로 변경하고, 사망 태그·락온 대상 판정과 `State.Engaged` 갱신을 한 함수로 합쳤다.
- `EndPlay()`는 종료 정리로 `State.Engaged`를 직접 0으로 초기화하도록 변경했다.
- `UWxAIPerceptionComponent`는 서버 컨트롤러의 감지·대상 선택 책임에 유지했다. 클라이언트 UI까지 필요한 교전 태그를 이관하면 복제 경로가 사라지고, 실제 락온 상태를 읽기 위해 `WxAI`에서 `WxCombat`을 참조해야 하므로 `AWxEnemyCharacter`가 투영을 계속 소유한다.
- UE 5.8.2 `WxEditor Win64 Development` 빌드와 `git diff --check`가 성공했다.
- 소스 검색으로 제거한 함수의 잔여 참조가 없음을 확인했다.
