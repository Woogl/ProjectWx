# 아이템 뷰모델 재초기화 이름 보존

## 계획

- 리뷰에서 제안하고 사용자가 수정을 승인한 범위: UWxViewModel_Item::Initialize의 표시 이름을 값으로 받아 Deinitialize의 멤버 초기화와 분리한다.
- 기존 객체 수명 테스트에서 현재 DisplayName을 직접 전달하는 재초기화 사례를 검증한다. 수정 전 실패와 수정 후 성공을 확인한다.
- UE 5.8 WxEditor Development 빌드와 공용 아이템·인벤토리 자동화 테스트를 실행한다. 무관한 미커밋 변경은 보존한다.

## 완료

- Initialize의 InDisplayName을 FText 값 매개변수로 변경했다. Deinitialize가 멤버를 초기화해도 전달받은 이름은 보존된다. 선언부에 값 전달의 이유를 기록했다.
- ObjectLifecycle 테스트가 기존 DisplayName 멤버를 직접 전달해 원본을 교체하고 이름이 유지되는지 검사하도록 변경했다. 기존 원본 해제·아이콘 초기화·변경 알림 검증도 유지했다.
- 수정 전 동일 테스트에서 이름이 "Renamed" 대신 빈 문자열이 되는 실패를 확인했다: C:/Wx/Saved/Logs/ItemVM_AliasedName_Before.log.
- 수정 후 공용 아이템 ObjectLifecycle 및 인벤토리 Lifecycle/DelayedDefinition/LegacyReferences 총 4개 테스트 통과: C:/Wx/Saved/Logs/ItemVM_AliasedName_After.log.
- UE 5.8 WxEditor / Win64 / Development 빌드 성공, 종료 코드 0: C:/Wx/Saved/Logs/BuildDoctor/build_2026-09-06_000444_136_30948.log.
