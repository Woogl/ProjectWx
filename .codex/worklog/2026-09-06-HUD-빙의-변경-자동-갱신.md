# HUD 빙의 변경 자동 갱신

## 계획

- 승인받은 대로 HUDComponent가 OnPossessedPawnChanged에서 이전 HUD와 진행 중인 생성 요청을 정리하고 새 Pawn 기준 HUD를 생성한다.
- 빙의 해제 시 HUD를 정리하고 동일 Pawn 알림에서는 기존 중복 생성 방지를 유지한다.
- Controller의 HUD 타입 참조와 RebuildHUD 호출을 제거한다. UIManager 동작은 수정하지 않는다.
- UE 5.8 WxEditor Development 빌드 및 실제 PIE 반복 부활에서 HUD 자동 교체와 기존 부활 동작을 검증한다.

## 완료

- HUDComponent가 OnPossessedPawnChanged에서 기존 HUD와 대기 중 생성 요청을 정리하고 새 Pawn의 HUD를 생성하도록 변경했다. 동일 Pawn 알림의 중복 생성 방지는 유지했다.
- Controller의 HUDComponent 참조 및 RebuildHUD 호출을 제거했다. UIManager 동작은 변경하지 않았다.
- UE 5.8 WxEditor Development 빌드 성공: Saved/Logs/BuildDoctor/build_2026-09-06_032445_725_8520.log.
- NullRHI PIE에서 실제 ST 체크포인트 상호작용 후 사망 화면 버튼으로 두 번 연속 부활을 검증했다. 동일 월드/Controller 유지, Pawn 교체, 체크포인트 위치, HP/MP 회복, Device 상태 유지, 적 재생성, UI/입력 복구 및 활성 HUD가 정확히 하나인 것을 확인했다.
- 일반 빙의 해제 시 HUD 제거, 재빙의 시 HUD 하나 생성도 통과했다. 결과: Saved/Logs/HUDPossessionPIEResult.json. NullRHI 검증이므로 화면 렌더링의 시각적 확인은 포함하지 않는다.
