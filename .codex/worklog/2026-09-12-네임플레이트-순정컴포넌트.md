# 네임플레이트 순정 WidgetComponent 전환

## 계획

- 사용자 요청대로 UWxNameplateComponent를 제거하고 적 캐릭터의 동일한 이름의 서브오브젝트를 순정 UWidgetComponent로 전환한다. 기존 화면 공간·크기·부착 위치를 유지한다.
- Resolver는 위젯을 보유한 UWidgetComponent로부터 Owner를 조회한다. Character ViewModel의 IWxUIData 조회를 유지한다.
- Scale과 표시 설정을 WBP Conversion Library 입력으로 옮기고 Nameplate ViewModel은 거리·태그·플레이어 유효 상태만 갱신한다. Collapsed 상태의 재표시를 위한 갱신 수명은 유지한다.
- 기존 BP 설정을 확인하고 WBP 바인딩을 이전한 후 폐기 필드를 제거한다. 클래스 리다이렉트로 기존 BP 및 배치 액터의 컴포넌트 참조를 호환한다.
- 순정 컴포넌트로 Owner 조회, 거리·태그에 따른 Scale/Visibility 갱신 및 재표시 회귀 테스트를 수행한다. UE 5.8 WxEditor Development 빌드 및 실제 BP 로드를 확인한다.

## 완료

- UWxNameplateComponent 헤더·구현을 삭제하고 AWxEnemyCharacter의 NameplateComponent 서브오브젝트를 순정 UWidgetComponent로 변경했다. Screen 공간, DesiredSize, 기존 부착 이름·위치를 유지한다.
- Resolver는 위젯을 보유한 UWidgetComponent를 조회하여 Owner를 찾는다. Character ViewModel의 IWxUIData 조회는 유지한다.
- Nameplate ViewModel은 Distance, OwnedTags, bHasViewer만 제공한다. 기존 Scale 설정 및 Visibility 필드를 제거했다. Collapsed 상태에서도 조건 변화를 전달하도록 기존 티커 수명을 유지한다.
- WBP_Nameplate_Enemy의 Scale 변환은 Distance만 VM에 바인딩하고 ReferenceDistance/MinScale/MaxScale은 변환 핀 상수로 유지한다. Visibility는 새 Conversion Library 함수에 거리·태그·관찰자 상태를 바인딩하고 기존 태그 조건·최대 거리는 상수 핀으로 이전했다.
- 캐릭터 BP 4개와 기존 클래스 참조가 있는 외부 액터 패키지 3개를 로드하여 개별 표시 설정이 기본값과 같음을 이전 전에 검증했다. 임시 이전 도구와 에디터 의존성은 제거했다.
- Config/DefaultEngine.ini에 WxUI.WxNameplateComponent → UMG.WidgetComponent 클래스 리다이렉트를 추가하여 기존 저장 컴포넌트 참조를 호환한다.
- 최종 WxEditor Win64 Development 빌드 성공: Saved/Logs/BuildDoctor/build_2026-09-12_160742_877_19700.log.
- Wx.UI 자동화 테스트 3개 성공, 경고·오류 0: Saved/Automation/NativeNameplate/index.json. 실제 WBP에서 거리·태그·플레이어 유무·Collapsed 재표시를 검증하고 기존 BP 및 배치 액터가 엔진 컴포넌트 타입으로 로드됨을 확인했다.
- 변경 경로 git diff --check 통과. Source와 WxUI 소스에서 삭제된 클래스 참조가 남지 않음을 확인했다.
