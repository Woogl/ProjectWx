# 적중 연출 예측 분기 정리

## 계획

- 승인된 범위: Hit 컴포넌트의 예측 전용 Cue·태그 분기를 제거하고 서버 실행 결과만 사용한다.
- HitStop 컴포넌트의 FrozenHandles, GE 추가·제거 구독, 복제본 제외 및 머신별 판정 분기를 제거한다. Effect.HitStop 태그 유무로 정지·해제를 통일한다.
- 이동 정지와 카메라 연출의 로컬 제어 검사는 유지한다. 기존 작업 중인 변경은 보존한다.
- 소스 경로 및 태그 중첩 해제 계약을 확인하고 git diff --check와 UE 5.8 WxEditor Win64 Development 빌드로 검증한다. 실제 네트워크 검증 미수행 시 한계를 기록한다.

## 완료

- Hit 컴포넌트의 CanGameplayEffectApply에 서버 권위 조건을 명시하고, 예측 클라이언트용 Cue 조건·태그 대체 분기와 후처리의 중복 권위 분기를 제거했다. 0 피해 생략 및 반사 결과의 Cue 유지 조건은 보존했다.
- HitStop의 FrozenHandles, GE 추가·제거 구독, IsSimulatedProxy 및 비복제 어빌리티 비교를 제거했다. IsFrozen은 Effect.HitStop 태그만 조회한다. BeginPlay에서 구독 직후 현재 태그 상태도 반영한다.
- 이동 정지의 IsLocallyControlled 검사와 카메라 Cue 코드는 유지했다. 직전 서버 전용 적용 및 무적 관련 외부 변경을 보존했다.
- 엔진 소스에서 RegisterGameplayTagEvent 기본값 NewOrRemoved와 태그 카운트 0 진입·이탈 시 콜백을 확인했다. 여러 효과 중 일부가 끝나도 태그가 남아 있으면 정지를 유지하는 계약이다. 제거된 예측 분기·핸들 참조가 대상 파일에 남아 있지 않음을 확인했다.

- 실제 원격 클라이언트의 공격자·피격자 히트스톱, 연타 해제 및 짧은 태그의 복제 관찰 여부는 네트워크 PIE 미실측이다. 검증은 소스 계약 확인과 컴파일·링크까지이며, 런타임 자동화 테스트는 추가하지 않았다.
