# 아이템 사용·처형 피해 이벤트 컴포넌트 분리

## 계획

- `UWxAnimNotify_UseItem`을 추가해 `Event.UseItem` GameplayEvent와 Notify·Mesh 페이로드를 발행한다.
- 플레이어 캐릭터에 `UWxItemUseManagerComponent`를 부착하고, 어빌리티가 검증한 `ConsumableDef`를 임시 등록한 뒤 이벤트 시점에 서버에서 아이템 차감과 효과 적용을 한 번만 처리한다.
- `UWxAbility_UseItem`의 GameplayEvent AbilityTask, 콜백, 직접 사용 처리 책임을 제거한다.
- `UWxAnimNotify_FinisherDamage`를 추가해 `Event.ApplyFinisherDamage` GameplayEvent와 Notify·Mesh 페이로드를 발행한다.
- 플레이어 캐릭터에 `UWxFinisherDamageManagerComponent`를 부착하고, 처형 어빌리티가 확정한 대상과 `DamageDataRow`를 임시 등록한 뒤 이벤트 시점에 서버에서 피해를 한 번만 처리한다.
- `UWxAbility_Finisher`의 GameplayEvent AbilityTask, 콜백, 직접 피해 처리 책임을 제거한다.
- `UWxAnimNotify_ExecuteAbilityAction`은 이번에는 제거하지 않고 `Event.SummonActor`만 임시 허용해 향후 소환 재구현까지 보존한다.
- `AM_UseItem`, `AM_Finisher`, `AM_BackstabFinisher`의 공용 Notify를 전용 Notify로 교체하되 기존 시간과 트랙을 유지한다.
- UE 5.8에서 관련 에셋과 컴포넌트 부착 상태를 확인하고 WxEditor(Development) 타겟을 빌드한다.

## 완료

- `UWxAnimNotify_UseItem`과 `UWxItemUseManagerComponent`를 추가했다. 어빌리티는 검증한 `ConsumableDef`를 컴포넌트에 준비하고, 컴포넌트가 `Event.UseItem` 수신 시 서버에서 한 번만 아이템을 사용한다.
- `UWxAnimNotify_FinisherDamage`와 `UWxFinisherDamageManagerComponent`를 추가했다. 처형 어빌리티는 확정한 대상·`DamageDataRow`를 컴포넌트에 준비하고, 컴포넌트가 `Event.ApplyFinisherDamage` 수신 시 서버에서 한 번만 피해를 적용한다.
- `UWxAbility_UseItem`과 `UWxAbility_Finisher`에서 GameplayEvent AbilityTask·콜백·직접 실행 책임을 제거했다.
- 플레이어 캐릭터에 `ItemUseManagerComponent`와 `FinisherDamageManagerComponent`를 기본 서브오브젝트로 부착했다.
- `UWxAnimNotify_ExecuteAbilityAction`은 향후 소환 재구현까지 `Event.SummonActor`만 허용하도록 축소했다.
- `AM_UseItem`, `AM_Finisher`, `AM_BackstabFinisher`를 전용 Notify로 교체했다. 각각 기존 시간 0.276423초/트랙 0, 1.002579초/트랙 1, 1.120590초/트랙 0을 보존했다.
- 세 몽타주와 `GA_UseItem`, `GA_Finisher`, `BP_Player`가 저장된 상태이며 Blueprint 컴파일에서 경고·오류가 없었다.
- PIE에서 플레이어 인스턴스의 두 컴포넌트 부착과 BeginPlay 실행을 확인했다.
- 구현 직후 UE 5.8 `WxEditor Win64 Development` 전체 빌드가 성공했다. 최종 재빌드는 동시에 진행 중인 `WxSave`의 기존 API 불일치(`NotifyLevelRestoreFinished`, `OnRestoreReady` 선언 누락)에서 중단됐으며 이번 변경 파일의 컴파일 오류는 없었다.
- 소스와 에셋 검색에서 아이템·처형의 `UWxAnimNotify_ExecuteAbilityAction` 및 구 `Event.AbilityAction.*` 참조가 남지 않았고 `git diff --check`를 통과했다.
