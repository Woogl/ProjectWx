# WxDevice 상태 동기화 구조 개선

> 후속 변경: 2026-09-06 사용자 승인으로 커스텀 직렬화를 제거하고 엔진 기본 프로퍼티 복제로 전환했다. 현재 직렬화 방식 및 검증은 [기본 복제 전환 기록](2026-09-06-WxDevice-기본복제.md)을 참조한다. 아래 내용은 최초 구현 당시 기록이다.

## 계획

- 승인: 실제 적용 전이를 관측하여 직접 상호작용과 장치 이벤트의 재진입을 동일하게 처리하고 추측 플래그를 제거한다.
- 상태 태그, 진입 번호, 실행 상태, 상호작용자를 하나의 복제 구조체로 관리한다. 최초 수렴과 재진입을 구분한다.
- 미태그 기본 상태의 초기 수렴, 자동 완료 전 마지막 상태 기록, 클라이언트 선행 완료 복구를 지원하고 반복 실패를 제한한다.
- 상태 및 실패 이유를 로그와 디버그 정보에 노출한다.
- 조건 실패, 지연 전이, 자기 전이, 미태그 초기화, 자동 완료의 회귀 검증 및 UE 5.8 WxEditor Win64 Development 빌드를 수행한다.
- 기존 StateTree 에셋과 무관한 사용자 변경은 보존한다.

## 완료

- 실제 적용 전이 직전과 틱 종료 시 활성 태그/인스턴스를 관측하는 실행 확장을 구현했다. 발행 예약 플래그와 재진입 멀티캐스트를 제거하고 직접 상호작용·장치 이벤트를 같은 경로로 처리한다.
- FWxDeviceStateSnapshot으로 태그·진입 번호·실행 상태·당사자를 함께 직렬화한다. 최초 수신의 과거 재생, 동일 번호 완료 수신의 중복 요청, 미해소 당사자로의 진입을 방지한다.
- 미태그 초기 상태 수렴, 동일 틱 마지막 진입·완료 기록, 완료한 클라이언트 복구를 지원한다. 요청·복구는 같은 목표당 3회로 제한하고 실패 원인을 한 번 기록한다.
- 실제 RunStatus를 IsRunning에 반영하여 완료한 장치는 상호작용 후보에서 제외한다. 전이 처리 중 Start/Restart는 실행 확장을 교체하지 않도록 방어한다.
- DescribeSynchronization 및 Gameplay Debugger에 현재/목표 태그·번호·실행 상태·재시도 횟수·당사자 대기·초기 목표·오류를 노출했다.
