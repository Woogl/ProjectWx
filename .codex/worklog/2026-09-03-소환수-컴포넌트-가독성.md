# 소환수 컴포넌트 가독성 개선

## 계획

- `UWxMinionComponent`의 공개 API, 서버 권한, 처리 순서와 반환값은 변경하지 않는다.
- 소환수 배열 순회에서 유효하지 않은 액터와 ASC를 `continue`로 먼저 제외해 성공 경로의 중첩을 줄인다.
- 내비게이션 투영처럼 두 조건이 모두 필요한 짧은 분기는 조건을 결합해 중첩을 줄인다.
- 정확 태그 후보 발동은 실패 시 `continue`, 성공 시 즉시 반환하는 형태로 정리한다.
- 새 소환수 자리를 만들기 위한 제거 수를 먼저 계산해 기존 `while` 반복의 의도를 명확히 한다.
- 변경 전과 같은 UE 5.8 `WxEditor` Development 빌드를 실행해 동작 보존을 검증한다.

## 완료

- 권한 검사와 어빌리티 태그 검사를 별도 early return으로 나눠 실패 원인을 읽기 쉽게 했다.
- 종료 시 소환수 파괴, 명령 대상 순회, 사망 소환수 제거에서 유효하지 않은 대상을 `continue`로 먼저 제외했다.
- 내비게이션 시스템 존재와 투영 성공 조건을 한 분기로 결합해 중첩을 줄였다.
- 정확 태그 후보 발동은 실패 시 `continue`, 성공 시 즉시 반환하도록 정리했다.
- 소환 전에 제거할 수를 계산하고 그 횟수만 반복하도록 바꿔, 기존 `while`의 목적과 종료 조건을 명확히 했다. 오래된 소환수의 파괴 후 배열 제거 순서는 보존했다.
- 공개 API, 처리 순서, 반환값과 GAS 발동 정책은 변경하지 않았다.
- UE 5.8 `WxEditor Win64 Development` 빌드 성공.
