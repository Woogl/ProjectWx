# 네임플레이트 Scale 입력 구조체 제거

## 계획

- 사용자 지시에 따라 FWxNameplateScaleInput과 ScaleInput 필드를 제거하고 Distance, ReferenceDistance, MinScale, MaxScale 개별 FieldNotify 필드로 풀어 쓴다.
- Conversion Library는 네 값을 개별 인자로 받아 기존 Scale 공식을 유지한다.
- 저장된 WBP의 변환 입력 핀을 네 VM 필드에 연결한 뒤 기존 구조체를 제거한다. 이전 형식은 에셋 전환 중에만 유지한다.
- 기존 회귀 테스트를 갱신하고 각 설정값 변경에 대한 WBP 반영을 확인한다. UE 5.8 WxEditor Development 빌드와 Wx.UI 테스트를 수행한다.

## 완료

- FWxNameplateScaleInput과 ScaleInput 필드 및 이전 변환 함수를 제거했다. 네 값을 개별 FieldNotify 필드 및 Conv_DistanceToNameplateScale 인자로 전달한다.
- WBP_Nameplate_Enemy의 기존 Scale 바인딩을 네 개 변환 입력 핀으로 이전하고 컴파일·저장했다. 임시 이전 도구와 추가 에디터 의존성은 제거했다.
- 거리 변화뿐 아니라 정지 상태에서 ReferenceDistance, MinScale, MaxScale 각각의 변경도 실제 WBP RenderScale에 반영되는 회귀 검증을 추가했다.
