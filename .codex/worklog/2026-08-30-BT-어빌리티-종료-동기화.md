# BT 어빌리티 종료 동기화

## 계획

- `UWxBTTask_ActivateAbility`가 취소 요청 직후 종료 델리게이트를 해제하지 않도록 수정한다.
- BT Abort가 요청된 뒤에는 어빌리티의 실제 종료 통지를 기다리고, 정상·취소 종료 여부와 무관하게 `FinishLatentAbort`로 완료한다.
- 동기 취소와 태스크 수명 종료에서도 델리게이트가 안전하게 정리되도록 상태 및 정리 경로를 보완한다.
- Abort 대기 상태는 `UBehaviorTreeComponent`의 태스크 상태로 판별하고, 동기 취소 재진입만 로컬 플래그 하나로 보호하도록 간소화한다.
- UE 5.8의 `WxEditor` Development 타겟을 빌드해 컴파일을 검증한다.

## 완료

- `AbortTask`가 취소 요청 뒤 종료 델리게이트를 유지하고, 활성 어빌리티는 실제 종료까지 지연 Abort하도록 수정했다.
- BT Abort 대기 중 종료는 정상·취소 여부와 무관하게 `FinishLatentAbort`로 마감하도록 처리했다.
- 동기 취소와 태스크 종료 시 델리게이트 정리 경로를 보완했다.
- Abort 대기 여부는 `GetTaskStatus(this) == EBTTaskStatus::Aborting`으로 판별하도록 간소화하고, 동기 콜백 방지 플래그 하나만 유지했다.
- `WxEditor Win64 Development` 빌드에 성공했다.
