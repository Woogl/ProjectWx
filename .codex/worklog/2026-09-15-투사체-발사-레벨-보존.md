# 투사체 발사 레벨 보존

## 계획

- 발사 시 어빌리티 레벨을 값으로 저장한다. 어빌리티가 없으면 1을 사용한다.
- 초기 충돌 전에 저장을 완료하고 비행 및 반사 후에도 유지한다.
- 저장 레벨을 적중 피해 GE와 추가 효과에 전달하고 독립 패시브 판정을 유지한다.
- 추가 사용자 요청: 근접·광역·피니셔도 출처 어빌리티 레벨을 사용한다. 명시한 발사 레벨을 우선하고 어빌리티가 없으면 1로 처리한다. 레벨 전달·반사 보존 확인 및 UE 5.8 WxEditor Development 빌드를 수행한다.

## 완료

- SpawnProjectile 노티파이가 발사 시 어빌리티 레벨(없으면 1)을 읽어 전달한다. 서브시스템은 지연 스폰을 사용하고 FinishSpawning 전에 투사체의 레벨을 저장한다.
- 서버 전용 피해 레벨은 투사체가 보관하며 반사 시 변경하지 않는다. 클라이언트 연출용 레벨 복제는 추가하지 않았다.
- ApplyDamage에 DamageLevel 인자를 추가했다. 명시된 값이 우선이며 생략(음수) 시 출처 어빌리티 레벨, 출처가 없으면 1을 사용한다. 근접·광역·피니셔도 같은 경로로 적용된다.
- 이전에 요청한 SourceAbility 기본 인자 제거를 반영했다. C++ 호출부는 모두 명시 전달한다. 투사체의 nullptr 및 패시브 발동 키 보존 로직을 유지한다.
- MakeHitSpec에 레벨을 전달하여 타격 GE, 연결된 피해 GE, 추가 효과에 적용한다. 기본 피해 공식에 임의의 레벨 배수는 추가하지 않았다.
