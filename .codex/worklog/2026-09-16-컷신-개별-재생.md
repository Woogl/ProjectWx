# 컷신 개별 재생 단순화

## 계획

- 사용자가 승인한 대로 각 머신이 같은 시퀀스를 동일 시전자와 공통 원점에 바인딩하고 로딩 후 처음부터 재생한다.
- PlayerController의 WxSkillCutsceneClientComponent와 준비 응답·왕복 시간 동기화 코드를 제거한다.
- GameState의 서버 상태와 로컬 재생 상태를 분리한다. 정상 서버 완료는 로컬 컷신을 끊지 않으며 강제 취소는 해당 세션을 정리한다. 늦게 도착한 다음 세션은 순서대로 재생한다.
- AbilityTask는 서버 세션 종료를 기다리는 기존 의미와 LocalPredicted를 유지한다. 기존 포즈 제한 해제·복원은 유지한다.
- 감속과 무관한 로컬 실시간으로 재생한다. 로컬 로딩 실패·시간 초과를 정리하고 서버는 자신의 완료 기준으로 감속과 무적을 복원한다.
- UE 5.8 WxEditor Development 빌드와 컷신 회귀 테스트를 실행한다. 정상 종료와 강제 취소를 구분하는 테스트를 추가한다.

## 완료

- WxSkillCutsceneClientComponent 헤더·구현과 PlayerController 부착 코드를 제거했다. 참가자 목록, 준비 RPC, 공통 시작 시각, 왕복 지연·시계 보정을 제거했다.
- 복제 State와 로컬 LocalState를 분리했다. 시작 상태를 받으면 자체 로딩 후 시퀀스 처음부터 재생한다. 동일한 State.Avatar와 Origin을 로컬 세션에 보존하고 로컬 폰 대체는 하지 않는다.
- 서버 정상 종료는 클라이언트 로딩·재생을 중단하지 않는다. 각 로컬 시퀀스의 OnFinished에서 카메라·시퀀스와 포즈 설정을 정리한다. 새 세션은 이전 세션 완료 후 순서대로 재생하며 강제 취소는 일치하는 현재/대기 세션만 정리한다.
- 각 머신의 플랫폼 시계로 재생 속도를 유지한다. 전용 서버는 시퀀스 길이만큼 실시간으로 기다리며, 화면이 있는 서버는 자신의 시퀀스 완료를 기준으로 게임플레이를 진행한다. 서버의 감속·무적 복원과 AbilityTask 완료는 다른 클라이언트의 재생 완료를 기다리지 않는다.
