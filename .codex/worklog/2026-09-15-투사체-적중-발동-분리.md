# 투사체 적중 발동 분리

## 계획

- ApplyDamage가 출처 어빌리티를 명시적으로 받도록 하고 근접·광역·피니셔 호출부에서 전달한다. 투사체는 독립 적중으로 처리한다.
- 독립 적중이 기존 패시브 지급 발동 키를 지우지 않도록 수정한다.
- 기존 변경을 보존하고 호출 경로 및 UE 5.8 WxEditor Development 빌드로 검증한다.

## 완료

- ApplyDamage의 AnimatingAbility 자동 조회를 제거하고 명시적 SourceAbility 인자를 추가했다. 근접·광역·피니셔는 출처를 전달하며 투사체는 nullptr로 독립 적중 처리한다.
- 무효 키를 가진 독립 적중은 기존 ChargedActivationKey를 덮어쓰지 않아 근접 → 투사체 → 같은 근접 추가 적중의 중복 지급을 방지한다.
- C++ 호출부 4곳 및 변경 diff를 확인했고 git diff --check를 통과했다. 기존 사용자 변경은 보존했다.
- 최초 제한 환경 빌드는 진단 출력 없이 종료됐다. build-doctor를 샌드박스 밖에서 실행한 UE 5.8 WxEditor Win64 Development 빌드는 성공(종료 코드 0)했다.
- 빌드 로그: C:/Wx/Saved/Logs/BuildDoctor/build_2026-09-15_020157_454_21324.log
