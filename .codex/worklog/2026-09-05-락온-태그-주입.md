# 락온 태그 주입

## 계획

- `Ability.LockOn`은 플레이어의 어빌리티 활성 태그로 유지하고, 피대상 상태용 `State.LockedOn` 네이티브 태그를 `WxCore`에 추가한다.
- `UWxAbilityTask_LockOnCamera`가 대상을 바인딩할 때 대상 ASC에 로컬 Loose Tag를 추가하고, 재타겟팅·해제 시 캐시한 기존 대상에서 제거한다.
- `UWxNameplateComponent`의 기본 `VisibilityRequirements`에 `State.LockedOn`을 필수 태그로 추가해, `락온 중 && 3000cm 이내 && 생존`을 기본 표시 조건으로 한다.
- 태그 선언·정의·생산·소비 참조와 포맷을 확인하고, UE 5.8 `WxEditor` Win64 Development 빌드로 검증한다.

## 완료

- `WxCore`에 네이티브 `State.LockedOn`을 추가했다. `Ability.LockOn`은 기존대로 플레이어 어빌리티 활성 의미로만 유지한다.
- 로컬 소유 플레이어에서만 실행되는 `UWxAbilityTask_LockOnCamera`가 대상 바인딩 시 Loose Tag를 추가하고, 재타겟팅·해제 시 캐시한 기존 대상에서 제거하도록 했다.
- `UWxNameplateComponent`의 기본 필수 태그로 `State.LockedOn`을 설정했다. 기본 표시 조건은 `State.LockedOn && 3000cm 이내 && !Ability.Death`다.
