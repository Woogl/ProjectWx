# 선택 대상 타겟팅 필터

## 계획

- `WxCombat`에 `UWxTargetingFilterTask_SelectedTarget`을 추가한다.
- 플레이어 캐릭터는 `UWxLockOnComponent`의 락온 대상, AI 캐릭터는 사용자가 입력한 Blackboard Object 키의 액터를 선택 대상으로 사용한다.
- 선택 대상이 있으면 해당 액터만 통과시키고, 선택 대상이 없으면 어떤 후보도 필터링하지 않는다.
- `WxCombat`의 기존 `AIModule`·`TargetingSystem` 의존성을 활용하며 `WxAI` 의존성은 추가하지 않는다.
- UE 5.8 `WxEditor` Development 빌드로 컴파일을 검증한다.

## 완료

- `UWxTargetingFilterTask_SelectedTarget` 헤더와 구현을 `WxCombat`에 추가했다.
- 플레이어의 락온 컴포넌트 대상을 우선 사용하고, 없으면 AI Controller Blackboard에서 사용자가 지정한 Object 키를 조회하도록 구현했다.
- 선택 대상이 있을 때 다른 후보만 제외하며, 소스·키·대상이 없거나 키 값이 액터가 아니면 필터를 적용하지 않도록 했다.
- `WxAI` 의존성이나 기존 모듈 설정은 변경하지 않았다.
- UE 5.8 `WxEditor Win64 Development` 빌드 성공을 확인했다.
