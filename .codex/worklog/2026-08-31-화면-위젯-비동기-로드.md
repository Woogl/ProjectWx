# 화면 위젯 비동기 로드

## 계획

- 미사용 동기 API인 `PushSoftContentToLayer`를 `UWxUIManagerSubsystem`과 `UWxUILibrary`에서 제거한다.
- 사망·대화·HUD 화면을 기존 `UWxAsyncAction_PushWidgetToLayer` 경로로 전환한다.
- 비동기 액션에 C++ 완료 콜백과 취소 기능을 추가한다.
- 대화 종료·HUD 컴포넌트 종료·레이아웃 교체 중인 요청은 취소하여 뒤늦게 위젯이 나타나는 것을 방지한다.
- 로드 시작 당시 레이아웃이 교체된 경우 결과를 폐기해 월드 전환 후 잘못된 화면에 push되지 않게 한다.
- 관련 README와 리뷰 항목을 갱신한다.
- UE 5.8 설치 경로를 런처 정보에서 조회한 뒤 `WxEditor Development` 빌드로 검증한다.
- 현재 작업 트리의 다른 변경사항은 건드리지 않는다.

## 완료

- `UWxUIManagerSubsystem`·`UWxUILibrary`의 `PushSoftContentToLayer` 동기 API를 제거했다.
- 사망·대화·HUD 화면을 `UWxAsyncAction_PushWidgetToLayer` 비동기 스트리밍 경로로 전환했다.
- 비동기 액션에 C++ 완료 콜백과 취소를 추가하고, 요청 시작 당시 레이아웃이 교체되면 결과를 폐기하도록 했다.
- 대화 종료·HUD 컴포넌트 종료 시 진행 중 요청을 취소하며, push 도중 재진입 취소가 발생하면 추가된 위젯도 즉시 비활성화한다.
- `Plugins/WxUI/README.md`의 소프트 클래스 push 규약과 `Docs/Programmer/module_review_WxUI.md`의 7번 후속 조치를 갱신했다.
- 정적 확인: WxUI/게임 소스에 `PushSoftContentToLayer` 참조가 남지 않았고 `git diff --check`를 통과했다.
- 검증: 런처 정보에서 UE 5.8.2 설치 경로를 조회해 `WxEditor Win64 Development` 빌드에 성공했다. 최종 로그는 `.Codex/skills/build-doctor/logs/build_2026-08-31_021122.log`다.
- 첫 검증은 동시에 수정 중이던 `WxNameplateComponent.cpp`의 C4458로 중단됐으나, 해당 작업에서 원인이 제거된 뒤 본 작업 파일을 추가 수정하지 않고 전체 빌드 성공을 확인했다.
