# Ability 카테고리 우선순위 메타데이터

## 계획

- `UWxAbilityBase`, `UWxAbilityAction`에 엔진 순정 `PrioritizeCategories=("Wx")` 메타데이터를 적용한다.
- 전역 `UObject` Detail Customization 등록과 구현 파일을 제거해 인라인 Action 상세 패널의 재귀 경로를 없앤다.
- `WxEditor` Development와 DebugGame 타겟을 빌드한다.

## 완료

- `UWxAbilityBase`, `UWxAbilityAction`에 `PrioritizeCategories = ("Wx")`를 적용했다.
- `UObject` 전역 Detail Customization 등록과 `WxCategoryDetailCustomization` 파일을 제거했다.
- `WxEditor Win64 Development` 빌드와 UnrealHeaderTool 검사가 성공했다.
- DebugGame 빌드는 실행 중인 에디터의 Live Coding 잠금으로 실행하지 못했다.
