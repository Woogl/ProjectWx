# Wx 카테고리 정렬 재귀 수정

## 계획

- 전역 `Wx` 카테고리 최상단 정렬 기능은 유지한다.
- 카테고리를 새로 만드는 `EditCategory()` 기반 구현을 엔진 순정 `SortCategories()` 기반 정렬로 교체한다.
- `AbilityActions` 인라인 UObject 상세 패널에서 카테고리 생성이 재귀하지 않도록 한다.
- `WxEditor` Development와 DebugGame 타겟을 빌드한다.

## 완료

- `EditCategory()` 호출을 제거하고 `SortCategories()` 기반으로 교체했다.
- 빌드는 성공했지만 `UObject` 전역 Detail Customization 범위에서 발생하는 Action 추가 크래시는 해소되지 않았다.
- 전역 등록을 제거하고 클래스 메타데이터로 전환하는 후속 작업으로 대체했다.
