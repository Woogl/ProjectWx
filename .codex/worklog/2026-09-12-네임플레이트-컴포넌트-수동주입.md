# 네임플레이트 컴포넌트 복원과 수동 뷰모델 주입

## 계획

- 사용자가 승인한 역할 분담에 따라 UWxNameplateComponent를 복원한다. 컴포넌트는 공유 Character VM 수동 주입과 플레이어 유무·거리 기반 가시성 및 스케일을 담당한다.
- UWxViewModel_Nameplate와 네임플레이트 리졸버를 제거하고 Character VM에는 Distance나 bHasViewer를 추가하지 않는다.
- WBP는 Character.AbilitySystem.OwnedTags의 기존 이벤트 기반 갱신을 사용해 태그 가시성을 판단한다. 기존 내용 바인딩과 표시 조건·거리·스케일 설정을 보존한다.
- 거리 갱신은 컴포넌트의 기존 TickComponent에서 처리한다. 사용자의 후속 지적을 반영해 별도 NameplateSubsystem은 두지 않는다. 위젯 교체·재등록·플레이어 부재 후 복구·해제 경로를 처리하고 공유 VM을 해제하지 않는다.
- 에셋을 정식 UE 편집 API로 변경·컴파일·저장하고 기존 네이티브 컴포넌트 오버라이드를 확인한다. UE 5.8 WxEditor Development 빌드 및 표시·태그·수명 회귀 검증을 수행한다.

## 완료

- UWxNameplateComponent를 복원하고 AWxEnemyCharacter의 동일 이름 서브오브젝트에 적용했다. 기존 WidgetComponent 클래스 리다이렉트를 제거했다.
- 위젯 초기화·교체 시 ASC별 공유 Character VM을 수동 주입한다. 재등록과 늦은 ASC 준비는 기존 컴포넌트 틱에서 재시도하며, 위젯 교체·해제 시 소스 참조만 끊고 공유 VM은 유지한다.
- 거리 제한·플레이어 부재·스케일은 기존 TickComponent에서 처리한다. 기본 컴포넌트 틱 전에 가시성을 계산하며, 별도 서브시스템·코어 티커·거리 VM 필드는 두지 않는다.
- UWxViewModel_Nameplate, UWxViewModelResolver_NameplateCharacter, 거리 기반 MVVM 변환 2개를 제거했다. Character VM에는 Distance와 bHasViewer를 추가하지 않았다.
- WBP_Nameplate_Enemy의 Character 소스를 Manual로 바꾸고 스케일 바인딩을 제거했다. 가시성은 Character.AbilitySystem.OwnedTags와 기존 태그 요구 조건을 사용하는 Conv_TagRequirementsToVisibility에 연결했다. 기본 거리 3000cm, 기준 거리 1000cm, 스케일 0.5~1 및 기존 내용 바인딩을 보존했다.
- 에셋 편집 API로 컴파일·저장한 뒤 새 프로세스에서 재저장하여 이전 리졸버 참조까지 제거했다. UI·Character·외부 액터 에셋에서 삭제한 VM·리졸버·변환 이름이 남지 않음을 확인했다. 임시 에셋 편집 코드와 편집기 모듈 의존성은 제거했으며 재현 코드는 Saved/WxMigrateNameplateComponent.cpp에 남겼다.
